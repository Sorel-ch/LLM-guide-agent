| see | 第一段 | 缺 | - | - | - | 关渡、贵子坑到二子坪游客服务站，约10公里，步行约7至8小时。本段山脉属于火山地形，由山顶向西北可远望淡水河流域、关渡平原，关渡夕照更是令人惊艳的美景，向南则可俯瞰台北盆地，并经过贵子坑水土保持园区，有台北最古老地质-五指山层，另本区之二子坪步道拥有5科180种之蝴蝶，有「蝴蝶花廊」的美誉。 |
| see | 第二段 | 缺 | - | - | - | 二子坪游客服务站、大屯山、竹子湖至小油坑游客服务站，约9公里，步行约6至7小时。本段步道经过大屯山观景平台可赏著名的「大屯夕照」、「大屯云海」的最佳观景点，另经过竹子湖可一览四周山景，将小油坑壮阔的景致，及沿溪环绕观赏花卉，春天赏海芋、夏天赏绣球花、秋天赏芒草美景。 |
| see | 第三段 | 缺 | - | - | - | 小油坑游客服务站、七星山、擎天岗至风柜口，约14公里，步行约7至8小时。本段步道途经台北最高峰七星山主峰1120公尺，顶山石梯岭步道四季可赏柳杉林，再经擎天岗之大片草原，可见擎放牧牛只漫步于草原上之景色。 |
| see | 第四段 | 缺 | - | - | - | 风柜口、双溪沟古道、五指山古道、白石湖、圆觉瀑布至大沟溪亲水公园，约16公里，步行约6至7小时。本段步道由古道开始，古道内维持山林原始之自然风貌，如同走进侏㑩纪公园之蕨类森林，穿出古道到达白石湖地区有吊桥、草莓园及各季花卉，再经圆觉瀑布到达大沟溪生态治水园区。 |
| see | 第五段 | 缺 | - | - | - | 剑潭山支线，由捷运剑潭站经圆山风景区、剑南山、大仑头尾山至碧山岩，约13公里，步行约6至7小时。石阶绵延的大仑头尾山步道后，进入剑潭山亲山步道有老地方观机平台，可观赏飞机起降及夕阳，步出步道后通往士林夜市，来个美食之旅作为Ending。 |
| see | 第六段 | 缺 | - | - | - | 中华科技大学起点，经过四兽山、九五峰、拇指山至捷运麟光站，约12公里，步行约5至6小时。本段为森林景观丰富多样的步道，邻近四兽山步道群及永春陂湿地，步道制高点九五峰，登上高处，每一个角度都能远眺台北101，还有城市的美景， 再经保留低海拔森林及溪流等自然资源，是城市中难得的生态乐园的富阳生态公园结尾。 |
| see | 第七段 | 缺 | - | - | - | 捷运麟光站、福州山、猫空至政治大学，约12公里，步行约5至6小时。由传奇庄严的指南宫竹柏参道开始，路过百年历史之石灯笼，再经大地处设置之透水步道，通达小天空步道及猫空缆车站，再经过沿途有多种不同花卉的樟树步道，通往知性之政大校园。 |
| see | 环台北之径 | 缺 | - | - | - | 完成台北大纵走主线一到第七段路线后，可于动物园串联景美河河滨自行车道，再经由新店溪河滨自行车道，连接淡水河河滨自行车道，最后可至关渡捷运站，再回到大纵走第一段，完成环绕台北一圈的壮举。 |
