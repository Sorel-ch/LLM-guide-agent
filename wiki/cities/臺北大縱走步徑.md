| see | 第一段 | 缺 | - | - | - | 關渡、貴子坑到二子坪遊客服務站，約10公里，步行約7至8小時。本段山脈屬於火山地形，由山頂向西北可遠望淡水河流域、關渡平原，關渡夕照更是令人驚豔的美景，向南則可俯瞰臺北盆地，並經過貴子坑水土保持園區，有臺北最古老地質-五指山層，另本區之二子坪步道擁有5科180種之蝴蝶，有「蝴蝶花廊」的美譽。 |

| see | 第四段 | 缺 | - | - | - | 風櫃口、雙溪溝古道、五指山古道、白石湖、圓覺瀑布至大溝溪親水公園，約16公里，步行約6至7小時。本段步道由古道開始，古道內維持山林原始之自然風貌，如同走進侏儸紀公園之蕨類森林，穿出古道到達白石湖地區有吊橋、草莓園及各季花卉，再經圓覺瀑布到達大溝溪生態治水園區。 |
