'''野柳地質公園'''，又稱為'''野柳風景區'''，是位於[[臺灣]][[新北市]][[萬里區]]野柳里的風景區，屬於[[北海岸及觀音山國家風景區]]範圍內。受到風化、海蝕及地殼運動等作用，造就了海蝕洞、豆腐石及壺穴等奇景，因而成為[[台灣北海岸|臺灣北海岸]]知名的[[旅遊景點]]之一<ref>{{Cite web |title=野柳地質公園 |url=https://newtaipei.travel/zh-tw/attractions/detail/109735 |website=新北市觀光旅遊網 |language=zh-tw |archive-url=https://web.archive.org/web/20250928090940/https://newtaipei.travel/zh-tw/attractions/detail/109735 |archive-date=2025-09-28 |access-date=2025-11-27 |dead-url=no }}</ref>。

野柳地區為[[大屯山]]山脈延伸至[[東海]]之[[岬角]]，全區長約1700[[公尺]]、寬約250公尺。<ref>{{Cite web |title=【打卡景點】全台7座地質公園，特殊岩石環境海蝕景觀！ |url=https://tw.news.yahoo.com/%E3%80%90%E6%89%93%E5%8D%A1%E6%99%AF%E9%BB%9E%E3%80%91%E5%85%A8%E5%8F%B0-7-%E5%BA%A7%E5%9C%B0%E8%B3%AA%E5%85%AC%E5%9C%92%EF%BC%8C%E7%89%B9%E6%AE%8A%E5%B2%A9%E7%9F%B3%E7%92%B0%E5%A2%83%E6%B5%B7%E8%9D%95%E6%99%AF%E8%A7%80%EF%BC%81-001154414.html |website=Yahoo News |date=2021-05-19 |language=zh-Hant-TW |access-date=2025-11-27}}</ref>此處地景因[[造山運動]]、[[風化]]及[[海蝕]]等[[地质作用|作用]]而呈現奇特形態的[[蕈狀岩]]，包含「[[女王頭]]」、「仙女鞋」、「蕈狀石」、「燭臺石」、「薑石」、「[[單面山]]」等特殊景觀。<ref>{{Cite web|url=http://www.ylgeopark.org.tw/content/info/YlIntroduction.aspx|title=野柳地質公園簡介|accessdate=2017-03-26|last=|work=野柳地質公園|archive-date=2020-05-26|archive-url=https://web.archive.org/web/20200526102510/http://www.ylgeopark.org.tw/content/info/YlIntroduction.aspx|dead-url=no}}</ref>

== 地名來由 ==
[[大航海時代]]，[[西班牙]]人經常乘船航行於[[基隆]]與[[淡水區|淡水]]之間，常常在當地[[岬角]]觸礁擱淺並遭[[原住民]]洗劫。因此，他們在[[地圖]]上將當地標示為“{{lang|es|Punto Diablos}}”（「魔鬼岬」，在[[西班牙語]]中，“{{lang|es|Punto}}”意為「岬角」、“{{lang|es|Diablo}}”意為「魔鬼」）。後來，[[臺灣西班牙統治時期|荷蘭人在打敗西班牙人後]]將當地標示為“{{lang|nl|Duijvel hoek}}”或“{{lang|nl|Caap Diable}}”（原名在[[荷蘭文]]中之翻譯）。<ref>{{Cite web|url=http://gushi.tw/%E3%80%90%E8%87%BA%E7%81%A3%E5%9C%B0%E5%90%8D%E7%9C%9F%E7%9B%B8%E3%80%91%E9%87%8E%E6%9F%B3%E8%B7%9F%E9%87%8E%E7%94%9F%E7%9A%84%E6%9F%B3%E6%A8%B9%E6%9C%89%E9%97%9C%E4%BF%82%E5%97%8E%EF%BC%9F/|title=【臺灣地名真相】野柳跟野生的柳樹有關係嗎？|accessdate=2017-03-27|author=|date=2017-03-27|publisher=[[故事]]|deadurl=yes|archiveurl=https://web.archive.org/web/20170327191352/http://gushi.tw/%E3%80%90%E8%87%BA%E7%81%A3%E5%9C%B0%E5%90%8D%E7%9C%9F%E7%9B%B8%E3%80%91%E9%87%8E%E6%9F%B3%E8%B7%9F%E9%87%8E%E7%94%9F%E7%9A%84%E6%9F%B3%E6%A8%B9%E6%9C%89%E9%97%9C%E4%BF%82%E5%97%8E%EF%BC%9F/|archivedate=2017-03-27}}</ref>之後因漢人將“{{lang|es|Diablos}}”省稱並轉音為“{{lang|nan-latn|iá-liú}}”（{{lang-nan-tw|han=野柳}}）而得名。

== 地理 ==
當地[[地層]]主要為[[中新世]]野柳群大寮層<ref>{{Cite web |title=臺灣地景保育網 地景保育通訊 |url=https://landscape.forest.gov.tw/Front/LandscapeNews/communication/Periodicals.aspx?id=7KShBTi6PLM=&Cn=33&Sn=252 |website=landscape.forest.gov.tw |access-date=2025-11-27}}</ref>，分布於萬里區[[龜吼漁港|龜吼]]至萬里區[[國聖埔]]海灘，主要由1000萬年至2500萬年前生成之厚層[[砂岩]]所構成，[[顏色]]多呈[[青]][[灰]]色或[[黃]]灰色。

== 經營 ==
[[戰後台灣|戰後]]，野柳風景區一度為臺北縣[[萬里鄉 (台灣)|萬里鄉]][[公共物品|公共造產]]。

1978年，當地改由[[臺北縣政府]]管理，並設置「臺北縣野柳風景特定區管理所」負責經營；當時，園區[[門票]]正面印有「野柳[[烏來]]風景特定區」字樣，背面印有「實踐[[三民主義]]　建立安和社會　復興[[中華文化|民族文化]]　堅守[[中華民國與美國關係|民主陣容]]」的字樣。<ref>{{Cite web|title=解說員日誌～野柳「門票」|url=https://lkk96tw.blogspot.com/2007/03/blog-post_9133.html?m=1|date=2007-03-15|access-date=2023-06-04|archive-date=2023-06-04|archive-url=https://web.archive.org/web/20230604100220/https://lkk96tw.blogspot.com/2007/03/blog-post_9133.html?m=1|dead-url=no}}</ref>

2002年，[[交通部觀光局]]成立[[北海岸及觀音山國家風景區]]管理處，並將野柳風景特定區納入轄下。2006年，野柳風景特定區[[委外經營]]由「新空間國際有限公司」營運<ref>{{Cite web |title=看見好的台灣 看好台灣觀光的未來 賴瑟珍看台灣：成功翻轉、野柳成為國際級地標的推手─野柳地質公園總經理楊景謙 |url=http://b2b.travelrich.tw/newweb/news_into.aspx?Second_classification_id=44&Subject_id=30927 |website=看見好的台灣 看好台灣觀光的未來 賴瑟珍看台灣：成功翻轉、野柳成為國際級地標的推手─野柳地質公園總經理楊景謙 |access-date=2025-11-27}}</ref>，並隨後改稱「野柳地質公園」，發展野柳的生態與觀光事業。

2010年，「野柳地質公園委託經營案」獲得[[行政院公共工程委員會]][[金擘獎]]。
