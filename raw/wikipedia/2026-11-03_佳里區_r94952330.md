'''佳里區'''（{{Lang-nan-tw|tl=Ka-lí-khu}}），舊稱「蕭{{zy|壠|lǒng|ㄌㄨㄥˇ|lung<sup>5</sup>}}社」(旌義)、「[[佳里興]]」，前身「佳里鎮」，位於[[臺灣]][[臺南市]]西部，北鄰[[學甲區]]，西鄰[[將軍區]]，西南連[[七股區]]，東鄰[[麻豆區]]，南接[[西港區]]。全境地勢平坦，海拔約5.5公尺，境內有[[將軍溪]]與七股溪流經。區內人口約有5.8萬人，[[2010年中華民國縣市改制直轄市|縣市合併]]前為全[[臺南縣|縣]]人口最多的[[鎮 (中華民國)|鎮]]。

佳里區是[[北門郡|大北門地區]]鹽分地帶的門戶及政經中心。[[台灣日治時期|日治時期]]以來出了許多鹽分地帶文學家及詩人，被視為臺灣文學重鎮。此外也是[[西拉雅]]系平埔族蕭壠社的聚居地，為臺灣最早的西拉雅文化發源地之一。代表農作物為[[牛蒡]]，有'''牛蒡的故鄉'''之美譽。該區[[足球]]風氣鼎盛，該四級足球球隊皆曾獲全國足球冠軍。

== 歷史 ==
佳里區舊稱「[[蕭壠堡|蕭壠]]」或「蕭壟」（{{lang-nan-tw|tl=Siau-lang／Siau-lâng}}）<ref>{{Cite web |url = https://twblg.dict.edu.tw/holodict_new/result_detail.jsp?n_no=40235&curpage=1&sample=%E8%95%AD%E5%A3%9F&radiobutton=1&querytarget=1&limit=20&pagenum=1&rowcount=1 |title = 蕭壟《臺灣閩南語常用詞辭典》 |author = 教育部《臺灣閩南語常用詞辭典》編輯委員會 |date = 2011年07月 |publisher = 中華民國教育部 |language = zh-tw |accessdate = 2020年11月21日 |archive-date = 2020年11月28日 |archive-url = https://web.archive.org/web/20201128210235/https://twblg.dict.edu.tw/holodict_new/result_detail.jsp?n_no=40235&curpage=1&sample=%E8%95%AD%E5%A3%9F&radiobutton=1&querytarget=1&limit=20&pagenum=1&rowcount=1 |dead-url = no }}</ref>及「[[佳里興]]」。
蕭壠為[[平埔族|平埔原住民]][[西拉雅族]]社名「Saulang」之音譯，意為「契約之地」。昔日蕭壠社與新港社（今新市）、目加溜灣社（今善化）、麻荳社（今麻豆）共稱平埔族四大社。<ref>{{Cite web |url=http://web2.tainan.gov.tw/Jiali/CP/10667/history-1.aspx |title=《關於佳里鎮》，臺南縣佳里鎮公所官網 |accessdate=2010-03-29 |archive-date=2010-04-29 |archive-url=https://web.archive.org/web/20100429075849/http://web2.tainan.gov.tw/Jiali/CP/10667/history-1.aspx |dead-url=no }}</ref>「蕭壠（Soulang）」一語有「河川曲流處」的意思，剛好可以說明這個社的特色：位於[[曾文溪]]下游，瀕臨河岸亦靠近海口，是各社中最依賴魚產的村子。<ref>[http://www.books.com.tw/exep/prod/booksfile.php?item=0010391773 《舊文獻.新發現 台灣原住民歷史文獻解讀》]{{Dead link|date=2018年8月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>[[荷治時期]]荷蘭人曾授予蕭壠社民牛隻使用，為第一批引進台灣的牛隻。另外荷蘭人為了在地的基督教信仰教育，1659年也在此設立東印度地區第一間以當地人為招募對象的「蕭壠神學院」，這也成為了臺灣第一所神學院。<ref>[http://culture.tainan.gov.tw/form/index-1.php?m2=252&id=1597 《蕭壟神學院》 - 臺灣第一在臺南] {{Wayback|url=http://culture.tainan.gov.tw/form/index-1.php?m2=252&id=1597 |date=20200808202426 }}，臺南市政府文化局</ref>

明鄭時期，鄭成功死亡之後，鄭襲和鄭經因為繼位問題爆發戰爭，雙方軍隊就此在佳里區交戰。

[[康熙|清朝初年]]間，有艘[[王船]]沿古曾文溪而上停駐於蕭壠東勢角一帶，居民逐恭請[[十二瘟王|玉勅代天巡狩千歲爺]]，巡按人間，監察善惡，掃除瘟疫邪煞，訪查民瘼，燮理陰陽，按察出巡祈求合境平安，從此為了防止天災地變、掃除瘟疫以及各式危害以求安全，舉辦盛大刈香[[醮|王醮科儀]]，為'''「[[蕭壠香]]」'''<ref name="佳里金唐殿蕭壠香">{{cite book|author=黃文博 |title=《佳里金唐殿蕭壠香》|publisher=臺南市政府文化局 |isbn=978-986-04-0189-9 |date=2014-02 }}</ref>。

[[乾隆|清朝乾隆]]年間[[林爽文事件]]中，蕭壠堡居民主動派出義民，自組義民軍協助朝廷協助[[清朝|朝廷]][[欽差大臣]]官兵平亂有功，[[乾隆皇帝]][[詔|恩旨]]，御賜'''「旌義」'''[[御匾]]，賜名蕭壠為「旌義里」里名，以示獎勵<ref>《臺案彙錄庚集》，「廣東、泉州等莊義民...業經降旨賞給「褒忠」、「旌義」里名匾額，以示獎勵。」</ref>。勅封蕭壠大廟為「[[佳里金唐殿|金唐殿]]」<ref name="佳里金唐殿蕭壠香"/>，勅立「下馬碑」，以示尊崇。據此勅石立「旌義碑」並興建「義民亭」以為永垂不朽之恩賜誌念。

古代的佳里區位於濱海的蕭壠半島，西南靠[[臺江內海]]，北臨古曾文溪（今將軍溪），當時的蕭壠市街與[[佳里興]]尚隔溪分處南北。十九世紀中葉古曾文溪改道、臺江陸浮後，佳里區才位於內陸至今。

佳里區在[[明鄭時期]]隸屬[[天興縣|天興縣（州）]]下之[[永定里 (堡里)|永定里]]及[[開化里 (堡里)|開化里]]，到了[[台灣清治時期|清治時期]]則隸屬[[臺灣府]][[諸羅縣]]，1704年以前一直為縣治所在；1787年後諸羅改名嘉義，繼續隸[[嘉義縣 (清朝)|嘉義縣]]管轄；清末1887年改隸[[臺南府]]。1920年臺灣地方改制，與[[佳里興堡]]合併，因古縣治所在地[[佳里興]]，而將蕭壠及佳里興合併改名為「佳里」，並設置「佳里-{庄}-」，劃歸[[臺南州]][[北門郡]]管轄，為郡治；1933年12月升格為「[[佳里街]]」。戰後改設為[[臺南縣]]佳里鎮，2010年12月25日改稱佳里區。

=== 蕭壠屠殺事件 ===
{{Unreferencedsect|time=2012-11-12T05:22:37+00:00}}
{{main|蕭壠事件}}
因日本某親王（據說是[[北白川宮能久]]）於臺南[[鹽水區|鹽水]]被暗殺，當時軍隊行經蕭壠，而導致於1895年農曆9月3日蕭壠居民被血腥屠殺，死亡人數據達兩千人。當時的生還者回憶：「事後，-{庄}-民前來收屍，整整裝十八輛牛車之多，由於死亡人數太多，連棺木都一棺難求。」因此佳里區在每年農曆九月三日，有祭拜因走番仔反而犧牲的祖先習俗。

1895年10月10日，日軍混成第四旅團登陸布袋嘴（嘉義地區），當地義軍領袖林昆岡，以敢死隊之勢捍衛區裡。然而武器窳劣不敵，退據蕭壠街（今臺南市佳里區）。於是日軍大肆搜索，民兵躲到溪邊雜樹林的天然溝壑中，因嬰兒哭聲而被發現後，日兵分別截住長坑的頭尾兩端，然後亂槍齊放，對著坑內猛烈射擊了近2小時，躲到坑裡避難的臺灣人無一幸免。

[[File:佳里興震興宮廟埕.jpg|200px|thumb|佳里古天興縣治紀念碑]]
關於佳里的舊地名「蕭壠」，有傳說即認為是得自當地在事件中消失了很多人後而取的「消人」。不過，「蕭壠」的由來是平埔族的語言，意思是彎曲的河。自古地圖上來看，在明朝前曾文溪是從佳里出海的。由於早在1699至1704年之間繪製之[[康熙臺灣輿圖]]，即有出現蕭壠社的地名，因此此傳說不足採信。

=== 目前近況 ===
{{Unreferenced section|time=2021-09-24T08:28:27+00:00}}
佳里區是近代最早發展的鄉鎮區之一，居住在此的以閩南人和部分外省人為主。不過由於人口外移加上人口老化的影響，所以現在居住在佳里區的輕中壯年齡層(20~50歲之間)的人口不算太多。加之以在佳里區要謀生實屬不大容易，導致年輕的人口往外遷移，這也造成了在臺灣各地的旅外臺南同鄉會成員年年增加。雖然在地方政府政策和觀光兩路安排下，在佳里區和附近的[[西港區]]、[[七股區]]、[[將軍區]]及[[學甲區]]的返鄉的人口雖略有增加，但補不上流失的速度。在佳里區主要的大姓是[[黃姓]](六安里)和[[洪姓]](六安里)，再次為[[陳姓]]和[[翁姓]]([[洪姓]]和[[翁姓]]以'''六桂堂'''為堂號)。

=== 區政組織 ===
[[佳里區公所]]是[[臺南市政府]]在佳里區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為臺南市政府。[[区长]]由[[臺南市市長|市長]]任命，其任期為無任期保障。在區長及主任秘書之下，設有4課3室等7個內部單位<ref>{{Cite web |url=https://jiali722.tainan.gov.tw/cp.aspx?n=7109 |title=佳里區政-組織概況 |publisher=臺南市佳里區公所 |date=2017-05-18 |access-date=2021-09-24 |language=zh-tw |archive-date=2021-12-08 |archive-url=https://web.archive.org/web/20211208100924/https://jiali722.tainan.gov.tw/cp.aspx?n=7109 |dead-url=no }}</ref>。

=== 行政區 ===
現今佳里區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設佳里-{庄}-屬臺南州北門郡{{r|鎮志政事篇|p=168}}。佳里-{庄}-轄佳里興、溪州、子良廟、新宅、番子寮、蕭壠、下營、塭子內等8個大字{{sfn|施添福|2002|p=602}}。1933年佳里-{庄}-改為「佳里街」{{r|鎮志政事篇|p=168}}。1946年1月，改為「佳里鎮」，屬臺南縣北門區{{r|鎮志政事篇|p=169}}。1950年，裁撤區署，佳里鎮改直隸於臺南縣。2010年，臺南縣市合併改制為直轄市，佳里鎮改制為市轄區「佳里區」，隸屬臺南市。

佳里區因歷史與地緣關係可劃分為五個地區（佳里地區、子龍地區、[[塭子內|塭內地區]]、延平地區、佳興地區），每個地區設有一警察派出所，隸屬於[[臺南市政府警察局]]佳里分局。1963年下廍里改名為嘉福里、1969年中元里改名為忠仁里。2018年鄰里整併，營頂里、溪州里合併為營溪里；禮化里、興化里合併為佳興里；頂廍里、嘉福里合併為下營里；通興里、龍安里、蚶寮里合併為塭內里；三協里併入子龍里；漳州里併入海澄里；安西里拆成安西里與文新里，且光復路以東部分併入東寧里；建南里拆成建南里與南勢里。

== 經濟產業 ==
[[File:佳里市區北郊.JPG|200px|thumb|佳里市區北郊]]
[[File:佳里市區Central Jialy.jpg|200px|thumb|佳里市區光復路一景]]
[[File:Tainan-Jialy store of Starbucks Coffee in Jialy District, Tainan, Taiwan 20200509.jpg|200px|thumb|2020年5月甫開幕的星巴克佳里門市]]
佳里區在[[2010年中華民國縣市改制直轄市|縣市合併]]前為臺南縣5個五萬人口以上的鄉鎮市之一，僅次於北方的[[新營區|新營]]與南方的[[永康區|永康]]、[[仁德區|仁德]]、[[歸仁區|歸仁]]<ref>[http://ngis.nat.gov.tw/statistic/Document/pdf/99.pdf 《都市及區域發展統計彙編99年版》] {{Wayback|url=http://ngis.nat.gov.tw/statistic/Document/pdf/99.pdf |date=20200313113912 }}，頁156。（國家發展委員會）</ref>，如此的人口也造就了商業機能的發達，市區約以文化路、延平路、新生路、光復路所包圍的區塊為核心區域，而中山路、光復路、延平路等主要的南北向街道沿新生路以南也有相當的繁榮度，金融機構等亦不在少數，鄰近學區的安西路一帶近年來則因黃昏市場興起、連鎖超市的進駐等因素帶動人潮的往來。近郊有連鎖大型賣場[[大全聯]]進駐，是大北門與大曾文地區唯一的量販店；其他商店業者，如[[全聯福利中心]]、[[星巴克]]<ref>{{Cite web |url=https://www.elle.com/tw/life/style/g32428993/starbucks-tainan-nature/ |title=存档副本 |access-date=2020-06-02 |archive-date=2021-09-24 |archive-url=https://web.archive.org/web/20210924035544/https://www.elle.com/tw/life/style/g32428993/starbucks-tainan-nature/ |dead-url=no }}</ref>、[[寶雅生活館]]、[[麥當勞]]、[[85度C]]、[[丹丹漢堡]]、[[屈臣氏]]、[[康是美]]、[[爭鮮]]、[[肯德基]]、[[特力屋]]、[[NET (品牌)|NET]]設有連鎖分店。

佳里區的紡織業曾風光一時，但隨著產業外移等因素已趨近沒落。海澄里境內設有佳里工業區（萊竿寮工業區），以輕工業為主。而臺南沿海地區的虱目魚產業在佳里區還設有加工廠，虱目魚罐頭也被視為佳里的特產之一。農業部分除稻作等糧食作物之外，以胡蘿蔔、花卉、牛蒡為主要的經濟作物。

== 交通 ==
=== 公路 ===
[[佳里區]]為[[臺南市]]西側最發達熱鬧的市鎮之一，市區的交通路網甚為發達。原本由[[台19線]]（中山路、延平路）及[[市道176號]]（進學路、新生路）在市區內構成主要十字路網中心，但隨市區的發展及交通流量需求，兩公路皆已改道行經市區東側的「佳東路」。「佳東路」為[[佳里區|佳里]]環市區道路中的一段，與「佳南路」、「佳西路」及「佳北路」構成完整的外環道路線。

除由外環道路及十字路線構成的道路基本架構外，[[佳里區|佳里]]由外環道路輻散出多條聯外公路，計有[[南19線]]（忠孝路）、[[南32線]]（文化路）、[[南37線]]（光復路、成功路）及[[南41線]]（中山路、勝利路）等四條，再加上外圍的[[南26線]]、[[南27線]]、[[南28線]]、[[南29線]]及[[南51線]]等五條轉接道路，讓[[佳里區|佳里]]無論往北到[[學甲區|學甲]]，往西北通達[[將軍區|將軍]]，或是連繫西南側的[[七股區|七股]]及東南側的[[西港區|西港]]、東側的[[麻豆區|麻豆]]，各個方向都有便利的公路可以到達<ref name="motc2018">{{cite web |title=公告調整臺南市區道公路路線。 |url=https://odmdoc.motc.gov.tw/IFDEWebBBS_MOTC/ExternalBBS.aspx?ThirdDocId=107RD05954 |publisher=中華民國交通部 |website=中華民國交通部公告發布令 |series=交路字第1070413619號 |accessdate=2019-04-12 |date=2018-11-21 |archive-url=https://web.archive.org/web/20181123200756/https://odmdoc.motc.gov.tw/IFDEWebBBS_MOTC/ExternalBBS.aspx?ThirdDocId=107RD05954 |archive-date=2018-11-23 |dead-url=yes }}</ref>
