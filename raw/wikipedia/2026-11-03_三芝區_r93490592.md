'''三芝區'''，舊稱「小雞籠社」，後稱「三芝」，得名自清代行政區名「芝蘭三堡」，前身「三芝鄉」，位於[[中華民國]][[新北市]]西北部，北鄰[[石門區]]，西北濱[[台灣海峽]]，西南連[[淡水區]]，東南連[[金山區 (台灣)|金山區]]及[[臺北市]][[北投區]]，是第7、8、9屆[[中華民國總統]][[李登輝]]的故鄉。

由於氣候溫暖且雨量豐富，在日治時期即有盛產米、茶、甘藷及各種蔬果等農作物。經濟產業以農業為主，現則主要生產茭白筍、西瓜與箭竹筍等蔬果{{sfn|施添福|2013|p=154}}。每年春季舉辦的賞櫻活動，為三芝區之盛事{{sfn|施添福|2013|pp=154－155}}。

== 歷史 ==
清代以來屬「[[芝蘭三堡]]」，日治1920年在當地設庄（相當於今日的[[鄉 (中華民國)|鄉]]）時，取前者之名設立[[三芝庄]]，隸屬[[臺北州]][[淡水郡]]，戰後改為[[臺北縣 (1945年－2010年)|臺北縣]]三芝鄉。2010年因臺北縣[[2010年中華民國縣市改制直轄市|改制直轄市]]，改為三芝區至今。

== 地理 ==
=== 概況 ===
三芝區位大屯火山群西北斜面，地勢由西北部向東南升高，昔日火山噴發之熔岩流向三芝石門交界之麟山鼻，形成特殊的岬角海岸地形。三芝的階狀台地有圓山頂、二坪頂(三層台地)、車埕等，特殊的梯田景觀，被登錄為臺灣北部地景保育景點。<ref name="區公所">{{cite news |url=http://www.sanzhi.ntpc.gov.tw/content/?parent_id=10074&type_id=10006 |title=新北市三芝區公所《認識三芝 地理環境》 |accessdate=2016-05-27 |archivedate=2016-03-29 |archiveurl=https://web.archive.org/web/20160329150557/http://www.sanzhi.ntpc.gov.tw/content/?parent_id=10074&type_id=10006 |dead-url=no }}</ref>

三芝海岸長度約7.3公里，麟山鼻至沙崙湖為岩砂混合岸砂岸，潮間帶寬廣，俗稱「咾咕」的藻礁為三芝的特色之一。<ref>{{cite web |url=https://conservation.forest.gov.tw/File.aspx?fno=61535 |title=臺灣北部地景保育景點登錄點列表 |publisher=農委會林務局 |archiveurl=https://web.archive.org/web/20201018022930/https://conservation.forest.gov.tw/File.aspx?fno=61535 |archivedate=2020-10-18 |dead-url=no |accessdate=2020-10-18 }}</ref>

=== 區政組織 ===
[[三芝區公所]]是[[新北市政府]]在三芝區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為新北市政府。[[区长]]由[[新北市市長|市長]]任命，其任期為無任期保障。在區長及主任秘書之下，設有4課2室等6個內部單位及1名人事管理員<ref>{{Cite web |url=https://www.sanzhi.ntpc.gov.tw/home.jsp?id=c5de478ccbdd4431 |title=公所簡介-組織系統 |publisher=新北市三芝區公所 |access-date=2021-09-26 |language=zh-tw |archive-date=2021-09-26 |archive-url=https://web.archive.org/web/20210926075534/https://www.sanzhi.ntpc.gov.tw/home.jsp?id=c5de478ccbdd4431 |dead-url=no }}</ref>。

=== 行政區 ===
現今三芝區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設三芝庄屬臺北州淡水郡{{r|鄉志政事志|pp=66、71}}。三芝庄轄舊小基隆、新小基隆、錫板、後厝、土地公埔、北新庄子等6個大字{{sfn|施添福|2013|pp=148、156－157}}。1946年，改為「三芝鄉」，屬臺北縣淡水區{{r|鄉志政事志|p=73}}。1950年，裁撤區署，三芝鄉改直隸於臺北縣{{sfn|施添福|2013|p=148}}。2010年，臺北縣改制為直轄市，三芝鄉改制為市轄區「三芝區」，隸屬新北市。三芝區的行政區劃轄有八賢里、埔頭里、古庄里、新庄里、埔坪里、茂長里、橫山里、錫板里、後厝里、福德里、圓山里、店子里、興華里等13個里，共計254鄰<ref>{{cite web |url=https://www.sanzhi.ntpc.gov.tw/content/?parent_id=10096&type_id=10008 |title=鄰里資訊 |publisher=三芝區公所 |accessdate=2018-12-30 |archive-date=2018-09-11 |archive-url=https://web.archive.org/web/20180911193556/http://www.sanzhi.ntpc.gov.tw/content/?parent_id=10096&type_id=10008 |dead-url=no }}</ref>。

=== 文化資產 ===
*三芝新庄里石滬
:位於三芝區新庄里蕃社路31之1號八仙宮附近沿海，乃北臺灣稀有保存尚屬完整之石滬。由卵石堆砌而成，形狀如兩半圓形結構，右側部分較為完整，2013年公告為新北市歷史建築。<ref>{{cite web |url=https://nchdb.boch.gov.tw/assets/overview/historicalBuilding/20130812000002 |title=三芝新庄里石滬 |publisher=文化部文化資產局 |archiveurl=https://web.archive.org/web/20201018023604/https://nchdb.boch.gov.tw/assets/advanceSearch/historicalBuilding/20130812000002 |archivedate=2020-10-18 |dead-url=no |accessdate=2018-12-30 }}</ref>

*三芝三板橋
[[File:三芝三板橋FUJI2351.jpg|thumb|right|301px|三芝三板橋]]
:三板橋乃清道光初年同安人林永出資所建之大屯山區過溪橋樑，砥溪中巨石分三段石板架設而成，名三板橋。於圓山村與店子村之間，為昔日居民往來重要路橋。由當地大屯山安山岩石條為材料，三個橋墩四個橋孔，橋墩可見井字排列之構造，為[[新北市文化資產#直轄市定古蹟|新北市市定古蹟]]。<ref>{{cite web |url=https://nchdb.boch.gov.tw/assets/overview/monument/20080116000001 |title=三芝三板橋 |publisher=文化部文化資產局 |archiveurl=https://web.archive.org/web/20201018023847/https://nchdb.boch.gov.tw/assets/advanceSearch/monument/20080116000001 |archivedate=2020-10-18 |dead-url=no |accessdate=2018-12-30 }}</ref>

*淡水三芝八庄大道公輪祀
:村落庄頭聚集之民俗信仰活動，九年一輪無廟有像，歷史超過二百年不曾間斷，1892年馬偕博士著作中曾記載與此活動相遇。活動方式異於他處，地域性特色濃厚，深具文化性，登錄為[[新北市文化資產#民俗|新北市文化資產]]。<ref>{{cite web |url=https://nchdb.boch.gov.tw/assets/overview/folklore/20101012000003 |title=淡水三芝八庄大道公輪祀 |publisher=文化部文化資產局 |archiveurl=https://web.archive.org/web/20200820000043/https://nchdb.boch.gov.tw/assets/advanceSearch/folklore/20101012000003 |archivedate=2020-08-20 |dead-url=no |accessdate=2018-12-30 }}</ref>

*亦宛然掌中劇團布袋戲
:[[李天祿]]之父許金木遂拜許金水為師，許金水乃福建布袋戲老師父陳婆的得意弟子。許金木後自組戲團名為「華陽台」，李天祿9歲從父習藝，1931年組團，以掌中戲偶「宛然若真」之意而取名「亦宛然」。民國73年李天祿開全臺首例，帶領「亦宛然」的師父，投入板橋莒光國小的布袋戲薪傳工作。亦宛然掌中劇團包含南管布袋戲、北管布袋戲，其手工藝雕刻，偶衣刺繡精緻，在李天祿與李傳燦父子一脈薪傳下，成為臺灣代表性技藝優良的布袋戲團。<ref>{{cite web |url=https://nchdb.boch.gov.tw/assets/overview/traditionalPerformingart/20091012000001 |title=亦宛然掌中劇團 |publisher=文化部文化資產局 |archiveurl=https://web.archive.org/web/20201018024307/https://nchdb.boch.gov.tw/assets/advanceSearch/traditionalPerformingart/20091012000001 |archivedate=2020-10-18 |dead-url=no |accessdate=2018-12-30 }}</ref>
