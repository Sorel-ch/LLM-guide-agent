'''吳川市'''（[[邮政式拼音]]：{{lang|la|Ngchün}}）是[[中国]][[广东省]][[湛江市]]代管的一个[[县级市]]，位于广东省西南部，东邻[[茂名市]][[电白区]]，北与[[化州市]]接壤，西南接[[湛江市]][[坡头区]]，南濒[[南海]]，地处粤西最大河流[[鉴江]]入海口，市政府驻[[梅菉街道]]文明路10号。
==历史==
据吴川市[[长岐镇 (吴川市)|长岐镇]]的梧山岭贝丘遗址考古发现，吴川地区早在[[新石器时代]]便有人类活动。[[春秋战国时期]]，吴川属[[百越]]之地。秦统一岭南后，属[[象郡]]辖地。[[汉代]]时，吴川地域先后属[[合浦郡]]、[[高凉郡 (东汉)|高凉郡]]管辖。[[南朝]][[刘宋|宋]][[元嘉 (刘宋)|元嘉]]年间始置平定县，[[隋代|隋]][[開皇]]九年（598年），废平定县，置吴川县，以县境东有吴川水（即今[[鉴江]]）而得名，为吴川县建制之始<ref>[https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/lswh/lsyg/content/post_378894.html 历史沿革] {{Wayback|url=https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/lswh/lsyg/content/post_378894.html |date=20220322043405 }} 吴川市人民政府门户网站 2019-05-18</ref>，[[吴川县城址|县治]]于今吴川市[[吴阳镇]]。

唐代沿袭隋制，吴川县先后隶属于[[高州 (广东)|高州]]、[[罗州 (唐朝)|罗州]]。宋[[开宝]]五年（972年），废罗州，改隶[[广南西路]][[辩州]]；[[太平兴国]]五年（982年），改隶[[化州]]。明[[洪武]]九年（1377年），改属[[高州府]]。清沿明制。清朝末年，吴川县麻斜河以东一带土地及沿海岛屿（今[[调顺街道|调顺岛]]、[[特呈岛]]、[[南三岛]]、[[硇洲岛]]）被划为[[法国]]租界“[[广州湾]]”（后改隶[[湛江市]]）。

民国二年（1913年），属广东省[[高雷道]]。1926年，广东省政府将原跨[[茂名县]]、吴川县两地的梅菉圩划出，设立梅菉市（后改制为梅菉管理局），吴川县治由[[吴阳镇|吴阳]]迁至[[黄坡镇|黄坡]]，1928年回迁。1938年，再迁[[黄坡镇|黄坡]]。1941年，因抗日战争，县治从黄坡迁至[[塘缀镇|塘缀]]，直至抗战胜利后于1946年回迁[[黄坡镇|黄坡]]。1947年，原[[茂名县]]覃巴、三民、梅博乡及[[电白县]]王村港乡划归梅菉，改设[[梅茂县]]。

中华人民共和国成立后，1952年，原吴川县与[[梅茂县]]合并为吴梅县，县治于梅菉镇。1953年4月，吴梅县改称吴川县，县治仍在梅菉镇。1958年，化县与吴川县合并，改称化州县，县政府驻化州城，覃巴除高岭村外划归电白县，茂名县的南盛、龙首、兰石划归化州县。1961年4月，两县分治，恢复吴川县，原化州县的龙首、兰石，电白县的覃巴复归吴川县<ref>{{Cite web |title=行政区域_吴川市人民政府网站 |url=https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/wcgk/xzqy/content/post_378908.html |website=www.gdwc.gov.cn |access-date=2026-01-23 |archive-date=2026-06-21 |archive-url=https://web.archive.org/web/20260621173109/https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/wcgk/xzqy/content/post_378908.html |url-status=live }}</ref>。

1994年5月，国务院批准撤销吴川县，设[[县级市|县级]]吴川市，由[[湛江市]]代管<ref>{{Cite web |title=吴川撤县设市  广东省人民政府门户网站 |url=https://www.gd.gov.cn/zwgk/gongbao/1994/11/content/post_3357147.html |website=www.gd.gov.cn |access-date=2026-01-23 |archive-date=2026-06-21 |archive-url=https://web.archive.org/web/20260621173108/https://www.gd.gov.cn/zwgk/gongbao/1994/11/content/post_3357147.html |url-status=live }}</ref>。

==地理==
吴川全境地势低平，最高点为位于[[塘缀镇]]的尖山岭，海拔为172米。地势北高南低，东北、西北部为低[[丘陵]]区，海拔50-200米，约占全市面积的65%，中部是鉴江、袂花江冲积而成的平原，地势平坦，东南为[[台地]]，海岸线属沙丘，全长70.02公里。

吴川属[[亚热带海洋性季风气候]]，雨量丰沛，日照充足，土地资源肥沃，被称为“鱼米之乡”，年平均气温23.4℃、年平均日照时数为1972.1小时、年平均降水量为1568.1毫米。境内水网密布，是典型的滨江临海城市，鉴江自北向南由化州石宁入境，流经[[梅菉街道]]，转[[吴阳镇]]沙角旋出海，袂花江、梅江、三丫江、塘河、板桥河、乌泥河等江河均流入鉴江，每年过境水量达55.5亿立方米，皆汇入[[南海]]。<ref>[https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/wcgk/zrzy/content/post_378906.html 自然资源] {{Wayback|url=https://www.gdwc.gov.cn/bmzz/wcsrmzfw/zjwc/wcgk/zrzy/content/post_378906.html |date=20201224103439 }} 吴川市人民政府门户网站 2020-09-03</ref>

==经济==

另外，建筑业也是吴川的重要支柱产业，施工队伍遍及全国各地，早于1985年，吴川就成为全省建筑业四个超亿元县之—。20世纪八九十年代，吴川建筑业者曾占据深圳70%、珠海60%的市场份额。搭棚业更是吴川建筑行业的一大特色，以工艺独特精巧、质量扎实而闻名<ref>{{Cite web|title=“中国建筑装饰之乡”炼成记!吴川有约20万名建筑从业者活跃于世界各地|url=https://www.sohu.com/a/www.sohu.com/a/579571182_100116740|website=www.sohu.com|access-date=2026-01-24}}</ref>。2014年，吴川获颁“中国建筑装饰之乡”称号<ref>{{Cite web|title=吴川获称“建筑装饰之乡”|url=http://news.ifeng.com/a/20140902/41825739_0.shtml|website=news.ifeng.com|access-date=2026-01-24|archive-date=2026-06-21|archive-url=https://web.archive.org/web/20260621173117/https://news.ifeng.com/a/20140902/41825739_0.shtml|url-status=live}}</ref>。

==文化==
{{see also|搭棚}}
民间艺术丰富多彩，其中，[[飘色]]、[[泥塑]]、花桥被誉为“吴川三绝”。[[梅菉鎮|梅菉镇]]2000年被[[中华人民共和国文化部|文化部]]命名为“中国民间艺术之乡”。

* 吴川飘色：起源于[[黄坡镇]]沙岗村，由[[清朝]][[咸丰]]年间民间艺人陈趣珩始创<ref>{{Cite web |title=广东省文化馆-非遗中心-抬阁［芯子、铁枝、飘色］（吴川飘色） |url=http://www.gdsqyg.com/agdfyzg/mingluinfo?mlproid=2017041400000121 |website=www.gdsqyg.com |access-date=2026-01-24}}</ref>，为一门集戏剧、音乐、美术、魔术、杂技、力学于一体的综合造型艺术，特点为高、精、险、奇、巧，被称为“流动的戏剧”“隐蔽的东方艺术”<ref>{{Cite web |title=千古文化留遗韵 吴川飘色技惊四座_湛江云媒（湛江新闻网） |url=https://www.gdzjdaily.com.cn/p/2875952.html |website=www.gdzjdaily.com.cn |access-date=2026-01-24 |archive-date=2026-06-21 |archive-url=https://web.archive.org/web/20260621173110/https://www.gdzjdaily.com.cn/p/2875952.html |url-status=live }}</ref>。2017年，吴川飘色入选第二批[[国家级非物质文化遗产]]<ref>{{Cite web |title=国务院关于公布第二批国家级非物质文化遗产名录和第一批国家级非物质文化遗 产扩展项目名录的通知 |url=https://www.gov.cn/gongbao/content/2008/content_1025937.htm |website=www.gov.cn |last=马娟 |access-date=2026-01-23 |archive-date=2023-07-27 |archive-url=https://web.archive.org/web/20230727141838/https://www.gov.cn/gongbao/content/2008/content_1025937.htm |url-status=live }}</ref>。
* 吴川泥塑：俗称“泥鬼”，是以当地陶泥和稻草为材料、雕刻着色而成的人物雕塑，起源于梅菉瓦窑村，由迁移至此的佛山廖岭居民将石湾陶艺传入后衍变而来<ref>{{Cite web|title=广东省文化馆-非遗中心-吴川泥塑|url=http://www.gdsqyg.com/agdfyzg/mingluinfo?mlproid=2018011294820633|website=www.gdsqyg.com|access-date=2026-01-24}}</ref>，早在唐末宋初，当地庆元宵就有制作泥塑展览的传统<ref>{{Cite web|title=中国泥塑巡礼系列：吴川泥塑|url=https://www.sohu.com/a/www.sohu.com/a/432428552_772510|website=www.sohu.com|access-date=2026-01-24}}</ref>。2007年入选“广东省非物质文化遗产名录”。
* 花桥：“行花桥、闹元宵”是吴川当地的一项传统民俗活动<ref>{{Cite web|title=行花桥闹元宵！吴川人山人海不夜天__南方+_南方plus|url=https://www.nfnews.com/content/n61zlwkKoP.html|website=www.nfnews.com|access-date=2026-01-24|language=en}}</ref>，起源于梅菉隔海村，始于明朝，兴于清朝<ref>{{Cite web|title=吴川梅菉上隔海村：精心装扮“花桥” 迎接元宵民俗_湛江云媒（湛江新闻网）|url=https://www.gdzjdaily.com.cn/p/2911551.html|website=www.gdzjdaily.com.cn|access-date=2026-01-24|archive-date=2026-06-21|archive-url=https://web.archive.org/web/20260621173111/https://www.gdzjdaily.com.cn/p/2911551.html|url-status=live}}</ref>，每年[[元宵节]]，男女老少登上[[梅江 (袂花江支流)|梅江]]之上的“花桥”，欣赏泥塑、灯饰，祈求来年平安顺遂。

== 特产 ==
吴川[[月饼]]历史悠久，传说起源于[[南宋]]时期吴川县上郭村进士吴颐，相传吴颐奉旨率军征战，大获全胜，宋度宗[[赵禥]]赐肉犒赏，其回乡后，每逢中秋节仿“帝赐肉”烤炙成饼，赠予亲友，据此流传开来<ref>{{Cite web|title=吴川月饼 {{!}} 广东省情网|url=https://dfz.gd.gov.cn/gdmycp/cp/shipin/content/post_4009475.html|website=dfz.gd.gov.cn|access-date=2026-01-24|archive-date=2026-01-06|archive-url=https://web.archive.org/web/20260106034205/http://dfz.gd.gov.cn/gdmycp/cp/shipin/content/post_4009475.html|url-status=live}}</ref>。吴川月饼以个头大著称，又以[[伍仁]]（瓜仁、榄仁、麻仁、桃仁、杏仁）月饼最为著名，2010年9月，吴川被授予全国首个“中国月饼之乡”称号。2013年，吴川月饼获批为[[中国地理标志产品]]。2015年，“吴川月饼”传统制作技艺入选广东省非物质文化遗产名录。

“烂镬[[炒粉]]、手工[[马鲛鱼]]丸、五香[[扣肉]]、酸甜海蜇、[[炸子鸡]]、腰卷、吴川烤鱼、姜糖酒蟹、白灼吴阳脆虾、香甜八宝饭”被评为吴川“十大名菜”<ref>{{Cite web|title=寻味吴川“十大名菜” 探索发展新机遇_吴川市人民政府网站|url=https://www.gdwc.gov.cn/zfxxgk/zjswcsscjdglj/content/post_1760953.html|website=www.gdwc.gov.cn|access-date=2026-01-24|archive-date=2026-06-21|archive-url=https://web.archive.org/web/20260621173111/https://www.gdwc.gov.cn/zfxxgk/zjswcsscjdglj/content/post_1760953.html|url-status=live}}</ref>。 其中，最具代表性的为吴川“烂镬炒粉”，以其独特的制作工具“烂镬”（将铁锅烧至极热，使锅面形成一层薄焦膜）而闻名，粉条吸满锅气，外焦里嫩，口感爽滑<ref>{{Cite web|title=鲜美吴川 花样暖冬_第37860版：吴川视窗_2025-01-21_南方日报数字报_南方网|url=https://epaper.nfnews.com/nfdaily/html/202501/21/content_10124915.html|website=epaper.nfnews.com|access-date=2026-01-24|archive-date=2026-06-21|archive-url=https://web.archive.org/web/20260621173109/https://epaper.nfnews.com/nfdaily/html/202501/21/content_10124915.html|url-status=live}}</ref>。
