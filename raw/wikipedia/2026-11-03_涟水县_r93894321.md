'''涟水县'''为[[中国]][[江苏省]]下辖县，现由[[淮安市]]代管。区域总面积为1678平方公里，县人民政府驻[[涟城镇]]。

== 历史 ==
*[[夏朝|夏]]、[[商朝|商]]、[[周朝|商]]时期，涟水境为“[[夷]]”聚居之地。
*[[File:涟水河畔 - panoramio.jpg|缩略图]][[春秋时期|春秋]][[战国]]时期，涟水境先属[[吴国|吴]]，后属[[越国|越]]，再属[[楚国|楚]]。
*[[秦朝|秦]]时涟水境属[[东海郡]]。
*[[汉朝|汉]]初，涟水境属[[韩信]]封地楚。
*[[汉武帝]][[元狩]]六年（公元前117）在涟水境置[[淮浦县]]，建淮浦城，涟水始设[[县]]。
*[[王莽]]时期改淮浦为淮敬。
*[[三国]]时期淮浦属魏，隶属[[广陵郡]]。
*建武三年（495）并淮浦入襄贲。
*[[隋]][[开皇]]五年（585）改襄贲为涟水县。这是涟水的始称。
*[[唐]]武德四年（621）在涟水境置涟州，州治涟水城，辖涟水、金城二县。
*[[貞觀 (唐朝)|贞观]]元年（627）废涟州，并金城县，并划归[[泗州]]管辖。
*[[宋朝|宋]]太平兴国三年（978）涟水县升为涟水郡。
*[[元朝|元]]代划归山东路。
*[[明]][[洪武]]二年（1369）涟水境改称[[安东县]]，属[[淮安府]]。
*[[清朝]]时期，涟水仍称[[安东县]]。
*[[中华民国]]三年（1914），因与[[遼寧省 (中華民國)#奉系軍閥時期|奉天省]][[安东县]]同名，复名涟水县至今。

== 人口 ==
根據[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]數據顯示，截至2020年11月1日零時，漣水縣常住人口為829699人，佔淮安市的18.21%。

== 地理 ==
涟水县位于[[江苏省]]北部，[[淮安市]]东北部。东南隔[[古黄河]]与[[盐城市]][[阜宁县]]、[[淮安市]][[淮安区]]相望，东北毗邻[[盐城市]][[响水县]]和[[滨海县]]，西南与[[淮安市]][[淮阴区]]接壤，西北毗邻[[宿迁市]][[沭阳县]]，北部与[[连云港市]][[灌南县]]相接。

涟水县在[[亚热带]]和[[暖温带]]气候的过渡地带上，月平均温度最低0度，年均降水量约1000毫米，气候四季分明。

涟水县河流、湖泊较多，城内涟漪湖、东湖、茵湖三湖相连，设[[五岛公园]]，为[[江苏省]][[黄嘴白鹭]]自然保护区。

== 经济 ==
涟水县是农业大县，[[全国商品粮生产基地]]县之一。

在工业方面，酿酒业是涟水工业经济的支柱，上市公司、骨干企业为位于[[高沟镇 (涟水县)|高沟镇]]的[[今世缘]]。

涟水亦是[[淮扬菜]]的发源地之一，涟水的两大特产：[[鸡糕]]和[[高沟捆蹄]]，制作方法独特，口味别致，深得当地人和他乡客的喜爱。

== 教育 ==
位于涟水的[[涟水中学]]为国家重点示范高中、[[郑梁梅高级中学]]为省重点示范高中、[[炎黄职业技术学院]]是全日制民办高等院校。此外涟水还有涟水一中、涟水红日中学、涟水怀文学校、涟水金城外国语学校、[[江苏省涟水中等专业学校]]等学校。
