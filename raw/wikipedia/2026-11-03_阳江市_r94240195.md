'''阳江市'''（[[邮政式拼音]]：{{lang|la|Yeungkong}}<ref>中华民国《1947年广东政区及邮政式广东地名一览》，大部分根据粤语标准音广州话拼写，其他部分由潮汕、客家、官话或其他方音拼写而成。</ref>，[[粵拼]]：joeng<sup>4</sup>gong<sup>1</sup>），古称'''莫阳'''、'''南恩州'''，是[[中华人民共和国]][[广东省]]下辖的[[地级市]]，位于广东省西南沿海。市境东邻[[江门市]]，北接[[云浮市]]，西界[[茂名市]]，南临[[南海]]。地处粤西沿海低山丘陵区，西北为[[云雾山]]，东北为[[天露山]]，中南部为[[漠阳江]]谷地及阳春盆地。漠阳江纵贯全市，并有其支流[[潭水河]]、[[那龙河]]等。市人民政府驻[[江城区]]东风二路60号。

'''阳江'''的刀具、豆豉、豬腸碌被眾多陽江人戲譽為「陽江三件寶」（一說是小刀、豆豉、漆器，但生活中民眾更樂於接受前一說法）。

== 城市名称 ==
阳江的名称来源于阳江的母亲河——“[[漠阳江]]”，而漠阳江的名称又源“莫阳”，阳江最早叫“莫阳”。因为阳江古时候属于[[古越]]，居住的多是越人。古越语中，“黄牛”为“莫”，（[[陽江話|阳江话]]现在称“牛”还叫“牛咩”）；“山羊”越语为“阳”，和太阳的“阳”。“莫阳”（{{langx|za|𭷱𦍕|mozyiengz}}）就是牛羊的意思，据此推测古代的阳江曾是牛羊聚居的地方，或者是牛羊集市。而漠阳江江边现有一村，叫牛场村。阳江处于江之北，所以叫阳江。（中国古代地理立位，山北水南曰阴，山南水北曰阳）。至于阳春，古代“青”、“春”谓之东，阳春在江东边，所以名叫阳春。

阳江作为古高凉县、郡的治所，已经有1000多年历史，但相当长的一段时间内，“阳江”还只是个地域概念，未有具体的城市存在。宋代以前的阳江，作为一个地方的文化、经济、政治中心，也不过是一个地形相对高起来的山坡或土墩而已。[[隋]][[大业]]二年（公元606年），阳江县的名字正式出現，相沿至今。[[北宋]][[绍圣]]四年（1097年）知州[[丁琏]]（番禺人）依鼍山（现在江城第一小学周围）筑起一座土城，这就是阳江城的老祖宗。长期以来，阳江的治地中心都在鼍山脚下，因此阳江又称鼍城。<ref>《阳江地方志》</ref>

==历史==
据阳春[[独石仔洞穴遗址]]（[[旧石器时代]]晚期至[[新石器时代]]早期的古人类洞穴遗址）考古发现，距今10000年以前，阳春及阳江两地已有人类生活的迹象。[[先秦]]时期为[[禹贡]]扬州之外的百越聚居之地，未归属中原政权。

前214年，秦始皇平定[[百越]]后设[[南海郡 (中国古代)|南海郡]]，两阳地区为南海郡地。

前111年，设[[合浦郡]][[高凉县 (西汉)|高凉县]]，两阳地区为高凉县地。220年，吴国析合浦郡置高凉郡，高凉郡管[[安宁县]]、[[思平县]]，高凉郡治、安宁县治皆在原阳江县地，为原阳江县地建县、建郡之始。

238年，置[[莫阳县]]，属[[高兴郡]]，为原阳春县地建县之始。

523年，设阳春郡并置[[阳春县]]，为阳春县得名之始。公元527年设[[高州]]，下辖[[高凉郡 (东汉)|高凉郡]]、[[杜陵郡]]、[[宋康郡]]等郡，改安宁县为高凉县。高州州治、高凉郡治、高凉县治皆在今江城，高州管辖今阳江市、[[恩平市]]及[[茂名市]]的大部分地方。

598年，在现阳江地方新设[[阳江县]]，为阳江县得名之始。

621年，置[[春州 (唐朝)|春州]]，州治在今阳春城区，领阳春县、[[流南县]]两县，为阳春有春州之名之始。公元649年，废高州都督府，置[[恩州]]，州治在阳江，属广州[[都督府]]管辖。

1048年，因河北[[贝州]]改为恩州，原恩州则改称[[南恩州]]，州治乃在阳江。1073年，废春州，铜陵县并入阳春县，阳春县属南恩州。

1276年，置南恩路[[总管府]]，公元1282年降为散州，州治、府治皆在阳江。

1368年，撤除恩州，阳江县、阳春县归[[肇庆府]]管辖。

1867年，改阳江县为[[阳江直隶州]]，领阳春县、[[开平县]]、[[恩平县]]。1870年，阳江直隶州改为直隶厅，阳春县、开平县、恩平县归肇庆府管。1906年，阳江直隶厅改为直隶州，领阳春县、恩平县。

=== 中华民国时期 ===
1912年，撤除州府，复设阳江县、阳春县。

=== 中華人民共和國時期 ===
1949年10月26日 ，中華人民共和國人民解放军占领[[阳江县]]。

阳江、阳春属江门[[粤中专区]]。

1953年改属[[粤西行署]]。

1956年改属[[湛江专区]]。

1958年冬，合并阳江县、阳春县为[[两阳县]]。

1961年复分[[两阳县]]为阳江县、阳春县。[[文化大革命]]期间，阳江发生了一系列[[阳江大屠杀|大屠杀事件]]。

1983年9月开始，由[[江门市]]代管。

1988年1月7日，阳江撤县建市，为阳江市，属地级市建制，并代管[[阳春县]]。

2014年10月20日，撤销[[阳东县]]，设立阳江市[[阳东区]]。

2018年7月1日，[[江湛鐵路]]正式開通運營。

== 地理 ==
[[File:Yangjiang1.jpg|thumb|left|阳江海陵岛]]
阳江东、西、北三面群山环抱，东北有[[天露山]]屏障，西北有云雾山脉环绕，地势由北向南倾斜，南部濒临南海。全市地形主要为低山[[丘陵]]，境内最高山峰为望夫山脉的[[鹅凰嶂]]（海拔1338米），最长河流为[[漠阳江]]（199公里），海岸线总长度466.82公里，其中大陆岸线长331.72公里，海岛岸线长135.1公里，主要岛屿68个<ref>{{Cite web |title=地理气候_阳江市人民政府门户网站 |url=http://www.yangjiang.gov.cn/yj/mlyj/yjgk/dlqh/content/post_842369.html |website=www.yangjiang.gov.cn |access-date=2026-03-31}}</ref>。

===辐射===
阳江市的部分地区属于[[背景辐射|高本底地区]]。其原因是该地区盛产[[独居石]]矿。独居石是一种含[[稀土]][[磷酸盐]]的矿物。这种矿石中[[放射性核素]][[钍-232]]和[[铀-233]]含量较高。<ref>{{Cite web |url=https://www.chinansc.cn/gzxc/bwbd/hyfsjczsxgwt/201705/t20170503_550630.html |title=存档副本 |access-date=2025-02-27 |archive-date=2025-08-12 |archive-url=https://web.archive.org/web/20250812064251/https://www.chinansc.cn/gzxc/bwbd/hyfsjczsxgwt/201705/t20170503_550630.html |dead-url=no }}</ref>阳江室内外γ辐射水平分别为（0.36±0.06）μSv/h和（0.16±0.06）μSv/h，对照地区分别为（0.13±0.05）μSv/h和（0.09±0.03）μSv/h，高本底地区室内外γ辐射水平约为对照地区的3倍和2倍。<ref>{{Cite web |url=http://www.zgfsws.com/CN/10.13491/j.issn.1004-714x.2018.05.001 |title=存档副本 |access-date=2025-02-27 |archive-date=2026-01-20 |archive-url=https://web.archive.org/web/20260120060741/http://www.zgfsws.com/CN/10.13491/j.issn.1004-714x.2018.05.001 |dead-url=no }}</ref>

== 人口 ==
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,602,959人<ref>{{cite web |author1=阳江市统计局、阳江市第七次全国人口普查领导小组办公室 |title=阳江市第七次全国人口普查公报 |url=http://www.yangjiang.gov.cn/yjtjj/gkmlpt/content/0/533/post_533678.html |access-date=2021-06-01 |archive-date=2021-06-02 |archive-url=https://web.archive.org/web/20210602214015/http://www.yangjiang.gov.cn/yjtjj/gkmlpt/content/0/533/post_533678.html |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,421,748人相比，十年共增加了181,211人，增长7.48%，年平均增长率为0.72%。其中，男性人口为1,362,137人，占总人口的52.33%；女性人口为1,240,822人，占总人口的47.67%。总人口性别比（以女性为100）为109.78。0－14岁的人口为585,241人，占总人口的22.48%；15－59岁的人口为1,575,442人，占总人口的60.53%；60岁及以上的人口为442,276人，占总人口的16.99%，其中65岁及以上的人口为324,772人，占总人口的12.48%。居住在城镇的人口为1,409,820人，占总人口的54.16%；居住在乡村的人口为1,193,139人，占总人口的45.84%。

截至2021年底，阳江市常住人口262.07万人，比上年增长0.6%，城镇化率54.96%；全市户籍人口302.75万人。

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,553,280人，占98.09%；各[[中国少数民族|少数民族]]人口为49,679人，占1.91%。与2010年第六次全国人口普查相比，汉族人口增加147,399人，增长6.13%，占总人口比例下降1.25个百分点；各少数民族人口增加33,812人，增长213.1%，占总人口比例增加1.25个百分点。

=== 语言 ===
阳江市境内通行地区独有的[[粤语]]方言[[阳江话]]，跟标准粤语[[广州话]]有一定的区别。另外在阳春市通用[[阳春话]]，在阳西县儒洞镇、沙扒镇通用[[海话]]，屬[[閩南語]]下的一種方言。

== 旅游 ==
[[File:Yangjiang3.JPG|thumb|[[海上丝绸之路博物馆]]]][[File:Yangjiang2.jpg|thumb|阳江海陵岛]]
阳江市是广东省著名的滨海旅游城市，旅游资源丰富，有滨海沙滩、峰林溶洞、温泉瀑布、湖光山色和灿烂的人文景观。
*[[海陵岛]]、阳春春湾——凌霄岩为省级旅游度假区，海陵岛的{{link-yue|大角湾|大角灣}}于2001年又被评为4A级国家旅游区。
*拥有阳江温泉、阳春春都温泉、阳西咸水温泉
*[[广东海上丝绸之路博物馆]]将保存“[[南海一号]]”等古沉船。

== 物产 ==
*历史上手制[[风筝]]较多，有南国风筝之乡之称，特色风筝有“灵芝”。
*阳江是目前中国国内主要的刀剪生产出口地。  
*阳江地方特产有[[豆豉]]、[[蠔]]、[[蓋蘇文魚]]、[[禾蟲]]和全国闻名的阳江[[十八子菜刀]]，阳西的凉果，阳春的春砂仁和马水桔。
*南药：春砂仁、益智、檀香、沙姜、藿香等。
*特色小吃：阳江猪肠碌，乒乓糕，杏仁茶，糕点“狗利仔”“酒杯印”。
*其中阳江刀具、豆豉、猪肠碌被众多阳江人“戏誉”为“阳江三件宝”（一说是小刀、豆豉、漆器，但生活中民众更乐于接受前一说法）。[[阳江豆豉]]、[[阳江姜豉]]、[[阳江黄鬃鹅]]都是[[中国地理标志产品]]。
