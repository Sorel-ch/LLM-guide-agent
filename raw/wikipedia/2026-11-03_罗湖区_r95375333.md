'''罗湖区'''是[[中国]][[广东省]][[深圳市]]下辖的一个[[市辖区]]，于1979年1月成立，是原[[深圳经济特区]]内的四区之一。连接[[中国内地]]与[[香港]]的[[罗湖口岸]]、[[文錦渡口岸]]及[[蓮塘口岸]]均位于本区，區人民政府駐[[文錦路|文錦中路]]1008號。

羅湖區是[[深圳經濟特區]]最早建成并城市化的区域<ref>{{cite news |title=致敬特區40年 連接深港 服務灣區 繁花似錦四十載 羅湖先行-香港商報 |url=https://www.hkcd.com.hk/content_app/2020-08/31/content_1211223.html |accessdate=2025-07-24 |work=香港商報網 |agency=[[香港商報]] |date=2020-08-31}}</ref>，先後獲得全國和諧社區建設示範區、全國文化先進區等榮譽稱號<ref>{{cite news |title=深圳市罗湖区第六届人民代表大会第一次会议关于罗湖区人民政府工作报告的决议 |url=https://www.szlh.gov.cn/zwgk/zfgb/2012/2012n1y6rd1qzd79q/content/post_5235202.html |accessdate=2025-07-24 |publisher=深圳市罗湖区人民政府 |date=2012-01-06}}</ref>。作为[[改革开放]]与[[港深关系|深港融合]]的重要窗口，区内[[深圳国际贸易中心大厦|国贸大厦]]、[[信興廣場|地王大厦]]等标志性建筑见证了“[[深圳速度]]”的崛起<ref>{{Cite web |title=四十年、一扇窗——两地值守者眼中的罗湖桥-新华网 |url=http://www.xinhuanet.com/politics/2018-12/03/c_1210007574.htm |website=[[新华网]] |access-date=2025-11-18}}</ref>。如今该区以[[第三产业|服务业]]为主，是深圳中东部重要的城市核心区<ref>{{Cite web |title=深圳城市定位再升级 都市核心区再扩容 |url=https://www.stcn.com/article/detail/1345909.html |website=www.stcn.com |access-date=2025-11-18}}</ref>。

== 地理 ==
罗湖区总面积约78.75平方公里，下辖10个街道，南面隔[[深圳河]]与[[香港]][[新界]][[北區 (香港)|北區]]相望，东邻[[盐田区]]，南连[[福田区]]，西北与[[龙岗区]]、[[龙华区 (深圳市)|龙华区]]接壤。该区属[[丘陵]]地带，地貌起伏多变<ref>{{Cite journal |last=卜心国 |last2=王仰麟 |last3=吴健生 |title=深圳快速城市化中地形对景观垂直格局的影响 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:_9dSX71P8qwJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaLx1wk:ABGrvjIAAAAAaRv3zwnBPTZBofxvtJ0Z46JADuA&scisig=ABGrvjIAAAAAaRv3z4g9yNbVsFUIEfM7Kjk1qYE&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=地理学报 |date=2008 |volume=1 |access-date=2025-11-18}}</ref>，坐拥东湖、洪湖、[[仙湖植物园|仙湖]]等多处天然淡水水体，[[深圳水庫|深圳水库]]亦坐落于此，成为深港两地重要的供水命脉<ref>{{Cite journal |last=王翠然 |last2=田炯 |title=基于生态补偿的社会经济发展调控研究-以深圳水库为例 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:Mu5_NEYS6pgJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaLx9ds:ABGrvjIAAAAAaRv37ds7DI5sv8MYcbRVfJ6jgFE&scisig=ABGrvjIAAAAAaRv37ViYcN85WwWypUiJKda8vLM&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=环境保护科学 |date=2008 |volume=34 |issue=3 |access-date=2025-11-18}}</ref>。深圳最高峰[[梧桐山]]（海拔944米）位于本区东部。罗湖西以[[紅嶺路|红岭路]]与福田区相邻，东则以[[梧桐山]]山脉与[[盐田区]]天然为界。

== 历史 ==
罗湖区之名源于其辖区内历史悠久的[[羅湖 (香港)|罗湖村]]（如今由深港分别管辖），其村名则来自今[[羅湖口岸|罗湖口岸]]周边被池塘包围的罗湖山<ref>{{Cite journal |last=丘振声 |title=香港的壮族地名 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:16iF45ItRAAJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaL9npI:ABGrvjIAAAAAaRv7hpJKuCM7p2J-mgRXLksdOvM&scisig=ABGrvjIAAAAAaRv7hne0lQKEwuEqhWpGfiseqYI&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=广西文史 |date=2003 |issue=4 |access-date=2025-11-18}}</ref>。[[深圳經濟特區|深圳经济特区]]成立后，因修建[[深圳站]]、扩建[[羅湖口岸|罗湖口岸]]，且罗湖山存在地质灾害危险，该山已被填平<ref>{{Cite web |title=罗湖不见湖，南海没有海？这些“错位”藏着大湾区的过往与向往_南方网 |url=https://news.southcn.com/node_49957036fa/1b5aeacf88.shtml |website=news.southcn.com |access-date=2025-11-18}}</ref><ref>{{Cite web |title=深圳故事｜罗湖山去哪儿了？-深圳市档案馆 |url=http://www.szdag.gov.cn/dawh/tqssn/content/post_939354.html |website=www.szdag.gov.cn |archive-url=http://web.archive.org/web/20230327012159/http://www.szdag.gov.cn/dawh/tqssn/content/post_939354.html |archive-date=2023-03-27 |access-date=2025-11-18}}</ref>。

罗湖区原为滨海农村，清末民初逐渐发展为[[深圳鎮|深圳镇]]，在[[深圳經濟特區|深圳经济特区]]设立前，名为'''[[東門商業區|深圳墟]]'''的原始聚落即位于现今罗湖辖区，该墟市人口不足三万，其中心位于现存[[媽祖廟|天后宫]]遗址的东门一带<ref>{{Cite web |title=从“深圳墟”到“深圳市”—— 中国“模范城市”中的历史传承-建筑档案 |url=https://www.jzda001.com/index/index/details?type=1&id=4506 |website=www.jzda001.com |access-date=2025-11-18}}</ref>。

[[廣九鐵路]]開通後，於此地設立[[深圳站]]。1953年，寶安縣政府考慮到深圳墟連接廣九鐵路，交通便利，便將寶安縣城從[[南頭城|南頭]]搬到深圳墟，逐漸成為彼鄰[[香港]]的商業中心与交通枢纽<ref>{{Cite journal |last=文彤 |title=跨境旅游与边境城市口岸地区发展——以深圳罗湖口岸为例 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:s5QJqd1xWkQJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaL74h4:ABGrvjIAAAAAaRv9-h6D5vAWIWT4Kl7B4-oRzEI&scisig=ABGrvjIAAAAAaRv9-hCgVjomZX3N7myC00wEKB4&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=社会科学家 |date=2014 |volume=29 |issue=11 |access-date=2025-11-18}}</ref>。

1979年，寶安縣升格为[[深圳市]]，而深圳镇于1979年1月改制成立罗湖区，是当时深圳最早成立的區，下辖福田、附城、盐田3个公社和深圳、沙头角2个镇<ref>{{Cite web |title=港深地名故事｜大山大水 時代傳奇 羅湖架橋 雙城煙火-香港商報 |url=http://hkcd.com/content_app/2024-07/14/content_8646914.html |website=hkcd.com |access-date=2025-11-18}}</ref>。

1980年8月26日，[[深圳經濟特區|深圳经济特区]]成立。1981年8月，深圳经济特区内全部区域划归罗湖区<ref>{{Cite web |title=一文看懂深圳市行政区划演变_光明新闻数字报 |url=https://gmxw.sznews.com/PC/content/202408/01/content_3240469.html |website=gmxw.sznews.com |access-date=2025-11-18}}</ref>。

1983年9月，深圳市将经济特区划分为罗湖、上步、南头、沙头角4个管理区，其中罗湖管辖附城公社和人民路、和平路2个街道。到当年底，和平路、人民路更名为桂园、蛟湖街道，撤销附城公社改为笋岗、南湖、黄贝、翠竹4个街道。

1990年1月，原罗湖管理区、沙头角管理区合并组建新的罗湖区。

1997年11月，沙头角、盐田和梅沙的镇区從羅湖區分出，建立[[鹽田區]]。

1998年增设东湖、莲塘2个街道。1999年蛟湖更名为东门街道。2003年增设东晓、清水河2个街道<ref>{{Cite web |title=深圳市罗湖区志上卷 {{!}} 广东省情网 |url=https://dfz.gd.gov.cn/dfz/f/book/viewer?keywords=,%E7%BD%97%E6%B9%96%E5%8C%BA%E5%BF%97%E4%B8%8A%E5%8D%B7&bookId=86ce2f1cf47649839f599cc66a874fc6&file=/dfz/book/86ce2f1cf47649839f599cc66a874fc6/0.pdf&bookName=%E7%BD%97%E6%B9%96%E5%8C%BA%E5%BF%97%E4%B8%8A%E5%8D%B7&snTopicCode=undefined&pubDate=1641954755000 |website=dfz.gd.gov.cn |access-date=2025-11-18}}</ref>。

== 人口 ==
根據[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]數據，截至2020年11月1日零時，羅湖區常住人口114.38萬人。

根据2010年（11月1日零时）第六次人口普查结果，罗湖区常住人口923,423人，其中男性465,533人，女性人口为457,890人，男女性别比例为102比100。按年龄段分类，0—14岁人口为109,078人，占11.81%；15—64岁人口为786,800人，占85.21%；65岁及以上人口为27545人，占2.98%。按民族划分，汉族人口907,754人，占98.30%；各少数民族人口156,69人，占1.70%。按受教育程度划分，具有大学程度的人口为212,323人，占22.99%；具有高中（含中专）程度的人口为267,142人，占28.93%；具有初中程度的人口为291,676人，占31.59%；具有小学程度的人口为93,407人，占10.12%。文盲人口（15岁及以上不识字的人）为5,258人，文盲率0.57%。这次普查，接受普查登记的境外人员有33,227人，以香港居民为主，达到29,830人，占境外人员的89.78%<ref name="第六次人口普查数据">2010年第六次人口普查数据来源于 [http://www.szlh.gov.cn/tjj/a/2011/h02/a176392_572158.html 《深圳市罗湖区2010年第六次全国人口普查主要数据公报》] {{webarchive|url=https://web.archive.org/web/20140201164100/http://www.szlh.gov.cn/tjj/a/2011/h02/a176392_572158.html |date=2014-02-01 }}</ref>。

=== 住宅区 ===
罗湖区作为深圳最早进行[[城市化]]建设的区域，其住宅区发展呈现出明显的阶段性特征<ref>{{Cite journal |last=王宏亮 |last2=高艺宁 |last3=吴健生 |last4=王娜 |last5=赵宇豪 |last6=彭子凤 |last7=王仰麟 |title=高度城市化地区建设用地扩展及其驱动力分析 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:6RA9zvuTw_IJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaUCcx8:ABGrvjIAAAAAaRwEax8PLKXGXrArYw9ROyK36Og&scisig=ABGrvjIAAAAAaRwEa1b1gx9R_OdGRLaMkGpNVOY&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=北京大学学报 (自然科学版) |date=2021 |volume=57 |issue=4 |access-date=2025-11-18}}</ref>。由于开发时间较早、开发计划变动较快，区域内缺乏系统性整体规划，不同年代的建筑群交错并存，形成了新旧融合的城市肌理。位于罗湖区的[[东湖丽苑]]是中国[[改革开放]]之后的第一个[[商品房]]小区<ref>{{Cite web |title=内地商品房的”原点”：东湖丽苑 |url=http://www.sz.gov.cn/szstory/202301/content/post_10371216.html |website=www.sz.gov.cn |access-date=2025-11-18}}</ref>。

1980年代建设的住宅多以四至六层的多层建筑为主，部分配备少量商业设施即冠以“大厦”之称<ref>{{Cite journal |last=许涛 |title=阳光普照老住区——深圳老住宅区引入物业管理之台前幕后 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:man3_UcTEcMJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaUD_-4:ABGrvjIAAAAAaRwF5-4sLBgsEJXk3-ios0fURO0&scisig=ABGrvjIAAAAAaRwF55UZdq71q0b667U7yTTlgG8&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=住宅与房地产 |date=2006 |issue=5 |access-date=2025-11-18}}</ref>。随着土地资源日益紧张，2000年后兴建的小区普遍发展为15至30层的高层建筑，且普遍采用“住宅底层商铺”的混合开发模式。为优化城市空间品质，罗湖区自2003年起推进[[市區更新|城市更新]]工作，重点开展[[城中村]]综合整治与[[深圳經濟特區|二线关]]插花地等特殊区域的规范化管理。目前区域内已形成锦上花家园、百仕达花园等具有代表性的大型住宅社区以及[[黄贝岭站|黄贝岭村]]等较多人居住的城中村<ref>{{Cite journal |last=王德 |title=深圳市罗湖区 “城中村” 居民的居住意识分析 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:ufSQJGhVpSwJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaUDpPI:ABGrvjIAAAAAaRwFvPJWKTrb6G38CYyfXFX5zKY&scisig=ABGrvjIAAAAAaRwFvOtsMpq_8jnMIxVN1YtAPeI&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=规划师 |date=2001 |volume=17 |issue=5 |access-date=2025-11-18}}</ref><ref>{{Cite journal |last=罗湖平 |last2=李雅婷 |last3=郑鹏 |last4=邓雅轩 |last5=古睿 |title=城市人居环境整治满意度的空间特征及其形成机理 |url=https://scholar.googleusercontent.com/scholar.bib?q=info:inuKtLn2qdIJ:scholar.google.com/&output=citation&scisdr=ChXbxjI8ELCNlaUD1AI:ABGrvjIAAAAAaRwFzAI3dyEIicqESoyS4zmDuio&scisig=ABGrvjIAAAAAaRwFzA03KRa2bsG6MG40MrsbIMs&scisf=4&ct=citation&cd=-1&hl=zh-CN |journal=经济地理 |date=2025 |volume=45 |issue=8 |access-date=2025-11-18}}</ref>。

=== 商业区 ===
罗湖区有三个主要商圈：东门商圈、人民南商圈、地王商圈。随着深圳城市中心逐步西移，罗湖区传统商业影响力虽有所减弱，但由于坐拥[[深圳大剧院]]、[[信興廣場|地王大厦]]等地标性建筑且毗邻[[香港]]，区域人流依然密集。

==== 东门商圈 ====
东门片区作为[[深圳鎮|深圳镇]]旧址所在地，承载着约三百年的城镇发展历史，故素有“老街”之称（深圳地铁亦以此命名[[老街站 (深圳)|老街站]]）。该区域长期为深圳及前身[[寶安縣|宝安县]]的核心商业地带，至1999年经整体复古风貌改造后，正式确立为[[東門商業區|步行街区]]。中心广场设置的铜雕《老东门墟市图》，再现了清末民初时期市井交易的繁华景象<ref>{{Cite web |title=【文化深圳】从“深圳墟”到国际消费中心，沉淀百年历史，东门步行街再起芳华_罗湖社区家园网 |url=https://www.luoohu.com/content/2020-11/27/content_23758065.htm |website=www.luoohu.com |access-date=2025-11-18}}</ref>。东门商圈以平价商品为主要特色，聚集了大量个性化小型店铺，同时吸引[[茂業國際|茂业百货]]、[[天虹股份|天虹商场]]等多家本土连锁百货入驻。餐饮服务设施密集分布，尤其集中于[[步行街]]范围内，形成浓厚的商业氛围，中国内地第一家[[麦当劳]]即在此开业<ref>{{Cite web |title=麦当劳入华28年：奢侈“洋快餐”成“日常” |url=http://jl.ifeng.com/a/20181218/7106219_0.shtml |website=jl.ifeng.com |access-date=2025-11-18}}</ref>。

==== 人民南商圈 ====
人民南商圈得名于贯穿片区的人民南路，深圳地铁亦设有[[人民南站]]。又因标志性建筑[[深圳国际贸易中心大厦|国贸大厦]]坐落于此，亦被称为“国贸商圈”。该区域地处罗湖中心腹地，北接[[東門商業區|东门商业区]]，南邻[[深圳站]]，凭借毗邻[[羅湖口岸|罗湖口岸]]的区位优势，成为香港旅客北上消费的重要区域。商圈内消费定位较高，汇聚[[金光华广场]]等高端商场与多家豪华酒店<ref>{{Cite web |title=從人車分流到文化浸潤 深圳羅湖區人民南街區煥新提升城市品質-香港商报 |url=https://hkcd.com/newsTopic_content.php?id=8695952 |website=hkcd.com |access-date=2025-11-18}}</ref>。

==== 地王商圈 ====
地王商圈又名大剧院商圈，以标志性建筑[[信興廣場|地王大厦]]、[[深圳大剧院]]为核心，地王大厦曾长期占据深圳第一[[摩天大樓|摩天楼]]的地位。2011年[[京基100]]建成后，以441.28米的高度取代其成为深圳新地标。商圈内集中了多个大型商业设施，包括于2004年开业的[[深圳萬象城|深圳万象城]]。深圳地铁[[大剧院站 (深圳市)|大剧院站]]服务本区域，范围内还曾坐落[[深圳证券交易所]]原址及前[[平安银行]]总部所在的[[平安银行大厦]]<ref>{{Cite web |title=地王商圈 仰望都市繁华景色_旅游频道_凤凰网 |url=https://travel.ifeng.com/roll/detail_2011_07/19/7781863_0.shtml |website=travel.ifeng.com |access-date=2025-11-18}}</ref>。

=== 工业区 ===
[[File:Lo Wu Border Crossing.jpg|left|thumb|200x200px|位于罗湖区的[[羅湖口岸|罗湖口岸]]，曾经一度是世界上最繁忙的陆路口岸]]
罗湖区的工业用地主要分布于远离核心商业与住宅地带的边缘区域，产业形态以传统[[制造业]]为主导。在邻近铁路干线且避开商业中心的区位，则规划建设了专业化物流园区（即大型仓储区），其中以依托[[廣深鐵路|广深铁路]][[筍崗站|笋岗站]]发展而成的笋岗-清水河物流园区尤为典型。

随着城市化进程的快速推进，原有工业区逐渐被新兴住宅项目包围，形成工业与居住功能交织的城市空间格局。为适应城市发展转型，该片区已被纳入深圳市重点城市更新单元，逐步由传统物流仓储区向融合创新研发、商业服务与高端居住的复合功能区转变<ref>{{Cite web |title=深圳羅湖打造“科創清水河” |url=http://sz.people.com.cn/BIG5/n2/2021/0715/c202846-34821578.html |website=sz.people.com.cn |access-date=2025-11-18}}</ref>。
