'''馬公市'''位於[[澎湖本島]]西半部，東鄰[[湖西鄉]]，為[[澎湖縣]][[縣治]]所在地，為[[澎湖群島]]的政經文化及交通中心。管轄範圍包括[[桶盤嶼]]、[[虎井嶼]]等地，面積約為33.9918平方公里，人口約6.3萬人，每平方公里約有1千8百多人，是澎湖縣面積最大、人口最多、人口密度最高的行政區。

馬公市[[臺灣清治時期|清代]]舊稱「媽宮」、「娘媽宮」與「[[東西澚]]」，其中前兩者得名自[[澎湖天后宮]]，後者則源自清代行政區名。[[台灣日治時期|日治時期]]以[[日語]]仿音改名「馬公」，期間成立隸屬[[澎湖郡]]的[[馬公街]]是今日馬公市行政區劃的最早前身。[[臺灣戰後時期|戰後]]改制為馬公鎮，隸屬澎湖縣，至1981年因屬縣治所在地而改制為[[縣轄市]]<ref name=":0">{{Cite web|title=〈歷史沿革〉|url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=150|accessdate=2019-09-12|author=|date=|format=|publisher=澎湖縣馬公市公所|language=zh-tw|archive-date=2021-10-15|archive-url=https://web.archive.org/web/20211015115116/https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=150|dead-url=no}} {{Wayback|url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=150 |date=20211015115116 }}</ref>，成為[[臺灣]]唯一地處[[外島 (中華民國)|離島]]的[[臺灣市制|市]]，也是臺灣離島地區的最大都市。

== 市名緣由 ==
[[File:媽宮街井位置圖.jpg|缩略图|媽宮街井規劃平面圖，圖上標示媽宮五個通稱町名，分別為宮內町、北町、東町、南町、西町（1912）。|替代=|左]]

馬公地區位於澎湖本島（[[大山嶼]]）西部，古稱「媽宮嶼」（Má-king-sū），自古便是避風港。早於明清文獻，便有「娘宮」、「媽澳」、「媽祖臺」、「祖媽宮」、「馬祖澳」等記載，其中以「媽宮」最為常見。由於島上在明朝[[萬曆]]年間便有祭祀[[媽祖]]的[[澎湖天后宮]]，故「媽宮」應與媽祖信仰有所關聯，隨後也從地方廟宇擴大成當地地名概念。<ref name=":地名01" />{{Rp|143}}

1920年（大正九年），[[台灣總督府]]第八任[[台灣總督]][[田健治郎]]推動行政區域改制，原[[澎湖廳 (日治時期)|澎湖廳]]改組成[[澎湖郡]]，澎湖郡轄下的「媽宮」便仿其音，轉稱「馬公」，沿用迄今。<ref name=":地名01">{{Cite book|title=《續修澎湖縣志．卷二．地理志》|last=顏|first=尚文|publisher=澎湖縣政府|year=2005|isbn=9860015104|location=澎湖縣|pages=|language=zh-tw}}</ref>{{Rp|143}}<ref name=":地名02">{{Cite book|title=《臺灣歷史地圖》|last=黃|first=驗|publisher=遠流|year=2015|isbn=9789860475227|location=臺北市|pages=|last2=黃|first2=裕元|language=zh-tw|edition=2016年第三刷|authorlink2=}}</ref>{{Rp|98-100}}

[[第二次世界大战|二戰]]結束後，馬公市民間一直有復名的聲浪，不少人認為「媽宮」之名才有城市歷史的延續感，主張從「馬公市」復名回「媽宮市」，亦便於子孫追溯故鄉的文化淵源。<ref>{{Cite web|title=〈馬公市公所於2013年3月11日召開推動『媽宮復名』籌備會~〉|url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=187&act=view&dataserno=201803012563|accessdate=2019-11-18|author=馬公市公所|date=2013-03-18|format=|publisher=澎湖縣馬公市公所|language=zh-tw|archive-date=2021-10-15|archive-url=https://web.archive.org/web/20211015115121/https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=187&act=view&dataserno=201803012563|dead-url=no}} {{Wayback|url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=187&act=view&dataserno=201803012563 |date=20211015115121 }}</ref>

== 歷史 ==
{{See also|澎湖遊兵|媽宮城|馬公街|澎湖提標館}}

[[File:Penghu10 595.jpg|thumb|240px|[[中央老街]]]]

自康熙二十三年（1684年）清廷領有澎湖之後<ref>{{cite web |title=〈清領時期總論〉 |url=http://nrch.culture.tw/twpedia.aspx?id=1234 |access-date= |author=許雪姬 |date=2010-03-30 |publisher=[[臺灣大百科全書]] |language=zh-TW |archive-date=2021-06-23 |archive-url=https://web.archive.org/web/20210623061316/http://nrch.culture.tw/twpedia.aspx?id=1234 |dead-url=yes }} {{Wayback|url=http://nrch.culture.tw/twpedia.aspx?id=1234 |date=20210623061316 }}</ref>，媽宮街因瀕臨港灣，常有軍隊駐紮，四季皆可停泊船隻，商業活動頻繁，漸漸發展成熱鬧的市街，在[[乾隆|乾隆朝]]形成所謂「七街一市{{NoteTag|約莫在乾隆年間便有所謂的「七街一市」，即指環繞澎湖天后宮附近的鬧街，分別是「右營直街」、「右營橫街」、「左營街」、「渡頭街」、「海邊街」、「倉前街」以及「大井街」，一市則為天后宮廟埕的「魚市」。{{sfn|林豪|1893}}}}」，市街活動多由官府和班兵把持，駐紮澎湖約有七個標營{{NoteTag|分別是「水師提標營」、「閩安標營」、「海壇標營」、「南澳標營」、「南澳標右營」、「銅山標營」、「銅山標右營」、「烽火門」。{{sfn|林豪|1893}}}}，各自設有廟館伙房廣布於媽宮四周{{NoteTag|廟館設置源自於朝廷實施三年一換的班兵制度，期滿之時，因季風難行，班兵必須滯留澎湖，常常導致盤纏耗盡仍不得歸返。各標營為了解決調防的食宿問題，先後於媽宮各處購置房產，之後更向四周擴散，甚至開始有大批產業，或以收受租金為廟館收入來源。{{sfn|張玉璜|1998|pp=35–41}}}}，造成軍民雜處的亂象<ref name="馬公1">{{cite book |url=http://ianthro.ioe.sinica.edu.tw/wp-content/uploads/1988/07/B19-.pdf |title=《媽宮的寺廟：馬公市鎮發展與民間宗教變遷之研究》 |author=余光弘 |publisher=[[中央研究院民族學研究所]] |year=1988 |isbn= |location=臺北市 |language=zh-TW |access-date=2020-02-06 |archive-url=https://web.archive.org/web/20180925082234/http://ianthro.ioe.sinica.edu.tw/wp-content/uploads/1988/07/B19-.pdf |archive-date=2018-09-25 |dead-url=no }} {{Wayback|url=http://ianthro.ioe.sinica.edu.tw/wp-content/uploads/1988/07/B19-.pdf |date=20180925082234 }}</ref>{{Rp|57-62}}。[[道光|道光朝]]之後，地方教育和商業發展漸趨蓬勃<ref name="馬公1" />{{Rp|127-129}}、到[[光緒]]年間，媽宮已發展成「十街二市{{NoteTag|街道增加「太平街」、「東門街」（今重慶街）和「小南門街」（今民族路南段）；而原有天后宮廟埕的魚市旁，新增一個「菜市」，雖曰「二市」，其實都在同一處。{{sfn|張玉璜|1998|p=60}}}}」的規模<ref name="馬公1" />。

媽宮城含括的濱港區域，由「東甲」、「南甲」和「北甲」組成，當時合稱作「媽宮三甲」<ref name=":6">{{cite web |title=〈媽宮三甲與闔澎三大公廟〉 |url=https://penghu.info/OB1851A63843990F7D5F |author=許玉河 |website=Penghu.Info |publisher=澎湖知識服務平台 |language=zh-TW |access-date=2020-10-05 |archive-date=2021-04-14 |archive-url=https://web.archive.org/web/20210414032727/https://penghu.info/OB1851A63843990F7D5F |dead-url=no }} {{Wayback|url=https://penghu.info/OB1851A63843990F7D5F |date=20210414032727 }}</ref>。約莫於[[道光]]年間（1821年－1850年），媽宮僅有「東甲」（官署區）和「南甲」（港埠區）兩個聚落形成<ref name="馬公1" />。媽宮東甲因與官方政府關係密切，很早便有奉祀[[玄天上帝]]、此具備軍事色彩的神祇當作聚落的信仰中心（[[東甲北極殿]]）。南甲最初的領域則含括媽宮西半部，如火燒坪、澳仔底以及測天島（小案山）等地，一同集結成[[神明會]]的組織；然後在[[同治]]三年（1864年）[[南甲海靈殿|海靈殿]]落成，確立南甲為一獨立祭祀圈或生活圈的態勢儼然成形<ref>{{cite journal |title=〈由祭祀圈到信仰圈－臺灣民間社會地域的構成與發展 |author=林美容 |journal=《歷史月刊》|issue=9 |year=1988 |language=zh-TW }}</ref>；由於海靈殿起建全由民間出資，也成為民間勢力崛起的表徵<ref name="馬公1" />。

[[File:澎湖廳衙門.JPG|缩略图|260x260像素|清末[[澎湖水師鎮|澎湖總鎮署]]衙門（今馬公市仁愛路與建國路附近）]]
「北甲」聚落的形成時間稍晚，大約於清領末期才有祭祀「[[朱府王爺]]」的[[神明會]]組織<ref name=":03">{{cite book |chapter =〈第十章．澎湖天后宮的交陪廟〉|title =《開臺澎湖天后宮志》 |author=郭金龍 |publisher=[[開臺澎湖天后宮]]管理委員會 |year=2006 |isbn=9868272300 |location=澎湖縣 |pages=345-346 |language=zh-TW }}</ref>，直到[[台灣日治時期|日治時期]]的明治三十二年（1899年）才正式起建北甲的角頭廟（[[北甲北辰宮]]）<ref name="馬公1" />。綜論媽宮三甲的聚落，約在光緒十三年（1887年），吳宏洛奉旨築城的時候便已存在<ref name=":6" /><ref name=":1">{{cite book |title=《媽宮（1604-1945）：一個臺灣傳統城鎮空間現代化變遷之研究》 |author=張玉璜 |publisher=[[澎湖縣立文化中心]] |year=1998 |isbn=9570215895 |location=澎湖縣 |pages= |language=zh-TW }}</ref>{{RP|56-57}}。
[[File:Mako_1_8000_1945.jpg|thumb|1945美軍一萬分之一地圖 馬公Makō]]

1981年12月25日，馬公鎮與苗栗縣苗栗鎮、南投縣南投鎮、雲林縣斗六鎮、臺南縣新營鎮同時升格為縣轄市<ref>{{cite news |title=台灣省屬五個鎮 今起改為縣轄市 |url=https://ens.phlib.nat.gov.tw/paper/index-1.asp?Parser=99,4,21,,,,19811225 |accessdate=2026-02-28 |work=[[建國日報 (澎湖)|建國日報]] |date=1981-12-25 |location=臺灣 |page=1 |language=zh-tw |archive-date=2026-01-16 |archive-url=https://web.archive.org/web/20260116210033/https://ens.phlib.nat.gov.tw/paper/index-1.asp?Parser=99,4,21,,,,19811225 |dead-url=no }}</ref>。將馬公港內東北側淺灘填海造陸（今新生路以南區域），1993年完成上述區域馬公第三漁港港區建設。2020年開始規劃將案山淺灘區與測天島北側填海造陸以解決大型郵輪無法停泊的問題<ref>[https://penghudaily.blogspot.com/2020/08/blog-post_392.html?m=1 案山擬海埔新生地 擴建第三漁港至測天島] {{Wayback|url=https://penghudaily.blogspot.com/2020/08/blog-post_392.html?m=1 |date=20220627152154 }}，澎湖日報，2020/8/15</ref>

=== 市政組織 ===
[[澎湖縣馬公市公所|馬公市公所]]是澎湖縣馬公市最高層級的地方[[行政機關]]，在中華民國政府架構中為縣轄市自治的行政機關，同時負責執行縣政府及中央機關委辦事項，馬公市的自治監督機關為[[澎湖縣政府]]。市長由全體市民直接選舉產生，任期為四年，可連選連任一次。馬公市公所並置市政會議，為市政最高決策機構，在市長之下，設有6課3室等9個內部單位及3個附屬機關<ref>{{cite web |url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=18 |title=公所介紹-公所簡介 |access-date=2025-03-03 |publisher=澎湖縣馬公市公所 |language=zh-tw |archive-date=2025-03-21 |archive-url=https://web.archive.org/web/20250321182758/https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=18 |dead-url=no }}</ref><ref>{{cite web |url=https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=191 |title=公所介紹-組織架構 |access-date=2025-03-03 |publisher=澎湖縣馬公市公所 |language=zh-tw |archive-date=2025-03-22 |archive-url=https://web.archive.org/web/20250322023200/https://www.penghu.gov.tw/Tmakun/ch/home.jsp?id=191 |dead-url=no }}</ref>。

[[澎湖縣馬公市民代表會|馬公市民代表會]]是馬公市的最高[[民意機關]]，代表馬公市全體市民立法和監察市政。市民代表由公民直選選出，任期為四年，可連選連任。共有12位市民代表，第一選區1席市民代表、第二選區5席市民代表、第三選區4席市民代表、第四選區2席市民代表，主席、副主席由12位市民代表互選產生<ref>{{cite web |url=https://www.penghu.gov.tw/Rmarkun/home.jsp?id=3 |title=沿革 |access-date=2025-03-03 |publisher=馬公市民代表會 |language=zh-tw |archive-date=2025-04-18 |archive-url=https://web.archive.org/web/20250418035107/https://www.penghu.gov.tw/Rmarkun/home.jsp?id=3 |dead-url=no }}</ref><ref>{{cite web |url=https://www.penghu.gov.tw/Rmarkun/home.jsp?id=5 |title=代表名冊 |access-date=2025-03-03 |publisher=馬公市民代表會 |language=zh-tw |archive-date=2022-07-26 |archive-url=https://web.archive.org/web/20220726160813/https://www.penghu.gov.tw/Rmarkun/home.jsp?id=5 |dead-url=no }}</ref>。

馬公市為[[澎湖縣議會]]第一選區，在澎湖縣議會19席縣議員中，馬公市共選出11席縣議員<ref>{{Cite web |url=http://www.phcouncil.gov.tw/mop.php |title=澎湖縣選區介紹 |author=澎湖縣議會 |publisher=澎湖縣議會全球資訊網 |access-date=2022-10-27 |language=zh-tw |archive-date=2019-04-29 |archive-url=https://web.archive.org/web/20190429044838/http://www.phcouncil.gov.tw/mop.php |dead-url=no }} {{Wayback|url=http://www.phcouncil.gov.tw/mop.php |date=20190429044838 }}</ref>。

1945年（民國34年），[[國民政府]]將「馬公街」改為「馬公鎮」，下設里。
