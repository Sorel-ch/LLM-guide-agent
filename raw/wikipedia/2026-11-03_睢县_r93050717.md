'''{{Zy|睢|suī|ㄙㄨㄟ|seoi1}}县'''在[[中华人民共和国]][[河南省]]东部、[[惠济河]]中游，是[[商丘市]]下辖的一个[[县级行政区|县]]。睢县位于商丘市西部，总面积926平方公里，与[[民权县]]、[[杞县]]、[[宁陵县]]、[[太康县]]、[[柘城县]]毗邻。北距民权县县城27.5公里，西距杞县县城38公里，东距宁陵县县城27公里，西南距太康县县城47公里，东南距柘城县城49公里。县人民政府驻[[城郊乡 (睢县)|凤城街道]]鳳城大道1號。

== 历史沿革 ==
[[新石器时代]]睢县就已有人类居住，在睢县[[周龙岗遗址|周龙岗]]发现了[[新石器时代]]的遗址。[[春秋时期]]，睢县境属于[[宋国|宋]]、[[陈国|陈]]二国。[[战国]]时期属于[[魏国 (战国)|魏国]]。[[秦朝]]置[[襄邑县]]，属[[砀郡]]，为睢县设县之始，距今已有2600多年的历史。至[[西汉]][[元狩]]元年归属[[陈留郡]]。[[王莽]]时期被改称“襄平”，至[[东汉]]初复原。[[三国]]时期[[陈留郡]]被改为[[陈留国]]，襄邑遂属陈留国，直至[[晋朝]]。[[南北朝]]时期，[[北魏]]属[[阳夏郡]]，[[东魏]]属[[梁郡]]，[[北齐]]时襄邑县并入[[雍丘县]]，属于[[睢阳郡]]。[[隋朝]]初属[[宋郡]]，[[开皇]]十六年改属[[梁郡]]。[[唐高祖]]年间属[[杞州]]，[[唐太宗]][[貞觀]]年间又属[[宋州]]。[[五代]]时期襄邑县属[[开封府]]，直至[[北宋]]初。[[宋徽宗]][[崇宁]]四年，襄邑升为[[拱州]]，并设保庆军节度，属京畿，下辖[[考城]]、[[太康县|太康]]、[[楚丘]]、[[宁陵]]、[[柘城]]五县。[[大观 (年号)|大观]]四年废拱州，仍称襄邑县，[[政和 (年號)|政和]]四年再升拱州，[[宣和]]二年再废。此时襄邑县仅保留保庆军节度，属[[京东西路]]。金朝时因古时有[[睢水]]流过，改拱州保庆军为[[睢州 (金朝)|睢州]]，属南京路，州以“睢”得名从此开始。元朝改南京路为[[汴梁路]]，仍辖睢州。明朝初，睢州属[[开封府]]，洪武十年降睢州为睢县，[[洪武]]十三年复升为睢州，为[[直隶州]]，下辖考城、柘城两县。[[嘉靖]]二十四年，[[归德州 (开封府)|归德州]]被升为[[归德府]]，睢州由直隶州降为[[散州]]，连同所辖两县归属归德府，清朝此建制保持不变。[[中华民国]]二年（1913年），改睢州为睢县，次年划归[[开封道]]管辖。1932年，睢县划归河南省第二行政督察区管辖，1948年4月又改属河南省第十二行政督察区<ref name=his>{{cite book |author1=河南省地方史志编纂委员会 |title=河南省志：区域建置志 地貌山河志 |date=1994-11 |publisher=河南人民出版社 |location=郑州}}</ref>。

1948年，[[中国人民解放军]]接管睢县后，属[[商丘专区]]管辖。1958年12月，商丘专区撤销，睢县改属[[开封专区]]。1961年12月恢复商丘专员公署，1969年改称地区行署，睢县属之<ref name=his />。1997年6月，[[商丘地区]]撤销，设立地级[[商丘市]]，睢县属商丘市管辖。

== 自然地理 ==
=== 地形 ===
睢县位处[[豫东平原]]，为黄河下游冲积扇一部分。总的地形平坦，西北略高，东南略低，西北与东南之间的高差为9米。境内河流有[[惠济河]]、[[通惠渠]]等。城内有[[凤城湖|北湖]]及周围五个卫星湖，全县湿地总面积2112公顷，有“中原水城”之称<ref name=sz>{{cite book |author1=河南省地方史志编委会 |title=河南省志 市地县概况 |date=1995-08 |publisher=河南人民出版社 |location=郑州 |isbn=9787555405665 |accessdate=2021-12-07}}</ref><ref name=intro>{{cite web |author1=睢县人民政府办公室 |title=睢县县情 |url=https://www.suixian.gov.cn/index/index/detail/id/23/type/6.html |website=睢县人民政府 |accessdate=2021-12-07 |archive-date=2021-12-07 |archive-url=https://web.archive.org/web/20211207143209/https://www.suixian.gov.cn/index/index/detail/id/23/type/6.html |dead-url=no }}</ref>。

=== 气候 ===
睢县属[[暖温带]][[季风]]气候，年平均气温14摄氏度。7月份气温最高，平均气温为27.1摄氏度，历史极端最高气温为42.3摄氏度（1966年7月19日）；1月份气温最低，平均气温为-0.7摄氏度，历史极端最低气温为-15.7摄氏度（1969年2月6日）。

== 经济 ==
[[File:20220311 Shoe-Making Industrial Park in Sui County.jpg|200px|缩略图|睢县制鞋产业园]]
2022年，睢县完成生产总值人民币260.78亿元，人均生产总值36,624元，在河南省各县级行政区（不含市辖区）中分别排第70位和第93位。其中第一产业62.79亿元，第二产业97.78亿元，第三产业100.22亿元<ref name=stat>{{cite book |author1=河南省统计局 |title=河南统计年鉴2023 |publisher=中国统计出版社 |location=北京 }}</ref>。

睢县经济传统上以农业为主，主要农作物有小麦、玉米、大豆、红薯等，经济作物有棉花、芝麻、花生、油菜等。睢县境内沙荒面积较大，适合发展林业，主要树种有[[杨属|杨]]、[[泡桐]]、[[槐]]、[[柳]]、[[桑树|桑]]、[[松]]、[[柏]]等<ref name=sz />。近年来农业发展上以[[辣椒]]、[[芦笋]]、中药材的种植为特色，辣椒、芦笋、中药材的种植面积分别达10万亩、5万亩、5000亩<ref>{{cite web |title=农业经济 |url=https://www.suixian.gov.cn/index/index/detail/id/200.html |website=睢县人民政府 |accessdate=2021-12-09 |archive-date=2021-12-09 |archive-url=https://web.archive.org/web/20211209034333/https://www.suixian.gov.cn/index/index/detail/id/200.html |dead-url=no }}</ref>。工业上，睢县以制鞋和电子信息为主导产业，并形成产业集群，有制鞋及鞋材配套企业一百余家，电子信息企业20余家<ref name=intro />。

== 交通 ==
睢县西距省会[[郑州市]]166公里，东距[[商丘市]]62公里。{{China Expwy Name|S60|P=Henan}}东西横贯县境。{{中国国道名|343}}、{{中国省道名|213|P=河南}}、{{中国省道名|214|P=河南}}、{{中国省道名|316|P=河南}}等国、省干道过境，并以县城为中心呈放射状向四周扩散。

睢县境内并无铁路经过，距离县城最近的普速铁路车站和高速铁路车站分别为[[陇海铁路]]上的[[民权站]]和[[徐兰高速铁路]]上的[[民权北站]]。

== 文化 ==
=== 文物古迹 ===
{{main|睢县各级文物保护单位列表}}
睢县境内有[[全国重点文物保护单位]]1处：位于[[后台乡]]阎庄村的[[阎庄圣寿寺塔|圣寿寺塔]]。该塔始建于[[北宋]]，为六角九级密檐式砖塔，2006年被列为[[第六批全国重点文物保护单位]]。另外有[[河南省文物保护单位]]10处：
* [[汤斌祠]]：位于县城西部，为[[清朝|清]]初名臣[[湯斌|汤斌]]为其母亲所建的祠堂，祠堂内的碑刻和祠前的节烈牌坊于1963年被公布为[[第一批河南省文物保护单位]]，然而碑刻和牌坊已在文化大革命期间被损毁，今仅存门楼和大殿。
* [[周龙岗遗址]]：位于[[蓼堤镇]]周龙岗村北，[[新石器时代]][[龙山文化]]至[[商朝]]时期的古遗址，1988年被公布为[[第二批河南省文物保护单位]]。
* [[乔寨遗址]]：位于[[周堂镇]]西乔寨村，龙山文化遗址，1988年被公布为第二批河南省文物保护单位。
* [[袁家山|吕祖庙]]：位于县城文化路，又称“袁家山”，为一处[[明代]]船型园林建筑群，2000年被公布为[[第三批河南省文物保护单位]]。
* [[东关清真寺 (睢县)|东关清真寺]]：始建于明代，后经多次整修，为豫东地区保存较为完整的民族文化古建筑。[[豫东战役#睢杞战斗|睢杞战役]]时，[[粟裕]]曾在寺内设指挥部。2008年被公布为[[第五批河南省文物保护单位]]。
* [[匡城故城]]：位于[[匡城乡]]匡城村西北，[[东周]]时期[[宋国]]城池遗址，2008年被公布为第五批河南省文物保护单位。
* 睢州故城：目前为国家4A级景区[[凤城湖|北湖景区]]，位于县城北部，为[[春秋时期|春秋]]至[[明朝|明代]]的睢州旧城，因[[黄河]]决口被淹没而废弃，为豫东地区常见的“城上湖”。2008年被公布为第五批河南省文物保护单位。
* [[无忧寺塔]]：位于[[平岗镇 (睢县)|平岗镇]]周塔村，始建于唐代，于宋代重建，原为八角五级楼阁式砖塔，现存三级。2016年被公布为[[第七批河南省文物保护单位]]。
* [[河南省立睢县中学教学楼]]：位于[[城关回族镇 (睢县)|城关镇]]湖东路，建于1949-1952年间，由师生利用课余时间亲手使用城砖建造而成，目前为睢县人民文化馆。2021年被公布为[[第八批河南省文物保护单位]]
* [[睢县王氏三烈故居]]：位于匡城乡英王村，为烈士三兄弟王鸿翔、王鸿业、王鸿钧的出生地及旧居。
