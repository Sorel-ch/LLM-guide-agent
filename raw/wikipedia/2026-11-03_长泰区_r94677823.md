'''长泰区'''（[[閩南語]]長泰話: Tiônn-thuà-khi）是[[中华人民共和国|中國]][[福建省]][[漳州市]]的一個[[市辖区 (中华人民共和国)|市辖区]]。土地面积912.67平方公里，其中耕地16.7万亩，山地90.3万亩，區政府駐[[武安街道]]解放路84號。

== 历史沿革 ==
[[隋]][[唐]]时期，现长泰区境属[[泉州 (景云)|泉州]][[南安县 (隋朝)|南安县]]武德乡。876年，置武德场。888年，改名武胜场，后改武安场。

[[南唐]][[保大 (南唐)|保大]]十三年（955年），长泰建县，取意“长久安泰”。县治设于今武安镇辖区内，归泉州。

[[北宋]][[太平兴国]]五年（980年），转属[[漳州 (古代)|漳州]]。

2021年2月2日，撤县设区<ref>{{Cite web |url=http://www.fujian.gov.cn/zwgk/zfxxgk/szfwj/jgzz/mzcjbzzc/202102/t20210203_5530847.htm |title=《福建省人民政府关于同意调整漳州市部分行政区划的批复》闽政文〔2021〕48号 |access-date=2021-02-03 |archive-date=2025-04-20 |archive-url=https://web.archive.org/web/20250420143144/https://www.fujian.gov.cn/zwgk/zfxxgk/szfwj/jgzz/mzcjbzzc/202102/t20210203_5530847.htm |dead-url=no }}</ref>。

== 行政区划 ==
长泰区下辖1个[[街道办事处|街道]]、3个[[镇 (中华人民共和国)|镇]]、1个[[乡 (中华人民共和国)|乡]]<ref>{{PRC admin/ref sgc|35/06/25}}</ref>：{{PRC admin/children|35/06/25}}。

== 人口 ==
2018年，長泰區户籍人口21萬人，外來人口12萬人。

根据(福建省)漳州市[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]公报显示：长泰县常住人口为228235人，男性占比52.42%，女性占比47.58%，年龄结构中0-14岁占比18.8%，15-59岁占比64.4%，60岁以上占比16.8%，65岁以上占比11.12%。<ref>{{Cite web|title=中國: 福建省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/fujian/admin/|access-date=2023-08-14|website=www.citypopulation.de|archive-date=2021-02-26|archive-url=https://web.archive.org/web/20210226125808/https://www.citypopulation.de/zh/china/fujian/admin/|dead-url=no}}</ref>

== 地理 ==
长泰县北面为泉州市[[安溪县]]、南面为[[龙海市]]、西面为[[华安县]]和[[漳州市]][[龙文区]]，而东南面则为[[厦门市]]。

长泰地理可以用“七山一水二分田”来形容，呈向南开口的马蹄形地貌，阻滞了[[台风]]和[[寒流]]的入侵，气候温暖，雨量充沛，属南亚[[热带海洋性气候]]，年平均气温约21摄氏度，降雨量1460毫米，气候环境有利于农业生产。

== 特产 ==
[[芦柑]]、[[无公害蔬菜]]、[[柚子]]、[[龙眼]]、[[荔枝]]、[[香蕉]]、[[食用菌]]、[[麻竹]]、[[茶叶]]、[[畜牧]][[水产]]、[[砂仁]]。

== 矿产 ==
水能资源蕴藏量大，并已有相当程度的开发，是全国农村初级电气化县。非金属矿藏有[[高岭土]]、[[叶腊石]]、[[钾长石]]、[[花岗岩]]、[[矿泉水]]、[[温泉]]、[[九龙璧]]等。

== 旅游景点 ==
长泰森林覆盖率达55%。境内有[[天柱山国家森林公园]]、[[百里龙津]]、[[活盘湖]]、[[十里村漂流]]、[[百丈崖瀑布]]等风景景点。
