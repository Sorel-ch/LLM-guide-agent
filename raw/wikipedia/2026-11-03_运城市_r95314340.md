'''运城市'''，古称'''河东'''，是[[中华人民共和国]][[山西省]]下辖的[[地级市]]，位于[[山西省]]西南部，[[陕西省|秦]][[山西省|晋]][[河南省|豫]][[黄河]]金三角。市境北界[[临汾市]]，东临[[晋城市]]与[[河南省]][[济源市]]、[[洛阳市]]，南接河南省[[三门峡市]]，西隔黄河与[[陕西省]][[渭南市]]毗邻。地处[[黄土高原]]东南部，[[吕梁山]]、[[太岳山]]、[[中条山]]之间的运城盆地。[[汾河]]在市境北部汇入黄河，[[涑水河]]自东北向西南斜贯市境，市人民政府驻[[盐湖区]]河东街248号。

运城是[[华夏文明]]的重要发祥地，史学研究中，[[舜]]的都城[[蒲阪]]、[[禹]]的都城[[阳城 (夏朝)|阳城]]被认为在今运城境内。

==历史==
考古發現运城有可能是上古[[黃帝]]和[[炎帝]][[阪泉之戰]]的地點。距今约180万年前，这里就有人类活动生息。[[舜]]都[[蒲坂]]、[[禹]]都[[阳城 (夏朝)|阳城]]、以及[[夏]]的都城均在这里。[[春秋时期|春秋]]时统属[[晋国]]，[[晋献公]]于前669年定都于绛（今[[绛县]]）。韩、赵、魏[[三家分晋]]后，运城属[[魏国 (战国)|魏国]]。当时，魏国早期都城[[安邑城|安邑]]即在今[[夏县]]。[[秦始皇]]统一中国，设36郡，运城属[[河東郡_(中國)|河东郡]]，治所[[安邑縣]]。以后两千多年，建置频繁，但一直惯称这一地区为“[[河东]]”。东汉[[兴平 (东汉)|兴平]]二年(195)，汉献帝避难河东，暂都安邑，次年废。明清起，为[[山西省|山西]]地。

元末时，因政府经营[[中國鹽業史|盐业]]之故，设立河东[[都转盐运使司]]。为便于管理，驻地由[[解州]]城移驻潞村（或称路村）。[[延祐]]年间，潞村更名为圣惠镇。[[至正]]十六年（1356年），[[那海德俊]]任[[盐运使]]时开始筑城，初名凤凰城，因是盐运司所在地，后更名运城。明朝沿袭元制，并不断修缮[[运城城墙]]。[[成化]]九年（1473年），政府又增派[[巡盐御史]]驻运城，以监临盐政。明清时，运城“其地虽属安邑县辖”，但在政务上自成体系<ref>{{Cite web |url=http://www.huaxia.com/sxyc/csgs/2012/12/3131146.html |title=古代运城的创建与发展 |accessdate=2021-08-31 |author= |date=2012-12-18 |work= |publisher=华夏经纬网，来源：运城市台办供稿 |language=Zh-hans |archive-date=2021-08-30 |archive-url=https://web.archive.org/web/20210830230403/http://www.huaxia.com/sxyc/csgs/2012/12/3131146.html }}</ref>。

1947年4月起，中国共产党领导的[[华北野战军]]发起[[运城战役]]，三打运城。同时，[[晋冀鲁豫野战军]]第4纵队和[[太岳军区]]部队，陆续攻占今运城市境内的各县{{noteTag|1947年4月4日，解放军攻占[[绛县]]，7日攻占[[新绛县]]，8日攻占[[稷山县]]、[[河津县]]，11日攻占[[萬泉縣]]，13日攻占[[荣河县]]，15日攻占[[猗氏县]]，23日攻占[[临晋县 (唐朝)|临晋县]]、[[虞乡县]]，24日攻占[[平陆县]]，25日攻占[[永济县]]、[[解县]]，26日攻占[[闻喜县]]，29日攻占[[芮城县]]；7月14日攻占[[夏县]]；8月26日攻占[[垣曲县]]；12月28日攻占[[安邑县]]<ref name="a1">{{Cite web |url=http://www.ycsdsw.com/view.asp?id=117 |title=运城及各县的解放 |accessdate=2021-08-31 |author= |date=2017-09-01 |work= |publisher=运城党史网 |language=Zh-hans |archive-date=2021-08-30 |archive-url=https://web.archive.org/web/20210830205216/http://www.ycsdsw.com/view.asp?id=117 }}</ref>。}}。12月28日，攻占[[运城城墙|运城]]，今运城市主城区。29日，[[西北野战军]]第2纵队围困[[安邑縣|安邑]]县城。中华民国政府任命的安邑县长[[张毓桐]]率部逃跑。31日，解放军消灭出逃敌军。中共政權取得运城全境<ref name=a1/>。1949年时成立[[运城专区]]。1954年，运城、[[临汾专区|临汾]]两专区合并为[[晋南专区]]。1958年，以安邑县、[[解虞县]]、[[临猗县]]合并为[[运城县]]。1970年，晋南地区撤消，重设[[运城地区]]。

2000年6月，经国务院批准，撤运城地区设运城市<ref>{{cite web |title=历史沿革 |url=https://www.yuncheng.gov.cn/doc/2019/10/29/2221.shtml |website=运城市人民政府 |date=2024-07-13}}</ref>。

==地理==
[[File:ISS066-E-83120 - View of Earth.jpg|thumb|运城市域卫星图：北依吕梁山与[[临汾]]市接壤，东峙[[中条山]]和[[晋城]]市毗邻，西和南隔[[黄河]]在[[风陵渡]]与[[陕西省]][[潼关]]、[[河南省]][[三门峡市]]相望，中部则为[[五老峰国家森林公园|五老峰]]]]
位于[[山西]]省西南部的[[晋南盆地]]，北依吕梁山与[[临汾]]市接壤，东峙[[中条山]]和[[晋城]]市毗邻，西、南与[[陕西省]][[渭南市]]、[[河南省]][[三门峡市]]隔[[黄河]]相望。地势平坦，气候温和，是传统的农业大区<ref>{{cite web |title=自然地理环境 |url=https://www.yuncheng.gov.cn/doc/2021/05/06/123127.shtml |website=运城市人民政府 |date=2024-07-20}}</ref>。

===气候===
运城属[[暖温带季风气候]]，四季分明。冬夏较长，春秋较短。冬季较冷，夏季炎热多雨。1月平均气温−0.9℃，极端最低气温-18.9℃（1971年1月23日）。7月平均气温27.4℃，极端最高气温42.7℃（1966年6月21日）。年均降水约530毫米。年日照时数2218.6小时，平均日照百分率45%-55%。

== 人口 ==
[[File:First View of Yuncheng.jpg|thumb|运城市面]]
截至2022年末，运城市常住人口为471.85万人，比上年末减少1.47万人。其中，城镇常住人口240.29万人，占常住人口比重为50.93%。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为4,774,508人<ref>{{cite web |author1=运城市统计局、运城市第七次全国人口普查领导小组办公室 |title=运城市第七次全国人口普查公报 |url=https://www.yuncheng.gov.cn/doc/2021/06/03/237003.shtml |access-date=2023-07-23 |archive-date=2023-07-23 |archive-url=https://web.archive.org/web/20230723212642/https://www.yuncheng.gov.cn/doc/2021/06/03/237003.shtml |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的5,134,779人相比，十年共减少了360,271人，下降7.02%，年平均增长率为-0.72%。其中，男性人口为2,410,247人，占总人口的50.48%；女性人口为2,364,261人，占总人口的49.52%。总人口性别比（以女性为100）为101.95。0－14岁的人口为802,712人，占总人口的16.81%；15－59岁的人口为3,018,752人，占总人口的63.23%；60岁及以上的人口为953,044人，占总人口的19.96%，其中65岁及以上的人口为654,104人，占总人口的13.7%。居住在城镇的人口为2,352,523人，占总人口的49.27%；居住在乡村的人口为2,421,985人，占总人口的50.73%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为4,764,709人，占99.79%；各[[中国少数民族|少数民族]]人口为9,799人，占0.21%。与2010年第六次全国人口普查相比，汉族人口减少361,552人，下降7.05%，占总人口比例下降0.04个百分点；各少数民族人口增加1,281人，增长15.04%，占总人口比例增加0.04个百分点。

== 交通 ==
* {{中国国道名|209}}过境。

[[運城盐湖国际機場]]（IATA代碼：YCU；ICAO代碼：ZBYC）是中華人民共和國山西省運城市的一座機場，位於運城市鹽湖區陶村鎮張孝村，距市中心11公里，2005年2月7日通航。

[[運城北站]]位於山西省運城市鹽湖區姚孟鄉陶上村，是[[大西客运专线|大西高鐵]]上的新建車站，也是運城第二個火車站，於2014年7月1日開通運營。運城北站站房面積7999平方米，車站設有4個月台。

==文化==
===名胜古迹===
[[File:Lord Guan.jpg|thumb|关羽像]]
全市文物旅游景点1600余处，其中国家级文物保护单位102处，名列全国各地市第一名。驰名中外的有武庙之祖[[解州关帝庙]]、四大名楼之一永济[[鹳雀楼]]、艺术宫殿[[芮城]][[呂祖]]廟[[永乐宫]]、《[[西厢记]]》故事发生地永济[[普救寺]]、中华祭祀圣地万荣[[后土祠]]、[[中国死海]][[运城盐湖]]，以及盐湖舜帝陵、[[黄河大铁牛]]、万荣秋风楼、[[夏县]][[司马光]]墓等。
