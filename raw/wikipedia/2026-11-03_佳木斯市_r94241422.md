'''佳木斯市'''简称'''佳'''，是[[中华人民共和国]][[黑龙江省]]下辖的[[地级市]]，[[滿洲國]]和[[中華民國大陸時期|民國時期]]曾先後為[[三江省]]、[[合江省 (中华民国)|合江省]]省會，原[[黑龍江生產建設兵團]]司令部所在地，位于黑龙江省东北部，是中国最东边的[[地级行政区]]。市境南界[[双鸭山市]]、[[七台河市]]，西接[[哈尔滨市]]、[[伊春市]]，西北隔[[松花江]]与[[鹤岗市]]接壤，东北隔[[黑龙江 (河流)|黑龙江]]与[[俄罗斯]][[犹太自治州]][[比罗比詹]]毗邻，东隔[[乌苏里江]]与俄罗斯[[哈巴罗夫斯克边疆区]][[伯力]]相望。地处[[三江平原]]腹地，地势低平，多[[沼泽]]，[[松花江]]贯穿市区。市人民政府驻[[前进区]]。

佳木斯市是黑龙江省东北部地区的政治、经济、科技、教育、文化、卫生中心。2006年佳木斯市获得[[中国中央电视台]]的“年度中国最佳生态环境魅力城市”称号。是中国最早迎接太阳升起的地方<ref name="a2"/>，被称为“东方第一城”。

== 地名 ==
该市地名“[[wikt:佳木斯|佳木斯]]”（{{lang-mnc|ᡤᡳᠶᠠᠮᡠᠰᡳ|v=Giyamusi|a=Giyamusi}}）起源於何時沒有確切記載，最早有文字紀錄的是清代<ref>{{cite web |title=从地名读懂黑龙江 |url=https://mzt.hlj.gov.cn/mzt/c103766/202311/c00_31688000.shtml |website=黑龙江省民政厅 |publisher=《北方文学》 |accessdate=2023-11-24 |archive-date=2024-07-26 |archive-url=https://web.archive.org/web/20240726200505/https://mzt.hlj.gov.cn/mzt/c103766/202311/c00_31688000.shtml |url-status=dead }}</ref>。

清[[康熙]]五十九年（1720年）《[[康熙皇輿全覽圖]]》上，今佳木斯地區被標註為「甲母克寺噶珊」（{{lang-mnc|ᡤᡳᠶᠠᠮᡠᡴᠰᡟ<br />ᡤᠠᡧᠠᠨ|v=giyamuksy gašan}}）。 [[乾隆]]四十三年（1778年）出版的《盛京、吉林、黑龍江標註戰績圖》上，以滿漢文字稱「嘉木寺屯」。按[[满语]]解釋，佳木斯爲驛丞，噶珊爲村，所以佳木斯意爲「驛丞村」或「站官屯」<ref name="a2">{{Cite web |url=https://finance.sina.com.cn/xiaofei/consume/20060222/1117563448.shtml |title=佳木斯 最先迎接阳光的边陲之城 |accessdate=2024-01-10 |author= |editor=王彦艳 |date=2006-02-22 |work= |quote=新浪网，来源：中国消费网 |publisher= |language=Zh-hans |archive-date=2024-01-10 |archive-url=https://web.archive.org/web/20240110152704/https://finance.sina.com.cn/xiaofei/consume/20060222/1117563448.shtml |dead-url=no }}</ref>。

此外，或有说法认为「佳木斯」为[[赫哲语]]，意爲「骨頭」或「屍體」<ref>{{cite journal |author1=郝庆云 |title=浅谈黑龙江省地名的特点 |journal=《哈尔滨师专学报》 |date=1994年4月 |pages=73-75 |url=http://iqh.ruc.edu.cn/old/zglsdlyj/lsdl_dmxyd/dmyj/e539c7cb23984812a7cebefa5b1b9255.htm |access-date=2025-09-09 |archive-date=2026-01-05 |archive-url=https://web.archive.org/web/20260105155326/http://iqh.ruc.edu.cn/old/zglsdlyj/lsdl_dmxyd/dmyj/e539c7cb23984812a7cebefa5b1b9255.htm |url-status=live }}</ref>；或说意为“{{or|巫师（[[萨满]]）祈祷之处|date=2021年2月22日}}”。

== 历史 ==
據史書記載，佳木斯歷史上長期是[[通古斯民族|滿-通古斯民族]]活動的地區，當地還有松花江通往黑龍江江口的古[[驛道]]。[[先秦]]時為[[肃慎]]地。[[两汉]]、[[晋代]]属[[挹娄]]。[[南北朝]]时属[[勿吉]]。[[隋]][[唐]]時期属[[靺鞨]]。[[辽代]]属[[生女真]]五大部族領地，称[[五国部]]。[[金代]]置[[胡里改路]]，治今[[依兰县]]。[[元朝|元]][[至元 (元世祖)|至元]]中析[[開元路 (元朝)|开元路]]置[[水达达路]]。[[明朝|明]][[永乐]]七年（1409年）置[[奴儿干都司]]<ref name="a1"/>。

[[清朝|清]][[雍正]]七年（1729年）设[[三姓副都統]]，治今依兰县，隶属[[吉林将军]]。[[光绪]]十四年（1888年）于今佳木斯市区罝东兴镇。光绪三十二年（1906年）置[[依兰府]]，今市境属之。[[宣统]]二年（1910年）设[[桦川县]]，驻东兴镇<ref name="a1"/>。

[[民國紀年|民國]]元年（1912年），桦川县迁至[[悦来镇 (桦川县)|悦来镇]]。1930年，东兴镇与佳木斯屯合并为佳木斯镇，属桦川县。[[满洲国]]成立後，于1934年设立[[三江省]]，省政府驻佳木斯，桦川县迁驻佳木斯镇。1937年正式设立[[佳木斯市 (中华民国)|佳木斯市]]，属三江省。佳木斯成为省、市署驻地<ref name="a1"/>，东北十大新都市之一。

[[File:Republic of China edcp location map (disputed territories) Hokiang.svg|thumb|第二次國共內戰期間，佳木斯市作为合江省省會，实际上由解放軍控制]]
1945年10月下旬，中共在佳木斯市成立三江地区[[行政公署]]。11月撤销三江地区，新设[[合江省 (解放区)|合江省]]<ref name="a1"/>。[[第二次国共内战]]期间，該地成为中共[[解放區]]对抗[[國民政府]]的后方根据地，称之为“东北的小延安”<ref name="a2"/>。1947年國民政府公布《[[东北新省区方案]]》，设[[合江省 (中華民國)|合江省]]，省会驻[[佳木斯市 (中华民国)|佳木斯市]]。1949年[[东北人民政府]]撤销[[合江省 (解放区)|合江省]]，将其并入[[松江省 (中华人民共和国)|松江省]]<ref name="a1"/>。1954年8月，松江省并入[[黑龙江省]]，佳木斯为省辖市。

1984年12月15日，[[中华人民共和国国务院|中国国务院]]批准国函〔1984〕178号，撤销[[合江地区]]，其所属[[桦南]]、[[集贤县|集贤]]、[[宝清县|宝清]]、[[富锦]]、[[依蘭縣|依兰]]、[[汤原县|汤原]]、[[桦川]]、[[萝北]]、[[绥滨]]、[[饶河县|饶河]]、[[同江縣|同江]]、[[抚远县|抚远]]、[[友谊县|友谊]]13县划归佳木斯市<ref>{{Cite web|url=https://www.gov.cn/govweb/test/2007-03/23/content_559128.htm|title=中华人民共和国行政区划（1984年）|accessdate=2024-01-10|author=|editor=|date=2007-03-23|work=|quote=|publisher=中国政府网，来源：行政区划网，《中华人民共和国行政区划简册（1985年版）》，中华人民共和国民政部编，1985年3月1版|language=Zh-hans|archive-date=2024-01-12|archive-url=https://web.archive.org/web/20240112165214/https://www.gov.cn/govweb/test/2007-03/23/content_559128.htm|dead-url=no}}</ref>，[[地市合并]]。

1987年，撤销同江县，改设[[同江市]]；将集贤县划归[[双鸭山市]]；将萝北、绥滨两县划归[[鹤岗市]]。1988年，撤销富锦县，改设[[富锦市]]。1991年，将宝清、友谊两县划归[[双鸭山市]]；将依兰县划归[[哈尔滨市]]。1993年将饶河县划归双鸭山市。2006年7月，撤销[[永红区]]，并入佳木斯市[[郊区 (佳木斯市)|郊区]]。2016年1月，撤销抚远县，设立[[抚远市]]<ref name="a1">{{Cite web |url=https://www.jms.gov.cn/html/index/alone/000100010001.html |title=建制沿革 |accessdate=2024-01-10 |author= |editor= |date= |work= |quote= |publisher=佳木斯市人民政府网站 |language=Zh-hans |archive-date=2024-01-10 |archive-url=https://web.archive.org/web/20240110135131/https://www.jms.gov.cn/html/index/alone/000100010001.html |dead-url=no }}</ref>。

== 地理 ==
佳木斯市东邻[[双鸭山市]]，南接[[牡丹江市|牡丹江]]、[[七台河]]、[[鸡西市]]，西依[[哈尔滨]]、[[伊春市]]，北邻[[鹤岗市]]。

佳木斯属中[[温带大陆性季风气候]]，冬严长干燥，春季大风易旱，夏季温热多雨，秋凉爽。1月平均气温−18.5℃，7月平均气温22.5℃。全年均温3.62℃，降水一般在500毫米以上。3月底土壤开始解冻，11月中旬大地开始封冻。无霜期为130天。

=== 行政区划 ===
佳木斯市现辖4个[[市辖区 (中华人民共和国)|市辖区]]、3个[[县 (中华人民共和国)|县]]，代管3个[[县级市]]。

* 市辖区：[[向阳区 (佳木斯市)|向阳区]]、[[前进区]]、[[东风区]]、[[郊区 (佳木斯市)|郊区]]
* 县级市：[[同江市]]、[[富锦市]]、[[抚远市]]
* 县：[[桦南县]]、[[桦川县]]、[[汤原县]]

此外，随着中俄国界东段界桩确定，抚远三角洲开发建设管理委员会于2008年10月设立，为佳木斯市政府的派出机构，对[[黑瞎子岛]]171平方公里领土行使行政和民事管辖权，对抚远三角洲开发建设实行统一管理。

== 人口 ==
2022年佳木斯市户籍总人口为225.6万人，比上年末减少2.3万人。<ref>{{Cite web|title=2022年佳木斯市户籍总人口为225.6万人，比上年末减少2.3万人_佳木斯人口_聚汇数据|url=https://m.gotohui.com/p/list/185378.html|access-date=2023-08-31|website=m.gotohui.com|archive-date=2023-08-31|archive-url=https://web.archive.org/web/20230831010414/https://m.gotohui.com/p/list/185378.html|dead-url=no}}</ref>

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,156,505人<ref>{{cite web |author1=佳木斯市统计局、佳木斯市第七次全国人口普查领导小组办公室 |title=2020年佳木斯市第七次全国人口普查主要数据公报 |url=https://credit.jms.gov.cn/470.news.detail.dhtml?news_id=33401 |access-date=2023-07-23 |archive-date=2023-07-23 |archive-url=https://web.archive.org/web/20230723184512/https://credit.jms.gov.cn/470.news.detail.dhtml?news_id=33401 |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,552,097人相比，十年共减少了395,592人，下降15.5%，年平均增长率为-1.67%。其中，男性人口为1,079,952人，占总人口的50.08%；女性人口为1,076,553人，占总人口的49.92%。总人口性别比（以女性为100）为100.32。0－14岁的人口为228,293人，占总人口的10.59%；15－59岁的人口为1,426,896人，占总人口的66.17%；60岁及以上的人口为501,316人，占总人口的23.25%，其中65岁及以上的人口为336,148人，占总人口的15.59%。居住在城镇的人口为1,405,396人，占总人口的65.17%；居住在乡村的人口为751,109人，占总人口的34.83%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,098,374人，占97.3%；各[[少数民族]]人口为58,131人，占2.7%。与2010年第六次全国人口普查相比，汉族人口减少386,492人，下降15.55%，占总人口比例下降0.06个百分点；各少数民族人口减少9,100人，下降13.54%，占总人口比例增加0.06个百分点。其中，[[满族]]人口减少4,542人，下降13.97%，占总人口比例增加0.02个百分点；[[朝鲜族]]人口减少6,093人，下降24.5%，占总人口比例下降0.1个百分点；[[回族]]人口减少394人，下降9.51%，占总人口比例增加0.01个百分点；[[蒙古族]]人口增加606人，增长24.93%，占总人口比例增加0.05个百分点；[[赫哲族]]人口增加321人，增长13.97%，占总人口比例增加0.03个百分点。

== 交通 ==
[[File:知青文化广场 3.jpg|thumb|知青文化广场]]
[[File:佳木斯文化艺术中心.jpg|thumb|佳木斯文化艺术中心]]
佳木斯市交通便利，铁路、公路、水路、航空较为发达，是黑龙江省东部地区的交通枢纽。

=== 铁路 ===
境内有[[图佳铁路]]、[[佳富铁路]]、[[前抚铁路]]、[[哈佳铁路]]、[[绥佳铁路]]，五条铁路干线通往全国各地。

=== 公路 ===

==== 国道 ====
{{中国国道名|102}}、{{中国国道名|201}}、{{中国国道名|221}}过境。

==== 高速公路 ====
{{China Expwy Name|G11}}（鹤岗-大连）、{{China Expwy Name|G1011}}（哈尔滨-同江）、{{China Expwy Name|G1012}}（建三江-黑瞎子岛）在境内相交，高速公路发达。

=== 水路 ===
“江海联运”沿[[松花江]]、[[黑龙江 (河流)|黑龙江]]下行经[[鞑靼海峡]]可达[[俄罗斯]]、[[日本]]、[[朝鲜民主主义人民共和国|朝鲜]]、[[韩国]]等国家及太平洋沿岸国家地区。
