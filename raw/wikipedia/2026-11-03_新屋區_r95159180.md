'''新屋區'''（{{lang-hak|hlhp=sinˋ vug kiˋ}}；{{Lang-nan-tw|tl=Sin-ok-khu}}），前身「新屋鄉」，位於[[臺灣]][[桃園市]]西端，東北方臨[[觀音區]]、[[中壢區]]，東南方臨[[楊梅區]]，西南邊與[[臺灣省]][[新竹縣]][[新豐鄉 (台灣)|新豐鄉]]相臨，西濱[[臺灣海峽]]，為典型的農業鄉。全境耕地面積廣大，並有半數以上人口從事農業，水稻為主要作物，是[[北臺灣|北臺灣地區]]的重要稻米產區。在桃園市國土計畫草案中屬於鄉村發展區域，產業功能主要為農業發展地區第一類<ref>{{Cite web |url=https://urbandatasrv.tycg.gov.tw/TYSP/index.aspx |title=桃園市國土計畫資訊網 |access-date=2019-04-26 |archive-date=2019-04-25 |archive-url=https://web.archive.org/web/20190425071913/https://urbandatasrv.tycg.gov.tw/TYSP/index.aspx |dead-url=no }}</ref>。

境內居民主要為[[客家裔臺灣人|客家]]族群，客家人比例約佔全區人口的88%左右<ref>{{cite web | url=http://ebooks.lib.ntu.edu.tw/1_file/hakka/78/51272219271.pdf | title=各鄉鎮客家人口統計 | 3= | access-date=2017-10-11 | archive-url=https://web.archive.org/web/20171010210810/http://ebooks.lib.ntu.edu.tw/1_file/hakka/78/51272219271.pdf | archive-date=2017-10-10 | dead-url=yes }}</ref>，2011年[[行政院客家委員會]]公告新屋區為[[臺灣客家文化重點發展區]]。當地主要姓氏有[[徐姓|徐]]、[[黃姓|黃]]、[[葉姓|葉]]、[[姜姓|姜]]、[[羅姓|羅]]、[[陳姓|陳]]等。此外新屋區也是[[范姜姓|范姜]]姓氏的起源地。

== 歷史 ==
=== 地名由來 ===
[[清初]][[乾隆]]年間，范姜一氏來臺拓墾，取得墾照，建立「[[姜勝本墾號|姜勝本]]」墾號後，逐步向內地開拓廣大土地：南以[[社子溪]]為界，東至[[上田心子|營盤腳]]（今楊梅區上田-{里}-），西抵[[石牌嶺]]（今新屋區石牌-{里}-），北達[[下大堀|大堀坑]]（今觀音區大堀-{里}-）。經過百餘年的努力，范姜一族不但使荒野變田園，而且吸引了拓荒者遷入此地。

在范姜先祖胼手胝足，耕墾得法之下，范姜家族短短數年已有田產處處。開墾有成的范姜族人於[[咸豐]]四年（西元1854年）興建祖堂，其後陸續起造不少新屋，當地人引為盛事，以[[臺灣客家語|客語]]稱其為「起新屋」。因此「新屋」便成為當地的地名，沿用至今。鄰近的[[閩南裔臺灣人|閩南人]]，因臺灣話較常使用「厝」字指稱房舍，故稱新屋為'''新厝仔'''（sin-chhù-á）。

「新屋」一名，來自於范姜公廳新建時，其嶄新的建築，使該地得名。五棟范姜老屋群<ref>[http://www.shinwu.gov.tw/core/main/inpage.php?pageId=8 《新屋鄉公所-人文古蹟-范姜老屋群》]{{dead link|date=2018年3月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>中的[[范姜公廳]]，於1985年8月19日經內政部評定為第三級[[臺灣古蹟列表|古蹟]]，是新屋區最珍貴之古宅（註：[[台灣客家語|客語]]「公廳」指祭拜祖先的[[祠堂]]）。區內詳細地名由來可參見《新屋鄉志·拓墾篇》<ref>{{Cite web |url=http://county.naer.edu.tw/co_page/index.php |title=新屋鄉志拓墾篇 |access-date=2016-12-08 |archive-url=https://web.archive.org/web/20161220073327/http://county.naer.edu.tw/co_page/index.php |archive-date=2016-12-20 |dead-url=yes }}</ref><ref>{{Cite web |url=http://guolingarea.blogspot.tw/2010/11/blog-post.html |title=桃園市新屋區地名沿革 |access-date=2016-12-08 |archive-date=2017-08-09 |archive-url=https://web.archive.org/web/20170809040400/http://guolingarea.blogspot.tw/2010/11/blog-post.html |dead-url=no }}</ref>。

=== 沿革 ===
1895年4月17日，清日簽訂〈[[馬關條約]]〉，[[台灣日治|將臺灣、澎湖群島割讓給日本]]；6月28日，臺灣改設3縣1廳，新屋隸屬[[臺北縣 (日治時期)|臺北縣]]新竹支廳竹北二堡。1897年，改為6縣3廳，屬[[新竹縣 (日治時期)|新竹縣]]新埔辦務署{{r|鄉志大事篇|p=687}}。1898年，改為3縣3廳，屬臺北縣新埔辦務署楊梅壢支廳。1899年裁併新埔辦務署，新屋改隸臺北縣桃仔園辦務署楊梅壢支廳。1901年11月9日，全臺設20廳，新屋隸屬[[桃園廳|桃仔園廳]]楊梅壢支廳第19區、第20區{{r|鄉志大事篇|p=688}}。1905年3月29日，桃仔園廳改名桃園廳{{r|鄉志大事篇|p=689}}。1909年10月23日，全臺20廳改設12廳，新屋一部分屬大坡區，一部分屬新屋區{{r|鄉志大事篇|p=690}}。1920年10月1日，廢廳設州，州下設郡、市，郡下設街、-{庄}-，[[新屋庄|新屋-{庄}-]]屬[[新竹州]][[中壢郡]]。新屋-{庄}-轄犁頭洲、九斗、上青埔、北勢、石磊子、新屋、東勢、埔頂、社子、番婆-{坟}-、十五間、大坡、后庄、蚵殼港、笨子港、槺榔、下田心子、崁頭厝、大牛欄、石牌嶺等20個大字{{r|鄉志大事篇|p=692}}。

[[臺灣戰後時期|戰後]]1945年12月27日，改5州3廳為8縣，隸屬[[新竹縣 (1945年－1950年)|新竹縣]]中壢區新屋鄉{{r|鄉志大事篇|p=698}}。1946年10月，新屋鄉公所正式成立{{r|鄉志大事篇|p=699}}。1950年10月25日，調整行政區域，新屋鄉改隸[[桃園縣]]{{r|鄉志大事篇|p=701}}。1959年2月2日，崁頭村因諧音與臺語「砍頭」近似，改名「永安村」{{r|鄉志大事篇|pp=706－707}}。1974年12月1日，大欄村改名「永興村」{{r|鄉志大事篇|p=712}}。1983年8月8日，平均村改名「清華村」{{r|鄉志大事篇|p=715}}。2014年12月25日，因應桃園縣改制為直轄市，新屋鄉改為「新屋區」<ref name="疆域沿革">{{cite web |url=https://www.xinwu.tycg.gov.tw/home.jsp?id=13&parentpath=0,1,8 |title=本區介紹-認識本區-疆域沿革 |publisher=桃園市政府-新屋區公所 |access-date=2023-01-17 |language=zh-tw |archive-date=2023-01-17 |archive-url=https://web.archive.org/web/20230117193451/https://www.xinwu.tycg.gov.tw/home.jsp?id=13&parentpath=0,1,8 |dead-url=no }}</ref>。

== 地理 ==
=== 地形 ===
新屋區位於桃園市西端，西臨[[臺灣海峽]]，東毗[[中壢區]]，北接[[觀音區]]，東南與南鄰[[楊梅區]]及[[臺灣省]][[新竹縣]][[湖口鄉]]、[[新豐鄉 (台灣)|新豐鄉]]。全區東西長約18.5公里，南北寬約9.2公里，土地面積約85平方公里，佔全市土地總面積的6.96%{{r|鄉志地理篇|p=51}}。全區地勢為自東緣交界的楊梅地區向西漸緩傾斜至臺灣海峽的平地，整體地形呈現斜三角形狀，北端窄而南半部寬，海拔高度介於5至100公尺間。新屋區地形由東至西大致可分為三個地形區，一為東側的臺地丘陵區，一為中部的沖積平原區，一為西部的海岸砂丘區{{r|鄉志地理篇|pp=54－55}}。

=== 氣候 ===
新屋區位於[[北回歸線]]以北，氣候屬於潮濕[[副熱帶季風氣候|副熱帶季風]]型，夏季高溫，冬季寒冷潮濕，由於該區西面濱臨海域且境內缺乏山嶺屏障的緣故，故夏季相較於鄰近的楊梅、中壢兩區稍顯溫和涼爽，然有時可能會受到颱風（主要為由東往西移動者）造成過山沉降的效應影響，而出現全臺灣最高溫<ref>{{cite news 根據新屋區戶政事務所及桃園市政府民政局人口統計，2025年底新屋區戶數約2萬戶，人口約5萬人，為桃園市平地地區人口最少的行政區，男女性人數分別約是2.6萬人與2.4萬人，性別比約為111.58%，是桃園市性別比最高的行政區。區內人口最多與最少的里分別是頭洲里與深圳里，2025年底兩里人口分別為6,121人與655人，其中深圳里也是桃園市人口最少的里<ref name="新屋戶政">{{Cite web |url=https://www.xinwu-hro.tycg.gov.tw/home.jsp?id=28&parentpath=0,23,27 |title=各里人口/戶數月統計 |publisher=桃園市新屋區戶政事務所 |accessdate=2021-03-26 |language=zh-tw |archive-url=https://web.archive.org/web/20200702083356/https://www.xinwu-hro.tycg.gov.tw/home.jsp?id=28&parentpath=0,23,27 |archive-date=2020-07-02 |dead-url=no }}</ref><ref name="桃市府民政局">{{Cite web |url=https://cab.tycg.gov.tw/home.jsp?id=10514&parentpath=0,10432,10513 |title=統計資訊-人口統計 |publisher=桃園市政府民政局 |language=zh-tw |archive-url=https://web.archive.org/web/20210124053924/https://cab.tycg.gov.tw/home.jsp?id=10514&parentpath=0,10432,10513 |archive-date=2021-01-24 |dead-url=no }}</ref>。

新屋區的[[人口老化]]與[[少子化]]問題嚴重，由於發展緩慢，且土地主要仍為農業區，年輕人口不斷外流<ref>{{cite news |url=https://www.chinatimes.com/realtimenews/20231205004751-260405?chdtv |title=桃園這區40年沒發展致人口外移？ 市府提都市計畫解方 |author=蔡明亘 |date=2023-12-05 |access-date=2025-01-15 |publisher=中時新聞網 |language=zh-tw }}</ref>。2025年底時，新屋區人口中0至14歲人口佔比約為10.79%，15至64歲人口佔比約為67.74%，65歲以上人口佔比約為21.47%，老化指數約為198.96%，是桃園市青壯年人口佔比最低、人口老化程度最高的行政區，也是桃園市唯一已進入超高齡社會的行政區<ref>{{cite web |url=https://www.ris.gov.tw/app/portal/346 |title=人口統計資料 |author=內政部戶政司 |publisher=中華民國 內政部戶政司 全球資訊網 |access-date=2025-01-15 |language=zh-tw |archive-date=2011-01-20 |archive-url=https://web.archive.org/web/20110120074449/https://www.ris.gov.tw/app/portal/346 |dead-url=no }}</ref>。

=== 區政組織 ===
[[File:Sinwu Township Office front view 20100929.jpg|thumb|2010年9月底的新屋鄉公所（現已改制為新屋區公所）]]
[[新屋區公所]]是[[桃園市政府]]在新屋區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為桃園市政府。[[区长]]由[[桃園市市長|市長]]任命，其任期為無任期保障。在區長及主任秘書之下，設有5課4室等9個內部單位<ref>{{Cite web |url=https://www.xinwu.tycg.gov.tw/home.jsp?id=20&parentpath=0,1,10 |title=本區介紹-本所組織介紹-本所組織介紹 |publisher=桃園市政府新屋區公所 |access-date=2021-09-26 |language=zh-tw |archive-date=2021-06-12 |archive-url=https://web.archive.org/web/20210612083026/https://www.xinwu.tycg.gov.tw/home.jsp?id=20&parentpath=0,1,10 |dead-url=no }}</ref>。新屋區為[[桃園市議會]]第十一選區，在市議會的63席市議員中，新屋區共選出1席區域市議員（不含平地原住民與山地原住民議員）<ref>{{Cite web |url=https://www.tycc.gov.tw/content/intro/intro_main.aspx?wtp=1&wnd=204&town=%e7%ac%ac%e5%8d%81%e4%b8%80%e9%81%b8%e5%8d%80 |title=議員介紹-本屆議員-第十一選區 新屋區 |publisher=桃園市議會 |access-date=2021-09-26 |language=zh-tw |archive-date=2021-09-26 |archive-url=https://web.archive.org/web/20210926044142/https://www.tycc.gov.tw/content/intro/intro_main.aspx?wtp=1&wnd=204&town=%E7%AC%AC%E5%8D%81%E4%B8%80%E9%81%B8%E5%8D%80 |dead-url=no }}</ref>。

=== 行政區 ===
現今新屋區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設新屋-{庄}-屬新竹州中壢郡。新屋-{庄}-轄犁頭洲、九斗、上青埔、北勢、石磊子、新屋、東勢、埔頂、社子、番婆-{坟}-、十五間、大坡、后庄、蚵殼港、笨子港、槺榔、下田心子、崁頭厝、大牛欄、石牌嶺等20個大字{{r|鄉志政事篇|p=220}}。1945年12月27日，改為「新屋鄉」，屬新竹縣中壢區{{r|鄉志政事篇|p=228}}。1950年，調整行政區域並裁撤區署，新屋鄉改隸新成立的桃園縣{{r|鄉志政事篇|p=230}}。2014年12月25日，桃園縣改制為直轄市，新屋鄉改制為市轄區「新屋區」，隸屬桃園市<ref name="疆域沿革"/>。

== 文化 ==
=== 地方語言 ===
新屋的本土語言雖以[[臺灣客家語]]海陸腔為主，但西南角蚵間-{里}-為臺灣西部臺語泉腔的最北端的分布區，此外，新屋地區存在許多[[方言島]]，如[[大牛欄]]地區有漳腔臺語（類似於[[海陸豐話]]，有受[[潮州話]]以及[[海陸客語]]影響），而石磊里西部有[[軍話|水流軍話]]等。<ref>{{cite web|url=http://twblg.dict.edu.tw/holodict_new/mobile/result_detail.jsp?n_no=6182|title=台灣閩南語常用詞辭典 - 海口腔|publisher=教育部|access-date=2013-10-02|archive-url=https://web.archive.org/web/20131004212857/http://twblg.dict.edu.tw/holodict_new/mobile/result_detail.jsp?n_no=6182|archive-date=2013-10-04|dead-url=yes}}</ref><ref>{{cite web|url=http://www.hakka.gov.tw/ct.asp?xItem=27077&ctNode=1880&mp=1869|title=獎助客家研究優良博碩士論文 - 新屋水流軍話與海陸客語雙方言現象研究|author=楊明龍|publisher=客家委員會|date=2005|access-date=2013-10-02|archive-url=https://web.archive.org/web/20150924025201/http://www.hakka.gov.tw/ct.asp?xItem=27077&ctNode=1880&mp=1869|archive-date=2015-09-24|dead-url=yes}}</ref><ref>{{cite web|url=http://www.uijin.idv.tw/doc/%E8%AB%96%E6%96%87%E8%91%97%E4%BD%9C/%E7%A0%94%E8%A8%8E%E6%9C%83%E8%AB%96%E6%96%87/%E7%BC%BA%E5%B0%91%E8%A3%9C%E4%B8%8A/2010.04.23%E5%8F%B0%E7%81%A3%E8%A5%BF%E5%8C%97%E6%B5%B7%E5%B2%B8%E9%96%A9%E5%AE%A2%E4%BA%A4%E7%95%8C%E5%9C%B0%E5%B8%B6%E7%9A%84%E8%AA%9E%E8%A8%80%E5%88%86%E4%BD%88_%E6%B4%AA%E6%83%9F%E4%BB%81.pdf|title=台灣西北海岸的語言分佈與閩客互動|date=2011|author=洪惟仁|access-date=2013-10-02|archive-date=2019-05-02|archive-url=https://web.archive.org/web/20190502051950/http://www.uijin.idv.tw/doc/%E8%AB%96%E6%96%87%E8%91%97%E4%BD%9C/%E7%A0%94%E8%A8%8E%E6%9C%83%E8%AB%96%E6%96%87/%E7%BC%BA%E5%B0%91%E8%A3%9C%E4%B8%8A/2010.04.23%E5%8F%B0%E7%81%A3%E8%A5%BF%E5%8C%97%E6%B5%B7%E5%B2%B8%E9%96%A9%E5%AE%A2%E4%BA%A4%E7%95%8C%E5%9C%B0%E5%B8%B6%E7%9A%84%E8%AA%9E%E8%A8%80%E5%88%86%E4%BD%88_%E6%B4%AA%E6%83%9F%E4%BB%81.pdf|dead-url=yes}}</ref>

=== 石滬文化 ===
2015年，桃園市政府首次舉辦石滬文化節，活動地點在綠色隧道南端點忘憂門廣場，在桃園市長鄭文燦的帶領下奠下第一塊基石，完成第一波重建石滬奠基行動。石滬是先民捕魚的方式，外島的[[澎湖石滬]]出名已久，而在台灣本島最多石滬群的地方就在新屋區，已有300多年的歷史。<ref>{{Cite web |url=http://www.tycg.gov.tw/ch/home.jsp?id=9&parentpath=0,1&mcustomize=multimessage_view.jsp&dataserno=201510270006&aplistdn=ou=news,ou=chinese,ou=ap_root,o=tycg,c=tw&toolsflag=Y |title=2015石滬文化節 鄭市長：保存新屋石滬文化資產，推動社區營造及海洋文化 |access-date=2015-10-29 |archive-date=2020-08-09 |archive-url=https://web.archive.org/web/20200809180456/https://www.tycg.gov.tw/ch/home.jsp?id=9&parentpath=0%2C1&mcustomize=multimessage_view.jsp&dataserno=201510270006&aplistdn=ou%3Dnews%2Cou%3Dchinese%2Cou%3Dap_root%2Co%3Dtycg%2Cc%3Dtw&toolsflag=Y |dead-url=no }}</ref><ref>[http://n.yam.com/ttn/society/20151027/20151027355755.html 2015桃園石滬文化祭 新屋愛鄉協會社造有成]</ref><ref>{{Cite web |url=https://news.ltn.com.tw/news/life/breakingnews/3170734 |title=40年首見！新屋蚵間里石滬湧入千條魚 |access-date=2020-07-14 |archive-date=2021-03-24 |archive-url=https://web.archive.org/web/20210324010109/https://news.ltn.com.tw/news/life/breakingnews/3170734 |dead-url=no }}</ref>

== 污染 ==
*新屋區外環道三民路北側農田，常露天焚燒雜草產生濃煙或是施加惡臭肥料，使鄰近之[[新屋國中]]校園師生健康受到威脅。
*[[社子溪]]常有工廠違法排放廢水，造成溪內及出海口污染<ref>{{Cite web |url=http://www.libertytimes.com.tw/2012/new/may/26/today-north2.htm |title=新屋社子溪染紅 禍首砂石廠揪出 |access-date=2012-10-22 |archive-date=2012-10-03 |archive-url=https://web.archive.org/web/20121003010402/http://www.libertytimes.com.tw/2012/new/may/26/today-north2.htm |dead-url=no }}</ref>。
*部分農田及道路被傾倒廢土，污染水源地或是妨礙交通<ref>[http://www.nownews.com/2011/05/18/11461-2713642.htm 新屋鄉受污染嚴重 邱佳亮質疑：環保局稽查不力！]</ref><ref>{{Cite web |url=http://www.libertytimes.com.tw/2011/new/sep/14/today-north4.htm |title=新屋農地供倒廢土 縣府大掃蕩 |access-date=2012-10-22 |archive-date=2011-09-14 |archive-url=https://web.archive.org/web/20110914093456/http://libertytimes.com.tw/2011/new/sep/14/today-north4.htm |dead-url=no }}</ref>。
