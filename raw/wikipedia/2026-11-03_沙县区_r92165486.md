'''沙县区'''，是[[中华人民共和国]][[福建省]][[三明市]]的[[市辖区]]，位于福建省中部、[[闽江]]南源[[沙溪 (閩江)|沙溪]]下游，區政府駐[[凤岗街道 (沙县)|凤岗街道]]府前中路89號。

== 县名由来 ==
沙县之名源自流经该地的主要溪流——[[沙溪 (閩江)|沙溪]]，东晋[[太元 (东晋)|太元]]四年（公元379年）设置的沙戍、以及后续的沙村县均以沙溪为名；而沙溪之名则来源于其水域内多有[[沙洲]]。<ref>{{Cite web |title=沙县县名由来 _ 历史沿革 _ 沙县区人民政府门户网站 |url=http://www.fjsx.gov.cn/zjsx/lsyg/200708/t20070814_480053.htm |work=www.fjsx.gov.cn |dead-url=no |archive-url=https://web.archive.org/web/20221006073543/http://www.fjsx.gov.cn/zjsx/lsyg/200708/t20070814_480053.htm |archive-date=2022-10-06 |access-date=2022-05-25}}</ref>

==历史沿革==
===古代时期===
沙县地区古属[[九州 (中国)|九州]]中的[[扬州 (古代)|扬州]]，在[[周朝]]时为[[七闽]]地，[[战国时期]]越人在此地建立[[闽越国]]。

[[秦朝]]时此地为[[閩中郡]]辖区，[[汉朝]]建立后复归闽越国。[[冶县]]（行政中心在今[[福州]]）建立后，沙县地区属之，[[建安 (东汉)|建安]]元年（公元196年）属[[南平縣]]。

[[三国]]时期，[[孫吳]]政权设立[[晋安郡]]，南平县及沙县地区属之。

东晋太元四年，南平县改称[[延平县 (东晋)|延平县]]，并在南乡沙源地设置沙戌，其后于义熙年间升格为沙村县。

[[南北朝|南朝]]时期，沙村县建制得以延续，[[隋朝]][[隋滅陳之戰|统一中国]]后，沙村县改属[[闽州|丰州]]，后废除该县，辖境属[[建安郡]]。<ref name=":0">{{Cite book |title=沙县志 |last=沙县地方志编纂委员会 |publisher=中国科学技术出版社 |location=北京 |year=1992年4月 |isbn=7-110-02307-9 |pages=43-44}}</ref><ref name="fjsx22">{{cite web |title=沙县境域变迁 |url=http://www.fjsx.gov.cn/zjsx/sxgk/200710/t20071002_480320.htm |website=沙县人民政府 |date=2007-10-02 |author=张卿子 |dead-url=no |archive-url=https://web.archive.org/web/20200901002608/http://www.fjsx.gov.cn/zjsx/sxgk/200710/t20071002_480320.htm |archive-date=2020-09-01 |access-date=2020-02-04}}</ref>

唐永徽六年（665年），重新设立沙县。唐开元十三年（725年），析出县西黄连峒一带设立[[宁化县]]。<ref name="fjsx2">{{cite web|author=张卿子|url=http://www.fjsx.gov.cn/zjsx/sxgk/200710/t20071002_480320.htm|title=沙县境域变迁|website=沙县人民政府|date=2007-10-02|access-date=2020-02-04|archive-date=2020-09-01|archive-url=https://web.archive.org/web/20200901002608/http://www.fjsx.gov.cn/zjsx/sxgk/200710/t20071002_480320.htm|dead-url=no}}</ref><ref name="fjsx"></ref>

大历十二年（777年），沙县隶属汀州。五代后汉-{乾佑}-元年（948年），沙县隶属剑州（宋太平兴国四年（979年）剑州改名为南剑州，元朝至元十五年（1278年）南剑州改为南剑路，大德六年（1302年）南剑路改为延平路）。至正末年（1360年），[[陈友定]]据守延平路，沙县为陈友定辖地。明洪武元年（1368年)，明朝平陈友定，延平路改为延平府，沙县隶属延平府。<ref name=fjsx>{{cite web|url=http://www.fjsx.gov.cn/zjsx/lsyg/200710/t20071002_480281.htm|title=县级建置|website=沙县人民政府|date=2007-10-02|access-date=2020-02-04|archive-date=2020-12-24|archive-url=https://web.archive.org/web/20201224212217/http://www.fjsx.gov.cn/zjsx/lsyg/200710/t20071002_480281.htm|dead-url=no}}</ref>

明朝镇压沙县[[邓茂七]][[明朝浙閩民變|起事]]后，明景泰三年（1452年），福建都督范雄、刑部右侍郎[[薛希琏]]、巡按监察御史[[陈员韬]]以“沙县新岭以南地区险远，难以控制”为由，析沙县二十四都部分及二十五至三十二都设立永安县。明成化六年（1470年），将沙县十九都部分划归新设的明溪县。<ref name=fjsx2></ref>

===民国时期===
[[中華民國大陸時期|中华民国]]成立初期，由于[[废府州厅改县|废府]]政策，延平府撤销，沙县隶属于[[建安道]]。[[国民革命军]][[國民革命軍北伐|北伐]]后，废除道制，沙县直属于[[福建省政府]]。1922年—1927年，军阀[[郭锦棠]]、[[郭凤鸣]]兄弟割据沙县一带。1933年底[[闽变]]爆发，沙县在新成立的[[中华共和国]]中属于[[延建省]]，1934年国军消灭中华共和国政权后，沙县被[[中国共产党]]率领的[[中国工农红军]][[中国工农红军东方军|东方军]]攻克并短暂成立[[中华苏维埃共和国]]沙县革命委员会，2月红军撤出沙县，沙县重归[[国民政府]]管辖。<ref name=":02">{{Cite book |title=沙县志 |last=沙县地方志编纂委员会 |publisher=中国科学技术出版社 |location=北京 |year=1992年4月 |isbn=7-110-02307-9 |pages=43-44}}</ref>

1933年12月14日，[[中华共和国]]人民政府将沙县划归[[延建省]]<ref group="註">延建省政府成立前，沙县政务由[[闽海省]]省府管理</ref>。1934年1月，中华共和国被[[南京国民政府]]消灭后，<ref name="一九三三年福建事变若干史事徵考">郑澄桂，一九三三年福建事变若干史事徵考，《档案与史学》，1998年第6期</ref><ref name="《福建省历史地图集》">福建省地方志编纂委员会，《福建省历史地图集》，福建省地图出版社，2004年</ref>[[中国工农红军]]攻占沙县，成立[[中华苏维埃共和国]]沙县革命委员会。2月底，中国工农红军撤离沙县。撤离后，沙县为中国国民党政权统治区。1934年末，福建省设立10个行政督察区，沙县隶属第三行政督察区。1935年年，福建省将10个行政督察区改为7个行政督察区，沙县隶属第二行政督察区。<ref name=fjsx></ref>

民国28年（1939年），析沙县三元、历东、历西等地设立[[三元特种区]]。6月，三元特种区改为[[三元县]]。<ref name=fjsx2></ref>

===中华人民共和国时期===
1949年6月16日，沙县从国民党政权转到共产党政权，成立沙县人民民主政府。1950年2月，沙县隶属[[南平专区]]。1970年7月1日，沙县隶属[[三明地区]]。1983年，撤销三明地区，设立[[三明市]]，沙县隶属三明市。<ref name=fjsx></ref>

1983年7月，洋溪公社划归三明市[[梅列区]]管辖。1984年10月，夏茂公社、青州公社改为夏茂镇、青州镇；原虬江公社位于城区的7个生产大队并入城关镇，城关镇更名为凤岗镇。镇头公社改为琅口乡，南坑仔公社改为[[南霞乡]]。1993年，高桥乡、富口乡、高砂乡、琅口乡改为[[高桥镇 (三明市)|高桥镇]]、[[富口镇]]、[[高砂镇]]、[[琅口镇]]。1999年，西霞乡更名际口乡。<ref>{{cite web|url=http://www.fjsx.gov.cn/zjsx/lsyg/200710/t20071002_480319.htm|title=80-90年代的境内区划|website=沙县人民政府|date=2007-10-03|access-date=2020-02-04|archive-date=2021-10-03|archive-url=https://web.archive.org/web/20211003121510/http://www.fjsx.gov.cn/zjsx/lsyg/200710/t20071002_480319.htm|dead-url=no}}</ref>

2000年7月，大洛乡改为[[大洛镇]]。12月，撤销际口乡，其区域并入凤岗镇，琅口镇古县村划归凤岗镇管辖。2002年9月30日，撤消梨树乡，原梨树乡梨树村、月邦村、坡后村、中堡村并入夏茂镇；原梨树乡池科村、新桥村、泉水峡村并入高桥镇。2003年9月，撤销凤岗镇、虬江乡和琅口镇，按沙溪河水北和水南地域设立[[凤岗街道 (三明市)|凤岗街道]]、[[虬江街道]]。<ref>{{cite web|url=http://www.fjsx.gov.cn/zjsx/lsyg/201210/t20121017_494227.htm|title=2000年以来的行政区划|website=沙县人民政府|date=2017-02-24|access-date=2020-02-04|archive-date=2021-10-03|archive-url=https://web.archive.org/web/20211003120538/http://www.fjsx.gov.cn/zjsx/lsyg/201210/t20121017_494227.htm|dead-url=no}}</ref>

2021年2月，福建省人民政府经报国务院同意，撤销沙县，设立三明市沙县区。<ref>{{Cite web |url=https://news.hangzhou.com.cn/gnxw/content/2021-02/03/content_7905244.html |title=福建沙县撤县设区 |access-date=2021-02-03 |archive-date=2021-02-03 |archive-url=https://web.archive.org/web/20210203045205/https://news.hangzhou.com.cn/gnxw/content/2021-02/03/content_7905244.html |dead-url=no }}</ref>

== 人口 ==

根据(福建省)三明市[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]查公报显示：沙县常住人口为250503人，男性人口占比51.24%，女性人口占比48.76%，年龄结构中0-14岁占比21.67%，15-59岁占比59.53%，60岁以上占比18.8%，65岁以上占比13.45%。<ref>{{Cite web|title=中國: 福建省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/fujian/admin/|access-date=2023-08-14|website=www.citypopulation.de|archive-date=2021-02-26|archive-url=https://web.archive.org/web/20210226125808/https://www.citypopulation.de/zh/china/fujian/admin/|dead-url=no}}</ref>
2022年初，沙县区常住人口数为25.02万人，其中城镇人口17.62万人。户籍人口27.0642万人，其中男性13.9062万人。

==知名产业==
{{main|沙县小吃}}
