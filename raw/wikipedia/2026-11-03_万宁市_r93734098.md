'''万宁市'''是[[中国]][[海南省]]下辖的一個[[縣級市]]。位于[[海南岛]]东南部，总面积为4443.6平方公里，其中陆地面积1883.5平方公里。全市总人口为545597。<ref>2010年[[中华人民共和国第六次全国人口普查]]</ref>市人民政府驻[[万城镇 (万宁市)|万城镇]]，南距[[三亚市]]112公里，北离[[海口市]]139公里，处于[[海南环线高速公路]]东段中部。

== 歷史沿革 ==
* 万宁市在[[汉代]]属[[珠崖郡]][[紫贝县]]地。[[唐代]][[貞觀]]五年（公元631年），以平昌县拆置“万安县”，隶属[[琼州]]；
* [[龙朔]]二年（662年）增设万安州；
* [[天宝 (唐朝)|天宝]]元年（742年）改州为郡；
* [[至德 (唐朝)|至德]]二年（757年）改万安为“万全郡”。
* [[北宋]][[熙宁]]六、七年间（1074—1075），改万安州为万安军，移军治于博辽。
* [[大觀 (年號)|大观]]年间（1107—1110）。军治移到后朗村水口今（[[万城镇 (万宁市)|万城镇]]），废军复为州。
* [[南宋]][[紹興 (南宋)|绍兴]]七年（1137年），始设“万宁县”。
* 绍兴十三年（1143年）复置[[万安军]]。
* [[明代]][[洪武]]三年（1370年）改称万州。
* 清[[光绪]]三十一年（1905）改为万县。
* 民国三年（1914年）复改为[[万宁县]]。
* 1926年3月，[[中国共产党]]万宁支部成立。
* 1928年1月29日，万宁一万余群众进行总暴动，配台[[琼崖工农革命军]]，进攻县城，建立起县，区、乡[[苏维埃]]政权。
* 1939年初，当时担任万宁县国民政府县长的[[梁秉枢]]，积极和共产党团结合作，共同抗日。
* 1939年2月10日，日军进犯[[海口]]，万宁县城沦陷。
* 1939至1945年下半年，日军占据万宁。
* 1950年4月27日，万宁解放，共产党取得了在万宁的政权。
* 1958年12月，[[琼东]]、[[乐会]]、万宁三县合并。取名琼海县，撤销万宁县。
* 1959年11月，[[琼海]]县划出万宁县。
* 1988年4月，[[海南省|海南]]建省，万宁属海南省辖。<ref>{{Cite web |url=http://wanning.hainan.gov.cn/wngov/wngk/200910/t20091008_9797.html |title=万宁市政府：历史文化 |accessdate=2013-05-30 |archive-date=2013-06-28 |archive-url=https://archive.today/20130628085619/http://wanning.hainan.gov.cn/wngov/wngk/200910/t20091008_9797.html |dead-url=no }}</ref>1996年撤销万宁县，设立万宁市。<ref> 《中华人民共和国国务院公报》 1996年25期 </ref>

== 地理 ==
万宁市位于[[海南岛]]东南部沿海，东濒[[南海]]，西毗[[琼中黎族苗族自治县]]，南邻[[陵水黎族自治县]]，北与[[琼海市]]接壤。市域总面积为4443.6平方公里，其中陆地面积1883.5平方公里，海域面积2550平方公里。在土地面积中，山地约占一半，丘陵和平原各占四分之一。地势自西向东倾斜.呈梯阶状平缓下降。万宁市各种地形兼备.地貌类型多样.西北和
南部届山地和丘陵地形.[[牛上岭]]为万宁市最高峰，海拔1288米。万宁市属[[热带季风气候]]，气候温和、温差小、积温高。年平均气温25.1℃，最冷月平均气温19.6℃，最热月平均28.9℃；年平均降雨量2000-2400毫米左右；年日照时数平均在1900小时以上。

== 经济 ==
2020上半年，万宁市地区生产总值115.2亿元，同比2019年增长4.0%，地方一般公共预算收入7.91亿元。地方一般公共财政预算支出25.56亿元。社会消费品零售总额43.68亿元。旅游接待过夜人数267.8万人次，旅游总收入28.13亿元。城镇常住居民人均可支配收入16485元。农村常住居民人均可支配收入8902元。<ref>{{Cite web |url=http://wanning.hainan.gov.cn/wanning/zjwn/wngk/200910/t20091008_1699612.html |title=万宁概况 |author=万宁政府网 |date=2020-02-01 |publisher= |language= |accessdate= |quote= |archive-date=2021-12-28 |archive-url=https://web.archive.org/web/20211228225135/http://wanning.hainan.gov.cn/wanning/zjwn/wngk/200910/t20091008_1699612.html |dead-url=no }}</ref>

== 人口 ==
根据第七次人口普查数据，截至2020年11月1日零时，万宁常住人口为545992人<ref>{{Cite web|title=中國: 海南省 (地级，行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/hainan/admin/|access-date=2023-10-09|website=www.citypopulation.de|archive-date=2024-11-30|archive-url=https://web.archive.org/web/20241130124721/https://www.citypopulation.de/zh/china/hainan/admin/|url-status=live}}</ref>。
