'''信宜市'''（[[邮政式拼音]]：{{lang|la|Sunyi}}），别称“'''玉都'''”。为[[中华人民共和国]][[广东省]]辖[[县级市]]，现由[[茂名市]]代管。位于广东省西南部，东接[[阳春市]]，南接[[高州市]]，西与[[广西壮族自治区|广西]][[北流市]]、[[容县]]毗邻，北与[[罗定市]]、[[广西壮族自治区|广西]][[岑溪市]]接壤，盛产[[玉石]]。市人民政府駐[[东镇街道 (信宜市)|东镇街道]]人民路39号。

信宜市是广东省著名侨乡，先后获得全国生态保护与建设示范区、全国重点生态功能区、中国南玉之都、中国长寿之乡、全国义务教育发展基本均衡县、广东省教育强市等称号。

== 历史 ==
[[File:Guangdong Sheng Bowuguan 2012.11.18 11-05-04.jpg|缩略图|左|信宜出土的西周青銅[[盉]]]]
古代属[[百越]]地。[[秦代]]属[[桂林郡]]，[[汉代]]属[[苍梧郡]]，[[晋代]]属[[晋康郡 (东晋)|晋康郡]]。[[南朝梁]]廢梁德郡，保留梁德县。[[隋代]]更名为怀德县，屬瀧州。[[唐]]初析置出信义、潭峨、特亮县、扶莱五县。唐乾封二年（667年），[[扶莱县]]划归禺州。[[宋太祖]]年间，怀德、潭峨、特亮三县并入信义县，以该地南有信山，北有招义山而得名。[[宋太宗]]即位后，为避“[[赵光义|义]]”之讳，于[[太平兴国]]五年（公元976年）将信义更名为信宜。1995年9月撤县设[[县级市]]。<ref name=re>{{Cite web|url=http://www.xinyi.gov.cn/Item/660.aspx|title=行政区域-信宜市人民政府|accessdate=2018-02-01|work=www.xinyi.gov.cn|deadurl=yes|archiveurl=https://web.archive.org/web/20161113081839/http://xinyi.gov.cn/Item/660.aspx|archivedate=2016-11-13}}</ref>

== 人口 ==
2021年末，信宜市户籍总人口151.75万人。

根據2003年刊行的《信宜市志（1979—2000）》的資料，祖籍信宜市的華僑華人有50萬之衆，另外祖籍信宜市的港澳臺人士約有10萬人。

== 地理 ==
信宜市为广东省山地市之一，有“八山一水一分田”一说，地貌以山地地貌为主，山地面积合计1944.82平方公里，占全市总面积的63.1%。地势呈东高西低走向，海拔最低50米，最高为粤西第一高峰[[大田顶]]的1704米。以[[贵子镇]]-[[大成镇 (信宜市)|大成镇]]连线，把市境分成东西两部分，东部以海拔800米以上的中等山峰为主。西部以海拔800米以下的低山[[丘陵]]为主。平原主要分布于[[鉴江]]流域的镇隆、水口、东镇、池洞、北界等镇。境内水资源丰富，是[[鉴江]]、[[黄华江]]、[[罗定江 (河流)|罗定江]]、[[北流江]]的发源地。

信宜市地处低纬度的山区市，属[[亚热带季风气候]]区，冬半年偏北气流为主，夏半年偏东南气流为主。气候随海拔高度不同而有差异。西南部海拔100米以下地区属北热带气候，中部、北部、西北部和东部海拔200-500 米地区属南亚热带气候，中部、北部、西北部和东部海拔500-700米及其以上的中低山地区属中亚热带气候。根据信宜年鉴统计，信宜市全年平均气温 22.6℃左右，月平均气温最高28℃左右（7月），月平均最低气温15℃左右（1月），降雨主要靠冷风低槽和台风雨，年降水量在1800毫米以上，汛期明显，8-10月是[[热带气旋]]主要影响期。水库主要有[[尚文水库]]、[[高城水库]]、[[扶曹水库]]等。

== 经济 ==
信宜市的农业在整个产业结构中占比较大，工业基础相对薄弱，近年第三产业的经济贡献也逐渐增加。生态环保、绿色矿业、装备制造、食品药品、旅游康养为信宜官方提出的五大主导产业<ref>{{Cite web|title=茂名日报 第2021-02-03期 A2版:建设宜居宜业宜游的现代化美丽信宜|url=http://paper.mm111.net/shtml/mmrb/20210203/950370.shtml|access-date=2021-08-15|work=paper.mm111.net|archive-date=2021-08-15|archive-url=https://web.archive.org/web/20210815093109/http://paper.mm111.net/shtml/mmrb/20210203/950370.shtml|dead-url=no}}</ref>。

=== 第一产业 ===
信宜是山区农业市，种植业主要有以稻谷、早粮为主的粮食作物种植业和以水果、大豆、果蔗、花生、木薯蔬菜等经济作物种植业两种；畜牧业以养猪业和养鸡业为主；渔业中生产养殖业发展态势良好；其中最为著名的农产品有[[怀乡鸡]]、[[三华李]]、凼仔鱼、山楂以及[[肉桂]]、[[益智仁|益智]]、[[八角]]、[[沉香木|沉香]]等南药。

=== 第二产业 ===
目前已经形成了以矿产业、电子电器和现代装备制造业、玉器加工业、竹器编制业、毛纺皮具制衣业、石化产品后加工和林产化工业、小水电和风电、制药业、农副产品加工业等为主的产业格局。其中，玉器产业、竹器编织业是信宜的传统产业。

信宜自[[1970年代]]开始从事温控产品生产，是中国最大的温控产品生产基地，产销量占全国市场的90％以上份额<ref>{{Cite web|title=茂名日报 第2017-05-08期 A3版:全国九成电饭煲有颗信宜“芯”|url=http://paper.mm111.net/shtml/mmrb/20170508/616537.shtml|access-date=2021-08-15|work=paper.mm111.net|archive-date=2021-08-15|archive-url=https://web.archive.org/web/20210815083321/http://paper.mm111.net/shtml/mmrb/20170508/616537.shtml|dead-url=no}}</ref>。

=== 第三产业 ===
目前信宜市形成了以传统服务业、旅游业、房地产业为主导的第三产业结构体系。信宜旅游资源丰富，是国家级生态保护与建设示范区，知名旅游景点有天马山、西江温泉、镇隆古城、莲花湖庄园等。

== 风景名胜 ==
{{main article|信宜市各级文物保护单位列表}}信宜市近年来重视发展旅游业。自2021年以来已建成窦州里文化创意街、山水双合、马安竹海、虎跳峡风景旅游区等景点。预计活化西江温泉旅游区、天马山自然风景区、[[窦州古城]]等传统景区。此外，开设[[怀乡起义指挥部旧址|怀乡起义纪念馆]]、[[林砺儒]]文化史馆等文化型旅游景点。

== 方言 ==
信宜方言指的是信宜地区使用的方言，包括[[信宜白话]]和信宜𠊎话。信宜白话，属于汉藏语系下的汉语族[[粤语]]支高阳片；信宜𠊎话，属于汉藏语系汉语族[[客语]]支，之前属于不分片客语，后来经比较可算粤台片[[𠊎話]]小片。

== 教育 ==
{{Update|章节|time=2026-07-10|reason=数据过旧+需要来源（较新的）}}信宜市实行“六三三学制”，包括九年义务教育及三年高级中学（或中专）教育。亦与茂名市其余区（县级市）学位报名方式存在不同。

信宜市直九年义务教育报名采用统一填报方式，分“房户一致”（派位+保障学区）“房户不一致”和“无房无户”（派位）进行学位分配。信宜市全境高级中学分数报名采用批次志愿填报，分为“提前批次”（华南师范大学附属砺儒高级中学科创班、砺儒数理类特色班与广东信宜中学科创班、凤凰数理类特色班）、“第一批次”（华南师范大学附属砺儒高级中学、广东信宜中学）；“第二批次”均衡分配学校抽签（信宜市实验高级中学、信宜市第一中学）、“第三批次”均匀分配学校抽签（信宜市实验高级中学、信宜市第一中学、信宜市第二中学、信宜市第三中学）、“第四批次”学校+专业填报（信宜市职业技术中学）及“‘3+4’中本贯通班”（信宜市职业技术中学+[[韩山师范学院]]烹饪专业）。[[File:Education Town.jpg|缩略图|信宜市教育城初级中学]]
信宜市目前的教育以中小学教育为主，现有中学53所，小学357所。2002年5月，开始在市区东南郊兴建包括高中、初中、小学及幼儿园的信宜教育城。信宜教育城于2003年秋季大部分建成并开始招生。初中部从原来的[[信宜中学]]分出为信宜市教育城初级中学，[[信宜中学]]只保留高中部。

==矿产== 
信宜位于[[粤西]]至桂东成矿带的西南段，矿产资源丰富，已发现矿产有[[玉石]]、[[滑石]]、[[高岭石]]、[[萤石]]、[[石英]]、[[金]]、[[银]]、[[铜]]、[[铁]]、[[锡]]、[[锌]]、[[钼]]等30多种。其中[[花岗岩]]总储量达数十亿立方米，居全省首位，[[大成镇]]的饰面用花岗岩为本市最主要的优势矿产之一。银岩锡矿是全国第三大锡矿，东坑金矿为广东省第二大金矿，玉矿是全国唯一的“南方碧玉”，以它雕制的工艺美术品誉满中外。<ref>{{Cite web|url=http://www.xinyi.gov.cn/Item/657.aspx|title=物产资源-信宜市人民政府|accessdate=2018-02-01|work=www.xinyi.gov.cn|deadurl=yes|archiveurl=https://web.archive.org/web/20161113080555/http://xinyi.gov.cn/Item/657.aspx|archivedate=2016-11-13}}</ref>2013年，信宜市被中国工艺美术协会授予“中国南玉之都”称号。
