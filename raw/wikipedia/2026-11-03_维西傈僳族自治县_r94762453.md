'''维西傈僳族自治县'''（[[傈僳语]]：{{lang|lis|ꓪꓰꓽ-ꓫꓲꓸ ꓡꓲ-ꓢꓴ ꓫꓵꓽ ꓝꓲꓹ ꓚꓵꓹ ꓫꓬꓹ}}；{{Lang-bo|z=འབའ་ལུང་ལི་སུའུ་རིགས་རང་སྐྱོང་རྫོང།|p=Ba<!--a-->lung Lisu<!--u-->rig Ranggyong Zong|w='ba'-lung li-su'u-rigs rang-skyong rdzong}}）是[[中华人民共和国]][[云南省]][[迪庆藏族自治州]]下属的一个[[自治县]]。全县面积4477平方千米，2020年总人口14.64万人。县人民政府驻保和镇。该县在[[纳西语]]中被称作“你那”。该县也是中国唯一的[[傈僳族]]自治县，与[[怒江傈僳族自治州]]（中国唯一的[[傈僳族]][[自治州]]）相邻。

== 词源 ==
“维西”之名旧作“为习”（《[[木氏宦谱]]》）、“危习”（《[[滇云历年传]]》），为少数民族语言地名，原是今县城附近一村镇名，在滇、川划界文书中译写作“为西”，代表这一片地域。清初设维西厅时，首见“维西”之名，因地理位置及历史背景，此译法可能有“维系西藏”的含义<ref name="县志"/>{{rp|55}}。

==历史==
按清初[[余庆远]]《[[维西见闻记]]》，维西历史上为“[[吐蕃]]东封地”<ref>{{cite book |author=余庆远 |author2=李汝春 校注 |title=维西史志资料 2·维西见闻纪（附：维西夷人图） |publisher=维西傈僳族自治县志编委会办公室 |year=1994 }}</ref>{{rp|12}}。唐初，吐蕃势力东渐，在今维西[[塔城镇|塔城]]置铁桥节度使（神川都督府）<ref name="潘发生">{{cite journal |author=潘发生 |title=吐蕃神川都督府 |journal=西藏研究 |year=1994 |issue=3 |pages=69-75 |id={{CNKI|xzyj199403010|CJFD}} }}</ref>，下辖东、西二城，西城在今维西其宗村<ref name="县志">{{cite book |author1=李汝春 主编 |author2=维西傈僳族自治县志编纂委员会 编 |title=维西傈僳族自治县志 |location=昆明 |publisher=云南民族出版社 |year=1999  |isbn=7-5367-1915-9 }}</ref>{{rp|51}}。[[南诏]][[异牟寻]]内附唐朝后，向吐蕃发动进攻，于贞元十年（794年）占领[[神川铁桥]]，吐蕃势力退至金沙江以北<ref name="冯智">{{cite journal |author=冯智 |title=吐蕃南诏神川铁桥 |journal=西藏研究 |year=1992 |issue=2 |pages=26-34 |id={{CNKI|xzyj199202004|CJFD}} }}</ref>。唐乾符年间（874年-879年），南诏并铁桥节度、宁北节度为[[剑川节度]]<ref name="县志"/>{{rp|51}}。[[大理国]]时，维西地称“罗裒间”，属[[成纪镇]]，由么些（纳西族）大酋统辖<ref name="县志"/>{{rp|51}}。

元至元十四年（1277年），在罗裒间置[[临西县 (云南)|临西县]]，属[[丽江路]][[巨津州]]。明洪武年间，巨津土知州阿戟向临西县扩张，取代临西土知县而“兼管县事”。县境土酋在丽江土司支持下与阿戟势力对抗，永乐四年（1406年），么些土酋阿奴弟进京朝贡，乞设[[刺和庄长官司]]，获得允许，直隶于[[云南都司]]，政权存续较短。正统二年（1437年），康藏地方政权武力占领临西（时称“你那”），丽江土司在万历年间夺回，旋废州县，由土府直接管理，委派禾氏为“你那大管军”。<ref name="县志"/>{{rp|52}}

清康熙六年（1667年），在[[康区]]南部[[格鲁派]]势力的支持下，以[[罕都]]为代表的[[和硕特部]]蒙藏联合势力占领[[中甸]]，随后[[吴三桂]]将[[金沙江]]外本属于丽江土司的多地割送罕都。康熙十一年（1672年），吴三桂又将金沙江以内的喇普也割让给罕都，包括今维西大部，双方以[[塔城镇|塔城关]]为界<ref name="罗布">{{cite journal |author=罗布 |title=吴三桂与五世达赖喇嘛——清初西南边疆多元关系之一角 |journal=思想战线 |year=2017 |volume=43 |issue=5 |pages=31-39 |id={{CNKI|sxzx201705004|CJFD}} }}</ref>。康熙二十年（1681年）[[三藩之乱]]平息后，吴三桂割送地区划归[[四川]]，由[[巴塘土司]]羁縻<ref name="县志"/>{{rp|52}}。雍正四年（1726年），清廷勘定川滇界，维西地划归云南[[鹤庆府]]<ref name="西绕云贞">{{cite journal |author=西绕云贞 |title=天下一统的重要决策——迪庆藏区归滇研究 |journal=西藏研究 |year=2003 |issue=3 |pages=30-37 |id={{CNKI|xzyj200303004|CJFD}} }}</ref>。雍正五年（1727）四月，置'''维西厅'''，移鹤庆府通判驻防，次年选定宝华山麓建筑土城一座，是为治所，即今维西县城。乾隆二十一年（1756年），改隶[[丽江府]]。乾隆二十二年（1757年），改维西通判为维西抚夷通判。<ref name="县志"/>{{rp|52}}

民国2年（1913年），维西厅拆分为维西县和[[阿墩行政委员]]（今[[德钦县]]）。民国3年（1914年），原维西厅“怒俅地方”拆分为[[菖蒲桶行政委员]]（今[[贡山独龙族怒族自治县]]）、[[上帕行政委员]]（今[[福贡县]]）。维西县先后隶属云南省[[滇西道]]、[[云南殖边督办公署|第一殖边督办公署]]、第七行政督察区、第十三行政督察区，第十三行政督察区曾于1948年短暂驻扎于维西。1949年5月12日，中共维西党组织发起武装暴动，推翻县政府，建立临时人民政权“维西县临时参议会”。10月1日中华人民共和国成立后改为维西县人民政府，隶属滇西北人民专员公署，1950年改属[[丽江专区]]。1957年9月13日，维西与中甸、德钦共同建立迪庆藏族自治州。<ref name="县志" />{{rp|52-53}}1985年6月11日，国务院批准撤销维西县建立维西傈僳族自治县，同年10月13日正式成立<ref>{{Cite wikisource |title=国务院关于同意云南省设立双江等八个自治县给云南省人民政府的批复|date=1985-06-11|author=中华人民共和国国务院}}</ref><ref name="政区沿革">{{Cite book |title=云南省政区沿革（1949-1985）|author=云南省民政厅|publisher=内部发行|year=1988}}</ref>{{Rp|187}}。2024年9月，所辖[[叶枝镇]]、[[巴迪乡]]划归[[德钦县]]管辖。<ref>{{cite web |author1=云南省民政厅 |title=国务院批复同意我省调整 德钦县与维西傈僳族自治县行政区划 |url=https://www.yn.gov.cn/zwgk/gsgg/202409/t20240927_305017.html |website=云南省人民政府 |date=2024-09-27 |accessdate=2024-10-02 |archive-date=2024-10-07 |archive-url=https://web.archive.org/web/20241007152341/https://www.yn.gov.cn/zwgk/gsgg/202409/t20240927_305017.html |dead-url=no }}</ref>

== 经济 ==
2022年，维西县[[国内生产总值|生产总值]]达71.49亿元，按可比价格计算，比上年增长1.4%。其中[[第一产业]]增加值9.64亿元，增长4.8%；[[第二产业]]增加值21.56亿元，下降1.8%；[[第三产业]]增加值40.29亿元，增长2.3%。三次产业结构为13.5∶30.1∶56.4。人均生产总值48,387元。城乡常住居民人均可支配收入分别为39,945元、12,265元。职工年平均工资159,781元。地方一般公共预算收入2.18亿元，人均1,477元。地方一般公共预算支出35.72亿元，人均24,177元。<ref>{{Cite book|title=云南统计年鉴 2023|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

== 人口 ==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，维西傈僳族自治县总人口（常住人口）共有146,363人，城镇人口36,437人（占24.89%），乡村人口109,926人（占75.11%）。共有男性76,932人、女性69,431人，[[人類性別比|性别比]]为110.80。0—14岁人口共28,171人（占19.25%），15—59岁人口共98,850人（占67.54%），60岁及以上人口共19,342人（占13.22%），其中65岁及以上人口共13,891人（占9.49%）。大学专科学历及以上人口有11,611人，15岁以上的文盲有21,361人，占15岁以上人口的18.07%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>
