'''大田县'''，别称“'''岩城'''”，是[[福建省]][[三明市]]下辖的一个[[县]]。位于福建省中部[[戴云山脉]]西侧，面积2294平方公里，有“九山半水半分田”之称<ref>{{cite web |title=大田概况 _ 大田县人民政府门户网站 |url=http://www.datian.gov.cn/dtgk/ |website=大田县人民政府门户网站 |accessdate=2023-12-30 |archive-date=2023-12-30 |archive-url=https://web.archive.org/web/20231230091205/http://www.datian.gov.cn/dtgk/ |dead-url=no }}</ref>。

==历史==
明嘉靖十四年（1535年），划出[[尤溪县]]14个都、永安县1个都、漳平县1个里10个社和德化县1个团置县，属福建道[[延平府]]。清雍正十二年（1734年）改隶[[永春直隶州]]。中華民國建立後隸屬[[南路道 (福建)|南路道]]，1927年廢道直屬福建省，1934年7月隸屬福建省[[仙游縣|第四行政督察區]]，1935年10月改屬[[龍岩市|第六行政督察區]]，1946年1月改屬[[永安市|第九行政督察區]]，1947年4月第九区改为第六区。中华人民共和国建立后1950年9月属[[永安专区]]，1956年6月改属[[晋江专区]]，1963年3月属三明专区，1983年7月三明专区改为三明市。<ref name=a1>{{cite book |editor=中华人民共和国民政部 |title=中华人民共和国政区大典·福建省卷 |date=2016-08 |publisher=中国社会出版社 |location=北京 |isbn=978-7-5087-5392-8 |page=615}}</ref><ref>{{cite book |editor=大田县地方志编纂委员会 |title=大田县志 |date=1996-11 |publisher=中华书局 |isbn=7-101-01536-0 |page=卷一第一章第一节 |url=http://data.fjdsfzw.org.cn/2016-09-21/content_404.html |access-date=2023-06-16 |archive-date=2021-10-22 |archive-url=https://web.archive.org/web/20211022131016/http://data.fjdsfzw.org.cn/2016-09-21/content_404.html |dead-url=no }}</ref>

==地理==
大田县东邻[[德化县]]，南连[[永春县]]，西南毗[[漳平县]]，西界[[永安市]]，西北交[[三元区]]，北接[[尤溪县]]，面积2294平方千米，地处[[戴云山]]西坡，地势由西南向东北倾斜，最高峰大仙峰海拔1553.4米，多年平均气温19.1°C，无霜期年均289天，年均日照时数1513小时，年均降水量1550.2毫米，年均降雨日数162天，降雨集中在3到9月，境内河流分属闽江、九龙江、晋江流域<ref name=a1/>，河流多年平均径流量19.79亿立方米，地下水总量3.54亿立方米<ref>{{cite web |author1=大田县政府办 |title=自然地理 |url=http://www.datian.gov.cn/dtgk/zrdl/201712/t20171218_1058184.htm |website=大田县人民政府 |date=2022-02-15 |accessdate=2023-06-16 |archive-date=2018-07-03 |archive-url=https://web.archive.org/web/20180703082900/http://www.datian.gov.cn/dtgk/zrdl/201712/t20171218_1058184.htm |dead-url=no }}</ref>，主要河流有均溪、仙峰溪、文江溪和桃源溪，最大的均溪境内干流长81.7公里，森林面积232.45万亩，森林覆盖率69.49%，共有植物141科621种，其中中国国家一级保护植物5种，二级保护植物16种<ref name=b2>{{cite web |author1=大田县政府办 |title=大田县自然资源 |url=http://www.datian.gov.cn/dtgk/zrzy/201711/t20171129_1047787.htm |website=大田县人民政府 |date=2022-02-15 |accessdate=2023-06-16 |archive-date=2022-08-14 |archive-url=https://web.archive.org/web/20220814055420/http://www.datian.gov.cn/dtgk/zrzy/201711/t20171129_1047787.htm |dead-url=no }}</ref>。

==经济==
2022年大田县地区生产总值258.38亿元，地方一般公共预算收入8.75亿元，社会消费品零售总额64.42亿元，城镇居民人均可支配收入45162元，农村居民人均可支配收入23684元<ref>{{cite web |author1=大田县政府办 |title=综合概况 |url=http://www.datian.gov.cn/dtgk/dtjj/201711/t20171129_1047784.htm |website=大田县人民政府 |date=2023-05-15 |accessdate=2023-06-16 |archive-date=2022-08-14 |archive-url=https://web.archive.org/web/20220814071358/http://www.datian.gov.cn/dtgk/dtjj/201711/t20171129_1047784.htm |dead-url=no }}</ref>。全县耕地面积29.95万亩，其中水田18.72万亩、旱地3.23万亩，粮食作物以水稻为主，主要经济作物有油茶、木薯等<ref name=b2/>，特产有大田肉兔、大田高山茶、早兴风吹茶油、建设山宝糟菜、均溪九层粿、武陵雪山萝卜、前坪金峰生姜、梅山福梅辣椒等，工业以水泥、煤炭、冶矿为主，是福建省水泥、矿产品采选和深加工的重要工业生产基地<ref name=c3>{{Cite ZGBK |id=65974 |title=中国大百科全书 |editor=中国大百科全书编委会 |chapter=大田县}}</ref>，[[兴泉铁路]]、[[泉南高速]]、[[莆炎高速]]、[[356国道]]、[[235国道]]过境<ref>{{cite web |author1=大田县政府办 |title=大田县交通概况 |url=http://www.datian.gov.cn/dtgk/jtgk/201711/t20171129_1047798.htm |website=大田县人民政府 |date=2021-07-27 |accessdate=2023-06-16 |archive-date=2022-08-14 |archive-url=https://web.archive.org/web/20220814072657/http://www.datian.gov.cn/dtgk/jtgk/201711/t20171129_1047798.htm |dead-url=no }}</ref>。

==社会==
2020年中国[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]中，大田县常住人口为299513人，其中男性159135人，女性140378人，城镇人口162066人，乡村人口137447人，14岁以下占25.93%、15到59岁占56.30%、60岁及以上占17.77%，15岁及以上人口的平均受教育年限为8.56年<ref>{{Cite web |author=大田县统计局 |date=2021-06-04 |title=大田县第七次全国人口普查公报 |url=http://www.datian.gov.cn/xxgk/gggs/202106/t20210603_1671051.htm |archive-url=https://web.archive.org/web/20230616154748/http://www.datian.gov.cn/xxgk/gggs/202106/t20210603_1671051.htm |archive-date=2023-06-16 |access-date=2023-06-16 |website=大田县人民政府}}</ref>。境内有中国全国重点文物保护单位[[大田土堡群]]，福建省省级文物保护单位有[[银丁坂银矿遗址]]、[[广平文昌阁]]、[[镇东桥]]、[[林埔祠]]等20处，中国国家级非物质文化遗产项目有大田板灯龙和杂剧作场戏<ref name=c3/><ref>{{cite web |author1=大田县政府办 |title=大田县文化和体育 |url=http://www.datian.gov.cn/dtgk/whty/201711/t20171129_1047797.htm |accessdate=2023-06-16 |date=2022-01-10 |archive-date=2022-08-14 |archive-url=https://web.archive.org/web/20220814055930/http://www.datian.gov.cn/dtgk/whty/201711/t20171129_1047797.htm |dead-url=no }}</ref>。

==语言==
大田县大部分地区通行四到五种方言，分别为：[[前路话]]（含[[桃源話]]）、[[后路话]]、[[大田閩南話|闽南话]]、[[大田客家話|客家話]]；其中前路话和后路话属[[闽南语]][[大田片]]方言；当地的“闽南话”与[[泉州]]通行的[[泉漳片]][[泉州话]]相近，但它们之间仍存在一定差异，[[客家話]]方言岛主要分佈在大田县的北部和西部。並因方言复杂，交流不便，当地政府一直在致力[[推广普通话]]，被评为全国推广普通话先进县。

前路、后路的提法是按照地域位置进行区分，前路、后路以文江龙门为界，在大田的18个乡镇中，属于的前路的有均溪镇、上京镇、石牌镇、华兴乡、屏山乡、吴山乡、济阳乡、武陵乡、谢洋乡、湖美乡、前坪乡、桃源镇、太华镇；属于后路的有广平镇、建设镇、奇韬镇、文江乡、梅山乡。

前路中屏山乡、吴山乡、济阳乡、谢洋乡、桃源镇的新街、旧街、西安、下东坂和广前等村讲闽南话，桃源鎮的上东坂、黄山头和太华鎮的高星，广平的大吉、大竹林等村講客家話，其他乡镇讲[[前路话]]（即大田话、前道话），但桃源镇其他[[村級行政區|村社]]和上京鎮的黄城、桂坑、城口、丰田、南坑等村一带通行的前路话与其他地域的前路话存在一定差异，也有学者将其单独划出，称为[[桃源话]]；后路中各乡镇基本讲后路话（即后道话、尤溪县称作新桥话），故该方言也通行于[[尤溪县]]的[[上尤溪]]、[[沙县]]的部分乡镇
