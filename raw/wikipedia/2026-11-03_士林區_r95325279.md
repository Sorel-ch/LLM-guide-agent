'''士林區'''，舊稱「八芝蘭」，前身「士林鎮」<ref>{{cite web |url=https://sldo.gov.taipei/News_Content.aspx?n=0B28F6DC02F5914C&sms=3F7FFD3F3FBC3EAC&s=C10EF582DBAA65C3 |title=認識士林-歷史沿革 |date=2021-11-26 |access-date=2025-01-23 |publisher=臺北市士林區公所 |language=zh-tw |archive-date=2024-06-06 |archive-url=https://web.archive.org/web/20240606080033/https://sldo.gov.taipei/News_Content.aspx?n=0B28F6DC02F5914C&sms=3F7FFD3F3FBC3EAC&s=C10EF582DBAA65C3 |dead-url=no }}</ref>，位於[[臺灣]][[臺北市]]北部，為[[臺北高等行政法院]]所在地。全境面積為62.3682平方公里，人口約有25.8萬人，人口密度每平方公里約有4千1百多人，是臺北市面積最大、人口密度最低的行政區。區內東北為[[大屯火山群]]，以[[七星山 (臺北市)|七星山]]1,120公尺最高，東南部有大崙山及[[大直]]諸山，平原則分布在西南部[[南磺溪|磺溪]]、[[外雙溪]]下游及[[基隆河]]、[[淡水河]]間。

士林區內有[[士林夜市]]、[[陽明山國家公園]]等景點，以及[[國立故宮博物院]]，[[國立臺灣科學教育館]]、[[臺灣戲曲中心]]、[[臺北市立天文科學教育館]]、[[臺北表演藝術中心]]等文教設施與機構，[[天母]]地區外籍人士居多。士林區區花為[[玫瑰]]。

== 歷史 ==
[[File:八芝蘭番仔井.jpg|thumb|番井沸泉——芝蘭八景之一]]
士林區舊名「八芝蘭」（Pattsiran），為[[凱達格蘭語]]「溫泉」之義。在漢人尚未入墾之前，為平埔原住民族凱達格蘭族「[[麻少翁社]]」居住地。清朝時期實施堡里制，簡化其名為「芝蘭堡」（稍後再劃為[[芝蘭一堡]]）。清末時因當地讀書風氣興盛，科考人才輩出，遂改稱「士林」，有「士子如林」之涵義<ref>[http://www.taipeilink.net/cgi-bin/SM_theme?page=43795943 《臺北市 士林區》，臺北市政府官方網站] {{Wayback|url=http://www.taipeilink.net/cgi-bin/SM_theme?page=43795943 |date=20150205235726 }}</ref>。

[[臺灣荷西統治時期|荷蘭統治時期]]本區記有[[巴賽族]]「[[毛少翁社]]」、「[[瓦笠社]]」<ref name="封域篇">{{cite book |title=《臺北市志》卷一 沿革志 封域篇 |date=1988-06 |publisher=[[臺北市文獻委員會]] |pages=174-185}}</ref>。

1740年，屬[[淡水廳|淡水海防廳]]淡水保八芝蓮林庄、瓦笠庄。1760年屬淡水廳淡水保石角庄、八芝蘭林庄、瓦笠庄、毛少翁社，另設八芝蘭林街。[[嘉慶]]年間改隸淡水廳[[芝蘭一堡]]。[[同治]]年間屬芝蘭堡石角溝庄、芝蘭街、毛少翁社庄、毛少翁社及[[大加蚋堡|大加蠟堡]]社仔庄、溪州底庄{{r|封域篇}}。1879年，屬[[臺北府]][[淡水縣]]芝蘭一堡林口庄、員山仔庄、福德洋庄、棋林厝庄、社仔庄、洲尾庄、石角庄、南雅庄、三角埔庄、東勢庄、番仔仔庄、庄仔頂庄、草山庄、公舘地庄、菁碧庄、雙溪庄、番仔嶺庄、平頂庄、毛少翁社庄；芝蘭二堡中洲庄、溪洲庄；大加蠟堡溪洲底庄、溪沙尾庄{{r|封域篇}}。

1895年，[[臺灣日治時期|日治]]初期原臺北府改設[[臺北縣 (日治時期)|臺北縣]]，本區先後屬士林辦務署、台北辦務署。1901年臺北縣裁撤，改隸[[臺北廳]]{{r|封域篇}}。1909年，屬臺北廳士林支廳士林區芝蘭一堡'''[[士林 (大字)|士林街]]、[[林子口|林子口庄]]、[[福德洋庄]]、[[湳雅 (臺北市)|湳雅庄]]、[[石角 (臺北市)|石角庄]]、[[洲尾庄]]、[[三角埔 (臺北市)|三角埔庄]]、[[下東勢|下東勢庄]]、[[公館地|公舘地庄]]、[[永福庄]]、[[雙溪 (臺北市)|雙溪庄]]、[[坪頂 (臺北市)|埤頂庄]]、[[菁礐庄]]、[[草山 (臺北市)|草山庄]]、[[七股 (臺北市)|七股庄]]'''；社子區之'''[[社子 (臺北市大字)|社子庄]]、[[溪洲底|溪洲底庄]]'''；和尚洲區之'''[[和尚洲中洲埔|中洲庄]]'''{{r|封域篇}}。1920年，[[臺北州]]及[[臺北市 (州轄市)|臺北市]]設立，[[街庄社鄉|庄]]改制為[[大字]]。士林隸屬[[臺北州]][[七星郡]]，設「'''士林庄'''」。後因人口聚集，乃於1933年升格為「'''[[士林街]]'''」。

1945年，[[第二次世界大戰|二戰]]結束，[[臺灣戰後時期|中華民國接管臺灣]]。1946年1月起，全臺灣劃分為八縣，士林鎮屬[[臺北縣]]七星區{{r|鎮誌沿革章|p=29}}。1947年1月，裁撤七星區，士林鎮改隸臺北縣淡水區{{r|區志大事記|p=397}}。1949年8月26日，成立[[陽明山管理局|草山管理局]]（1950年12月改名陽明山管理局{{r|區志大事記|p=398}}），士林鎮劃為該局轄區，行政區域仍屬臺北縣，仍稱「臺北縣士林鎮」<ref>《戡亂期間臺灣省陽明山管理局設置辦法》</ref>{{r|區志大事記|pp=397－398}}。1967年7月1日，[[臺北市]]升格為[[直轄市 (中華民國)|直轄市]]。1968年7月1日，陽明山管理局改隸臺北市，士林鎮改為「士林區」<ref>{{cite web |title=士林緣起 |url=https://slhr.gov.taipei/cp.aspx?n=7FC1E1AA9EE0C3DB |website=臺北市士林區戶政事務所 |date=2009-07-26 |access-date=2021-07-07 |archive-date=2022-04-05 |archive-url=https://web.archive.org/web/20220405083809/https://slhr.gov.taipei/cp.aspx?n=7FC1E1AA9EE0C3DB }}</ref>{{r|區志大事記|p=403}}。1974年1月，裁撤陽明山管理局，士林區直隸於臺北市{{r|區志大事記|pp=403、405}}。1990年3月12日，臺北市實施第四期行政區域調整，將原屬士林區的洲美里劃歸北投區，並將原屬中山區的福樂里、康寧里<ref>{{cite web |title=福華里 |url=https://li.taipei/News_Content.aspx?n=2D219AB0D78FA045&sms=D982815F3A372FF5&s=441235A76D72C117 |website=臺北市鄰里服務網 |language=zh-tw |date=2019-02-22 |quote=民國79年3月12日區里行政區域調整，將原屬中山區之福樂里、康寧里兩里併入本里里名保留不變 |access-date=2021-07-07 |archive-date=2022-04-05 |archive-url=https://web.archive.org/web/20220405081820/https://li.taipei/News_Content.aspx?n=2D219AB0D78FA045&sms=D982815F3A372FF5&s=441235A76D72C117 }}</ref>、明勝里及部分的[[劍潭里|劍潭-{里}-]]<ref>{{cite web |title=明勝里 |url=https://li.taipei/News_Content.aspx?n=6ED9E94A0AD4FCD2&sms=D982815F3A372FF5&s=63F1746ABC5CA9E3 |website=臺北市鄰里服務網 |language=zh-tw |date=2019-06-05 |quote=將中山區劍潭 里中山北路以西部分併入本里 |access-date=2021-07-07 |archive-date=2022-04-05 |archive-url=https://web.archive.org/web/20220405081822/https://li.taipei/News_Content.aspx?n=6ED9E94A0AD4FCD2&sms=D982815F3A372FF5&s=63F1746ABC5CA9E3 }}</ref>併入士林區{{r|區志大事記|p=409}}。

== 地理 ==
=== 位置 ===
*北接[[北投區]]、[[新北市]][[金山區 (台灣)|金山區]]、[[萬里區]]
*東面為[[新北市]][[汐止區]]
*西面為[[新北市]][[五股區]]、[[蘆洲區]]、[[三重區]]、[[八里區]]
*南接[[大同區 (臺灣)|大同區]]、[[中山區 (臺北市)|中山區]]、[[內湖區]]

=== 區政組織 ===
[[File:Shilin District Administration Center, Taipei City 20140527.jpg|thumb|士林區行政中心]]
[[士林區公所]]是[[臺北市政府]]在士林區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為臺北市政府。[[区长]]由[[臺北市市長|市長]]任命，其任期為無任期保障。在區長、副區長及主任秘書之下，設有5課4室等9個內部單位<ref>{{Cite web |url=https://sldo.gov.taipei/cp.aspx?n=762836A0F3E7F9DC |title=機關介紹-組織架構 |publisher=臺北市士林區公所 |access-date=2021-09-27 |language=zh-tw |archive-date=2022-04-05 |archive-url=https://web.archive.org/web/20220405081827/https://sldo.gov.taipei/cp.aspx?n=762836A0F3E7F9DC }}</ref>。

=== 行政區 ===
[[File:TaipeiShiLinSubDistrictMap.png|thumb|臺北市士林區次分區位置圖：社子（左一）、後港（左二）、街上（左三）、蘭雅（中左）、天母（中上）、芝山岩（中右）、陽明山（右）。]]
現今士林區行政範圍的確立，來自於1990年3月，調整行政區域，將原屬中山區的劍潭地區部分土地劃入士林區區域，同時原屬士林區的洲美里也在此時劃出並納入北投區{{r|區志政事篇|p=163}}。

=== 都市更新 ===
*文林苑都市更新
{{Main|文林苑都市更新爭議}}
位於文林路士林橋、前街及後街一帶的[[都市更新]]爭議。事件始於王家不同意所擁有的兩塊土地和建物，包含在臺北市政府核定的都市更新範圍內，經由[[樂揚建設]]擔任實施者規劃都市更新事業計劃興建「文林苑」住宅大樓。2014年經過長期抗爭與訴訟，反對戶與建商樂揚建設達成和解，雙方簽字，樂揚建設同意撤銷所有訴訟。文林苑於2016年9月完工交屋。<ref>{{Cite web|last=自由時報電子報|date=2016-05-11|title=文林苑最快下半年交屋 王家：回傷心地有何意義 - 政治 - 自由時報電子報|url=https://news.ltn.com.tw/news/politics/breakingnews/1693530|access-date=2023-11-02|website=news.ltn.com.tw|language=zh-Hant-TW|archive-date=2023-11-02|archive-url=https://web.archive.org/web/20231102072823/https://news.ltn.com.tw/news/politics/breakingnews/1693530|dead-url=no}}</ref>

=== 廟宇 ===
[[士林慈諴宮]]、[[士林神農宮]]與[[芝山巖惠濟宮]]被稱為士林地區的三大古廟。
*[[永平福德宮]]：位於臺灣臺北市士林區永倫里、社子國小校園內的[[土地祠]]，1763年建立。
*[[士林街福德宮]]：位於臺灣臺北市大南路，主祀[[福德正神]]，興建於1861年。
*[[天母三玉宮]]：位於臺灣臺北市天母東路，為主祀[[五穀先帝]]，興建於1947年。
*[[金鶴宮]]：位於臺灣臺北市芝玉路，主祀[[瑤池金母]]，興建於1974年。
*[[士林德和宮]]：位於臺灣臺北市士林區德行里的[[土地祠]]。
*芝山巖聖佑宮：位於臺北市士林區雨聲街90號，主祀石頭公祖，興建於1972年。
*後港墘景佑宮：位於臺北市士林區承德路四段277巷33號，主祀福德正神。
*[[坤天亭]]：位於臺灣臺北市士林區富安里的[[哪吒廟]]，為[[社子島]]的信仰中心。
*社子台北[[共和宮]]：位於臺北市士林區社子街117號，主祀劉邢黃府千歲，興建於1974年。
*[[社仔社福宮]]：位於臺北市士林區社中街210巷31號，主祀福德正神。
*[[葫蘆寺]]：位於臺北市士林區社子島延平北路五段285巷35號，主祀[[觀世音菩薩]]，興建於1955年。
*葫蘆堵海光宮：位於臺北市士林區葫蘆街87號，主祀觀世音菩薩，興建於1968年。
*[[囝仔公威靈廟]]：位於臺灣臺北市士林區富洲里的[[陰廟]]，為社子島的水流公信仰之一。

*[[昭明寺]]：位於臺灣臺北市中山北路，供奉本師釋迦牟尼佛，興建於1934年。屬於臨濟宗妙心寺派。
