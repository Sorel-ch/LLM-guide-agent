'''巴马瑶族自治县'''是[[中国]][[广西壮族自治区]][[河池市]]所辖的一个[[自治县]]，总面积1971平方公里。<ref name="geo">{{cite web |url = http://www.bama.gov.cn/zjbm/zrdl/20180102-1330274.shtml |title = 地理位置 |work = 巴马瑶族自治县人民政府 |date = 2018-01-02 |accessdate = 2019-09-08 |archive-url = https://web.archive.org/web/20191211083621/http://www.bama.gov.cn/zjbm/zrdl/20180102-1330274.shtml |archive-date = 2019-12-11 |url-status = dead }}</ref> 2015年总人口为29.9万<ref name="pop">{{cite web |url = http://www.bama.gov.cn/zjbm/qhrk/20150922-1330276.shtml |title = 人口与民族 |work = 巴马瑶族自治县人民政府 |date =2015-09-02|accessdate = 2019-09-08 |archive-url = https://web.archive.org/web/20190420140552/http://www.bama.gov.cn/zjbm/qhrk/20150922-1330276.shtml |archive-date = 2019-04-20 |dead-url = yes }}</ref>，縣內共有100位超過一百歲的老人，是世界五大长寿之乡之一。<ref name="gen" />[[盤陽河]]流經县境內。[[自治县]]人民政府駐[[巴马镇]]新建路368号。

== 历史 ==
1955年9月21日，国务院第18次会议批准设立'''巴马瑶族自治县'''，县治巴马街。当时决定划辖原属[[东兰县]]的西山瑶族自治区（[[县辖区 (中华人民共和国)|区]]级）和第七、第九区，及原[[凤山县]]第七、第八区的部分乡。后决定增加划辖原东兰县第五区的弄竹乡，原[[田东县]]第八、第九区全部和第七区的龙田、新力、洪晚、赖满、龙威、子帽、燕洞等 7 个乡，原凤山县第六区全部和第七区的百马、那沙、那门、甲篆、平安、坡月、仁乡、松吉、兴仁、好合等 10 个乡，共计辖 98 个乡，1956年1月27日正式成立。

1956年8月11日，凤山县坡心区的那光、那乙、祥兰、合心及平乐区的东烈等5个乡归巴马县。1956年3月2日，巴马瑶族自治县改属[[桂西壮族自治州]][[百色地区]]。1958年1月25日，百色地区改为百色专区，巴马瑶族自治县改属[[百色专区]]。1965年5月18日，巴马瑶族自治县改属[[河池专区]]。1971年，河池专区改为河池地区，巴马瑶族自治县改属[[河池地区]]<ref>{{cite book |editor=巴马瑶族自治县县志编纂委员会办公室 |title=巴马瑶族自治县志 |url=http://lib.gxdfz.org.cn/file-c73-1.html |archive-date=2019-12-09 |archive-url=https://web.archive.org/web/20191209234958/http://lib.gxdfz.org.cn/file-c73-1.html |access-date=2026-09-24 |url-status=live}}</ref>。

== 人口 ==
2015年人口29.91万，少数民族26万人，占总人口的86.9%，其中[[瑶族]]人口5.3万，占总人口的17.7%。县内主体民族有瑶、壮、汉、仫佬、毛南、回、水等12个。<ref name="pop" />

根據第七次人口普查數據，截至2020年11月1日零時，巴馬瑤族自治縣常住人口為236152人<ref>{{Cite web|title=中國: 广西壮族自治区 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/guangxi/admin/|access-date=2023-08-19|website=www.citypopulation.de|archive-date=2023-08-19|archive-url=https://web.archive.org/web/20230819233655/https://www.citypopulation.de/zh/china/guangxi/admin/|dead-url=no}}</ref>。

== 长寿之乡 ==
巴马县居民以长寿闻名，截止2015年末县内共有3470位80-89周岁老人，726位90-99周岁老人，94位100-109周岁老人和6位110岁以上老人。100周岁以上老人合计有100人，寿星比例为34.48人/10万人，是世界长寿之乡认定标准的3.31倍，位居世界五大长寿乡之首。<ref name="gen" />

有上万外地老人来到巴马县甲篆镇坡月村的百魔洞养老、养生。
