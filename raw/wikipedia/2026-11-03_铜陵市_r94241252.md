'''铜陵市'''是[[中华人民共和国]][[安徽省]]下辖的[[地级市]]，位于安徽省南部。市境西北界[[合肥市]]，北、东临[[芜湖市]]，南接[[池州市]]，西连[[安庆市]]。地处[[长江中下游平原]]与皖南丘陵区过渡带，中部为沿江冲积平原，东南部、西北部以低山丘陵为主。[[长江]]由西南往东北流贯，将市境分为东西两部分，江中有[[和悦洲]]、[[老洲乡|老洲]]、[[胥坝乡|胥坝]]等[[沙洲]]。长江以西有[[陈瑶湖]]、[[白荡湖]]、[[菜子湖]]等湖泊。全市总面积2,991平方公里，总人口130.2万人。铜陵以产[[铜]]著称于世，是中华民族[[青铜]]文化的重要发祥地之一。铜开采、冶炼的历史始于三千年前的[[商周時期|商周时代]]，故有“中国古铜都”之誉。铜陵是[[宁铜铁路|宁铜]]、[[铜九铁路|铜九]]、[[庐铜铁路|庐铜]]等铁路交汇点，是长江下游重要的[[港口]]以及[[长江三角洲城市群]]成员<ref>{{cite web |url=http://www.tl.gov.cn/ |title=铜陵市政府网站 |date= |accessdate=2017-06-10 |archive-date=2019-01-12 |archive-url=https://web.archive.org/web/20190112012324/http://www.tl.gov.cn/ |dead-url=yes }}</ref>。市人民政府驻[[铜官区]]湖东路666号。

== 历史 ==
[[File:Flooded Datong Town, Tongling (2020).jpg|thumb|[[2020年中国南方水灾]]期间被淹没的铜陵[[大通古镇]]]]

* [[东汉]]时期，官府在此设立铜官镇。<ref name=":0"/>
* [[东晋]]时期，因北方战乱，大批[[山西省|山西]]流民迁入此地，因而在此侨置[[定陵县 (东晋)|定陵县]]。<ref name=":0"/>

* [[南北朝]][[南齐|齐]][[梁 (南朝)|梁]]时期，官府在此设立采铜机构，兴办官营手工[[工场]]。
* [[隋朝]]统一后，将定陵县并入[[南陵县]]。<ref name=":0"/>
* [[唐朝]]时期采铜规模扩大，兴建了官办铜矿，称之[[铜官场]]。唐朝后期，从南陵划出工山、安定、凤台、归化、丰资五乡，设置[[义安县]]。<ref name=":0"/>
* 888年，[[庐州]][[刺史]][[杨行密]]统兵袭[[宣州]]，扎营[[铜官场]]之山麓，此山遂以[[铜官山]]之名首见于史册。
* [[南唐]]，曾封[[铜官山]]为[[利国山]]。保大九年，改义安县为[[铜陵县]]，同时自[[顺安镇]]移县治至铜官镇。<ref name=":0"/>
* [[清]]初，这里曾设立过[[铜官督]]。
* [[鸦片战争]]后，[[帝国主义]]列强为了掠夺[[铜矿]]资源，曾在此设立过[[安裕公司]]、[[伦华公司]]。
* 1938年，[[日本]]侵占铜陵后，设立[[铜官山矿业有限公司]]。
* 1949年4月21日，[[渡江战役]]后铜陵成为江南第一个解放的城市。
* 1952年11月，[[人民政府]]在此成立了[[铜官山矿务局]]。
* 1956年10月12日，成立[[铜官山市]]。<ref name=":0"/>
* 1958年9月5日，[[铜官山市]]与[[铜陵县]]合为铜陵市。同时由省辖改隶属于[[安庆专区]]。<ref name=":0"/>
* 1959年4月3日，恢复[[铜陵县]]建制。<ref name=":0"/>
* 1964年7月29日，实行政企合一，改为[[铜陵特区]]。<ref name=":0"/>
* 1965年，恢复[[池州专区]]，专署驻[[贵池县]]。辖原属[[安庆专区]]的[[贵池]]、[[青阳]]、[[东至]]、[[铜陵]]4县；由[[太平府 (安徽省)|太平]]、[[贵池]]2县析置[[石台县]]。池州专区辖5县。
* 1971年，撤销[[池州专区]]，改置[[池州地区]]。[[铜陵县]]属于池州地区。12月11日，铜陵特区改为铜陵市，为省直辖市。<ref name=":0">{{Cite web|title=历史沿革|url=https://www.tl.gov.cn/mltd/99/102/200509/t20050928_227436.html|access-date=2022-01-24|date=2021-04-25|work=www.tl.gov.cn|publisher=铜陵市人民政府|language=zh-cn|archive-date=2022-01-23|archive-url=https://web.archive.org/web/20220123164714/https://www.tl.gov.cn/mltd/99/102/200509/t20050928_227436.html}}</ref>
* 1974年3月1日，[[铜陵县]]自池州地区划入。<ref name=":0"/>
* 2015年，经国务院批准，将安庆市枞阳县划归铜陵市管辖；撤销铜陵市铜官山区、狮子山区，设立铜陵市铜官区；撤销铜陵县，设立铜陵市义安区。<ref>{{Cite web|title=尘埃落定！安徽官方披露安庆铜陵淮南六安部分区划调整信息|url=https://www.thepaper.cn/newsDetail_forward_1416625|access-date=2022-01-23|work=www.thepaper.cn|publisher=澎湃新闻|archive-date=2022-01-23|archive-url=https://web.archive.org/web/20220123170000/https://www.thepaper.cn/newsDetail_forward_1416625|dead-url=no}}</ref>

== 人口 ==
2022年铜陵市常住人口为130.1万人<ref>{{Cite web|title=铜陵市人民政府|url=https://www.tl.gov.cn/|access-date=2023-10-27|website=www.tl.gov.cn|archive-date=2024-04-16|archive-url=https://web.archive.org/web/20240416001033/https://www.tl.gov.cn/|dead-url=no}}</ref>，相较于2021年度有所下降，减少了0.5万人。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为1,311,726人<ref>{{cite web |author1=铜陵市统计局、铜陵市第七次全国人口普查领导小组办公室 |title=铜陵市第七次全国人口普查公报 |url=https://tjj.tl.gov.cn/3010/202105/t20210526_1454589.html |access-date=2023-07-24 |archive-date=2023-07-24 |archive-url=https://web.archive.org/web/20230724122656/https://tjj.tl.gov.cn/3010/202105/t20210526_1454589.html |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的1,562,670人相比，十年共减少了250,944人，下降16.06%，年平均增长率为-1.74%。其中，男性人口为655,329人，占总人口的49.96%；女性人口为656,397人，占总人口的50.04%。总人口性别比（以女性为100）为99.84。0－14岁的人口为188,432人，占总人口的14.37%；15－59岁的人口为825,602人，占总人口的62.94%；60岁及以上的人口为297,692人，占总人口的22.69%，其中65岁及以上的人口为229,027人，占总人口的17.46%。居住在城镇的人口为867,982人，占总人口的66.17%；居住在乡村的人口为443,744人，占总人口的33.83%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为1,307,565人，占99.68%；各[[中国少数民族|少数民族]]人口为4,161人，占0.32%。与2010年第六次全国人口普查相比，汉族人口减少251,007人，下降16.1%，占总人口比例下降0.05个百分点；各少数民族人口增加63人，增长1.54%，占总人口比例增加0.05个百分点。

== 矿产资源 ==
铜陵自然资源尤以矿产资源储量丰富，矿种全而闻名。已探明的矿种主要有铜、硫、铁、金、银、煤、石灰石等，其中铜、金、银、硫铁矿和石灰石储量均在全省名列前茅。大理石、石灰岩、膨润土、铅锌矿、珍珠岩、钾长石、石英石等，也有一定储量。铜陵八宝分别为：金，银，铜，铁，锡，生姜，老蒜，麻。

== 交通 ==
[[File:Tongdu.jpg|thumb|right|铜都大道]]
[[File:Nanjing-Tongling Railway in snow (20160124125500).jpg|thumb|[[宁铜铁路]]铜陵钟鸣段]]
[[File:Tongling Station.jpg|thumb|right|[[铜陵站]]]]
[[File:Tongling Northern Station.jpg|thumb|right|[[铜陵北站]]]]

铜陵位于[[宁铜铁路]]的终点以及[[铜九铁路]]的起点，境内亦有[[宁安客运专线]]、[[合福客运专线]]通过，截止2016年5月15日，[[铜陵站]]每日开行36对旅客列车，[[铜陵北站]]每日开行32对旅客列车。铜陵是{{中国高速公路名|G3}}（原合铜黄高速公路，现已并入京台高速公路）和{{中国高速公路名|G50}}的交汇点。{{中国国道名|236}}过境。铜陵东距[[南京]]约200千米，西距[[九江]][[庐山]]约300千米，南距[[九华山]]约80千米，距[[黄山]]约120千米，北距[[合肥]]约130千米。[[铜陵长江大桥]]于1995年12月26日建成通车，[[铜陵长江公铁大桥]]于2015年7月1日建成通车。

铜陵距[[合肥新桥国际机场]]约150千米，可以在市内购买机票；距[[池州九华山机场]]约20千米。
