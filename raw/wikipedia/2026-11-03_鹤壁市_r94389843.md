'''鹤壁市'''是[[中华人民共和国]][[河南省]]下辖的[[地级市]]，位于河南省北部。市境东、西、北三面皆被[[安阳市]]包围，南面与[[新乡市]]邻接。地处[[太行山脈]]东南之丘陵与平原区间，地势西高东低。[[卫河]]及其支流[[淇河 (衛河支流)|淇河]]为境内主要河流。全市总面积2,140平方公里，常住总人口約158万人，鹤壁是河南省重要的[[煤炭]]城市，因煤而兴。市人民政府驻[[淇滨区]]九州路。

== 历史 ==
=== 名称典故 ===
“鹤壁”一名最早见于《[[金史]]》，相传古时有双鹤栖于南山之峭壁，逐名其山为“鹤山”，其村为“鹤壁”。亦有一说为其名源于道士在饭店[[影壁]]上所画白鹤可起舞的神话传说。

=== 建制沿革 ===
[[商代]]最后一位君主[[帝辛]]（被后人贬称[[商纣王]]）定都于'''沫邑'''，后改为'''[[朝歌]]'''，即今[[淇县]]。商末，帝辛与[[周武王]]决战于此。武王灭商后，封帝辛之子[[武庚]]为诸侯，统治朝歌一带，并派[[管叔鲜|管叔]]、[[蔡叔]]、[[霍叔]]监视其举动，称“[[三监]]”。周武王封[[康叔]]为卫侯，[[春秋时期|春秋]]初为[[卫国]]属地，朝歌曾为卫国都城，后被[[晋国|晋]]所占。《[[左传]]》记曰：[[鲁襄公]]二十三年（前550年）[[齐国|齐]]“伐晋，取朝歌”。[[齐景公]]三十八年（前510年）设'''中牟邑'''，即今鹤壁市山城区。[[三家分晋]]后为[[赵国]]地。[[赵献子]]元年（前423年），赵国将都城迁至中牟邑。后被[[魏国 (战国)|魏]]所占。

[[汉代]]至[[三国]]分属[[河內郡_(中國)|河内郡]][[荡阴县]]（今鹤壁市区）、[[朝歌县]]（今淇县）及[[魏郡]][[黎阳县]]（今[[浚县]]）。[[东汉]][[建安 (东汉)|建安]]十七年（212年）荡阴县、朝歌县改属魏郡。[[西晋]][[泰始 (西晋)|泰始]]元年（265年）朝歌县属[[汲郡]]。[[东晋]][[永和 (东晋)|永和]]七年（351年）于黎阳县置[[黎阳郡]]。[[太元 (东晋)|太元]]十四年（389年）废黎阳郡复黎阳县入汲郡。

[[北魏]][[天兴 (北魏)|天兴]]四年（401年）析[[冀州 (古代)|冀州]]置[[相州]]，治[[邺县]]（今[[河北省]][[临漳县]]邺镇）。[[永安 (北魏)|永安]]元年（528年）分黎阳县置[[东黎县]]。[[东魏]][[天平 (东魏)|天平]]元年（534年）改相州为[[司州]]，废荡阴县入[[邺县]]，于黎阳县置[[黎州]]。天平二年（535年）置[[魏德县]]。[[北齐]]年间废魏德县、东黎县。[[北周]][[建德 (北周)|建德]]六年（577年）司州复为相州。[[宣政]]元年（578年）分汲郡置[[卫州]]，治枋头城（今浚县西南）。[[大象 (北周)|大象]]二年（580年）相州移治安阳城（今[[安阳市]]）。

[[隋朝|隋]][[开皇]]六年（586年）复置荡阴县。开皇十六年（596年）改荡阴县为[[荡源县]]，属黎州。[[大业 (年号)|大業]]二年（606年）改朝歌县为[[卫县]]，改卫州为汲郡，废黎州。[[唐朝|唐]][[武德]]元年（618年）复置卫州，卫县属之，次年于黎阳县复置黎州。武德六年（623年）改荡源县为[[汤阴县]]。[[貞觀]]元年（627年）卫州移治汲县（今[[卫辉市]]）。[[北宋]][[熙宁]]六年（1073年）废卫县，[[元祐 (年號)|元祐]]初复置。[[政和 (年號)|政和]]五年（1115年）改黎州为[[濬州]]，仍治黎阳县。[[宣和]]初汤阴县改属濬州，后复属相州。[[金朝|金]][[明昌]]三年（1192年）升相州为[[彰德府]]。

[[元朝|元]][[元宪宗|宪宗]]五年（1255年）于卫县西鹿台乡置[[淇州]]，属[[卫辉路]]，卫县废为集，并置[[临淇县]]；濬州属[[大名路]]；汤阴县属[[彰德路]]。[[至元 (元世祖)|至元]]三年（1266年）废临淇县入淇州。[[明朝|明]][[洪武]]元年（1368年）改淇州为[[淇县]]，属[[卫辉府]]；改濬州为[[濬县]]，属[[大名府]]；汤阴县属[[彰德府]]。[[清代]]因之。[[中華民國|民国]]二年（1913年）废府存县，淇县、濬县、汤阴县均属[[河南省]][[河北道]]。1928年废道制。1932年，三县属河南省第三行政督察区。

[[中华人民共和国]]建立后，濬县、淇县、汤阴三县属[[平原省]][[安阳专区]]。1953年平原省撤销，安阳专区改属河南省。1954年，淇县并入汤阴县。1956年9月建鹤壁矿区。1957年3月，析汤阴县7个乡及3个村之地置鹤壁市<ref>{{cite journal |author1=中华人民共和国国务院 |title=国务院关于設置三門峽市、平頂山市和鶴壁市的决定 |location=北京市 |journal=《[[中华人民共和国国务院公报]]》 |date=1957年 |issue=13 |page=251 |id={{CNKI|GWYB195713006|CJFD|r}}}}</ref>，为[[省辖市]]，委托安阳专区领导，后改为省直接领导。1958年12月，安阳专区撤销，鹤壁市归[[新乡专区]]领导。1960年10月，安阳专区的汤阴县划归鹤壁市。1961年11月，汤阴县又复归安阳专区；同年设[[山城区|山城]]、[[鹤山区|鹤山]]两个[[市辖区]]。1961年12月恢复安阳专区，鹤壁市又改属之。1962年恢复淇县建制。1966年设立郊区。1986年1月，将[[安阳市]]的浚县、淇县划归鹤壁市管辖。2001年12月，郊区更名为[[淇滨区]]。

=== 市区搬迁 ===
市区经历了三次搬迁。1957年，市区选在[[鹤壁集镇|鹤壁集]]，随着二矿、三矿的建设，1957年12月市区南移到中山；后又随着五矿、六矿的建设，1959年，市区又从中山迁到现在的老区大湖。随着矿区的发展，市区的周围基本上都是塌陷区，城市的发展受到制约。1992年，鹤壁在东南浚县淇县交界处建立淇滨经济开发区，随着规模的扩大，1999年5月市政治中心迁到淇滨区，目前新区已成为鹤壁市新的政治、经济、文化中心<ref>{{Cite web|url=http://www.xzqh.org/html/show.php?contentid=12385|title=鹤壁市历史沿革|publisher=行政区划网|date=2009-12-06|accessdate=2011-08-14|archive-date=2011-12-10|archive-url=https://web.archive.org/web/20111210125339/http://www.xzqh.org/html/show.php?contentid=12385|dead-url=no}}</ref>。

== 地理 ==
鹤壁位于河南北部，[[太行山]]东麓，与[[华北平原]]接连。

== 人口 ==
2024年末，全市常住人口155.9万人，<ref>{{Cite web|title=2024年鹤壁市国民经济和社会发展统计公报 - 鹤壁市统计局|url=https://tjj.hebi.gov.cn/zfxxgk/fdzdgknr/tjxx/tjgb/art/2025/art_9134be562f91455b9b0013e816d7b0f4.html}}</ref> 年末全市常住人口155.9万人，其中城镇100.3万人，乡村55.6万人；城镇化率为64.34%，比上年末提高1.15个百分点。全年出生人口1.15万人，人口出生率为7.36‰；死亡人口1.18万人，人口死亡率为7.55‰；自然增长率为-0.19‰。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为1,565,973人<ref>{{cite web |author1=鹤壁市统计局、鹤壁市第七次全国人口普查领导小组办公室 |title=鹤壁市第七次全国人口普查公报 |url=https://www.hebi.gov.cn/sjkf/tjgb/art/2021/art_a40e1130948041a39711b90b1228f2b9.html |access-date=2023-07-24 |archive-date=2023-07-24 |archive-url=https://web.archive.org/web/20230724134730/https://www.hebi.gov.cn/sjkf/tjgb/art/2021/art_a40e1130948041a39711b90b1228f2b9.html |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的1,569,208人相比，十年共减少了3,235人，下降0.21%，年平均增长率为-0.02%。其中，男性人口为792,316人，占总人口的50.6%；女性人口为773,657人，占总人口的49.4%。总人口性别比（以女性为100）为102.41。0－14岁的人口为339,116人，占总人口的21.66%；15－59岁的人口为969,400人，占总人口的61.9%；60岁及以上的人口为257,457人，占总人口的16.44%，其中65岁及以上的人口为187,128人，占总人口的11.95%。居住在城镇的人口为955,004人，占总人口的60.98%；居住在乡村的人口为610,969人，占总人口的39.02%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为1,563,490人，占99.84%；各[[中国少数民族|少数民族]]人口为2,483人，占0.16%。与2010年第六次全国人口普查相比，汉族人口减少4,151人，下降0.26%，占总人口比例下降0.06个百分点；各少数民族人口增加916人，增长58.46%，占总人口比例增加0.06个百分点。

== 资源 ==
矿产资源有[[煤]]、[[硫铁矿]]、[[陶土]]、[[铝矾土]]、[[白云岩]]等。九十年代发现大量[[金属镁]]资源。是中国重要煤炭基地之一。

== 经济 ==
*有[[煤炭]]、[[机械]]、[[化学工业|化工]]、[[纺织]]等工业。所产汽车配件质量在国内名列前茅。[[耐火砖]]、[[铸铁管]]、[[釉面砖]]等先后打入国际市场。
*农业盛产[[小麦]]、[[玉米]]、[[谷子]]、[[红薯]]、[[柿子]]、[[苹果]]。
*著名的淇河三珍：[[淇河鲫鱼]]、[[缠丝鸭蛋]]、[[冬凌草]]。
*豫北黑[[山羊]]为优良畜种。

== 交通 ==
铁路：[[京广铁路]]从鹤壁市穿境而过，在鹤壁设[[鹤壁站]]。[[京广高速铁路]]于2012年12月26日全线通车，在鹤壁设[[鹤壁东站]]。

高速公路：{{中国高速公路名|G4}}和{{China Expwy Name|S26|P=Henan|[[范辉高速]]}}。国道：{{中国国道名|107}}。

== 名胜古迹 ==
鹤壁的人文景观和自然风光各具特色，是河南省重要的旅游观光地区。境内[[大伾山]]、[[浮丘山]]、[[云梦山 (河南)|云梦山]]、[[五岩山]]各具特色。华北地区唯一未被污染的[[淇河 (卫河支流)|淇河]]从境内蜿蜒流过，两岸景色秀丽，为《[[诗经]]》所咏唱。
*鹤壁集古瓷窑遗址
*五岩寺石窟
*玄天洞石塔
