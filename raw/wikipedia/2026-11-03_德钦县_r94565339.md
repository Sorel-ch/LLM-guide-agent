'''德钦县'''（{{Lang-bo|p=Dêqên Zong|z=བདེ་ཆེན་རྫོང་|w=dge chen rdzong}}）是[[中华人民共和国]][[雲南省]][[迪庆藏族自治州]]下属的一个[[县]]。位於[[維西縣]]西北境，舊屬維西縣，全县面积7291平方千米，2020年总人口5.47万人。县人民政府驻[[升平镇 (德钦县)|升平镇]]。

== 词源 ==
此地有喇嘛寺名“德钦林”，“德钦”为[[藏语]]“极乐太平”之意，“德”为“平”，“钦”为“安”。<ref>{{cite book |author=德钦县人民政府编 |title=云南省德钦县地名志 |publisher=内部资料 |year=1987 }}</ref>{{rp|7}}

== 历史 ==
德钦历史上属康藏地方政权，明洪武五年（1372年），为[[磨儿勘招讨司]]（[[芒康]]）与剌宗万户府（[[巴塘]]）辖区。正德四年（1509年），被[[丽江土司]][[木定]]占领，时称'''阿得酋'''。崇祯十二年（1648年），[[和硕特部]][[固始汗]]派兵南下，击败木氏，德钦为和硕特部控制。清康熙五十八年（1719年），清廷收复巴塘地区，设[[巴塘土司]]，德钦复归巴塘管辖。雍正四年（1726年），清廷勘定川滇界，德钦地划归云南[[鹤庆府]]，时称'''阿墩子'''<ref name="西绕云贞">{{cite journal |author=西绕云贞 |title=天下一统的重要决策——迪庆藏区归滇研究 |journal=西藏研究 |year=2003 |issue=3 |pages=30-37 |id={{CNKI|xzyj200303004|CJFD}} }}</ref>。

雍正五年（1727），[[维西厅]]设立，德钦地方划属维西厅<ref>{{cite book |author1=李汝春 主编 |author2=维西傈僳族自治县志编纂委员会 编 |title=维西傈僳族自治县志 |location=昆明 |publisher=云南民族出版社 |year=1999  |isbn=7-5367-1915-9 }}</ref>{{rp|52-54}}。光绪三十二年（1906年），设'''阿墩子弹压委员'''，属维西厅，后试设县未果。民国4年（1915年），改设'''阿墩子行政委员'''，民国21年（1932年）又改'''阿墩子设治局'''，民国24年（1935年）更名'''德钦设治局'''。民国38年（1949年）5月26日，国民政府总统指令公布，核准升德钦设治局为德钦县<ref>「                      中華民國總統府公報第226號
總統指令 穗統一字第十八號 三十八年五月二十六日  令行政院（仍另行文） 三十八年五月十九日卅八穗四字第三六五二號呈，為內政部呈轉雲南省政府咨請將龍武、德欽、寧蒗三設治局改設為縣，并將維西縣屬奔欄鄉劃歸德欽管轄一案，核屬可行，擬予照准，呈請鑒核明令公布，並鑄發印信由。呈件均悉。准予公布。印信仰候飭局鑄發可也。此令。代　總　統　[[李宗仁]] [[行政院院長]]　[[何應欽]]
」</ref>，一纸空文，并未实施。

1949年12月25日，德钦设治局宣布起义。1950年4月，中国人民解放军进驻。1950年5月20日，[[中共丽江地委]]派出的随军代表接管德钦县参议会和设治局。1952年5月4日，召开德钦县首届各族各界人民代表大会第一次会议，决定成立'''德钦县藏族自治区'''及人民政府，隶属[[丽江专区]]。<ref name="李世华1997">{{cite book |author1=李世华 主编 |author2=云南省德钦县志编纂委员会 编 |title=德钦县志 |location=昆明 |publisher=云南民族出版社 |year=1997 |isbn=7-5367-1417-3 }}</ref>{{rp|4-22}}1955年12月，德钦县首届各族各界人民代表会议第六次会议决定，改德钦县藏族自治区为德钦县<ref>{{Cite web |title=【建制沿革】 |url=http://www.diqing.gov.cn/mldq/jzyg |website=迪庆藏族自治州人民政府 |date=2024-01-12 |access-date=2026-03-05}}</ref>；1956年9月11日国务院批准<ref name="政区沿革">{{Cite book |title=云南省政区沿革（1949-1985） |author=云南省民政厅 |publisher=内部发行 |year=1988}}</ref>{{Rp|53}}。1957年9月13日，德钦与中甸、维西共同建立迪庆藏族自治州<ref name="李世华1997" />{{rp|4-22}}。

2024年9月，[[维西傈僳族自治县]]所辖[[叶枝镇]]、[[巴迪乡]]划归德钦县管辖<ref>{{cite web |author1=云南省民政厅 |title=国务院批复同意我省调整 德钦县与维西傈僳族自治县行政区划 |url=https://www.yn.gov.cn/zwgk/gsgg/202409/t20240927_305017.html |website=云南省人民政府 |date=2024-09-27 |accessdate=2024-10-02 |archive-date=2024-10-07 |archive-url=https://web.archive.org/web/20241007152341/https://www.yn.gov.cn/zwgk/gsgg/202409/t20240927_305017.html |dead-url=no }}</ref>。因存在地质灾害隐患，未来德钦县城将由[[升平镇 (德钦县)|升平镇]]搬迁到[[叶枝镇]]，新县城建设于2025年4月26日全面启动<ref>{{Cite web |title=云南德钦首批县城避险搬迁群众入住新居 |url=https://www.xinhuanet.com/20260513/919ef314ac004c2fa8773e54dfcca322/c.html |website=新华网 |date=2026-05-13 |access-date=2026-07-06}}</ref>。

==经济==
2022年，德钦县[[国内生产总值|生产总值]]达47.30亿元，按可比价格计算，比上年增长1.3%。其中[[第一产业]]增加值2.81亿元，增长4.7%；[[第二产业]]增加值18.38亿元，下降1.9%；[[第三产业]]增加值26.11亿元，增长3.1%。三次产业结构为5.9∶38.9∶55.2。人均生产总值85,306元。城乡常住居民人均可支配收入分别为46,087元、12,272元。职工年平均工资181,727元。地方一般公共预算收入1.23亿元，人均2,223元。地方一般公共预算支出26.52亿元，人均47,826元。<ref>{{Cite book|title=云南统计年鉴 2023|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

==人口==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，德钦县总人口（常住人口）共有54,736人，城镇人口8,674人（占15.85%），乡村人口46,062人（占84.15%）。共有男性28,356人、女性26,380人，[[人類性別比|性别比]]为107.49。0—14岁人口共8,997人（占16.44%），15—59岁人口共37,383人（占68.30%），60岁及以上人口共8,356人（占15.27%），其中65岁及以上人口共6,172人（占11.28%）。大学专科学历及以上人口有6,706人，15岁以上的文盲有14,617人，占15岁以上人口的31.96%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>
