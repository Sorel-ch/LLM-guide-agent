'''马龙区'''是[[中华人民共和国]][[云南省]][[曲靖市]]下属的一个[[市辖区]]。居[[昆明市]]与曲靖市[[麒麟区]]之间，东及东北部与麒麟区、[[沾益区]]接壤，南与[[陆良县]]、[[宜良县]]毗邻，西及西北与嵩明、寻甸两县交界，全区面积1599平方千米，2020年总人口19.31万人。

==历史==
[[西汉]][[元封]]二年（前109年）设[[铜濑县]]（[[东汉]]称“同濑”），隶属[[益州郡]]。[[三国时期|三国]][[蜀汉]][[建兴 (蜀汉)|建兴]]三年（225年）将益州郡改为建宁郡，同濑县属建宁郡。[[唐朝|唐]][[武德]]元年（618年）更名为同起县，属南宁州。[[南诏]]时期称曲轭川，隶属拓东节度。[[大理国]]后期称纳垢部，是滇东三十七部之一，属[[石城郡]]。[[元朝]]初年，设纳垢千户所，下辖易龙百户，隶属于磨弥万户府。至元十三年（1276年），纳垢千户所改为马龙州，易隆百户改为[[通泉县 (云南)|通泉县]]，属[[曲靖路]]。明洪武十五年（1382年），撤通泉县并入马龙州，马龙州属[[曲靖府]]。宣德六年（1432年）至成化十二年（1476年），马龙州曾改属[[仁德府]]。清朝仍称马龙州，属曲靖府。<ref name="曲靖市政区大典">{{Cite book |title=曲靖市政区大典 |publisher=云南人民出版社 |location=昆明 |year=2014 |isbn=978-7-222-12039-6 |page=80 |editor=《曲靖市政区大典》编纂委员会}}</ref><ref>{{Cite web |title=美丽云南 {{!}} 马龙古道 今日俊美——美名：曲靖·马龙区 |url=https://dct.yn.gov.cn/html/2206/01_21894.shtml |website=云南省文化和旅游厅 |date=2022-06-01 |access-date=2026-02-18}}</ref>

民国二年（1913年），废除州制，改马龙州为马龙县。1950年3月，马龙县人民政府成立，属[[曲靖专区]]。1958年10月，撤销马龙县并入[[麒麟区|曲靖县]]。1961年7月，马龙县从曲靖县析出，恢复建制。1963年4月，[[寻甸县]]钟灵山以东的七十一个自然村划归马龙县。1977年12月，马龙县通泉公社所属的四个大队划归曲靖县。<ref name="曲靖市政区大典" />2018年2月9日，国务院批复同意撤销马龙县，设立曲靖市马龙区<ref>{{Cite web |title=中华人民共和国二〇一八年县级以上行政区划变更情况 |url=http://xzqh.mca.gov.cn/description?dcpid=2018 |website=中华人民共和国民政部 |url-status=dead |archive-url=https://web.archive.org/web/20190710213043/http://xzqh.mca.gov.cn/description?dcpid=2018 |archive-date=2019-07-10 |access-date=2026-02-18}}</ref><ref>{{cite web |title=经国务院批准曲靖马龙撤县设区 |url=http://yn.yunnan.cn/html/2018-04/02/content_5147414.htm |website=云南网 |date=2018-04-02 |author=蒋琼波 |dead-url=no |archive-url=https://web.archive.org/web/20201025192928/http://yn.yunnan.cn/html/2018-04/02/content_5147414.htm |archive-date=2020-10-25 |access-date=2018-05-23 |publisher= |quote=}}</ref>，5月21日正式挂牌成立<ref>{{Cite web |title=撤县设区 曲靖“马龙区”正式揭牌 珠江源大城市开启新征程 |url=http://society.yunnan.cn/html/2018-05/21/content_5215819.htm |website=云南网 |date=2018-05-21 |language=zh-CN |author=全婧 |author2=胡向苏 |url-status=live |archive-url=https://web.archive.org/web/20201029071600/http://society.yunnan.cn/html/2018-05/21/content_5215819.htm |archive-date=2020-10-29 |access-date=2026-02-18}}</ref>。

==经济==
2022年，马龙区[[国内生产总值|生产总值]]达130.08亿元，按可比价格计算，比上年增长12.1%。其中[[第一产业]]增加值22.39亿元，增长5.1%；[[第二产业]]增加值64.52亿元，增长18.6%；[[第三产业]]增加值43.17亿元，增长7.3%。三次产业结构为17.2∶49.6∶33.2。人均生产总值68,102元。城乡常住居民人均可支配收入分别为41,966元、15,990元。职工年平均工资94,067元。地方一般公共预算收入6.21亿元，人均3,250元。地方一般公共预算支出22.77亿元，人均11,924元。<ref>{{Cite book|title=《云南统计年鉴2023》|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

==人口==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，马龙区总人口（常住人口）共有193,137人，城镇人口67,504人（占34.95%），乡村人口125,633人（占65.05%）。共有男性100,900人、女性92,237人，[[人類性別比|性别比]]为109.39。0—14岁人口共32,078人（占16.61%），15—59岁人口共131,786人（占68.23%），60岁及以上人口共29,273人（占15.16%），其中65岁及以上人口共21,371人（占11.07%）。大学专科学历及以上人口有18,901人，15岁以上的文盲有13,865人，占15岁以上人口的8.61%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>
