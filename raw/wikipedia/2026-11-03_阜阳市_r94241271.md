'''阜阳市'''，简称'''阜'''，古称'''汝阴、顺昌、颍州'''，是[[中华人民共和国]][[安徽省]]下辖的[[地级市]]，位于安徽省西北部。市境东北接[[亳州市]]，东接[[淮南市]]，东南临[[六安市]]，西南邻[[河南省]][[信阳市]]，西毗河南省[[驻马店市]]，西北达河南省[[周口市]]。地处淮北平原南部，地势平坦。[[淮河]]流经南面边界，[[颍河]]自西北往东南贯穿并流经市区，于市境东南注入淮河。总面积10,118平方公里，全市常住总人口約815万人，市人民政府驻[[颍州区]]清河东路539号。阜阳代表文化是淮河文化，界首彩陶、颍上花鼓灯、黄岗柳编、杜氏刻铜等列入[[国家级非物质文化遗产代表性项目名录|国家级非物质文化遗产名录]]<ref>{{cite web|url=http://www.fy.gov.cn/about|title=走进阜阳-阜阳市人民政府|date=2021-05-19|publisher=阜阳市人民政府|accessdate=2021-06-03|dead-url=no|archive-date=2021-02-25|archive-url=https://web.archive.org/web/20210225163654/http://www.fy.gov.cn/about/}}</ref>。阜阳是[[中原经济区]]城市，2019年加入[[长江三角洲城市群]]。<ref>{{cite web|url=http://www.gov.cn/xinwen/2019-10/15/content_5440091.htm|title=长三角城市经济协调会新增7个城市|date=2019-10-15|publisher=中华人民共和国中央人民政府|accessdate=2021-06-03|dead-url=no|archive-date=2021-06-03|archive-url=https://web.archive.org/web/20210603180005/http://www.gov.cn/xinwen/2019-10/15/content_5440091.htm}}</ref>

==历史==
由於「襟帶長淮，控扼陳蔡」的地理原因，在商周就建立了妫姓的[[胡国]]。[[秦朝]]始置[[颍州区|汝阴县]]，汉属[[汝南郡]]。西晋置[[汝阴郡 (曹魏)|汝阴郡]]、郡治汝阴就在境内，[[北魏]][[孝昌 (年号)|孝昌]]四年（523年）置[[颍州 (北魏)|潁州]]，隋設汝陰郡，宋設[[順昌府]]，金朝时，复设颍州。[[清朝]][[雍正]]十三年（1735年），颍州升为[[颍州府]]，设置[[附郭县]]——[[阜阳县]]。1913年[[中华民国北京政府]]全国廢州縣。1948年7月30日，[[中国人民解放军]][[豫皖苏军区]]四分区独立三团攻尅阜阳<ref>{{Cite web |url=http://www.ahage.net/fuyang/fuyangdiqudashiji_9.html |title=阜阳地区历史大事记（商朝至解放初）(9) |accessdate=2014-10-04 |author=安史 |date=2008-07-22 |work= |publisher= |language=Zh-hans |archive-url=https://web.archive.org/web/20141006153223/http://www.ahage.net/fuyang/fuyangdiqudashiji_9.html |archive-date=2014-10-06 |dead-url=yes }}</ref>。[[中华人民共和国成立]]后，设立[[阜阳专区|阜阳地区专员公署]]。1996年2月26日，撤消[[阜阳地区]]和[[阜阳市 (县级市)|县级阜阳市]]，設立地級阜陽市。下辖三区五县（市）。1998年2月，[[亳州市]]从阜陽市划出，由省直辖。

2000年5月，[[中华人民共和国国务院]]批准设立地级[[亳州市]]，[[涡阳县|涡阳]]、[[蒙城县|蒙城]]、[[利辛县|利辛]]三县划归[[亳州市]]管辖。目前，阜陽市辖[[界首市]]和[[太和县|太和]]、[[临泉县|临泉]]、[[颍上县|潁上]]、[[阜南县|阜南]]四县及[[颍州区|颍州]]、[[颍泉区|颍泉]]、[[颍东区|颍东]]三区。<ref>[http://www.fy.gov.cn/DocHtml/1/2011/9/15/4206464410284.html 历 史 沿 革] {{webarchive|url=https://web.archive.org/web/20120502193211/http://www.fy.gov.cn/DocHtml/1/2011/9/15/4206464410284.html |date=2012-05-02 }}</ref>

== 地理 ==
===气候===
阜阳市位于淮北平原西部，安徽省西北方，地处亚热带和暖温带的过渡区域，属[[温带|暖温带]][[温带季风气候|半湿润季风气候]]。

阜阳四季分明，雨量适中，光照充足。年均气温15摄氏度左右，无霜期220天，年均降水910毫米左右。由于地处季风气候区，因此降水、温度等的年际、年内变化受季风影响较大。

== 政治 ==
1990年代以來阜阳治安欠佳、官場敗壞，在[[华东地区]]流传一首妇孺皆知的民諺——“蚌埠偷，淮南抢，阜阳没有共产党”，即在阜阳乡亲父老们看来，当地是没有一个官员堪称共产党员的，此民諺和相關政治問題在[[新华网]]、[[中国青年报]]報導。<ref>{{cite news|title=阜阳嬗变|work=中国经济周刊|date=2007-05-28|via=新华网|last=汪孝宗|url=http://news.sohu.com/20070528/n250262856.shtml|accessdate=2022-07-28|archive-date=2022-07-28|archive-url=https://web.archive.org/web/20220728102658/http://news.sohu.com/20070528/n250262856.shtml|dead-url=no}}</ref><ref>{{cite news|title=我的故乡阜阳是如何沦陷的|date=2009-07-21|work=中青在线-中国青年报|url=http://zqb.cyol.com/content/2009-07/21/content_2766220.htm|archiveurl=https://web.archive.org/web/20090724155317/http://zqb.cyol.com/content/2009-07/21/content_2766220.htm|archivedate=2009-07-24|accessdate=2022-07-06}}</ref><ref>{{cite news|title=期待正义之光照耀阜阳的白宫|date=2008-12-26|work=中国江西网|url=http://news.sina.com.cn/pl/2008-12-26/091916925516.shtml|archiveurl=https://web.archive.org/web/20220706111543/http://news.sina.com.cn/pl/2008-12-26/091916925516.shtml|archivedate=2022-07-06|accessdate=2022-07-06}}</ref>

== 人口 ==
2022年末，全市常住人口814.1万人<ref>{{Cite web|title=阜阳市2022年国民经济和社会发展统计公报 - 中国统计信息网|url=http://www.tjcn.org/tjgb/12ah/37484.html|access-date=2023-11-01|website=www.tjcn.org|archive-date=2023-11-01|archive-url=https://web.archive.org/web/20231101150735/http://www.tjcn.org/tjgb/12ah/37484.html|dead-url=no}}</ref>，比上年末减少3.0万人；常住人口城镇化率43.47%，比上年末提高0.73个百分点。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为8,200,264人<ref>{{cite web |author1=阜阳市统计局、阜阳市第七次全国人口普查领导小组办公室 |title=阜阳市第七次全国人口普查公报 |url=https://tjj.fy.gov.cn/content/detail/60a7a8b3886688eb6c8b4578.html }}{{Dead link}}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的7,599,913人相比，十年共增加了600,351人，增长7.9%，年平均增长率为0.76%。其中，男性人口为4,157,132人，占总人口的50.7%；女性人口为4,043,132人，占总人口的49.3%。总人口性别比（以女性为100）为102.82。0－14岁的人口为2,003,910人，占总人口的24.44%；15－59岁的人口为4,812,494人，占总人口的58.69%；60岁及以上的人口为1,383,860人，占总人口的16.88%，其中65岁及以上的人口为1,130,854人，占总人口的13.79%。居住在城镇的人口为3,441,982人，占总人口的41.97%；居住在乡村的人口为4,758,282人，占总人口的58.03%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为8,131,828人，占99.17%；各[[中国少数民族|少数民族]]人口为68,436人，占0.83%。与2010年第六次全国人口普查相比，汉族人口增加603,443人，增长8.02%，占总人口比例增加0.11个百分点；各少数民族人口减少3,092人，下降4.32%，占总人口比例下降0.11个百分点。

== 经济 ==
=== 综合 ===
2019年初步核算，阜阳市地区生产总值2705.0亿元，按可比价格计算，比上年增长9.0%，增幅高于全省1.5个百分点。其中，第一产业增加值350.4亿元，增长3.5%，快于全省0.3个百分点；第二产业增加值1033.2亿元，增长10.3%，快于全省2.3个百分点；第三产业增加值1321.3亿元，增长9.6%，快于全省1.9个百分点。三次产业结构调整为13.0 : 38.2 : 48.8。<ref>{{cite web |author1=阜阳市统计局 |title=阜阳统计年鉴2019 |url=http://tjj.fy.gov.cn/download/?mod=site_attach&_id=5e153c8b7f8b9ad94c8b456e |website=http://tjj.fy.gov.cn/ |publisher=阜阳市统计局 |accessdate=2020-03-04 |archive-date=2020-06-10 |archive-url=https://web.archive.org/web/20200610045057/http://tjj.fy.gov.cn/download/?mod=site_attach&_id=5e153c8b7f8b9ad94c8b456e |dead-url=no }}</ref>

2019年，全市生产总值比上年增长9.0%，高于全省1.5个百分点；规模以上工业增加值增长10.4%，高于全省3.1个百分点，居全省第4位；固定资产投资增长13.9%，高于全省4.7个百分点，居全省第3位；房地产开发投资增长30.9%，高于全省19.2个百分点，居全省第3位；社会消费品零售总额增长12.4%，高于全省1.8个百分点，居全省第2位；财政收入增长8.5%，高于全省2.0个百分点，居全省第4位；金融机构人民币贷款余额增长20.9%，高于全省6.8个百分点，居全省第2位；居民人均可支配收入增长10.9%，高于全省0.8个百分点，居全省首位；农村居民人均可支配收入增长10.6%，高于全省0.5个百分点，居全省第3位。

全年财政收入352.3亿元，增长8.5%，增幅高于全省2.0个百分点。其中，地方财政收入200.6亿元，增长7.2%。财政支出655.1亿元，增长14.0%。其中，民生类支出559.3亿元，增长13.4%，高于上年同期1.7个百分点。

年末全市金融机构人民币存款余额4342.3亿元，比年初增加287.8亿元，增长7.1%。其中，住户存款余额2693.6亿元，比年初增加309.3亿元，增长13.0%，快于全市金融机构人民币存款余额5.9个百分点。金融机构人民币贷款余额3195.2亿元，比年初增加542.2亿元，增长20.9%，增幅高于全省 6.8个百分点，居全省第2位。

全年全市居民人均可支配收入20700元，比上年增长10.9%，增幅高于全省0.8个百分点，居全省首位。按常住地分，城镇居民人均可支配收入32844元，增长9.1%，增幅与全省持平；农村居民人均可支配收入13079元，增长10.6%，增幅高于全省0.5个百分点，居全省第3位。

==资源==
*动物资源有鱼、鸟、兽等100余种。
*野生植物有[[土荆芥]]、[[野西瓜]]等。
*中草药材主要有板蓝根、车前子、[[半夏]]、[[芡实]]、[[马齿苋]]、[[枸杞]]、[[半边莲]]、[[香附子]]等。
[[File:Fuyang Cuisine - Ge La Tiao.jpeg|缩略图|格拉条，流行于阜阳地区的一种小吃]]
*土特产品有[[格拉条]]、[[枕头馍]]、颍州樱桃、雨前香椿、侯大升陈醋、颍州包瓜菜、闻集草莓、半截楼西瓜、煎烩鸡、[[醉三秋酒]]等。
*煤炭资源丰富、仅东部已探明其蕴藏量就达100亿吨，可采储量80多亿吨，皆为5700大卡左右的优质煤炭。据初步探测其西部地区煤炭储存量大大超过其东部地区。现有谢桥矿（设计能力800万吨煤炭）、颍上刘庄矿（年产800万吨，被誉为国内第一对数字化的矿井，有高度为90.8米的“亚洲第一井塔”）、口孜煤矿（设计年产500万吨，预计将于2009年投产）、罗园煤矿（年产300万吨，进入项目实施阶段）。
*据卫星遥感勘测，界首市、太和县的地下蕴藏丰富的石油和天然气资源。
*太和县、阜南县蕴含地热资源。
