'''石河子市'''（{{lang-ug|شىخەنزە شەھىرى|Shixenze Shehiri}}）是[[中华人民共和国]][[新疆维吾尔自治区]]下辖的[[县级市]]，与[[新疆生产建设兵团第八师]]实行“[[师市合一]]”，位于新疆[[准噶尔盆地]]南缘、[[天山]]中段北麓、[[玛纳斯河]]西岸。是个由军人选址、军人设计、军人建造的城市。城市绿化覆盖率达42%，2000年被[[联合国]]人居中心授予“人居环境改善良好范例奖”<ref>{{Cite web |title=新疆篇：新疆石河子——戈壁滩上的花园城市 |url=http://news.cctv.com/lm/803/22/58331.html |website=cctv.com |access-date=2022-09-05 |archive-date=2022-09-05 |archive-url=https://web.archive.org/web/20220905113430/http://news.cctv.com/lm/803/22/58331.html |dead-url=no }}</ref>。人口以[[漢族]]為主。

石河子市曾是[[新疆生产建设兵团]]总部的所在地，今为[[新疆生产建设兵团第八师]]师部驻地，第八师和石河子市实行一个党委领导，领导班子分设，采取[[师市合一]]体制。

== 历史 ==
[[File:1965-10 1965年 周恩来视察新疆石河子农场与上海知青.jpg|缩略图|左|1965年周恩来视察新疆石河子农场，与上海知青沟通]]
石河子在西汉文帝至东汉前期属[[乌孙]]，魏晋南北朝时期先后属[[柔然]]、[[高车]]，北周保定二年（公元562年）属[[突厥汗国|突厥]]，隋仁寿三年（公元603年）属[[西突厥]]，唐贞观二十二年（公元648年）属唐朝，唐显庆三年（公元658年）属[[安西都护府]]，武周长安二年（702年）属[[北庭都护府]]<ref>{{cite web|title=安史之乱后，大唐北庭都护府孤悬塞外，硬生生坚持了三十五年之久|url=https://www.163.com/dy/article/DRTLETBI0517SV1D.html|website=网易|accessdate=2022-01-15|date=2018-09-17|archive-date=2022-01-15|archive-url=https://web.archive.org/web/20220115094141/https://www.163.com/dy/article/DRTLETBI0517SV1D.html|dead-url=no}}</ref>，唐开成五年（公元840年）属[[喀喇汗朝]]，12世纪中期属[[西辽]]，[[蒙古帝国]]初期设置[[别失八里|别失八里等处行尚书省]]，后归属[[察合台汗国]]，明朝时属[[东察合台汗国]]，15世纪前期属[[卫拉特]]，清初为卫拉特准噶尔部呼拉玛游牧地。清乾隆二十六年（公元1761年），实行[[屯田制]]，设立营屯。清乾隆三十九年（公元1774年）[[招民开垦]]， 石河子一带形成散落式村庄。

石河子，东有泉水汇成的小河，其底多石，因以得名。清乾隆四十三年（公元1788年），设[[玛纳斯县|绥来县]]，石河子在绥来县县治内。清光绪十年（1884），新疆设行省，石河子为绥来县西乡村庄之一。民国三十三年（公元1944年），绥来县设立石河子乡。1945年9月，[[三区民族军]]进驻后，石河子为[[沙湾市|沙湾县]]管辖下的一个镇。

中华人民共和国建立后，1950年10月，沙湾县将五个镇（乡）改为三个区，石河子为第三区，区公所驻石河子。1950到1953年，中国人民解放军新疆军区二十二兵团司令部、政治部机关及其直属队、二十六师、骑兵第八师、新疆军区后勤运输部生产总队、骑兵第七师三十团先后进入一带石河子[[屯垦]]，并在新疆军区统一领导下，开始建设石河子新城。1958年11月，[[沙湾县星火人民公社]]成立，石河子区公所撤销。1961年，经自治区批准，星火公社及所辖4个大队划归新疆军区生产建设兵团。<ref name="shz">{{cite web|title=石河子概况|url=http://www.shz.gov.cn/gkxx/sh/88662.htm?COLLCC=1393173950&|website=石河子人民政府网|accessdate=2022-01-15|date=2021-11-01}}{{Dead link}}</ref>

1975年新疆军区生产建设兵团及其所属师建制撤销后，6月15日，石河子市宣布成立。1976年1月2日，国务院批准设立石河子地区及石河子市，以沙湾县的石河子镇和沙湾县的部分地区为其行政区域，隶属[[石河子地区]]<ref>{{cite web|title=中华人民共和国行政区划（1976年）|url=http://www.gov.cn/govweb/test/2007-03/23/content_559092.htm|website=中央人民政府网|accessdate=2022-01-15|archive-date=2022-01-13|archive-url=https://web.archive.org/web/20220113135324/http://www.gov.cn/govweb/test/2007-03/23/content_559092.htm|dead-url=no}}</ref>，原兵团石河子指挥部所属独立团、[[五七农场]]、星火公社及农八师[[新疆生产建设兵团第八师石河子总场|一四五团]]等单位划归石河子市管辖。

1978年9月，石河子地区撤销，保留石河子市，直属自治区管理。1979年2月，成立石河子农工商联合企业，与石河子市合署办公，实行[[政企合一]]。1981年12月，新疆生产建设兵团恢复建制，农八师建制同时恢复建制，与石河子农工商联合企业为[[一个机构两块牌子]]。1984年9月，自治区决定，石河子市为自治区直辖市，与农八师合组一个党委，称师市党委。2012年12月24日，经中央编办批准，“新疆生产建设兵团农八师石河子市”更名为“新疆生产建设兵团第八师石河子市”。<ref name="shz"></ref>

== 地理 ==
石河子地处天山北麓中段，准噶尔盆地南部，古尔班通古特沙漠南缘，距自治区首府乌鲁木齐150千米，西距边境重镇伊犁州伊宁市549千米。面积460平方公里。地势平坦，平均海拔高度450.8米。自东南向西北倾斜。石河子垦区地形由南向北依次为天山山区、山前丘陵区、山前倾斜平原、洪水冲积平原、风成沙漠区。石河子属典型的温带大陆性气候，冬季长而严寒，夏季短而炎热。日照充沛，年日照时数为2721～2818小时。境内有玛纳斯河、宁家河、金沟河、大南沟河、巴音沟河等五条河流，河水年径流量15.3亿立方米，地下水可采量3亿立方米。建有大中小型水库11座，蓄水总量4.33亿立方米。

== 人口 ==
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为 498587人<ref>{{Cite web|title=中國: 新疆维吾尔自治区 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/xinjiang/admin/|access-date=2023-12-25|website=www.citypopulation.de}}</ref>。

根据2010年[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]，全市[[常住人口]]为380130人<ref>{{cite book |author=石河子市统计局|title=《石河子市2010年第六次全国人口普查主要数据公报》}}</ref>，同[[中华人民共和国第五次全国人口普查|第五次全国人口普查]]相比，十年共增加81245人，增长27.18%。年平均增长率为2.43%。其中，男性人口为193713人，占50.96%；女性人口为186417人，占49.04%。总人口性别比（以女性为100）为103.91。0－14岁人口为49095人，占12.92%；15－59岁人口为270858人，占71.25%；60岁及以上人口为60177人，占15.83%，其中65岁及以上人口为46071人，占12.12%。[[汉族]]人口为349149人，占91.85%；各[[少数民族]]人口为30981人，占8.15%。

== 经济 ==
2022年，石河子实现生产总值870亿元，增长5.4%。其中工业增加值440亿元，完成固定资产投资240亿元，实现社会消费品零售总额132亿元。新增市场主体5583户。全口径税收收入完成126.4亿元、增长58.1%，一般公共预算收入69.68亿元<ref>{{Cite web |title=平稳增长 稳中向好——2022年八师石河子市经济社会发展综述 |url=https://www.btzx.com.cn/web/2023/1/7/ARTI1673068506793463.html |website=兵团在线 |date=2023-01-07 |archive-url=https://web.archive.org/web/20230107073838/http://www.btzx.com.cn/web/2023/1/7/ARTI1673068506793463.html |archive-date=2023-01-07 |access-date=2024-08-30 |dead-url=no}}</ref>。
== 工业 ==
石河子市是[[新疆生产建设兵团]]重要工业生产基地，以能源产业和化工新材料产业为支柱产业，石河子市现有新材料企业28家，其中碳基材料生产企业12家、硅基材料生产企业9家、铝基材料企业7家<ref>{{Cite web|title=石河子产业转型升级 释放高质量发展潜力|url=https://www.shznews.com/2023/11/07/9913056.html|website=石河子新闻|date=2023-11-07|access-date=2024-08-30|archive-date=2024-08-30|archive-url=https://web.archive.org/web/20240830161406/https://www.shznews.com/2023/11/07/9913056.html|dead-url=no}}</ref>。主要生产电解铝、氧化铝、高纯铝、电池铝箔、超净醇、草酸、高性能树脂、晶圆棒、晶体乙醛酸等工业材料。
