'''云龙县'''是[[中华人民共和国]][[云南省]][[大理白族自治州]]下辖的一个[[县]]，县人民政府驻[[诺邓镇]]。云龙县位于[[云南省]]西部，[[大理白族自治州]]西北部，全县面积4370平方千米，2020年总人口18.30万人，[[中國民族列表|少数民族]]占总人口的86.23%，以[[白族]]为主。

==名称==
“云龙”二字得名于[[澜沧江]]，因“澜沧江上夜覆云雾，晨则渐以升起如龙”故名。2026年2月，“云龙”入选第四批省级地名文化遗产保护名录<ref>{{Cite web |title=第四批省级地名文化遗产保护名录出炉|url=https://ynmz.yn.gov.cn/cms/gongshigonggao/12025.html|website=云南省民政厅|date=2026-02-12|access-date=2026-05-08}}</ref>。

== 历史 ==
[[西汉]][[元封 (西汉)|元封]]二年（前109年）设比苏县，属[[益州郡]]。[[东汉]][[永平 (东汉)|永平]]十二年（69年）起至[[西晋]]，比苏县属[[永昌郡]]。西晋[[永嘉 (西晋)|永嘉]]五年（311年）从永昌郡中分出比苏县，设置西河郡，梁末废比苏县。[[唐朝|唐]][[武德]]四年（621年），属[[南宁州 (云南)|南宁州]]总管府，称为[[尹州]]。唐[[麟德]]元年（664年）改属[[姚州 (云南)|姚州]]都督府，仍称尹州。[[南诏]]境内澜沧江以东属[[剑川节度]]，澜沧江以西属永昌节度。[[大理国]]属胜乡郡，称“云龙赕”。[[元朝|元]]末设置云龙甸军民总管府并防送千户所，隶属[[大理金齿宣慰司|金齿宣慰司]]。明[[洪武]]十七（1384年）改为云龙州，[[明朝]]皇帝[[朱元璋]]授大理国第一代国王[[段思平]]的二十四代孙段保为云龙土知州，属[[大理府]]。明[[正统 (年号)|正统]]间，改属[[蒙化府]]，后仍归大理府。[[民國紀年|民国]]二年（1913年）改州为县，属[[腾越道]]。民国18年（1929年）改县公署为县政府，直属省。1950年属大理专区，1956年属大理白族自治州。1958年撤销云龙县并入[[永平县]]，1961年恢复云龙县建制，仍属大理白族自治州。

==地理==
云龙县地处[[云南省]]西部，[[大理白族自治州]]西北部边缘，位于大理白族自治州、[[保山市]]和[[怒江傈僳族自治州]]的结合部。云龙县东连[[洱源县]]和[[漾濞彝族自治县|漾濞县]]，南邻永平县和保山市，西交怒江州[[泸水市]]，北接[[剑川县]]和怒江州[[兰坪白族普米族自治县|兰坪县]]。云龙县位于[[东经]]98°52′—99°46′，[[北纬]]25°28′—26°23′之间，东西最大跨距91.8千米，南北最大跨距109千米。云龙县城距州府[[大理市]]158公里，距省会[[昆明市]]518公里。云龙县国土总面积4,400.95平方千米。<ref name=":0">{{Cite web |date=2021-10-26 |title=云龙概况 |url=http://www.ylx.gov.cn/ylxrmzf/c102588/202110/3bc433dacba5433480d5e0c688968963.shtml |website=云龙县人民政府 |access-date=2022-08-06 |archive-date=2021-11-23 |archive-url=https://web.archive.org/web/20211123140421/http://www.ylx.gov.cn/ylxrmzf/c102588/202110/3bc433dacba5433480d5e0c688968963.shtml |dead-url=no }}</ref><ref name=":1">{{cite book|author1=段丽元 主编|author2=中华人民共和国民政部|title=中华人民共和国政区大典·云南省卷|location=北京|publisher=中国社会出版社|year=2016|isbn=978-7-5087-5306-5|pages=2428-2429}}</ref>

全县最高点是苗尾乡的喇嘛枯山，海拔3,663米，最低点为民建乡的红旗坝，海拔730米，县城所在地海拔1,640米<ref name=":0" />。

=== 气候 ===
云龙县属于亚热带大陆性高原季风气候。年平均气温16.1℃，年平均[[降水量]]781.4毫米。<ref name=":1" />

==经济==
2022年，云龙县[[国内生产总值|生产总值]]达77.24亿元，按可比价格计算，比上年增长0.7%。其中[[第一产业]]增加值18.43亿元，增长4.1%；[[第二产业]]增加值29.20亿元，下降2.8%；[[第三产业]]增加值29.61亿元，增长1.9%。三次产业结构为23.9∶37.8∶38.3。人均生产总值42,591元。城乡常住居民人均可支配收入分别为38,277元、13,728元。职工年平均工资111,945元。地方一般公共预算收入3.40亿元，人均1,875元。地方一般公共预算支出17.78亿元，人均9,806元。<ref>{{Cite book|title=云南统计年鉴 2023|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

== 人口 ==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，云龙县总人口（常住人口）共有182,977人，城镇人口51,298人（占28.04%），乡村人口131,679人（占71.96%）。共有男性94,841人、女性88,136人，[[人類性別比|性别比]]为107.61。0—14岁人口共32,035人（占17.51%），15—59岁人口共119,165人（占65.13%），60岁及以上人口共31,777人（占17.37%），其中65岁及以上人口共23,467人（占12.83%）。大学专科学历及以上人口有13,305人，15岁以上的文盲有6,659人，占15岁以上人口的4.41%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref><ref name=":3">{{Cite web |last=云龙县统计局 |date=2021-07-08 |title=云龙县第七次全国人口普查主要数据公报 |url=https://mp.weixin.qq.com/s/WFG__fBQq_lAQslFS5_A2w |website=云龙县融媒体中心 |access-date=2022-08-06 |archive-date=2022-08-05 |archive-url=https://web.archive.org/web/20220805181347/https://mp.weixin.qq.com/s/WFG__fBQq_lAQslFS5_A2w |dead-url=no }}</ref>2020年末统计，云龙县[[户籍人口]]共有208,277人<ref name=":0" />。
