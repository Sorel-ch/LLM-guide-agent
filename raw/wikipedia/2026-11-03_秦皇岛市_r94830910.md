'''秦皇岛市'''，简称'''秦'''，旧称'''临榆'''，是[[中华人民共和国]][[河北省]]下辖的[[地级市]]，位于河北省东北部，市境西南界[[唐山市]]，西北接[[承德市]]，东北临[[辽宁省]][[朝阳市]]、[[葫芦岛市]]，东南滨[[渤海湾]]。地处[[燕山山脉]]丘陵区及山前平原过渡带，地势北高南低。[[滦河]]、[[洋河 (秦皇岛市)|洋河]]、[[戴河]]、[[汤河 (秦皇岛市)|汤河]]皆流经市境注入渤海湾，市人民政府驻[[海港区 (秦皇岛市)|海港区翠岛大街1号]]。秦皇岛是[[京哈铁路]]上重要城市之一，为[[中華人民共和國沿海開放城市|沿海开放城市]]，中国北方重要的对外贸易口岸，国务院批准的全国甲级旅游城市。著名的风景区[[山海关]]、[[北戴河区|北戴河]]坐落于此。

== 名稱 ==
通說是[[秦始皇]]求仙時，曾驻跸此地而得名<ref>《永平府志》：「秦皇島，在撫寧縣東七十里，有山在海中，世傳秦始皇求仙駐蹕於此。」</ref>。

另傳[[唐太宗征讨高句丽|唐太宗征討高句麗]]時，曾驻跸此地，而[[唐太宗]]在[[玄武門之變]]前，曾為[[秦王]]，因而取名「秦王島」，又稱「秦皇島」<ref>《光緒二十四年中外大事匯記》：“昔唐太宗征高麗駐蹕此島，故曰秦王島。或以為始皇求仙處，誤也。島北地勢漸低，斜接灘岸，海水由溢出口。寬十餘丈，平時水深三四尺，潮漲水深五六尺。”</ref><ref>《抚宁县志》：“秦王岛，误秦皇岛，在县东七十里。四面皆水，惟岛居中。唐太宗征高丽，驻跸于此。”</ref><ref>《[[大公報]]》, 1948-05-28</ref>。

== 历史 ==
[[商朝|商]][[周朝|周]]时期为[[孤竹国]]中心区域，[[春秋时期]][[晋国|晋]]灭[[肥國 (春秋)|肥]]，肥子逃奔[[燕国]]，燕封肥子在此地建肥子国。[[战国]]时期，此地属[[燕国]][[辽西郡]]。[[秦朝|秦]][[汉朝|汉]]时期这里是东巡朝拜和兵家必经之地。[[秦始皇]]第四次出巡到[[碣石镇|碣石]]，刻碣石门。并派燕人[[盧生|卢生]]、[[韩终]]、[[侯公]]、[[石生]]等[[方士]]入海求神仙和[[長生不死]]之药，秦皇岛由此得名。[[汉武帝]]东巡观海，到[[碣石山 (河北)|碣石]]筑汉武台，并在此用兵攻朝鲜[[卫满朝鲜|衛氏王朝]]，把[[北戴河区|北戴河]]金山嘴作为屯粮城。[[曹操]]率兵北伐[[乌桓]]，取道[[渤海]]之滨，望临碣石，赋《观沧海》诗。

[[File:Qinhuangdao 1908 AMS-WO.jpg|thumb|left|1908年的秦皇岛地图(註：本地圖在1908年出版，來自1908年GSGS版本的Kodaline空照圖，1927年增修鐵路路線，1944年由美國陸軍指揮中心重製，刪除了英國式地圖網格，改採用世界地圖圓錐投影網格制定座標)]]
[[隋朝|隋]][[唐朝|唐]]时期，这里是抵御关外[[突厥汗国|突厥]]、[[契丹人|契丹]]的战略要地，[[唐玄宗]]派[[史思明]]统平州太守，兼统卢龙军使。[[元朝]][[忽必烈]]将中书省平滦路设在此地，后改为[[永平府]]，[[明朝]]曾在此设立盐署。1381年，[[朱元璋|明太祖朱元璋]]派开国元勋中山王[[徐达]]主持修建了[[山海关]]关城。明[[嘉靖]]十四年（1535年）版《山海关志》最早记有这一地名：“秦皇岛，城西南25里，又入海1里。”1644年，明王朝覆灭，[[李自成]]带兵4万余众到山海关征讨[[吴三桂]]，山海关守将吴三桂投降[[多尔衮]]，开关引清军15万同[[李自成]]大战，这就是改变中国历史命运的“甲申山海关石河大战”，经三天苦战，农民军终因兵寡失利，退至境内卢龙县（永平府），重整军队再战，大败，李自成逃回京城。清王朝从此入主[[中原]]。

[[清朝|清王朝]]统治时期，在山海关设立臨榆县。

1897年11月22日，[[北洋大学|北洋大学堂]]附设津榆铁路学堂迁至山海关，定名[[山海关北洋铁路官学堂]]<ref name="山海关北洋铁路官学堂创建研究">{{cite journal |author1=张雪永 |title=政治漩涡中的教育：山海关北洋铁路官学堂创建研究 |journal=西南交通大学学报（社会科学版） |date=2013-01-15 |issue=14 |pages=129-136}}</ref>。

1898年，秦皇岛港启锚开运，[[天津]]至[[臨榆|临榆]]的[[津榆铁路]]通车。同年，清政府正式将北戴河开辟为“各国人士避暑地”。秦皇島開港後，逐漸清挖泥沙，將島相連於陸地。

[[中華民國|民国]]初期，秦皇岛属[[直隶省]][[渤海道]]，外国[[军人]]、[[神父]]、[[牧师]]等开始进入秦皇岛境内。

1948年4月，中共冀东区委组建了中共秦榆工作委员会，[[王明德]]任书记，下设[[臨榆|临榆]]、秦皇岛两个工作组。1948年11月配备了由[[王世煜]]任市委书记、[[王植范]]为市长的接收领导班子。1948年11月23日至26日，驻山海关的[[国民革命军第八十七军|第八十七军]]，驻秦皇岛的[[国民革命军第八十六军|第八十六军]]和[[国民革命军第五十三军|第五十三军]]撤退，[[中国人民解放军|解放军]]冀察热辽军区第十三分区警卫第八团另一个警卫营2000余人于11月27日入驻秦皇岛。秦皇岛与山海关合并设立[[秦榆市]]。1948年12月2日，设立[[秦榆市]]军事管制委员会，军管会主任[[田星云]]，副主任[[王世煜]]（市委书记）、[[李雪瑞]]（冀东第十三军分区司令员、秦榆市警备司令）、[[王植范]]（首任市长）。1949年3月22日，由于[[冀东行政区]]由[[東北行政委員會 (1946年－1949年)|东北行政委员会]]划归[[华北人民政府]]，[[秦榆市]]一分为二，原属秦榆市管辖之[[山海关市]]划归东北[[辽西省]]，海滨区及上庄坨矿区设秦皇岛市，秦榆市军事管制委员会改为秦皇岛市军事管制委员会，军管会主任[[王世煜]]，副主任[[李雪瑞]]、[[王植范]]。1949年8月设立河北省，冀东行政区撤销，秦皇岛市为河北省的省辖市。1952年11月，撤销辽西省，山海关划归秦皇岛市。

1976年7月28日[[北京时间]]03时42分53.8秒，[[唐山市]]发生[[唐山大地震|7.8级大地震]]，秦皇岛和[[天津]]也遭受部分损失。

1984年秦皇岛成为全国首批[[沿海开放城市]]。秦皇岛作为[[2008年夏季奥林匹克运动会|北京2008奥运会]]协办城市成功举办奥运赛事。

== 地理 ==
秦皇岛市地处河北省东北部，北纬39°24'-40°37'，东经118°33'-119°51'。南面频临[[渤海]]，北面背靠[[燕山]]，东接[[辽宁省]][[葫芦岛市]]，西邻[[唐山市|唐山]]、[[承德市|承德]]两市，距首都[[北京市|北京]]约280公里。市境地势北高南低。

秦皇岛市气候类型属于半湿润[[温带季风气候]]，冬季寒冷夏季较热，年平均气温10.6℃，最热月(7月)平均气温24.7℃，最冷月(1月)平均气温-5.6℃，年降水量601.9毫米，年日照时数2513.6小时。

=== 行政区划 ===

* 市辖区：[[海港区 (秦皇岛市)|海港区]]、[[山海关区]]、[[北戴河区]]、[[抚宁区]]
* 县：[[昌黎县]]、[[卢龙县]]
* 自治县：[[青龙满族自治县]]

另外，秦皇岛市设有[[国家级经济技术开发区|国家级]][[秦皇岛经济技术开发区]]和[[北戴河新区]]。

== 人口 ==
根据2010年[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]，全市[[常住人口]]为2987605人<ref>{{cite book|author=秦皇岛市统计局|title=《秦皇岛市2010年第六次全国人口普查主要数据公报》}}</ref>，同[[中华人民共和国第五次全国人口普查|第五次全国人口普查]]相比，十年共增加202580人，增长7.27%。年平均增长率为0.70%。其中，男性人口为1516194人，占50.75；女性人口为1471411人，占49.25。总人口性别比（以女性为100）为103.04。0－14岁人口为425790人，占14.25；15－64岁人口为2279262人，占76.29；65岁及以上人口为282553人，占9.46。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为3,136,879人<ref>{{cite web |author1=秦皇岛市统计局、秦皇岛市第七次全国人口普查领导小组办公室 |title=秦皇岛市第七次全国人口普查公报 |url=http://www.qhdnews.com/home/details?code=NTE%CE%B3&pcode=NTA%CE%B3&id=47129 |access-date=2023-07-23 |archive-date=2023-07-23 |archive-url=https://web.archive.org/web/20230723205309/http://www.qhdnews.com/home/details?code=NTE%CE%B3&pcode=NTA%CE%B3&id=47129 |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,987,605人相比，十年共增加了149,274人，增长5%，年平均增长率为0.49%。其中，男性人口为1,582,129人，占总人口的50.44%；女性人口为1,554,750人，占总人口的49.56%。总人口性别比（以女性为100）为101.76。0－14岁的人口为475,914人，占总人口的15.17%；15－59岁的人口为1,928,327人，占总人口的61.47%；60岁及以上的人口为732,638人，占总人口的23.36%，其中65岁及以上的人口为509,121人，占总人口的16.23%。居住在城镇的人口为2,006,711人，占总人口的63.97%；居住在乡村的人口为1,130,168人，占总人口的36.03%。

2022年末，全市常住总人口309.81万人，比上年末减少3.62万人。其中，城镇常住人口202.83万人，比上年末减少0.74万人；占总人口比重（常住人口城镇化率）为65.47%，比上年末提高0.52个百分点。<ref>{{Cite web|title=秦皇岛市2022年国民经济和社会发展统计公报 - 中国统计信息网|url=http://www.tjcn.org/tjgb/03hb/37323.html|access-date=2023-07-17|website=www.tjcn.org|archive-date=2023-07-17|archive-url=https://web.archive.org/web/20230717041015/http://www.tjcn.org/tjgb/03hb/37323.html|dead-url=no}}</ref>

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,645,242人，占84.33%；各[[少数民族]]人口为491,637人，占15.67%；其中，[[满族]]人口为464,296人，占14.8%；[[蒙古族]]人口为6,751人，占0.22%；[[回族]]人口为9,230人，占0.29%。与2010年第六次全国人口普查相比，汉族人口增加131,026人，增长5.21%，占总人口比例增加0.17个百分点；各少数民族人口增加18,248人，增长3.85%，占总人口比例下降0.17个百分点。其中，满族人口增加13,123人，增长2.91%，占总人口比例下降0.3个百分点；蒙古族人口增加2,469人，增长57.66%，占总人口比例增加0.07个百分点；回族人口减少240人，下降2.53%，占总人口比例下降0.02个百分点。

== 交通 ==
[[File:Qinhuangdao Railway Station Platforms.jpg|thumb|[[秦皇岛站]][[津秦客运专线|津秦客專]]站台]]
[[File:Beidaihe Railway Station 20090810.jpg|thumb|[[北戴河站]]站台]]
* [[秦皇岛站]]为[[京哈铁路]]、[[大秦铁路]]和[[津山铁路]]的沿线车站，中国首条快速客运专线——[[秦沈客运专线]]起点。该线于2003年10月12日正式运营。2013年12月，[[津秦客运专线]]也投入运营。
* [[北戴河站]]亦是京哈铁路及津秦客运专线的沿线车站。
* {{中国国道名|205}}0公里起点。
* {{中国国道名|228}}过境。
* [[秦皇岛北戴河机场]]位于[[昌黎县]]，于2016年3月31日正式启用。其有来往[[石家庄]]、[[上海市|上海]]、[[重庆市|重庆]]、[[哈尔滨市|哈尔滨]]、[[广州市|广州]]、[[鄂尔多斯市|鄂尔多斯]]的航班<ref>{{Cite web|title=秦皇岛北戴河机场航班信息|url=http://mail.qhd.gov.cn/front_pcthi.do?uuid=9B24943DCC7A7290275BF71268836207}}{{Dead link}}</ref>。
* [[秦皇岛港]]是中国最大的能源输出港口，是中国山西煤炭外运的主要港口之一，是天然不冻良港。

== 旅遊 ==
[[File:Shanhaiguan.jpg|thumb|天下第一关——[[山海关]]]]
著名的旅遊勝地[[北戴河区|北戴河]]、[[南戴河街道|南戴河]]、[[昌黎县|昌黎]][[黄金海岸 (昌黎)|黃金海岸]]和天下第一關[[山海关]]以及青龙满族自治县的祖山自然风景区。

知名的旅游景点有[[山海关|天下第一关]]、[[老龙头]]、[[孟姜女庙]]<ref>{{cite news|url=http://www.nanzao.com/tc/china/44438/si-mian-gong-zi-wei-ji-bei-dai-he-li-zhong-guo-meng-di-yi-bei|title=四面“共”字為基 北戴河立中國夢第一碑|date=2014-12-12|publisher=[[南華早報]]中文版|accessdate=2014-12-13|archivedate=2014-12-19|archiveurl=https://web.archive.org/web/20141219040647/http://www.nanzao.com/tc/china/44438/si-mian-gong-zi-wei-ji-bei-dai-he-li-zhong-guo-meng-di-yi-bei|dead-url=no}}</ref>以及[[北戴河秦行宫遗址|北戴河秦始皇东巡行宫遗址]]等。

秦皇岛野生动物园于1995年开园，是中国第二大野生动物园。
