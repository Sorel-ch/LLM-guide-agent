==概述==
沅陵县位于[[中华人民共和国|中国]][[湖南省]]西部、[[怀化市]]最北部，[[县]]政府驻[[沅陵镇]]。该县为湖南省辖域面积最大的县，总面积为5,825平方公里，是[[湘潭市]]的1.17倍；南北纵贯106.6公里，东西横跨99.5公里。 总人口約为51万人，位居怀化市第三，仅次于鹤城区和溆浦县。“书通二酉”一词典出于境内的大、小酉山。

[[沅江]]由西南入境，向东流入[[常德市]]，最终注入[[洞庭湖]]。其横亘县境中央，将全县分成南、北两部分。由五强溪水电站蓄沅江水形成的[[五强溪水库]]，是湖南第二大水库，更是湖南发电装机最大的水库。沅江以北诸山属[[武陵山脉]]，沅江以南属[[雪峰山脉]]。

得益于其山水格局，沅陵是湖南省水能蕴藏量最丰沛的地区，水资源总量居全省之首。<ref>{{Cite web |title=水利水电 |url=https://www.yuanling.gov.cn/yuanling/c128252/singleArticle2020.shtml |website=沅陵县人民政府 |date=2026-04-08 |language=zh |url-status=live |archive-url=https://web.archive.org/web/20260618215018/https://www.yuanling.gov.cn/yuanling/c128252/singleArticle2020.shtml |archive-date=2026-06-18 |access-date=2026-06-18}}</ref>全县粮食播种面积稳定在66.3万亩以上，为湘西地区重要的粮油生产基地。<ref>{{Cite web |title=2025年度沅陵县农业农村局工作总结 |url=https://www.yuanling.gov.cn/yuanling/c118894/202601/42ed9e760fd244c7988775c53a5a96cb.shtml |website=沅陵县人民政府 |date=2026-01-14 |language=zh |url-status=live |archive-url=https://web.archive.org/web/20260618215450/https://www.yuanling.gov.cn/yuanling/c118894/202601/42ed9e760fd244c7988775c53a5a96cb.shtml |archive-date=2026-06-18 |access-date=2026-06-18}}</ref>山地面积占全县72.7%的地形，虽限制了大规模平原耕作，却促进了山地农业发展。<ref>{{Cite web |title=环境资源 |url=http://www.yuanling.gov.cn/yuanling/c108825/singleArticle2020.shtml |website=沅陵县人民政府 |date=2026-01-12 |language=zh |url-status=live |archive-url=https://web.archive.org/web/20260311133339/http://www.yuanling.gov.cn/yuanling/c108825/singleArticle2020.shtml |archive-date=2026-03-11 |access-date=2026-06-19}}</ref>碣滩茶和官庄毛尖鲜浓甘爽，为湘西茶的主要品种，海拔600米以上的高山[[桃|黄桃]]为水果的代表。中药材种植面积大，被中国林学会认证为“中国[[川黄檗|黄柏]]之乡”。此外，五强溪鱼、大合坪黑猪等也获评了[[国家地理标志产品]]。

早在[[战国]]时期，[[楚国]]便在沅陵设[[黔中郡]]，[[秦始皇]]统一六国后，黔中郡跻身三十六郡之列，城址在沅陵镇黔中郡村（原太常乡窑头村）。传统认为[[西汉|汉]][[汉高祖|高祖]]五年（前202年）始置沅陵县，但里耶秦简的发现表明，早在秦朝沅陵便开启了其两千余年的独立建制史。西汉初年，长沙王子[[吳陽_(西漢)|吴阳]]受封为沅陵顷侯，在此建立侯国。此后，沅陵长期作为郡、州、路、府的治所，是中央政权经略西南的枢纽。[[隋]]开皇九年（589年）改置[[辰州 (隋朝)|辰州]]，治所迁至现址，沅陵作为“辰州”核心的地位进一步巩固。明、清两代，[[辰州府]]统辖沅陵、泸溪、辰溪等县，府治始终设在沅陵，其行政格局延续五百余年。这座古城也因沅水、酉水交汇的水运之利，成为商贸繁盛的“湘西门户”，[[抗日战争]]时期更一度成为湖南省临时省会，享有“小南京”之称。

沅陵工业发端于清末矿冶。抗战时期，湘西电厂等设施的兴建使沅陵成为支撑战时经济的后方工业区。20世纪60年代，一批国防军工企业进驻沅陵的深山如013基地所属军工企业，是国家“[[三线建设]]”在湘西的缩影，虽因时代变迁于80至90年代陆续外迁，却为当地留下了宝贵的工业遗产与技术人才储备。湖南黄金的前身历经从湘西金矿到辰州矿业的改制，从传统矿山成长为全球前列的[[锑]]生产商、国内[[金]]、[[钨]]的主要生产商。<ref>{{Cite web |title=公司简介 |url=https://www.hngoldcorp.com/about/381.html |website=湖南黄金 |date= |language=zh |url-status=live |archive-url= https://web.archive.org/web/20260310034018/http://hngoldcorp.com/about/381.html |archive-date=2026-03-10 |access-date=2026-06-19}}</ref>五强溪水电站作为湖南首座百万千瓦级电站，不仅改写了全省能源格局，更将沅陵的水能优势转化为现实生产力。当前，县域工业以有色冶金、电子信息、清洁能源等为主导，2025工业总产值约为340亿元<ref>{{Cite web |title= 沅陵县发展和改革局2025年度工作总结 |url= https://www.yuanling.gov.cn/yuanling/c118803/202601/d33ee1cad4274e5ab86ac02ae35d9cfb.shtml |website=沅陵县人民政府 |date= 2026-01-21 |language=zh |url-status=live |archive-url= https://web.archive.org/web/20260619110037/https://www.yuanling.gov.cn/yuanling/c118803/202601/d33ee1cad4274e5ab86ac02ae35d9cfb.shtml |archive-date=2026-06-19 |access-date=2026-06-19}}</ref>，工业增加值74.64亿元，占全年GDP的33%<ref>{{Cite web |title= 沅陵县2025年国民经济和社会发展统计公报 |url= https://www.yuanling.gov.cn/yuanling/c108869/202604/48d5d42998fd444887013a5eb5cbe4f7.shtml |website=沅陵县人民政府 |date= 2026-04-30 |language=zh |url-status=live |archive-url= https://web.archive.org/web/20260619111618/https://www.yuanling.gov.cn/yuanling/c108869/202604/48d5d42998fd444887013a5eb5cbe4f7.shtml |archive-date=2026-06-19 |access-date=2026-06-19}}</ref>。

历史上，沅陵为[[大湘西]]的水运中心。现代，沅陵是连接湘西北和湘北的重要公路枢纽，[[G56|G56（杭瑞高速）]]和[[G319|G319（高成公路]]）均贯穿沅陵。此外还有[[G59|G59（呼北高速）]]、[[G241|G241（呼北公路）]]过境东部，北通张家界，南达安化、邵阳。

==历史沿革==
===石器时代===
约20万年前的[[旧石器时期]]，沅陵所在的沅水流域已有古人类存在。

[[新石器时期]]，沅陵属于[[高庙遗址|高庙文化]]区，县境周边有泸溪下湾遗址。该文化与[[三苗]]族群紧密相关，以[[白陶]]、凤纹而闻名，为中华文明的重要起源。
===先秦时期===
沅陵及周边地区是[[百濮]]的核心聚居地。<ref>{{Cite web |title=武陵地区土著濮人源流考证 |url=https://mzj.zjj.gov.cn/c6844/20171020/i318284.html |website=张家界市民委（市宗教局） |date=2013-06-14 |language=zh |url-status=live |quote=清代王鸣盛《尚书·后案》曰：“湖南辰州（府）实古濮人地。”近代民族学家吕思勉在《中国民族史》一书说：“所谓黔中郡，疑亦濮族之地。”现代学者田曙岚在《论濮僚与仡佬的相互关系》一文中明确指出：“湘西丘陵地实为古卜人或濮人宅住地。”}}</ref>百濮曾在[[商朝]]末年和[[庸国|庸]]、[[古蜀|蜀]]等部族联合，作为[[周武王]]伐[[纣]]的联军参加[[牧野之战]]。

[[周桓王]]十六年（公元前704年），[[楚武王]]“始开濮地而有之”，百濮部落的活动区域开始被[[楚国]]正式纳入版图。<ref>{{cite wikisource |title=史記/卷040 |wslanguage=zh |quote=於是始開濮地而有之。}}</ref>

此后，来自中原的楚国逐渐占有了百濮地区。至[[春秋时期]]，沅陵已属楚巫中地。公元前4世纪左右，楚国在沅陵设立了[[黔中郡]]。

[[战国]]中后期，黔中郡于秦楚间几经易手。[[周慎靓王]]五年（公元前316年），秦将[[司马错]]借灭蜀之势首次自楚夺取黔中，设置秦黔中郡<ref>{{cite wikisource |title=華陽國志/卷一 |wslanguage=zh |quote=儀城江州。司馬錯自巴涪水，取楚商於地，為黔中郡。}}</ref>（一说在[[周赧王]]七年（公元前308年）<ref>{{cite wikisource |title=華陽國志/卷三 |wslanguage=zh |quote=七年，封〔公〕子惲為蜀侯。司馬錯率巴、蜀眾十萬，大舶船萬艘，米六百萬斛，浮江伐楚，取商於之地，為黔中郡。}}</ref>）。之后楚国夺回。周赧王三十五年（公元前280年），司马错再次攻占黔中。<ref>{{cite wikisource |title=史記/卷005 |wslanguage=zh |quote=二十七年，錯攻楚。赦罪人遷之南陽。白起攻趙，取代光狼城。又使司馬錯發隴西，因蜀攻楚黔中，拔之。}}</ref>此后不久，黔中郡又归于楚国控制。周赧王三十八年（公元前277年），秦国蜀守[[张若]]复攻取楚国的巫郡和黔中郡。<ref>{{cite wikisource |title=史記/卷005 |wslanguage=zh |quote=三十年，蜀守若伐楚，取巫郡，及江南為黔中郡。}}</ref>次年（前276年）楚国发起反击，成功收复了被秦军占领的“江旁十五邑”。<ref>{{cite wikisource |title=史記/卷040 |wslanguage=zh |quote=二十三年，襄王乃收東地兵，得十餘萬，復西取秦所拔我江旁十五邑以爲郡，距秦。}}</ref>

===秦汉时期===
秦汉时期，沅陵作为当时沟通中原与[[西南夷]]的水上重镇，中央对其的经略不断加深，不仅建立城池，还一度设立封国。但因周围武陵蛮的客观威胁，沅陵在经济文化方面始终未能同中原一样稳定发展。

====秦代归于一统====
秦王[[嬴政|政]]二十四年（公元前223年），秦国攻灭楚国，沅陵所在区域彻底结束了作为楚国西部边陲、反复被秦楚争夺的拉锯状态，正式成为统一[[秦帝国]]的一部分。

传统说法认为，沅陵在秦朝属[[三十六郡]]之一的[[黔中郡]]，《括地志》记载“黔中故城在辰州沅陵县西二十里”。根据2001年由[[中国科学院|中科院]]长沙土地构造研究所和湖南考古研究所人员组成的专家组的调查和测试，其初步确认位于沅陵县城南窑头村的古遗址，就是秦代古黔中郡故城遗址。<ref>{{cite web |title=夜郎国，你在哪里 |url=https://www.cctv.com/geography/news/20021016/3.html |website=央视网 |language=zh}}</ref>2002年[[里耶秦简]]的出土，使传统说法开始面临争议。简文明确记载沅陵、迁陵、临沅、酉阳等沅水、澧水流域的县，均属“[[洞庭郡]]”管辖。新说认为秦朝在沅陵所在的沅水流域推行的是“洞庭郡”建制，沅陵属秦洞庭郡下辖县，而“黔中郡”一名，在此区域不再使用。<ref>{{cite web |title=秦王朝不存在“黔中郡” |url=https://zqb.cyol.com/content/2002-07/18/content_494341.htm |website=中国青年网 |language=zh |date=2002-7-18}}</ref>'''这也是“沅陵”之名首次见诸世间。'''

====西汉建制与侯国====
[[汉高祖]]五年（公元前202年），[[西汉|汉朝]]对秦朝的郡县体制进行了调整：将秦朝的洞庭郡改制为[[武陵郡]]，沅陵县即隶属于武陵郡。<ref>{{cite wikisource |title=後漢書/卷112 |wslanguage=zh |quote=武陵郡，秦昭王置。名黔中郡，高帝五年更名。}}</ref>原一般认为这代表“沅陵”之名首次出现在历史上，但这一说法被里耶秦简的发现推翻。

汉[[高后]]元年（前187年）封[[长沙王]][[吳臣_(西漢)|吴臣]]之子[[吴阳 (西汉)|吴阳]]为沅陵顷侯。<ref>{{cite wikisource |title=史記/卷019 |wslanguage=zh |quote=沅陵。	長沙嗣成王子，侯。	八。元年十一月壬申，頃侯吳陽元年。}}</ref>吴阳时期，沅陵人口6481人，分六乡：都乡、黔梁乡、庑乡、郪乡、武春乡、平阿乡。<ref>{{cite web |author1=楊先雲 |title=虎溪山漢簡《計簿》所載沅陵侯國 |url=http://m.bsm.org.cn/?hanjian/8349.html |website=武漢大學簡帛研究中心 |language=zh |date=2021-03-01 |url-status=live}}</ref>他的陵墓——[[虎溪山一号汉墓]]出土文物众多，其中《美食方》是现存最早的西汉饮食文献，《计簿》是迄今所见最早的西汉侯国“黄簿”实物，详细记载当时沅陵行政统计信息。<ref>{{cite web |title=中国考古百年 &#124;20年多前的虎溪山一号汉墓发掘往事 |url=https://www.silkroads.org.cn/portal.php?mod=view&aid=40192 |website=丝绸之路世界遗产 |language=zh |date=2021-3-9 |url-status=live}}</ref>沅陵侯国共历经三代沅陵侯，共历时约46年，因末代哀侯[[吴周 (西汉)|吴周]]无子而被撤销。<ref>{{cite wikisource |title=史記/卷019 |wslanguage=zh |quote=十一。亖。中五年，哀侯周元年。後三年，侯周薨，無後，國除。}}</ref>

[[新莽]]时，天下地名大都为[[王莽]]所改，沅陵县改为沅陆县，其上级武陵郡改为建平郡。<ref>{{cite wikisource |title=漢書顏師古註/地理志 |wslanguage=zh |quote=武陵郡，高帝置。莽曰建平。屬荊州。……沅陵，莽曰沅陸。}}</ref>新莽灭亡后均恢复原名。

====东汉征讨与羁縻====
{{See also|相单程|马援|詹山}}

[[东汉]]时，沅陵县属[[荊州刺史部|荆州]][[武陵郡]]。
[[光武帝]][[建武 (东汉)|建武]]二十三年（公元47年），武陵郡精夫[[相单程]]率众起义，很快攻占了多个县城，当地各族民众纷纷响应。[[刘秀]]派武威将军[[刘尚]]率领一万余人前去镇压。<ref>{{cite wikisource |title=後漢書/卷24 |wslanguage=zh |quote=建武二十三年，精夫相單程等據其險隘，大寇郡縣。遣武威將軍劉尙發南郡、長沙、武陵兵萬餘人，乘船溯沅水，入武谿擊之。尙輕敵入險，山深水疾，舟船不得上。蠻氏知尙糧少入遠，又不曉道徑，遂屯聚守險。尙食盡引還，蠻緣路徼戰，尙軍大敗，悉爲所沒。}}</ref>建武二十五年（公元49年），因相单程初步取胜，朝廷镇压失利，“伏波将军”[[马援]]率领大军前来征讨。马援大军在[[壶头山]]一带与相单程军对峙。相军凭借[[清浪滩]]等天险据守，让马援大军难以推进，且时值酷暑，汉军中瘟疫流行。<ref>{{cite wikisource |title=後漢書/卷24 |wslanguage=zh |quote=三月，進營壺頭。賊乘高守隘，水疾，船不得上。會暑甚，士卒多疫死，援亦中病，遂困，乃穿岸爲室，以避炎氣。賊每升險鼓噪，援輒曳足以觀之，左右哀其壯意，莫不爲之流涕。}}</ref>同年，主将马援也病逝军中。最终，[[监军]][[宗均]]设法用[[矫诏]]招降相单程（一说相被宗均设计诱杀）。<ref>{{cite wikisource |title=後漢書/卷86 |wslanguage=zh |quote=二十四年，相單程等下攻臨沅，遣謁者李嵩、中山太守馬成擊之，不能克。明年春，遣伏波將軍馬援、中郎將劉匡、馬武、孫永等，將兵至臨沅，擊破之。單程等飢困乞降，會援病卒，謁者宗均聽悉受降。}}</ref><ref name=":0">{{cite web |title=历史沿革（总） |url=http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |website=沅陵县人民政府 |archiveurl=https://web.archive.org/web/20260710094951/http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |archivedate=2026-7-10 |language=zh |date=2010-05-25 |quote= |url-status=live}}</ref>此后东汉朝廷对武陵蛮的统治策略逐渐由军事镇压转向[[羁縻]]安抚。

元嘉元年（151）七月，土著人[[詹山]]率4000余人举事，占领当地城市，“拘执县令，屯结深山，焚毁税册”。桓帝[[刘志]]派窦应明“征剿”，在酉水口下筑城屯兵，后称窦应明城。<ref>{{cite web |title=历史沿革（总） |url=http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |website=沅陵县人民政府 |accessdate=2026-07-10 |archiveurl=https://web.archive.org/web/20260710094951/http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |archivedate=2026-7-10 |date=2010-05-25}}</ref>

[[吕种]]被宋均任命为沅陵长，此后重新建立行政管理系统，任命和配置了官员，将苗民编户齐民，同时兴办官学，在地方推行儒家文化教育。<ref>{{cite wikisource |title=後漢書/卷41 |wslanguage=zh |quote=乃矯製調伏波司馬呂種守沅陵長，命種奉詔書入虜營，告以恩信，因勒兵隨其後。蠻夷震怖，即共斬其大帥而降，於是入賊營，散其眾，遣歸本郡，為置長吏而還。}}</ref>

东汉末年，汉朝中央失去对地方的控制。沅陵所在的武陵郡名义上归属[[刘表]]，实际控制力极弱。当地部族势力趁机坐大，在“五溪”各流域形成了较为独立的军事力量。

===魏晋南北朝时期===
该时期沅陵因地处西南，较少被大规模的长期战乱波及，得到了和平发展的机会。在这一时期沅陵的行政地位开始上升，最终奠定了近两千年的作为州府中心与中央王朝经略西南桥头堡的格局。

====三国两晋间易主====
[[建安 (东汉)|建安]]十三年（208年），[[刘表]]去世，荆州内部权利真空。[[赤壁之战]]后，[[刘备]]收取了武陵郡<ref>{{cite wikisource |title=三國志/卷32 |wslanguage=zh |quote=先主表琦為荊州刺史，又南征四郡。武陵太守金旋、長沙太守韓玄、桂陽太守趙範、零陵太守劉度皆降。}}</ref>，沅陵处于刘备方面控制，建安二十年（215年）的湘水划界更是确认了其控制权。<ref>{{cite wikisource |title=三國志/卷32 |wslanguage=zh |quote=先主聞之，與權連和，分荊州、江夏、長沙、桂陽東屬，南郡、零陵、武陵西屬，引軍還江州。}}</ref>但同年去世的[[黄盖]]生前亦有作为太守抵御武陵蛮的记录<ref>{{cite wikisource |title=三國志/卷55 |wslanguage=zh |quote=武陵蛮夷反乱，攻守城邑，乃以盖领太守。}}</ref>，说明[[孙权]]此前可能也对沅陵等县有过管辖。此后，[[孫吳|东吴]]在[[樊城之战]]和[[夷陵之战]]中巩固了对荆州的统治，沅陵在这一过程中由属蜀转为属吴。

吴末，析沅陵、[[零阳县]]地置黚阳县（即阳县）<ref>{{cite web |title=历史沿革（总） |url=https://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |website=沅陵县人民政府 |accessdate=2026-07-25 |archiveurl=https://web.archive.org/web/20260713191035/https://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |archivedate=2026-7-13 |language=zh |date=2010-05-25 |quote=吴末，析沅陵、零阳县地置即 阳县。 |url-status=live}}</ref>，该县后续沿革不详。[[西晋|晋]]灭吴后，沅陵归属未变，仍属[[荆州_(古代)|荆州]]武陵郡或[[武陵国]]，[[东晋]]亦同。

三国两晋时期，沅陵一带武陵蛮起义仍时有发生。东吴[[黄龙_(孙吴)|黄龙]]三年（231年），[[太常]][[潘承明]]奉命督军五万平定五溪地区人民的抗吴斗争，于军驻地酉水口（今城西太常）筑垒，历时四年，俘斩数万人。<ref>{{cite wikisource |title=三國志/卷47 |wslanguage=zh |quote=三年春二月，遣太常潘濬率眾五萬，討武陵蠻夷。……冬十一月，太常潘濬平武陵蠻夷，事畢，還武昌。}}</ref><ref>{{cite wikisource |title=水經注/37 |wslanguage=zh |quote=酉水又東逕沅陵縣北，又東南逕潘承明壘西，承明討五溪蠻，營軍所築也。其城跨山枕谷。}}</ref><ref>{{cite web |title=历史沿革（总） |url=http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |website=沅陵县人民政府 |accessdate=2026-07-25 |archiveurl=https://web.archive.org/web/20260710094951/http://www.yuanling.gov.cn/yuanling/c108828/201005/6df895d5cb704cf49210ed16c4cb141c.shtml |archivedate=2026-7-10 |language=zh |date=2010-05-25 |quote=黄龙三年(231)  二月，太常潘承明奉命督军五万镇压五溪地区人民的抗吴斗争，军驻酉水口(今太常乡)筑垒，反复攻击、杀掠，历时4年，俘斩数万人。 |url-status=live}}</ref>此外，武陵地区其它起义也不同程度上影响了沅陵。

====南朝地位上升====
[[刘宋]]时新置[[郢州_(刘宋)|郢州]]，沅陵县即属郢州武陵郡。<ref>{{cite wikisource |title=宋書/卷37 |wslanguage=zh |quote=孝武孝建元年，分荊州之江夏、竟陵、隨、武陵、天門，湘州之巴陵，江州之武昌，豫州之西陽，又以南郡之州陵、監利二縣度屬巴陵，立郢州……武陵太守，前漢地理志，高帝立。續漢郡國志雲，秦昭王立，名黔中郡，高帝五年更名。本屬荊州。領縣十……沅陵令，漢舊縣。}}</ref>[[南齐]]时武陵人[[黄闵]]著《武陵记》《沅陵记》等[[地方志|地志]]，记载了沅陵及周边的地理环境，后大都散佚。<ref>{{Cite book |title=漢唐地理書鈔 |author=王謨 |publisher=[[中華書局]] |location=北京 |year=1961 |isbn=978-7-101-05070-7 |page=358-361,439 |language=zh |quote=是黄閏旣爲武陵郡記，又爲沅陵縣記，如廣記引黄閏沅川記，當别爲一書，不可謂卽武陵記也。沅川蓋卽沅陵。}}</ref><ref>{{Cite news |title=穿越时空 揭秘沅陵 |url=http://paper.0745news.cn/hhrbpc/202310/06/c138403.html |author=周万水 |work=懷化日報 |date=2023-10-06 |issue=10987 |publication-place=懷化 |page=3 |department=文化 |language=zh |quote=南北朝时，武陵人黄闵曾撰写过一本《沅陵记》，书中详述了沅陵的人文、地理和世俗风貌。 |access-date=2026-08-11 |url-status=live}}</ref>在《[[南齐书]]·卷十五·志第七·州郡下》中，武陵郡的诸县首书为沅陵，表明此时沅陵可能已成为武陵郡治，反映沅陵在南朝经略西南的地位日渐重要。

[[南梁]]时，置武陵[[都尉]]府于沅陵。<ref name=":0" />[[天监]]十年（511年），析沅陵县置[[侨县]]夜郎县{{NoteTag|一说夜郎县在太清年间设立}}（今[[吉首市]]）及[[侨州]]卢州（今[[泸溪]]、[[花垣县]]地），以安置西南、北方沦陷地的流民。<ref>{{cite wikisource |title=元和郡縣圖志/卷30 |wslanguage=zh |quote=本漢沅陵縣地。梁天監十年置盧州}}</ref>[[太清 (年號)|太清]]四年（550年），自荆州、郢州析置[[武州_(南梁)|武州]]，沅陵属武州武陵郡。

[[南陈]]时，两个侨置州县{{NoteTag|指南梁设立的卢州和夜郎县}}又撤销，复并入沅陵县。<ref name=":0" /><ref name=":1">{{Cite book |title=湖南通誌 |url=https://www.shidianguji.com/book/NLG312001076076/chapter/1ljw3zqvpgx0b?page_from=M_search_page&paragraphId=7575165307841511474&search_mode=content&keywords=%25E5%25BB%25A2%2C%25E5%25BB%25A2%25E7%259B%25A7%25E5%25B7%259E%2C%25E7%259B%25A7&version=12&theme=orange |author=李瀚章 |author2=裕祿 |author3=卞宝第 |author4=庞际云 |publisher=岳麓书社 |location=長沙 |year=2009 |isbn=978-7-80729-701-7 |language=zh |editor=曾国荃 |editor2=郭嵩焘 |editor3=李元度 |quote=沅陵郡、太建七年，通寧郡，改廢盧州入之，領縣五。}}</ref>[[天嘉]]元年（560年），县改属新设的武州[[通宁郡]]{{NoteTag|一说“沅州通宁郡”，但两者其实并未共存过，这里认为是一种追溯性称呼}}，同时成为该郡郡治。[[太建]]七年（575年），改武州为[[沅州 (南陈)|沅州]]，通宁郡为[[沅陵郡]]，州治由临沅（今[[常德]]）移治沅陵。<ref name=":1" />[[至德_(南朝陈)|至德]]元年（583年），[[陈叔宝]]封其弟[[陈叔兴]]为沅陵郡王，直至陈亡。<ref>{{cite wikisource |title=陳書/卷28 |wslanguage=zh |quote=沅陵王叔興字子推，高宗第二十六子也。至德元年，立為沅陵王。禎明三年入關。隋大業中為給事郎。}}</ref>沅陵在数十年间由普通县变为州郡治所，并在此后两千年长期保持其政治地位。

沅陵上级政区在南朝不断细化正是南方得到开发在政区上的体现，也表明南朝的偏安一隅使其被迫精细经营其仅剩的控制区。而沅陵政治地位的不断上升，表明沅陵作为攻略西南水陆要塞的区位受到朝廷重视，也为其此后的繁荣奠定了基础。

===隋唐五代时期===
隋[[开皇]]九年(589年)，改置辰州，治沅陵。[[大业]]二年(606年)，复改辰州为沅陵郡，隶[[荆州 (古代)|荆州]]。唐[[武德]]二年(619年)，沅陵郡改为[[辰州 (隋朝)|辰州]]，县属辰州。唐[[貞觀 (唐朝)|贞观]]元年(627年)，分天下为10道，县属辰州，隶[[江南道]]。[[开元]]二十一年(733年)分天下为15道，县属辰州，隶黔中道。
===宋元时期===
宋隶[[荆湖北路]]。元改辰州为辰州路，治沅陵，隶湖广行中书省。
===明清时期===
明县属辰州府，隶[[湖广布政使司]]。清县仍属辰州府，隶[[辰沅永靖道]]。
===中华民国时期===
民国元年(1912年)，废沅陵县存辰州府，府仅辖沅陵县地。3年裁府恢复沅陵县，属辰沅道。 民国24年7月，设湘西绥靖处于沅陵。辖19县。
===中华人民共和国时期===
1950年1月1日，湖南省临时人民政府在沅陵设置湘西行政公署，辖沅陵、[[会同]]、[[永顺]]3个专区，县属沅陵专区。1952年8月，撤销湘西行政公署及其所辖 3个专区，沅陵县改属[[芷江专区]]。12月，芷江专区迁驻黔阳县[[安江]]镇，改名黔阳专区，县属黔阳专区。1968年，黔阳专区改称黔阳地区，1981年，黔阳地区改称[[怀化地区]]，县属怀化地区，1997年改属[[怀化市]]至今。

== 地理==
沅陵县被北部的武陵山脉与南境的雪峰山脉包夹，中部海拔300至800米的低山丘陵连绵起伏，[[喀斯特地貌]]（如溶洞、天坑）随处可见，还有沿沅江分布的狭长河谷平原，由沅江及其支流冲积而成。沅陵县城位于沅江与酉水交汇处的平地。在该县东南部，面积广阔的[[五强溪水库]]，是湖南省最大的人工湖之一。

主要山峰包括圣人山（海拔1,355.3米）和锅锅垴（海拔1,294.0米），分属雪峰山、武陵山；主要河流包括沅江、酉水、怡溪、朱红溪。借母溪国家级自然保护区内溪流纵横，是沅陵重要的生态屏障。

沅陵县东与[[桃源縣|桃源]]、[[安化]]相连，南与[[溆浦]]、[[辰溪]]接壤，西与[[泸溪]]、[[古丈]]、[[永顺县|永顺]]毗邻，北与[[张家界市]]交界。

== 饮食文化 ==
沅陵粉当属湖南小吃一绝，而[[米粉]]中当以猪脚粉为主打，其由米粉和特制猪脚而成，是当地人过早的主选食物。现今已有以“三鲜”“牛肉”“猪肚子”“饼饼肉”等带有地方特色的佐料的其它米粉。沅陵小吃诸如“猪脚粉”之类的早点，只有在上午11点左右之前才有供应，商家并不会因为生意好而在其它时间段进行供应，所以因此而形成了沅陵特有的早餐文化。因为沅陵交通不便原因，许多古老、优秀的文化没有得到发扬光大，{{POV-statement|所以也只有当地人才能享受如此的人间美味}}。
