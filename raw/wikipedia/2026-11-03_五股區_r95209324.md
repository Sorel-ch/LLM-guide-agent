'''五股區'''，舊稱「五穀坑」，前身「五股鄉」<ref name="地方沿革">{{cite web |url=https://www.wugu.ntpc.gov.tw/home.jsp?id=9a82909484ee3b60 |title=認識五股-地方沿革 |access-date=2025-01-03 |publisher=新北市五股區公所 |language=zh-tw |archive-date=2024-09-18 |archive-url=https://web.archive.org/web/20240918045300/https://www.wugu.ntpc.gov.tw/home.jsp?id=9a82909484ee3b60 |dead-url=no }}</ref>，位於[[臺灣]][[新北市]]西北部，[[臺北盆地]]西部地帶，東以[[淡水河]]與[[臺北市]]相隔，北有[[觀音山 (新北市)|觀音山]]{{sfn|施添福|2013|p=405}}。曾為[[臺北州]][[新莊郡]][[五股庄|五股-{庄}-]]、[[臺北縣]]新莊區五股鄉及縣直轄五股鄉，[[2010年中華民國縣市改制直轄市|五都改制]]後改隸新北市，為「五股區」<ref name="地方沿革"/>。

自1984年五股工業區（今[[新北產業園區]]）成立後，成為[[臺北都會區]]重要的綜合工業區，使其產業特色為二級產業。商業活動主要集中在成泰路一帶，擁有政事、醫療、文教等機構分布，亦為五股區的人口主要分布地區{{sfn|施添福|2013|p=409}}。觀音山地區則以農業為主，最主要生產蔬菜與綠竹筍，並以綠竹筍發展當地的特色產業{{sfn|施添福|2013|p=410}}。

== 歷史 ==
「五股」原名為「五榖坑」，根據一紙清治乾隆年代的契約，經輔大歷史系教授尹章義研考解讀，出自乾隆三十八年正月「劉伴郎退還田契字」契約，記載「興直山下外-{庄}-五榖坑口」明確的指出五股坑原名為「五榖坑」。<ref group="註">歷史學者尹章義的考據，「五股」名稱的由來，是[[平埔族]]在此耕作，希望「五穀」豐收。</ref>，[[台灣清治時代|清治]][[道光]]年間，[[臺灣閩南人]]、[[客家人]]逐漸遷入，「五榖坑」即簡化為「五-{谷}-坑」再轉音為「五股坑」。[[台灣日治時期|日治時期]]，又簡化稱之為「五股」。清治乾隆32年初，設置八里坌巡檢，五股坑區、八里坌、貴子坑區等隸屬巡檢管轄。

清治光緒20年（1894年），[[甲午戰爭]]之後，簽立[[馬關條約]]，進入[[臺灣日治時期]]，明治28年（1895年）日人施行地方官判，台北縣置支廳、五股隸屬滬尾(淡水)辦務署，1920年7月26日，臺灣地方行政制度改革，廢廳設州，州下設郡、市，郡下設街、-{庄}-{{r|續修鄉志第壹篇|p=74}}。10月1日，實施新州制與市街-{庄}-制，[[五股庄|五股-{庄}-]]屬[[臺北州]][[新莊郡]]。五股-{庄}-分為觀音坑、洲子、成子寮、五股坑、石土地公、水碓、更寮、新塭等8個大字{{r|續修鄉志第壹篇|p=75}}。

[[二戰]]後的1945年10月25日，臺灣進入[[臺灣戰後時期|中華民國時期]]。1946年1月16日，五股-{庄}-改為「五股鄉」，屬[[臺北縣]]新莊區（[[縣轄區 (中華民國)|縣轄區]]）。五股鄉轄興珍村、更寮村、竹華村、洲後村、集福村、觀音村、成州村、五龍村、五股村、德音村等10個村。1950年8月16日，調整行政區域並裁撤新莊區，五股鄉改由臺北縣直轄{{r|續修鄉志第壹篇|p=75}}。之後境內村數歷經7次變更，至2010年為止，五股鄉共轄20個村{{r|續修鄉志第壹篇|pp=75－76}}。2010年12月25日，配合[[2010年中華民國縣市改制直轄市|臺北縣改制為直轄市新北市]]，五股鄉改制為「五股區」<ref>{{Cite web |url=https://www.wugu.ntpc.gov.tw/home.jsp?id=c94a1cc307126238 |title=認識五股-地方沿革 |publisher=新北市五股區公所 |access-date=2022-11-02 |language=zh-tw |archive-date=2022-11-02 |archive-url=https://web.archive.org/web/20221102145254/https://www.wugu.ntpc.gov.tw/home.jsp?id=c94a1cc307126238 |dead-url=no }}</ref>。

== 地理 ==
=== 位置 ===
五股區位於新北市西北部，[[台北盆地]]的西部，東接[[蘆洲區]]，西連[[林口區]]，南接[[泰山區 (台灣)|泰山區]]，北以[[觀音山 (新北市)|觀音山]]與[[八里區]]為鄰，東南與[[三重區|三重]]、[[新莊區|新莊]]兩區相接，東北則以[[淡水河]]為天然界線與[[臺北市]][[北投區]]相隔{{R|續修鄉志第壹篇|p=25}}。

現今五股區行政範圍的確立，來自於1920年10月1日，日本將臺灣十二廳改為五州二廳，設五股-{庄}-屬臺北州新莊郡{{r|五股志第三篇|p=138}}。五股-{庄}-轄觀音坑、洲子、成子寮、五股坑、石土地公、水碓、更寮、新塭等8個大字{{r|五股志第三篇|p=139}}。1946年1月16日，改為「五股鄉」，屬臺北縣新莊區{{r|五股志第三篇|p=172}}。1950年8月16日，裁撤區署，五股鄉改直隸於臺北縣{{r|五股志第三篇|p=173}}。2010年12月25日，臺北縣改制為直轄市，五股鄉改制為市轄區「五股區」，隸屬新北市{{r|續修鄉志第參篇|p=144}}。五股區的行政區劃轄有五龍里、更寮里、貿商里、興珍里、成泰里、民義里、五福里、五股里、成德里、成州里、芳洲里<ref>{{Cite web |url=https://www.wugu.ntpc.gov.tw/home.jsp?id=eb99d34af4f4ff80&act=be4f48068b2b0031&dataserno=f825b9ecf3a84dc29f4449d575d1344f&mserno=be3fddfc5a7df5b3276c93ebdc12dd83 |title=公告-本區行政區域調整新舊里鄰門牌對照查詢 (115年7月1日生效，依調整前排序) |publisher=新北市五股區公所}}</ref>、成功里、六福里、德音里、陸一里、徳泰里、福德里、集賢里、水碓里、集福里、觀音里等21里，共計515鄰<ref>{{Cite web |url=https://www.wugu.ntpc.gov.tw/home.jsp?id=ae9453d8ad824ee8 |title=鄰里資訊-各里概況 |publisher=新北市五股區公所 |access-date=2022-10-28 |language=zh-tw |archive-date=2022-10-28 |archive-url=https://web.archive.org/web/20221028132414/https://www.wugu.ntpc.gov.tw/home.jsp?id=ae9453d8ad824ee8 |dead-url=no }}</ref>。

== 產業 ==
五股是新北市乃至於整個大台北地區主要的[[工業區]]之一，區內大型工廠有臺灣理研公司、萬源紡織廠，規模甚大員工達數百人；次為泰山、盛泰、泰源染整印花廠及福太洋傘關係企業、獅子油脂公司等。因新北產業園區的闢建，大小工廠、公司行號已達千餘家，使五股區朝向以工商業為主流導向的轉型期發展。

中興路一段設有「大都市科學園區」<ref>{{Cite web |url=https://www.cfgis.ntpc.gov.tw/ntland/InduPark/Com.aspx?dist=%E4%B8%89%E9%87%8D%E5%8D%80&park=%E4%B8%AD%E6%AD%A3%E5%8C%97%E8%B7%AF%E5%B7%A5%E6%A5%AD%E5%8D%80&com=%E5%A4%A7%E9%83%BD%E5%B8%82%E7%A7%91%E5%AD%B8%E5%9C%92%E5%8D%80 |title=大樓資訊 |access-date=2016-05-21 |archive-url=https://web.archive.org/web/20170222064725/https://www.cfgis.ntpc.gov.tw/ntland/InduPark/Com.aspx?dist=%E4%B8%89%E9%87%8D%E5%8D%80&park=%E4%B8%AD%E6%AD%A3%E5%8C%97%E8%B7%AF%E5%B7%A5%E6%A5%AD%E5%8D%80&com=%E5%A4%A7%E9%83%BD%E5%B8%82%E7%A7%91%E5%AD%B8%E5%9C%92%E5%8D%80 |archive-date=2017-02-22 |dead-url=yes }}</ref>。

五股的農業以聞名全台灣之綠竹筍（俗稱觀音筍）為最大宗，清甜脆嫩、聞名遐邇，為五股之特產，亦為五股農民的主要收入之一。

=== 國道與快速公路 ===
[[中山高速公路|國道一號（中山高速公路）]]是台灣第一條高速公路，大致以北北東—南南西走向蜿蜒經過五股區東南部，並在新五路交會處設有[[五股交流道]]。

[[汐止五股高架道路]]是與國道一號並行且位於其兩側之高架道路，南下方向可直接銜接[[五股楊梅高架道路]]，亦可經[[五股轉接道]]連接國道一號平面車道與五股交流道。

省道[[台64線]]又稱「東西向快速公路八里新店線」，自五股區西北部的觀音山隧道入區境後沿[[觀音坑溪]]谷地而行，至五股區東北部的[[淡水河]]西岸地帶轉向南沿[[二重疏洪道]]西側而行，最終於五股區東南端出區境。在五股區內設有觀音山交流道、五股一交流道、五股二交流道，後者設有連絡道可直接連接國道一號的五股交流道。

省道[[台65線]]是五股－土城的快速公路，又稱「新北市特二號道路」，其五股端交流道位於五股區西南端，可銜接新五路、國道一號的汐止五股高架道路或經由連絡道銜接省道台64線五股二交流道，亦可經由此線至土城端銜接[[福爾摩沙高速公路|國道三號]]。

== 近年及未來開發 ==
=== 水碓重劃區 ===
90年推出，總銷達25億、規劃650戶的當地指標大案，麗寶機構「阿亮的家」，就位於五股區內、德音國小附近。不過五股區名喚重劃區，腹地卻有限，又沒有足夠吸引大量區外客的條件，因此大規模個案在五股區推出，自然需要更多的時間消化，後來幾年五股區房市轉趨平淡。近年再沒有較大規模的個案出現，推案算是零星，且多為在地小建商投資興建的透天案，客源則算是分散，畢竟透天總價相對較高。

=== 五股洲子洋重劃區 ===
{{main|洲子洋重劃區}}
[[洲子洋重劃區]]位五股都市計劃北側，是五股區自一級洪水平原管制解禁後，第一個市地重劃區。範圍南自五股坑溪、中興路，北至觀音坑溪，東鄰疏洪堤防，西以成泰路為界，全區和五股都市計劃類似，也呈狹長型，占地約52公頃，是全台現今面積最大的民間自辦重劃區。五股洲子洋重劃區緊鄰424公頃的大台北都會公園，主打著1高2快3捷、台北車站10分鐘以及低房價等交通和價錢優勢，吸引許多建商和買家的進入。

=== 五股新市鎮 ===
五股新市鎮實施範圍為中山高速公路以北、五股坑溪以南、二重疏洪道以西，與林口台地間之淡水河左岸沖積平原，總面積逾200公頃。洲子洋重劃區南邊至五股工業區的一整片區塊。根據該計畫，這塊新市鎮將以『城市之心，天空之城』，也就是鎖定高產值、低污染之產業主軸(IT都市消費服務倉儲零售及生鮮業)，再搭配右側二重疏洪道都會親水公園，與北側台北港(特定區)、南邊新莊副都心(行政中心)連成一氣，成為一兼具物流、都市消費及綠色產業環的發展廊帶。目前正研議改採「低度開發」模式，將該處的住宅區、商業區，從25％左右降低到5％以下；並同步將產專區、道路公園等設施比例拉高，規畫成「產業專用園區」，大幅降低廢土處理費，也加快開發時程。整個計畫目前正在環評階段，預計最快2022年完成開發，為新北市升格、朱立倫上任後的重點開發擘劃之一。
