'''遂宁市'''（[[四川话]][[四川话拼音|拼音]]：Xu<sup>4</sup>lin<sup>2</sup>；[[国际音标]]：{{IPA|[ɕy<sup>24</sup>nin<sup>21</sup>]}}）是[[中华人民共和国]][[四川省]]下辖的[[地级市]]，位于四川省东部。市境东临[[广安市]]、[[南充市]]，北界[[绵阳市]]，西接[[德阳市]]，南邻[[资阳市]]、[[重庆市]]。地处[[四川盆地]]中部丘陵区，[[涪江]]自北往南纵贯市境，与[[梓江]]、[[蓬溪河]]、[[郪江]]等河流汇合。全市总面积5,322平方公里，人口329万，市人民政府驻[[船山区]]。遂宁是全省[[纺织品]]和[[食品工业]]的重要基地，素有“东川巨邑”、“川中重镇”之称。亦相传因[[五代]][[后唐]]时于此地修建的城池形状如古代的斗，故遂宁別称“'''斗城'''”。

== 历史 ==
=== 古巴蜀国时期的遂宁 ===
遂宁历史久远。根据在[[射洪县]][[仁和镇 (射洪市)|仁和镇]]马鞍山南山采集到的人顶头骨化石初测，至少在公元1万年前，遂宁就有人类活动。[[夏]][[商朝|商]]时期，全国划为[[九州 (中国)|九州]]，遂宁县境（指今遂宁市船山区、安居区和[[重庆市]][[潼南县]]境）属[[梁州]]管辖。 

[[春秋时期|春秋]]初年，四川境内出现[[巴国]]和[[古蜀|蜀国]]两个[[奴隶制]]国家，遂宁县境属[[古蜀|蜀国]]管辖区，[[秦朝|秦]]统一后为[[蜀郡]]所辖。[[东汉]]末年（220年），置德阳县，治所在今城区内，境内置县也由此开始。[[西晋]]后期（约303年），流民[[李雄 (十六国)|李雄]]起义建立[[成汉]]国，置德阳郡，辖德阳县，郡、县治所仍在今城区内，境内置郡也由此开始。

=== 名称由来 ===
“遂宁”作为地名，始于[[东晋]]。东晋与[[十六国]]并存，而遂宁则属于[[十六国]]中的[[成汉]]国。当时，各国统治者之间连年混战，成汉国统治者内部也为争权夺位斗争不息，人民痛苦不堪。[[永和 (东晋)|永和]]三年（347年），东晋大将[[桓温]]伐蜀，大败[[李雄]]遗部李势，灭成汉国，结束了四川长达50多年的混战。当桓温凯旋，途经县境时，但见风和日丽，歌舞升平，一派和平安宁的气氛。这位长年征战沙场的将军感慨万端，一种厌恶战乱、渴望太平的思绪油然而生，因而在这里设郡，定郡名为“遂宁”，表示 “平息战乱，达到安宁”的意思。从此，川中丘陵中的这片红土地，便有了一个吉祥的名字——“遂宁”。

=== 建制沿革 ===
在历史的沧桑演进中，“遂宁”这个名称或用或改，遂宁的“级别”或升或降，遂宁的辖区或大或小，但有一点没有改变，这就是不论哪个朝代，都以遂宁城为郡、府、州、县的治所，足见古人对遂宁这块土地的厚爱。遂宁也因此成了川中重镇和政治、经济、文化的中心。

[[南北朝]]至[[宋朝|宋]][[元朝|元]]时期，今市境内先后设置或更名石山郡、小溪县、方义县、遂州、遂州总管府、遂州总督府、武信军节度使，辖区常有三五县。辖区最大时期当数[[唐]]末，在遂州设的武信军[[节度使]]，管辖了遂（遂宁）、昌（[[隆昌]]）、合（[[合川]]）、渝（[[重庆]]）、泸（[[泸州]]）五州。自[[明朝]]开始，遂宁降州为县，先后隶属潼川府（今[[三台]]县）、嘉陵道（今[[南充]]市）。

1935年，[[中華民國|民国]]政府将四川划为18个行政督察区，在遂宁置四川第十二行政督察区，设专员公署，辖遂宁、[[安岳]]、[[中江]]、[[三台]]、[[射洪]]、[[盐亭]]、[[蓬溪]]、[[潼南]]、[[乐至]]等9县，专员公署、县治所均设在今市城区。全国解放后，置川北行政区遂宁分区，1952年改为遂宁专区，仍辖上述各县。1958年撤专区留县，遂宁并入绵阳专区。

1985年2月，经[[中华人民共和国国务院|国务院]]批准，遂宁撤县，建为[[省辖市]]，管辖市中区（原遂宁县）、蓬溪县和射洪县。1997年10月，经国务院批准，蓬溪县涪江以西地区建立大英县，县治所设在蓬莱镇。遂宁市所辖为一区三县，即市中区、蓬溪县、大英县、射洪县。2003年12月，经国务院批准，分市中区行政区，设船山区、安居区（治所设安居镇）。至此，遂宁所辖为二区三县，即船山区、安居区、蓬溪县、大英县、射洪县。

1997年分蓬溪县设大英县。2004年撤销原遂宁市中区，分设船山区和安居区。

== 地理 ==
遂宁市位于[[四川盆地]]中部，[[涪江]]中游。介于东经105°03′26″－106°59′49″，北纬30°10′50″－31°10′50″之间。东西宽90.3公里，南北长108.9公里，总面积5325平方公里。东邻[[重庆]]、[[广安]]、[[南充]]，西连[[成都]]，南接[[内江]]、[[资阳市|资阳]]，北靠[[德阳]]、[[绵阳]]，与成都、重庆呈等距三角。历史上，遂宁曾以其深厚的文化底蕴、迷人的灵性山水和发达的农工商贸而成为川中政治、经济和文化中心，尤以纺织食品工业闻名，素有“成渝后花园”、“川中重镇”之称。

== 人口 ==
2023年末，全市常住人口274.8万人<ref>{{Cite web |title=2023年遂宁市国民经济和社会发展统计公报 - 遂宁市人民政府 |url=https://www.suining.gov.cn/gongkai/show/b4d8093ff78119fca9fa89bd57f68fc6.html |website=www.suining.gov.cn |access-date=2024-11-22 |archive-date=2024-12-04 |archive-url=https://web.archive.org/web/20241204073110/https://www.suining.gov.cn/gongkai/show/b4d8093ff78119fca9fa89bd57f68fc6.html |dead-url=no }}</ref>。比上年末减少2.4万人，其中城镇人口164.28万人，乡村人口110.52万人。 城镇居民常住人口城镇化率59.78%，比上年末提高1.1个百分点。2024年出生人口1.36万人，人口出生率4.83‰；死亡人口1.75万人，人口死亡率6.25‰；人口自然增长率为-1.42‰。年末常住人口274.8万人，与上年持平，其中城镇人口165.4万人，乡村人口109.4万人。常住人口城镇化率60.19%，比上年末提高0.41个百分点。年末全市户籍人口351.06万人，比上年末减少2.06万人。<ref>{{Cite web |title=(四川省)2024年遂宁市国民经济和社会发展统计公报-红黑统计公报库 |url=https://tjgb.hongheiku.com/djs/58685.html |website=tjgb.hongheiku.com |access-date=2025-10-09}}</ref>

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,814,196人<ref>{{cite web |author1=遂宁市统计局、遂宁市第七次全国人口普查领导小组办公室 |title=遂宁市第七次全国人口普查公报 |url=https://stjj.suining.gov.cn/tjgb/-/articles/36933479.shtml }}{{Dead link}}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的3,252,619人相比，十年共减少了438,423人，下降13.48%，年平均增长率为-1.44%。其中，男性人口为1,427,876人，占总人口的50.74%；女性人口为1,386,320人，占总人口的49.26%。总人口性别比（以女性为100）为103。0－14岁的人口为436,776人，占总人口的15.52%；15－59岁的人口为1,668,545人，占总人口的59.29%；60岁及以上的人口为708,875人，占总人口的25.19%，其中65岁及以上的人口为558,522人，占总人口的19.85%。居住在城镇的人口为1,612,641人，占总人口的57.3%；居住在乡村的人口为1,201,555人，占总人口的42.7%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,801,560人，占99.55%；各[[中国少数民族|少数民族]]人口为12,636人，占0.45%。与2010年第六次全国人口普查相比，汉族人口减少448,139人，下降13.79%，占总人口比例下降0.36个百分点；各少数民族人口增加9,716人，增长332.74%，占总人口比例增加0.36个百分点。

== 经济 ==
遂宁[[化学工业|化工]]、[[食品]]、[[纺织]]、[[机械]]等产业具有比较优势，是四川省内上市公司数量并列第二多的城市。

上市公司有：沱牌曲酒（SHA：600702）、四川美丰（SHE：000731）、华纺股份（SHE:600448）、明星电力（SHA：600101）、高金食品（SHE：002143）、华润锦华（SHE：000810）、天齐锂业（SHE：002466）。
