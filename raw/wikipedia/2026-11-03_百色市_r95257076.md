'''百色市'''（{{langx|za|Bwzswz Si}}）是[[中华人民共和国]][[广西壮族自治区]]下辖的[[地级市]]，位于广西西部，[[右江]]流域，距自治区首府[[南宁市]]266公里。市境西邻[[云南省]][[文山州]]，北接[[贵州省]][[黔西南州]]，东与[[河池]]、[[南宁]]两市毗邻，南与[[崇左市]]及[[越南]][[高平省]]接壤。地处桂滇黔三省区交界，中越边境结合部，东北部为[[青龙山]]余脉，西北部为[[金钟山]]余脉，西南部为[[黄连山]]，东南部为右江谷地。[[右江]]（上游称[[驮娘江]]）自西北往东南斜贯全境，于市区纳[[澄碧河]]。是广西面积最大的地级市，[[壮族]]人口比例超过七成，市人民政府驻[[右江区]]向阳路13号。

== 历史 ==
据[[徐松石]]《粤江流域人民史》记：“百，口也；色，塞也，地在山脉塞口之内也。”亦有指“百色”是来自[[壮语]]中的原始村落“博涩寨”（{{langx|za|Bakdahguhsaeg}}），意思是洗衣服的好地方<ref>{{cite news |title=访广西民族大学文学院院长、博士韦树关 |url=http://www.gxmzb.net/szb/html/2015-03/20/content_12497.htm |work=[[广西民族报]] |date=2015-03-20 }}{{Dead link}}</ref><ref>{{Cite web |url=http://www.baise.gov.cn/html/gzidy.html |title=历史沿革 百色市人民政府网 |access-date=2017-04-21 |archive-date=2019-06-09 |archive-url=https://web.archive.org/web/20190609011743/http://www.baise.gov.cn/html/gzidy.html |dead-url=yes }}</ref>。[[清朝|清]][[雍正]]七年（1729年）析土田州百色置[[百色厅]]，移思恩府理苗同知自[[武缘县]]来驻，属[[思恩府]]；[[光绪]]二年（1876年）升为[[直隶厅]]。

[[中華民國|民国]]元年（1912年），百色直隶厅改为百色府。1913年废府，置百色县。1914年，县属[[田南道]]。1929年12月，[[中国共产党]]在此发动[[百色起义]]，建立[[中国工农红军第七军]]及右江[[苏维埃]]政府。民国31年（1942年），置[[廣西省 (中華民國)|广西省]]第五行政督察区，专署驻百色县。

[[中华人民共和国]]成立后，设立[[百色专区]]，专署驻百色县。1952年，百色专区隶属[[桂西僮族自治区]]，1956年改为[[桂西僮族自治州]]。1958年，成立省级[[广西僮族自治区]]，百色专区属之。1970年百色专区改为[[百色地区]]。

1983年10月，百色县改为县级百色市。2002年6月，撤销百色地区及县级百色市，设立地级百色市；原县级百色市改设[[右江区]]<ref>{{Cite web |url=http://www.gov.cn/gongbao/content/2002/content_61537.htm |title=国务院关于同意广西壮族自治区撤销百色地区设立地级百色市的批复 |accessdate=2017-04-21 |archive-date=2016-03-04 |archive-url=https://web.archive.org/web/20160304111709/http://www.gov.cn/gongbao/content/2002/content_61537.htm |dead-url=no }}</ref>。

== 地理 ==
百色位于[[廣西]]西部。由於地勢西高東低，因此百色東西兩地气温差别很大。百色東部属南[[亚热带季风气候]]，气候温暖。冬季短暂温和，夏季漫长炎热。冬季干燥，日照少。夏秋季节多晴朗天气。1月平均气温13.4℃，极端最低气温-2.0℃（1955年1月12日）。7月平均气温28.4℃，极端最高气温42.5℃（1958年4月23日）。年平均气温22.0℃。降雨主要集中在5月~8月。年均降水量1070.6毫米。<ref>[http://cdc.cma.gov.cn/home.do 中国气象科学数据共享服务网] {{webarchive|url=https://web.archive.org/web/20150302053152/http://cdc.cma.gov.cn/home.do |date=2015-03-02 }}</ref>而百色西部由於是地處[[雲貴高原]]東緣，地勢平均高於海拔500米，而[[隆林縣]]和[[西林縣]]一帶更高於海拔1000米。氣候情況與[[雲南省]]中部大部份城市相若，全年溫差較少而氣溫偏低。

== 人口 ==
截至2022年底，百色市户籍人口422.62万人<ref>{{Cite web|title=百色市2022年国民经济和社会发展统计公报 - 中国统计信息网|url=http://www.tjcn.org/tjgb/20gx/37521.html|access-date=2023-09-06|website=www.tjcn.org|archive-date=2023-09-06|archive-url=https://web.archive.org/web/20230906021122/http://www.tjcn.org/tjgb/20gx/37521.html|dead-url=no}}</ref>，比上年末减少0.19万人。常住人口356.20万人。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为3,571,505人<ref>{{cite web |author1=百色市统计局、百色市第七次全国人口普查领导小组办公室 |title=百色市第七次全国人口普查主要数据公报 |url=http://www.baise.gov.cn/zwgk/jcxxgk/sjfb/bssgb/t9049992.shtml |access-date=2021-10-16 |archive-date=2021-10-16 |archive-url=https://web.archive.org/web/20211016183142/http://www.baise.gov.cn/zwgk/jcxxgk/sjfb/bssgb/t9049992.shtml |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的3,466,758人相比，十年共增加了104,747人，增长3.02%，年平均增长率为0.3%。其中，男性人口为1,826,662人，占总人口的51.15%；女性人口为1,744,843人，占总人口的48.85%。总人口性别比（以女性为100）为104.69。0－14岁的人口为798,115人，占总人口的22.35%；15－59岁的人口为2,171,649人，占总人口的60.8%；60岁及以上的人口为601,741人，占总人口的16.85%，其中65岁及以上的人口为442,548人，占总人口的12.39%。居住在城镇的人口为1,551,425人，占总人口的43.44%；居住在乡村的人口为2,020,080人，占总人口的56.56%。

=== 民族 ===
全市常住人口中，[[壮族]]人口为2,676,720人，占74.95%；[[汉族]]人口为588,273人，占16.47%；其他[[少数民族]]人口为306,512人，占8.58%。与2010年第六次全国人口普查相比，汉族人口增加69,860人，增长13.48%，占总人口比例增加1.52个百分点；各少数民族人口增加34,887人，增长1.18%，占总人口比例下降1.52个百分点。其中，壮族人口增加8,706人，增长0.33%，占总人口比例下降2.01个百分点；[[瑶族]]人口增加11,089人，增长8.14%，占总人口比例增加0.2个百分点；[[苗族]]人口增加11,192人，增长8.75%，占总人口比例增加0.21个百分点。

== 物产 ==
* 矿产有铝、煤、锑、锰、铁、石膏、滑石等 20多种。
* 可开发水能 18.94 万千瓦。
* 林以松、杉、栎、竹为主。
* 野生动物有穿山甲、山瑞、果子狸等。
* 有灵芝、黄精、首乌等药材。
* 物产有[[八角]]、[[茴香]]、[[云耳]]、[[芒果]]、[[扁桃]]、[[茶叶]]、[[柑橘]]、[[龙眼]]、[[黄皮]]、[[板栗]]、[[红碎茶]]。其中百色芒果在百色种植历史已有三百多年，现为国家地理标志产品。
