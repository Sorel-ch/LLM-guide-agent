'''新社區'''，舊稱「新番社」{{r|鄉誌開發史篇|p=65}}、「新社仔」{{r|縣續土志一|p=58}}，前身「新社鄉」<ref name="歷史沿革">{{Cite web |url=https://www.xinshe.taichung.gov.tw/981609/981610/981612/981613/1105393/post |title=機關介紹-認識新社-歷史沿革-新社區歷史沿革 |publisher=臺中市新社區公所 |date=2012-10-30 |access-date=2022-10-13 |language=zh-tw |archive-date=2022-10-14 |archive-url=https://web.archive.org/web/20221014101050/https://www.xinshe.taichung.gov.tw/981609/981610/981612/981613/1105393/post |dead-url=no }}</ref>，位於[[臺灣]][[臺中市]]中部偏東{{r|鄉誌鄉域篇|p=3}}，[[大甲溪]]西南岸，居[[臺中市 (省轄市)|臺中市區]]、[[豐原區|豐原]]、[[東勢區|東勢]]等地交通要衝位置{{r|鄉誌鄉域篇|p=9}}。

新社區在經濟發展上，長年以農業為主，早年有稻米、雜糧、甘蔗、甘藷、芭蕉等農產品，至1970年代以後則逐漸轉為生產水果、蔬菜、香菇與花卉等，並在21世紀後開始發展休閒農業{{sfn|施添福|2006|p=376}}。因當地盛產花卉，亦素有「臺中後花園」之美譽。特產有[[椪柑]]、[[葡萄]]、[[楊桃]]、高接[[梨]]、[[枇杷]]、[[香菇]]、[[盆景]]等種植。

== 歷史 ==
新社區在漢人未入墾之前，為[[平埔族|平埔原住民]]聚居之地，屬[[噶哈巫族]]「'''樸仔籬'''」社群居住地。據記載，[[臺灣清治時期|清]][[道光]]十三年（1833年），有[[粵]]人杜行修者，率領五十壯男經大墩、三櫃城、大坑（皆[[臺中市]]境內），到達新社一帶，為漢人到達新社之始，由於當時遷移以粵人居多，目前新社區為臺中市第二大[[客家]]聚落，僅次[[東勢區]]。而原住民於[[嘉慶]]年間，內遷到新社轄區各地後，不久即有漢人進入與他們做買賣，並稱該地原住民聚落為「'''新番社'''」（{{lang-hak|tphp=sin+ fan+ sha+}}；{{lang-nan-tw|tl=Sin-huan-siā}}；簡稱「新社」），此為新社地名的起源。

清[[道光]]末年，彰化地區[[戴萬生]]等人因官府鎮壓[[天地會]]（又名八卦會）而爆發[[戴潮春事件|民變]]，在臺發動革命，全臺陷入一片混亂之中，沿海居民則紛紛入山避難，大舉遷入新社地區墾殖，與原住民劃地而居，新社因而逐漸發展。

民變平息之後，[[彰化縣]]府派兵到東勢角設治，新社為[[栜東上堡]]'''新社區'''，為新社治理之始。[[台灣日治時期|日本治臺]]後，新社改為[[臺中廳]]東勢角支署新社區；[[大正]]9年（1920年）臺灣地方制度改變，改為[[臺中州]][[東勢郡]]'''[[新社庄 (臺中州)|新社-{庄}-]]'''。

1945年[[中華民國政府]]接收日本[[臺灣總督府]]轄區之初，[[臺中縣]]東勢區「'''新社鄉'''」。2010年12月25日，配合[[2010年中華民國縣市改制直轄市|臺中縣市合併改制]]，新社鄉改制為「新社區」<ref name="歷史沿革"/>。

== 地理 ==
=== 位置 ===
新社區位於臺中市偏東，輪廓略呈扭曲之西北－東南走向長條形。東北部隔[[大甲溪]]與[[東勢區]]相望，東與[[和平區 (台灣)|和平區]]為鄰，南與[[臺灣省]][[南投縣]][[國姓鄉]]為界，西南與[[太平區 (臺灣)|太平區]]、[[北屯區]]連接，西為[[豐原區]]，北為[[石岡區]]。全區之中心點位於東經120.4度，北緯24.2度處，面積68.89平方公里。在全市區當中，面積排名第五位<ref name="地理環境">{{Cite web |url=https://www.xinshe.taichung.gov.tw/981609/981610/981612/981614/1105398/post |title=機關介紹-認識新社-地理環境 |publisher=臺中市新社區公所 |date=2012-10-30 |access-date=2023-02-02 |language=zh-tw |archive-date=2023-02-02 |archive-url=https://web.archive.org/web/20230202185139/https://www.xinshe.taichung.gov.tw/981609/981610/981612/981614/1105398/post |dead-url=no }}</ref>。

=== 地形 ===
{{main|新社河階群}}
新社區境內佔多數地形是屬於河階台地面，為古代[[大甲溪]]受到[[蓬萊運動]]影響，造成河道數次更動，因此形成數階的台地面，共有十三座河階，是為「[[新社河階群]]」。大南、水底寮、下水底寮、七分、十分及永居湖等河階位於新社區轄內，水井子、南眉及仙塘坪等河階則與鄰區相交界，其餘的河階已不在新社區轄內。

根據臺中市政府民政局統計，2025年底新社區戶數約8.5千戶，人口約2.3萬人<ref name="民政局">{{Cite web |url=https://demographics.taichung.gov.tw/Demographic/Web/Demographic_19.aspx |title=臺中市人口統計管理平台-新社區人口統計 |publisher=臺中市政府民政局 |access-date=2020-07-17 |language=zh-tw |archive-date=2020-08-06 |archive-url=https://web.archive.org/web/20200806024443/https://demographics.taichung.gov.tw/Demographic/Web/Demographic_19.aspx |dead-url=no }}</ref>。在人口分布上，區內平原地區人口較為稠密，山區丘陵地則較為稀疏。區內人口最多與最少的里分別是新社-{里}-與中和里，2025年底兩里人口分別為3,812人與579人{{r|鄉誌住民篇|p=117}}<ref name="民政局"/>；人口密度最高與最低的里分別是新社-{里}-與福興里，2025年底兩里人口密度分別為每平方公里5,956人與51人{{r|鄉誌鄉域篇|pp=5－7}}<ref name="民政局"/>。族群結構方面，新社區主要為客家人，分布於新社、中正、月湖、東興、慶西、中和、福興、協成、復盛等9里；次多為閩南人，分布於崑山、永源、大南等3里以及因陽明山計畫而自他地遷入的新村等地。中興里則多為退役軍人{{r|鄉誌住民篇|p=118}}。各個聚落的最大姓氏，分別為東興里的彭姓，慶西里下水底寮聚落、大南里（不含水頭仔）的劉姓，大南里的廖姓，新社街區的詹姓，崑山-{里}-的陳姓，其他尚有馬力埔、食水嵙與中正里的張姓，崑山-{里}-的吳姓等人數較多的姓氏{{r|鄉誌開發史篇|pp=73－74}}。

1946年，新社區人口總數為11,318人，嗣後人口成長主要為自然增加，其中1949年、1955年分別受到政府播遷來臺與陽明山計畫的影響，人口二度大量增加。1982年，新社區的人口達到28,006人，其後人口開始負成長{{r|鄉誌住民篇|p=111}}。由於該區經濟產業主要為農業，工商業則較不發達，使年輕人口逐漸外移{{r|鄉誌住民篇|p=113}}。現今新社區與臺中市山線其他行政區相同，人口持續衰退<ref name="m1-10.xls"/>，2019年底時新社區尚有24,289人，至2024年底時已下滑至22,849人<ref name="民政局"/>。新社區的老年人口比例已於2021年1月突破20%，是臺中市繼[[東勢區]]以後第二個進入[[超高齡社會]]的行政區，至2025年底止，新社區的幼年人口佔比約為8.53%，壯年人口佔比約為67.48%，老年人口佔比約為23.99%，老化指數約為281.06%，是臺中市人口老化較為嚴重的地區<ref name="民政局"/>。

=== 區政組織 ===
[[File:新社區公所.JPG|thumb|200px|新社區公所]]
[[新社區公所]]是[[臺中市政府]]在新社區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為臺中市政府。[[区长]]由[[臺中市市長|市長]]任命，其任期為無任期保障。在區長及主任秘書之下，設有4課4室等8個內部單位<ref>{{Cite web |url=https://www.xinshe.taichung.gov.tw/981609/981610/981617/1105419/post |title=機關介紹-組織架構 |publisher=臺中市新社區公所 |date=2012-06-29 |access-date=2021-04-21 |language=zh-tw |archive-date=2021-04-21 |archive-url=https://web.archive.org/web/20210421112751/https://www.xinshe.taichung.gov.tw/981609/981610/981617/1105419/post |dead-url=no }}</ref>。

=== 行政區 ===
現今新社區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設新社-{庄}-屬臺中州東勢郡{{r|鄉誌行政篇|p=167}}。新社-{庄}-轄新社、永居湖、鳥銃頭、水底寮、大南、馬力埔、七分等7個大字{{r|縣續政志一|p=42}}。1945年12月25日，改為「新社鄉」，屬臺中縣東勢區{{r|鄉誌行政篇|p=167}}。1950年，裁撤區署，新社鄉改直隸於臺中縣{{r|縣續政志一|p=9}}。2010年12月25日，臺中縣市合併改制為直轄市，新社鄉改制為市轄區「新社區」，隸屬臺中市<ref name="歷史沿革"/>。

== 教育 ==
[[File:20260726 153557 TMSH Front Gate.jpg|thumb|alt=見說明|[[臺中市立新社高級中學]]正門]]
清領時期，臺灣教育的地方最高學府是府縣儒學，純由官方建置，其職掌有文廟的管理與學生的指導監督及管課，當時全臺共有13個府縣儒學，包括1727年在臺灣中部成立的彰化縣儒學。早期新社區的移民入墾初時，不易赴縣城求學，當時東勢地區僅有[[丘逢甲]]、劉章識兩人赴縣、省城求學，一般利用地方義學、社學、民學等機構求學{{r|鄉誌教育與藝文篇|p=311}}。其中民學是當時鄰近新社區一帶僅有的機構，即私人設立的私塾（或稱書房），設於東勢公館及土牛劉厝伙房，在重男輕女的時期僅有少數男性求學。至於一般民間在各地所組社的軒、園等戲樂園或子弟班，均以庄內子弟為主要成員，凡遇地方上逢祭典即上演，皆以演忠孝節義或歷史典故為多數{{r|鄉誌教育與藝文篇|pp=311－312}}。

日本治臺後，致力於一般正規初等教育工作，先於街庄普遍設立公學校，後著手進行職業教育{{r|鄉誌教育與藝文篇|p=312}}。1899年，設立新社公學校，傳習日本語文{{r|鄉誌教育與藝文篇|p=271}}。之後又陸續成立[[小學校 (台灣)|尋常小學校]]、[[公學校]]與農業學校，分別是1920年大南尋常小學校（1919年原為東勢尋常小學校大南分教場，1920年改制）、1929年臺中州立實踐農業學校（1925年原為新社公學校附設新社農業補習學校，1929年改制，之後經歷過東勢農林國民學校、東勢農林國民學校，1941年再改為新社實踐農業學校大地館）、1941年水底寮公學校（1926年原為新社公學校水底寮分教場，1941年改制）{{r|鄉誌教育與藝文篇|pp=271－272}}。1941年4月1日，實施[[台灣六年國民義務教育|六年國民義務教育]]，公學校更名為[[國民學校]]，並於新社國民學校增設高等科{{r|鄉誌教育與藝文篇|p=272}}。1945年4月1日，水底寮國民學校成立麻竹坑分教場<ref>{{cite web |url=https://dles.tc.edu.tw/p/412-1281-7194.php |title=認識大林-校史沿革 |access-date=2024-12-18 |publisher=臺中市新社區大林國民小學 |language=zh-tw |archive-date=2024-12-27 |archive-url=https://web.archive.org/web/20241227175127/https://dles.tc.edu.tw/p/412-1281-7194.php |dead-url=no }}</ref>。此外，1934年今中和里地區由於盛產樟腦油、香蕉等高經濟作物，人口漸聚而成部落，當地居民遂而集資成立私立抽藤坑國語講習所（今中和國小）{{r|鄉誌教育與藝文篇|p=285}}。

1945年戰後，學制改革，國民政府除重視正規教育之外，一般民間積極設立有關民間社會教育類之民間補習班{{r|鄉誌教育與藝文篇|p=314}}。原有新社實踐農業學校大地館，則改制為臺中縣立新社初級農業職業學校{{r|鄉誌教育與藝文篇|p=305}}。期間進行數次更名、調整與增設各級學校，包括1946年大南國民學校（日籍僑生返日後，由原大南尋常小學校改制）{{r|鄉誌教育與藝文篇|p=282}}、東興國民學校（原為水底寮國民學校，1946年改名）{{r|鄉誌教育與藝文篇|p=300}}、1950年大林國民學校（1945年原為水底寮國民學校麻竹坑分教場，1950年改制）{{r|鄉誌教育與藝文篇|p=286}}、1956年中和國民學校（原為私立抽藤坑國語講習所，1946年改制為分班並隸屬水底寮國民學校，1950年改隸大林國民學校並更名為中和分班，1956年獨立改制）{{r|鄉誌教育與藝文篇|pp=286－287、300}}、1957年崑山國民學校（1952年原為新社國民學校崑山分班，1957年改制）{{r|鄉誌教育與藝文篇|p=296}}、1961年新社農業學校（原為新社初級農業職業學校，1961年改名）{{r|鄉誌教育與藝文篇|p=305}}、1964年新社初級中學{{r|鄉誌教育與藝文篇|p=305}}等。1968年8月1日，國民政府廢除初中聯考，實施九年國民教育{{r|鄉誌教育與藝文篇|p=287}}，初級中學改為國民中學{{r|鄉誌教育與藝文篇|p=305}}，國民學校改為國民小學。此後另行調整改制的學校尚有1975年福民國民小學（1951年原為和平國校白毛分班，1955年改制為分校，1975年獨立改制）<ref>{{cite web |url=https://fmes.tc.edu.tw/p/404-1388-27816.php  |title=認識福民-福民國小沿革 |access-date=2024-12-18 |publisher=臺中市新社區福民國小 |language=zh-tw }}</ref>、1983年協成國民小學（1973年原為東興國小協成分班，1979年改制為分校，1983年獨立改制）{{r|鄉誌教育與藝文篇|p=290}}、2000年新社高級中學（1979年將新綜國中併入新社國中{{r|鄉誌教育與藝文篇|p=305}}，1998年改制為[[完全中學]]，2000年實施綜合高中學制並改制[[高級中學]]<ref>{{cite web |url=https://sshs.tc.edu.tw/p/426-1069-2.php |title=關於學校-校史 |access-date=2024-12-18 |publisher=臺中市立新社高級中學 |language=zh-tw |archive-date=2025-02-08 |archive-url=https://web.archive.org/web/20250208193738/https://sshs.tc.edu.tw/p/426-1069-2.php |dead-url=no }}</ref>）等。

新社區現有高級中學為[[臺中市立新社高級中學]]一校，並附設國中部，其他公立教育機構計有臺中市新社區新社國民小學、臺中市新社區大林國民小學、臺中市新社區大南國民小學、臺中市新社區中和國民小學、臺中市新社區東興國民小學、臺中市新社區協成國民小學、臺中市新社區崑山國民小學、臺中市新社區福民國民小學等8所國民小學<ref>{{Cite web |url=https://www.tc.edu.tw/school/list/list |title=首頁 > 公務作業 > 學校專區 > 學校資料 |author=臺中市政府教育局 |publisher=臺中市政府教育局全球資訊網 |access-date=2021-04-05 |language=zh-tw |archive-date=2021-03-09 |archive-url=https://web.archive.org/web/20210309093642/https://www.tc.edu.tw/school/list/list |dead-url=no }}</ref>。
