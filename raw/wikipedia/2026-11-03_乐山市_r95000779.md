'''{{zy|乐|lè|ㄌㄜˋ|lok6}}山市'''（[[四川话]][[四川话拼音|拼音]]：No<sup>2</sup>san<sup>1</sup>；[[岷江话|本地发音]]：[{{IPA|nʊʔ<sup>3</sup>sã<sup>55</sup>}}]），古称'''嘉州'''、'''嘉定'''，是[[中华人民共和国]][[四川省]]下辖的[[地级市]]，位于四川省中南部。市境东界[[自贡市]]、[[宜宾市]]，南接[[凉山州]]，西邻[[雅安市]]，北连[[眉山市]]。地处[[四川盆地]]西南部，北部为[[成都平原]]，东部为川中丘陵区，西南为[[大小凉山|小凉山]]山地，地势西南高，东北低。[[岷江]]自北往南纵贯而入，于市区与[[大渡河]]、[[青衣江]]汇合，再往东南流出市境。全市总面积12,720平方公里，人口326.05万，市人民政府驻[[市中区 (乐山市)|市中区]]。乐山是[[国家历史文化名城]]、[[中国优秀旅游城市]]，著名的[[乐山大佛]]座落于岷江东岸[[凌云寺]]南侧，[[中国四大佛教名山]]之一的[[峨眉山]]位于市境西北。

== 历史 ==
乐山历史悠久，2000多年前即为[[蜀王]][[開明 (蜀國)|开明]]故治。[[汉朝]]置[[南安县 (西汉)|南安县]]。[[北周]]置[[峨眉县 (北周)|峨眉县]]、[[平羌县]]。[[隋朝]][[开皇]]九年（589年），改峨眉县为[[青衣县]]。开皇十年，青衣县改为[[龙游县 (隋朝)|龙游县]]。开皇十三年，置[[峨眉县]]<ref>《[[隋书]]·志二十四·地理上》眉山郡......龙游后周置，曰峨眉，及置平羌郡。开皇初郡废。九年改县为青衣。平陈日，龙见水，随军而进，十年改名焉。大业初置眉山郡。平羌后周置，仍置平羌郡。开皇初郡废。夹江开皇三年置。峨眉开皇十三年置。有峨眉山、绥山......</ref>。

[[唐朝]]龙游县，为嘉州州治。[[宋朝]]时改设[[嘉定府]]。[[明朝]]时改为[[嘉定直隸州]]。1734年复为嘉定府，又置乐山县。《嘉定府志》称“以县境内有至乐山为名”，但至乐山在县境何处，历代说法不一<ref>{{Cite web |url=http://www.cnepaper.com/sjdsb/html/2013-05/18/content_10_3.htm |title=乐山老县名考(十)乐山县 |accessdate=2015-04-11 |author= |date=2013年5月18日 |work= |publisher=三江都市报多媒体报刊 |language=Zh-hans |archive-date=2020-12-19 |archive-url=https://web.archive.org/web/20201219192231/http://www.cnepaper.com/sjdsb/html/2013-05/18/content_10_3.htm |dead-url=no }}</ref>。嘉定府与今乐山市辖区不尽相同。

民国时，仍为[[四川省 (中華民國)|四川省]]所管辖。1950年，置[[乐山专区]]，1968年，改为[[乐山地区]]。1978年，乐山县与[[五通桥区]]合并，设立乐山市（县级市）。1985年，乐山地区撤地设市，成立地级乐山市。1997年，所辖六县（[[眉山县]]、[[彭山县]]、[[仁寿县]]、[[洪雅县]]、[[丹棱县]]、[[青神县]]）划出，设置[[眉山地区]]。

== 地理 ==
乐山市位于[[四川省]]中部，[[四川盆地]]西南的[[岷江]]、[[大渡河]]和[[青衣江]]的交汇处。以丘陵为主，西南为山地，沿江为冲积平地。北与[[眉山市|眉山]]接壤，东与[[自贡市|自贡]]、[[宜宾市|宜宾]]毗邻，南与[[凉山彝族自治州|凉山]]相接，西与[[雅安市|雅安]]连界。

=== 气候 ===
全市属[[亚热带|中亚热带气候带]]，气候以温和湿润、四季分明、雨量丰沛、春冬宜人为特点。平均海拔约500米。年降水量1394毫米，年均温17.2℃。西南山区气候垂直差异明显，从山麓至山巅依次分布着中亚热带一暖温带一温带一寒温带的完整气候带，气候条件十分复杂，是地域内发展农业综合经营和立体农业的区域，是木材、茶叶、中药材等作物的主产区，也是宝贵的旅游资源。受季风影响和地形的抬升作用，气候湿润，雨量丰沛。<ref>{{Cite web |title=四川省公共气象服务网 {{!}} 本地气候 |url=https://www.scggqx.com/sc_les/qxsh/lytqdh/ |website=www.scggqx.com |access-date=2025-05-04 |archive-date=2025-08-14 |archive-url=https://web.archive.org/web/20250814032529/https://www.scggqx.com/sc_les/qxsh/lytqdh/ |url-status=live }}</ref>{{乐山市气候数据}}

===资源===
====矿藏====
已探明资源约30种。其中[[磷]]、[[岩盐]]、[[石灰石]]、[[高岭土]]、[[天然气]]、[[石膏]]、[[白云石]]、[[矿泉水]]、[[芒硝]]储量较大。

====水力====
*水资源：855.1亿立方米
*水力资源理论蕴藏量：790万千瓦
*可开发量：575万千瓦
*主要水电站：[[龚嘴水电站]]（70万千瓦）、[[铜街子水电站]]（60万千瓦）

====物产====
国家重点保护珍稀植物[[银杉]]、[[珙桐]]、[[水杉]]等<ref>{{cite web |title=乐山市城市绿地系统生物多样性保护专项规划 |url=https://www.docin.com/p-843789494.html |publisher=四川省城乡规划设计研究院 |date=2013年12月 |access-date=2022-10-09 |archive-date=2022-10-12 |archive-url=https://web.archive.org/web/20221012070530/https://www.docin.com/p-843789494.html |dead-url=no }}</ref>，并有[[大熊猫]]、[[枯叶蝶]]等珍稀动物。
1986年，在乐山市五通桥西坝镇发现了宋代窑址，民间大量使用的西坝窑瓷器浮出，四川省科技人员进行了大规模考察，发现了西坝窑几乎可以与同时代的[[建窑]]和[[吉州窑]]平起平坐。主要特征就是在烧制过程中发生的窑变，美轮美奂，变幻无穷。
最近发现一件西坝窑灯树刻有“[[泰和 (年号)|泰和]]”，估计1201年-1208年[[金章宗]]时期，乐山市可能在[[金朝]]统治下。并非南宋统治。

== 人口 ==
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为3,160,168人<ref>{{cite web |author1=乐山市统计局、乐山市第七次全国人口普查领导小组办公室 |title=乐山市第七次全国人口普查公报 |url=https://www.leshan.gov.cn/lsswszf/tjgb/202106/095e5f2886e94b0aa6fd70dfa896ed40.shtml |access-date=2023-07-23 |archive-date=2023-07-23 |archive-url=https://web.archive.org/web/20230723195628/https://www.leshan.gov.cn/lsswszf/tjgb/202106/095e5f2886e94b0aa6fd70dfa896ed40.shtml |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的3,235,759人相比，十年共减少了75,591人，下降2.34%，年平均增长率为-0.24%。其中，男性人口为1,585,671人，占总人口的50.18%；女性人口为1,574,497人，占总人口的49.82%。总人口性别比（以女性为100）为100.71。0－14岁的人口为446,056人，占总人口的14.11%；15－59岁的人口为1,939,933人，占总人口的61.39%；60岁及以上的人口为774,179人，占总人口的24.5%，其中65岁及以上的人口为606,448人，占总人口的19.19%。居住在城镇的人口为1,678,367人，占总人口的53.11%；居住在乡村的人口为1,481,801人，占总人口的46.89%。

=== 民族 ===
乐山市共有41个民族，汉、彝、回、苗是世居民族。全市常住人口中，[[汉族]]人口为2,953,987人，占93.48%；各[[少数民族]]人口为206,181人，占6.52%。与2010年第六次全国人口普查相比，汉族人口减少121,497人，下降3.95%，占总人口比例下降1.57个百分点；各少数民族人口增加45,906人，增长28.64%，占总人口比例增加1.57个百分点。其中，[[彝族]]人口增加40,107人，增长26.2%，占总人口比例增加1.38个百分点。

彝族：主要的少数民族，集中分布在南部的马边、峨边彝族自治县及金口河区。
