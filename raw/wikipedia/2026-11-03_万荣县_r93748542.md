'''万荣县'''是[[中国]][[山西省]][[运城市]]所辖的一个[[县]]。縣人民政府駐解店鎮。

== 历史 ==
万荣县1954年由万泉、荣河两县合并而成。[[万泉县]]，始置于[[唐]][[武德]]三年，[[元代]]曾省入[[猗氏县|猗氏]]，后复置。[[荣河县]]，[[战国]]为[[魏國|魏]]汾阴邑，[[西汉]]置汾县，属[[河東郡 (中國)|河东郡]]，唐[[开元]]十年以得“宝鼎”之祥改称宝鼎县，[[北宋]][[大中祥符]]四年改为荣河县。<ref name="未命名-20230318184054">{{Cite web |url=http://www.sxwanrong.gov.cn/zjwr/wrgk/lsyg/579d38a6_420f_4a19_8b05_d18e6bcaad3f.html |title=历史沿革 |accessdate=2013-07-18 |archive-date=2014-07-14 |archive-url=https://web.archive.org/web/20140714230616/http://www.sxwanrong.gov.cn/zjwr/wrgk/lsyg/579d38a6_420f_4a19_8b05_d18e6bcaad3f.html |dead-url=yes }}</ref>

1954年8月15日，万泉、荣河合并为万荣县，属[[晋南专区]]。1958年11月1日与河津、稷山合并为[[稷山县]]。1959年7月1日复置万荣县。1970年4月9日晋南专区分为临汾地区、运城地区，万荣县属[[运城地区]]。<ref name="未命名-20230318184054"/>

== 地理 ==
万荣县地处晋西南[[黄土高原]]，[[黄河]]与[[汾河]]交汇处，全县总面积1080.5平方公里。最高点[[稷王山]]主峰[[法云寺]]海拔1411.2米。<ref>{{Cite web |url=http://www.wanrong.gov.cn/doc/2021/01/15/10129455.shtml |title=万荣地貌 |website=万荣县人民政府门户网站 |access-date=2022-07-30 |archive-date=2022-07-30 |archive-url=https://web.archive.org/web/20220730120453/http://www.wanrong.gov.cn/doc/2021/01/15/10129455.shtml |dead-url=no }}</ref>

== 人口 ==
