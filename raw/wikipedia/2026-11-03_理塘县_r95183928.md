'''理塘县'''（{{Lang-bo|z=ལི་ཐང་རྫོང|w=li thang rdzong|p=Litang Zong}}）是[[中华人民共和国]][[四川省]][[甘孜藏族自治州]]辖县，位于甘孜州西南部，东毗[[雅江县]]，南邻[[木里县]]、[[稻城县]]、[[乡城县]]，西接[[巴塘县]]，北连[[白玉县]]、[[新龙县]]。旧名'''理化县'''，属[[西康省]]。全县总面积14,352平方公里，平均海拔4,014米，2020年全县总人口67,293人。<ref>{{Cite web |date=2021-08-11 |title=理塘简介 |url=http://www.gzlt.gov.cn/ltxrmzf/c100438/202003/91f7ba8d0bf6475cb4931afcef941621.shtml |website=理塘县人民政府 |access-date=2022-06-18 |archive-date=2022-06-18 |archive-url=https://web.archive.org/web/20220618161017/http://www.gzlt.gov.cn/ltxrmzf/c100438/202003/91f7ba8d0bf6475cb4931afcef941621.shtml }}</ref>

== 歷史 ==
元至元九年（1272年）置李唐州，后设奔不儿亦思刚招讨使司（萬戶府）；元至元二十五年（1288年）設錢糧總管府。明置里塘宣撫司，後為[[參卜郎千戶所]]；明末清初為固始汗屬地。清康熙四十八年（1709年）設正副營官，屬青海岱慶和碩齊部。康熙五十八年（1719年）征西藏，里塘各土司皆呈戶口納糧，內附[[四川省]]。雍正七年（1729年）置里塘正副宣撫司，屬[[打箭爐廳]]；乾隆五十七年（1792年）設糧務委員。光绪二年（1876年）改土归流，置里化县，光緒三十二年（1906年）置順化縣，光緒三十四年（1908年）置[[里化廳]]，轄稻壩（稻城）、定鄉（鄉城）、順化（理塘）等縣。宣統三年（1911年）升里化府。民國二年（1913年），易'''里'''為'''理'''，置理化縣，屬[[川邊特別行政區]]，民國十四年（1925年），改屬[[西康省]]西康道，國府廢道後直屬西康省政府。1951年12月14日更名為理塘縣。<ref>{{cite book|editor=段木干|title=中外地名大辭典|publisher=人文出版社|date=1981-06|page=3359}}</ref><ref>{{cite book|editor=丹珠昂奔 周潤年 莫福山 李雙劍|title=藏族大辭典|publisher=甘肅人民出版社|date=2003-02|page=1079}}</ref><ref>{{cite web |author1=理塘县人民政府 |title=历史沿革 |url=http://www.gzlt.gov.cn/ltxrmzf/c103276/list.shtml |date=2021-08-11 |accessdate=2022-07-04 |archive-date=2022-07-06 |archive-url=https://web.archive.org/web/20220706055509/http://www.gzlt.gov.cn/ltxrmzf/c103276/list.shtml |dead-url=no }}</ref>

== 地理 ==
理塘县位于四川省西部，甘孜藏族自治州西南部，青藏高原东南缘[[金沙江]]与[[雅砻江]]之间。横断山脉中段的[[沙鲁里山]]纵贯南北，地形以丘状高原和山原地貌为主，地勢西高東低，山河呈南北走向。主要山脉有海拔6174.5米的[[格聂山]]，海拔5807米的肖扎山，海拔5780米的克麦弄山和海拔5601米的库尔岗中山。理塘县河流分为雅砻江与金沙江兩大水系，流域面积在100平方公里以上河流有48条，其中[[无量河]]、热依河等8条河流注入雅砻江，那曲河、[[拉波河]]、章纳河3条河流注入金沙江<ref name=a1>{{cite web |author1=理塘县人民政府 |title=自然环境 |url=http://www.gzlt.gov.cn/ltxrmzf/c100548/list.shtml |date=2021-08-12 |accessdate=2022-07-04 |archive-date=2022-07-06 |archive-url=https://web.archive.org/web/20220706050238/http://www.gzlt.gov.cn/ltxrmzf/c100548/list.shtml |dead-url=no }}</ref>。被雪山环绕的县城位于开阔的草原上，海拔達4014米，比拉萨還要高约400米，是世界上海拔最高的城镇之一<ref>{{cite book|author=Buckley, Michael and Straus, Robert |year=1986|title=Tibet: a travel survival kit|url=https://archive.org/details/tibettravelsurvi00buck |page=[https://archive.org/details/tibettravelsurvi00buck/page/n234 219]|publisher=Lonely Planet Publications|location= South Yarra, Victoria, Australia. |ISBN=0-908086-88-1}}</ref>。

理塘县拥有海子山国家级自然保护区、格木县级自然保护区、下坝扎嘎神山自然保护区、无量河省级湿地公园、擦若溪风景名胜区等。生态保护红线面积为7510.94平方公里，占全县总面积的52.33%，占全州生态红线面积的10.77%。有中國國家二級保护植物[[油麦吊云杉]]和[[长苞冷杉]]，中國国家一级保护动物有[[白唇鹿]]、[[林麝]]、[[马麝]]、[[金錢豹]]、[[雪豹]]、[[中华秋沙鸭]]、[[金雕]]、[[玉带海雕]]、[[胡兀鹫]]、[[斑尾榛鸡]]、[[四川雉鹑]]。中國国家二级保护动物有[[猕猴]]、[[亞洲黑熊]]、[[水獭]]、[[猞猁]]、[[金猫]]、[[水鹿]]、[[藏原羚]]、[[斑羚]]、[[岩羊]]、[[盘羊]]、[[草原雕]]、[[藏马鸡]]。<ref name=a1/>

理塘县土壤以高山草甸土、暗棕壤、高山灌丛草甸土为主，有9个类，13个亚类。森林面积18375.73公顷，全县森林覆盖率为7.4%，活立木蓄积量为5139.1343萬立方米，主要树种為[[冷杉]]和[[云杉]]，天然草地总面积1235.77万亩，可利用面积989.16万亩，主要牧草品种有[[高山嵩草]]、[[四川嵩草]]、[[黑花苔草]]等。理塘县属高原气候区，冬季干冷漫长，暖季温凉短暂，平均气温3.0°C，极端最高气温25.6°C，最低气温-30.6°C，年降雨量为722.2毫米，无霜期50天，年平均日照时数2637.7小时，年太阳辐射量達159.4千卡/平方厘米。<ref name=a1/>

== 社會 ==
