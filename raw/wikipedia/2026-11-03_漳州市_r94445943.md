'''漳州市'''（{{lang-nan|poj=Chiang-chiu-chhī}}），简称'''漳'''，是[[中华人民共和国]][[福建省]]下辖的[[地级市]]，位于福建省南部，地处闽东南山地与沿海丘陵平原区，西北有[[博平岭]]横亘，北部有[[戴云山]]余脉绵延，沿海为[[漳州平原]]，是福建省最大平原。[[九龙江]]斜贯北部，往东流出[[厦门港]]，还有[[鹿溪]]、[[漳江]]、[[东溪 (晋江支流)|东溪]]等沿海诸河。市人民政府驻[[芗城区|芗城区胜利西路118号]] 。漳州为[[国家历史文化名城]]，[[海峡西岸经济区]]中心城市，国务院批复确定的全国沿海经济开放区，是全国较早实行对外开放的地区之一。漳州位于[[闽南金三角]]南端，[[厦深铁路|厦深]]、[[龙厦铁路|龙厦]]、[[鹰厦铁路|鹰厦]]等铁路和[[福厦客运专线]]交汇于此。

== 歷史 ==
{{main|蛮獠啸乱|漳州 (古代)|漳州路|漳州府|汀漳道|闽南护法区|联军办事处|龙汀省|龙溪专区}}

=== 唐朝以前 ===
今漳州境域在约1万年前已有先民在这里生息劳作。[[秦王政]]二十五年（前222年，另说秦始皇三十三年），列入[[秦国|秦]]版图，属[[闽中郡]]。

[[西汉]]初，以梁山为界，北属[[闽越国]]，南属[[南越国]]。[[始元 (西汉)|始元]]二年（前85年），改“封邦建国”为郡县制后，北属[[会稽郡]][[冶县]]，南属[[南海郡 (中国)|南海郡]][[揭阳县]]。

[[西晋]]至[[南北朝]]，北属[[南安郡 (南梁)|南安郡]][[龙溪县]]（507年置）、兰水县，南属[[义安郡]][[绥安县 (东晋)|绥安县]]。

[[隋朝|隋]][[开皇]]十二年（592年），兰水县和绥安县并入龙溪县，今漳州境域才结束分属两郡状况。

=== 唐朝至民国 ===
[[唐朝|唐]][[垂拱]]二年（686年），设立漳州（治所在今[[云霄县]][[火田镇 (云霄县)|火田镇]]西林村），辖怀恩、[[漳浦县|漳浦]]2县，因州治傍[[漳江]]而名漳州。[[开元]]四年（716年），徙州治至李澳川（今漳浦县[[绥安镇]]）。开元二十九年（741年）后，划龙溪县、[[龙岩县]]来属。[[貞元 (唐朝)|贞元]]二年（786年），州治再徙龙溪县桂林村（今漳州城区）<ref>{{Cite web |url=https://www.zhangzhou.gov.cn/cms/html/zzsrmzf/jzyg/index.html |title=建置沿革 |access-date=2023-06-16 |archive-date=2022-10-21 |archive-url=https://web.archive.org/web/20221021235559/http://www.zhangzhou.gov.cn/cms/html/zzsrmzf/jzyg/index.html |dead-url=no }}</ref>。

[[南唐]][[保大 (南唐)|保大]]四年（946年）十月，漳州守将[[林赞尧]]发动叛乱，旋被镇压；随后，[[董思安]]任漳州刺史，因父名章，与“漳”同音，为避讳，改漳州为南州，历20年，至[[北宋]][[乾德 (北宋)|乾德]]四年（966年）才复名漳州。

[[北宋]][[太平兴国]]五年（980年），[[泉州 (景云)|泉州]][[长泰县]]改隶漳州。

[[明朝]]实行[[海禁]]政策，漳州[[月港]]在海禁期间成为繁盛的走私港<ref>朱纨《阅视海防事》：“泉州之安海、漳州之月港乃闽南大镇，人货萃聚。”（《明经世文集》卷205《朱中丞甓余集》）</ref>。

[[清朝|清]][[顺治]]二年（1645年），設立[[閩浙總督|浙閩總督]]。顺治十五年（1658年），福建、浙江兩省各設總督，福建總督駐漳州，浙江總督駐溫州。[[康熙]]十一年（1672年），福建總督改駐福州。

1684年—1842年，[[闽海关]]始設於漳州，由[[福州将军|福州將軍]]兼管。[[道光]]二十二年（1842年），閩海關迁至福州，依舊歸福州將軍管理。

1864年—1865年，[[太平天国]]侍王[[李世贤]]在漳州建立政权<ref>{{Cite web |url=https://books.google.com.tw/books?id=ZUGEAAAAIAAJ&q=%E6%9D%8E%E4%B8%96%E8%B4%A4+%E7%A6%8F%E5%BB%BA+%E6%94%BF%E6%9D%83&dq=%E6%9D%8E%E4%B8%96%E8%B4%A4+%E7%A6%8F%E5%BB%BA+%E6%94%BF%E6%9D%83&hl=zh-CN&sa=X&ved=2ahUKEwiP4_rZ8pb9AhWRZt4KHUqBDeQQ6AF6BAgFEAI |title=简明中囯近代史 |access-date=2023-02-15 |archive-date=2023-02-15 |archive-url=https://web.archive.org/web/20230215063622/https://books.google.com.tw/books?id=ZUGEAAAAIAAJ&q=%E6%9D%8E%E4%B8%96%E8%B4%A4+%E7%A6%8F%E5%BB%BA+%E6%94%BF%E6%9D%83&dq=%E6%9D%8E%E4%B8%96%E8%B4%A4+%E7%A6%8F%E5%BB%BA+%E6%94%BF%E6%9D%83&hl=zh-CN&sa=X&ved=2ahUKEwiP4_rZ8pb9AhWRZt4KHUqBDeQQ6AF6BAgFEAI |dead-url=no }}</ref><ref>{{Cite web |url=https://books.google.com.tw/books?id=DbSEAAAAIAAJ&q=%E6%B1%AA%E6%B5%B7%E6%B4%8B+%E6%94%BF%E6%9D%83&dq=%E6%B1%AA%E6%B5%B7%E6%B4%8B+%E6%94%BF%E6%9D%83&hl=zh-CN&sa=X&ved=2ahUKEwjY_pfw9Zb9AhWHEogKHc33DEs4ChDoAXoECAkQAg |title=中國近代史綱 |access-date=2023-02-15 |archive-date=2023-02-15 |archive-url=https://web.archive.org/web/20230215064233/https://books.google.com.tw/books?id=DbSEAAAAIAAJ&q=%E6%B1%AA%E6%B5%B7%E6%B4%8B+%E6%94%BF%E6%9D%83&dq=%E6%B1%AA%E6%B5%B7%E6%B4%8B+%E6%94%BF%E6%9D%83&hl=zh-CN&sa=X&ved=2ahUKEwjY_pfw9Zb9AhWHEogKHc33DEs4ChDoAXoECAkQAg |dead-url=no }}</ref>。

民国初年，属[[汀漳道]]，后撤道，各县直属省辖，又设立行政督察区。

1918年9月—1920年8月，漳州是[[陈炯明]]建立的[[闽南护法区]]的政治中心。[[File:闽南护法区.png|thumb|[[闽南护法区]]控制区域图|left]]

1923年7月—1924年2月，陈炯明任命的潮汕边防督办[[黄大伟]]与赣军将领[[賴世璜|赖世璜]]（依附陈炯明）、[[桂軍|桂军]]将领[[刘志陆]]、[[李厚基]]旧部王献臣在漳州建立“[[联军办事处]]”政权<ref name=wszl>{{Cite book | author = 郑之翰、陈鉴修 | title = 漳州文史资料选辑 | location = [[漳州]] | publisher = [[中国人民政治协商会议]]漳州市委员会文史资料研究委员会 | date = 1982 | accessdate = 2023-07-25 | url = https://mp.weixin.qq.com/s?src=11&timestamp=1690266757&ver=4671&signature=KCV4jwss1Zd*CaZGC2WzkobPBq*eJufPmAIiaFuwL6nvwW53Bc*7Ak8cjWhyhyiyzJSjejd0YzZ0D5qUJlbj0yYWJpz2iQeU1ipTxz4jeLtMPsOtgm13dGirvSp6lQwn&new=1 | language = zh-hans | archive-date = 2023-07-25 | archive-url = https://web.archive.org/web/20230725073848/https://mp.weixin.qq.com/s?src=11&timestamp=1690266757&ver=4671&signature=KCV4jwss1Zd*CaZGC2WzkobPBq*eJufPmAIiaFuwL6nvwW53Bc*7Ak8cjWhyhyiyzJSjejd0YzZ0D5qUJlbj0yYWJpz2iQeU1ipTxz4jeLtMPsOtgm13dGirvSp6lQwn&new=1 | dead-url = no }}</ref>。“联军办事处”政权瓦解后，军阀[[张毅 (1894年)|张毅]]统治漳州一带至1926年11月17日。1928年—1932年，漳州一带由军阀[[张贞 (民国)|张贞]]统治。

1931年2月—1935年，中国共产党的地方组织在[[平和县|平和]]、[[诏安县|诏安]]与[[廣東省 (中華民國)|广东省]][[饶平县|饶平]]、[[大埔县|大埔]]4县交界区域建立[[饶和埔诏苏区]]。1932年4月—1938年2月，[[中国共产党]]的地方组织在[[南靖县|南靖]]、[[平和县|平和]]、[[漳浦县|漳浦]]3县交界区域建立[[靖和浦苏区]]。[[File:靖和浦革命根据地地图.png|thumb|[[靖和浦革命根据地]]地图（1933年）]]

1933年12月13日—1934年1月21日，[[龙溪县]]（漳州）短暂作为[[中华共和国]][[龙汀省]]（初称龙漳省）省会，还在1934年1月13日—21日成为中华共和国首都，历时8天<ref>{{Cite web |url=http://wmf.fjsen.com/2013-11/18/content_12987153_2.htm |title=漳州史上曾做过八天“国都” |access-date=2022-11-10 |archive-date=2022-11-10 |archive-url=https://web.archive.org/web/20221110041904/http://wmf.fjsen.com/2013-11/18/content_12987153_2.htm |dead-url=no }}</ref>。

中華民国大陸時期末年，今漳州市大部分地区属第五[[行政督察区]]。

=== 1949年至今 ===
1949年，[[中国人民解放军|解放军]]占领漳州。1950年，成立[[龙溪专区]]。1951年6月，析龙溪县城关设县级漳州市。1960年，龙溪县与海澄县合并为[[龙海区|龙海县]]。1971年，龙溪专区改称[[龙溪专区|龙溪地区]]。1985年6月，龙溪地区改设地级漳州市，原县级漳州市改设[[芗城区]]。1993年，龙海县改设县级[[龙海区|龙海市]]。1996年，析芗城区和龙海市部分区域设[[龙文区]]。2021年2月2日，龙海市、长泰县撤县（市）设区行政区划调整，设[[龙海区]]、[[长泰区]]。

此外，名义上划属漳州市龙海区的[[东碇岛]]目前为中華民國实际控制，由[[金门县]]管辖。

== 地理 ==
漳州為福建省最南端的[[地級市]]，與[[廣東省]]為鄰。漳州西北多山，东南滨海，属南[[亚热带季风气候]]，年平均温度21℃，年降雨量1500毫米。

漳州地处[[福建]]东南。[[陆域]]南北长187公里，东西宽127公里，面积12607平方公里，介于北纬23°34′至25°15′、东经116°54′至118°08′之间。东邻福建省厦门市、东北与福建省泉州市接壤，西北与福建省龙岩市毗邻，西与广东省梅州、潮州两市交界，东南与台湾隔海相望。

[[博平岭]]横亘于西北，[[戴云山]]餘脉深入北部境内。[[平和县]]的[[大芹山]]主峰海拔1544.5米，为全市第一高峰。九龙江全长258公里，为福建第二大河。流域面积14741平方公里，在漳州境内流域面积7586平方公里。此外还有[[鹿溪]]、[[漳江]]、[[东溪 (晋江支流)|东溪]]等主要河流。[[九龙江]]中下游平原面积720平方公里，是省内最大[[平原]]。

== 人口 ==
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为5,054,328人<ref>{{cite web |author1=漳州市统计局、漳州市第七次全国人口普查领导小组办公室 |title=漳州市第七次全国人口普查公报 |url=http://tjj.zhangzhou.gov.cn/cms/html/zzstjj/2021-06-10/91345274.html }}{{Dead link}}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的4,809,983人相比，十年共增加了244,345人，增长5.08%，年平均增长率为0.5%。其中，男性人口为2,599,071人，占总人口的51.42%；女性人口为2,455,257人，占总人口的48.58%。总人口性别比（以女性为100）为105.86。0－14岁的人口为1,004,102人，占总人口的19.87%；15－59岁的人口为3,143,679人，占总人口的62.2%；60岁及以上的人口为906,547人，占总人口的17.94%，其中65岁及以上的人口为623,456人，占总人口的12.34%。居住在城镇的人口为3,101,501人，占总人口的61.36%；居住在乡村的人口为1,952,827人，占总人口的38.64%。

2022年末，全市常住人口506.8万人，比上年末减少0.2万人，其中，城镇常住人口321万人，城镇化率为63.3%。全年出生人口3.7万人，出生率为7.30‰；死亡人口3.5万人，死亡率为6.90‰；自然增长率为0.39‰。年末户籍人口数为527.2万人，比上年末增加1.0万人，增长0.19%。<ref>[https://www.hongheiku.com/shijirenkou/1405.html 2022年漳州市人口] {{Wayback|url=https://www.hongheiku.com/shijirenkou/1405.html |date=20220124071706 }}</ref>

=== 民族 ===
全市常住人口中，[[汉族]]人口为4,952,602人，占97.99%；各[[中国少数民族|少数民族]]人口为101,726人，占2.01%。其中，[[畲族]]人口为46,891人，占0.93%。与2010年第六次全国人口普查相比，汉族人口增加218,361人，增长4.61%，占总人口比例下降0.44个百分点；各少数民族人口增加25,984人，增长34.31%，占总人口比例增加0.44个百分点。其中，畲族人口减少3,475人，下降6.9%，占总人口比例下降0.12个百分点。

== 語言 ==
{{参见|漳州话|漳潮客语}}
漳州市的主要方言为[[閩語]][[閩南片]][[泉漳片|泉漳小片]][[漳州话]]（可细分为北部小片和南部小片），在漳州市大部分地方通行。漳州话保留較多[[中古漢語]]特色，擁有发达的[[文白异读]]系统。

此外，还有其他方言分布：
*[[客家语]][[漳潮客语|漳潮片]]：通行于[[平和县]]西南部、[[诏安县]]北部和[[南靖县]]西端。
*[[闽语]][[闽南片]][[潮汕片|潮汕小片]][[饶平话]]：通行于[[诏安县]]西端。
*[[闽语]][[闽南片]][[泉漳片|泉漳小片]][[泉州话]]府城腔：通行于[[华安县]]东北部。
*[[闽语]][[闽南片]][[泉漳片|泉漳片]]西片[[漳平话]]：通行于[[华安县]]西部以及[[南靖县]]北端和西北端。
*[[山客话]]：通行于[[华安县]][[新圩镇 (华安县)|新圩镇]]官畲村和坪水村。

== 文化 ==
漳州文化生活豐富，並擁有大量國家級非物質文化遺產。漳州市的漳州[[木版年画]]、漳州木偶头雕刻、[[歌仔戏]]（薌劇）、漳州[[布袋木偶戏]]、[[锦歌]]、漳州蔡福美传统制鼓技艺、漳州八宝印泥、龙海区的[[保生大帝]]、漳浦县的漳浦剪纸信俗、华安县的高山族拉手舞及东山县的东山歌册被列入[[国家级非物质文化遗产名录]]。此外、漳州文化还包括有[[潮剧]]、[[剪紙]]、[[灯謎]]、[[車鼓弄|大車鼓舞蹈]]、[[泉州南音]]等。
