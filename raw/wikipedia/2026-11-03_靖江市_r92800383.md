'''靖江市'''位于[[中华人民共和国]][[江苏省]]中南部，为[[中国]][[江苏省]]下辖[[县级市]]，现由[[泰州市]]代管。是江苏省新兴的港口工业城市，区域总面积为665平方公里。市人民政府驻[[靖城街道]]。靖江历史上又有'''马洲'''、'''骥江'''、'''骥沙'''、'''骥渚'''、'''阴沙'''、'''牧城'''等旧称<ref>{{Cite web|author=马洲文化|date=2023-08-03|title=靖江现存历代文物简述|url=https://www.jingjiang.gov.cn/zjjj/jjgk/whct/art/2022/art_8b90e5e5daf94380b03fab1743a3d2cd.html|access-date=2023-11-19|website=靖江市人民政府|archive-date=2025-06-13|archive-url=https://web.archive.org/web/20250613055948/https://www.jingjiang.gov.cn/zjjj/jjgk/whct/art/2022/art_8b90e5e5daf94380b03fab1743a3d2cd.html|dead-url=no}}</ref>。

== 历史 ==
靖江原是[[长江]]中的一片[[沙洲]]，[[宋]]代移民垦殖，以后逐渐与北岸连接。靖江建县于[[明朝|明]][[成化]]七年（公元1471年）<ref name=":0">{{Cite web|author=靖江市府办|date=2023-03-21|title=靖江概况（2023）|url=https://www.jingjiang.gov.cn/zjjj/jjgk/jjgl/art/2023/art_e5bea020f682468fa52d3a6070281ac2.html|access-date=2023-11-19|website=靖江市人民政府|archive-date=2023-11-19|archive-url=https://web.archive.org/web/20231119123943/https://www.jingjiang.gov.cn/zjjj/jjgk/jjgl/art/2023/art_e5bea020f682468fa52d3a6070281ac2.html|dead-url=yes}}</ref>，由[[江阴县]]析置，隶属[[南直隶]][[常州府]]，为常州五邑之一。[[清]]代属于江苏省常州府，为常州八邑之一。[[中華民國|民国]]初年属于江苏省苏常道。1949年属于苏北行政公署。1952年以后属于扬州地区及[[扬州市]]，1993年撤县建市，1996年改由[[泰州市]]代管。

== 人口 ==
根據[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]結果，截至2020年11月1日零时，靖江市常住人口66.34万人。

== 地理 ==
靖江市位于[[长江]]下游北岸，东、西、南三面临江，总面积665平方公里，拥有52.3公里的长江岸线，其中深水岸线35公里<ref name=":0" />。因地处[[长江三角洲]]的冲积平原，其地势低平。靖江气候四季分明，冬天最冷可达零下10度。靖江市隔[[长江]]与[[江阴市]]、[[张家港市]]相对，北侧毗邻[[泰兴市]]及[[如皋市]]。

== 产业 ==

=== 造船业 ===
靖江市的深水岸线长，为[[造船]]提供了良好的地理环境。靖江市的首批造船产业起步于20世纪70年代初，后于90年代因中国加入[[世界贸易组织]]，伴随国际造船业进入第二轮复苏期，靖江造船业因劳动力成本低等原因得以获得快速发展的机遇<ref name=":1">{{Cite web|author=中国县域经济报记者姜帆|author2=张伟伟|date=2023-08-24|title=江苏靖江造船业领跑全国|url=http://paper.ce.cn/pad/content/202308/24/content_279832.html|access-date=2023-11-19|website=经济日报|archive-date=2024-12-11|archive-url=https://web.archive.org/web/20241211011331/http://paper.ce.cn/pad/content/202308/24/content_279832.html|dead-url=no}}</ref>。现今，靖江是中国规模最大、配套最完善的民营造船基地<ref name=":1" />、中国国家级的船舶出口基地<ref>{{Cite web|author=经济网|date=2023-11-08|title=从新时代造船看江苏靖江为何成为国家级船舶出口基地|url=http://www.eworldship.com/html/2023/Shipyards_1108/197782.html|access-date=2023-11-19|website=国际船舶网|archive-date=2023-11-19|archive-url=https://web.archive.org/web/20231119123947/http://www.eworldship.com/html/2023/Shipyards_1108/197782.html|dead-url=no}}</ref>。2021年靖江一个市的造船量超过世界排名第三造船大国[[日本]]<ref>{{Cite web|author=正解局|date=2023-10-30|title=江苏一个县造的船，比日本还多：怎么做到的？|url=https://t.10jqka.com.cn/pid_318136243.shtml|access-date=2023-11-19|website=同花顺|archive-date=2023-11-19|archive-url=https://web.archive.org/web/20231119123948/https://t.10jqka.com.cn/pid_318136243.shtml|dead-url=no}}</ref>。2022年，靖江造船企业手持订单占全球十分之一<ref>{{Cite web|author=靖江市政府办公室|date=2023-02-16|title=靖江造船企业手持订单占全球十分之一|url=https://www.taizhou.gov.cn/xwzx/sqdt/art/2023/art_435a15554d454ec8ba6b0ec1a83f9ca3.html|access-date=2023-11-19|website=泰州市人民政府|archive-date=2025-06-13|archive-url=https://web.archive.org/web/20250613060118/https://www.taizhou.gov.cn/xwzx/sqdt/art/2023/art_435a15554d454ec8ba6b0ec1a83f9ca3.html|dead-url=no}}</ref>。来自靖江的[[江苏扬子江船业集团公司]]和[[江苏新时代造船有限公司]]位居2023年上半年中国造船完工量企业排名前两名<ref>{{Cite web|author=中国船舶工业行业协会|date=2023-07-21|title=一图读懂丨2023年上半年船舶统计数据|url=http://www.cansi.org.cn/cms/document/18883.html|access-date=2023-11-19|website=中国船舶工业行业协会|archive-date=2024-12-09|archive-url=https://web.archive.org/web/20241209051004/http://www.cansi.org.cn/cms/document/18883.html|dead-url=no}}</ref>。

== 文化 ==
===方言===
靖江大部分地区所说的[[靖江话]]（[[老岸话]]）属于[[吴语]]，是长江以北使用吴语的少数几个县市之一。老岸话的使用人口约占七成。西南部沿江的新桥镇、东兴镇、八圩镇说[[沙上话]]（与[[扬中话]]基本相同）属于[[江淮方言]]，使用人口约占总人口二成。其他一成的人口操[[夹沙话]]、[[崇明话]]、[[泰兴话]]、[[如皋话]]等。
