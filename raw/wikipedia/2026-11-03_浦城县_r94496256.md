'''浦城县'''位于中华人民共和国[[福建省]]最北端，隶属于[[南平市]]。踞八闽上游，[[仙霞岭]]山脉与[[武夷山脉]]交接处，为江西，浙江，福建三省交界处。总面积为3,383.02平方公里。浦城县历来就是兵家必争之地，是福建的“北大門”，自古為中原入閩第一關，为闽北交通要地。

== 历史沿革 ==
[[秦朝|秦]]时，属[[闽中郡]]。[[闽越]]时，在今浦城县境内筑[[临浦城]]、[[临江城]]和[[汉阳城]]。[[汉朝|汉]][[始元 (西汉)|始元]]年间，设'''[[冶县]]'''，今浦城县地属之。[[东汉]][[建安 (东汉)|建安]]年间，置'''汉兴县'''。[[三国]][[永安 (东吴)|永安]]年间，改称'''[[吴兴县 (孙吴)|吴兴县]]'''。[[隋朝|隋]][[开皇]]年间，吴兴县并入[[建安县 (东汉)|建安县]]。[[唐朝|唐]][[武德]]年间，置'''唐兴县'''。[[天授 (武周)|天授]]年间，改称'''武宁县'''。[[神龍 (年號)|神龙]]年间，复名唐兴县，[[天宝 (唐朝)|天宝]]年间，定名'''浦城县'''。1931年—1935年，[[中国共产党]]在浦城县境内先后建立[[建浦县]]、浦城县、[[广浦县]]、[[浦西特区]]、[[龙浦县]]等5个县级苏维埃政权，实行红色割据。

== 地理 ==
以[[山地]]为主。

最高峰[[营盘尖]]，海拔1,664米，位于东北部。属亚热带季风气候。

主要河流[[南浦溪]]。

属中亚热带季风湿润气候区，年平均气温17.4℃，年平均降雨量1,780.2毫米，为福建省多雨地带之一。常年平均日照时数为1,893.5小时。

== 经济 ==
以农业工业为主，为福建省最大的商品粮基地，近年来工业与服务业在经济中的比重不断上升。

== 語言 ==
浦城县南部通行[[闽北语]]，北部通行[[吴语]]的[[上丽片|处衢片]]方言[[浦城話]]。

== 文化教育 ==
以闽北文化为主，近十年来县府在小学增设乡土课程学习闽北文化。

==物产==
* 盛产稻麦，浦城[[薏米]]为[[中国地理标志产品]]<ref>{{Cite web|title=《地理标志产品保护规定》实施以来批准的地理标志名录（2005年7月至2009年6月）|url=http://kjs.aqsiq.gov.cn/dlbzcpbhwz/bhml/200906/t20090622_118997.htm|accessdate=2021-03-26|publisher=中华人民共和国国家质量监督检验检疫总局|archiveurl=https://web.archive.org/web/20110311120900/http://kjs.aqsiq.gov.cn/dlbzcpbhwz/bhml/200906/t20090622_118997.htm|archivedate=2011-03-11|dead-url=yes}}</ref>。
* [[浦城桂花]]为[[中国地理标志产品]]。
* 矿产有铜、铅、锌、锡、金、银、钴、铁、硫铁、煤、钨、钼、铀、萤石、磷、钾长石、蛇纹石、云母、石棉、石墨、大理石等29种。
* 野生动物主要有虎、豹、熊、猴、山羊、角怪、[[鸳鸯]]、[[穿山甲]]、[[娃娃鱼]]等。
* 药材主要有[[泽泻]]、[[厚朴]]、莲子、米仁、[[蕲蛇]]等。
* 当地名小吃和食物有灯盏糕（也称[[盒子糕]]）、锅边糊（也称[[鼎边糊]]）、肉饼、酸枣糕、大米粿、肉燕、豆腐丸等。
