'''盘锦市'''是[[中华人民共和国]][[辽宁省]]下辖的[[地级市]]，位于辽宁中南部，[[辽河]]下游。市境西、北邻[[锦州市]]，东界[[鞍山市]]，东南接[[营口市]]，南临[[渤海]][[辽东湾]]，是中國沿海最北端的地級市。市人民政府驻[[兴隆台区|大窪區]]。

盘锦市是辽宁省乃至整个[[中国东北地区|东北地区]]重要的石油城市、工业城市之一，于1984年经[[中华人民共和国国务院|国务院]]批准建立，坐拥中国第三大油田[[辽河油田]]和新兴中国石化五百强企业[[中国兵器工业集团|华锦化工集团]]。辖区内分布有很多采油厂，例如曙光采油厂，兴隆台采油厂，高升采油厂等，境內有東北第二大[[沼澤]]區，佔地15000畝。

== 地名 ==
“盘锦”一名始于1950年轻工业部在盘山县、锦县交界处设立的盘锦苇场。一说盘锦苇场的“盘锦”来自附近的盘锦河，另一说是取盘山县、锦县两县首字，以示苇场在两县之间。<ref>{{Cite web |title=“盘锦”地名由来 |url=http://lnsdfz.gov.cn/dm/201111/t20111122_753910.html |accessdate=2020-07-23 |date=2012-05-22 |publisher=辽宁省地方志 |archive-date=2021-02-15 |archive-url=https://web.archive.org/web/20210215162639/http://lnsdfz.gov.cn/dm/201111/t20111122_753910.html |dead-url=no }}</ref><ref>{{cite book |editor=盘锦市大洼县地方志编纂委员会 |title=大洼县志 |date=1998-05 |publisher=沈阳出版社 |location=沈阳 |isbn=7-5441-1109-1 |pages=200}}</ref>

如今，盘锦市又有“油城”“鹤乡”之称。

== 历史 ==
盘锦市所辖地区在[[战国时期]]属[[燕国]]版图，[[东汉|汉]]末属[[辽西郡]]。[[晋朝|晋]]、[[南北朝]]时为[[高句丽]]占据。

[[唐朝|唐]]灭[[高句丽]]后，设[[都护府]]，后改为[[显宁府]]，[[元朝]]属[[广宁府路]]。

[[明朝]]为[[广宁卫]]，境内有高平驿、盘山驿等[[驿站]]，成为边陲重地，军事交通要道。

清初[[汉地#清代至民國|关内]]向[[中国东北地区|东北]]移民，是中国历史上最大的人口移动之一，盘锦地区开始有大规模的人类活动。

[[清朝]]属[[廣寧縣 (奉天)|广宁县]]，光绪三十二年（1906年）设盘蛇驿（明盘山驿，今[[北镇]]境内），清末改为[[盘山厅]]。

《盘山县志》记载，1908年，经双台子绅商联名呈请，盘山厅署从盘蛇驿搬到被谓之为“交通便利，碱河（即[[双台子河]]）前横，地靠火车站、河码头，形止气蓄，乃天然巨镇”的双台子。

民国2年（公元1913年）改厅为[[縣 (中華民國)|县]]，名为[[盘山县]]。

1932年，[[满州国]]改[[辽宁省]]为[[奉天省 (滿洲國)|奉天省]]，辖盘锦地境；

1934年，[[锦州省]]成立，辖盘山县。 

1937年12月，[[大辽河]]以西的[[海城县 (辽宁省)|海城县]]第六区、营口县第七区划归盘山县管辖。 

1945年，[[日本投降|“八一五”光复]]后，是年10月[[中国共产党]]领导的盘山县民主政府成立，属辽西地委；是年12月，[[中国国民党]]领导的盘山县政府成立，盘山县民主政府转[[田庄台镇|田庄台]]。 

1948年2月，中国人民解放军进驻盘锦地区全境，成立盘山县人民政府，隶属[[辽西省]]。1949年在今大洼县境内成立盘山农场，隶属[[東北行政委員會 (1946年－1949年)|东北行政委员会]]农林部。1950年，盘山农场改为辽西省盘山第一稻田农场。1953年2月，盘山第一稻田农场改为盘山机械农场。1954年，辽西省、[[辽东省]]合并，归属于[[辽宁省]]。1955年，改为辽宁省盘锦国营农场管理局。1956年11月，盘锦地区国营农场管理局改为盘锦农垦局，直属[[农垦部]]。1961年4月，在盘锦农垦局管辖地区设置盘锦区人民委员会，归营口市领导。1962年4月，辽滨苇场所属的大辽河东岸苇田划给营口县和海城县。1966年1月，盘山县与盘锦农垦局合并为[[盘锦垦区]]，试行政场合一制，直属辽宁省。

1970年1月，在盘锦垦区内分设县级[[盘山区]]和[[大洼区]]。1970年7月15日，将盘锦垦区改为[[盘锦地区]]，辖盘山区和大洼区，直属辽宁省。1975年11月，盘锦地区与营口市合并，原地区所辖盘山区、大洼区改为盘山县、大洼县。同时将台安县划归鞍山市。1978年，将原营口市[[河北街道 (营口市)|河北街]]从辽滨苇场划出，归营口市西市区管辖。 

1984年6月5日《国务院关于辽宁省成立盘锦市的批复》(84)国函字89号，设立[[地级市|地级]]盘锦市，归属辽宁省管辖，以原[[盘山县]]的行政区域设[[盘山区|盘山]]、[[兴隆台区|兴隆台]]、[[郊区 (盘锦市)|郊区]]三个区，[[大洼县]]划归盘锦市管辖。<ref>{{Cite web|url=http://www.xzqh.org/html/show/ln/4401.html|title=盘锦市历史沿革|publisher=行政区划网|date=2011-08-04|accessdate=2011-08-07|archive-date=2021-02-15|archive-url=https://web.archive.org/web/20210215162705/http://www.xzqh.org/html/show/ln/4401.html|dead-url=no}}</ref>9月，成立盘锦市筹备领导小组。1985年3月，石山种畜场划归盘锦市。1986年11月，撤销[[盘锦市郊区]]，恢复盘山县，以原盘锦市郊区的行政区域为盘山县的行政区域。将原盘锦市盘山区更名为双台子区。

2016年3月，国务院同意撤销大洼县，设立盘锦市大洼区，以原大洼县的行政区域为大洼区的行政区域，大洼区人民政府驻大洼镇红海滩大街66号。

== 自然环境 ==
[[File:盘锦芦苇荡panjin bulrush reserve area - panoramio.jpg|thumb|盘锦芦苇荡]]
盘锦市坐落于辽宁省西南部，位于[[辽河]]的入海口和[[渤海]]北岸，地理坐标为北纬40°39′—41°27′、东经121°25′— 122°31′。总面积4062.34平方公里<ref>{{Cite web|title=盘锦简介|url=https://www.panjin.gov.cn/html/1772/|access-date=2023-11-15|website=盘锦市人民政府|language=zh-cn|archive-date=2024-01-16|archive-url=https://web.archive.org/web/20240116214414/https://www.panjin.gov.cn/html/1772/|dead-url=no}}</ref>。

=== 自然地理 ===
盘锦是一座湿地城市，辽河口湿地位于盘锦，使其素有“湿地之都”之称。盘锦地处[[辽河平原|辽河冲积平原]]最南端的[[辽河三角洲]]，属于退海冲积平原，地势平坦低洼，全境无山脉，平均海拔仅4米。盘锦据有全中国境内海岸线的最北端。辽河（[[双台子河]]）贯穿市境中部，东南缘为[[浑河]]（[[大辽河]]），西缘为[[大凌河]]，均注入盘锦境内的[[辽东湾]]。

盘锦是从[[燕山运动]]开始形成的[[新生代]][[沉積盆地|沉积盆地]]，经过漫长年代的河流冲积、洪积、海积和风积，不断覆盖着深厚的四季松散沉积物，且[[盐碱地|盐碱]]成分高<ref>{{Cite book|title=《盘锦市志》综合卷|year=1998|pages=352-356}}</ref>，区内前新生代岩石地层属华北地层区。自新生代以来地层以沉积为主，区内上部新近沉积土以淤泥质亚黏土、粉质黏土、黏土、粉土、粉砂、细砂为主，地基承载力一般为 50~150kPa，欠固结，易造成建筑物地基下沉<ref name=":0">{{Cite journal |author=张静 |author2=冯东向 |author3=綦巍 |author4=周雪 |author5=赵玉星 |date=2018 |title=基于 SBAS-InSAR技术的盘锦地区地面沉降监测 |journal=工程地质学报 |volume=26 |issue=4 |page=99-107 |doi=10.1354/j.cnki.jeg.2017-382}}</ref>。

=== 自然景观 ===
盘锦素有“鹤乡”的美称，因其所在的辽河三角洲作为许多濒危鸟类如[[丹顶鹤]]和[[黑嘴鸥]]的繁殖地而得名，其境内亦有[[斑海豹]]分布。盘锦市亦为世界最大芦苇生产基地<ref name=":0" />。在开垦前，盘锦市的市区大部分为大片的苇田、荒地，现今主要位于大洼区。辽河三角洲的湿地上盛产[[碱蓬|碱蓬草]]。随着其成熟，大片的碱蓬草地会被染红，形成盘锦市最著名的景观“红海滩”。

== 人口 ==
截至2022年底，盘锦市户籍人口129.3万人。全年出生人口6332人，出生率4.9‰；死亡人口6021人，死亡率4.7‰；人口自然增长率0.2‰。全市户籍人口中，0—17岁人口17.3万人，占13.4%；18—34岁人口23.6万人，占18.3%；35—59岁人口55.8万人，占43.1%；60岁及以上人口32.6万人，占25.2%。<ref>2022年盘锦市户籍人口<nowiki/>https://www.panjin.gov.cn/html/1934/2022-03-14/content-112668.html {{Wayback|url=https://www.panjin.gov.cn/html/1934/2022-03-14/content-112668.html |date=20230817150827 }}</ref>

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为1,389,691人<ref>{{cite web |author1=盘锦市统计局、盘锦市第七次全国人口普查领导小组办公室 |title=盘锦市第七次全国人口普查公报 |url=https://tjj.panjin.gov.cn/2021_06/10_08/content-326970.html |access-date=2023-07-23 |archive-date=2023-07-23 |archive-url=https://web.archive.org/web/20230723214757/https://tjj.panjin.gov.cn/2021_06/10_08/content-326970.html |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的1,392,493人相比，十年共减少了2,802人，下降0.2%，年平均增长率为-0.02%。其中，男性人口为692,330人，占总人口的49.82%；女性人口为697,361人，占总人口的50.18%。总人口性别比（以女性为100）为99.28。0－14岁的人口为166,985人，占总人口的12.02%；15－59岁的人口为907,698人，占总人口的65.32%；60岁及以上的人口为315,008人，占总人口的22.67%，其中65岁及以上的人口为218,588人，占总人口的15.73%。居住在城镇的人口为1,075,688人，占总人口的77.4%；居住在乡村的人口为314,003人，占总人口的22.6%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为1,316,741人，占94.75%；各[[少数民族]]人口为72,950人，占5.25%。与2010年第六次全国人口普查相比，汉族人口减少22,598人，下降1.69%，占总人口比例下降1.43个百分点；各少数民族人口增加19,796人，增长37.24%，占总人口比例增加1.43个百分点。其中，[[满族]]人口增加15,790人，增长48.29%，占总人口比例增加1.14个百分点；[[朝鲜族]]人口减少1,056人，下降10.65%，占总人口比例下降0.07个百分点；[[蒙古族]]人口增加3,221人，增长60.75%，占总人口比例增加0.23个百分点。

== 經濟 ==

=== 石油经济 ===
{{参见|辽河油田}}
盘锦市坐拥的[[辽河油田]]，在1990年代曾是[[中華人民共和國|中国]]的产量仅次于[[大庆油田]]和[[胜利油田]]的第三大[[油田]]。这一资源优势使盘锦成为[[辽宁省]]及[[中国东北地区]]重要的油城，其油气采掘业一度占到全市工业份额的90％左右<ref name=":1">{{Cite web |title=从卖原料到精加工——“油城”盘锦加快建设世界级石化基地 |url=https://www.gov.cn/xinwen/2019-08/07/content_5419518.htm |website=中国政府网 |date=2019-08-07 |author=王炳坤、李宇佳 |access-date=2025-06-22 |via=新华社 |archive-date=2025-06-22 |archive-url=https://web.archive.org/web/20250622042657/https://www.gov.cn/xinwen/2019-08/07/content_5419518.htm |dead-url=no }}</ref>，经济发展深受[[石油]]资源和[[石油產業]]的驱动。但自[[九五计划]]起，辽河油田油气产量出现逐年递减的趋向<ref>{{Cite web |title=发展接续产业避免资源型城市“矿竭城衰” |url=https://finance.sina.cn/sa/2004-03-12/detail-ikkntiak7944411.d.html |website=新浪财经 |date=2004-03-12 |author=张毅、于力、张米扬 |last= |access-date=2025-06-22 |via=新华网 |archive-date=2025-06-22 |archive-url=https://web.archive.org/web/20250622042657/https://finance.sina.cn/sa/2004-03-12/detail-ikkntiak7944411.d.html |dead-url=no }}</ref>，2007年，盘锦被中国政府列为资源型城市经济转型试点市<ref name=":1" />，2008年被认定为[[资源枯竭型城市]]<ref>{{Cite web |title=这座资源枯竭城市为何“长”出一批“瞪羚企业” |url=https://www.panjin.gov.cn/html/2535/2021-12-16/content-109128.html |website=盘锦市人民政府 |date=2021-12-16 |access-date=2025-06-22 |via=新华社 |archive-date=2025-06-22 |archive-url=https://web.archive.org/web/20250622042657/https://www.panjin.gov.cn/html/2535/2021-12-16/content-109128.html |dead-url=no }}</ref>。

1992年4月，盘锦成立盘锦经济开发区，旨于发展[[外向型经济]]和石油高新技术产业<ref>{{Cite web |title=盘锦经济开发区简介 |url=https://gd.huaxia.com/c/2010/10/18/697969.shtml |website=华夏经纬版权所有盘锦市人民政府台湾事务办公室 |date=2010-10-18 |access-date=2025-06-22 |archive-date=2023-03-23 |archive-url=https://web.archive.org/web/20230323175557/https://gd.huaxia.com/c/2010/10/18/697969.shtml |dead-url=no }}</ref>。1993年3月，该经开区晋升为省级开发区，2013年5月盘锦在盘锦经济开发区基础上转型建设了盘锦高新技术产业开发区<ref name=":2">{{Cite web |title=辽宁盘锦高新区创建国家高新区案例（国家高新区创建方案） |url=https://www.sohu.com/a/www.sohu.com/a/521867636_626579 |website=搜狐 |date=2022-02-10 |author=高新技术产业研究院 |access-date=2025-06-22}}</ref><ref name=":3">{{Cite web |title=园区简介 |url=https://gxq.panjin.gov.cn/11812/ |website=盘锦高新技术产业开发区管理委员会 |date=2024-11-12 |access-date=2025-06-22 |archive-date=2020-11-26 |archive-url=https://web.archive.org/web/20201126071827/http://gxq.panjin.gov.cn/11812/ |dead-url=no }}</ref>。盘锦高新技术产业开发区地处[[兴隆台区]]北部，规划面积达47平方公里，下辖“能源装备制造产业园”“石油化工产业园”“数字经济产业园”，发展方向为高端装备制造、石油化工、光学电子、数字经济、新材料、新医药、新能源等产业<ref name=":2" />。至2015年，盘锦市的非油气产业增加值占全市经济比重已接近80%，其中精细化工、石油装备等六大接续产业占九成<ref name=":4">{{Cite web |title=东北资源型城市走出转型新路（东北地区转型发展亮点） |url=http://politics.people.com.cn/n/2015/0309/c1001-26658036.html |website=人民网 |date=2015-03-09 |author=何勇、刘文波 |last= |url-status=no |archive-url=https://web.archive.org/web/20150607190628/http://politics.people.com.cn/n/2015/0309/c1001-26658036.html |archive-date=2015-06-07 |access-date=2025-06-22 }}</ref>。2023年高新区实现地区生产总值90.5亿元人民币<ref name=":3" />。[[File:Liaohe oil field.jpg|thumb|[[辽河油田]]位于盘锦市。]]
2019年3月，[[沙特阿美]]联手[[北方工业集团]]、盘锦鑫诚实业集团联合成立华锦阿美石油化工有限公司<ref name=":1" />，计划在盘锦市建设一座大型炼油化工一体化联合装置，该项目于2023年第二季度开工建设，2026年投入运营<ref>{{Cite web |url=https://m.caixin.com/m/2023-03-27/102012446.html?cx_referer=https%3A%2F%2Fwww.caixin.com%2F2023-03-27%2F102012446.html |title=能源内参｜沙特阿美辽宁盘锦合资炼化项目将开工 总投资超百亿美元；经过386轮竞价 中石化301.5亿元竞得内蒙古一煤矿 |access-date=2023-03-27 |archive-date=2023-03-27 |archive-url=https://web.archive.org/web/20230327103243/https://m.caixin.com/m/2023-03-27/102012446.html?cx_referer=https://www.caixin.com/2023-03-27/102012446.html |dead-url=no }}</ref>。

=== 海洋经济 ===
2005年12月，盘锦市在[[大辽河]]入海口东岸，位于[[大洼县]]境内组建了辽滨经济区，以图发展五万吨级以下中、小[[船舶制造]]，[[石油化工业|石油化工]]中下游产业和[[海洋工程]]装备制造产业，其规划总面积73平方公里，拥有8万亩滩涂和3万亩闲置荒地<ref name=":5">{{Cite web |title=问城盘锦：资源枯竭型城市转型的产业抉择 |url=https://news.sciencenet.cn/sbhtmlnews/2009/4/218390.html |website=科学网 |date=2009-04-19 |author=张赋兴 |access-date=2025-06-22 |via=科学时报 |archive-date=2025-06-22 |archive-url=https://web.archive.org/web/20250622042657/https://news.sciencenet.cn/sbhtmlnews/2009/4/218390.html |dead-url=no }}</ref>。同年，辽滨经济区引进了辽宁宏冠船业有限公司、辽河石油勘探局海洋装备制造总厂等19个项目<ref name=":5" />。2006年6月，[[辽宁省人民政府]]将盘锦辽滨经济区纳入[[辽宁沿海经济带]]。

=== 农产 ===
盘锦持有的[[中国地理标志产品]]有：[[盘锦河蟹]]（有「北方[[大闸蟹]]」美誉）、[[盘锦河豚]]、[[盘锦泥鳅]]、[[盘锦大米]]（尤以[[大洼县]][[清水乡]]大米远近驰名。“盘锦大米”具有中国名牌和中国驰名商标两项殊荣。2011年盘锦大米荣获“中国粮油榜十佳粮食地理品牌”和“最具影响力中国农产品区域公用品牌”两个殊荣。2012年9月，盘锦被中国粮食行业协会授予“生态稻米之乡”称号）、盘锦[[盐碱地]][[番茄]]（盐碱土壤环境下生长的一种水果型番茄）。

此外还有可造[[紙]]的[[芦苇]]与大洼县[[唐家镇 (盘锦市)|唐家镇]]的[[盘锦北窑葡萄]]等特产。

=== 旅游业 ===
盘锦是[[大辽河]]、[[辽河]]、[[大凌河]]与[[渤海]]交汇处，其[[湿地]]广阔、珍稀禽鸟多、自然景观独特、水乡物产丰富<ref name=":4" />。人文资源方面，有中日甲午陆战最后一仗战场的[[甲午战争田庄台遗址]]，有[[张作霖]]、[[张学良]]祖居地的大洼县[[东风镇 (盘锦市)|东风镇]]，有中国唯一通代[[碑林]]“辽河碑林”等<ref>{{Cite web |title=湿地之都――生态盘锦 |url=https://gd.huaxia.com/c/2010/10/18/697943.shtml |website=华夏经纬版权所有盘锦市人民政府台湾事务办公室 |date=2010-10-18 |access-date=2025-06-22 |archive-date=2022-01-22 |archive-url=https://web.archive.org/web/20220122085845/https://gd.huaxia.com/c/2010/10/18/697943.shtml |dead-url=no }}</ref>。

==== 湿地资源 ====
[[File:盘锦芦苇荡.JPG|thumb|位于盘锦的河流和一片芦苇]]盘锦市拥有中国[[国家5A级旅游景区]]一处，即[[红海滩]]风景廊道景区，该景区由数以万计的珍稀水禽和一望无际的浅海滩涂构成<ref>{{Cite web |title=云瞰盘锦红海滩：一望无际的“红色海洋” |url=http://ln.news.cn/20231107/91b1e44af5854a6d8bba9b9e94fbd120/c.html |website=新华网 |date=2023-11-07 |author=刘舒 |access-date=2025-06-21 |archive-date=2024-09-22 |archive-url=https://web.archive.org/web/20240922145156/http://www.ln.news.cn/20231107/91b1e44af5854a6d8bba9b9e94fbd120/c.html |dead-url=no }}</ref>。其滩涂上生长着2.2万亩[[碱蓬属]]植物<ref>{{Cite web |title=从泥滩荒地到“湿地之都”“候鸟天堂” 盘锦：碱蓬草染红了“南大荒” |url=https://www.news.cn/mrdx/2022-10/20/c_1310670514.htm |website=新华每日电讯 |date=2022-10-20 |author=于力、武江民 |access-date=2025-06-21}}</ref>，碱蓬草出土时[[子叶]]鲜红、成熟时植株火红，极具观赏价值，故称红海滩<ref>{{Cite web |title=《以文化的名义说海洋》72说：故乡的辽东湾之四：红火火一一碱蓬草 |url=http://haiyangqiangguo.cn/news-detail-691.html |website=海洋文化教育研究中心 |date=2022-05-27 |author=李明春 |access-date=2025-06-21 |via=海洋文化教育公共服务平台 |archive-date=2023-10-03 |archive-url=https://web.archive.org/web/20231003034553/http://haiyangqiangguo.cn/news-detail-691.html |dead-url=no }}</ref>，是“中国最美六大沼泽湿地”之一<ref>{{Cite web |title=生机勃勃红海滩（行天下） |url=https://paper.people.com.cn/rmrbhwb/pc/content/202505/22/content_30074589.html |website=人民网 |date=2025-05-22 |author=吴树民 |access-date=2025-06-21 |via=《人民日报海外版》（2025年05月22日 第 11 版） |archive-date=2025-05-22 |archive-url=https://web.archive.org/web/20250522080510/http://paper.people.com.cn/rmrbhwb/pc/content/202505/22/content_30074589.html |dead-url=no }}</ref>。除红海滩外，盘锦市还有[[辽河口国家级自然保护区]]，亦是一片沼泽[[湿地]]，其是许多濒危鸟类如[[丹顶鹤]]和[[黑嘴鸥]]的繁殖地，172种上百万的鸟类在迁徙时在此停留，其中包括[[丹顶鹤]]、[[蓑羽鹤]]、[[白鹳]]、[[黑鹳]]、[[白额雁]]、[[大天鹅]]和{{link-en|褐鹰|Brown goshawk}}等超过20种的濒危物种，被誉为鹤乡。地处盘锦市双台子区的盘锦湖滨公园，傍湖而建，此湖属于[[河迹湖]]，曾是[[辽河]]的一个部分，湖滨公园境内包括辽河碑林、湿地动物园等设施。

==== 海滩资源 ====
地处辽东湾的盘锦金帛滩旅游区是一处位于辽滨沿海经济开发区的[[海滩]]，近年来被开辟供旅游用，被宣传为全中国最北端的海滩。
