'''海淀区'''{{NoteTag|“海淀区”的“-{淀}-”字在本詞中並非“-{澱}-”的[[简化字]]<ref>{{cite book |title=北平地名典 |publisher=北平民社 |editor1=李炳衛|editor2=童卓然 |location=北平 |date=1933年8月 |page=第137页 }}</ref>。“-{淀}-”字有淺水湖泊含义<ref name="hddm" />{{rp|1}}。}}是[[中华人民共和国]][[北京市]]西北部的一个[[市辖区]]，是北京最发达的[[北京城六區|中心城区]]之一，地区生产总值位列各区之首<ref name=":7">{{Cite web |title=海淀区信息公开大厅 |url=https://zyk.bjhd.gov.cn/jbdt/auto4514_51808/auto4514_54025/auto4514/auto4514_54045/auto4514/202504/t20250423_4766489.shtml |website=zyk.bjhd.gov.cn |access-date=2025-07-16}}</ref>。全区面积430.77平方公里，南北长约30公里，东西最宽处29公里，边界线长约146.2公里，约占北京面积2.6%<ref>{{Cite web |title=海淀概况_首都之窗_北京市人民政府门户网站 |url=https://www.beijing.gov.cn/renwen/bjgk/hdgk/index.html |website=www.beijing.gov.cn |access-date=2025-09-30 |archive-date=2025-08-14 |archive-url=https://web.archive.org/web/20250814051254/https://www.beijing.gov.cn/renwen/bjgk/hdgk/index.html |dead-url=no }}</ref>。

海淀区山水秀丽、历史悠久、经济昌盛、高校云集。作为高教区，有“中国教育看北京，北京教育看海淀”的说法，[[清华大学]]、[[北京大学]]等均位于此地。

== 区名由来 ==
海淀区因区政府驻[[海淀街道|海淀镇]]而得名，恰如[[丰台区]]因区政府驻[[丰台街道|丰台镇]]而得名。“海淀”在历史上也做“'''海甸'''”、“'''海店'''”、“海垫”<ref>{{Cite book |title=北京地名发展史 |author=孙冬虎 |publisher=北京燕山出版社 |year=2010 |page=195-199}}</ref>，其本名当为「'''海店'''」<ref>《[[钦定日下旧闻考|日下旧闻考]]》卷三十七载：“海店即今海淀。”</ref><ref name=":2">{{Cite journal |author=杨萧杨 |title=元明时期北京海淀附近的地理环境——兼论“海淀”之得名 |url=https://tg.bass.org.cn/CN/10.13262/j.bjsshkxy.bjshkx.221005 |journal=北京社会科学 |year=2022 |issue=10 |page=63-71}}</ref><ref name=":17">{{Cite book |title=燕都说故 |author=白秉全 |publisher=北京燕山出版社 |year=1996 |page=121-124 |chapter=海淀原是「海店」}}</ref>。早在[[元朝|元初]]1260年[[王恽 (元朝)|王恽]]的《[[中堂事记]]》中就有关于“海店”的文字记载 ，至今已七百多年<ref>[[中統 (年號)|中统]]元年（1260年）赴[[元上都|开平]]，三月五日发燕京，宿通玄北郭。六日早憩'''海店'''，距京城二十里。

元代[[王恽 (元朝)|王恽]]《中堂事记》

(中统二年)三月壬辰。五日丙寅，未刻，丞相[[禡禡|祃祃]]与同僚发自燕京，是夕宿通玄北郭。偕行者，都事杨恕、提控术甲谦、详定官周止、省掾王文蔚、刘杰。六日丁卯，午憩'''海店'''，距京城廿里，凡省部未绝事务，于此悉行决遣。是晚宿[[南口地区|南口]]新店，距海店七十里。

== 历史 ==

=== 早期聚落 ===

海淀歷史悠久，最晚在[[战国时期|戰國時代]]已經有村落，区内多处出土了[[春秋时期|春秋]]晚期的方折式[[燕国|匽]]字刀币，[[东升地区]]的[[朱房北站|朱房村]]有周长约两千米的[[清河汉城遗址|汉代古昌平城遗址]]。[[三国]]时，[[曹魏]][[四鎮將軍|镇北将军]][[劉靖 (曹魏)|刘靖]]为[[蓟城]]农业治理[[桑干河|㶟水]]，修戾陵堰，开车箱渠；262年，引㶟水经车箱渠入[[高梁河]]，整饬了西郊水系<ref>{{Cite web |title=本院新闻_首都发展研究院 |url=https://www.bjdi.pku.edu.cn/xwzx/byxw/80268.htm |website=www.bjdi.pku.edu.cn |access-date=2025-12-15}}</ref>；[[玉渊潭公园|玉渊潭]][[八里庄街道 (海淀区)|八里庄]]也出土了[[曹魏]]墓葬。[[File:Northern Wei Buddha Statue.jpg|thumb|[[魏太和造像]]（489年）|left]][[北魏]][[太和 (北魏)|太和]]十三年（489年）三月，佛教徒为[[孝文帝改革|改革]]的[[魏孝文帝|北魏孝文帝]]和其母雕造了一座石佛像，今称[[魏太和造像]]，早于[[洛阳市|洛阳]][[龙门石窟]]，曾立于区内[[苏家坨地区|车耳营村]]山坡上，后被盗，复还后收入[[首都博物馆]]。

[[北齐]][[河清]]三年（564年），[[幽州 (古代)|幽州]][[刺史]][[斛律丰洛|斛律羡]]引高梁河北入[[温榆河|易荆水]]、东入[[潮白河|潞水]]，扩大了[[灌溉|灌区]]<ref>{{Cite web |title=北京西山永定河故事丨永定河上“都江堰” |url=https://xinwen.bjd.com.cn/content/s65a4b803e4b0f6c5abd4cb9b.html |website=xinwen.bjd.com.cn |access-date=2025-12-15}}</ref>。至[[唐朝|唐]][[神龍 (年號)|神龙]]元年 (705年)，于现太舟坞村，设[[羁縻]]府「带州」，在[[天宝 (唐朝)|天宝]]年间（750年）有人口569户, 1990口。
[[File:画家与麦钟桥 - panoramio.jpg|thumb|[[南长河]]（古[[高梁河]]）麦庄桥下[[写生]]的画家（2010年）]]
979年，[[宋太宗]]为收复[[燕雲十六州|燕云十六州]]而北伐[[辽朝|辽国]]，在[[高梁河之战|'''高梁河决战''']]中[[北宋|宋]]军大败，从此无力北上。[[金朝|金代]]，[[金章宗]]在[[西山 (北京)|西山]]筑[[西山八大水院|八大行宫]]；也尝试了水利漕运<ref>金都于燕，东去潞水五十里，故为闸以节高良河、白莲潭诸水，以通山东、河北之粟。

《金史·河渠志》</ref><ref>{{Cite web |title=母亲河“金口”难开_历史名城_首都之窗_北京市人民政府门户网站 |url=https://www.beijing.gov.cn/renwen/lsfm/lsmc/201801/t20180118_1869408.html |website=www.beijing.gov.cn |access-date=2025-12-15}}</ref>。至[[元朝|元代]]（1291年）[[郭守敬]]疏通[[高梁河]]后，水位下降，海淀聚落规模开始扩大<ref name=":4">{{Cite web |title=清华校河的变迁-清华大学校史馆 |url=https://xsg.tsinghua.edu.cn/info/1003/3380.htm |website=xsg.tsinghua.edu.cn |access-date=2025-05-03 |archive-date=2024-09-14 |archive-url=https://web.archive.org/web/20240914011704/https://xsg.tsinghua.edu.cn/info/1003/3380.htm |dead-url=no }}</ref><ref>{{Cite web |title=母亲河“金口”难开_历史名城_首都之窗_北京市人民政府门户网站 |url=https://www.beijing.gov.cn/renwen/lsfm/lsmc/201801/t20180118_1869408.html |website=www.beijing.gov.cn |access-date=2025-12-15}}</ref>。海淀镇之雏形即'''[[元朝|元]]初'''“海店”，为[[燕雲十六州|燕云之地]]和[[蒙古高原草原-内蒙古草原-东北草原|漠北草原]]商旅与[[元大都]]往来的歇脚之地。其选址依托台地西缘，既避低地水患，又便于利用[[巴沟 (北京)|巴沟低地]]的湖泊，形成滨水而居的早期聚落。

=== 园林鼎盛与西郊兵戈 ===
[[File:Seventeen Arch Bridge at winter solstice sunset (20201222160213).jpg|thumb|[[颐和园]]十七孔桥[[冬至]]霞光穿洞]]
明代起，海淀低地因泉水丰沛、风景殊胜，成为官僚[[紳士階級|士绅]]营建私家园林的首选。武清侯[[李偉 (明朝)|李伟]]（[[万历]]帝外祖父）营建的[[清华园]]、[[米萬鍾|米万钟]]的勺园等名园相继落成，清代更发展为“[[三山五园]]”皇家园林集群。

但海淀因地处西郊，常见兵戈：1449年[[土木堡之变]]后的[[京师保卫战|北京保卫战]]中，海淀即为[[明朝軍事|北京守军]]与[[也先]]的交战之地；1457年，[[景泰帝|朱祁钰]]逝世，因[[夺门之变]]，其[[景泰陵|景泰皇陵]]只得葬于[[青龙桥街道|青龙桥]]一带<ref>《明史·本纪第十一》：毁所营寿陵，以亲王礼葬西山，给武成中卫军二百户守护。</ref>；1550年[[庚戌之变]]中，[[严嵩]]惧战，不准出击，海淀亦作为拱卫近郊之西北兵营<ref>戊寅，虏至通州，以[[潮白河|白河]]阻不得渡，乃驻营河之东岸[[三河县 (河北省)|孤山一带]]，分掠[[密云区|密云]]、[[怀柔区|怀柔]]、[[三河市|三河]]、[[昌平区|昌平]]各州县。（略）城外列正兵营四：东北于果树埧，西北于<u>北海店</u>，东南于[[十里河站 (北京市)|十里河]]，西南于[[广安门|彰义门]]，列奇兵于[[正阳门|正阳]]等九门。

=== 毁灭与重生 ===
[[File:Looting of the Yuan Ming Yuan by Anglo French forces in 1860.jpg|thumb|[[第二次鸦片战争]]，英法联军[[圆明园|焚毁掳掠圆明园]]（1860年）]]
1860年[[第二次鸦片战争|英法联军]][[英法联军攻占北京|焚毁西郊园林]]后<ref>八月，英、法兵薄[[张家湾镇 (北京市)|张家湾]]，帝出奔[[承德避暑山庄及其周围寺庙|热河]]，英兵攻海淀，克之，纵[[火烧圆明园 (电影)|火燔圆明园]]。（略）恭王奕新留守，仍督[[僧格林沁|僧]]、[[端华|端]]二军守海淀。

[[載垣|载垣]]密使僧格林沁设法擒[[巴夏禮|巴夏礼]]解京，拘于刑部狱。（略）而英人照会至，限三日内交还巴夏礼。令其退至[[天津市|天津]]再议，不许，又令退至[[通州区|通州]]，亦不许。（英军）反麾兵攻海淀，禁兵不战自溃。炭释巴夏礼，巴夏礼出，欲泄忿，纵火燔圆明园。（略）俄因释放前此与巴夏礼同执之十余人，已监毙八九。英人愤甚，再扰海淀，火三日夜不绝。复声言攻[[故宫|禁城]]。

《清史纪事本末》</ref>，海淀镇一度衰落<ref name=":6" />。[[中华人民共和国]]成立后，依托[[燕京大学]]、[[清华大学]]等高校的建设，海淀台地被规划为文化教育区。50年代至新世纪，[[中央委员会|中央]]和[[北京市人民政府|北京市]]大力投资海淀区，建成了[[学院路 (北京)|学院区]]（[[八大学院]]）、[[中国科学院|科学城]]、[[万寿路街道|行政办公区]]。<ref>{{Cite web |title=海淀史志办 |url=http://hdszb.bjhd.gov.cn/dsyj/dszt/201207/t20120725_4188173.htm |website=hdszb.bjhd.gov.cn |access-date=2025-09-30 |archive-date=2025-04-18 |archive-url=https://web.archive.org/web/20250418032424/http://hdszb.bjhd.gov.cn/dsyj/dszt/201207/t20120725_4188173.htm |dead-url=no }}</ref>低地水系经整治后，部分湖泊河道保留为景观水域（如[[未名湖]]），从皇家禁苑转变为公共文教空间。<ref name=":1">{{Cite journal |author=侯仁之 |title=北京海淀附近的地形水道与聚落——首都都市计划中新定文化教育区的地理条件和它的发展过程 |journal=地理学报 |year=1951 |volume=18 |page=1 - 20}}</ref>

=== 历史区划 ===
今海淀区[[清河 (北京)|清河]]以南、[[西山 (北京)|西山]][[百望山森林公园|百望山]]山前之地，古属[[燕国]]和[[薊國|蓟国]]，后主要属于[[秦朝|秦]][[汉朝|汉]]后历代[[明清北京城|北京城]]的[[附郭县]]和近邻行政区，如[[秦朝|秦]]之[[蓟县 (古代)|蓟县]]、[[汉朝|汉]]之[[广阳郡]]、[[秦朝|秦]]之[[上谷郡]]、[[曹魏]]之[[燕郡]]、[[西汉]]至[[五代十国|五代]]之[[幽州 (古代)|幽州]]、[[隋朝|隋]]之[[涿郡]]、[[唐朝|唐]]之[[幽都县|幽都]]、[[辽朝|辽]]之[[南京道]]、[[金朝|金]]之[[燕京八景|燕京]]、[[金朝|金]]之[[中都路]]、[[元朝|元]]之[[大都路]]、[[明朝|明初]]之[[北平府]]、[[明朝|明]]迁首都后之[[順天府|顺天府]]、[[辽朝|辽]]至[[清朝|清]]之[[宛平縣|宛平]]；[[金朝|金]][[元朝|元]]时少部分地区亦属[[明清北京城|都城]]内；清代，大部分归[[京师]]直辖；1928年设[[北平市]]后，又成为最初的市辖行政区。清河以北、山后之地，则属于以北京为中心的大行政区之属县（州），大行政区曾有[[幽州 (古代)|幽州]]、[[析津府]]、[[大兴府]]、[[大都路]]、[[順天府|顺天府]]、[[京兆地方]]，属县名曾有[[軍都縣|军都]]、[[昌平区|昌平]]、[[万年县 (消歧义)|万年]]、[[玉河]]等。

海淀区现有地域在[[中華民國大陸時期|民国时期]]分属市郊区和河北省[[宛平縣|宛平]]、[[昌平区|昌平]]两县<ref name="hddm" />{{rp|1}}。1949年1月10日，北平市十八区人民政府在海淀镇成立，同年7月与十六区一部、十七区合并，改称十六区。原[[昌平区|昌平县]][[东北旺站|东北旺]]一带等五村随后也并入十六区。1950年8月，十六区更名为十三区。[[展览路街道|展览路]]、[[北礼士路|礼士路]]以东地区于1951年5月划归[[西四区 (北京市)|西四区]]、[[西单区]]管辖。1952年9月1日，十三区正式更名为海淀区；以[[G6辅路|德胜门至清河镇的马路]]为界，以西（包括清河）归海淀区，以东归[[朝阳区|东郊区]]；[[北安河乡|北安河]]等村也归海淀。1963年，昌平县的台头村、梁家园村划归海淀区，此后区界不变<ref name="hddm" />{{rp|1}}。

== 自然条件 ==
=== 地形 ===
[[File:Xiangshan (Fragrant Hills) Park (43745555980).jpg|thumb|center|upright=3.0|香山鸟瞰山前平原（海淀台地和巴沟低地）]]
[[File:Beijing Haidian 1.jpg|thumb|万寿山俯瞰[[昆明湖]]南湖岛、十七孔桥（2013）]]
海淀区地处[[华北平原]]北缘与[[太行山]]余脉[[西山 (北京)|西山]]的交汇处，系古代[[永定河]][[沖積扇|冲积扇]]的一部分：约7000年前，古永定河出[[西山 (北京)|西山]]后先转向东北、再向东南入海，称为“古清河”。受[[华北平原]][[地殻運動|构造运动]]及[[地勢|地势]]影响，古[[永定河]]河道南迁，古清河因失去水源补给而断流，冲积扇上遗留的河道低洼地带逐渐发育为湖泊、沼泽及洼地群，构成海淀地貌雏形<ref name=":3">{{Cite web |title=从溪流到水泥沟：关于清华校河景观变迁的探析-清华大学校史馆 |url=https://xsg.tsinghua.edu.cn/info/1003/1157.htm |website=xsg.tsinghua.edu.cn |access-date=2025-05-03}}</ref>。然而，永定河南迁后，故道内泉水众多，[[湿地|水乡泽国]]，并不宜居。[[金朝|金代]]，引[[昆明湖|瓮山泊]]水入[[高梁河]]，打通了海淀台地，[[万泉河 (北京)|万泉河]]流域水位下降，地面出露，始形成较大规模的人类聚落<ref name=":4" /><ref name=":5">{{Cite journal |author=岳升阳 |title=万泉河述往 |journal=北京观察 |year=2013 |issue=9 |page=70-75}}</ref>。
[[File:颐和园玉泉山远眺.jpg|thumb|颐和园[[昆明湖]]东堤远眺[[玉带桥 (北京)|玉带桥]]、[[玉泉山]]]]
海淀地势西高东低。区内最高峰为[[苏家坨地区|苏家坨镇]][[阳台山 (北京)|阳台山]]妙高峰，海拔1278米；最低处为[[清河街道 (北京市)|清河街道]]东的[[黑泉村]]，海拔35米。

海淀区内约1/5的面积是[[太行山]]余脉的[[山|山地]]及[[丘陵]]，主要分布在西部；海拔100米以上的西部[[山地]]名为[[西山 (北京)|西山]]，面积约为66平方公里，占总面积15%左右。[[西山 (北京)|西山]]有大小山峰67座，其中海拔600米以上的18座，山势呈南北走向，仅黄道岭向东延伸至[[百望山森林公园|百望山]]。东西走向的百望山将海淀一分为二，山之南称'''山前'''，山之北称'''山后'''。[[温泉地区|温泉]]、[[西北旺地区|冷泉、韩家川以南]]及[[香山街道 (北京市)|香山]]一带，山势低缓，属[[丘陵|低山丘陵]]；东部平原上的残丘有[[玉泉山]]、[[万寿山 (北京)|万寿山]]、[[北京市自来水集团有限公司田村山净水厂|田村山]]等。[[File:Overview of Greater Sujiatuo (20170906144351).jpg|thumb|鸟瞰[[苏家坨地区|苏家坨]]（2017年）]]
海淀区东部和南部的其余大部分为海拔50米左右的平原，面积约360平方公里，占全区总面积的85%左右。今[[温泉地区|温泉镇]]、[[苏家坨地区|苏家坨镇]]、[[上庄地区|上庄镇]]、[[西北旺地区|西北旺镇]]等[[百望山森林公园|百望山]]北部四镇均为海淀山后的平原，包括苏家坨低地，主要由[[南沙河 (温榆河)|南沙河]]数个[[沖積扇|洪冲积扇]]和[[南口地区|南口]]洪冲积扇共同构成。海淀山后虽仍较海淀南部核心区的山前地带落后许多、遍布农田，但2015年后正逐步实现南北一体发展<ref name=":16">{{Cite web |title=北京市海淀区人民政府关于印发2026年《政府工作报告》的通知 |url=https://zyk.bjhd.gov.cn/zwdt/xxgk/zfgzbg/202602/t20260209_4805226.shtml |website=zyk.bjhd.gov.cn |access-date=2026-06-16}}</ref>。海淀山前的平原由[[永定河]][[沖積扇|洪冲积扇]]和[[清河 (北京)|清河]]洪冲积扇组成，以50米等高线为界，可分为'''海淀台地'''与'''巴沟低地'''。

海淀台地东南高而西北低，构成[[西直门]]至[[玉泉山]]一带的[[沖積扇|冲积扇]]背脊。这一高亢地带自[[元朝|元代]]起即为交通要道，[[乾隆帝|乾隆]]时自西直门至[[白石桥南站|白石桥]]、[[魏公村]]、[[海淀黄庄站|黄庄]]、海淀镇向西至[[颐和园]]修筑石道，称白颐路、西颐路，后拓展为京颐公路，经[[文化大革命|文革]]改名后形成今[[中关村大街]]斜贯其中，成为连接北京城与[[西山 (北京)|西山]]的重要纽带。台地以西，则是海拔降至47米以下的[[巴沟 (北京)|巴沟]]低地，原为永定河冲积平原的一部分，后因泉水汇聚与[[水利工程|人工疏浚]]，逐渐形成湖泊沼泽密布的水乡景观，始称八沟。此两者，形成“东南干燥、西北润泽”的分野，为海店的聚落分布奠基<ref name=":1" />。
=== 土壤、地下水成因和土地资源 ===
受[[地质学|地质]]、[[氣候|气候]]、[[地形]]诸因素影响，海淀区土壤具多样性。山地垂直带明显，棕壤及地带性褐土交错分布，山地土壤自高到低分山地棕壤、[[淋溶土|淋溶]]褐土、普通褐土、潮褐土、褐潮土、潮土等类。山后倾斜平原广泛分布潮土；山前平原褐土与洼地[[水稻土]]相连。[[File:Jingxi Rice at Yudao Yuanxiang (20221003161016).jpg|thumb|在[[上庄地区|上庄]]西马坊村保护性种植的京西稻|left]]古海淀聚落位于山前的古永定河冲积扇，其土壤大部分为褐土类，适合种植。表层[[沉積物|沉积物]]以[[黏土|粘质]]—轻中壤土为主，夹杂[[沙|砂]]层、[[卵石|卵砾石]]等松散[[沉積物|堆积物]]，孔隙度较高，透水性较强，抗[[侵蚀作用|侵蚀]]能力较弱。又因深层[[岩性]]颗粒细，[[地下水]]下渗受阻，故形成了地下水溢出带。区域内存在两类主要地下水体：[[第四紀|第四纪]]松散层孔隙水和[[奥陶纪]][[石灰岩|灰岩]]溶裂隙水。地下水年波动幅度较小，保障了地表水体（如湖泊、湿地）的持续存在。如'''[[泉宗庙|万泉庄]]'''，即是古清河河道的地下水，受海淀台地顶托上涌。因泉眼众多，遂称“万泉”。<ref name=":3" /><ref name=":5" />

海淀区土地总面积 430.77 平方千米，其中[[耕地]] 1047.77 公顷，占总面积的 2.43%；[[园地栽培|园地]] 1977.09 公顷，占 4.58%；[[疏林|林地]] 15249.16 公顷，占 35.36%；[[草坪|草地]] 88.29 公顷，占 0.20%；城镇村及工矿用地 19809.77 公顷，占 45.93%；交通运输用地 2967.26 公顷，占 6.88%；水域及水利设施用地 1302.55 公顷，占 3.02%；其他土地 687.36 公顷，占 1.59%。全区共有永久基本农田保护面积 667 公顷，主要分布在山后的上庄镇、西北旺镇、温泉镇和苏家坨镇<ref name=":15">{{Cite web |title=北京市海淀区人民政府公报（2021年） |url=https://zyk.bjhd.gov.cn/jbdt/auto10489_51767/zfgb/P020230828591825991259.pdf |website=北京市海淀区人民政府}}</ref>。

=== 水系、水文和湿地 ===
海淀区属[[海河|海河流域]]，河湖水网发达。海淀水系如今虽流量不大，但对城市用水和全区农业[[灌溉]]起了重要作用<ref>[http://www.bjhd.gov.cn/gk/haidiangaikuang/201508/t20150816_927035.htm#002 海淀概况,北京市海淀区政府门户网站] {{webarchive|url=https://web.archive.org/web/20151004212144/http://www.bjhd.gov.cn/gk/haidiangaikuang/201508/t20150816_927035.htm|date=2015-10-04}}</ref>。同时，海淀河流让[[通州区|通州]]至京城间的金代闸河、元[[通惠河]]与[[坝河]]、明清[[京杭大运河|大运河]]水量充足，使[[漕运|漕粮]]可直接运达京城粮仓<ref>{{Cite book |title=海淀历史文化研究 |author=李彦来 |publisher=北京出版社 |year=2012 |isbn=978-7-200-09337-7}}</ref>。
[[File:Beijing-Miyun Diversion Canal near Baiwangshan (20220430084532).jpg|thumb|[[京密引水渠]]]]
海淀区共有大小河流10条，总长度119.8公里。有[[高梁河]]、[[清河 (北京)|清河]]、[[万泉河 (北京)|万泉河]]、[[南长河]]、[[昆玉河]]、[[南旱河]]、[[北旱河]]、[[小月河]]、[[南沙河 (温榆河)|南沙河]]（上庄水库）、[[北沙河 (温榆河)|北沙河]]（与昌平区交界）。区内有9条较大防洪排水河道，总长70公里；还有周家巷沟、宏丰渠、前章村沟等60余条中小排水沟；新中国成立后人工开凿的[[永定河引水渠]]和[[京密引水渠]]共两条输水渠，把[[官厅水库|官厅]]、[[密云水库|密云]]两大水库的水引入[[玉渊潭公园|玉渊潭]]和[[昆明湖]]。海淀区有[[上庄地区|上庄水库]]、[[苏家坨地区|五七水库]]2个较大水库，另有[[昆明湖]]、[[玉渊潭公园|玉渊潭湖]]、[[福海]]、[[紫竹院公园|紫竹院湖]]、[[八一湖桥|八一湖]]等湖泊，还有[[团城湖]]（[[南水北调工程|南水北调]]调节池）、[[翠湖湿地]]、西五环晋元桥东的西郊雨洪调蓄工程等水面，水域面积辽阔，水面6.7平方千米，在北京中心城区居第一位。
[[File:Qing River in Xiaojiahe (20170823094630).jpg|thumb|[[清河 (北京)|清河]]（2017年，[[马连洼街道|马连洼]]肖家河）]]
海淀区的山区、半山区主要分布永久性河流、季节性或间歇性河流以及小型库塘湿地，而平原主要分布库塘湿地、[[水產養殖|水产养殖场]]、[[水田|稻田]]以及永久性湖泊、[[运河]]和输水河等；另外，海淀区北部多河流湿地，南部多库塘湿地，地表水汇集由北部、西北部山区汇集到平原区南部几个大型库塘中，比如[[颐和园]]、[[圆明园]]、[[玉渊潭公园]]等。海淀区水资源总量 15342 万立方米，京密引水渠和永定河引水渠通水后，最多年供水达1亿立方米。然而，[[地下水]]占海淀区多年平均用水量的80%。平原区地下水资源按贫富可分为三个水文地质单元：[[四季青地区]]为富水区，面积约130平方千米；[[清河街道 (北京市)|清河地区]]为次富水区，面积 100平方千米；山后地区为贫水区，面积130平方千米<ref name=":15" />。

海淀的繁华仰仗着丰沛的水资源，不仅留存下了[[中关村|中湾儿]]、[[马连洼街道|马连洼儿]]、[[青龙桥街道|青龙桥]]、泄水湖等地名，至[[中華民國大陸時期|民国]]仍盛：[[冰心]]任教[[燕京大学]]时常到繁华的海淀镇下馆子解馋，水产之鲜美以至于“店家隔着窗户从窗外的-{zh-hans:河道里;zh-tw:河道裡;zh-hk:河道裏}-捕鱼上来烧熟”<ref>{{Cite web |title=奔海淀镇 探寻中关村前世(组图) |url=https://travel.sina.cn/domestic/pages/2009-10-12/detail-ifyixcaw4014504.d.html |website=travel.sina.cn |date=2009-10-12 |language=zh-CN |last=Timeout |access-date=2026-03-31}}</ref>。历史上，海淀[[百望山森林公园|山]]前[[水系]]以[[玉泉山]]与万泉庄两大水源为脉络，历经自然演替与人工疏浚，形成复杂水网<ref>{{Cite journal |author=侯仁之 |author-link=侯仁之 |author2=岳升阳 |title=海淀镇与北京城——历史发展过程中的地理关系与文化渊源 |journal=北京规划建设 |year=2000 |issue=1 |page=62-65}}</ref>。
[[File:亜東印画輯 01 155 "玉泉山から見た水田（北京郊外）".jpg|thumb|[[玉泉山]]俯瞰下的水田，宛若江南（20世纪20年代）]]
'''玉泉山水系'''主源玉泉山诸泉，水量丰沛，经[[昆明湖]]调蓄后，分两脉流动。南支古时沿[[南长河|长河]]注入北京城，成为[[北护城河 (北京)|护城河]]与三海（[[中南海]]、[[北海公园|北海]]）的水源；北支经[[青龙桥街道|青龙桥]]、[[清河 (北京)|清河]]汇入[[温榆河]]，历史上曾为[[漕运]]要道。元初，[[郭守敬]]主持开凿古[[通惠河]]，引[[白浮泉]]至[[昆明湖|瓮山泊]]（[[金朝|金代]]称金海，[[明朝|明代]]呼西湖、大泊湖），以[[金朝|金代]]开凿的[[南长河|长河]]引到[[元大都|大都]]城下，从[[西直门|和义门]][[西直门桥|北水关]]入城至[[积水潭站|积水潭]]；其引玉泉山水济[[漕运|漕]]，使海淀成为[[明清北京城|京城]]水系枢纽。[[乾隆]]年间扩建昆明湖，加固堤岸以抬高水位，进一步强化了其对城市供水的调节功能。
[[File:2015年清華校河(2021重调色版).jpg|thumb|[[万泉河 (北京)|万泉河]]流经[[清华大学]]]]
'''万泉庄水系'''以[[巴沟 (北京)|巴沟村]]、万泉庄一带泉群为核心，自南向北流经海淀低地，与玉泉山水系交汇。清代[[泉宗庙|泉宗庙遗址]]一带原有二十八泉，《萬泉莊記》称「平地涼涼出乳穴者不可勝數」，[[万泉河 (北京)|万泉河]]即从中流淌出<ref name=":1" />。<blockquote>广可丈余，围以砖凳，泉味清甘，四时不竭；水溢于地，流数百步而为池，居人汲饮赖之。蔬畦相错，灌溉甚广。盖郊北之水来自西山，泉源随地涌出，固无足异<ref name=":13" />。</blockquote>坐落于[[永定河]]古河床的泉水溢出带是海淀水源的重要来源。该溢出带北起[[黑龙潭及龙王庙|黑龙潭]]，南至丰台水头庄[[凉水河]]源头，间有万泉庄、[[紫竹院公园|紫竹院]]湖、[[玉渊潭公园|玉渊潭]]、[[莲花池]]等湖泊。海淀以'''玉泉山'''泉水最为有名，以“天下第一泉”著称，是[[明清北京城|北京城]]给水的主要源泉之一；玉泉水系是[[明清北京城]]唯一的地表水源地，通过[[南长河]]输入。明末《[[春明夢餘錄|春明梦馀录]]》中的「玉泉垂虹」即为[[金朝|金代]][[金章宗|《明昌遗事》]]确立于距今八百年前的[[燕京八景]]之一，[[乾隆]]认为其堪比[[济南府|济南]][[趵突泉]]而更名「玉泉趵突」。此外亦有[[北安河乡|金山泉]]、[[大觉寺 (北京)|大觉寺泉]]、[[温泉地区|温泉]]、[[黑龙潭及龙王庙|黑龙潭泉]]、[[双清别墅|双清泉]]等名泉。

元明以后，海淀随着京西稻田开垦与水渠疏浚，逐渐形成宛若[[江南]]“稻田藕塘相望”的水乡。20世纪50年代的万泉河畔，农人仍赶着[[北京鸭]]沿河放养；外地[[漁民|渔民]]的小舟上，停着几只[[鸬鹚捕鱼|鱼鹰]]：“两岸溪田一水通，维舟不断稻花香”<ref>万泉十里水云乡，兰若闲寻趁晓凉。

=== 气候 ===
[[File:Snow and fog in Haidian District, Beijing.jpg|left|thumb|大雪中的[[北京市八一学校|八一学校]]操场（2022）]]
海淀区气候属于[[温带季风气候|暖温带半湿润季风气候]]，夏季炎热多雨，盛行东南风；冬季寒冷干燥，盛行西北风。近三十年来，海淀区全年均温 13.1℃，一月平均低温 -7.1℃（历史最低-20.2℃），平均相对湿度43%；七月平均高温 32.0℃（历史最高41.7℃），平均相对湿度72%。海淀区年平均降水量近 600 毫米，多雨季节在6至8月，此三月平均降水天数34.3天，全年平均降雪天数9.7天，占全年降水的70%；冬季12月到次年2月降水量最少，仅占1%。全年无霜期 211 天，全年日照时长2350小时（可照百分比54%），阳光充沛。

=== 第一个国家高新区 ===
<blockquote>犹如[[巴黎]][[香榭丽舍大街|香榭丽舍]]或[[纽约]][[百老匯大道|百老汇]]，海淀是一种对[[中华民族|国族]]宏大叙事的礼赞：中国有能力改造自己，重新跻身强国之列。（中略）科技革命每天重塑着中国。海淀是这场变革的中心，并饱含着无数梦想：期盼科技能带来更美好、更安康，乃至（一如中国人长久追求的）更富足的生活。（[[時代雜誌|时代杂志]]，1999年）<ref name="time" /></blockquote>

80年代初期，[[陈春先|归国科研人员]]在海淀区[[中关村]]开始建立民营科技机构。到83年1月，[[胡耀邦]]、[[胡启立]]、[[方毅]]指示「带头开创新局面，可能走出了一条新路子」，中关村开始形成「电子一条街」和科研人员下海创业潮。1988年5月，[[中华人民共和国国务院|国务院]]在中关村批准建立第一个[[国家级高新技术产业开发区|国家高新区]]：[[中关村|北京市新技术产业开发试验区]]。2013年，[[中国共产党中央委员会总书记|中共中央总书记]][[习近平]]表示：“中关村已经成为我国创新发展的一面旗帜”。到2019年，中关村高新技术企业实现增加值1.04万亿，占北京市GDP达到29.4%。新经济增加值在全市占比达到36.1%，已成为北京市经济增长引擎之一。<ref>{{Cite web |title=促进国家高新技术产业开发区高质量发展国务院政策例行吹风会 |url=http://www.scio.gov.cn/gwyzclxcfh/cfh/2020n_15720/2020n07y23r_15849/tw_15851/202208/t20220808_304864.html|quote=2013年9月30日，中央政治局将集体学习放到了中关村，习近平总书记指出，中关村已经成为我国创新发展的一面旗帜。}}</ref><ref>{{Cite web |title=中关村科学城的兴起（1951—1999年）_一带一路·共建繁荣_中国网_一带一路官网 |url=http://ydyl.china.com.cn/2019-09/11/content_75195166_7.htm |website=ydyl.china.com.cn |access-date=2026-01-25}}</ref>[[File:ByteDance 1733 Commercial Space (20240731145554).jpg|thumb|[[字节跳动]]位于本区[[北京三环路|北三环]]西路甲18号的总部]]
多家著名企业均落脚于海淀区。海淀区是中国互联网公司的发源地之一，被[[時代雜誌|时代杂志]]誉为「'''中国硅谷'''」<ref name="time">{{Cite magazine |author=Joshua Cooper Ramo |date=27 September 1999 |title=HAIDIAN DISTRICT: China's Silicon Valley, 1999 |url=http://www.time.com/time/asia/magazine/99/0927/haidian.html |magazine=Time |volume=154 |issue=12 |archive-url=https://web.archive.org/web/20010129025100/http://www.time.com/time/asia/magazine/99/0927/haidian.html |archive-date=29 January 2001 |access-date=4 May 2010 |url-status=dead}}</ref>。海淀北部[[中关村软件园]]及其周边（[[马连洼街道|马连洼]]、[[上地软件园站|上地]]一带）入驻有[[百度]]、[[联想集团|联想]]、[[腾讯]]（北京）、[[新浪]]、[[快手 (軟體)|快手]]、[[科大讯飞]]、[[美团]]等总部，[[小米集團]]则将总部设于与[[上地信息产业基地]]相隔不远的华润五彩城。海淀中南部则有[[字节跳动]]（[[抖音]]）总部，区内同时还有[[搜狗]]、[[搜狐]]、[[奇虎360|360]]、[[知乎]]、[[优酷]]、[[滴滴出行]]、[[爱奇艺]]、[[豆瓣]]等互联网企业总部。区内的中小型科技公司同时产出了许多国民级软件，如[[WPS Office|WPS]]（[[金山办公]]）、[[作业帮]]、[[有道词典]]、[[天眼查]]、[[去哪儿网]]等。

另外，海淀区同时拥有多家'''跨国高新企业'''机构的区域总部、办事处和研发中心，如[[微软]]、[[英特尔]]、[[英伟达]]、[[IBM]]、[[AMD]]、[[蘋果公司|苹果]]、[[Google|谷歌]]、[[台積電|台积电]]、[[华为]]、[[阿里巴巴集团|阿里巴巴]]、[[三星電子|三星]]、[[德州仪器]]、[[索尼]]、[[戴爾|戴尔]]、[[惠普]]、[[紅帽公司|REDHAT]]、[[博通有限|博通]]、[[NTT DOCOMO|DOCOMO]]、[[Arm (企業)|ARM]]、[[新思科技|新思]]、[[ANSYS公司|ANSYS]]、[[明導國際|西门子EDA]]、[[艾司摩爾|ASML]]、[[格芯]]、[[瑞芯微電子|瑞芯]]、[[Snapchat]]等。海淀区同时也驻扎了许多新兴[[独角兽企业]]的总部或研发总部，如[[深度求索|DeepSeek]]<ref>{{Cite web |title=海淀向北：万亿之后，拿什么留住下一个DeepSeek？ - 21经济网 |url=https://www.21jingji.com/article/20250711/herald/0de8bf2cf9ef2c7435d03c7ca5b47e99.html |website=www.21jingji.com |access-date=2026-01-25 |archive-date=2025-08-15 |archive-url=https://web.archive.org/web/20250815160737/https://www.21jingji.com/article/20250711/herald/0de8bf2cf9ef2c7435d03c7ca5b47e99.html |dead-url=no }}</ref>、[[智谱]]、[[月之暗面 (公司)|月之暗面]]（[[Kimi (聊天機器人)|Kimi]]）、[[龙芯中科]]、[[摩尔线程]]、[[兆易创新]]、[[海光信息]]、[[旷视科技]]、[[地平线机器人]]、[[贝壳找房]]、[[寒武紀科技|寒武纪科技]]、[[芯驰科技|芯驰]]、[[商汤科技]]、{{le|百川智能|Baichuan}}、{{le|第四范式 (公司)|4Paradigm|第四范式}}、[[紫光集團|紫光股份]]、[[紫光国微]]等。2026年，[[罗氏|罗氏制药]]设立了全资法人实体，并与区政府签订备忘录<ref>{{Cite web |title=北京市海淀区人民政府与罗氏（中国）投资有限公司 签署战略合作意向备忘录 |url=https://zyk.bjhd.gov.cn/ywdt/hdywx/202603/t20260324_4809499.shtml |website=zyk.bjhd.gov.cn |access-date=2026-06-16}}</ref>。

=== 观光 ===

海淀区自古山水秀丽，公园总数达144个<ref name=":12" />，汇聚了许多京西最著名的风景名胜。漫步[[颐和园]] ( [[国家5A级旅游景区]]，[[世界遗产|世界文化遗产]] ) ，[[昆明湖]]碧波荡漾，[[佛香阁]]巍峨矗立；毗邻的[[圆明园遗址公园]] ( [[国家5A级旅游景区]] )，断壁残垣间诉说着[[近代史]]的沧桑。春日，[[国家植物园 (北京)|国家植物园]] ( [[国家4A级旅游景区]] )的花朵竞相绽放；秋时，[[香山公园]] ( [[国家4A级旅游景区]] )的红叶染透山峦，或见燕京八景之西山晴雪。登临[[中央广播电视塔]] ( [[国家4A级旅游景区]] ) ，北京城区的壮阔尽收眼底；泛舟[[玉渊潭公园]] ( [[国家4A级旅游景区]] )，樱花纷飞恍若幻境。[[紫竹院公园]] ( [[国家4A级旅游景区]] )的翠竹幽径与江南亭台相映成趣，而[[凤凰岭|凤凰岭自然风景区]] ( [[国家4A级旅游景区]] )的奇峰怪石、清泉古刹，则辟出一方远离喧嚣的桃源。

=== 治安、犯罪与管制 ===
海淀区治安总体优良；但由于地处首都，人员复杂，偶发事端，且高校云集，故言论与集会管制严格。

70年代初，中法[[混血兒|混血]]吴文北（父亲[[吴新谋]]）利用其特殊身份便利，以[[中关村]]为基地，和兄弟吴文中在北京多个地区实施盗窃，目标包括[[国家外国专家局|外国专家公寓]]及高校宿舍，涉案金额巨大，亦牵涉政治斗争<ref>{{Cite web |title=文革期间中法混血儿惊天大案 毕汝谐（纽约 作家） - biruxie的日志 |url=https://www.backchina.com/blog/322305/article-331909.html |website=www.backchina.com |access-date=2026-09-29}}</ref>。[[File:Beijing june 1989 Zhongguancun street.jpg|thumb|1989年六四事件中，[[中关村大街]]上被焚毁的车辆]][[改革开放]]后，[[市场经济]]的兴起和剧烈的人口流动让北京犯罪频发、社会动荡；又逢[[恢復高考|恢复高考]]和[[东欧剧变]]，[[民主]][[自由]]的新思潮涌入学术界和多所高校，亦间接为学潮埋下伏笔。[[严厉打击刑事犯罪活动 (1983年)|1983年严打]]中，王姓、余姓两个大学女生在[[玉渊潭公园|八一湖]]中[[裸泳]]。王姓女子因与10多名男性发生性关系及裸泳而以[[流氓罪]]被判处死刑，她在听闻判决后说：<blockquote>[[性自主|性自由]]是我选择的一种生活方式，我的这种行为现在也许是超前的，但20年后人们就不会这么看了。<ref>{{Cite web |title=1983年“严打”：非常时期的非常手段-纪实台-中国网络电视台 |url=https://jishi.cntv.cn/20101118/100179_2.shtml |website=jishi.cntv.cn |access-date=2026-09-29}}</ref></blockquote>1989年[[六四事件]]中，4月开始，上千名来自海淀区各高校学生涌入天安门广场一带要求与高层对话，最终发展为[[學生運動|学潮]]；6月3日傍晚，海淀区边界的[[木樨地]]（天安门以西五公里外）街头示威者开始聚集，阻挡镇压部队前进的街垒和路障被加固，[[中国人民解放军陆军第八十二集团军|第38集团军群]]扫射了阻挡行军的学生和市民，造成[[六四清场|重大伤亡]]。

== 民风与精神 ==
[[刻板印象]]中的海淀民风，居民消费观朴素务实、仿佛苦修，常着黑色[[羽绒服]]<ref>{{Cite web|title=黑色羽绒服成为北京冬季标配，实用性与群体认同促成流行|url=https://www.huxiu.com/article/4831406.html|website=虎嗅网|date=2026-01-31|access-date=2026-02-01|last=虎嗅网}}</ref>、[[冲锋衣]]和[[校服]]，重视[[学区]]而轻视商业；[[資訊業|IT企业]]多如牛毛，产业园大厦间和地铁中的职员风尘仆仆、无精打采；又因[[政府|机关]]、[[武装力量|部队]]、[[高等学校|高校]]众多，老旧[[小区]]和[[单位型社区|大院儿]]林立，这些势力通天却高度封闭的社区割裂了整体的[[城市规划]]，使海淀区的[[市區更新|城市更新]]严重受限，故常被诟病「[[品味|土]]」、「苦」、不洋气<ref>{{Cite web |title=中国人自己的“老钱风”，都在北京海淀-36氪 |url=https://36kr.com/p/2547659487892357 |website=36kr.com |date=2025-12-22 |access-date=2025-12-22}}</ref><ref>{{Cite web |title=帝都“海淀老钱风”，为什么比各种风都厉害？ |url=https://na.ifeng.com/c/8VWwGrqFYwE |website=na.ifeng.com |access-date=2025-12-22}}</ref>。

另一方面，海淀区在[[北京城六區|北京城区]]中最富有'''创新'''精神，彰显了80年代至21世纪初北京的活力、青春与自由：几十所开放高校的学术资源和人文氛围外溢、许多书店[[咖啡店|咖啡屋]]举办着讲座和[[沙龍 (聚會)|沙龙]]、科技[[风险投资|投资者]]和[[創業|创业者]]在[[中关村]]云集、[[五道口]][[夜生活]]灯红酒绿、各民族各宗教与外国人带来了多元文化等等。

但近十年来，海淀的公共社会空间逐渐被更严格的城市管理渗透，自由、轻松、活泼的氛围日益消散。伴随着房价仍然高企、[[经济衰退|经济下行]]、[[中华人民共和国户籍制度|北京户籍]]僵化、行政干预严格，海淀区乃至北京市的资源不断向几个头部科技民企和央企总部集中，可成长的中小企业占比越来越少，吸收青年人才能力越来越弱，[[商圈|市井烟火气]]越来越淡。国家和城市间的竞争也是人才流失的重要因素：[[美国|美]]、[[加拿大|加]]、[[新西兰|新]]、[[澳大利亚|澳]]、[[新加坡]]、[[西欧]]等一直是北京人的热门移民目的地；而[[长江三角洲经济圈|长三角]]的[[上海市|上海]]、[[粵港澳大灣區|粤港澳]]的[[深圳市|深圳]]甚至[[成渝地区|成渝]]也在逐渐成为本区人才的新移居地。以[[北京大学]]毕业生为例：2013年，72%的本科毕业生选择留京，本硕博总体去上海和广东的比例不超过8%；到2025年，留京比例下降到42%（同时普通211、985院校毕业生留京率已下探到30%），沪粤两地总体占比超25%，是11年前的3倍，[[新一線城市|新一线城市]]中[[杭州市|杭州]]3.71%、[[成都市|成都]]3.09%、[[南京市|南京]]1.87%、[[重庆市|重庆]]1.4%<ref>{{Cite web |title=北京大学2024年毕业生就业质量报告 |url=https://scc.pku.edu.cn/userfiles/ff80808158467de901584bc7b814030d/files/cms/article/attachment/2025/10/%E5%8C%97%E4%BA%AC%E5%A4%A7%E5%AD%A62024%E5%B9%B4%E6%AF%95%E4%B8%9A%E7%94%9F%E5%B0%B1%E4%B8%9A%E8%B4%A8%E9%87%8F%E6%8A%A5%E5%91%8A.pdf |author=北京大学学生就业指导服务中心}}</ref><ref>{{Cite web |title=【404文库】阜成门六号院｜十年来年轻人口减半：北京为什么越来越留不住年轻人了？ |url=https://chinadigitaltimes.net/chinese/726901.html |date=2026-04-30 |language=zh-Hans |last=2026年4月30日 |access-date=2026-06-22}}</ref>。

== 宗教和祖源 ==
海淀是北京市宗教工作重点区，五大宗教齐全，依法登记的活动场所共27处<ref>{{Cite journal |author=北京市海淀区民宗侨办 |title=以首善的标准做好宗教工作 |journal=中国宗教 |year=2018 |volume=1 |page=60-61}}</ref>。[[道教]][[桃源觀|桃源观]]，[[汉传佛教]][[龙泉寺 (海淀区)|龙泉寺]]等，均在[[凤凰岭|凤凰岭风景区]]内。[[香山公园|香山]]有[[藏傳佛教|藏传佛教]][[宗镜大昭之庙|昭庙]]、[[汉传佛教]][[碧云寺 (北京市)|碧云寺]]。寿安山有[[十方普觉寺|卧佛寺]]，[[阳台山 (北京)|阳台山]]有[[大觉寺 (北京)|大觉寺]]。另有[[新教]][[海淀堂]]在图书城步行街附近。[[天主教]]活动场所共有[[北京天主教神哲学院|后八家圣弥额尔教堂]]、[[正福寺天主堂|正福寺教堂]]、[[白家疃天主堂]]、[[西北旺天主堂]]、[[西三旗天主堂]]。此外，因高知分子众多，海淀区还有着规模不小的[[中国新教地下教会|基督教地下教会]]，如[[北京守望教会]]等。海淀区亦有建于[[万历]]的两座[[清真寺]]，位于[[蓝靛厂清真寺|蓝靛厂]]和[[海淀清真寺|海淀镇]]<ref>可参见 [[:Category:海淀区宗教建筑物]]</ref>。海淀历史上宗教昌盛，如[[王恭廠大爆炸|晚明]]腐朽之下西山佛寺却极奢，百年来随着[[无神论|信仰改变]]和[[城市化]]，大量庙宇被拆改。<blockquote>盖今天下二氏之居，莫盛于[[两京制|两都]]，莫极盛于[[明清北京城|北都]]；而宛平西山，实尤其极盛者也（略）予尝经行其居，见其旧有存者，其殿塔幢幡，率齐云落星，备极靡丽，如万寿寺佛像，一座千金；古林僧衲衣，千珠千佛，其他称是。此非杼轴不空、财力之盛不能也。<ref name=":14" /></blockquote>2021年，海淀区常住人口中汉族占95%；各少数民族人口占5%。与2010年相比，汉族人口下降5.4%；各少数民族人口上升16.3%。[[马甸|马甸儿]]曾有大型[[穆斯林]][[社区]]（[[马甸清真寺]]），祖先多是[[中国西北地区|西北]]的[[回族]]羊马商人，而其在北京至西北草原商路上的位置则促成了大型羊马市场的繁荣<ref name="WangZhouFanp117">Wang, Wenfei, Shangyi Zhou, and C. ''Eurasian Geography and Economics'', 2002, 43, No. 2, pp. 104-122. Cited page: p. 117.</ref>；[[魏公村]]（元代畏兀村）和[[甘家口街道|甘家口]]一带也曾形成过[[维吾尔族|新疆村]]<ref>{{Cite web |title=杨圣敏：元朝以来的北京“新疆村”_爱思想 |url=https://www.aisixiang.com/data/73401.html |website=www.aisixiang.com |archive-url=http://web.archive.org/web/20250616212605/https://www.aisixiang.com/data/73401.html |archive-date=2025-06-16 |access-date=2026-03-19}}</ref><ref>{{Cite web |title=魏公村：见证北京多元文化 |url=https://xinwen.bjd.com.cn/content/s60925a82e4b054f0ea81f3bc.html |website=xinwen.bjd.com.cn |access-date=2026-03-19}}</ref>；80年代至00年代，[[东升地区|东升乡]]二里庄和八家村因[[流动人口]]多从事[[資源回收|废品回收]]，形成过「[[河南省|河南]]村」（又称「破烂儿村」）<ref>{{Cite web |title=民生周刊 |url=https://paper.people.com.cn/mszk/html/2014-01/13/content_1377813.htm |website=paper.people.com.cn |access-date=2026-03-19}}</ref>；新千年，[[知春路]]的西五道口和蓝旗营一带形成过[[安徽省|安徽]]村<ref>{{Cite web |title=“外地人”催生“新北京” |url=https://news.sina.cn/sa/2007-12-07/detail-ikftpnny3969558.d.html |website=手机新浪网 |date=2007-12-07 |language=zh-CN |last=《小康》杂志 |access-date=2026-03-19}}</ref>。这些社区伴随着新规划用地和清理[[北京低端人口|低端人口]]正逐渐消亡<ref>{{Cite journal |author=刘海泳 |author2=顾朝林 |title=北京流动人口聚落的形态、结构与功能 |journal=地理科学 |year=1999 |volume=19 |issue=6 |page=497-503}}</ref><ref>{{Cite journal |author=陶栋艳 |author2=童昕 |author3=冯卡罗 |title=从“废品村”看城乡结合部的灰色空间生产 |journal=国际城市规划 |year=2014 |volume=1 |page=8-14}}</ref>，但北京作为[[中国北方|北方]]唯一的[[一线城市]]，仍在持续虹吸[[晋冀鲁豫]]、[[中国东北地区|东北]]和[[淮海地区|淮海]]的中低阶层人口。
