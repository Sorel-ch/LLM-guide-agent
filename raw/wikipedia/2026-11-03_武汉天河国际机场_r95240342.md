'''武汉天河国际机场'''（{{airport codes|WUH|ZHHH}}），位于中华人民共和国[[湖北省]][[武汉市]][[黄陂区]][[天河街道 (武汉市)|天河街道]]，距离武汉市区约26公里，[[机场飞行区等级]]为最高的4F级<ref name="武汉天河机场正式成为中部首家4F级机场">{{cite web| url =http://www.caac.gov.cn/local/ZNGLJ/ZN_XXGK/ZN_HYDT/201711/t20171103_47411.html| title =武汉天河机场正式成为中部首家4F级机场| publisher =中国民用航空中南地区管理局| accessdate =2017-11-03| archive-date =2017-11-07| archive-url =https://web.archive.org/web/20171107031314/http://www.caac.gov.cn/local/ZNGLJ/ZN_XXGK/ZN_HYDT/201711/t20171103_47411.html| dead-url =no}}</ref>，能够起降[[波音747]]和[[空中客车A380]]等特大型飞机<ref name="zhongnancaac">{{cite web | url=http://news.hbtv.com.cn/p/1014158.html | title=天河机场成中部首家4F级机场 系全国第十家可起降世界最大客机A380 | publisher=湖北卫视 | accessdate=2017-11-05 | author=长江云 | archive-date=2020-08-25 | archive-url=https://web.archive.org/web/20200825015901/http://news.hbtv.com.cn/p/1014158.html | dead-url=no }}</ref>，是中国大陆最繁忙的民用[[机场]]之一。机场一期工程于1990年12月16日动工，1995年4月15日作为国家一级民用机场正式开航启用<ref name="武汉天河国际机场简介">{{cite web| url =http://mil.news.sina.com.cn/2007-11-27/1822473641.html| title =武汉天河国际机场简介| publisher =新浪网| accessdate =2020-05-30| archive-date =2019-06-10| archive-url =https://web.archive.org/web/20190610214301/http://mil.news.sina.com.cn/2007-11-27/1822473641.html| dead-url =no}}</ref>。

武汉天河国际机场被[[中国民用航空局]]定位为“全国重要的[[枢纽机场]]”，是其指定的[[华中地区]]综合枢纽机场和最大的飞机检修基地<ref name="武汉天河国际机场">{{cite web| url=http://college.cauc.edu.cn/kgxy/news/FrameShow.asp?id=148| title=武汉天河国际机场| publisher=中国民航大学空中交通管理学院| accessdate=2012-04-08}}{{dead link|date=2018年3月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>。天河机场对持有第三国签证和机票的54个国家的外国旅客开放[[中华人民共和国签证政策#240小时口岸过境免签证|240小时过境免签政策]]<ref>{{Cite web |url = http://news.cnr.cn/native/gd/20181115/t20181115_524416646.shtml |title = 144小时！2019年开始这五市实施外国人过境免签政策 |author = 吴海波 |date = 2018-11-15 |publisher = 央视网 |quote = 国家移民管理局今天发布消息，经国务院批准，自2019年1月1号起，厦门、青岛、武汉、成都、昆明5个城市将实施外国人144小时过境免签政策。 |access-date = 2018-11-15 |archive-date = 2020-04-05 |archive-url = https://web.archive.org/web/20200405133603/http://news.cnr.cn/native/gd/20181115/t20181115_524416646.shtml |dead-url = no }}</ref>。[[中国邮政]]在天河机场设置的武汉航空邮件处理中心是[[中国邮政航空]]全国辅助中心<ref>{{cite web |author1=蔣璐 |title=2020年武漢基本建成中部門戶樞紐機場 |url=https://www.hkcd.com/content_p/2017-06/02/content_45145.html |website=香港商報 |publisher=湖北日報 |accessdate=2017-06-02 |archive-date=2024-12-09 |archive-url=https://web.archive.org/web/20241209053928/https://www.hkcd.com/content_p/2017-06/02/content_45145.html |dead-url=no }}</ref><ref>{{cite web |author1=左晨 周唯 |title=日均邮件量环比增长175% 武汉飞美国航空邮路恢复常态化运营 |url=http://news.cnhubei.com/content/2021-03/11/content_13671511.html |website=荆楚网 |publisher=湖北日报 |accessdate=2021-03-11}}</ref><ref>{{cite web |author1=高喜明 |title=武汉联动鄂州打造“空中出海口” |url=http://hb.people.com.cn/n2/2024/1225/c192237-41087212.html |website=人民网 |accessdate=2024-12-25 |archive-date=2025-07-08 |archive-url=https://web.archive.org/web/20250708234922/http://hb.people.com.cn/n2/2024/1225/c192237-41087212.html |dead-url=no }}</ref>。

== 历史 ==
=== 建设 ===
1951年8月1日时，武汉市中心的纯民用机场仅有[[武汉南湖机场]]，而南湖机场受既有条件影响存在诸多问题，即使经历多次扩建，机场规模依旧不能满足民航发展需求，其1800长的跑道（18/36）只能起降[[波音737-200]]及以下体量客机，为当时省会城市民用机场中最短者。早在1958年武汉市便有意新建机场，但因种种原因一直未能实行<ref>{{Cite book |title=湖北省志 交通邮电 |author=湖北省地方志编纂委员会 |location=武汉 |publisher=湖北人民出版社 |year=1995 |isbn=7-216-01650-5 |language=zh-Hans-CN }}</ref>{{Rp|644}}<ref>{{Cite journal |author=张益游 |title=怀念逝去的南湖机场 |journal=档案记忆 |year=2023 |issue=3 |pages=21-23 |id={{WFD|hbda202303007|CJFQ|r}} |doi=10.3969/j.issn.1003-8167.2023.03.007|issn=1003-8167 |language=zh-Hans-CN }}</ref>。

1985年7月1日，[[中华人民共和国国务院|中国国务院]]、[[中华人民共和国中央军事委员会|中央军委]]批准修建新的武汉国际机场<ref>{{Cite book |title=中国民用航空志|volume=中南地區卷 上冊|author=中国民用航空志中南地区卷编纂委员会 |location=北京 |publisher=中国民航出版社 |year=2013 |isbn=978-7-5128-0119-6  |language=zh-Hans-CN }}</ref>{{Rp|177}}。因新机场位于武汉市汉口北郊黄陂天河镇（今[[黄陂区]][[天河街道 (武汉市)|天河街道]]）东南约1公里处，得名“武汉天河机场”。1990年12月16日，天河机场正式动工兴建<ref name=年鉴1991>{{Cite book |title=武汉年鉴 1991 |author=武汉地方志编纂委员会办公室 |publisher=武汉年鉴社 |year=1991 |ISSN=1005-9210 |language=zh-Hans-CN}}</ref>{{Rp|大事记}}。1994年8月1日，由[[邓小平]]题写的“武汉机场”铜字安放在机场门口<ref name=年鉴1995/>{{Rp|大事记}}。9月27日，一期工程竣工。同年12月28日，一期工程通过国家正式验收，并于次日首航<ref name=年鉴1995>{{Cite book |title=武汉年鉴 1995 |author=武汉地方志编纂委员会办公室 |publisher=武汉年鉴社 |year=1995 |ISSN=1005-9210 |language=zh-Hans-CN}}</ref>{{Rp|大事记}}。

=== 早期运营 ===
1995年4月15日，天河机场作为国家一级民用机场正式开航启用，同日南湖机场关闭。1997年11月28日，天河机场脱离原中国民航湖北省管理局行政体制，实行独立运营。1998年5月18日，武汉天河机场股份有限公司正式成立，具有独立法人资格<ref>{{cite web |author1=陈亮 詹松 何晓刚 黄玮 |title=“40年同框”见证武汉巨变 |url=https://www.cnr.cn/hubei/jiaodian/20180813/t20180813_524329851.shtml |website=央广网 |publisher=长江日报 |accessdate=2018-08-13 |archive-date=2024-04-14 |archive-url=https://web.archive.org/web/20240414173114/https://www.cnr.cn/hubei/jiaodian/20180813/t20180813_524329851.shtml |dead-url=no }}</ref>，同年7月17日开通至日本[[福冈机场|福冈]]的首条国际航线<ref>{{cite web |author1=王爽婧 |title=20年前武汉开通首条国际直飞航线 如今已达近60条 |url=https://hb.ifeng.com/a/20180717/6731034_0.shtml |website=凤凰网湖北 |publisher=楚天都市报 |accessdate=2018-07-17}}</ref>。

=== 修建2号航站楼与新国际航站楼 ===
2004年3月5日，[[北京首都國際機場股份|北京首都国际机场股份有限公司]]接管天河机场股份有限公司51%的股权，湖北机场集团公司成立并开始管理天河机场。同年12月29日，机场二期工程开工。2008年4月15日，2号航站楼投入运行<ref>{{Cite web |url=http://www.caac.gov.cn/A3/200804/t20080416_13741.html |title=武汉天河机场第二航站楼启用 |access-date=2010-03-13 |archive-date=2011-03-01 |archive-url=https://web.archive.org/web/20110301133015/http://www.caac.gov.cn/A3/200804/t20080416_13741.html |dead-url=no }}</ref>。2010年5月，3号航站楼开始建设。2010年12月，启用新国际航站楼<ref>{{cite web |author1=徐金波 文飞飞 陈晓东 |title=武汉国际客流量今年增85% 启用全新国际航站楼 |url=https://www.chinanews.com/df/2010/12-28/2752843.shtml |website=中国新闻网 |accessdate=2010-12-28 |archive-date=2024-12-09 |archive-url=https://web.archive.org/web/20241209052500/https://www.chinanews.com/df/2010/12-28/2752843.shtml |dead-url=no }}</ref>。

2012年3月，原作为国际航站楼使用的1号航站楼[[登机桥]]被拆除，将104停机位改造成可停靠A380机型的大型停机位<ref name="武汉机场T1航站楼登机桥拆除完工">{{cite web | url=http://news.ccaonline.cn/Article/2012-03-31/303311_1.shtml | title=武汉机场T1航站楼登机桥拆除完工 | accessdate=2012-07-05 | deadurl=yes | archiveurl=https://web.archive.org/web/20140103234308/http://news.ccaonline.cn/Article/2012-03-31/303311_1.shtml | archivedate=2014-01-03 }}</ref>。2012年4月，新国际航站楼扩建完成<ref>{{cite web |author1=左洋 王飞 |title=武汉天河机场国际航站楼扩建提升候机能力 |url=http://www.ce.cn/aero/news/201202/08/t20120208_21111983.shtml |website=中国经济网 |publisher=武汉晚报 |accessdate=2012-02-08}}</ref>，[[法国航空|法航]]直飞巴黎航线开通<ref name="华中首条洲际直飞航线开通 武汉加速构建中部航空枢纽">{{cite web | url=http://finance.huanqiu.com/data/2012-04/2603783.html | title=华中首条洲际直飞航线开通 武汉加速构建中部航空枢纽 | accessdate=2012-04-13 | archive-url=https://web.archive.org/web/20140826161511/http://finance.huanqiu.com/data/2012-04/2603783.html | archive-date=2014-08-26 | dead-url=yes }}</ref>。2014年7月30日，南航直飞莫斯科航线开通<ref name="武汉开通直飞莫斯科航班 飞行时间缩至9小时">{{cite web| url=http://www.hb.xinhuanet.com/2014-07/28/c_1111827642.htm| title=武汉开通直飞莫斯科航班 飞行时间缩至9小时| accessdate=2014-07-28| deadurl=yes| archiveurl=https://web.archive.org/web/20140729143159/http://www.hb.xinhuanet.com/2014-07/28/c_1111827642.htm| archivedate=2014-07-29}}</ref>。2014年10月30日，海航采用波音787执飞北京武汉往返航线，这是“梦想客机”首次到汉执飞商业航班<ref name="天河机场迎来首架波音787 首航武汉飞北京">{{cite web| url=http://news.cnhubei.com/xw/wuhan/201410/t3084691.shtml| title=天河机场迎来首架波音787 首航武汉飞北京| accessdate=2015-05-12| archive-date=2020-04-28| archive-url=https://web.archive.org/web/20200428205640/http://news.cnhubei.com/xw/wuhan/201410/t3084691.shtml| dead-url=no}}</ref>。2014年12月16日，南航直飞旧金山航线开通，采用“梦想客机”波音787-8执飞<ref name="南航开通华中首条直达美国航线">{{cite web| url=http://www.csair.com/cn/about/news/news/2014/1998vjq1n3ec4.shtml| title=南航开通华中首条直达美国航线| accessdate=2015-05-12| archive-date=2020-04-28| archive-url=https://web.archive.org/web/20200428205626/http://www.csair.com/cn/about/news/news/2014/1998vjq1n3ec4.shtml| dead-url=no}}</ref>。

=== 航站楼 ===
==== 1号航站楼 ====
天河机场最初的1号航站楼（俗称“老T1”）于1995年投用，建成初期主要运营国内航班。2号航站楼于2004年启用后，1号航站楼改为用于国际和地区航班的起降服务，由于规模较小，作为国际航班专用期间只能同时满足一架波音777等级的飞机停放。随着天河机场越来越多国际及地区航线的开通，1号航站楼已经无法容纳更多国际航班<ref name="天河机场 国际航站楼 下月扩建">{{cite web | url=http://news.163.com/12/0131/03/7P2LM8BN00014AED.html | title=天河机场 国际航站楼 下月扩建 | accessdate=2012-02-03 | archive-date=2020-09-26 | archive-url=https://web.archive.org/web/20200926163111/http://news.163.com/12/0131/03/7P2LM8BN00014AED.html | dead-url=no }}</ref>。

2009年4月，位于2号航站楼停机坪与北三路之间的过渡性国际航站楼（也称“新T1”）完成设计及可行性研究报告，同年6月开建，2010年12月28日建成投用。新T1建筑高度14.5米，建筑面积约5300平方米，航站楼外形和风格与2号航站楼相仿，银灰色主基调，采用玻璃通透幕墙，配备商业、餐饮、行李房、停车场等，共投资9500余万元，设计使用年限50年<ref>{{Cite web|url=http://news.163.com/10/1205/05/6N48F5J200014AED.html|title=天河机场月底启用过渡航站楼_网易新闻|accessdate=2018-07-28|last=网易|work=news.163.com|archive-url=https://web.archive.org/web/20180728190855/http://news.163.com/10/1205/05/6N48F5J200014AED.html|archive-date=2018-07-28|dead-url=yes}}</ref>。新T1竣工并投入使用后，老T1国际航站楼即停止使用，2010年底时机场管理方宣布老T1承担的航空服务功能将会被过渡性国际候机楼取代，暂时“退役”，最终将被改建为办公楼<ref>{{Cite web|url=http://news.cnhubei.com/ctdsb/ctdsbsgk/ctdsb04/201005/t1141943.shtml|title=总设计师揭秘武汉天河机场T3航站楼尖板眼_荆楚网 www.cnhubei.com|accessdate=2018-07-28|last=荆楚网|work=news.cnhubei.com|archive-url=https://web.archive.org/web/20180728131255/http://news.cnhubei.com/ctdsb/ctdsbsgk/ctdsb04/201005/t1141943.shtml|archive-date=2018-07-28|dead-url=yes}}</ref>。

2012年2月6日，为了应对持续增长的国际客流需求，1号航站楼开始第一次扩建，在原来5300平方米基础上再增加4300平方米，并于同年4月9日投入使用。扩建后可同时停放一大两小三架飞机，或同时停放两架大型飞机<ref name="天河机场 国际航站楼 下月扩建" /><ref name="武汉天河机场建成新国际航站楼">{{cite web| url=http://news.cqnews.net/html/2012-04/09/content_14624026.htm| title=武汉天河机场建成新国际航站楼| accessdate=2012-07-05| deadurl=yes| archiveurl=https://archive.today/20130502050419/http://news.cqnews.net/html/2012-04/09/content_14624026.htm| archivedate=2013-05-02}}</ref>。然而，天河国际机场国际航线不断增多，国际客流继续快速增长。2014年12月，国际航站楼二期扩建工程可行性研究报告日前获省发改委批复，将扩建国际航站楼建筑面积5200平方米，停车场及道路面积3722平方米，扩建后总面积将达到1.46万平方米，满足国际旅客吞吐量200万人次/年，总投资6467万元。<ref>{{Cite web |url=http://news.carnoc.com/list/300/300868.html |title=武汉天河机场国际航站楼将扩建 |access-date=2014-12-05 |archive-date=2020-08-25 |archive-url=https://web.archive.org/web/20200825020142/http://news.carnoc.com/list/300/300868.html |dead-url=no }}</ref>2016年1月27日，新一轮扩建完成，T1候机区面积增加约2200平方米，值机区面积增加700平方米，并增设值机柜台8组，出港边检通道1条，安检通道1条<ref name="武汉天河机场建成新国际航站楼" /><ref>{{cite web| url=http://stock.sohu.com/20160127/n436065968.shtml| title=武汉天河机场扩建国际航站楼启用| accessdate=2016-11-25| deadurl=yes| archiveurl=https://web.archive.org/web/20161126133639/http://stock.sohu.com/20160127/n436065968.shtml| archivedate=2016-11-26| df=}}</ref>。2017年8月31日，随着3号航站楼投入使用，1号与2号航站楼均暂时关闭，所有国际线的到发已转场到3号航站楼，机场管理方宣布1号航站楼将会改建成公务/包机航站楼。

2019年9月24日，1号航站楼改造工程完工，在[[第七届世界军人运动会]]期间曾作为军运会的专机楼。军运会结束后，改建成为{{tsl|en|Fixed-base operator|商务公务专机楼}}和机场运控中心（AOC）<ref>{{cite web| url=http://m.xinhuanet.com/hb/2019-09/25/c_1125036331.htm| title=武汉天河机场T1航站楼即将回归| accessdate=2019-12-15| archive-date=2020-08-25| archive-url=https://web.archive.org/web/20200825020152/http://m.xinhuanet.com/hb/2019-09/25/c_1125036331.htm| dead-url=no}}</ref>。

==== 2号航站楼 ====
2号航站楼于2004年12月底开工，2008年4月15日投入运行。T2占地23万平方米，由一个主楼（值机/行李提取大厅）和两个指廊（登机口）呈“U”型组合布置。主楼地上三层、地下一层，为设备间和停车场；地上两层中，进出港分流，一层为到达层，二层为出发层，设有24个停机位，26条旅客安检通道。2004年底2号航站楼开工建设时，虽然1号航站楼容量已经饱和，但天河国际机场年旅客吞吐量仅有400余万人次，2号航站楼设计1300万人次的吞吐能力计划要到2020年才可达到这个目标。然而，2005年以后，武汉民航迅速发展，到2008年2号航站楼建成时，旅客吞吐量已达到860万人次，由于2号航站楼设计吞吐能力仅为全年1300万人次，到2013年已经处于满载状态。到2016年时，天河国际机场每天进出港500多个航班，全年旅客发送量达2077.2万人次，2号航站楼严重超载，不仅航班经常延误，而且由于航班容量明显不足无法开设新的航线<ref>{{Cite web |url=http://www.cnhan.com/html/xiansh/20170831/645611.htm |title=天河机场服役9年的T2航站楼关闭 吞吐能力更大的T3启用 |access-date=2017-09-06 |archive-url=https://web.archive.org/web/20170907034327/http://www.cnhan.com/html/xiansh/20170831/645611.htm |archive-date=2017-09-07 |dead-url=yes }}</ref>。2017年8月31日，随着3号航站楼投用，2号航站楼所有国内线的到发已转场到3号航站楼，T2随即封闭等待改建。3号航站楼建设时已建成与2号航站楼的连接通道，旅客在3号航站楼行走时，可见“通往2号航站楼”的指示牌。

2021年10月18日，2号航站楼改造工程开工，项目包含2号航站楼改造工程、航站楼室外工程、机坪改造工程、陆侧道路交通改造工程，2023年6月整体精装完工，同年9月完成行业验收，2024年4月15日投入使用。改造后的2号航站楼为两层半式国内旅客航站楼，采用出发到达分流模式，建筑面积15.84万平方米<ref>{{cite web |author1=武一力 |author2=习悦  |author3=甘頔 |title=武汉天河机场迈入双航站楼运行时代
 |url=https://www.chinanews.com/cj/2024/04-15/10199038.shtml |website=中国新闻网 |publisher=中国新闻网 |accessdate=2024-07-04}}</ref>，设计容量为1500万人次/年。航站楼设计保留现有商业夹层，新增安检区和安检后夹层商业区及地下一层餐厅区，配置自助值机、自助行李托运、自助安检验证、自助登机等一站式自助设备，楼内自助化率超过80%<ref>{{Cite web |url=http://news.cnhubei.com/content/2021-10/19/content_14180760.html |title=武汉天河机场T2航站楼改造开工 预计后年建成投用 |access-date=2022-06-10 |archive-date=2022-07-01 |archive-url=https://web.archive.org/web/20220701031024/http://news.cnhubei.com/content/2021-10/19/content_14180760.html }}</ref>。

2024年4月15日，2号航站楼恢复启用，仅服务除[[南航]]、[[东航]]、[[国航]]以外的国内航线，与3号航站楼通过连廊和[[穿梭巴士|摆渡车]]相连<ref>{{cite web |author1=邓腊秀 |title=武汉天河机场T2航站楼今日启用 |url=http://news.cjn.cn/asy/lbt/202404/t4874834.htm |website=长江网 |publisher=长江日报 |accessdate=2024-04-15}}</ref><ref>{{cite web |title=4月15日起，武汉天河机场T2航站楼启用 |url=https://www.ccaonline.cn/jichang/jchot/947306.html |website=中国民用航空网 |accessdate=2024-04-15}}</ref>。2号航站楼的A、B指廊末端各有一个室内[[观景台]]，设有橙色的6层景观台阶、台阶背后设有以英文字母设计为隔断的卡座，单个观景台可容纳100人观景<ref>{{cite web |author1=徐丹 |author2=甘頔 |author3=习悦 |title=感受飞机划过天际的震撼与浪漫，全国首个航站楼观景台惊艳亮相 |url=http://news.cjn.cn/whpd/yw_19947/202404/t4873651.htm |website=长江网 |publisher=长江日报 |accessdate=2024-04-12 |archive-date=2024-04-17 |archive-url=https://web.archive.org/web/20240417024627/http://news.cjn.cn/whpd/yw_19947/202404/t4873651.htm |dead-url=no }}</ref>。

==== 3号航站楼 ====

===交通中心===
天河机场交通中心（GTC）汇集了[[航空]]、[[地铁]]、[[城际铁路]]、[[公共汽車]]、长途客运、[[出租车]]、[[网约车]]、社会车辆8种交通方式。[[机场]][[航站楼]]和[[天河机场站 (地铁)|地铁]]通过立体式设计的交通中心（GTC），缩短乘客换乘距离。在T3与交通中心之间，旅客平均行走距离为190米，时间约3分钟。在交通中心，乘客可以通过楼梯、自动扶梯和垂直电梯，通达位于地下的地铁站厅和站台层。在交通中心换乘上地铁，约需2分钟；从T3航站楼到坐上地铁，全程约需5分钟<ref>[http://hb.qq.com/a/20160214/009552.htm 武汉天河机场连接地铁 7种方式往返机场与城区] {{Wayback|url=http://hb.qq.com/a/20160214/009552.htm |date=20181006235523 }}长江网-长江日报2016-02-14</ref>。

交通中心共四层，其中地上、地下分别两层。通过设置在地上二层的廊桥、地下一层的联络通道，与T3航站楼形成无缝对接。交通中心包含了交通换乘的传统功能，还根据现有规模拓展了包括休闲、购物等一系列综合服务功能。交通中心地面两层呈“T”字形布局，在地面一层分别设有出租车候车区、长途客运站以及购物区，而在地面二层设有3座连廊，将交通中心与T3航站楼连接起来。除了部分购物区外，还在西北角设有一处4000平方米的会议中心，东北角设有一座占地5000平方米的机场酒店。

除了功能区和设备区之外，交通中心利用地下、地上空间，设计建设了大量停车位。从地下一层到地面二层，整个交通中心最多可容纳3200余辆车停靠<ref>[http://www.hb.xinhuanet.com/2016-06/11/c_1119021206.htm 7种交通方式无缝衔接 华中最大换乘中心年底投用] {{Wayback|url=http://www.hb.xinhuanet.com/2016-06/11/c_1119021206.htm |date=20160810002045 }}2016-6-27 武汉晚报</ref>。

== 240小时过境免签 ==
2024年12月17日起，武汉天河国际机场口岸正式实施[[中华人民共和国签证政策#240小时免签|240小时过境免签]]政策。全球共54个国家的公民，持本人有效国际旅行证件，以及240小时内已确定日期及座位、由武汉天河国际机场出境前往第三国(地区)的联程机票，可以于机场口岸申请240小时过境免签。获准过境免签的外国人士，自入境的次日零时起，可在湖北省行政区域停留最多240小时<ref>{{cite web |author1=成熔兴 |title=2019年1月1日起武汉将实施外国人144小时过境免签 |url=https://www.hubei.gov.cn/hbfb/szsm/201811/t20181116_1548608.shtml |website=湖北省人民政府网站 |publisher=湖北日报 |accessdate=2018-11-16}}</ref>。

适用240小时过境免签的国家如下：

*欧洲[[申根公约|申根签证协议]]国家（25个）：{{Flag|奥地利}}、{{Flag|比利时}}、{{Flag|捷克}}、{{Flag|丹麦}}、{{Flag|爱沙尼亚}}、{{Flag|芬兰}}、{{Flag|法国}}、{{Flag|德国}}、{{Flag|希腊}}、{{Flag|匈牙利}}、{{Flag|冰岛}}、{{Flag|意大利}}、{{Flag|拉脱维亚}}、{{Flag|立陶宛}}、{{Flag|卢森堡}}、{{Flag|马耳他}}、{{Flag|荷兰}}、{{Flag|波兰}}、{{Flag|葡萄牙}}、{{Flag|斯洛伐克}}、{{Flag|斯洛文尼亚}}、{{Flag|西班牙}}、{{Flag|瑞典}}、{{Flag|瑞士}}、{{flaglist|挪威}}。
*欧洲其他国家（15个）：{{Flag|俄罗斯}}、{{Flag|英国}}、{{Flag|爱尔兰}}、{{Flag|摩纳哥}}、{{Flag|塞浦路斯}}、{{Flag|保加利亚}}、{{Flag|罗马尼亚}}、{{Flag|乌克兰}}、 {{Flag|白俄罗斯}}、{{Flag|塞尔维亚}}、{{Flag|克罗地亚}}、{{Flag|波黑}}、{{Flag|黑山}}、{{Flag|阿尔巴尼亚}}、{{Flag|北马其顿}}。

== 未来规划 ==
根据国务院印发《“十三五”现代综合交通运输体系发展规划》，将打造12个国际性综合交通枢纽，其中包括武汉。天河国际机场扩建的主要建设内容包括4号航站楼、卫星厅、第三跑道、第四跑道<ref>{{Cite web |url=http://www.huaxia.com/hb-tw/jlhz/jcsx/2017/03/5209349.html |title=国务院明确武汉为国际性综合交通枢纽 提出扩建天河机场 |accessdate=2017-04-06 |archive-date=2017-11-21 |archive-url=https://web.archive.org/web/20171121123504/http://www.huaxia.com/hb-tw/jlhz/jcsx/2017/03/5209349.html |dead-url=no }}</ref><ref>{{Cite web |url=http://www.dongfeng.net/index.php?c=content&a=show&id=8683 |title=天河机场“十三五”期间扩建 |access-date=2017-04-06 |archive-date=2020-08-25 |archive-url=https://web.archive.org/web/20200825020416/http://www.dongfeng.net/index.php?c=content&a=show&id=8683 |dead-url=no }}</ref>。根据规划，将在2035年前形成“5条跑道+双航站区”的格局<ref>{{cite web |author1=中国民航网 |title=武汉天河机场第三跑道工程开工建设 |url=http://www.caacnews.com.cn/1/5/202206/t20220630_1347678.html |website=中国民航网 |accessdate=2023-02-20 |archive-date=2023-02-20 |archive-url=https://web.archive.org/web/20230220062929/http://www.caacnews.com.cn/1/5/202206/t20220630_1347678.html |dead-url=no }}</ref>。[[沪渝蓉沿江高铁]]将新建[[武汉天河站]]，其位于临空经济副城、机场以南，近期站房规模6万平方米，是[[武汉铁路枢纽]]“五主两辅”格局中唯一空铁联运的客运站，旅客可在候车厅直接值机。从武汉天河站乘坐高铁，1.5小时可以到达合肥、3小时可以到达上海<ref>{{cite web |author1=赖俊 |title=看飞机起降、赏湖光山色 高铁武汉天河站设计出炉 |url=https://www.wuhan.gov.cn/sy/tswh/202406/t20240611_2414541.shtml |website=武汉市人民政府网站 |publisher=长江日报 |accessdate=2024-06-11 |archive-date=2024-12-09 |archive-url=https://web.archive.org/web/20241209052242/https://www.wuhan.gov.cn/sy/tswh/202406/t20240611_2414541.shtml |dead-url=no }}</ref>。
