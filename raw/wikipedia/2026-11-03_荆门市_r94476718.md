'''荆门市'''是[[中华人民共和国]][[湖北省]]下辖的[[地级市]]，鄂中区域性中心城市<ref>{{cite web |title=省人民政府关于荆门市城市总体规划（2013—2030年）的批复 - 湖北省人民政府门户网站 |url=http://www.hubei.gov.cn/zfwj/ezh/201408/t20140808_1712196.shtml |website=www.hubei.gov.cn |accessdate=2020-10-04 }}{{Dead link}}</ref>，位于湖北省中部。市境南临[[荆州市]]、[[潜江市]]、[[天门市]]、东接[[孝感市]]、东北界[[随州市]]、西北毗[[襄阳市]]、西达[[宜昌市]]。地处[[江汉平原]]西北部，西北部为[[荆山 (山脉)|荆山]]余脉，东北部为[[大洪山]]南麓。[[汉水]]自北往南纵贯全境，有[[长湖 (湖北)|长湖]]、[[借粮湖]]等湖泊。全市总面积12,339平方公里，人口255.07万<ref name=":0">{{Cite web|title=湖北省第七次全国人口普查公报（第二号）|url=http://tjj.hubei.gov.cn/tjsj/tjgb/pcgb/qrp/202105/t20210525_3559343.shtml|access-date=2021-07-02|archive-date=2021-06-11|archive-url=https://web.archive.org/web/20210611155330/http://tjj.hubei.gov.cn/tjsj/tjgb/pcgb/qrp/202105/t20210525_3559343.shtml|dead-url=yes}}</ref>，荆门东眺[[武汉]]，西临[[長江三峽|三峡]]，南望[[潇湘]]，北通[[川]][[陕]]，素有“荆楚门户”之称。市人民政府驻[[东宝区]]象山大道53号。

== 历史 ==
=== 先秦 ===
荆门的历史可以上溯到距今6000余年的[[新石器时代]]。现已在荆门发现了[[屈家岭遗址]]、[[荆家城遗址]]、[[马家垸遗址]]等保存完好、规模较大的文化遗存。经过对出土文物的考古鉴定，这些文化大多分属于[[大溪文化]]、[[屈家岭文化]]、[[石家河文化]]三类原始文化。其中屈家岭文化因首次发现于荆门市[[屈家岭管理区]]屈家岭村而得名。屈家岭遗址自1954年以来共进行了三次大规模发掘，出土了大量新石器时代的生产生活用具，是目前保存最为完好的屈家岭文化遗址。

[[商朝]]时，[[权人]]在今荆门市南郊的[[权水]]旁设治，建立[[权国]]。公元前一世纪，[[周朝]]取代商朝，权国遂归顺周朝，并被重新分封，其治域大大缩小。周成王时，封[[周武王]]的弟[[姬甲]]于今天[[沙洋县]]拾回桥一带，建立了[[那国]]，因为相邻的原因也兼领了权国。公元前688年前后，[[楚武王]]熊通灭那国、权国。灭权后[[楚国]]在权国故地设[[权县]]。

=== 歷代發展 ===
[[汉朝]]置[[当阳县]]，[[唐朝]][[贞元 (唐朝)|贞元]]二十一年（公元805年），设立[[荆门县]]。[[宋朝]]建[[荆门军]]，[[明朝]]复荆门县，[[清朝]]为[[荆门直隶州]]，[[中華民國|民国]]降州为县。

=== 中華人民共和国成立后 ===

续为荆门县。1979年分设荆门县、荆门市，1983年荆门县并入荆州市，直属[[湖北省人民政府]]。1996年，划原隶属[[荆州市]]的[[京山县]]、[[钟祥市]]为荆门市直管和代管。

== 地理 ==
接邻市县：[[荆州市]]、[[襄阳市]]、[[当阳市]]、[[南漳县]]、[[宜城市]]、[[应城市]]、[[天门市]]、[[潜江市]]。

坐标范围：东经112°11'~112°14'，北纬31°01'~31°04'。地处荆州以北100公里，为荆楚之门户，所以称之为荆门。

荆门地域东、西、北三面高，中、南部低，呈向南敞开形，形成低山坳谷、丘岗冲沟和平原湖区兼具地势。区域内地势平坦，土壤肥沃，湖泊密布，河网交织，堤垸纵横，是全市粮棉集中产区。

== 人口 ==
2022年末，全市常住人口254.77万人，常住人口城镇化率60.35%，比上年末提高0.59个百分点；户籍人口284.47万人<ref>{{Cite web |url=http://tjj.hubei.gov.cn/tjsj/tjgb/ndtjgb/sztjgb/202305/P020230504610345021770.doc |title=2022人口 |access-date=2023-12-10 |archive-date=2024-01-27 |archive-url=https://web.archive.org/web/20240127113406/http://tjj.hubei.gov.cn/tjsj/tjgb/ndtjgb/sztjgb/202305/P020230504610345021770.doc |dead-url=no }}</ref>。户籍人口城镇化率43.05‰。人口出生率4.58‰。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,596,927人<ref>{{cite web |author1=荆门市统计局、荆门市第七次全国人口普查领导小组办公室 |title=荆门市第七次全国人口普查公报 |url=https://www.jingmen.gov.cn/art/2021/6/21/art_19623_796087.html |access-date=2023-07-23 |archive-date=2025-02-18 |archive-url=https://web.archive.org/web/20250218105516/https://www.jingmen.gov.cn/art/2021/6/21/art_19623_796087.html |dead-url=yes }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,873,687人相比，十年共减少了276,760人，下降9.63%，年平均增长率为-1.01%。其中，男性人口为1,316,732人，占总人口的50.7%；女性人口为1,280,195人，占总人口的49.3%。总人口性别比（以女性为100）为102.85。0－14岁的人口为352,036人，占总人口的13.56%；15－59岁的人口为1,651,700人，占总人口的63.6%；60岁及以上的人口为593,191人，占总人口的22.84%，其中65岁及以上的人口为419,597人，占总人口的16.16%。居住在城镇的人口为1,525,278人，占总人口的58.73%；居住在乡村的人口为1,071,649人，占总人口的41.27%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,578,541人，占99.29%；各[[中国少数民族|少数民族]]人口为18,386人，占0.71%。与2010年第六次全国人口普查相比，汉族人口减少281,678人，下降9.85%，占总人口比例下降0.24个百分点；各少数民族人口增加4,918人，增长36.52%，占总人口比例增加0.24个百分点。

== 经济 ==
以前主要以农业为主，[[改革开放]]后重工业、轻工业和军工得到了很大的发展，使荆门市人均[[GDP]]达到全国中型城市前列。比较大型的企业有[[中国石化]]荆门分公司、荆门热电厂、洋丰集团、中天集团、金龙泉啤酒集团等。其中，金龙泉啤酒为中国啤酒业十强。航空航天部605研究所负责研制水上飞行器及飞艇。中天街是全市的商业中心，商贸发达。2022年，荆门实现地区生产总值2200.96亿元，经济发展处于湖北的中游水平。<ref>{{Cite web |url=http://www.jingmen.gov.cn/col/col627/index.html |title=存档副本 |access-date=2023-07-02 |archive-date=2020-12-05 |archive-url=https://web.archive.org/web/20201205023830/http://www.jingmen.gov.cn/col/col627/index.html |dead-url=no }}</ref>

== 教育 ==
*高等教育：[[荆楚理工学院]]，由原荆门职业技术学院、沙洋师范高等专科学校合并组建而成。
*中等教育：[[荆门市龙泉中学]]、[[荆门市第一中学]]、[[东宝中学]]、  石化中学（原中国石化荆门石油化工学校已被荆门职业技术学院兼并为中专部及大学分校区）、[[荆门技校]]、[[荆门成人中专]]、[[湖北信息工程学校]]、[[掇刀石中学]]。
