'''全南县'''（旧称“'''虔南'''”，1957年更名为“'''全南'''”）是[[赣州市]]下辖的一个县，地處江西省最南端，東鄰龍南市，南靠廣東省連平縣、翁源縣，西接廣東省始興縣，北連廣東省南雄市，東北毗信豐縣，縣政府駐含江路16號。

== 历史沿革 ==

民国初年，全国[[废府州厅改县]]，于1912年改[[虔南厅]]为虔南县。[[治所]]在今江西省全南县驻地城厢镇。1942年8月，[[赣南新政|蒋经国主政赣南]]期间，[[国民政府]]将[[信丰县]]新设的江口乡划入虔南县<ref>{{Cite web |url=http://www.qndw.gov.cn/n161369/c4789624/content.html |title=1942年信丰南部一片区域划入全南 |accessdate=2015-03-19 |author= |date=2012年6月29日 |work= |publisher=全南党务公开网 |language=Zh-hans |archive-date=2016-03-05 |archive-url=https://web.archive.org/web/20160305011600/http://www.qndw.gov.cn/n161369/c4789624/content.html |dead-url=yes }}</ref>。

1949年8月21日<ref>另说在20日由中国人民解放军第48军部队攻占。</ref><ref>{{Cite web |url=http://paper.srxww.com/srwb/html/2009-10/01/content_62322.htm |title=赣水苍茫红旗飘——赣南解放纪实 |accessdate=2015-03-19 |author= |date=2009-10-01 |work= |publisher=上饶新闻网，来源：上饶晚报 |language=Zh-hans |archive-date=2019-07-16 |archive-url=https://web.archive.org/web/20190716051203/http://paper.srxww.com/srwb/html/2009-10/01/content_62322.htm |dead-url=no }}</ref>，[[中国人民解放军第48军]]431团和粤赣湘边纵队赣南支队虔南大队在虔南县城会师。[[中华民国政府]]对虔南县的管辖结束。9月1日，成立虔南县人民政府<ref name="a1">{{Cite web|url=http://www.quannan.gov.cn/XinWenZhongXin/ArticleList.aspx?Flag=1&ClassId=428|title=全南年鉴|accessdate=2015-03-19|author=|date=|work=|publisher=全南县人民政府网站|language=Zh-hans|archive-date=2015-04-02|archive-url=https://web.archive.org/web/20150402092449/http://www.quannan.gov.cn/XinWenZhongXin/ArticleList.aspx?Flag=1&ClassId=428|dead-url=yes}}</ref>。其后，属[[赣州专区]]。1957年5月<ref name="a1"/>，因原名生僻，经[[中华人民共和国国务院|中国国务院]]批准，[[因用字生僻难认而更名的中国大陆地名列表|改名]]全南县。

== 人口 ==
根據第七次人口普查數據，截至2020年11月1日零時，全南縣市常住人口為169503人<ref>{{Cite web|title=2021年全南县人口常住户籍总人数口和第七次人口普查结果-红黑人口库|url=https://www.hongheiku.com/xianjirank/jxsgxsq/10772.html|access-date=2023-04-07|website=www.hongheiku.com|archive-date=2022-01-23|archive-url=https://web.archive.org/web/20220123204756/https://www.hongheiku.com/xianjirank/jxsgxsq/10772.html|dead-url=no}}</ref>。

== 地理 ==
全南县地处江西省最南端，与广东翁源、连平、始兴、南雄、江西龙南、信丰6县（市）交界。

全南属亚热带季风型气候区。

== 交通 ==
县城处于[[105国道]]与[[106国道]]、赣粤高速与京珠高速的公路连接线上，距赣州180公里，至韶关站142公里，至龙南站45公里，至广州260公里、至东莞320公里、至深圳380公里，是江西省融入“9+2”泛珠三角经济圈和承接沿海产业转移的前沿阵地。2013年1月通車的[[龙杨高速公路]]把全南融入珠三角二小时交通圈。
