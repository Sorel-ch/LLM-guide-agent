'''昆山市'''在[[中华人民共和国]][[江苏省]]东南部，邻接[[上海市]]，是[[江苏省]]的一个直管[[县级市]]<ref>{{cite web|title=江苏三县试点“省直管” 直接向省政府报告工作|url=http://news.sohu.com/20120926/n353936607.shtml|date=2012-09-26|publisher=搜狐|archiveurl=https://web.archive.org/web/20150206191955/http://news.sohu.com/20120926/n353936607.shtml|archivedate=2015-02-06|deadurl=no}}</ref>，行政上由[[苏州市]]代管。昆山历史悠久，文化底蕴深厚，江南水乡[[周庄镇 (昆山市)|周庄]]即位于昆山境内。昆山经济高度发达，自2005年来连续十六年位居[[中国百强县]]榜首<ref>{{Cite web|title=2023年中国中小城市高质量发展指数研究成果发布|url=http://www.csmcity.cn/luntan/bbs2023/2023_01.php|work=搜狐|language=|archive-url=https://web.archive.org/web/20210711094629/https://www.sohu.com/a/410162732_323328|archive-date=2021-07-11|access-date=2021-07-03|dead-url=no}}</ref>。市人民政府駐前进中路108号。区域总面积931.5平方公里。

昆山市自秦代置县以来已有2200多年，是“百戏之祖”[[昆曲]]的发源地<ref>{{Cite web|author=UNESCO|date=|title=Kun Qu opera|url=http://www.unesco.org/culture/ich/en/RL/kun-qu-opera-00004|accessdate=2016-05-14|publisher=|deadurl=no|archiveurl=https://web.archive.org/web/20160607132746/http://www.unesco.org/culture/ich/en/RL/kun-qu-opera-00004|archivedate=2016-06-07}}</ref>。昆山市曾于2010年获得联合国人居奖<ref>{{Cite web|date=2010-09-06|title=中国江苏昆山荣获2010年联合国人居奖|url=https://news.un.org/zh/story/2010/09/136882|archive-url=https://web.archive.org/web/20210711011810/https://news.un.org/zh/story/2010/09/136882|archive-date=2021-07-11|access-date=2021年7月3日|publisher=联合国新闻|dead-url=no}}</ref>，被评为首批“国家生态园林城市”。

== 历史 ==
[[秦代]]设[[娄县 (秦朝)|娄县]]。[[南朝梁]]改[[昆山县 (南梁)|昆山县]]，以当时境内的[[小昆山 (山峰)|小昆山]]（现位于上海市松江区小昆山镇）而得名；[[元代]]曾升为昆山州，[[明代]]复降为县；[[清代]]因为人口众多，税收任务繁重，分为昆山和[[新阳县 (清朝)|新阳]]兩县；[[中華民國|民国]]初年又重新合并，属[[江苏省 (中華民國)|江苏省]][[沪海道]]。1949年5月昆山解放，属华东军政委员会苏南苏州行政区专员专署<ref>{{cite web |title=历史文化 |url=http://www.ks.gov.cn/kss/lswh2/common_tt.shtml |website=昆山市人民政府 |date=2023-04-24 |access-date=2023-07-26 |archive-date=2023-07-26 |archive-url=https://web.archive.org/web/20230726083114/http://www.ks.gov.cn/kss/lswh2/common_tt.shtml |dead-url=no }}</ref>。

==人口==
根据[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]数据显示，截至2020年11月1日零时，昆山市常住人口为2,092,496人，比2010年增加44.76万人，年均增长2.44%。城镇常住人口165.22万人，全市常住人口城镇化率为78.96%，比2010年提升10.95个百分点<ref name="7rp"/>。

200多万常住人口中，2024年户籍人口129.46万人<ref>{{cite web|title=2024 年昆山市国民经济和社会发展统计公报|url=https://www.suzhou.gov.cn/szsrmzf/ndgmjjhshfztjsjfb/202505/cc1f2dcd13f64244bb80b4b4c53613cc/files/5b89f04d860740f4baee380ba3e9b097.pdf|publisher=昆山市统计局|date=2025-05-08}}</ref>；86.46万外来人口（净流入人口）中<ref>{{cite news|title=方世南等 推动新时代社会工作高质量发展的昆山实践|url=https://mp.weixin.qq.com/s/mxfT9ytE3f4VgFO157fOhQ|work=苏州市社会科学院|publisher=微信公众号|date=2026-01-26}}</ref>，10万拥有[[戶籍 (臺灣)|臺灣戶籍]]，大多为[[台湾商人]]及其台属<ref>{{cite news|title=昆山深化两岸产业合作试验区成立10年来——优化营商环境 助力台企发展（两岸脉动）|url=http://politics.people.com.cn/n1/2023/1217/c1001-40140446.html|publisher=人民网|date=2023-12-17}}</ref>；另有约2.1万外籍人口<ref>{{cite news|title=昆山：打造全周期人才友好型城市|url=https://news.2500sz.com/doc/2025/07/12/1160369.shtml|publisher=苏州日报|date=2025-07-12}}</ref>。

== 地理 ==
昆山位于东经120°48′21″~121°09′04″、北纬31°06′ 34 ″~31°32′36之间，东面和东南面毗邻[[上海市]][[嘉定区]]及[[青浦区]]，西面毗邻[[苏州市]]园区、[[吴中区]]及[[相城区]]，北面和东北面毗邻[[常熟市]]和[[太仓市]]，西南面与苏州市[[吴江区]]接壤。东西最大直线距离33公里，南北48公里，总面积931平方公里，其中超过24%是水面<ref>{{cite web| url=http://www.ks.gov.cn/zrgk?id=929&status=1| title=昆山-自然概况-位置| publisher=昆山市人民政府办公室| date=2019-04-04| deadurl=yes| archiveurl=https://web.archive.org/web/20180217120834/http://www.ks.gov.cn/zrgk?id=929&status=1| archivedate=2018-02-17}}</ref>。

昆山地处[[太湖]]平原。全境地势低平，河湖众多，吴淞江、娄江横穿东西。主要湖泊有西北部的[[阳澄湖]]，南部的[[淀山湖]]、[[澄湖]]、[[傀儡湖]]。其中阳澄湖是中国最著名的淡水[[螃蟹]]产地。

=== 气候 ===
昆山地处热带南部季风，属亚热带气候区。年平均气温 17.5.8；年平均降水量1127.5毫米，年平均日照时间1975.5小时。<ref>{{cite web| url=http://www.ks.gov.cn/zrgk?id=1119&status=1#| title=昆山-自然概况-气候| publisher=昆山市人民政府办公室| date=2019-04-04| deadurl=yes| archiveurl=https://web.archive.org/web/20170907234319/http://www.ks.gov.cn/zrgk?id=932&status=1| archivedate=2017-09-07}}</ref>。

== 经济 ==

昆山东面毗邻[[上海]]，有[[京沪铁路]]横贯。经济发达，2018年GDP为3,875亿元，超过国内近一半的[[首府|省会]]城市全市GDP，是中国第一个人均[[国民生产总值]]突破20,000[[美元]]的县级城市，2004年至2018年连续十四年位列[[中国百强县]]的第一位。因为临近上海，境内设立的国家级的经济技术开发区自1990年代以来吸引了大量的台资和外资企业投资建厂，其中较知名的有[[台展集團]]、[[南寶樹脂]]<ref>[http://www.hellotw.com/QA/zlck/tqxh/201008/t20100810_597694.htm 昆山市台灣同胞投資企業協會] {{webarchive|url=https://web.archive.org/web/20110922094558/http://www.hellotw.com/QA/zlck/tqxh/201008/t20100810_597694.htm |date=2011-09-22 }}</ref><ref name="崑">{{Cite web |url=http://www.voanews.com/cantonese/news/IT-Taiwan-Businessmen-on-Investment-Environment-in-Kunshan-115418159.html |title=大陸台商談昆山投資經營環境 |access-date=2012-06-01 |archive-date=2013-04-28 |archive-url=https://archive.today/20130428115042/http://www.voanews.com/cantonese/news/IT-Taiwan-Businessmen-on-Investment-Environment-in-Kunshan-115418159.html |dead-url=no }}</ref>、[[唯君電子]]<ref name="崑" />、[[捷安特]][[自行車]]、[[威京集團]]、[[日月光集團]]、[[富士康科技集團]]、[[正文科技集團]]、[[统一企业]]<ref>[http://big5.huaxia.com/xw/zh/2007/00599761.html 昆山臺商:「兩稅合一」有利於提高外資利用水準] {{webarchive|url=https://web.archive.org/web/20140811101130/http://big5.huaxia.com/xw/zh/2007/00599761.html |date=2014-08-11 }}</ref>、[[南亚电子]]、[[仁宝电脑]]、[[欣兴电子]]、[[纬创资通]]、[[神達電腦]]、[[正崴科技]]、[[禧玛诺]]、科迪制冷设备、[[伦飞电脑]]、[[蓝天电脑]]、今皓集團、[[和碩聯合科技]]等。由于长驻昆山經商和工作的臺湾人眾多，故當地有“[[小台北]]”的外号<ref>{{cite news

==政治==
===政治结构===
昆山市是苏州市代管的一个县级市，江苏省试点[[省直管]]县级市之一。市委书记周伟，市长陈丽艳。中国共产党昆山市委员会、昆山市人民政府、昆山市人民代表大会常务委员会和中国人民政治协商会议昆山市委员会驻昆山市前进中路108号<ref>{{cite web| url=http://www.rd.ks.cn/home/index| title=昆山市人民代表大会常务委员会| publisher=昆山人大| date=2015-10-28| deadurl=yes| archiveurl=https://web.archive.org/web/20190330103733/http://www.rd.ks.cn/home/index| archivedate=2019-03-30}}</ref>。

== 交通 ==
[[File:201907 Facade of Kunshannan Station.jpg|thumb|[[昆山南站]]]]
=== 铁路 ===
[[京沪铁路]]、[[沪宁高速铁路]]、[[京沪高速铁路]]经过昆山市，设有[[昆山站]]、[[昆山南站]]、[[阳澄湖站]]、[[花桥站 (铁路)|花桥站]]等车站。从昆山南站前往上海的高铁只需要20分钟左右。
===城市轨道交通===
2023年6月，据中华人民共和国交通运输部数据，昆山共运营城市轨道交通2条线，运营里程43公里。<ref>{{Cite web |url=https://finance.sina.com.cn/jjxw/2023-07-07/doc-imyzwcep8373906.shtml |title=城市轨道交通客流 |access-date=2023-07-07 |archive-date=2023-07-08 |archive-url=http://www.freezepage.com/1688794000IRHJNXSFAL |dead-url=no}}</ref>
* [[上海轨道交通11号线]]中的[[花桥站 (昆山市地铁车站)|花桥站]]、[[光明路站]]、[[兆丰路站]]位于[[江苏省]][[苏州市]]昆山市[[花桥镇 (昆山市)|花桥镇]]，并由[[昆山市轨道交通投资发展有限公司]]完成建设。上海地铁11号线也是中国大陆第一个跨省轨道交通线路。
* [[苏州轨道交通11号线]]横穿昆山大部，终到[[花桥镇 (昆山市)|花桥镇]]，与[[上海轨道交通11号线]]于[[花桥站 (昆山市地铁车站)|花桥站]]与[[苏州轨道交通3号线]]的[[唯亭站 (地铁)|唯亭站]]换乘。

=== 公路 ===
*国道：{{中国国道名|312}}过境。
*省道：S339、S224
*城市快速路：昆山拥有自己的[[中环快速路 (昆山)|中环快速路]]，并有黄浦江路南段、震川西路等高架项目在建。

=== 公共交通 ===
{{Main|昆山公交线路列表}}
昆山市目前市有多条公交线路，包括跨区域线路、区域线路、高峰线、夜间线和毗邻线路等，遍布昆山市的各个区域，同时可连接[[上海市]]、[[常熟市]]、[[苏州工业园区]]、[[太仓市]]等其他行政区域。

== 文化和旅游 ==
[[File:昆山奥灶馆夜景.jpg|thumb|right|300px|昆山[[奥灶面|奥灶馆]]夜景]]

位于市境南部[[淀山湖]]畔的[[中国历史文化名镇]][[周庄镇 (昆山市)|周庄镇]]是典型的[[江南水乡古镇]]，因画家[[陈逸飞]]描绘此处风情的画作而蜚声中外。小镇上既有小桥流水，又有深宅大院，吸引了大批游客来此。但近年来，由于旅游开发中的商业气息过于浓厚，也引来了不少争议。目前，[[锦溪镇 (昆山市)|锦溪镇]]、[[千灯镇]]近来年旅游开发提速，均以水乡人文特色为重点，借用深厚的文化底蕴，吸引了各地游客。

[[阳澄湖]]东岸的[[巴城镇]]则以阳澄湖度假区为依托，休闲度假产业发展迅猛。
* [[中国历史文化名镇]]：[[周庄镇 (昆山市)|周庄镇]]（第一批）、[[千灯镇]]（第三批）、[[锦溪镇 (昆山市)|锦溪镇]]（第四批）、[[巴城镇]]（第七批）
