'''文昌市'''，是[[中华人民共和国]][[海南省]]东北部沿海下辖的一個[[县級市]]，政府所在地为[[文城镇]]。面积2403平方公里，总人口約56万人。东南北三面临海，海岸线长210公里，沿海多天然良港和沙滩。出產之[[文昌雞]]被稱爲[[海南四大名菜]]之首。文昌雞始於潭牛鎮。
== 历史 ==
[[File:Wangcheng Lou, Wenchang (20230327123003).jpg|thumb|文昌文南老街望城楼]]
[[File:Wenchang 2.JPG|thumb|2007年的文昌街头]]
在[[漢武帝]]元封元年（公元前110年）时建'''紫贝县'''，是[[海南島]]三大歷史古邑之一，亦是海南閩南文化發源地。隋大業三年（公元607年）改稱'''武德縣'''。唐高祖武德五年，改稱'''平昌縣'''。[[唐太宗]]贞观元年（公元627年）才定名為'''文昌縣'''，历经2000多年，直至1995年11月7日撤县建市。

2016年6月25日，[[中国文昌航天发射场]]投入使用。

== 人口 ==
根据第七次全国人口普查数据，截至2020年11月1日零时，文昌常住人口为560894人<ref>{{Cite web|title=中國: 海南省 (地级，行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/hainan/admin/|access-date=2023-10-09|website=www.citypopulation.de}}</ref>。

== 地理 ==
文昌地处热带边缘，属[[热带季风气候]]。沿海地区风较大，夏秋季影响海南岛的[[台风]]有75%是从文昌登陆，故有“台风走廊”之称<ref>[http://www.chinaquhua.cn/hainan/wenchang.html 海南文昌市簡介] {{webarchive|url=https://web.archive.org/web/20111128133002/http://www.chinaquhua.cn/hainan/wenchang.html |date=2011-11-28 }}</ref>。

== 旅遊 ==
文昌市东南北三面临海，海岸线长210千米，沿海多天然良港和沙滩，擁有豐富旅遊資源，如：馮家灣、高隆灣、月亮灣、后港灣、八門灣紅樹林、七星嶺、銅鼓嶺、抱虎嶺、[[东郊镇 (文昌市)|東郊]]椰林、[[椰子大觀園]]、[[七洲列島]]等都是著名風景區<ref>{{Cite web |url=http://www.hiwenchang.com/forum-38-1.html |title=文昌景點 |access-date=2014-11-20 |archive-url=https://web.archive.org/web/20141129045813/http://www.hiwenchang.com/forum-38-1.html |archive-date=2014-11-29 |dead-url=yes }}</ref>。 

文昌市具有深厚歷史文化底蘊，主要人文景點有：[[文南老街]]、[[陳策將軍祖居]]、[[宋氏祖居]]、[[溪北書院]]、[[孔廟]]等。

飲食文化方面，文昌市是海南四大名菜<ref>{{cite web |title=海南四大名菜 |url=http://hncx.anhees.com/HainanFood/hnsdmc |website=hncx.anhees.com |author1=海南香 |archive-url=https://web.archive.org/web/20180621093335/http://hncx.anhees.com/HainanFood/hnsdmc |archive-date=2018-06-21 |accessdate=2018-11-08 |dead-url=yes}}</ref>之一的[[文昌鷄]]的發源和主要出產地。文昌鷄的概念，廣義上包含文昌鷄這種本地雞種、文昌鷄的烹飪文化。文昌鷄的烹飪文化，包含了文昌鷄飯的做法，這種做法，是聞名世界的[[海南雞飯]]的源頭。文昌出产的[[抱罗粉]]为海南四大名粉之一，抱罗粉始于[[抱罗镇]]。除了文昌雞，發源于鋪前鎮的[[海南糟粕醋]]因爲酸辣的口味，也被很多島外游客喜歡。糟粕醋經常被用來做火鍋底料，配以海鮮，其得名源於海南話<ref>{{cite web |author1=海南香 |title=猜思海南糟粕醋的得名由来 |url=https://hncx.anhees.com/hxcx/hainan-zaopocu-mingzi |website=海南香}}</ref>。

[[文昌航天发射场]]地處[[龍樓鎮]]，為中國四大航天發射場之一，是文昌市的新兴航天旅游景点。
