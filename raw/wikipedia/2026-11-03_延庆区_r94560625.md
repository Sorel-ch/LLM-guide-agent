'''延庆区'''是[[北京市]]下辖的一个区，是首都生态涵养发展区，生态屏障和重要水源保护地。区域东西长73公里，南北宽45.5公里<ref name=yqxz>{{cite book |title=《延庆县志》|publisher=北京出版社|year=2006年|language=zh-hans}}</ref>，面积1993平方公里，占北京市总面积的12%。区人民政府驻[[儒林街道]]湖北西路1號<ref name=p2015>{{cite web|url=http://politics.people.com.cn/n/2015/1117/c1001-27825644.html|date=2015-11-17|title=北京撤销密云县、延庆县 设立密云区、延庆区|quote=延庆区人民政府驻儒林街道湖北西路1号|access-date=2021-07-24|archive-date=2021-07-24|archive-url=https://web.archive.org/web/20210724211910/http://politics.people.com.cn/n/2015/1117/c1001-27825644.html|dead-url=no}}</ref>。

2015年11月，中华人民共和国国务院批准北京市调整行政区划，延庆县撤县设区<ref name="ifeng" />。

== 历史 ==
[[汉朝|汉代]]設[[上谷郡]]，郡治在此地西南。[[唐朝]]设[[妫川县]]（以[[妫水河]]命名），属[[妫州]]，有防御军城<ref name=yqxz />{{rp|385页}}。唐末及辽金时，改为[[缙山县]]（以[[缙云山 (北京市)|缙云山]]<ref>{{Cite web |url=http://www.bjyq.gov.cn/sy/yqgk/gcyy/sw/47eb8b35_d39b_4347_ad29_00edc421607e.html |title=北京-延庆概况-缙云霓裳。 |access-date=2014-11-02 |archive-date=2015-11-17 |archive-url=https://web.archive.org/web/20151117063331/http://www.bjyq.gov.cn/sy/yqgk/gcyy/sw/47eb8b35_d39b_4347_ad29_00edc421607e.html }}</ref>命名，又名缙山、缙阳山、佛爷顶），属[[儒州]]。

[[File:Sixteen_Prefectures.png|thumb|right|200px|燕云十六州]]自五代至辽代，妫、儒二州同属[[燕云十六州]]。[[元代]]改为[[龙庆州]]，属[[大都路]]。[[明朝]]改为[[隆庆州]]，后为避[[明穆宗|穆宗]]年号[[隆庆]]，改称[[延庆州]]，一直沿用至[[清朝]]。[[民国初年]]，始称延庆县，先後属[[察哈爾特別區]]、[[察哈尔省 (中华民国)|察哈尔省]]。

[[File:Republic of China edcp location map (disputed territories) Chahar.svg|thumb|國民政府時期，延慶區屬察哈爾省管轄]]
1952年改属[[河北省]][[张家口专区]]，1958年，划归[[北京市]]。<ref>{{Cite web |url=http://www.bjyq.gov.cn/sy/yqgk/lsyg/ |title=北京-延庆概况-历史沿革。 |access-date=2014-11-02 |archive-date=2016-07-01 |archive-url=https://web.archive.org/web/20160701081851/http://www.bjyq.gov.cn/sy/yqgk/lsyg }}</ref>2015年11月，经[[中华人民共和国国务院|国务院]]批准，延庆县撤县设区<ref name=ifeng>{{cite web |url=http://news.ifeng.com/a/20151113/46229193_0.shtml |title=北京密云延庆两县将撤县设区。 |publisher=News.ifeng.com |date= |accessdate=2018-05-28 |archive-date=2022-02-04 |archive-url=https://web.archive.org/web/20220204192454/https://news.ifeng.com/a/20151113/46229193_0.shtml }}</ref>。

== 地理概况 ==
* 延庆区位于北京西北部，距市中心直线距离74公里，是北京的西北门户<ref>{{Cite web |url=https://www.beijing.gov.cn/ywdt/zwzt/dah/bxsq/201704/t20170424_1815961.html |title=存档副本 |access-date=2024-03-13 |archive-date=2024-03-13 |archive-url=https://web.archive.org/web/20240313174746/https://www.beijing.gov.cn/ywdt/zwzt/dah/bxsq/201704/t20170424_1815961.html |dead-url=no }}</ref>。延庆东邻[[怀柔区]]，南邻[[昌平区]]，西与[[河北省]][[怀来县]]接壤，北与[[河北省]][[赤城县]]相邻。
* 延庆区北、东、南三面环山，西面临[[官厅水库]]，平均海拔500米以上，以山区为主，山区占全县面积70%<ref name=yqxz />{{rp|104}}。全区林木绿化率达到74%<ref name=sohuintro>http://m.sohu.com/n/416820997/?_trans_=000115_3w {{Wayback|url=http://m.sohu.com/n/416820997/?_trans_=000115_3w |date=20170111090915 }} 延庆简介：常住人口31.7万 首都生态涵养发展区。</ref>。
* 延庆区气候独特，冬冷夏凉，素有北京“夏都”之称，此外，延庆的[[地熱能]]、[[太阳能]]、[[風能]]等新能源和可再生能源丰富，占能源消耗比重达25%，是首批国家绿色能源示范县、北京市新能源和可再生能源示范区。<ref name=sohuintro/>
* 延庆区境内[[海坨山]]主峰海拔2241米，是北京市第二高峰。<ref>[http://www.bjyq.gov.cn/sy/yqgk/yqgk/ 北京-延庆概况。] {{webarchive|url=https://web.archive.org/web/20141102190705/http://www.bjyq.gov.cn/sy/yqgk/yqgk/ |date=2014-11-02 }}</ref>延庆县境內有著名景点[[八達嶺]]長城遺跡。

== 气候概况 ==

* 延庆区属于暖温带大陆性季风气候，夏季较热冬季寒冷，年平均气温9.6℃，最热月(7月)平均气温为24.1℃，最冷月(1月)平均气温为-7.4℃，年降水量为449.2毫米。
* 最高温度记录为39℃，出现在1961年6月10日<ref name="yqxz" />{{rp|65页}}。
* 截至2016年，最低温度记录为-27.3℃，出现在1973年1月23日<ref name=yqxz />{{rp|65页}}。2016年1月23日，最低温度记录-29.8℃，为30年来北京最低温度记录。<ref name=weather2016>[http://3g.china.com/act/10000159_21274324.html 北京迎30年来最冷一天：延庆最低气温逼近-30度] {{Wayback|url=http://3g.china.com/act/10000159_21274324.html |date=20160130031956 }}</ref>
* 6月至8月降水量最多的年份是1964年，为747.1毫米，最少的年份是1965年，为274毫米<ref name=yqxz />{{rp|66页}}。
* 延庆区日照非常充足，年日照时数可达2623.4小时，日照百分率60%，日照时数和太阳辐射均为北京市最高<ref name=yqxz />{{rp|67页}}。

== 延庆方言 ==
延庆旧时为[[张家口]]所辖，由于全县大部分地处长城之外，口音与[[張呼片|张家口话]]（属[[晋语]]）接近，与[[北京官话]]有显著不同。

全县语言大体分为六个区域，但是这六个方言区域的界限是模糊的，不确定的。<ref>{{Cite web |url=http://epaper.bjnews.com.cn/html/2013-01/20/content_404907.htm?div=5 |title=延庆话 本土化之后仍保有晋中南底色 |access-date=2016-02-08 |archive-date=2022-02-04 |archive-url=https://web.archive.org/web/20220204192518/http://epaper.bjnews.com.cn/html/2013-01/20/content_404907.htm?div=5 }}</ref>

* [[妫水河]]流域的延庆-[[永宁镇 (延庆县)|永宁]]地区。
* [[康庄镇 (延庆县)|康庄]]-西拨子-[[八达岭镇|八达岭]]一线，原为[[延庆卫]]军屯，这一地带自古就是内地通往大西北的交通要道，语言受到外来影响较大。
* [[张山营镇|张山营]]地区。该地区与[[河北省]][[怀来县|怀来]]、[[赤城县|赤城]]接壤，有的村屯原来就属于怀来县管辖，语言也受[[雁北地区]]影响较大。
* [[四海镇|四海]]-[[珍珠泉乡|珍珠泉]]地区，类似怀柔话。
* [[白河 (潮白河)|白河]]流域的[[千家店镇|千家店]]-沙梁子地区，比延庆其他地区更接近[[普通话]]。
* [[大庄科乡|大庄科]]地区，语言更接近昌平话。

延庆世界地质公园分为“一园四区”，由西部[[龙庆峡]]园区及[[古崖居]]园区，东部的[[千家店百里山水画廊景区|千家店]]园区、南部的[[八达岭]]园区组成。<ref>{{cite web |url=http://www.yqdzgy.cn/ |title=延庆地质公园官方网站。 |publisher=Yqdzgy.cn |date= |accessdate=2018-05-28 |archive-date=2020-03-26 |archive-url=https://web.archive.org/web/20200326174646/http://www.yqdzgy.cn/ |dead-url=no }}</ref>

延庆世界地质公园涵盖了延庆县主要的旅游资源。

延庆区年吸引游客超过1800万人次，是全国首批国家旅游标准化示范县和全国首个国家级旅游综合改革示范县。<ref name=sohuintro/>

=== 国家5A级旅游景区 ===
* [[八达岭长城]]，是[[明长城]]中保存最好的一段，也是最具代表性的一段。八达岭海拔1015米，八达岭长城最高敌楼海拔888米。2007年，八达岭长城入选首批[[国家5A级旅游景区]]。

=== 特色旅游 ===
* 自行车骑游，一项健康、环保、时尚、低碳的绿色运动。
* 冬季滑雪，延庆有较好的冰雪资源，是距离北京较近的滑雪胜地。
* [[龙庆峡水库|龙庆峡]]赏冰灯，自1987年以来的每年冬季，自[[龙庆峡水库]]取冰，进行雕塑，举办[[冰灯]]艺术展，迄今已举办29届。
* 鮮吃康莊樂園：北京少有的生態農莊。

== 水域情况 ==
* 延庆境内Ⅳ级以上河流18条，其中III级河流2条（[[白河 (潮白河)|白河]]、[[妫水河]]），Ⅳ级河流16条。
* [[官厅水库]]（属大型水库）的一部分位于延庆境内。另有[[白河堡水库]]（属中型水库）、[[佛峪口水库]]、[[龙庆峡水库]]位于延庆境内。

== 环境情况 ==
* 延庆区[[PM2.5]]年均浓度值为68.0[[微克]]/[[立方米]]，空气质量优于北京市其他区，排名第一。<ref>2013年北京市环境状况公报。</ref><ref>{{cite web |author=104 |url=http://beijing.qianlong.com/2015/1110/80489.shtml |title=2015年前10月延庆空气质量全市最好。 |publisher=Beijing.qianlong.com |date=2015-11-10 |accessdate=2018-05-28 |archive-date=2022-02-04 |archive-url=https://web.archive.org/web/20220204212449/http://beijing.qianlong.com/2015/1110/80489.shtml }}</ref>

* [[File:China Railways.svg|18x20px]] <!-- 注释出：[[File:Daqinrailway.gif|67x20px]] --> [[大秦铁路]]，一条煤炭货运专线铁路，延庆境内设有[[延庆北站]]和[[铁炉村站]]。
