'''臺東市'''（[[俗字]]寫作'''-{台}-東市'''），前身「臺東鎮」，位於[[臺灣]][[臺東縣]]東南部，為臺東縣[[縣治]]所在地{{sfn|施添福|1999|p=227}}。全境面積約為110平方公里，是臺灣面積最大且唯一大於100平方公里的縣轄市{{NoteTag|面積最大的縣轄市原為[[臺中縣]]太平市，後已於2010年底改制為[[太平區 (台灣)|市轄區]]迄今。}}。人口約有10.3萬人<ref name="臺東戶政"/>，人口密度每平方公里約有935人，為臺東縣人口最多、人口密度最高的行政區，亦為[[宜花東|宜花東地區]]的最大城市<ref name="ris.gov.tw"/>，聚集臺東縣內接近一半的人口<ref>{{Cite web |url=https://ttca.taitung.gov.tw/News.aspx?n=14828&sms=13415 |title=人口統計 |publisher=臺東縣政府民政處 |access-date=2022-10-26 |language=zh-tw |archive-date=2022-10-26 |archive-url=https://web.archive.org/web/20221026151019/https://ttca.taitung.gov.tw/News.aspx?n=14828&sms=13415 |dead-url=no }}</ref>。

1945年將臺東街改制臺東縣臺東區臺東鎮，並為縣治。1950年廢區，改直屬臺東縣。1974年將[[卑南鄉]]的其中10個村併入，後於1976年改制為縣轄市{{sfn|施添福|1999|p=227}}。由於[[台灣日治時期|日治時期]][[臺灣總督府]]為推廣製糖業，招墾西部移民移入種植蔗糖，[[臺灣戰後時期|二戰後]]初期則因鳳梨加工場的設置，推廣鳳梨栽植，加上中央政府設立數座安置退役軍人的農場，使其整體族群結構具有特殊性與呈現多元化{{sfn|施添福|1999|p=228}}。隨著交通建設的發展{{NoteTag|如[[南迴公路]]及[[南迴線|南迴鐵路]]。}}與產業活動的引進，且擁有豐富自然及人文資源，也促使臺東市主要的經濟型態逐漸由農業轉為商業與觀光業{{sfn|施添福|1999|pp=228－229}}。

== 歷史 ==
[[File:Map of Taitō-gai.jpg|thumb|臺東街（1919－1944年）區劃圖]]
[[File:Taito 1 10000 1945.jpg|thumb|1945年美軍繪製的臺東市街地圖]]
臺東市該地最早稱為「寶桑」，是「卑南覓」（臺東平野舊稱）番社地名「posong（或pooson）」的音譯。清朝政府以其為蕃地禁止漢人前䇠。在[[咸豐]]年間在卑南大溪流畔海岸一帶活動的漢人變多，形成寶桑庄。清廷於1875年因[[沈葆楨]]開山撫番，設置[[臺灣府南路撫民理番同知]]<ref>{{Cite web |title=《史卷六》-6 |url=https://ctext.org/wiki.pl?if=gb&chapter=628408 |website=電子化計劃中國哲學書電子化計劃 |access-date=2025-08-10 |archive-date=2023-04-23 |archive-url=https://web.archive.org/web/20230423121411/https://ctext.org/wiki.pl?if=gb&chapter=628408 |dead-url=no }}</ref>，後設置[[卑南廳]]廳治於此，改稱卑南街。1887年劉銘傳設「[[臺東直隸州]]」{{cn|，州治原規劃設於[[瑞穗鄉|水尾]]，但因[[大庄事件]]破壞甚大，後州治改維持在埤南|time=2024-03-06}}。<ref>{{Cite book |author=陳建年 |title=《臺東縣史》 |volume=地理篇 |chapter=第二章·地名 |pages=82 |publisher=臺東縣政府 |year=1999 |location=臺東縣 |language=zh-tw }}</ref>

1896年6月日本開始統治臺灣東部後，在東部設置臺南縣臺東支廳，1897年升格[[臺東廳]]，廳治仍設在埤南，{{cn|但廢除埤南堡，|time=2026-08-21}}改稱為卑南街，並維持清代隸屬於[[南鄉 (堡里)|南鄉]]地方行政區。卑南街實際上因新街道規劃，其可分為「卑南」（即卑南社及附近）、「新街」（今臺東市區部分，或稱卑南新街，因包含寶桑庄，故有時寫為寶桑新街）、「馬蘭拗」（即馬蘭社及附近）等3個聚落。

1919年1月15日市街改正後，改卑南街稱「'''[[臺東街]]'''」（府令第5號），屬[[臺東廳]]南鄉。

1920年廢南鄉改設臺東支廳，臺東街擴大，管轄臺東、馬蘭、旭村、利基利吉、猴子山、富原村、加路蘭7個大字，另外卑南、呂家、檳榔樹格社、北絲鬮社、知本社及美和等6個大字劃分設置「卑南區」。1937年卑南區改為[[卑南庄]]，1944年12月1日-{[[卑南庄]]}-廢-{庄}-併入臺東街（府令326號），此為總督府在臺灣最後一個行政區調整。

[[臺灣戰後時期|二戰後]]1945年，臺東街改為「臺東鎮」，屬[[臺東縣]]，並為縣治，下轄15個里。原卑南-{庄}-之轄區再度分離，並將臺東街北側利吉、富源、富山等地析出，設置[[卑南鄉]]。1974年10月10日將卑南鄉富岡、岩灣、南王、新園、建興、南榮、卑南、知本、豐田、建和村共2萬人併入台東鎮，其名稱不變，以湊合縣轄市10萬人口門檻。1976年元旦因人口達到改制為[[縣轄市]]之標準，改制為「'''臺東市'''」<ref>[https://www.youtube.com/watch?v=o51dUAncfVk 台東鎮改制為縣轄市 [[台視] {{Wayback|url=https://www.youtube.com/watch?v=o51dUAncfVk |date=20201111011306 }}影音文化資產]]</ref><ref>{{Cite web |url=https://tth.taitung.gov.tw/files/11-1000-575.php |title=轄區概況 台東縣台東戶政事務所生活服務網 |access-date=2020-10-06 |archive-date=2019-10-17 |archive-url=https://web.archive.org/web/20191017042650/http://tth.taitung.gov.tw/files/11-1000-575.php }}</ref><ref>[http://www.taitungcity.gov.tw/livinginthecity(0).htm 《發現古地圖：城市的起源》，臺東市公所全球資訊網] {{webarchive|url=https://web.archive.org/web/20091124050757/http://www.taitungcity.gov.tw/livinginthecity(0).htm |date=2009-11-24 }}</ref>。

== 地理 ==
=== 地形 ===
臺東市位於臺東縣東南部，北隔黑髮溪與[[東河鄉 (台灣)|東河鄉]]為界，西鄰[[卑南鄉]]，西南臨[[知本溪]]與[[太麻里鄉]]相望，東、南兩面臨[[太平洋]]{{sfn|施添福|1999|p=227}}。全市位居臺東三角洲平原，係由[[卑南溪]]、[[太平溪]]、[[利嘉溪]]、知本溪沖積而成，為花東縱谷南部的一片形勢較為完整、面積較為寬廣的平坦地{{sfn|施添福|1999|p=228}}。市境內海拔最高點為[[鯉魚山 (臺東縣)|鯉魚山]]（標高75公尺），可俯瞰臺東市的全景<ref name="細說台東">{{cite web |url=https://www.taitungcity.gov.tw/page.php?n=12 |title=認識台東-細說台東 |author=臺東市公所 |access-date=2024-03-06 |publisher=臺東市公所全球資訊網站 |language=zh-tw |archive-date=2021-08-08 |archive-url=https://web.archive.org/web/20210808145600/http://www.taitungcity.gov.tw/page.php?n=12 |dead-url=no }}</ref>。

=== 氣候 ===
臺東市的氣候為溫和、無嚴霜且酷暑，年溫差較小。年均溫約為攝氏23.6度，最熱月份為7月的35度，最冷為2月的14度。全年降雨量約有2,000毫米，主要集中在5月至10月，全年雨量充沛<ref name="細說台東"/>{{sfn|施添福|1999|p=228}}。

根據臺東縣政府民政處統計，2025年底臺東市戶數計有43,536戶，人口計有102,681人<ref name="臺東戶政">{{Cite web |url=https://tth.taitung.gov.tw/demographics/detail/XWHQYBHLGH |title=本所各鄉鎮市歷年人口數及原住民數統計 |publisher=臺東縣臺東戶政事務所 |accessdate=2026-03-25 }}</ref>，其中有23,417人為原住民人口，是臺灣原住民人口最多的鄉鎮市區<ref>{{Cite web |url=https://www.cip.gov.tw/zh-tw/news/data-list/940F9579765AC6A0/index.html?cumid=940F9579765AC6A0 |title=為民服務-主動公開資訊-統計資料-原住民人口數統計資料(每月一次) |author=原住民族委員會 |publisher=原住民族委員會全球資訊網 |access-date=2022-10-28 |language=zh-tw |archive-date=2022-10-28 |archive-url=https://web.archive.org/web/20221028033758/https://www.cip.gov.tw/zh-tw/news/data-list/940F9579765AC6A0/index.html?cumid=940F9579765AC6A0 |dead-url=no }}</ref>，性別結構上，男性人數與女性人數分別是50,575人與52,106人，性別比約為97.06，為臺東縣性別比最低且唯一低於100的行政區。市內人口最多與最少的里分別是自強里與豐原里，2025年底兩里人口分別為4,275人與1,358人<ref name="臺東戶政"/>，其中自強里也是臺東縣人口最多的村里，並與新生里、豐谷里、豐盛里、中心-{里}-並列臺東縣人口前五大村里<ref>{{Cite web |url=https://data.gov.tw/dataset/77132 |title=資料集-村里戶數、單一年齡人口（新增區域代碼） |publisher=中華民國行政院 數位發展部 政府資料開放平臺 |access-date=2022-10-26 |language=zh-tw |archive-date=2022-04-04 |archive-url=https://web.archive.org/web/20220404002804/https://data.gov.tw/dataset/77132 |dead-url=no }}</ref>。臺東市有12.61%為0至14歲人口，67.76%為15至64歲人口，19.63%則為65歲以上人口，老化指數約為155.75，為臺東縣人口老化程度相對輕微的地區<ref name="臺東戶政"/>。

=== 市政組織 ===
[[臺東縣臺東市公所|臺東市公所]]是臺東市最高層級的地方[[行政機關]]，在中華民國政府架構中為縣轄市自治的行政機關，同時負責執行縣政府及中央機關委辦事項，臺東市的自治監督機關為[[臺東縣政府]]。市長由全體市民直接選舉產生，任期為四年，可連選連任一次。臺東市公所並置市政會議，為市政最高決策機構，在市長之下，設有6課4室等10個內部單位以及6個附屬機關<ref>{{Cite web |url=http://www.taitungcity.gov.tw/page.php?n=26 |title=機關介紹 - 組織職掌 |author=臺東市公所 |publisher=臺東市公所全球資訊網站 |access-date=2021-09-06 |language=zh-tw |archive-date=2018-03-24 |archive-url=https://web.archive.org/web/20180324144959/http://www.taitungcity.gov.tw/page.php?n=26 }}</ref>。

[[臺東縣臺東市民代表會|臺東市民代表會]]是臺東市的最高[[民意機關]]，代表臺東市全體市民立法和監察市政。市民代表由公民直選選出，任期為四年，可連選連任。臺東市民代表會共有19位市民代表，分別為第一選區2席市民代表、第二選區6席市民代表、第三選區5席市民代表、第四選區2席市民代表、第五選區4席市民代表，主席、副主席由19位市民代表互選產生<ref>{{Cite web |url=http://www.trc.gov.tw/WebMaster/?section=14 |title=認識代表會 - 本屆市民代表 |publisher=臺東市民代表會 |access-date=2021-09-06 |language=zh-tw |archive-date=2022-07-02 |archive-url=https://web.archive.org/web/20220702111802/https://www.trc.gov.tw/WebMaster/?section=14 }}</ref>。

== 產業 ==
{{unreferenced section|time=2025-11-06}}
臺東市[[中心商業區]]位於縣政府前的中正路與中山路、[[台東舊站]]前的新生路及原[[台11線]]主線中華路一帶，因[[台東舊站]]廢除造成市區商圈沒落多年。當地政府後將之改建成旅遊服務中心及鐵道公園，2015年又將旅遊服務中心改建成客運轉運站及[[秀泰影城]]進駐原[[國光客運]]台東站，使第三級產業發展不致因此完全沒落。因公共運輸的整合成功，重新吸引了許多商業活動進駐市中心，然而台鐵[[臺東車站|新站]]附近商業活動仍不興盛，以民宿及機車租賃等第三級產業為主。重要農產品有[[稻米]]、[[釋迦]]、[[洛神花]]、[[油菜花]]、[[梅子]]、[[柚子]]、[[草莓]]、[[台湾藜]]等。

台東市[[富岡漁港]]位於潮汐交會帶，漁獲量豐富，主要的漁產有[[海瓜子]]、[[沙蝦]]、[[曼波魚]]、[[地震魚]]、小章魚、雨傘魚、[[白帶魚]]、蘭花蚌、[[鲯鳅]]等。
