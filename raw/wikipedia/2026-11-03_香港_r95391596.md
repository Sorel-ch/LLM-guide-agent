'''香港'''（{{langx|en|Hong Kong}}；[[縮寫]]：{{lang|en|HK}}／{{lang|en|HKG}}），全稱'''香港特別行政區'''<ref>{{cite web |title=基本法 - 基本法 - 第一章 (SC)|url=https://www.basiclaw.gov.hk/tc/basiclaw/chapter1.html |access-date=2026-09-27 |website=www.basiclaw.gov.hk |dead-url=no }}</ref>（{{langx|en|Hong Kong Special Administrative Region}}<ref>{{cite web |title=Basic Law - Basic Law - Chapter I (EN) |url=https://www.basiclaw.gov.hk/en/basiclaw/chapter1.html |access-date=2026-09-27 |website=www.basiclaw.gov.hk |dead-url=no }}</ref>，縮寫：{{lang|en|Hong Kong SAR}}／{{lang|en|HKSAR}}<ref>{{cite web |title=Hong Kong – the Facts |url=https://www.gov.hk/en/about/abouthk/facts.htm |quote=The Basic Law is the constitutional document of the Hong Kong Special Administrative Region (HKSAR).  |access-date=2026-09-27 |website=www.info.gov.hk |dead-url=no }}</ref>），簡稱'''港'''，[[中華人民共和國]]的[[特别行政区]]<ref>{{cite book |authors=中國地圖出版社編制 |title=《分省中國地圖集》 |publisher=中國地圖出版社 |year=2000 |page=131 |quote=根據1984年中英聯合聲明，中國政府於1997年7月1日恢復對香港行使主權，並設特別行政區。}}</ref>。香港是享有[[高度自治]]權的地方行政區域，保持[[資本主義]][[社會制度]]、[[經濟制度]]和[[生活方式]]<ref name="分" />{{rp|131}}。地域包括[[香港島]]、[[九龍]]和「[[新界]]」，位處[[廣東省]][[珠江口]]東側<ref name="海">{{cite book |editors=辭海編輯委員會 |title=《[[辭海]]》（1989年版） |publisher=[[上海辭書出版社]] |year=1989 |isbn=978-7-5326-0083-0 }}</ref>{{rp|5311}}。

香港位於[[中國大陸]]南端，地處[[西太平洋]]沿岸各國中心，又當[[太平洋]]和[[印度洋]]航運要冲<ref name="本" />{{rp|37}}。香港是全球少有的「自由港城」，開放區為整個香港地區，而世界其他[[自由港]]多為「自由港區」，即只將港口附近地區作為自由港<ref name="本" />{{rp|39}}。香港的[[國際金融中心]]、航運中心、貿易中心地位穩固，經濟自由度蟬聯全球第一<ref>{{cite web |title=以首個五年規劃引領香港高質量發展 |url=https://bau.com.hk/web/article/1556307124448067584/web/content_1556307124448067584.html |website=bau.com.hk |date=2026-10-04 }}</ref>。被稱爲「[[亞洲四小龍]]」之一<ref>{{Cite web |title=過去複製日本成功，終將複製日本失敗？亞洲四小龍的下一步 |website=天下雜誌 |date=2019-12-11 |url=https://www.cw.com.tw/article/5098094 }}</ref>。

香港[[自由經濟]]的長期運作，有賴政府維持良好的營商環境、自由開放的貿易、[[香港稅收|低稅率及簡單稅制]]和[[香港法律制度|法治]]及司法獨立等<ref>{{Cite web |title=一國兩制是香港自由經濟的根本保障 |website=www.hkcd.com.hk |date=2017-02-17 |url=https://www.hkcd.com.hk/content/2017-02/17/content_1037060.html }}</ref>。香港是「東方之珠」、國際[[大都會]]<ref>{{cite web |title=網絡巨頭讚港是真正國際大都會 |url=https://www.stheadline.com/daily-hongkong/3447223/%E7%B6%B2%E7%B5%A1%E5%B7%A8%E9%A0%AD%E8%AE%9A%E6%B8%AF%E6%98%AF%E7%9C%9F%E6%AD%A3%E5%9C%8B%E9%9A%9B%E5%A4%A7%E9%83%BD%E6%9C%83 |accessdate=2026-09-05 |date=2025-04-15 |publisher=星島頭條 |archiveurl=https://web.archive.org/web/20260905044351/https://www.stheadline.com/daily-hongkong/3447223/%E7%B6%B2%E7%B5%A1%E5%B7%A8%E9%A0%AD%E8%AE%9A%E6%B8%AF%E6%98%AF%E7%9C%9F%E6%AD%A3%E5%9C%8B%E9%9A%9B%E5%A4%A7%E9%83%BD%E6%9C%83 |archivedate=2026-09-05 |deadurl=yes }}</ref>，「[[香港品牌]]」是特區政府重點宣傳計劃，推廣香港為「亞洲國際都會」<ref>{{cite web |title=甚麼是香港品牌 |url=https://www.brandhk.gov.hk/zh-hk/%E7%94%9A%E9%BA%BC%E6%98%AF%E9%A6%99%E6%B8%AF%E5%93%81%E7%89%8C |accessdate=2021-12-02 |website=www.brandhk.gov.hk }}</ref>。2022年12月28日，特區政府頒布高端人才通行证计划，申請來港就業人數較往年明顯增加，其中以[[中國內地]]居民為主<ref>{{cite web |title=各入境事務處二○二四年工作回顧（附圖） |url=https://www.immd.gov.hk/hkt/press/press-releases/20250127.html |website=www.immd.gov.hk |date=2025-01-27 }}</ref>。

== 名源 ==
{{main|香港地名來源}}
「[[香港島]]」有各種詮釋：[[香料]]港口、芬芳海港、[[香姑]]港<ref name="章" />{{rp|20}}。因地產[[沉香木]]，又稱香江、香海<ref name="海" />{{rp|5311}}。明萬歷年間因轉運東莞所產香木始稱香港<ref name="分" />{{rp|131}}。「九龍」最早見於1552年（明[[嘉靖]]三十一年）[[應檟]]著《蒼梧總督軍門志》；「香港」則最早見於1573至1619年（明[[萬曆]]年間）[[郭棐]]著《粵大記》<ref name="劉" />{{rp|4}}。

== 香港特別行政區建立前歷史 ==
{{main|香港歷史}}

=== 先秦時期 ===
{{main|香港史前時期}}
人類居住香港約有7,000年歷史<ref name="劉" />{{rp|4}}。公元前1500年左右[[夏朝]]、[[商朝]]時期，古越族人開始從廣東移居香港<ref name="速1">{{cite book |title=《速讀香港史（遠古-1949）》 |author=周子峰 |publisher=[[中華書局（香港）]] |location=香港 |year=2021 }}</ref>{{rp|17}}。[[春秋戰國]]時期，[[百越族]]就已在香港活動，完全不同於中原部族之南方部族，種類多，善於[[捕獵]]、駕船，以鳥形風神作圖騰，不斷南遷，經常由香港出發揚帆遠航<ref name="本">{{cite book |title=《香港問題讀本》 |authors=國務院港澳事務辦公室香港社會文化司編著 |publisher=中共中央黨校出版社 |location=北京 |year=1997 }}</ref>{{rp|1}}。

=== 上古時期 ===
{{main|香港上古史}}
前214年（[[秦始皇]]卅三年），[[秦朝]]征服[[百越]]，在[[嶺南地區]]設置[[南海郡 (中国)|南海郡]]、[[桂林郡]]、[[象郡]]，遷移50萬人開發嶺南<ref name="本" />{{rp|2}}。香港自此納入[[中國]]版圖<ref name="海" />{{rp|5311}}。當時香港地區屬於南海郡[[番禺縣]]，從此香港一直在行政管轄之內<ref name="本" />{{rp|2}}。265年（[[甘露 (孫吳)|甘露]]元年），香港改隸南海郡[[博羅縣]]<ref name="速1" />{{rp|20}}。420年至478年（[[元熙 (東晉)|元熙]]二年至[[昇明]]二年），[[印度]]高僧[[杯渡禪師]]曾居屯門，後人稱杯渡山（今[[青山 (香港)|青山]]）<ref name="速1" />{{rp|21}}。

756年（[[至德 (唐朝)|至德]]元年）前，香港隸番禺縣及[[寶安縣]]<ref name="劉" />{{rp|7}}，其後改屬[[東莞縣]]至1572年（[[隆慶]]六年）止<ref name="劉" />{{rp|7}}。

963年（[[大寶 (南漢)|大寶]]六年），[[南漢]]後主[[劉鋹]]在合浦的海門鎮和東莞的[[大步海]]（今新界大埔海，即[[吐露港]]），招採珠士兵數千人，設媚川都專事泅水採珠<ref name="劉" />{{rp|10-11}}。1197年（[[慶元 (年號)|慶元]]三年），[[宋朝]]官方禁煮[[鹽業專賣|私鹽]]，[[大嶼山]]鹽民起義<ref name="劉">{{cite book |title=《簡明香港史（第三版）》 |last=劉蜀永 |year=2016 |publisher=[[三聯書店（香港）]] |isbn=978-962-04-4016-8 |url=http://books.google.com.hk/books?id=5SWvAAAAQBAJ&pg |archive-url=https://web.archive.org/web/20140808042435/http://books.google.com.hk/books?id=5SWvAAAAQBAJ&pg |archive-date=2014-08-08 |dead-url=no }}</ref>{{rp|468}}。

[[宋神宗]][[熙寧]]至[[元豐 (北宋)|元豐]]年間，[[進士]]鄧符協（[[江西]]吉水人）遷往岑田（[[錦田]]），成為鄧、侯、廖、文、彭[[新界五大氏族]]之首<ref name="本" />{{rp|2}}。1277年（[[景炎]]二年）4月，[[宋端宗]]一行逃到官富場（今[[九龍城]]以南），一度建立[[行宮]]<ref name="劉" />{{rp|468}}。宋元時期，不少宗族從中原遷居到新界本土及離島<ref name="本" />{{rp|5}}。

=== 中古時期 ===
{{main|香港明朝歷史|香港清朝歷史}}
1370年（[[洪武]]三年），明朝設[[官富巡檢司]]，大致相當於今香港地區<ref name="劉" />{{rp|468}}。1521年（[[正德]]十六年），[[葡萄牙人]]強行駛入香港，企圖前往廣州貿易，曾在屯門附近與明朝水師[[屯門海戰|激烈交鋒]]<ref name="本" />{{rp|3}}。廣東巡海道副使[[汪鋐]]督師，次年凱旋<ref name="劉" />{{rp|468}}。

據《[[新安縣志 (廣東省)|新安縣志]]》記載，1668年（[[康熙]]七年），在新安縣沿邊設置21座[[墩台]]，包括九龍墩台<ref name="本" />{{rp|5}}。清[[乾隆]]年間，香港多個鹽場改為稻田，鹽業、採珠、種莞香式微，漁農業復興<ref name="速1" />{{rp|30}}。[[嘉慶]]年間編《新安縣志》稱，[[赤柱]]有兵把守<ref name="本" />{{rp|4}}。作為中國南大門及交通要道，香港防務地位重要<ref name="速1" />{{rp|33}}。

1810年（嘉慶十五年），[[張保仔]]帶著中國帆船270艘和大炮1,200尊接受清朝招安<ref name="章" />{{rp|14}}。1817年（嘉慶二十二年），清在大嶼山東涌口建汛房和圍牆<ref name="劉" />{{rp|468}}。當時香港屬[[南頭古城|南頭]]管轄<ref name="章" />{{rp|14}}，舊屬廣東省[[新安|新安縣]]<ref name="海" />{{rp|5311}}。至1818年（嘉慶二十三年），新安縣人口達239,112人，新增村落366個，其中[[客家人]]村落345個<ref name="速1" />{{rp|30}}。

{{Main|香港開埠初期歷史|香港20世紀初歷史}}
{{seealso|第一次鴉片戰爭|香港割讓|穿鼻草約|南京條約|北京條約|展拓香港界址專條}}
1816年，[[阿美士德使團]]訪華，曾停留香港，返回英國後使團中一史家稱：「從船舶進出的便利和陸地環繞的地形看，這個港口是世界上無與倫比的良港。」<ref name="劉" />{{rp|20}}

1841年1月26日，[[英國皇家海軍|英國海軍]]在[[水坑口]]登陸升旗，香港正式成為[[英國屬土]]<ref name="元">{{cite book |url=http://www.yearbook.gov.hk/1997/cindex.htm |title=香港——邁進新紀元（1997年年報） |location=香港 |publisher=[[政府新聞處]] |year=1998 |access-date=2006-12-16 |archive-date=2017-05-25 |archive-url=https://web.archive.org/web/20170525020024/http://www.yearbook.gov.hk/1997/cindex.htm |dead-url=no }} {{Wayback|url=http://www.yearbook.gov.hk/1997/cindex.htm |date=20170525020024 }}</ref>{{rp|319}}。4月，英國外交大臣[[巴麥尊]]稱[[香港島]]為「幾乎沒有人煙的荒島」<ref name="劉" />{{rp|4}}。當時香港人口7,450人（包括2,000名船民）<ref name="劉" />{{rp|9}}。6月7日，[[義律]]宣佈香港為[[自由港]]<ref name="劉" />{{rp|469}}。1842年，鴉片戰爭後，英國佔領香港島<ref name="海" />{{rp|5311}}。

1843年1月，[[英國外交大臣]][[第四代阿伯丁伯爵喬治·漢密爾頓-戈登|阿伯丁]]説：「香港應成為一個自由港，因此港口税應盡量輕微，可以指望的主要財政收入來源，就是[[地皮|土地]]。」<ref name="速1" />{{rp|53}}4月5日，[[維多利亞女王]]頒佈《[[英王制誥]]》，宣佈設置「香港殖民地」<ref name="劉" />{{rp|469}}。4月6日，維多利亞女王向[[砵甸乍]]頒發《[[皇室訓令 (香港)|王室訓令]]》<ref name="劉" />{{rp|469}}。6月26日，香港正式歸屬英國<ref name="章" />{{rp|22}}。

1846年[[香港會]]開幕，[[跑馬地]]開始有[[賽馬]]<ref name="章" />{{rp|97}}。數年內有10數家商行進駐香港，有洋店主、[[醫生]]、酒館老闆和小商人；英國、印度、美國、德國、意大利、荷蘭和法國人開設商行，以[[怡和洋行]]、[[顛地洋行]]和[[旗昌洋行]]為3大洋行<ref name="章" />{{rp|99-100}}。有些官員關心開展貿易和發揚[[基督教]]，有些洋商關心發財致富，政府則着力收足税以應付香港行政開支；洋商則盡力抗拒加税，擺脱英國，擔任[[列強]]榮譽領事或在航船掛上[[丹麥國旗]]或[[美國國旗]]<ref name="章" />{{rp|103-104}}。[[華人]]平凡普通，是穩紮穩打的基層，認為平安無事就是個好年頭<ref name="章" />{{rp|45}}。急功近利、追逐享受、愛好耀眼燦爛奪目，香港的[[能量]]極端混亂、蜚短流長老早存在；有不踏實的無根感和空洞，[[環境]]令人感到興奮刺激，有發財機會，混亂吵嚷，隱含粗俗不羈和[[冒險]]<ref name="章" />{{rp|110}}。[[大班]]和其他商業鉅子往往很有趣、有勇氣，一般冒險進取，不是慣常慈悲為懷<ref name="章" />{{rp|118}}。華人圈向來是動態，沒有任何事永遠保持原貌；常態是人不停遷移，換[[职业|工作]]、[[姓名]]、[[生活方式]]；各[[階層]]和[[民系]]住進[[公共屋村]]，然後搬入[[公寓]]、[[大廈]]、[[別墅]]，世上大概沒有一個[[社群]]處於這種永不休止的騷動狀態<ref name="章" />{{rp|143}}。雖然洋商社群有賴於華人買辦、職員和仲介，但是以種族而論，他們似乎不信任華人；基於恐懼和厭憎，加上種族偏見，錯綜複雜<ref name="章" />{{rp|177}}。

1860年，訂立《[[北京條約]]》，正式割讓[[九龍半島]]予英國<ref name="元" />{{rp|320}}。1860年英占九龍半島[[界限街]]以南地方<ref name="海" />{{rp|5311}}。早期港英統治基本結合[[殖民主義]]和[[種族主義]]<ref name="劉" />{{rp|103}}。

1895年[[甲午戰爭]]結束後，德國、法國、俄國藉口要求租地；其後局勢緊張，英方認為如要防衞香港，必須取得鄰近土地的控制權<ref name="元" />{{rp|320}}。根據1898年6月9日在北京簽訂的《[[展拓香港界址專條]]》，中方同意把九龍界限街以北直至[[深圳河]]的[[新界]]地域，以及[[香港島嶼|235個島嶼]]租借予英國，為期99年<ref name="元" />{{rp|320}}。1898年，英方強行租借界限街以北、深圳河以南的九龍半島北部大片土地及附近島嶼<ref name="海" />{{rp|5311}}。新界所有土地均是[[官地]]，[[新界原居民|原居民]]為官地承批人，不得擅自改變土地用途，政府可以收回原居民的土地作公共用途<ref name="速1" />{{rp|124}}。

在港英人數度促成立[[自治]]政府，英方一直不允，稱香港華人佔多數，不會由少數歐籍人士統治<ref name="元" />{{rp|321}}。1907年，新界設立[[理民府]]制度，1910年新界分成南約、北約兩主區，新界「[[鄉約|八約]]」是九龍約、沙頭角約、元朗約、{{Tsl|zh-yue|雙魚 (香港)|雙魚約}}、六約、東海約、東島洞約和西島洞約；除警政及土地測量外，行政由南約及北約理民官負責<ref name="速1" />{{rp|124}}。

1911年，在[[盧押]]努力下，[[香港大學]]成立<ref name="章" />{{rp|248-249}}。先後設立[[香港大學文學院|文學院]]、工學院和[[香港大學醫學院|醫學院]]<ref name="元" />{{rp|321}}。20世紀初期，香港華人大多生活艱苦，工時長、工資微薄，往往傷病纏身或染有毒癮；約1/4華人抽鴉片，有2,000家鴉片窟<ref name="章" />{{rp|248}}。

[[省港大罷工]]使糧食價格高漲，銀行[[擠提]]<ref name="章" />{{rp|249}}。罷工領袖提出：每日工時以8小時為限，禁用童工，禁止警察不人道的粗暴行為，終止山頂區隔離政策；證券、股票和地價急跌，1925年9月每天有20宗破產個案；一群商人請求司徒拔向英國申請300萬貿易貸款，倫敦庫務署由[[西非]][[貨幣發行局]]和[[海峽殖民地]]籌集<ref name="章" />{{rp|251}}。1926年10月10日，[[國民政府]]和省港罷工委員會正式發表關於停止封鎖、結束罷工的公告<ref name="劉" />{{rp|160}}。學者指出，省港大罷工使香港華人大致分為：罷工工人與學生擁護廣州國民政府，華商與右派勞工支持港府反對罷工<ref name="速1" />{{rp|140}}。當時，英國在中國境內擁有最大量的外資利益，因而成為排外運動的主要目標，但不久反日情緒取而代之<ref name="元" />{{rp|321}}。

=== 1940年代、日本佔領及香港重光 ===
{{main|香港保衛戰|香港淪陷|香港日佔時期|香港重光}}
<gallery>
File:1945 liberation of Hong Kong at Cenotaph.jpg|1945年9月，[[英國]]及中國共同舉行升旗典禮暨慶祝遊行宣告[[香港重光]]
</gallery>
1941年12月11日，駐港英軍司令[[莫德庇]]少將下令棄守九龍，撤回港島堅守<ref name="速1" />{{rp|171}}。12月25日19時，[[香港總督]][[楊慕琦]]與莫德庇少將在[[半島酒店]]向日軍無條件投降，21時45分東京宣佈日軍佔領香港，[[香港日佔時期]]開始<ref name="劉" />{{rp|294}}。1942年1月，[[港九獨立大隊]]成立<ref name="劉" />{{rp|470}}。

1945年9月16日，[[香港重光]]，[[英國海軍]]少將[[夏慤]]代表[[英國政府]]及[[同盟國中國戰區]]最高統帥[[蔣介石]]，於[[香港督憲府]]接受[[日本陸軍]]少將岡田梅吉和[[日本海軍省|日本海軍]]中將藤田類太郎代表在香港的日軍[[無條件投降]]：「我們代表[[日本天皇]]和日本帝國[[大本營 (大日本帝國)|大本營]]，以及我們轄下的所有部隊，謹向夏慤海軍少將無條件投降，並履行海軍少將或其授權人所頒發的一切指示，和發出一切必要的命令，俾能予以實現。」<ref>Instrument of Surrender, at Government House, Hong Kong, 1945-09-16. </ref>

[[香港1946年|1946年]]，各地甫受日軍蹂躪，[[世界經濟]]蕭條，香港主要轉口貨品如米、麵粉、糖等，均告短缺，有些物料甚至要嚴格配給；當時，工商及物料供應署在其年報內有以下評論：「商人本能地相信[[自由放任|放任主義]]可行，我們雖未能完全同意，但卻承認，我們必須以市民福利和國際義務為大前提，盡量給予自由。」<ref name="顧" />{{rp|3}}5月，[[楊慕琦]]返港任港督，提出「[[楊慕琦計劃|發展香港人民自治計劃]]」，計劃推出後，香港市民十分冷淡<ref name="速1" />{{rp|183}}。楊慕琦計劃未能落實，主要原因：①[[英國殖民地部]]傾向支持計劃，而[[英國外交部]]則擔心激怒中國政府；②[[中華人民共和國成立]]，[[英國人]]擔心中共趁機收回香港；③親英的華人精英擔心中國政府左右香港[[議會政治]]；④[[朝鮮戰爭]]，中國與美國等[[西方國家]]關係破裂；⑤英籍高官擔心改革削弱行政權力；⑥[[葛量洪]]反對，認為華人不可能改造成忠心的市民或英國子民，首要任務是妥善處理內地與香港關係而非政制改革<ref name="速1" />{{rp|184}}。

=== 1950年代 ===
{{Main|香港1950年代}}
<gallery>

[[香港1952年|1952年]]調查報告顯示，平均每1,000户香港華人家庭，687户住在一個房間，120户住在[[劏房]]，23户住在屋頂天台，只有8户有[[房屋]]居住<ref name="章" />{{rp|291-292}}。同年[[朝鮮戰爭]]爆發，[[西方國家]]對華禁運，打擊香港轉口貿易<ref name="劉" />{{rp|471}}。

[[香港1950年代|1950年代]]，來港者眾，人口膨脹，香港社會連串緊急任務<ref name="顧72">{{cite book |title=《香港一九七三年——一九七二年的回顧》 |location=香港 |publisher=天天日報翻譯印刷發行 |year=1973 }}</ref>{{rp|5}}。工廠多是山寨廠，工人長時間工作，賺取微薄工資，[[童工]]為主，環境惡劣，產品水準佳，利潤大<ref name="章" />{{rp|210}}。房屋短缺、工時長收入低、物價急升百物騰貴，長期為市民生活三大問題<ref name="劉" />{{rp|418-420}}。

1955年8月，發現[[李鄭屋古墓]]<ref name="劉" />{{rp|471}}。[[香港1956年|1956年]]10月，九龍和荃灣發生[[雙十暴動]]<ref name="劉" />{{rp|471}}。

=== 1960年代 ===
<gallery>
File:USS Ticonderoga (CVA-14) at Hong Kong in 1960.jpg|1960年美軍[[提康德羅加號航空母艦]]於[[維多利亞港]]
</gallery>
{{Main|香港1960年代|六七暴動|香港立法局|香港公務員|政務主任}}
在1960年代中期之前，由於移民不斷湧入，政府必須集中力量先處理房屋、衛生、教育和福利等迫切問題<ref name="顧74">{{cite book |title=《香港一九七五——一九七四年的回顧》 |location=香港 |publisher=政府印務局印行 |year=1975 }}</ref>{{rp|1}}。

[[香港1966年|1966年]]，由於受到在中國[[文化大革命|發生之事件]]影響，香港之局勢日趨緊張，至1967年更演變為連串社會騷亂，全面影響香港居民生活，香港經濟暫時陷於癱瘓；騷亂事件在該年底受到控制，香港得以繼續在平穩中進展<ref name="顧" />{{rp|205}}。

1966年4月4日，香港青年[[蘇守忠]]身穿外衣寫上中英文「支持[[葉錫恩]]，參加絕食，反對加價」，在港島[[愛丁堡廣場渡輪碼頭|天星碼頭]]絕食[[天星小輪加價事件|抗議渡輪加價]]<ref name="劉" />{{rp|413}}。4月6日上午蘇守忠被控「阻街」提堂，晚上九龍市區暴動，警方施放催淚彈鎮壓，凌晨九龍宵禁，至4月9日晚結束，警方共拘捕1,465人，控告905人<ref name="速2">{{cite book |title=《速讀香港史（1949-2020）》 |author=周子峰 |publisher=[[中華書局（香港）]] |location=香港 |year=2021 }}</ref>{{rp|52}}。

1967年夏，突然天翻地覆，香港遇到平素最怕的威脅——[[六七事件|政治暴動]]<ref name="已">{{cite journal |title=這是三十年來最特出的經濟奇蹟 香港繁榮有增無已 |location=香港 |journal=[[讀者文摘]]1973年6月號 }}</ref>{{rp|29-30}}。5月15日，中國外交部要求英國政府責成港英釋放被捕人員<ref name="劉" />{{rp|415}}。最初是罷工，毆打管工，青年團體騷動，示威遊行，包圍[[港督府]]，要「英國[[法西斯]]分子滾出去」<ref name="已" />{{rp|29-30}}。7月12日，代理布政司在立法局宣佈，政府決心抓住並掌握主動權；港府圍攻60餘個左派工會和學校，逮捕超過1,500人<ref name="劉" />{{rp|416}}。受過[[港英政府|香港政府]]援助的中國人都支持香港政府，不肯響應大罷工<ref name="已" />{{rp|29-30}}。8月22日，北京[[紅衛兵]]數萬人放火[[火燒英國代辦處事件|焚燒英國代辦處]]；8月下旬，北京方面指示香港不宜照搬國內<ref name="劉" />{{rp|416-417}}。年底，銀行、證券交易所、出口貿易、旅遊事業，一切都恢復正常的繁榮<ref name="已" />{{rp|29-30}}。12月25日，炸彈陣平息<ref name="劉" />{{rp|417}}。至年底周恩來向左派施壓，事件始告結束<ref name="速2" />{{rp|56}}。中國要工業化，從美國、日本和歐洲羅致科技，要借重資本家又不讓他們帶着資產階級觀念居留內地，事實證明的最佳辦法，就是保持香港現狀；只要以「利」為前提，就安如磐石<ref name="已" />{{rp|29-30}}。

=== 1970年代 ===
{{Main|香港1970年代}}
[[中華人民共和國成立]]後，中國政府的一貫立場是：香港是中國的領土，中國不承認三個[[不平等條約]]，主張在適當時機通過談判解決香港問題，未解決前暫時維持現狀<ref name="鄧3" />{{rp|387}}。1972年3月8日，中國常駐聯合國代表[[黃華 (1913年)|黃華]]致函聯合國非殖民化特委會主席，反對將香港和澳門列入「反殖宣言」中適用的殖民地地區的名單內<ref name="劉" />{{rp|471}}。

港督[[麥理浩]]一面準備對中國就[[香港前途問題]]談判；另一面殖民政府亦需要規劃社會服務；因此殖民政府需要加強工作，爭取市民信心，累積民眾支持，為日後面對中國時增加談判本錢<ref name="呂">{{cite book |title=那似曾相識的七十年代 |last=[[呂大樂]] |publisher=[[中華書局（香港）]] |year=2012 |isbn=978-988-8181-15-5}}</ref>{{rp|151}}。

香港是世界最大[[紡織品]]、[[玩具]]和[[手表]]出口地<ref name="章" />{{rp|211}}。應付世界經濟不景，香港沒有發生罷工事件，也沒有重大勞資糾紛；在港中國人自作安排，分配工作，輪流上班，是中國人應付困難時之典型辦法：有飯大家吃<ref name="顧75">{{cite book |title=香港一九七六——一九七五年的回顧 |location=香港 |publisher=政府印務局印行 |year=1976 }}</ref>{{rp|1}}。香港以一貫靈活、能屈能伸的精神，應付逆境，漸漸撥開雲霧，重見曙光<ref name="顧80">{{cite book |title=香港一九八一——一九八零年的回顧 |location=香港 |publisher=政府印務局印行 |year=1981 }}</ref>{{rp|6}}。香港的政制並無神秘之處，其基本原則是盡量讓市場供求力量自由發展，不作任何干預；多年來政府只在確有必要時始推行改革<ref name="顧80" />{{rp|12}}。政制若缺乏改進，會令行政人員耽於自滿，有見及此，政府必須盡量發揮能力和耐力，保持敏鋭觀察，作出明確反應和果斷決策；縱是非代議制政府，亦應具備若干基本條件，包括認真負責及體察民情；政府首要責任是深入了解人民生活和願望；政府希望盡量讓經濟自由發展，而市民則要求正義、公平待遇及負責任之行政當局<ref name="顧80" />{{rp|12}}。 

社會秩序是最基本[[問題]]，[[貪污]]滲透[[社會]]各處，以警隊貪污最嚴重，市民日常在街頭目睹「派片」、收黑錢、包庇外圍賭檔；第二大問題是暴力和街頭犯罪，當年公共屋邨（特別是[[徙置區]]）常有箍頸黨、道友埋伏，間有黑幫械鬥，治安欠佳，街頭幫會令市民不安；由政府帶頭以社會動員為基本的撲滅暴力罪行運動、[[清潔香港運動]]等，說明問題嚴重<ref name="呂" />{{rp|18-19}}。但正如[[吳昊 (香港)|吳昊]]稱，關於廉政公署，「初時市民對它沒有好感」<ref name="呂" />{{rp|22}}。[[廉政公署 (香港)|廉政公署]]曾以「靜默革命」作宣傳口號，亦以此描述其工作<ref name="呂" />{{rp|22}}。後來「革命」成功，是因為廉政公署靜默打擊有組織貪污，並改變香港組織文化和市民對貪污行賄之態度<ref name="呂" />{{rp|23}}。1977年10月的[[警廉衝突]]，政府頒佈特赦，從此徹底改變警隊貪污問題<ref name="呂" />{{rp|35}}。

[[香港1979年|1979年]]3月29日，[[鄧小平]]對麥理浩稱<ref name="劉" />{{rp|471}}：「我們把香港作為一個特殊地區，特殊問題來處理。到1997年，無論香港問題如何解決，它的特殊地位都可以得到保證。說清楚一點，就是在本世紀和下世紀初相當長的時間內，香港還可以搞它的資本主義，我們搞我們的社會主義。因此，請投資者放心。」<ref name="袁97">{{cite book |author=袁求實編著 |title=《香港回歸大事記1979-1997》 |location=香港 |publisher=[[三聯書店（香港）]] |year=2015 |edition=香港第二版 }}</ref>{{rp|17}}同年起，[[越南難民]]大量到香港<ref name="劉" />{{rp|472}}。

=== 1980年代 ===
{{Main|香港1980年代|香港聯繫匯率制度|中英聯合聲明}}
[[香港1983年|1983年]]10月17日，[[香港聯繫匯率制度]]開始實施，規定1[[美元]]兑換7.75-7.85[[港元]]<ref name="劉" />{{rp|472}}。

[[香港1984年|1984年]]2月22日，鄧小平〈穩定世界局勢的新辦法〉，會見美國[[喬治城大學]]戰略與國際問題研究中心代表團稱：「香港問題也是這樣，一個中國，兩種制度。……香港是[[自由港]]。世界上的許多爭端用類似這樣的辦法解決，我認為是可取的。否則始終頂着，僵持下去，總會爆發衝突，甚至武力衝突。」<ref name="鄧3" />{{rp|49}}3月28日，[[怡和控股]]決定從香港遷冊至[[百慕大]]<ref name="袁97" />{{rp|33}}。4月20日，[[傑弗里·豪]]在香港發表聲明稱：「要達成一份能使香港在1997年以後仍然繼續由英國管治的協議，是不切實際的設想。……就是要達成一套安排，使香港繼續成為一個興旺和有動力的社會，並且取得一項協議，使這些安排得以記錄在案……就是作為中國一部分的香港，將會享有高度的自治權。……中國政府已公開清楚表示，在1997年後，香港的行政將會由港人掌握。這將會是承接着香港在這方面的發展。我樂於告訴大家這個發展已經開始。今後的日子，香港政府將會繼續朝着代議政制的路向發展。」<ref name="袁97" />{{rp|35}}《[[中英聯合聲明]]》使香港在1997年7月1日成為[[中華人民共和國]]一個[[特別行政區]]後，能保存香港獨特經濟體系和生活方式；協議保存香港人熟悉之法律制度和香港沿用、包括普通法之一套法律；此外，更使香港可繼續自行決定本身之經濟、財政和貿易政策，和繼續參加國際組織和貿易協定，例如[[關稅及貿易總協定]]；當時英國政府有信心，認為協議提供關於香港前途所需之保證，使香港能夠繼續繁榮和維持在世界上作為主要之貿易和金融中心之獨特角色<ref>{{cite book |title=中華人民共和國政府和大不列顛及北愛爾蘭聯合王國政府關於香港前途的協議草案 |location=香港 |publisher=[[政府印務局]]印 |date=1984-09-26 }}</ref>{{rp|7}}。香港大多數市民認為可能是在不樂觀的局勢中取得的最好結果，鄧小平相當誠實而善意，[[改革開放]]政策邁向[[市場經濟]]<ref name="章" />{{rp|370}}。

[[香港1989年|1989年]]6月4日，北京發生[[六四事件|政治風波]]，百萬香港市民[[全球華人大遊行|上街游行集會]]<ref name="劉" />{{rp|473}}。10月11日，[[衛奕信]]宣布，在1990年7月向立法局提出[[香港人權法案]]，提出[[香港機場核心計劃]]<ref name="袁97" />{{rp|95}}。

=== 1990年代 ===
{{Main|香港1990年代}}
[[香港1991年|1991年]]7月27日，[[華東水災]]慈善演唱會於跑馬地舉行，超過8萬名觀眾，籌款逾1億港元<ref name="劉" />{{rp|473}}。[[柯利達]]秘密出使中國並與中方斡旋，成功説服英國首相[[馬卓安]]1991年赴中國簽署[[香港國際機場|機場]]協議<ref>{{cite book |author=梁家權、王慧麟、屈穎中、黃敏瓊、馬淑嫻 |year=2001 |chapter=柯利達定律：毋須理對方先搞掂自己 |title=英方絕密檔案曝光——六七暴動秘辛 |publisher=[[香港經濟日報|經濟日報出版社]] }}</ref>{{rp|68}}。9月3日，[[李鵬]]與馬卓安在北京簽署《關於香港新機場建設及有關問題的諒解備忘錄》<ref name="劉" />{{rp|473}}。

[[香港1992年|1992年]]4月，馬卓安委派曾任[[英國保守黨]]主席的[[彭定康]]擔任第二十八任，即最後一任[[香港總督]]<ref name="劉" />{{rp|323-324}}。10月7日，彭定康在立法局發表就任後第一份施政報告，提出重大改變香港當時政治體制的憲制方案，即政改方案<ref name="劉" />{{rp|324}}。彭定康打算將行政立法兩局議員的身份分開、全面推行[[單議席單票制]]、在立法局選舉引入[[新九組]]<ref name="劉" />{{rp|324}}。

[[香港1996年|1996年]]1月26日，全國人大[[香港特別行政區籌備委員會]]在北京成立<ref name="劉" />{{rp|474}}。12月11日，香港特別行政區政府第一屆政府推選委員會在深圳選舉產生[[臨時立法會]]<ref name="劉" />{{rp|474}}。

[[香港2003年|2003年]]3月10日，[[醫院管理局]]承認，沙田威爾斯醫院有醫護人員出現[[嚴重急性呼吸道症候群|病毒性上呼吸系統病症]]，[[世界衛生組織]]派專家抵達香港調查<ref name="袁07" />{{rp|112}}。5月23日，世界衛生組織撤消對香港的旅遊警告<ref name="袁07" />{{rp|131}}。6月11日，香港證實最後一宗[[SARS疫情|SARS]]個案，至此共1,750人感染SARS，299人死亡<ref name="袁07" />{{rp|136}}。

[[香港2005年|2005年]]12月17日，包括[[韓國]]農民在內約1,000名「反[[世界貿易組織|世貿]]」行動示威者[[世界貿易組織第六次部長級會議|在香港會展附近]]與警方[[2005年香港反對世貿遊行衝突|激烈衝突]]，示威者多次衝擊警戒線，2,000名警察到場用消防水龍和催淚彈驅散，現場扣留900多人，共70人受傷，包括10名警察<ref name="袁07" />{{rp|405}}。

[[香港2006年|2006年]]5月24日，原全國政協主席[[李瑞環]]著《學哲學用哲學》繁體字版新書發佈會舉行，[[彭清華]]致詞稱，李瑞環告誡香港不要丟掉自己的優勢和特色、要加強團結<ref name="袁07" />{{rp|449}}。政府開始中區填海第三期工程，把[[舊中環天星碼頭]]和[[皇后碼頭]]拆卸作道路和商廈，引起民間團體和市民不滿，認為是摧毀港人集體回憶；天星碼頭清拆期間，逾百名示威者兩度衝擊地盤，雙方發生激烈肢體衝突，有示威者因強闖地盤，被控阻差辦公，其中1人更被控刑毀罪<ref name="科">{{cite web |website=大公文匯網 |url=https://www.tkww.hk/epaper/view/newsDetail/mobile/1371876650467332096.html |date=2012-12-18 |title=保育變抗爭早有前科 }}</ref>。大批警員亦將拒絕離開的保育人士逐一抬走，示威者以「人鏈」方式坐在警車前方，阻止警方帶走被捕人士；亦有示威者衝破警方防線，爬上地盤竹棚與警方對峙；清場期間情況混亂，有人不適暈倒，需送院接受治理<ref name="科" />。

2007年皇后碼頭清拆事件，3名保育碼頭人士無限期靜坐及絕食活動；本土行動成員何來和朱凱迪向高等法院提出司法覆核，要求阻止政府清拆皇后碼頭，獲高院接納；發展局局長林鄭月娥親到皇后碼頭出席公開論壇，表示不能接受不遷不拆保留皇后碼頭<ref name="科" />。碼頭清拆期間大批機動部隊警員在皇后碼頭範圍，警方用兩層鐵馬重重包圍碼頭，派出多部消防車戒備；海面亦有水警巡邏戒備；留守碼頭人士用單車鏈互相綁拒絕離開，亦有保育人士將自己鎖在皇后碼頭的柱子上，最後警方需強行剪斷頸上鐵鏈，險象環生<ref name="科" />。

== 中國內地與香港關係 ==
{{Main|中國大陸與香港關係}}{{Further|中港矛盾|香港境內水貨客問題|港深关系|粵港澳大灣區|大中華地區}}
很早以前，香港便成為[[中國南方]]及[[東南亞]]各地同世界各國交往之主要貿易通道，[[轉口貿易]]也一直是居民生計來源<ref name="本" />{{rp|37}}。

1846年11月25日，[[九龍寨城]]開始動工，1847年5月31日完工<ref name="劉" />{{rp|28}}。其後[[洪仁玕]]（[[太平天國]]天王[[洪秀全]]族弟）在香港醞釀提出《[[資政新篇]]》，強調[[法治]]和與外國通商<ref name="劉" />{{rp|117}}。[[容閎]]在香港[[馬禮遜學堂]]讀書4年，畢業於[[美國耶魯大學]]，作《[[西學東漸記]]》，組織幼童出國留學<ref name="劉" />{{rp|118-119}}。[[王韜]]1874年在香港創辦《[[循環日報]]》，推崇「君民共主（[[君主立憲]]）」<ref name="劉" />{{rp|120-121}}。[[何啟]]和[[胡禮垣]]彙編《新政真詮》，提出[[改良主義]]<ref name="劉" />{{rp|121-122}}。[[康有為]]於《康南海自編年譜》稱，其於1879年「薄遊香港，覽西人宮室之瑰麗，道路之整潔，巡捕之嚴密，乃始知西人治國有法度，不得以古舊之夷狄視之，乃復閱《[[海國圖志]]》、《[[瀛寰志略]]》等書，購地球圖，漸收西學之書，為講西學之基矣。」<ref name="劉" />{{rp|140}}

1923年2月19日，[[孫中山]]在香港大學發表演說〈我於何時及如何而得革命思想及新思想〉：「……我之此等思想發源地即為香港。至於如何得之，則我於三十年前在香港讀書，暇時輒閒步市街，見其秩序整齊，建築閎美，工作進步不斷，腦海中留有甚深之印象。……由市政之研究進而為政治之研究。研究結果，知香港政府官員皆潔己奉公，貪贓納賄之事絕無僅有，此與中國情形正相反。……中國對於世界他處之良好事物皆可模倣，而最要之先著，厥為改變政府。現社會中最有力之物，即為一組織良好之政府。……我既自稱革命家，社會上疑議紛起，多所誤會，其實一中國式之革命家究不過抱[[溫和主義]]，其所主張者非[[極端主義]]，乃爭一良好穩健之政府。……」<ref>{{cite book |author=孫中山 |chapter=〈我於何時及如何而得革命思想及新思想〉 |title=《孫中山全集》第七卷 |location=北京 |publisher=[[中華書局有限公司]] |year=1981 }}</ref>{{rp|115-117}}<ref>{{cite web |title=孫中山與香港 |url=https://www.eduhk.hk/chineseculture/content/hkculture/tm/history/history01.pdf |access-date=2022-05-19 |archive-date=2022-05-23 |archive-url=https://web.archive.org/web/20220523044242/https://www.eduhk.hk/chineseculture/content/hkculture/tm/history/history01.pdf }} {{Wayback|url=https://www.eduhk.hk/chineseculture/content/hkculture/tm/history/history01.pdf |date=20220523044242 }}</ref>

1938年6月14日，[[保衛中國同盟]]在香港[[宋慶齡]]寓所成立<ref name="劉" />{{rp|470}}。1941年12月8日，[[毛澤東]]出席[[中共中央政治局]]會議，關於工作布置，要加強[[南洋]][[華僑]]工作，[[廖承志]]應大膽地在香港與英國建立關係<ref name="中">{{cite book |editors=中共中央文獻研究室編，主編逄先知，副主編馮蕙、姚旭、趙福亭、吳正裕 |authors=馮蕙、劉益濤、高風、姜國珍 |title=《毛澤東年譜（1893－1949）》中卷 |location=北京 |publisher=人民出版社、中央文獻出版社 |year=1993 |ISBN=7-01-001818-9 }}</ref>{{rp|343}}。1947年5月15日，[[新華社香港分社]]成立<ref name="劉" />{{rp|470}}。1949年11月9日發生[[兩航事件]]，[[中國航空 (中華民國)|中國航空公司]]和[[中央航空公司]]在港員工接受[[中华人民共和国中央人民政府 (1949年－1954年)|中华人民共和国中央人民政府]]領導<ref name="劉" />{{rp|471}}。

1954年8月，[[周恩來]]提出「推進中英關係，爭取和平合作」：香港是中國的，但解決香港問題的時機尚未成熟<ref name="劉" />{{rp|471}}。1957年4月，周恩來提出要保持香港特殊地位「為我所用」之方針：香港總有一天我們是要收回的，連英國也可能這樣想；內地「要進行社會主義建設，香港可以作為我們同國外進行經濟聯繫的基地，可以通過它吸引外資，爭取外滙」，所以「保持香港這個陣地有好處」<ref name="本" />{{rp|24}}。「我們不能把香港看成內地。對香港的政策同對內地是不一樣的，如果照抄，一定搞不好。因為香港現在還在英國統治之下，是純粹的資本主義市場，不能社會主義化，也不應該社會主義化。香港要完全按照資本主義制度辦事，才能生存和發展，這對我們是有利的。……至於將來怎麼辦？我們不會來個七反八反的，不會像『三反』、『五反』那樣的搞法。……香港的企業家是我們的朋友，他們搞的是資本主義，不是帝國主義。過去我們同[[民族資產階級]]合作過，將來同香港的企業家還是可以合作的。港澳同胞不要擔心前途。……有些人一時還不相信我們，對我們的政策有懷疑，可以讓他們再看一看，看一二十年都可以。我們不要歧視他們，責怪他們。……我們要打開局面，就得對香港的民族資產階級講清政策，使人家有利可圖。」<ref name="本" />{{rp|25-26}}周恩來曾多次指示：「各地凡是有可能，對港澳供應都要負擔一些，不能後退。這個陣地越來越重要，對港澳供應確實是一種政治任務。」<ref name="本" />{{rp|26}}香港在地理和地質上都屬於中國一部分，大部分用水和糧食都有賴其供應<ref name="章" />{{rp|346}}。中國已深入香港整體而處於牢固地位，並且在香港所有活動裡扮演老練、果斷的角色<ref name="章" />{{rp|354}}。

1960年11月15日，香港政府與廣東省寶安縣簽訂協議，每年由[[深圳水庫]]供水50億[[加侖]]給香港<ref name="劉" />{{rp|471}}。1964年初，中國動工興建[[東深供水工程]]，把[[東江水]]引入深圳水庫再向香港供水，工程先後3次擴建；中國內地對香港供應[[淡水]]，解決香港市民生存之憂，為[[香港經濟]]發展注入動力<ref name="本" />{{rp|26}}。

1962年開始，由武漢、上海、鄭州始發的751次、753次、755次等「三趟快車」，常年向港澳供應鮮活冷凍商品<ref name="劉" />{{rp|471}}。1963年，針對中國外部有人責難中國港澳政策，中國政府公開聲明：「香港、澳門這類問題，我們一貫主張，在條件成熟的時候，經過談判和平解決，在未解決以前維持現狀。……中國人民不需要在香港、澳門問題上顯示武力，來證明自己反對帝國主義的勇氣和堅定性。」<ref name="本" />{{rp|25}}

[[金庸]]曾對[[池田大作]]說：「中國對於香港的政策，可以說是『現狀不變，長期利用』八個字，再加上八字：『民族大義，利於國家』。香港現狀的維持對中國有利，對全國人民有利。只要能長期維持下去，可以加以充分利用。」<ref name="探">{{cite book |title=探求一個燦爛的世紀 |publisher=明河社 |year=1998 |isbn=962-8129-20-1 |location=香港 |authors=池田大作、金庸 }}</ref>{{rp|31}}、「這其中香港所發生的作用之大、所作貢獻之重要，是無可估量的。由於這些實際的考慮，毛澤東和周恩來制定的香港政策是『保持現狀，充分利用』。香港只有保持現狀，才對中國有用，既然有用，就長期而充分的利用之。這個政策一直不變。」<ref name="探" />{{rp|36}}、「『反英抗暴鬥爭』，組織左派群眾，和香港的英國政府正面衝突，衝擊港督府，與警察打鬥，到處放置炸彈。英國出動正規軍反擊，雙方都有死傷，還累及不少無辜市民，一時局面十分惡劣。幸得周恩來總理親自下令制止這種違反中央政策、破壞香港穩定繁榮的行動，左派暴動才漸漸平息。其後這場動亂的組織者與發動者據說受到了黨內的批評，有些人還受到處分懲罰，被下放到邊遠地區的農場和礦山中勞動改造。經過了這次教訓後，『不得破壞香港現狀』的政策在中共高層領導中更加得到重視，這個政策的基本理由是：香港現狀的維持對國家有利、對全國人民有利，也即是對全黨有利，對香港廣大中國同胞有利。」<ref name="探" />{{rp|37}}

1978年8月，中國國務院成立[[國務院港澳事務辦公室]]<ref name="劉" />{{rp|471}}。

[[香港1982年|1982年]]4月27日，鄧小平在[[平壤]]同[[金日成]]會談，談到香港問題：到一九九七年，香港島、九龍半島、新界，中國全收回；在這個前提下，維持香港自由港和國際金融中心的地位；香港的社會制度不變，生活方式也不變；香港由香港人自己管理，組織地方政府，作為中國的特別行政區，掛中國國旗，也可能有個地方的旗幟，這可以商量，因為它也有些外事活動和國際交往；保留這樣一個香港對我們益處比較大<ref name="編">{{cite book |title=《鄧小平思想年編（一九七五——一九九七）》 |editors=中共中央文獻研究室 |publisher=中央文獻出版社 |year=2011 }}</ref>{{rp|414}}。8月10日，鄧小平會見美籍華人科學家鄧昌黎、陳樹柏等，談到香港問題時説：打中華人民共和國的旗，稱為「中國香港」；香港的管理，北京不派人，香港自己找人管，香港必須以愛國者為主體的香港人管理<ref name="編"/>{{rp|426}}。9月24日，鄧小平〈我們對香港問題的基本立場〉，會見[[撒切尔夫人]]稱：「中國就要正式宣布收回香港這個決策。……香港仍將實行[[資本主義]]，現行的許多適合的制度要保持。」<ref name="鄧3">{{cite book |title=鄧小平文選 |volume=第三卷 |publisher=人民出版社 |year=1993 |location=北京 }}</ref>{{rp|12}}

1998年7月1日下午，江澤民一行到[[沙田醫院]]和[[馬鞍山新市鎮]][[新港城中心]]參觀，市民熱烈歡迎<ref name="袁02">{{cite book |author=袁求實編著 |title=《香港回歸以來大事記1997-2002》 |location=香港 |publisher=[[三聯書店（香港）]] |year=2015 |edition=香港第一版 }}</ref>{{rp|148}}。2000年1月18日，根據國務院第二十四次常務會議決定，[[新華通訊社香港分社]]更名為[[中央人民政府駐香港特別行政區聯絡辦公室]]<ref name="袁02" />{{rp|313}}。

== 地理 ==

{{main|香港地理|珠江三角洲|亞太地區}}{{seealso|Template:香港地理極點}}

香港管轄總面積2,755.03[[平方公里]]，其中陆地面積1,114.57平方公里<ref name="積" />（香港島及鄰近島嶼80.72平方公里、九龍46.93平方公里、新界986.92平方公里，2025年年底數字）<ref name="積" />，水域面積1,640.40平方公里<ref name="積" />。從歷史看，香港地區可分為[[香港島]]、[[九龍]]和[[新界]]三部分<ref name="劉" />{{rp|4}}。

香港是[[亞太地區]]重要的海空交通中心，自由貿易港，與[[舊金山]]、[[里約熱內盧]]並稱世界三大天然良港<ref name="分">{{cite book |authors=中國地圖出版社編制 |title=《分省中國地圖集》 |publisher=[[中國地圖出版社]] |year=2000 }}</ref>{{rp|131}}。[[維多利亞港]]是世界三大天然深水良港之一，港深水闊，終年不凍<ref name="本" />{{rp|37}}。九龍半島和香港島之間是世界少有天然深水港灣，寬約1.5至9.6公里，深度2至14.5米，可供巨輪自由往來停泊，戰略地位十分重要<ref name="本" />{{rp|11}}。

=== 生態及氣候 ===
{{main|香港生態|香港首先發現物種列表|香港氣候}}
歷史上，香港曾出現[[野生動物]]包括[[豹]]、[[虎]]、[[貛]]、[[水獺]]、[[穿山甲]]、[[野貓]]、[[野豬]]、[[食蟹獴]]、[[蠑螈]]、200種[[蝴蝶]]、32種[[蛇]]（包括[[鉤盲蛇]]、[[白唇竹葉青]]、[[緬甸蟒]]）、[[金線魚]]、[[鯔魚]]、[[木棉魚]]、[[大黃魚]]、[[海蛇]]、[[魚狗]]<ref name="章" />{{rp|13}}。

香港為[[亞熱帶氣候]]，[[秋季]]冷熱適中；有時連續幾週多雲陰天，悶熱潮濕；常有強烈颱風<ref name="章">{{cite book |author=[[珍·莫里斯]] |title=香港：大英帝國的終章 |location=[[新北市]] |publisher=八旗文化/遠足文化 |year=2017 |ISBN=978-986-94231-9-9 }}</ref>{{rp|13}}。

=== 空氣污染 === 
{{main|香港環境保護|香港空氣污染}}
路邊空氣污染主要來自商業車輛的廢氣；而區域性的煙霧問題則是由香港和[[珠江三角洲]]地區的車輛、船舶、工業及發電廠排放的污染物引起<ref>{{cite web |title=空氣 |url=https://www.epd.gov.hk/epd/tc_chi/environmentinhk/air/air_maincontent.html |website=香港環境保護署 |date=2026-02-10 }}</ref>。高樓大廈林立的市區令到空氣中的[[懸浮粒子]]和微[[灰塵|塵]]難以吹散，[[屏風樓]]阻礙空氣流通，助長[[煙霞]]及低能見度等現象的發生<ref>[http://www.weather.gov.hk/wxinfo/pastwx/d1redvis2011c.htm 1968至2010年香港低能見度時數的長期趨勢] {{Wayback|url=http://www.weather.gov.hk/wxinfo/pastwx/d1redvis2011c.htm |date=20111103141547 }}，載香港天文台網站，發表於2011年1月21日</ref>。另外，當有[[熱帶氣旋]]於[[台灣]]或[[菲律賓]]附近，香港及[[珠三角]]就會受到其外圍環流影響而轉吹西北風及出現下沉氣流，這種天氣有利於臭氧經光化學反應而形成、傳播並積聚在珠江口附近，香港的空氣污染亦會變得嚴重<ref>李月嬋、翁忠海（2005年）：《[http://www.hko.gov.hk/publica/reprint/r577.pdf 由煙霞引致香港能見度下降的分析] {{Wayback|url=http://www.hko.gov.hk/publica/reprint/r577.pdf |date=20070412103635 }}》第五頁，發表於第十九屆粵港澳氣象科技研討會，載香港天文台網站</ref>。

同時，受[[珠江三角洲經濟區]]區域[[光化學煙霧]]問題影響，香港的[[臭氧]]濃度仍在上升<ref>{{#invoke:cite| web |author1=香港環保署空氣科學組 |title=2019年香港空氣質素 |url=https://www.aqhi.gov.hk/api_history/tc_chi/report/files/AQR2019c_final.pdf |website=香港環保署 |accessdate=2021-02-07 |archive-date=2021-05-20 |archive-url=https://web.archive.org/web/20210520032820/https://www.aqhi.gov.hk/api_history/tc_chi/report/files/AQR2019c_final.pdf |dead-url=no }} {{Wayback|url=https://www.aqhi.gov.hk/api_history/tc_chi/report/files/AQR2019c_final.pdf |date=20210520032820 }}</ref>。

=== 交通 ===
<gallery>

1993年10月15日，[[中環至半山自動扶梯系統]]開放使用，全長約800米，為世界最長有蓋自動[[電動扶梯]]系統<ref name="劉" />{{rp|473}}。[[山頂纜車]]於1888年5月通車<ref name="劉" />{{rp|469}}。

[[香港道路]]使用率位居世界前列<ref>[http://www.gov.hk/tc/about/abouthk/factsheets/docs/highways.pdf 《香港便覽 — 道路設施》] {{Wayback|url=http://www.gov.hk/tc/about/abouthk/factsheets/docs/highways.pdf |date=20070928005545 }}，香港政府新聞處，2007年4月</ref>，道路總長度有2,099公里<ref name="統計2015" />{{rp|39}}。香港之山形地勢，與市區之密集建築，使改善道路，施工維艱；但在港九市區，均在若干街道實施單向行車辦法，及大規模道路及天橋工程，藉以疏導交通<ref name="顧71">{{#invoke:cite| book |title=《香港一九七一年》 |location=香港 |publisher=[[天天日報]]翻譯印刷發行 |year=1972 }}</ref>{{rp|2}}。截至2014年年底，香港領牌車輛共70萬輛<ref name="統計2015" />{{rp|39}}。

1924年，[[何啟]]、[[區德]]投資興建[[啟德機場]]<ref name="劉" />{{rp|470}}。[[香港新機場]]是東南亞最繁忙的國際機場之一<ref name="分" />{{rp|131}}。2013年，有372,000架次飛機進出[[香港國際機場]]<ref name="統計2015" />{{rp|38}}。

陸路交通方面，[[廣深港高速鐵路香港段]]約26公里，工程於2010年動工，2018年9月23日正式啟用<ref>{{cite web |title=廣深港高速鐵路香港段 |url=https://www.hyd.gov.hk/tc/our_projects/railway_projects/xrl/index.html |date=2025-07-02 |website=www.hyd.gov.hk }}</ref>。

=== 建築 === 
{{main|香港建築|香港土地利用|香港摩天大樓}}
香港城市建築以[[現代主義建築]]為主，大量[[香港摩天大樓|香港摩天大-{}-樓]]分佈於[[維多利亞港]]兩岸，高度逾90米的建築逾3,069座<ref>The World's Best Skylines: ''[https://web.archive.org/web/20081218102352/http://homepages.ipact.nl/~egram/skylines.html Skyscraper Cities Ranking List]''</ref>。香港有些商業大廈及[[住宅]]皆是[[摩天大樓]]。全球最高100棟住宅大樓中，逾半位於香港<ref>Chun-Man CHAN：[https://web.archive.org/web/20070929012819/http://www.ciihk.org.hk/r%26d/backend/files/papers/7.pdf Advances in Structural Optimization of Tall Bulidings in Hong Kong]，[[香港科技大學]][[土木工程]]系</ref>。1988年11月25日，[[香港會議展覽中心]]開幕<ref name="劉" />{{rp|473}}。1990年5月[[中銀大廈 (香港)|中銀大廈]]在[[金鐘]]落成<ref name="劉" />{{rp|473}}。古老的技術抵禦挑戰，建築摩天大廈仍然以[[搭棚]]為主<ref name="章" />{{rp|149}}。

1978年「[[居者有其屋]]」計劃首期[[俊民苑]]正式動工<ref name="呂" />{{rp|35}}。私人大型屋邨[[美孚新邨]]，1966年開始興建，1975年各期全部完成；[[太古城]]則於1975年動工<ref name="呂" />{{rp|34}}。

行政機關負責香港與其他地區之聯繫、香港之各項社會事務和執行，及提供公共服務，立法機關有權監管和質詢<ref name="全1">{{cite book |title=《香港日用法律大全（一）》 |editor=李宗鍔法官 |publisher=[[商務印書館（香港）]] |year=1995 }}</ref>{{rp|85}}。據香港政府出版的《香港一九八三年——一九八二年的回顧》，香港之制度是以一套完備之法則維繫，但亦作出修訂以適應香港之需求；立法之精神在乎給予最高程度之自由，但維持起碼之限制，使人人受到保障，得享自由；獨立之司法制度是支持之力量；政府機構執行職責，提供服務，負責制定政策之人士並非民選，因此更要小心翼翼，對社會人士最輕微之意見亦須留意，並盡量作出反應；正因為決策人士並非民選，他們更有自由表達整個社會之意見，而毋須祇替其黨派説話；由於他們毋須競選連任，各項政策更能貫澈始終，持久實行，的確是其他實行民主政制之地區所罕見；政策之制定，主要出於對居民福利之關懷，並視乎是否可行而實施，而並非自覺地取決於任何一種政治理論；不過，最重要是政策是根據一個組織完善及範圍廣泛之諮詢網所搜集之意見而制訂及改進——可謂古希臘雅典民主政制之香港版本<ref name="顧" />{{rp|4-5}}。

1992年7月，[[民主建港協進聯盟]]（民建聯）成立；1993年3月，[[自由黨 (香港)|自由黨]]成立；1994年10月，[[民主黨 (香港)|民主黨]]成立<ref name="劉" />{{rp|473}}。在香港，政府使自由企業制度有效運作，奉行低税率和簡單税制，法律制度深受市民信任，法院行事公正，又獨立自主<ref name="顧95">{{cite book |title=《香港一九九六——一九九五年的回顧》 |location=香港 |publisher=政府印務局印行 |year=1996 }}</ref>{{rp|1}}。法院最終會維護公正，保障權利，使人們相處和與政府交往時，更有信心<ref name="顧95" />{{rp|3}}。自由並不等於毫無約束地任意行事，[[自由社會]]是指在整體社會接納下，各人可以尋求自己理想，不受約束；經濟、社會及政治壓迫可以限制自由，因此各人都有公平機會運用自由權，才是自由社會；[[香港法律制度|香港法制]]穩健並獲廣泛接納，而政府架構又確保沒有人或團體可欺壓他人，因此我們已直覺假定我們擁有真正自由<ref name="顧95" />{{rp|1}}。缺乏司法保障之民主，並不保證自由；司法制度最重要是獨立於政府行政機關之外，制約行政當局行使權力；因此選舉產生之立法機關權力要受到某種程度約束，否則容易演變成專制獨裁；香港政府架構最大優點是無人擁有至高無上之權力<ref name="顧95" />{{rp|2}}。政府如果得不到人民認同，必然存在不穩定因素；要多聽取他人意見，不與社會脱節，減少犯錯機會；如果市民基本上同意，便要給所有人覺得有充分機會提出觀點，他們的意見政府亦已考慮，沒有置之不理<ref name="顧95" />{{rp|2}}。社會一直享有[[言論自由]]，包括提倡改變政策和措施的自由；從不贊同急劇的轉變，因為穩定的政策和措施，能確保市民清楚知道其目前情況，知道日後不會有太大改變；但維持穩定不表示一成不變<ref name="顧95" />{{rp|2}}。

《[[中華人民共和國香港特別行政區基本法]]》規定，香港法院可就有關香港自治範圍的事務解釋基本法，但全國人民代表大會常務委員會擁有最終解釋權<ref>{{cite web |title=基本法 - 基本法 - 基本法簡介 (TC) |url=https://www.basiclaw.gov.hk/tc/basiclaw/facts.html |website=www.basiclaw.gov.hk |access-date=2024-11-19 |archive-date=2024-12-21 |archive-url=https://web.archive.org/web/20241221154729/https://www.basiclaw.gov.hk/tc/basiclaw/facts.html |dead-url=no }}</ref>。

== 立法 ==
{{Main|香港立法會}}
[[File:Legislative Council Complex 201308.jpg|thumb|[[立法會綜合大樓]]]]
立法機關可透過立法程序，批准、修改或反對行政機關所提議之行政措施，立法機關可在考慮通過撥款條例時，批准、削減甚或拒絕撥款辦理行政事務<ref name="全1" />{{rp|85}}。立法機關無權干預具體行政運作，例如公務員之任命、政府部門之工作程序等<ref name="全1" />{{rp|85}}。立法機關受到公眾監管，市民可藉輿論抨擊和投票選舉使議員失去議席<ref name="全1" />{{rp|85}}。雖然立法機關制訂[[成文法]]，但是成文法之釋義和引用原則卻是由[[香港司法機構|法院]]決定<ref name="全1" />{{rp|85}}。

== 司法及法律制度 ==
{{Main|香港法律制度|香港司法機構}}
[[File:Court of Final Appeal Building.jpg|thumb|left|[[終審法院大樓]]]]
[[File:HK Central Statue Square Legislative Council Building n Themis s.jpg|thumb|upright|終審法院大樓上蒙上雙眼的[[忒弥斯|泰美斯女神像]]，獲視為香港法治的象徵]]
[[香港司法機構]]是裁判行政機關與市民和市民之間之紛爭，倘行政機關不合法侵犯市民權益，法院就判令行政機關停止行動或對市民作出補償；不過法院必須執行符合立法機關所訂之法律，香港司法機構不能任意訂立法律；除非有當事人向法院入稟請求伸冤，法院不能隨意就任何行政、立法問題作出判決<ref name="全1" />{{rp|85}}。

司法工作之首要原則是，法庭必須不偏不倚，不受外界干擾或壓力，根據法律和法庭認定之事實作出判決<ref name="全1" />{{rp|86}}。在法庭之內，法律面前，的確人人應該平等，但法官不是在法律面前，在法律面前是全庭公眾、原告、被告，他們面向法官，法官就是法律，法官必須是高於庭內其他人<ref name="全1" />{{rp|86}}。

法律之目的，是確保沒有人會受到恣意欺壓，而刑事法亦是根據同樣之原則來執行，政府沒有權控制刑事訴訟事宜；律政司毋須聽命於任何人，但須全權負責法律程序之執行<ref name="顧" />{{rp|7}}。因此現時在香港，一位市民是否會被起訴，並非由警方或政府決定，而是由[[律政司 (香港)|律政司]]決定；律政司是律政人員，享有準司法權力；其權力祇限於提出起訴或撤回訴訟，以終止法律程序；律政司無定罪之權力；決定被告人是否有罪，及對裁定有罪者判處適當之刑罰，則屬具有獨立權力之司法部門之責，某些案件則必須聯同一個由市民組成之[[陪審團 (香港)|陪審團]]進行裁決<ref name="顧" />{{rp|8}}。

== 經濟 ==

{{Further|香港商業|香港旅遊業|香港貿易|香港工業|香港農業|香港漁業|香港礦業|香港輸入勞工計劃|港元}}
[[File:BOC, CKC, HSBC.JPG|thumb|位於[[中環]]的[[商業大廈]]（由左至右）：[[中銀大廈 (香港)|中銀大廈]]、[[長江集團中心]]及[[滙豐總行大廈]]]]
香港經濟属於[[自由市場]]經濟，其核心內容是通過價值規律、供求關係、競爭機制之自發調節來配置社會資源<ref name="本" />{{rp|39}}。前[[香港律政司]][[祈理士]]認為，自由貿易之哲理源自中國古代[[道家]]哲學，如[[老子]]《[[道德經]]》所言：「將欲取天下者，恆以無事。及其有事也，又不足以取天下矣。……無狎其所居，無厭其所生，夫唯弗厭，是以不厭。」<ref name="顧" />{{rp|3}}。有说法形容香港經濟是「轉型經濟」，接受而多少改變事物，後再經手傳出去<ref name="章" />{{rp|193}}。數十年來，歷任[[香港財政司]]始終相信：就解決問題的方法而言，市場力量比政府的管制措施或各類指示更為有效，而且肯定更為快捷<ref name="顧">{{cite book |title=《香港一九八三年——一九八二年的回顧》 |location=香港 |publisher=[[政府印務局]]印行 |year=1983 }}</ref>{{rp|3}}。

[[自由港]]政策特徵是政府對貿易、市場不加干預或極少干預<ref name="本" />{{rp|39}}。政府對關係社會、民生之土地、[[香港公共屋邨|公屋]]、食水、大米和一些[[公用事業]]直接控制、配置或立例管理，對貿易、商業、工業、航運等部門概不干預，在市場自動調節下運作，同時實行低稅制<ref name="本" />{{rp|39}}。香港管治精神講求[[效率]]，治理[[哲學]]採取務實的放任主義：[[自由貿易]]、自由企業、[[門戶開放]]，「正面性的[[不干預主義]]」<ref name="章" />{{rp|296-297}}。「積極不干預」政策，實際上是一種適度的積極干預政策：一、奉行自由主義經濟哲學，努力保持自由港地位，堅持自由企業制度和[[自由經濟]]政策，營造鼓勵[[競爭]]的[[投資]]環境，鞏固市場機制經濟基礎；二、通過政策措施補救自由放任經濟政策的缺陷，適度的必要干預<ref name="劉" />{{rp|356}}。香港經濟的主力在於[[彈性]]，由於沒有[[政府]]干預，向來[[自由]]，容易轉變[[理念]]，換手法、換重點；有恢復力，在[[戰爭]]、[[革命]]、[[暴亂]]、[[股災]]後，都能迅速回復[[平衡]]和平靜<ref name="章" />{{rp|228}}。

香港商品、貨幣、資金、人員進出自由；對外貿易自由、資本流動自由、企業經營自由、貨幣滙兌自由；本地及外國企業一視同仁，自由競爭<ref name="本" />{{rp|39}}。市場經濟之「[[無形之手]]」在香港可以相對較好優化資源配置、自動調節經濟<ref name="本" />{{rp|40}}。香港向來依靠自由企業，政府也制定[[香港銀行業]]與[[證券市場]]準則；[[經濟政策]]本質是任何事都決心一試，決不畫蛇添足；[[稅]]率低，只有[[煙草]]、[[酒]]、[[汽油]]、[[化妝品]]等才要[[關税]]；[[市場]]不受任何束縛而盡情發揮<ref name="章" />{{rp|287}}。香港工資、物價，在較多自由放任因素之經濟體制下具有很大彈性，遇到危機時較易作出反應和調整，使經濟較快復興，再現繁榮<ref name="本" />{{rp|40}}。香港的體制一直是[[民營企業]]與[[香港公營機構]]間取平衡<ref name="章" />{{rp|298}}。事實是，香港一無土地，二無資源，唯一財富就是港人勤勞智慧和適應能力；香港居民繼承幾千年來能吃苦、肯拼搏之優良傳統，靈活變通、善於抓住機遇<ref name="本" />{{rp|40}}。[[戴麟趾]]在其後記曾説：「本港在經濟方面，大體採取不干預政策，但這絕不表示政府麻木，胸無壯志，一直以來，所有決策都是經過深思熟慮才制定的」；各界人士都知道，政府審慎監察經濟制度，一旦發覺資本主義過份活躍，必須加以控制，便會樂於調整制度；民間各類商業活動就是在此情況進行；香港歷來之企業家，無論怎樣放肆，都不敢強言「不干預」具「全無法紀」之含義<ref name="顧" />{{rp|3}}。戴麟趾勒令：「如果你有大規模的問題，就要採用大規模的解決辦法。」<ref name="章" />{{rp|294}}祇有高度發展之商業法律制度，並有來自各國之法律專才，以及一個嚴正不苟、極具辦事能力和飲譽全球之司法制度，才能使國際間之商業財團有足夠信心，使香港成為經濟樞紐之一；香港之[[契約法]]體制必須為人所熟悉，其規例必須眾所周知及受到尊重，必須明確而不流於獨斷獨行，始能獲外來者接受，放心將其千萬元之交易交給法庭裁決<ref name="顧" />{{rp|5}}。

政府促進經濟發展，創造鼓勵及促進自由競爭之法制，制訂相關法例、條例，並採取措施保障法律實施<ref name="本" />{{rp|43}}。香港商業及金融得以轉動自如，不斷加速前進，其推動力就是安定和信任；香港之所以安定是因為在香港之政制下，任何人或團體均無權獨斷獨行或採取高壓手段（香港內部安全確實受威脅則作別論）；其次，或許是更為重要，就是信任，堅守不移；此信任比香港先進之法律、商業及政府結構更重要，使[[香港經濟]]體系活躍；多年來因為此信任，香港才能穩定、才能贏得並且維繫國際間對香港之信心，加上香港之組織，遂能吸引世界各地之商家紛紛到香港設立分公司，進行億萬元投資及貿易；香港之政制及法律，並非空談法治，而是切實執行，因而成為信心之基石，並且營造出一個容讓社會繁榮茁壯成長之環境<ref name="顧" />{{rp|4}}。經濟發展依靠通訊，1882年引進[[電話]]，到1939年平均每10個居民就有1部電話<ref name="章" />{{rp|198}}。

=== 經濟發展 ===
[[File:Tsing Ma Bridge (1).jpg|thumb|[[青馬大橋]]的夜景]]
1868年，[[華商]][[南北行]]公所成立<ref name="劉" />{{rp|469}}。1913年，[[中華總商會|華商總會]]成立<ref name="劉" />{{rp|470}}。1959年，香港產品在出口貿易中佔70%，比轉口貨多<ref name="劉" />{{rp|471}}。1960年11月22日，[[香港工業總會]]成立<ref name="劉" />{{rp|471}}。1960年代出現購物商場，並非本土都市社區經濟轉型之結果，反而是由觀光旅遊及相關服務行業所推動之轉變，很大程度上是「旅遊業所支配的都市發展」；後來到1970年代，購物商場文化在香港落地生根，則因為本地人口消費力隨着經濟發展而提升，而香港人亦開始習慣到購物商場去消費<ref name="呂" />{{rp|99}}。

1979年，[[長江實業]]購入[[和記黃埔集團]]22.4%股權，為香港第一家華資集團控制英資<ref name="劉" />{{rp|472}}。1980年7月7日，[[香港聯合交易所]]註冊成立<ref name="劉" />{{rp|472}}，與東京、倫敦、紐約相銜接<ref name="章" />{{rp|194}}。同年，[[包玉剛]]收購英資[[九龍倉]]<ref name="劉" />{{rp|472}}。1985年，包玉剛控制英資[[會德豐]]<ref name="劉" />{{rp|472}}。1986年4月24日，[[關稅及貿易總協定]]秘書處通知各締約國：由於英國政府4月23日向總協定秘書處提交聲明，使香港自該日起成為關稅及貿易總協定的第91名締約成員；中國駐聯合國日內瓦辦事處該日亦向關貿秘書處呈交聲明稱，自1997年7月1日起香港特區可以「中國香港」名義繼續作為協定締約方<ref name="袁97" />{{rp|59}}。

1987年10月19日，[[恆生指數]]以3362.39點收市，較上次交易10月16日下跌420.81點，10月20日[[香港聯交所]]宣布停市4天，10月26日以2241.69收市；10月30日的股票總市值為4181億多元，較9月月30日的7558億多元，[[八七股災|減縮3377億多元]]<ref name="袁97" />{{rp|73}}。綜觀各產業以[[服務業]]佔本地生產總值比重最高，2009年數字為92.7%，當中金融、保險、地產及商用服務業佔[[國內生產總值]]27.2%，批發、零售、進口與出口貿易、飲食及酒店業佔26.5%，社區、社會及個人服務業則佔18.2%<ref name="統計2015" />{{rp|23}}。2009年服務輸出總值達6,728億港元，佔本地生產總值40.5%<ref name="統計2015" />{{rp|21}}。

==人口==
{{Main|香港人口|香港人|華人}}
1955年，香港人口240萬，到1988年是560萬，98%是[[華人]]<ref name="章"/>{{rp|24}}。2013年，香港出生率全世界最低——每1,000人中只有7.6個新生嬰孩<ref name="統計2015"/>{{rp|10}}，人均壽命則是最高的地區：男性出生時平均預期壽命為81.1歲，女性則為86.7歲<ref name="統計2015"/>{{rp|44}}。2014年，65歲及以上人口佔總人口14.7%<ref name="統計2015"/>{{rp|10}}。隨著平均預期壽命增長及出生率的降低，人口將會越趨老化，估計於2033年，65歲及以上人口，將佔總人口27%<ref>香港統計處（2004年）：《[http://www.info.gov.hk/gia/general/200406/30/0630091.htm 香港人口推算2004－2033] {{Wayback|url=http://www.info.gov.hk/gia/general/200406/30/0630091.htm |date=20070427000000 }}》</ref>。

香港居民有[[廣府人]]、[[閩民系|福建人]]、[[客家人]]、[[蜑家人]]<ref name="章" />{{rp|14}}，真正土生土長為數不多，除戰後在香港出生外，其餘多是不同時期廣東、福建、江蘇、浙江及上海等地移民<ref name="本" />{{rp|40}}。2014年，香港女性較男性多出551,500人，每10,000名女性只有8,584名男性；初婚年齡男性中位數為31歲，女性為29歲<ref name="統計2015" />{{rp|10}}。根據2021年香港人口普查數據，四大區域之人口分別為：香港島1,195,529人、九龍2,232,339人、新界3,984,077人、水上1,125人，總人口7,413,070人<ref>{{#invoke:cite| web |title=主要統計表 |url=https://www.census2021.gov.hk/tc/main_tables.html |access-date=2022-04-10 |website=www.census2021.gov.hk |archive-date=2022-05-24 |archive-url=https://web.archive.org/web/20220524133324/https://www.census2021.gov.hk/tc/main_tables.html }} {{Wayback|url=https://www.census2021.gov.hk/tc/main_tables.html |date=20220524133324 }}</ref>。

== 社會 ==
{{main|香港社會|香港貧富懸殊問題|M型社會}}
衝突不和之主因，乃是缺乏房屋、生活環境擠迫及現實殘酷<ref name="顧72" />{{rp|4-5}}。援助嚴重殘疾、年老多病及其他易受傷害者；改善設備，特別是職業訓練、安置、收養和住屋<ref name="顧72" />{{rp|6}}。[[香港經濟]]須能應付各項開支，社會上之個人安全感亦同樣重要<ref name="顧72" />{{rp|9}}。

香港是多元化社會，只有少數是極左和極右的支持者，一般市民最大的願望是經濟繁榮，生活安定<ref name="劉" />{{rp|417}}。[[傳統]][[習俗]]淡化、風氣[[開放]]、[[時尚]]追求[[享樂主義|享樂]]、[[投機]]重實[[利益|利]]，使[[社會風氣]]喧囂躁動、熱衷投機、渴望暴富<ref name="劉" />{{rp|428-430}}。[[藍領]]希望好生活，[[白領]]重視享受，[[億萬富翁]]生活華麗，「拼命賺錢，盡情享受」幾乎是全社會共識<ref name="劉" />{{rp|427}}。

古老的品味偏好和習性依然，[[中樂]]和聲承受住[[搖滾]]和[[西洋古典音樂]]的來襲，[[麻將]]仍是主流消遣；陰陽曆並用，[[十二生肖]]紀年在香港華人社會仍是主流<ref name="章" />{{rp|149}}。中式殯葬盛行，有習俗入土3年後再在墳中撿骨改放到骨罈；因為[[抗生素]]影響，遺體腐化變慢，通常埋葬8年才撿骨，而非傳統六六大順埋6年<ref name="章" />{{rp|154}}。

=== 哲學及文學 ===
{{main|香港哲學|香港文學}}
[[File:Hong Kong Heritage Museum Jin Yong Gallery 2017.jpg|thumb|[[香港文化博物館]]的金庸展廳館]]
[[曹聚仁]]的《酒店》、[[徐速]]的《[[櫻子姑娘]]》、[[嚴慶澍|唐人]]的《金陵春夢》、[[劉以鬯]]的《[[酒徒 (小說)|酒徒]]》，都是南下作家的重要作品<ref name="劉" />{{rp|445}}。通俗文學中的新派[[武俠小說]]，尤以[[金庸]]、[[梁羽生]]的作品節奏緊、言辭優、情味濃、意境深，風靡全球華人<ref name="劉" />{{rp|446}}。1960年代後，[[依達]]、[[亦舒]]、嚴沁、[[岑凱倫]]、[[林燕妮]]等言情小説作家登場，作品溫柔多情<ref name="劉" />{{rp|446}}。[[倪匡]]的[[科幻小說]]結合[[科幻]]與現實，浪漫又情理細緻，多部作品形成「[[衛斯理]]科幻小説系列」<ref name="劉" />{{rp|446-447}}。1980年代末，[[梁鳳儀]]推出「財經小説」<ref name="劉" />{{rp|448}}。

=== 影視動漫 ===
{{Main|香港電影|香港電視廣播|香港漫畫|香港動畫}}
[[File:Hong kong bruce lee statue.jpg|thumb|[[星光大道 (香港)|星光大道]]上的[[李小龍]]像]]
香港最早拍製的其中一套故事片是1914年[[黎民偉]]編演的《[[莊子試妻 (電影)|莊子試妻]]》，是首創的粵劇電影；[[任劍輝]]、[[白雪仙]]的演出亦受稱頌<ref>{{cite web |title=光影中的虎度門: 香港粤劇電影研究 |url=https://studylib.net/doc/28964680/%E9%A6%99%E6%B8%AF%E7%B2%A4%E5%89%A7%E7%94%B5%E5%BD%B1%E7%A0%94%E7%A9%B6%E6%89%80?p=44 |pages=10, 42 }}</ref>。

電視作為家庭娛樂及資訊媒介，於1960年代末迅速普及，由1968年只有27%之住戶裝有電視機，到1970年已躍升為60%；1974年裝有電視機之住戶再升至86.2%，到1976年更達90%，電視成為最具影響力之傳播媒體<ref name="呂" />{{rp|20}}。1974年，「無綫電視」之「翡翠劇場」播《[[啼笑因緣 (1974年電視劇)|啼笑因緣]]》，改編自[[張恨水]]之[[啼笑因緣|作品]]，並非新劇種，可以理解為舊劇種及舊模式（比較貼近[[話劇]]）之高潮，代表本地製作（還有《[[歡樂今宵]]》）逐漸能替代外國配音電視片集，成為觀眾主要之選擇<ref name="呂" />{{rp|26-27}}。而《[[啼笑因緣 (歌曲)|啼笑因缘]]》之主題曲亦如[[黃霑]]在〈流行曲與香港文化〉中稱：「新中有舊。……這首詞，依舊沿用『文白夾雜』的一貫寫法，口語之中，仍有文言的語言習慣，還沒有拋開粵劇的味道。……連演繹者[[仙杜拉]]的唱法，也還是有粵曲運腔咬牙的影子。」<ref name="呂" />{{rp|27}}但無論如何，這首歌開風氣之先，帶动当代電視劇主題曲、[[香港粵語流行曲]]之新發展<ref name="呂" />{{rp|27}}。電視新聞報道[[寶生銀行]]劫匪挾持人質，電視台連續17小時現場直播案發情況，全港觀眾即時瞭解；5月26日，《華僑日報》刊出5月24至5月25日11人質「生死關頭情勢危急團結力量發揮神勇全港市民齊喝采」<ref name="呂" />{{rp|27}}。1976年，由全新概念之《[[狂潮]]》以及以[[武俠小說]]為藍本之《[[書劍恩仇錄 (1976年電視劇)|書劍恩仇錄]]》、《[[陸小鳳 (1976年電視劇)|陸小鳳]]》接力<ref name="呂" />{{rp|27}}。

[[李小龍]]電影《[[唐山大兄]]》、《[[精武門]]》、《[[猛龍過江]]》和《[[龍爭虎鬥]]》，塑造一系列追求平等尊嚴、嫉惡如仇的[[英雄]]形象，在[[西方世界|西方]]掀起「[[功夫]]熱」<ref name="劉" />{{rp|455}}。[[許冠文]]、[[許冠傑]]、[[許冠英]]兄弟的《[[鬼馬雙星]]》、《[[半斤八兩 (電影)|半斤八兩]]》等開拓喜劇電影，粵語電影得以重返影壇，取得成功<ref name="劉" />{{rp|453-456}}。1974年10月，《鬼馬雙星》開畫，當年港產片票房榜上排第一，收620多萬元<ref name="呂" />{{rp|25}}。1978年，[[嚴浩]]拍電影《茄喱啡》，電影刊物《大特寫》以「香港電影新浪潮」名之<ref name="呂" />{{rp|35}}。

=== 粤语流行音樂 ===
{{Main|香港音樂|香港粵語流行曲}}
1970年代起，[[蓮花樂隊]]主音[[許冠傑]]於[[無綫電視]]特備節目《[[雙星報喜 (無綫電視節目)|雙星報喜]]》中首次唱出和兄長[[許冠文]]共同創作的《[[鐵塔凌雲]]》一曲，大獲好評，該曲字詞文雅、秀麗，擺脫一般粵語流行曲予人粗俗不堪之感，帶動粵語流行曲熱潮，蓬勃發展<ref name="autogenerated1">[http://web.hku.hk/~daaobeta/thesis.html 黃霑博士論文：粵語流行曲的發展與興衰] {{Wayback|url=http://web.hku.hk/~daaobeta/thesis.html |date=20070707175632 }} 2003年</ref>。1976年至1983年，當時流行曲多以[[電視劇]]主題曲為主<ref name="ChauWahShan">見於《消費文化：影像、文字、音樂》前言 - 作者：[[周華山]] - [[青文書屋]] 1990年11月第一版</ref>。

1980年代，除許冠傑外，[[關正傑]]、[[譚詠麟]]、[[梅艷芳]]、[[張國榮]]、[[羅文]]、[[陳百強]]、[[徐小鳳]]、[[林子祥]]等是當時樂壇著名歌手，而本土樂壇有潛力的新人亦不斷湧現，包括[[張學友]]、[[林憶蓮]]、[[葉蒨文]]和[[陳慧嫻]]等，香港[[音樂產業]]欣欣向榮。香港粵語流行曲通過[[電台]]播放而普及，加上形象包裝及[[演唱會]]熱潮，粵語流行曲逐漸建立自身獨特感<ref name="ChauWahShan" />。

=== 傳媒 ===
{{Main|香港傳媒}}
{{Further|香港報紙列表|香港電台廣播|香港電視廣播|親中媒體#香港}}
[[File:Broadcast Drive sign with ATV building in the background 20060725.jpg|thumb|[[九龍塘]][[廣播道]]，於[[香港1970年代|1970年代]]曾為三間電視台及兩間電台的所在地]]

== 官方象徵 ==
[[File:Bauhinia blakeana (Key West).jpg|thumb|香港[[市花]][[洋紫荊]]]]
{{Main|洋紫荊|香港品牌}}
1960年代，[[洋紫荊]]（{{lang|la|''Bauhinia blakeana''}}）獲[[市政局 (香港)|市政局]]採納為標誌，1965年獲定為[[香港市花]]<ref>{{cite web |title=香港市花洋紫荊的故事 |url=https://www.herbarium.gov.hk/tc/special-topics/hong-kong-plants/hong-kong-plants-detail/index-id-2.html |website=www.herbarium.gov.hk |date=2021-08-30 }}</ref>。後來在《基本法》草議過程中獲選為[[香港區旗]]和[[香港區徽]]的設計藍本，唯在基本法中被「去洋化」稱為[[紫荊花]]<ref>{{cite web |title=【回歸20載】洋紫荊被去洋化變紫荊花 學者：兩品種極大分別 |url=https://www.hk01.com/%E7%A4%BE%E6%9C%83%E6%96%B0%E8%81%9E/97709/%E5%9B%9E%E6%AD%B820%E8%BC%89-%E6%B4%8B%E7%B4%AB%E8%8D%8A%E8%A2%AB%E5%8E%BB%E6%B4%8B%E5%8C%96%E8%AE%8A%E7%B4%AB%E8%8D%8A%E8%8A%B1-%E5%AD%B8%E8%80%85-%E5%85%A9%E5%93%81%E7%A8%AE%E6%A5%B5%E5%A4%A7%E5%88%86%E5%88%A5 |website=www.hk01.com |date=2017-06-24 }}</ref>。[[香港基本法]]第十條中文版誤称香港區旗區徽上的花是「紫荆花」，但英文版仍稱為bauhinia。原文：「香港特別行政區的區旗是五星花蕊的紫荆花紅旗。The regional flag of the HKSAR is a red flag with a bauhinia highlighted by five star-tipped stamens. 」，中國内地媒体也依照“紫荆花”来宣传<ref>例子可見[http://news.xinhuanet.com/ziliao/2007-05/24/content_6145122.htm 新華網稱香港市花是「紫荊花」] {{Wayback|url=http://news.xinhuanet.com/ziliao/2007-05/24/content_6145122.htm |date=20130910221512 }}</ref>。

== 國際地位 ==
{{seealso|香港旅遊業}}
2025年，香港在[[瑞士]][[洛桑]][[國際管理學院]]的《[[世界競爭力年鑑]]》排名第3；在其《2025年世界人才排名》中，香港上升5位躍居全球第4，位列亞洲第1<ref>{{#invoke:cite| web |title=World Talent Ranking 2025 |url=https://www.imd.org/centers/wcc/world-competitiveness-center/rankings/world-talent-ranking/ |date=2025-09-08 |access-date=2025-09-19 |archive-date=2026-04-16 |archive-url=https://web.archive.org/web/20260416040548/https://www.imd.org/centers/wcc/world-competitiveness-center/rankings/world-talent-ranking/ |url-status=live }}</ref>。國際管理發展學院發布《2025年世界數碼競爭力排名》，香港排名全球第4位，繼2024年上升3位<ref>{{cite web |title=香港在數碼競爭力排名上升至全球第四位 |url=https://www.info.gov.hk/gia/general/202511/04/P2025110400194p.htm |website=www.info.gov.hk |date=2025-11-04 }}</ref>。

據[[世界貿易組織]]的《全球貿易展望與統計》報告，香港是2025年全球第五大商品貿易經濟體，較2024上升兩位<ref>{{cite web |title=香港躋身第五大貿易經濟體　再創佳績 |url=https://www.tkww.hk/a/202604/03/AP69ceff8be4b04773b06a74b1.html |website=大公文匯網 |date=2026-04-03 }}</ref>。 

根據[[透明国际]]的「2025年[[清廉指數]]」，香港的廉潔程度在全球182個國家／地區中排名第12位，比去年上升5位中<ref>{{cite web |title=「清廉指數」 |url=https://www.icac.org.hk/tc/intl-persp/ranking-and-research/corruption-perceptions-index/index.html |website=www.icac.org.hk |date=2026-12-02 }}</ref>。

在世界銀行集團發表的《「營商環境成熟度評估」2024報告》，香港屬表現最好的十個經濟體之一<ref>{{cite web |title=《「營商環境成熟度評估」2024報告》肯定香港為最佳營商地點之一 |url=https://www.info.gov.hk/gia/general/202410/03/P2024100300656.htm |website=www.info.gov.hk |date=2024-10-03 }}</ref>。

2025年，香港在英國Z/Yen集團與中國（深圳）綜合開發研究院聯合發布第40期《[[全球金融中心指數]]》報告中，總排名位居全球第3位、亞太區榜首<ref>{{cite web |title=香港於《全球金融中心指數》總排名維持第三位  |url=https://finance.mingpao.com/fin/instantf/20260916/1789549765425 |website=finance.mingpao.com |date=2026-09-16 }}</ref>。

香港在《世界經濟自由度2024年度報告》中獲評為全球[[經濟自由度指數|最自由經濟體]]<ref>{{cite web |title=財政司司長發布《香港營商環境報告：一國兩制 獨特優勢》記者會開場發言及答問內容（附圖／短片） |url=https://hongkong-invest.com/%E8%B2%A1%E6%94%BF%E5%8F%B8%E5%8F%B8%E9%95%B7%E7%99%BC%E5%B8%83%E3%80%8A%E9%A6%99%E6%B8%AF%E7%87%9F%E5%95%86%E7%92%B0%E5%A2%83%E5%A0%B1%E5%91%8A%EF%BC%9A%E4%B8%80%E5%9C%8B%E5%85%A9%E5%88%B6/ |website=hongkong-invest.com |date=2025-07-30 }}</ref>。

全球最大的外籍人士網路社區InterNations開展的Expats Insider排名顯示，在2024年外籍人士城市排名中，香港較2023年上升12位，在53個城市中排名第22，自2022年排名倒數第十（第46位）以來持續提升。外籍人士對海外生活也更加滿意，排名從2022年的墊底（第50位）上升至2024年的第12位。大多數指數表現均有所改善，其中表現最佳的是個人理財指數（第19位）<ref>{{#invoke:cite| web |title=Hong Kong Is a Roller Coaster Ride for Expats |url=https://www.internations.org/expat_insider/hong-kong-40499/ |website=InterNations |language=en |access-date=}}</ref>。

2026年3月11日，英國知名城市指南《Time Out》公佈2026年全球50座最佳城市排行榜，香港排第15<ref>{{#invoke:cite| web |title=2026全球最佳城市｜上海第2名僅輸南半球「這裡」 香港排15 |url=https://www.stheadline.com/realtime-world/3552138/ |website=星島頭條 |date=2026-03-12}}</ref>。5月28日，波士頓諮詢公司發表《2026年全球財富報告》，香港2025年財富管理規模增至2.95萬億美元，首次超越瑞士，位列全球首位<ref>{{cite web |title=香港去年財富管理規模23萬億 超越瑞士居首 |url=https://www.hkej.com/instantnews/hongkong/article/4412690/%E9%A6%99%E6%B8%AF%E5%8E%BB%E5%B9%B4%E8%B2%A1%E5%AF%8C%E7%AE%A1%E7%90%86%E8%A6%8F%E6%A8%A123%E8%90%AC%E5%84%84+%E8%B6%85%E8%B6%8A%E7%91%9E%E5%A3%AB%E5%B1%85%E9%A6%96 |website=信報網站 |date=2026-05-27}}</ref>。
