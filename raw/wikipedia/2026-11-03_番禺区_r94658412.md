'''{{zy|番|pān|ㄆㄢ|pun<sup>1</sup>}}{{zy|禺|yú|ㄩˊ|jyu<sup>4</sup>}}'''是[[中华人民共和国]][[广东省]][[广州市]]于2000年设立的[[副地级市|副地级]][[市辖区]]，位于广东省及广州市中南部，[[珠江]]口西北岸，处于[[珠三角]]腹地。番禺区土地肥沃、水陆交通便利，自古以来就是[[岭南地区]]的鱼米之乡。  旧时[[番禺 (古代)|番禺]]（番禺縣）与同样经济富庶、文化互通的[[南海区|南海]]、[[顺德区|顺德]]合称“[[南番顺]]”，是[[岭南文化]]的发源地之一, 區人民政府駐清河东路319号。

番禺於[[秦始皇]]三十三年（前214年）置縣，是[[嶺南文化]]的重要發源地和“[[海上丝绸之路|海上絲綢之路]]”起點之一，嶺南建築、嶺南畫派、粵劇曲藝、廣東音樂等廣府文化和鰲魚舞、飄色、乞巧、[[舞獅|醒獅]]等民間藝術源遠流長。番禺還是著名的美食之都，歷來有“食在廣州、味在番禺”的美譽。

==地理== 
番禺全区位于[[北回归线]]以南，[[北纬]]二十三度（23°N）横贯区境。

番禺以东面临狮子洋水道西面与[[佛山市]][[南海区]]、[[顺德区]]一江之隔，南与[[南沙区 (广州市)|南沙区]]一江之隔；北部为海拔50米以下低丘，与广州市[[荔湾区]]芳村、[[海珠区]]、[[黄埔区]]南部一江之隔。

地势主要为丘陵与平原交错之肥沃土地，由西部向东部以及南部倾斜，陆地最高点为西部[[大夫山]]之顶峰大乌岗，海拔约226公尺。主要河流有[[珠江]]、[[西江]]及[[北江]]支流等，区内河网星罗棋布。冬季时有[[咸潮]]溯流侵袭本区。

番禺属南[[亚热带海洋性季风气候]]，年均降水量1646.9毫米，年均温22.2℃，“无气象意义上之冬季”，年平均日照时数1807.6小时。热量充足，降水丰沛，因能达到“水热同期”亦有利于农作物生长。

==人口==
2021年，番禺區常住人口281.83萬人，户籍人口112.82萬人。

== 经济 ==
番禺区2017年[[国内生产总值]]达1972.24亿元人民币，社会消费品零售总额1229.35亿元人民币，分别位列广州十区二市第四及第三<ref>数据来源于广州市统计局公布的《广州统计信息手册（2018年）》</ref>。

===基建===

響應[[廣州市人民政府]]之“南拓”計劃以及“廣州時尚創意都會區”方針。番禺區在建有大量巨資投入之基建。

=== 主要产业 === 
====旅游业====
番禺区旅游业繁荣兴旺，旅游资源丰富，于2019年获评首批“国家全域旅游示范区”<ref>{{Cite news |title=广州松弛感的打开方式：永庆坊里寻广味 莲花山里赏秋荷 |url=https://www.xkb.com.cn/articleDetail/438889 |author=毛毛雨 |author2=谢源源 |work=新快报 |date=2025-09-30 |access-date=2025-09-30 |archive-url=https://web.archive.org/web/20250930155725/https://www.xkb.com.cn/articleDetail/438889 |archive-date=2025-09-30 |url-status=live}}</ref>，其中[[长隆旅游度假区]]更是成为全国首批[[中国国家5A级旅游景区|国家级5A景区]]，石楼镇莲花山及海鸥岛常年吸引珠三角各地民众前来祈福观光及假日[[农家乐]]之“好去处”；全区共有3个[[全国重点文物保护单位]]、4个省级、10个市级文物保护单位。

====工业====
同时番禺区工业也相当发达，为广州“南拓”重要发展区。主要产业有[[珠宝设计|珠宝设计加工业]]、[[光电工程|光电制造业]]、[[汽车制造|汽车制造业]]、动漫后期编辑业、[[机电工程|机电制造业]]、[[化工业|日化工业]]等。

===== 街机游戏产业 =====
1980年代，番禺的商人凭借沿海的优势，将许多港台地区和日本淘汰下来的[[街机]]卖到国内。1990年代中期，番禺已经成为中国内地最大的进口游戏机销售市场<ref>{{Cite web |title=政策渐现松动 国产街机开始出街占领繁华地带 |url=https://www.gameres.com/174545.html |website=第一财经周刊 |date=2011-10-14 |archive-url=http://web.archive.org/web/20250505145508/https://www.gameres.com/174545.html |archive-date=2025-05-05 |access-date=2026-02-27}}</ref>。2000年[[电子游戏机禁令]]之后，街机进口业务受到打击，一些企业转而从事给国外公司代工，或者开发原创街机游戏<ref>{{Cite web |title=华立科技董事长苏本立: 终端市场超千亿，游戏游艺比肩移动游戏 |url=https://m.jiemian.com/article/1899293.html |website=界面新闻 |date=2018-01-23 |access-date=2026-02-27}}</ref>。

2008年，广州星力动漫游戏产业园在番禺区蔡三村成立，后来成为中国最重要的街机产业基地，以研发和交易为主，产品占据全国70%市场份额<ref>{{Cite web |title=番禺蔡三村：最会“玩”的村，承包全球游戏游艺机｜广州百村观察 |url=https://www.nfnews.com/content/ky9ONDNB6G.html |website=南方+ |date=2025-03-25 |language=en |last=傅鹏；钟晓宇 |access-date=2026-02-27}}</ref><ref name=":0">{{Cite web |title=广州番禺，为世界创造一座超级“线下游艺王国” |url=https://huacheng.gz-cmc.com/pages/2025/05/26/SF13885768dc59f89c6cbc4b82bfd75c.html |website=广州日报新花城 |date=2025-05-26 |language=en |last=肖桂来 |access-date=2026-02-27}}</ref>。而在[[抓物機|娃娃机]]领域，番禺掌握全球90%的市场份额<ref>{{Cite web |title=走进粤商课程：探秘番禺娃娃机产业，解码粤商发展密码 |url=https://mba.gdufe.edu.cn/2025/0421/c10487a218697/page.htm |website=广东财经大学MBA学院 |date=2025-04-21 |access-date=2026-02-27}}</ref>。截至2025年，番禺东环街辖内共有动漫游戏游艺产业企业超500家，其中较为知名的有[[華立科技 (廣東)|华立科技]]、影擎电子、淘气猫、通利动漫、宝点数字等<ref name=":0" />。

====农业====
番禺农业经近年来持续的城市化发展，大片土地被政府或财团收购，规模早已大不如前。现大多数集约农地位于东部[[石碁镇]]、[[石楼镇 (广州市)|石楼镇]]，而石楼镇之[[海鸥岛]]是以临海渔业和基耕鱼塘为特色。

===知名企业===
番禺区内的知名企业有[[广州番禺电缆集团]]、[[广东长隆集团]]、[[广州立白企业集团]]、[[广州汽车|广汽乘用车有限公司]]、[[珠江鋼管|广州珠江钢管有限公司]]、[[箭牌|箭牌糖果(中国)]]、[[日立製作所|广东日立电梯]]、广州香江集团、三雄极光照明、自由鸟服装等。

===商业区===
[[File: Guangzhou Panyu Avenue N. Hanxi Tunnel.png|thumb|万博商圈]]
*市桥商圈：番禺区传统的商业中心区，位于[[市桥街道]]，坐落有大北路步行街、易发步行街、[[新大新公司|新大新百货]]、繁华盛世等商业地标。
*洛溪-大石（番禺新城）商圈：位于番禺区北部，与[[海珠区]]一桥之隔，随着房地产业兴旺而发展起来的商圈，有吉祥道步行街、新地购物广场、大石城、富丽城、建华汇等商业中心。
*万博商圈：位于华南板块[[番禺大道]]北与汉溪大道交界处，现有[[天河城]]、海印又一城、万博中心、番禺[[万达广场 (中国)|万达广场]]，在建有长隆生态旅游城、保利大都汇、奥园国际中心等大型商业综合体，是番禺区未来的商业中心。
*南站商圈：建设中的商业区，以[[广州南站]]为依托，以商务商贸为主导功能的现代服务业集聚区，届时将建有继[[花城汇]]後广州最大规模的地下空间商业区。

=== 房地产业 ===
[[File:Clifford Estates 20220430-09.jpg|thumb|祈福新邨]]
番禺区由于离广州中心区域较近，交通方便，有多条[[地铁]]及快速路接驳，环境较安静，空气质素及绿化环境较好，故房地产业十分发达，建有多个超千亩的大型社区，包括星河湾、丽江花园、洛溪新城、锦绣香江、[[祈福新邨]]、[[碧桂园|华南碧桂园]]、[[广州亚运城]]、广州[[雅居乐]]花园、[[南国奥林匹克花园]]、富豪山庄等，是不少广州人及香港人退休及渡假的乐园。 1997年以前屋苑的业主多是北上之港人，但现在屋苑的业主多为在广州市市区上班的白领。

== 历史 == 
{{main|广州历史|番禺 (古代)}} 
*1921年2月1日（民国十年），广州市政厅成立，[[廣州市 (中華民國)|广州]]正式设市。廣東省城內番禺县府保留運作。
*1933年（民国二十二年），番禺县府从廣東省城內外遷至禺南[[新造]]。
*1937年（民国二十六年） 原属番禺县的彬社、公和、敦和、崇文、沥滘、车陂、石牌、冼猎杨、龙洞堡（现在海珠区大部份、天河区、芳村区一部份地方）划归广州市管辖。 
*[[抗日战争]]期间番禺沦陷后，原县政府輾轉遷移去廣東[[三水区|三水]]、沙坪、威井等地，而[[汪精卫]]政府另立的番禺县府驻於广州市[[东山区 (广州市)|东山区]]。 
*1945年光復后，番禺县政府移治禺南[[市桥]]，初在先锋巷谢氏祠堂。
*1949年10月[[中国人民解放军|中共部隊]]進駐番禺，地方改由广东省珠江三角洲地方军事管制委员会管治。
*1950年3月至1952年11月，隶属珠江地区专员公署。
*1952年12月至1956年1月，隶属粤中行政公署。
*1953年6月，番禺县部分地区划入广州市，成立黄埔区。
*1956年2月起，隶属[[佛山地区|佛山]]专员公署。
*1958年1月，番禺县珠江河以北地区（禺东、禺北）划归广州市。
*1958年12月15日至1959年6月10日，番禺、[[顺德]]合并为番顺县，县治设原順德縣的縣治[[大良街道|大良镇]]，其间一度改隶[[广州专区|广州]]专员公署。
**番禺縣地域經歷多番調劃，到1958年為止，剩原禺南地區（前沙灣司及茭塘司大部，不包括海珠島），時年轄內人口25萬，耕地65萬畝。
*1959年6月10日恢复两县建置，并将[[中山县]]属的大岗、万顷沙、南沙、黄阁等地划属番禺（萬頃沙、南沙在民國到共和國初是歸屬[[東莞]]），县府沿设[[市桥]]，確定番禺現行地域格局。
*1975年1月，改隶广州市。

==社会民生 ==
===主要事件===
==== 撤市设区 ==== 
20世紀中期，將番禺（禺南地區）改劃为广州市辖区的构想当年在番禺民间、政府、公务员系统和国企都有极大反对声音，民间反对声音主要为不想番禺失去经济发展的自主性，亦担心番禺施行已在广州实施但不适合番禺的政策（如停止核发摩托车牌号），而公务员反对声音主要为担心工资下调，因当时番禺公务员工资平均水平远在广州市区公务员之上<ref>{{cite web |title=今日话当年:番禺撤县设市10年后楼价涨了10倍 |url=http://news.dichan.sina.com.cn/2013/06/19/765397.html |publisher=信息时报 |date=2013-06-19 |access-date=2022-09-17 |archive-date=2022-11-15 |archive-url=https://web.archive.org/web/20221115131816/http://news.dichan.sina.com.cn/2013/06/19/765397.html |dead-url=no }}</ref>。当时番禺政府曾组织专家学者从文化、历史、经济等各方面论证撤市设区不适合番禺，番禺人大代表于1999年广州市人大会议联名向大会提交《关于撤市改区后对番禺产生严重影响应慎重考虑的议案》<ref>[http://www.panyu.gov.cn/portal/jsp/pynj/nr.jsp?xxnrId=5879&catId=4035&isFist=true&year=2000 《番禺年鉴（2000）》] {{webarchive|url=https://web.archive.org/web/20140808053452/http://www.panyu.gov.cn/portal/jsp/pynj/nr.jsp?xxnrId=5879&catId=4035&isFist=true&year=2000 |date=2014-08-08 }}</ref>。其时广州市政府承诺以后将[[广州地铁三号线]]通往番禺，撤市设区后给予番禺政府三年行政独立过渡，撤市设区后将重点发展番禺等等作为谈判条件。自1997年广州市提出设区设想，双方拉锯数年。直到2000年5月21日国务院下发《关于同意广东省撤销番禺市和花都市设立广州市番禺区和花都区的批覆》，番禺最终撤市设区，改劃为广州市辖区。时任广州市市长林树森称，“这一步是我在广州工作期间城建方面最难的一步”<ref>[http://news.dichan.sina.com.cn/2010/10/25/228646.html 南方都市报《新区一路向南 老城华丽转身》] {{webarchive|url=https://web.archive.org/web/20140810060127/http://news.dichan.sina.com.cn/2010/10/25/228646.html |date=2014-08-10 }}</ref>。

==== 土地利用 ==== 
在1998年影响盛极一时的“梁柏楠”案<ref>{{Cite news |url=http://www.chinanews.com.cn/news/2005/2005-02-24/26/543383.shtml |title=《中华文摘》文章：霍英东梁柏楠恩怨再调查 |website=中国新闻网 |date=2005-02-24 |accessdate=2023-04-26 |archive-date=2023-04-26 |archive-url=https://web.archive.org/web/20230426103354/http://www.chinanews.com.cn/news/2005/2005-02-24/26/543383.shtml |dead-url=no }}</ref>中，番禺得知即将撤市设区时，担心自己一级财政管理权将收归广州市，因此以107元/平方米的均价、协议出让的形式，向开发商贱卖了大量土地，使得华南板块意外“诞生”。<ref>{{Cite web |url=https://www.aisixiang.com/data/7615.html |title=何铭思：梁柏楠的南沙发迹和霍英东开发南沙的艰难 |date=2005-07-19 |website=爱思想 |access-date=2023-04-26 |archive-date=2023-04-30 |archive-url=https://web.archive.org/web/20230430073032/https://www.aisixiang.com/data/7615.html |dead-url=no }}</ref>这一举动导致番禺后来出现了严重的公建配套短缺和城市功能的混乱。<ref name="番禺融入广州了吗">{{Cite news |url=http://news.sina.com.cn/c/2014-07-03/061930460523.shtml|title=设区14年番禺融入广州了吗|publisher=南方都市报|date=2014-07-03|accessdate=2023-04-26|archive-date=2023-04-26|archive-url=https://web.archive.org/web/20230426103354/http://news.sina.com.cn/c/2014-07-03/061930460523.shtml|dead-url=no}}</ref>有传言称，广州市接管番禺后的第一件事，就是封存番禺区国土部门的公章。<ref name="番禺融入广州了吗"/>

有鉴于此，番禺撤市设区后，广州市政府对番禺区收紧土地供应，而番禺工业多为密集式私营办厂的生产或加工，工业土地需求大，故政策制约了番禺的工业发展；广州市政府的政策禁止农村农民新增自建房，番禺很多有新增家庭人口的农民家庭的居住需求得不到满足；自合番禺设区之后，大量市区人口到番禺置业，使番禺成为广州的住宅区。另外很大部分在广州工作、生活或渡假的香港人也在番禺区置业，如[[祈福新邨]]与碧桂园等楼盘有八成住户是香港人。

==== 番禺“反烧” ====
指发生在2009年下半年番禺区居民自发抵制政府兴建垃圾焚烧发电厂的公共事件。2002年，广州市番禺区人大通过了番禺区生活垃圾处理系统规划，该规划确定了未来生活垃圾设施的选址地点；2006年8月，广州市规划局批准了番禺区生活垃圾综合处理厂的选址地点。到2009年9月，番禺市政林园局表示，生活垃圾发电厂的征地工作基本完成，地点规划在番禺区大石街会江村区域；10月，番禺垃圾焚烧发电厂有关情况新闻通报会召开，提出番禺垃圾焚烧厂环评启动，公众可参与；建设垃圾焚烧厂项目引发周边居民的广泛担忧，11月23日，番禺区三百余居民自发就垃圾焚烧厂选址问题向政府上访<ref>{{cite web|author=中国百科网|title=由番禺垃圾焚烧场选址事件引发的法学思考|url=http://www.chinabaike.com/t/31251/2014/0422/2110480.html|website= |access-date=2017-11-22|archive-url=https://web.archive.org/web/20171201030333/http://www.chinabaike.com/t/31251/2014/0422/2110480.html|archive-date=2017-12-01|dead-url=yes}}</ref>，期间，广州当地媒体亦就此议题发动广泛的舆论问政<ref>{{cite web|author=笑蜀|title=从垃圾危机中捕捉公民社会曙光|url=http://www.chinavalue.net/Finance/Article/2010-2-28/190552.html|website=www.chinavalue.net|accessdate=2017-11-22|archive-date=2017-12-01|archive-url=https://web.archive.org/web/20171201033040/http://www.chinavalue.net/Finance/Article/2010-2-28/190552.html|dead-url=no}}</ref>，事件遂发酵成一起全国性公共议题，引来广东省以外的媒体参与讨论，不少网友亦在社交媒体上对选址程序发起质疑，最终，社会舆论压力迫使番禺区政府将建厂项目延后实施，表示将重新进行垃圾焚烧厂选址。番禺“反烧”事件一般被视为大陆公民社会发育进程中的一大标志性事件，与“厦门反PX项目运动”并称。

==== 公共交通 ==== 
番禺区有番字號的地區內[[巴士|巴士網絡]]，並不鏈接广州城区巴士線網，广州城区有少量巴士線则进出番禺。番禺公共汽车有限公司发行的[[番禺莲花卡]]，只能用于番禺公交。早年[[羊城通]]不能用于乘坐番禺巴士，及後於2006年11月已可使用。由於使用番禺莲花卡乘搭番禺巴士价格为[[人民币]]1.50元，使用羊城通为2元<ref>[http://informationtimes.dayoo.com/html/2010-04/12/content_927976.htm 番禺花都有望享羊城通优惠]{{Wayback|url=http://informationtimes.dayoo.com/html/2010-04/12/content_927976.htm |date=20110727034703 }}（内文提到广州市财政只负责中心区的公交票价优惠，故在番禺使用羊城通没有优惠）</ref>，所以番禺莲花卡在番禺被广泛使用。直至2013年1月1日，番禺区内的巴士路線才开始正式执行与广州市中心区统一的公交票价优惠政策，即普通市民持同一张羊城通卡在一个自然月内乘搭巴士或地铁累计达到15次后，从第16次开始每次享受6折优惠<ref>{{cite web|author= |title=番禺区明年1月1日开始实施公交票价优惠政策|url=http://pyrb.dayoo.com/html/2012-12/31/content_2097088.htm|work=区党报番禺日报|date=2012-12-31|archive-date=2014-01-18|archive-url=https://web.archive.org/web/20140118225118/http://pyrb.dayoo.com/html/2012-12/31/content_2097088.htm|dead-url=no}}</ref>。番禺出租车也是独立，且不得进入广州市区载客。從2018年開始，因為番禺莲花卡跟不上全國一卡通的標準，開始逐步暫停使用，從2018年1月1日開始，暫停番禺卡充值服務。從4月1日開始，停止番禺卡刷卡服務，並且逐步進行羊城通設備更新。<ref>[http://www.sohu.com/a/210424856_430226 再见了，番禺公交卡！你是选择置换退款还是保留这份“记忆”呢？]{{Wayback|url=http://www.sohu.com/a/210424856_430226 |date=20180310200943 }} </ref>

===外来人口===
受广州市开放且限制甚少的人口政策影响，番禺区截至2014年底为止，累计有150多万名外来人员(流动人口)居住在本区。<ref name="人口">{{Cite web |url=http://gd.qq.com/zt2015/edu30/index.htm |title=2014年12月31日腾讯网吴岳冬对话段落 |accessdate=2017-09-20 |archive-date=2017-09-21 |archive-url=https://web.archive.org/web/20170921001706/http://gd.qq.com/zt2015/edu30/index.htm |dead-url=no }}</ref>主要来自于广东邻近之省份如[[湖南]]、[[广西]]、[[四川]]及[[江西]]等地，绝大部份为[[农民工]]及其随迁人员落地番禺工作、学习。流动人口已占番禺总人口的约53％，比例逐渐赶超本地人口。

===医疗===
截至2013年，番禺共有“三甲”医院2间，“二甲”医院5间，“一甲”等级（社区农村）医院138间。[[广州市番禺区何贤纪念医院|何贤纪念医院]]、[[广州医科大学附属番禺中心医院|番禺区中心医院]]、[[广州市番禺区中医院|番禺区中医院]]等区内优秀医疗资源几乎全部集中在市桥城区。城镇居民医疗保障制度以及新型[[农村合作医疗]]制度在全区均可通用。

=== 广播及电视 === 
{{main|番禺区电视台}}
番禺区有自己的合营电台和电视台（番禺广播电视中心，番禺区文广新局直接管辖）。番禺有线电视在其转播的高收视率境外电视台的广告时段及广东公共频道插播自行招揽的广告和自行制作的番禺新闻，不過已於2020年1月1日起停止。番禺台与广州市区的有线电视传媒没有互通<ref>[http://www.pycatv.tv/Html/tv/business/20100415160643.html 电视频道节目对照表] {{Wayback|url=http://www.pycatv.tv/Html/tv/business/20100415160643.html |date=20170731155635 }}，番禺有线电视</ref>。
