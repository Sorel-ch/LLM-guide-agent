'''金湾区'''是[[中国]][[广东省]][[珠海市]]下辖的[[市辖区]]，位于广东省中南部，珠海市西南部，地处珠江出海口磨刀门与崖门之间的南海之滨。与[[江门市]][[台山]][[大广海湾经济区]]隔岸相对，随着[[洪鹤大桥]]和[[黃茅海跨海通道|黄茅海跨海通道]]建成，金湾区被[[港珠澳大橋|港珠澳大桥]]西沿长线贯穿东西。金湾区成立于2001年4月4日，由原属珠海市香洲区的[[三灶镇 (珠海市)|三灶]]、[[南水镇|南水]]、小林镇，和原[[斗门区|斗门县]]的[[红旗镇 (珠海市)|红旗]]、[[平沙镇]]组成<ref>{{Cite web |title=国务院关于同意广东省撤销斗门县设立珠海市斗门区和金湾区的批复__2001年第16号国务院公报_中国政府网 |url=https://www.gov.cn/gongbao/content/2001/content_60784.htm |website=www.gov.cn |last=于卫亚 |access-date=2025-09-21}}</ref>。红旗和平沙两地两地前身均系[[华侨农场]]，由解放军、归国[[華僑華人|难侨]]、[[知识青年|知青]]等人在汪洋大海中开垦而成，直到1988年[[珠海市]]才获行政上管理两地的权力<ref>{{Cite journal |author=李锦昊 |author2=陈浩然 |author3=马凌 |title=越南难侨的身份协商与国家认同——基于珠海市原红旗华侨农场的案例 |journal=人文地理 |year=2003 |volume=1003-2398(2023)01-0056-08 |issue=总第189期 |page=56-63 |doi=10.13959/j.issn.1003-2398.2023.01.007}}</ref><ref>{{Cite web |title=广东省人民政府关于华侨农场领导体制改革的通知  广东省人民政府门户网站 |url=https://www.gd.gov.cn/zwgk/gongbao/1988/9/content/post_3355134.html |website=www.gd.gov.cn |access-date=2025-09-21}}</ref>。陆域面积约570.99平方公里，海域面积约3007.35平方公里。截至2024年底，全区常住人口46.15万人<ref name=":0">{{Cite web |title=珠海市金湾区人民政府 |url=https://www.jinwan.gov.cn/jinwan/qygk/index.html |website=www.jinwan.gov.cn |access-date=2025-09-21}}</ref>。

金湾区是珠海市三个行政区之一，辖区范围内有规上工业企业747家，数量位列全市第一<ref>{{Cite web |title=增长7%左右！金湾2025年目标确定！_腾讯新闻 |url=https://news.qq.com/rain/a/20250115A05CMT00 |website=news.qq.com |date=2025-01-15 |language=zh-CN |last=腾讯网 |access-date=2025-09-21}}</ref>。截至2024年底，全区共有高新技术企业599家、科技型中小企业373家、国家专精特新“小巨人”企业20家<ref>{{Cite web |title=GDP目标增7%！金湾区2025政府工作报告出炉 |url=https://pub-zhtb.hizh.cn/a/202503/27/AP67e4c2fae4b09576534ab25b.html |website=pub-zhtb.hizh.cn |access-date=2025-09-21}}</ref>。
