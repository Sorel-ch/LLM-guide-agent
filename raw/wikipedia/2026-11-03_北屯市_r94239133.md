'''北屯市'''是[[中华人民共和国]][[新疆维吾尔自治区]]下辖的[[县级市]]，与[[新疆生产建设兵团第十师]]实行“[[师市合一]]”，位于[[阿勒泰地区]]境內[[阿勒泰市]]和[[福海县]]之间，面积911平方公里，人口约10.5万人，市人民政府驻[[北屯镇]]团结路300号。

== 歷史 ==
十师北屯市的前身是中国人民解放军二十二兵团骑兵第七师，1953年6月改番号为中国人民解放军新疆军区农业建设第十师，1955年1月建制一度撤销，1959年1月新疆生產建設兵團恢复农十师，同年4月5日在[[巴里巴盖乡|巴里巴盖]]正式成立，1958年8月選定多勒布爾津為师部新駐地，因是中国最北的屯垦戍边重地而命名為“北屯”，1959年5月十师抽调基建人员从巴里巴盖前往北屯開始建設，1959年11月1日农十师师部正式迁至北屯。<ref name=a1>{{cite web |title=第十师北屯市概述 |url=http://www.bts.gov.cn/c/2023-05-06/2864579.shtml |website=第十师北屯市政府网 |publisher=第十师北屯市史志办 |accessdate=2023-11-18 |date=2023-05-06 |archive-date=2023-11-18 |archive-url=https://web.archive.org/web/20231118053159/http://www.bts.gov.cn/c/2023-05-06/2864579.shtml |dead-url=no }}</ref><ref name=b2>{{cite web |title=新疆北屯市历史沿革 |url=https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806853.html |website=中国小康网 |accessdate=2023-11-18 |date=2019-12-09 |archive-date=2023-11-18 |archive-url=https://web.archive.org/web/20231118053205/https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806853.html |dead-url=no }}</ref>

1971年1月，北屯镇革命委员会成立，1974年改为北屯镇人民政府，隶属阿勒泰县，1975年5月兵團农十师建制撤销，成立阿勒泰地区农垦局。1982年4月1日恢复原建制。2011年12月20日中國國務院批准设立自治区直辖的县级北屯市，同年12月28日北屯市正式成立，2012年12月13日新疆生产建设兵团农业建设第十师更名为新疆生产建设兵团第十师，2019年9月16日北屯市由團場轉設的双渠镇、丰庆镇和海川镇正式成立。<ref name=a1/><ref name=b2/>

==地理==
境内平原多为[[额尔齐斯河]]与[[乌伦古河]]形成的冲积平原，得仁山位于市中心。地表水水源有河流、湖泊和自然坑塘，境内有额尔齐斯河、乌伦古河等58条河流。年平均气温3.6-3.9°C，极端最低气温零下49度，年降水量87-188.6毫米，蒸发量为1900-2300毫米，无霜期年平均约120天。<ref name=c3>{{Cite ZGBK |id=75780 |title=中国大百科全书 |editor=中国大百科全书编委会 |accessdate=2023-11-18 |chapter=北屯市 |archive-date=2023-11-18 |archive-url=https://web.archive.org/web/20231118053157/https://www.zgbk.com/ecph/words?SiteID=1&ID=75780&Type=bkzyb&SubID=76647 |dead-url=no}}</ref><ref>{{cite web |title=新疆北屯市地理环境 |url=https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806855.html |website=中国小康网 |accessdate=2023-11-18 |date=2019-12-09 |archive-date=2023-11-18 |archive-url=https://web.archive.org/web/20231118053206/https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806855.html |dead-url=no }}</ref>

土壤由额尔齐斯河冲积而成，多为耕层浅的砾质砂土和轻壤土。主要植被有[[大籽蒿]]、[[芨芨草]]、[[猪毛菜]]、[[甘草]]、[[芦苇]]、[[苦豆子]]、[[梭梭]]、[[胡杨]]、[[白桦]]、[[沙拐枣]]等，野生动物有[[狐狸]]、[[狼]]、[[熊]]、[[河狸]]、[[猞猁]]、[[紫貂]]、[[水獭]]、[[雪鸡]]、[[羚羊]]、[[鹿]]等，[[白斑狗鱼]]、[[河鲈]]、[[江鳕]]、[[欧鳊]]为中国珍稀鱼种。<ref name=c3/>

==經濟==
农业主产[[小麦]]、[[水稻]]、[[玉米]]、[[向日葵]]等，经济作物主要为[[棉花]]、[[甜菜]]、[[西瓜]]、[[辣椒]]等，畜牧业以养殖牛、猪、羊等牲畜为主，拥有可养殖水面126平方千米，主要中药材有[[鹿茸]]、[[党参]]、[[黄芪]]、[[贝母]]、[[雪莲花]]、[[阿魏]]、[[甘草]]、[[麻黄]]、[[五灵脂]]等。2021年北屯市实现地区生产总值71.7465億元，其中第一产业增加值19.5903億元，第二产业增加值16.6980億元，第三产业增加值35.4583億元，人均生产总值69,507元。<ref name=c3/><ref name=d4>{{cite web |title=新疆生产建设兵团第十师北屯市2021年国民经济和社会发展统计公报 |url=http://www.bts.gov.cn/c/2022-03-31/2842906.shtml |website=第十师北屯市政府网 |accessdate=2023-11-18 |date=2022-03-31 |archive-date=2025-04-25 |archive-url=https://web.archive.org/web/20250425101748/http://www.bts.gov.cn/c/2022-03-31/2842906.shtml |url-status=live }}</ref>

==社會==
2021年末北屯市总人口104,811人，其中男性53,196人，女性51,615人，出生率4.18‰，死亡率3.23‰，人口自然增长率0.95‰。[[216国道]]、318省道、319省道在此交会，[[奎屯—阿勒泰高速公路]]过境，[[奎北铁路]][[北屯市站]]于2011年6月份启用，名胜有国家AAA级旅游景区图瓦民俗文化旅游村和布伦托海海滨风情旅游区。<ref name=c3/><ref name=d4/><ref>{{cite web |title=新疆北屯市交通概况 |url=https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806858.html |website=中国小康网 |accessdate=2023-11-18 |date=2019-12-09 |archive-date=2023-11-18 |archive-url=https://web.archive.org/web/20231118053514/https://xianyu.chinaxiaokang.com/beitunshidiji/beitunshi/yilan/2019/1209/806858.html |dead-url=no }}</ref>
