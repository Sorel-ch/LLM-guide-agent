'''芷江侗族自治县'''，简称'''芷江县'''，位于[[湖南省]]西部，[[云贵高原]]东缘。區域总面积2096平方公里，总人口約31万人，县城芷江镇距[[怀化市]]仅39公里。芷江为[[国家历史文化名城]]，素有“滇黔门户、黔楚咽喉”之称。旅游景点有[[明山风景区]]，[[抗日胜利芷江洽降旧址#中国人民抗日战争胜利受降纪念馆|芷江中国人民抗日战争胜利受降纪念馆]]。[[自治县]]人民政府駐[[芷江镇]]。

== 历史 ==
芷江古属“[[五溪蛮]]地”。[[西汉]][[汉高祖|高祖]]五年（前202年）始置“无阳县”，县治在㵲阳河北、今芷江境内，县境广大，包含今怀化市南部大部。[[西晋]]改称“舞阳县”，[[南齐]]改称“潕阳县”，[[南梁]]改称“[[龙标县]]”。[[唐朝]][[先天 (年号)|先天]]二年（713年），析龙标县置'''潭阳县'''，隶沅州，县治位于今[[新店坪镇]]一里街村。

唐末，五溪地区为当地土著势力所据有。[[五代]][[长兴 (年号)|长兴]]三年（932年），[[马楚]]析沅州谭阳县置[[洽州|懿州]]，属[[羁縻州]]，为南江田氏所据。[[北宋]][[熙宁]]六年（1073年），宋军攻占懿州，次年改羈縻为[[郡县制|郡县]]：以谭阳县地置'''卢阳县'''，治懿州新城，即今芷江县城；置[[沅州]]，属[[荆湖北路]]，治卢阳县。

[[明朝|明]][[洪武]]九年（1376年），[[沅州府]]被降为沅州，隶属于[[辰州路]]，下辖[[黔陽縣|黔阳县]]、[[麻阳县]]；卢阳县被省，其地直属于沅州，仍为州治。[[明平云南之战|明平云南]]之后，沅州作为楚黔滇大道在[[湖廣等處承宣布政使司|湖广]]的最后一站，地位紧要。嘉靖二十七年（1548年），右都御史[[张岳 (正德进士)|张岳]]受命[[总督]]湖广、贵州、四川、云南军务，征讨[[腊尔山镇|腊尔山]]苗民叛乱，将总督府设于沅州，直到四十二年（1563年）苗民安宁后方裁撤。万历二十八年（1600年），为征讨[[播州之役|播州杨应龙叛乱]]，明廷设置[[偏沅巡抚]]，驻于沅州，根据战局情况或移驻[[偏桥卫]]（今[[施秉县]]）；[[奢安之亂|奢安之乱]]期间又再次设立。

[[清朝|清]][[康熙]]三年（1664年），湖广分治，沅州随辰州府归[[湖南等處承宣布政使司|湖南]]，偏沅巡抚移驻长沙。[[雍正]]八年（1730年），沅州改为[[直隸州]]。[[乾隆]]元年（1736年），沅州升为沅州府，在府治所在地新设[[治所同城|附郭]]之'''芷江县'''。嘉庆二十二年（1817年），因县境内六里地方要求改属贵州省[[玉屏侗族自治县|玉屏县]]，最终折衷析置[[晃州厅|晃州直隶厅]]。

1937年，[[中国抗日战争]]全面爆发后，[[怀化芷江机场|芷江机场]]紧急扩建，成为重要的空军基地。1942年，芷江县与黔阳县、[[辰溪县]]各划出部分地区，新置[[懷化縣]]。1945年4月，侵华日军为破坏芷江机场，发起[[湘西会战]]，结果受挫于[[中華民國國軍|国军]]。当年8月15日，[[日本投降|日本无条件投降]]，21日，中、日军方代表在芷江会面，[[芷江受降|洽谈受降细节]]。

1950年，设立[[会同专区]]，治芷江县。1952年8月，会同专区、[[沅陵专区]]撤销，成立[[芷江专区]]，即今[[怀化市]]前身，治芷江县。11月，专区迁治于黔阳县[[安江镇]]，改名黔阳专区。1986年，芷江县改称“芷江侗族自治县”，实行[[民族区域自治制度|民族区域自治]]。

== 人口和民族 ==
2020年末，全县常住人口为307661人<ref>{{Cite web|title=中國: 湖南省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/hunan/admin/|access-date=2023-11-03|website=www.citypopulation.de|archive-date=2023-11-03|archive-url=https://web.archive.org/web/20231103234706/https://www.citypopulation.de/zh/china/hunan/admin/|dead-url=no}}</ref>，与2010年第六次全国人口普查的339161人相比，减少31500人，下降9.29%。

2004年，全县总人口为354,562人，其中[[侗族]]等少数民族人口占50％以上。芷江县侗族主要分布在该县南部和西部。三道坑镇大部分、芷江镇东北部、晓坪乡一线以东为主要为汉族聚居区，此线以西则为侗族聚居区。另外公坪镇的[[土家族]]较多，而碧涌镇等地还有不少[[苗族]]村寨和人口。

全县[[国内生产总值]]为177,665万元（2004）[https://web.archive.org/web/20051123113329/http://www.hntj.gov.cn/tjgb/xqgb/hhgb/default.htm]。

== 地理 ==
芷江地处[[雪峰山脉]]、[[武陵山脉]]南麓和[[云贵高原]][[苗岭山脉]]东延末端。相邻[[县级行政区|县市]]有，西与[[贵州省]][[铜仁市]][[万山区]]、[[天柱县]]和怀化市[[新晃侗族自治县]]接壤，南与[[会同县]]、[[洪江市]]为邻，东连[[中方县]]、[[鹤城区]]，北接[[麻阳苗族自治县]]。

芷江属亚热带季风气候，冬湿冷夏闷热，天气终年湿润，日照较低。1月平均气温4.9℃，7月平均气温27.2℃，年平均气温16.5℃。降雨集中，4－6月降雨量占全年46%，秋冬降雨明显减少。

== 旅游 ==
境内有“形似神农架、神如九寨沟”的小九寨五郎溪三道坑风景区，还有明山叠单、茅丛河漂流、[[㵲阳河]]生态长廊、蟒湖山水人家等。

境内有旧石器、新石器时代的古文化遗址；有出土的商周时期的[[编钟]]、青铜凤形器等珍品；[[宋代]]古城墙、护城河；[[明代]]所建的龙津风雨桥横卧于舞水；内陆最大的[[妈祖]]庙——天后宫矗立于舞水之滨；文蕴丰厚的文庙和奎文阁等古建筑群分布于县城各处。另外，有第二次世界大战反法西斯胜利的标志性建筑芷江抗战胜利受降纪念馆以及盟军第二大机场[[芷江机场]]、中美空军联队俱乐部、受降堂、[[中国工农红军]]第二、六军团司令部旧址、[[湘西剿匪]]烈士纪念塔等一大批纪念性建筑。
