'''沾益区'''在[[云南省]]东部、[[南盘江]]上游，是[[曲靖市]]下辖的一个[[市辖区]]。全区面积2815平方千米，2020年总人口40.53万人，區政府駐西平街道。沾益区是[[珠江]]的发源地。

== 历史 ==
[[西汉]]属[[益州郡]][[味县]]管辖。东晋至隋朝为[[爨氏]]所统治。[[南诏]]后期设磨弥部，属拓东节度；[[大理国]]属石城郡。[[元朝|元]][[至元 (元世祖)|至元]]十三年（1276年），设立霑益州，属[[曲靖路]]，州治位于石梁（今[[宣威市]]境内）。天启五年（1625年），霑益州治所从石梁迁移至交水城（今[[西平街道]]）。[[清]][[雍正]]五年（1727年），分设霑益州和[[宣威州]]。<ref name="曲靖市政区大典">{{Cite book |title=曲靖市政区大典 |publisher=云南人民出版社 |location=昆明 |year=2014 |isbn=978-7-222-12039-6 |page=438 |editor=《曲靖市政区大典》编纂委员会}}</ref><ref name="历史文化">{{Cite web |title=历史文化 |url=http://www.zhanyi.gov.cn/news/zygk/9722.html |website=曲靖市沾益区人民政府 |date=2025-05-29 |language=zh |url-status=live |archive-url=http://web.archive.org/web/20260105192657/http://www.zhanyi.gov.cn/news/zygk/9722.html |archive-date=2026-01-05 |access-date=2026-02-18}}</ref>

民国二年（1913年），废除州制，改为霑益县，属[[滇中道]]，后于1929年直属云南省。1950年3月，沾益县解放，属[[曲靖专区]]。1958年，撤销沾益县并入[[麒麟区|曲靖县]]，县政府驻西平镇（今西平街道）；同年11月，[[马龙县]]亦并入。1961年，马龙县析出恢复建制。1965年，沾益县从曲靖县析出，恢复为沾益县。1970年属[[曲靖地区]]。1983年9月，撤销沾益县与曲靖县，合并设立县级曲靖市。1997年5月，撤销曲靖地区，设立地级曲靖市，原县级曲靖市分设为麒麟区和沾益县，属曲靖市。<ref name="曲靖市政区大典" /><ref name="历史文化" />2016年3月20日，国务院批复同意撤销沾益县，设立曲靖市沾益区<ref>{{Cite web |title=中华人民共和国二〇一六年县级以上行政区划变更情况 |url=http://xzqh.mca.gov.cn/description?dcpid=2016 |website=中华人民共和国民政部 |url-status=dead |archive-url=https://web.archive.org/web/20170224133141/http://xzqh.mca.gov.cn/description?dcpid=2016 |archive-date=2017-02-24 |access-date=2026-02-18}}</ref><ref>{{Cite web |title=云南省人民政府关于撤销沾益县设立曲靖市沾益区的通知 |url=http://www.yn.gov.cn/zwgk/zcwj/zxwj/201604/t20160419_143017.html |website=云南省人民政府门户网站 |date=2016-04-13 |language=zh-cn |url-status=live |archive-url=https://web.archive.org/web/20200713094633/http://www.yn.gov.cn/zwgk/zcwj/zxwj/201604/t20160419_143017.html |archive-date=2020-07-13 |access-date=2026-02-18}}</ref>，同年6月1日正式挂牌成立<ref name="历史文化" /><ref>{{Cite web |title=云南曲靖沾益县撤县设区 |url=https://www.chinanews.com.cn/m/df/2016/06-01/7891304.shtml |website=中国新闻网 |date=2016-06-01 |author=马骞 |author2=陈静 |access-date=2026-02-18}}</ref>。

[[沾益机场]]在抗日战争期间曾经有美国援华“[[飞虎队]]”进驻，机型有P-38等。该机场现在已经废弃。

==经济==
2022年，沾益区[[国内生产总值|生产总值]]达395.50亿元，按可比价格计算，比上年增长7.6%。其中[[第一产业]]增加值59.84亿元，增长5.1%；[[第二产业]]增加值170.99亿元，增长10.8%；[[第三产业]]增加值164.67亿元，增长5.7%。三次产业结构为15.1∶43.2∶41.7。人均生产总值98,274元。城乡常住居民人均可支配收入分别为44,112元、19,764元。职工年平均工资110,525元。地方一般公共预算收入8.47亿元，人均2,105元。地方一般公共预算支出28.68亿元，人均7,127元。<ref>{{Cite book|title=《云南统计年鉴2023》|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

==人口==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，沾益区总人口（常住人口）共有405,305人，城镇人口194,953人（占48.10%），乡村人口210,352人（占51.90%）。共有男性210,218人、女性195,087人，[[人類性別比|性别比]]为107.76。0—14岁人口共71,307人（占17.59%），15—59岁人口共267,903人（占66.10%），60岁及以上人口共66,095人（占16.31%），其中65岁及以上人口共47,089人（占11.62%）。大学专科学历及以上人口有35,346人，15岁以上的文盲有17,819人，占15岁以上人口的5.34%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>
