'''毕节市'''是[[中华人民共和国]][[贵州省]]下辖的[[地级市]]，位于贵州省西北部，[[乌江]]上游，[[黔]][[滇]][[川]][[四川省]]三省交界。东与[[遵义]]、[[贵阳]]两市相接，南连[[安顺]]、[[六盘水]]两市，西南与[[云南省]][[曲靖市]]接壤，北与云南省[[昭通市]]及[[四川省]][[泸州市]]相邻。地处[[云贵高原]]中部，[[乌蒙山]]蜿蜒境内，地貌以[[喀斯特地形]]和高山丘陵为主。[[乌江]]发源于市境，[[赤水河]]流经东缘，[[六冲河]]、[[二道河 (赤水河支流)|二道河]]、[[白水河 (南盘江)|白水河]]、[[牛栏江]]、[[可渡河]]等流经境内。全市总面积26,849平方公里，人口660.61万，是贵州省人口最多的[[地级行政区]]，市人民政府驻[[七星关区]]。

== 名称典故 ==
“毕节”是[[彝语]]“比跻”的谐音，乃[[彝族]]部族名。后来亦有不同的说法。清[[爱必达]]《黔南识略》卷二十六：毕节县“近城一水俨若壕堑，昔人谓之毕川，邑之得名以此。或-{云}-，元初设驿，时逢除夕，故名曰毕节。”清光绪《毕节县志》卷二：“毕节筑城以十二月晦日始成，因名毕节。”

== 历史沿革 ==
[[周朝]]时为[[古蜀|蜀国]]东南境，[[秦朝]]置[[巴郡]]。[[汉朝]]属[[益州]]之[[牂牁]]、[[犍为]]两郡所辖，[[蜀汉]]分属牂牁、[[朱提郡]]。[[西晋]]分益州置[[宁州]]，毕节市分属牂牁、朱提、建宁三郡。[[南北朝]]之宋、齐、梁均为宁州所辖。[[隋朝]]为[[爨氏]]之卢鹿部。[[唐朝]]先属[[昆明国]]，后为[[黔州都督府]]属地。[[五代]]时分属[[郝州]]、[[晖州]]、[[龚州]]、[[寶州 (黔州都督府)|宝州]]、[[禄州 (唐朝)|禄州]]。

[[宋朝]]时，毕节东部属罗氏鬼国、乌撒、毗那等部。[[元朝]]为亦溪不薛宣慰司、乌撒乌蒙宣慰司所治。[[明朝]]分属水西宣慰司、乌撒军民府、[[永宁宣抚司]]和乌撒、毕节、赤水、永宁四卫。

[[清]][[康熙]]五年（1666年）置大定（今大方）、黔西、平远（今织金）三府，改四川乌撒土府为[[威宁府]]；二十二年（1683年）降黔西、平远二府为州，隶属[[大定府 (清朝)|大定府]]；二十六年（1687年）降大定府为州，隶属威宁府，领大定、平远、威宁三州和毕节、永宁二县。[[雍正]]七年（1729年）升大定州为府领黔西、平远、威宁三州和毕节县、水城厅。

[[中华民国]]成立后，境内所有县划归[[贵西道]]管辖；民国24年（1935年），贵州省政府设毕节第四行政督察专员公署，辖毕节、[[大定縣|大定]]、[[黔西]]、[[威宁]]、[[水城县]]；民国30年（1941年）在原建制析设[[纳雍]]、[[金沙縣|金沙]]二县，织金县改隶第四行政督察区；民国31年（1942年）析威宁县东北部置[[赫章县]]，至此贵州第四行政督察区共辖毕节、大定、黔西、金沙、纳雍、水城、威宁、赫章9县。

[[中华人民共和国]]成立后，成立贵州省人民政府毕节区行政督察专员公署，辖民国末第四行政督察区所属各县。1955年，威宁县改建为[[威宁彝族回族苗族自治县]]。1958年，[[大定县]]更名为[[大方县]]。1970年，[[水城县]]并入[[水城特区]]，划归[[六盘水地区]]管辖，同年毕节专区更名[[毕节地区]]，辖毕节、大方、黔西、金沙、纳雍、赫章县和威宁彝族回族苗族自治县。

1994年，毕节撤县建县级市。2007年，成立贵州[[百里杜鹃风景名胜区]]，为正县级派出机构。

2011年10月，[[中华人民共和国国务院|国务院]]批准撤销毕节地区和县级毕节市，设立地级毕节市，原县级毕节市改为[[七星关区]]<ref>[http://cpc.people.com.cn/GB/64093/64387/16226005.html 国务院批准毕节撤地设市] {{Wayback|url=http://cpc.people.com.cn/GB/64093/64387/16226005.html |date=20160303205759 }}，中国共产党新闻网，2011年11月12日。</ref>。2011年12月27日，举行撤地设市挂牌仪式<ref>{{cite web |title=毕节撤地设市挂牌仪式举行 |url=http://www.bjsyq.cn/article/201112/3373.htm |website=毕节试验区 |accessdate=2020-07-27 |archive-date=2020-07-27 |archive-url=https://web.archive.org/web/20200727170536/http://www.bjsyq.cn/article/201112/3373.htm |dead-url=no }}</ref>。

== 地理 ==
毕节市地处贵州省西北部，东部和南部与本省[[遵义市]]、[[贵阳市]]、[[安顺市]]、[[六盘水市]]接壤，西部和北部与[[云南省]][[昭通市]]、[[四川省]][[瀘州市]]毗邻。位于川、滇、黔三省结合部，东经105°36′——106°43′，北纬26°21′——27°46′之间。境内大部属[[乌蒙山]]区，以[[喀斯特地形]]和高山丘陵为主。[[乌江]]、[[北盘江]]、[[赤水河]]皆发源于此；还有[[六冲河]]、[[二道河 (赤水河支流)|二道河]]、[[白水河 (南盘江)|白水河]]、[[牛栏江]]、[[可渡河]]、[[白甫河]]（白布河）等河流。平均海拔1600米，最高点为赫章县与威宁县交界的小韭菜坪，海拔2900.6米。

== 人口 ==
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为6,899,636人<ref>{{cite web |author1=毕节市统计局、毕节市第七次全国人口普查领导小组办公室 |title=毕节市第七次全国人口普查公报 |url=https://www.bijie.gov.cn/bm/bjstjj/zwgk/tjsj/tjgb/202106/t20210602_74711211.html }}{{Dead link}}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的6,537,498人相比，十年共增加了362,138人，增长5.54%，年平均增长率为0.54%。其中，男性人口为3,544,009人，占总人口的51.37%；女性人口为3,355,627人，占总人口的48.63%。总人口性别比（以女性为100）为105.61。0－14岁的人口为1,954,390人，占总人口的28.33%；15－59岁的人口为3,990,483人，占总人口的57.84%；60岁及以上的人口为954,763人，占总人口的13.84%，其中65岁及以上的人口为711,111人，占总人口的10.31%。居住在城镇的人口为2,906,332人，占总人口的42.12%；居住在乡村的人口为3,993,304人，占总人口的57.88%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为5,072,420人，占73.52%；各[[少数民族]]人口为1,827,216人，占26.48%。与2010年第六次全国人口普查相比，汉族人口增加226,721人，增长4.68%，占总人口比例下降0.6个百分点；各少数民族人口增加135,417人，增长8%，占总人口比例增加0.6个百分点。其中，[[苗族]]人口增加49,477人，增长11.04%，占总人口比例增加0.36个百分点；[[彝族]]人口增加15,648人，增长3.33%，占总人口比例下降0.15个百分点；未定族称人口（[[中国未识别民族|未识别民族]]）增加13,388人，增长3.04%，占总人口比例下降0.16个百分点。

== 交通 ==
目前经过毕节的高速公路有{{China Expwy Name|G56}}、{{China Expwy Name|G76}}、S20毕威高速、S79毕镇高速、S82大方高速，境内另有{{中国国道名|321}}、{{中国国道名|326}}经过。

2019年12月开通的[[成贵客运专线]]在毕节境内设[[毕节站]]、[[大方站 (贵州省)|大方站]]、[[黔西站]]，结束了毕节不通铁路的历史，此前已建成的几段铁路均为“擦边”、“过境”性质<ref>[http://www.gzbj.cn/news/bjsyq/2013/0417/content_12083.shtml 毕节铁路建设迎来发展春天] {{Wayback|url=http://www.gzbj.cn/news/bjsyq/2013/0417/content_12083.shtml |date=20130424042757 }}</ref>。同时在建的还有毕（节）水（城）兴（义）铁路毕节至水城段、昭通－威宁－毕节－金沙－遵义等铁路<ref>[http://news.gog.com.cn/system/2010/12/23/010979615.shtml “三纵三横”铁路规划使毕节通江达海] {{webarchive|url=https://web.archive.org/web/20130502095338/http://news.gog.com.cn/system/2010/12/23/010979615.shtml |date=2013-05-02 }}</ref>。

[[毕节飞雄机场]]位于市区东面，每周有多个航班来往全国主要城市。

==经济==
===毕节试验区===
毕节是贵州省最贫困落后的地区之一，直到1987年，全区人均工农业总产值仅为288.9元，农民人均收入只184元，人均粮食不足200公斤，未解决温饱人口达300余万，农村贫困人口占其总人口的53.68%，人口自增率21.29‰，森林覆盖率仅为8.53%。1988年6月，时任贵州省委书记的[[胡锦涛]]亲自倡导创建毕节“开发扶贫、生态建设”试验区。着手解决生态恶化、水土流失、人口膨胀、粮食短缺等问题。

=== 经济总量 ===
2019年，全市完成[[地区生产总值]]1901.36亿元，同比增长8.0%。人均地区生产总值28378元，同比增长7.5%<ref>{{cite web |author1=毕节市统计局 国家统计局毕节调查队 |title=毕节市2019年国民经济和社会发展统计公报 |url=http://www.bijie.gov.cn/bm/bjstjj/gk_5127345/xxgkml_5127355/tjsj_5127357/tjgb_5127358/202004/t20200428_57912076.html |website=毕节市人民政府 |accessdate=2020-07-20 |archive-date=2020-07-20 |archive-url=https://web.archive.org/web/20200720232218/http://www.bijie.gov.cn/bm/bjstjj/gk_5127345/xxgkml_5127355/tjsj_5127357/tjgb_5127358/202004/t20200428_57912076.html |dead-url=no }}</ref>。
