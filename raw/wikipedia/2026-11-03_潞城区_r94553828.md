'''潞城区'''是[[中华人民共和国]][[山西省]][[长治市]]的一个[[市辖区]]。位于山西东南部、[[浊漳河]]流域。面积612.5平方公里，區人民政府駐潞華街道城內正街16號。

== 历史 ==
[[殷商]]时，[[微子]]封于微地，称“微子国” <ref name="autogeneratedlc">{{Cite web |url=http://www.lc.gov.cn/more.aspx?pid=16&id=26 |title=潞城市历史沿革 |access-date=2013-10-23 |archive-date=2014-08-24 |archive-url=https://web.archive.org/web/20140824191028/http://www.lc.gov.cn/more.aspx?pid=16&id=26 |dead-url=yes }}</ref>，即今山西省潞城市东北部（其封地后迁徙至今山东省梁山西北一带，参见“[[微子]]”），现存一镇名叫“微子镇”（镇上有一地名叫“[[比干]]岭”）。

[[西周]]时，此地有“潞子国”<ref name="autogeneratedlc"/><ref>[《春秋舆图》： “赤狄潞氏国在(潞城)县东北四十里。”]</ref>。

[[春秋时期|春秋]]时，此地属“潞子婴儿国”<ref name="autogeneratedlc"/>。“潞”来源于当地一条河的名字“潞水”<ref>[《上党记》：“潞，浊漳河也。]</ref>。

[[秦朝|秦]]时置“潞县”，归[[上党郡]]管理。

[[汉朝|汉]]为“潞县”。

[[北魏]]时[[太平真君]]十一年（450年）废“潞县”改置“刈陵县”，属上党郡，后属[[襄垣郡]]。

[[隋朝|隋]][[开皇]]十六年（596年），废“刈陵县”，始称“潞城县”。

此后，历史上宋、元、明、清时期皆为“潞城县”。

1954年与长治县合并，称为“潞安县”。

1958年撤消“潞安县”，两地分别划归长治市和黎城县。

1962年，合并长治市的原潞城县部分行政区域，恢复设置，仍称“潞城县”。

1994年4月26日，潞城县撤县设市，改称“潞城市”<ref name="autogeneratedlc"/>。

2018年6月19日，[[中华人民共和国国务院|国务院]]批准撤销潞城市，设立长治市潞城区<ref>{{cite web|title=中华人民共和国二〇一八年县级以上行政区划变更情况|url=http://xzqh.mca.gov.cn/description?dcpid=2018|archive-url=https://web.archive.org/web/20190710213043/http://xzqh.mca.gov.cn/description?dcpid=2018|archive-date=2019-07-10|accessdate=2020-07-12|website=中华人民共和国民政部网|dead-url=yes}}</ref>；11月23日，潞城区正式挂牌成立<ref>{{Cite web|date=2018-11-24|title=长治潞州区等“新四区”11月23日同步挂牌|url=http://m.xinhuanet.com/sx/2018-11/24/c_1123761303.htm|access-date=2024-01-07|website=山西晚报|via=新华网|archive-date=2024-01-07|archive-url=https://web.archive.org/web/20240107144127/http://m.xinhuanet.com/sx/2018-11/24/c_1123761303.htm|dead-url=no}}</ref>。

== 人口 ==
根據第七次人口普查數據，截至2020年11月1日零時，潞城區常住人口為219256人。<ref>{{Cite web|title=中國: 山西省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/shanxi/admin/|access-date=2023-09-03|website=www.citypopulation.de}}</ref>

2010年第六次全国人口普查潞城市常住人口226874人。<ref>[http://www.changzhi.gov.cn/info/news/2011/nry/203579.htm 长治市2010年第六次全国人口普查主要数据公报] {{webarchive|url=https://web.archive.org/web/20140821122532/http://www.changzhi.gov.cn/info/news/2011/nry/203579.htm |date=2014-08-21 }}</ref>

== 地理 ==
全境地势较平，中部稍高，东西两侧稍低。

== 经济 ==
潞城市以矿业及其相关工业最为突出，有[[石灰岩]]，[[石膏]]矿，[[白云岩]]，[[水泥]]粘土，陶瓷[[粘土]]，砖瓦粘土，[[硫磺]]矿，冰洲石（无色透明纯净的[[方解石]]），[[铁矿]]，[[铜矿]]等矿产。潞城市辖区内有王曲电厂、[https://web.archive.org/web/20130927231424/http://www.tianjigroup.com/ 山西天脊煤化工集团有限公司]等知名企业。

潞城市2012年[[GDP]]约为97.00亿元 <ref>{{Cite web |url=http://www.elivecity.cn/html/jingjifz/1566.html |title=2012年长治市各区县市GDP和人均GDP排名 |access-date=2013-09-22 |archive-date=2015-09-23 |archive-url=https://web.archive.org/web/20150923235507/http://www.elivecity.cn/html/jingjifz/1566.html |dead-url=no }}</ref>。

== 典故 ==
