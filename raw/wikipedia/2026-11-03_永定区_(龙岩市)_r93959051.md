'''永定区'''是[[中华人民共和国|中国]][[福建省]][[龙岩市]]下辖的一个[[市辖区]]，為[[明]][[清]]時期為[[汀州府]]所轄的客家八縣之一，是“客家故里”、純客家區，客家人重要的聚居地和集散地之一，是目前是全國對台工作重點區。本區位于[[福建省]]西南部，是“南方礦區”、“烤煙之鄉”，[[地熱]]資源居龍巖市第一位，2015年2月9日正式撤縣，改为龙岩市永定区<ref name="撤县设区2015"/>。永定是“土樓之鄉”，是[[福建土樓]]的發源地和核心分佈區。區人民政府駐[[鳳城街道 (龍巖市)|鳳城街道]]九一街西路2号。

== 历史 ==
周時屬七閩地；秦時屬閩中郡。

漢初屬閩越國；三國時屬吳國的建安郡。

晉太康三年（282年），永定治地屬晉安郡新羅縣，上隸揚州。

南北朝宋泰始四年（468年），屬晉平郡。梁天監（502～519年）屬南安郡。

陳武帝（557～559年），永定屬閩州南安郡。 

隋開皇九年（589年），廢建安、南安二郡，改為泉州，大業初年，復為閩州。永定治地，屬泉州後隸閩州。

唐武德元年（618年），屬建州。

開元二十四年（736年），開福撫二州山洞置汀州，轄新羅、長汀、黃連三縣，永定治地屬汀州新羅縣。天寶元年（742），改汀州為臨汀郡（乾元元年（758年）復為汀州。

[[宋朝|宋]]为[[上杭县]]属地。

[[明朝|明]][[成化]]十四年（1478年）析上杭县地置永定县，历属[[汀州府]]、[[汀州道]]。

1929－1934年为[[中央苏区]]辖县。1949年9月1日，解放军再度攻占永定县。历属[[龙岩专区]]、[[龙岩地区]]、[[龙岩市]]。

2014年12月13日，国务院同意撤销“永定县”，设立“龙岩市永定区”的决定。<ref>{{Cite web |url=http://202.108.98.30/description?dcpid=2014 |title=2014年县级以上行政区划变更情况 |access-date=2014-12-25 |archive-date=2014-11-02 |archive-url=https://web.archive.org/web/20141102170503/http://202.108.98.30/description?dcpid=2014 |dead-url=no }}</ref>2015年2月9日上午9时30分许正式撤销“永定县”，同时设立“龙岩市永定区”。并同时在保留的一些原有机构更名的基础上设立一些新机构（如“龙岩市永定区土楼消防队”等）；同时将城建、土地、城乡规划、社会经济等划归龙岩市的有关部门管理和编制（简称“多规合一”），实现由县域经济单位向城区单位转型；其余不变。<ref name="撤县设区2015" />

== 地理 ==
[[File:Maqidong_mountain_in_Daxi_township.jpg|thumb|永定區大溪鄉的馬薺崬山]]

永定区东连[[南靖县]]，东南与[[平和县]]交界，西南与[[广东省]][[大埔县]]、[[梅州市]][[梅县区]]接壤，西北与[[上杭县]]相连，东北与[[新罗区]]毗邻。以山地、丘陵为主。最高峰[[赤岩头]]，海拔1547米。另外也有蒙公山、仙洞山、馬薺崬等山嶺。主要河流有[[汀江]]、[[永定河 (福建省)|永定河]]，最大水库为[[棉花滩水库]]。

==语言==
大部分地区通用[[客家语]][[永定话]]，部分地区使用[[闽中语]]以及[[闽南语]][[龙岩话]]，另有闽南-客家[[混合语|混合方言]][[孔夫话]]通行于培丰镇孔夫村及其周边地区。<ref>张振兴. 福建省龙岩市境内闽南话与客家话的分界.方言.1984(3): 165.</ref>

== 交通 ==
===城区交通===
中心城区有东大街、南门街、九一路、环城路、银河路等主干路，由北环路、东环路。西环路组成[[绕城公路]]。中心城区有书院大桥、南门大桥、东门大桥、龙凤大桥、龙角大桥等五座公路桥横跨永定河，另有一座人行桥风景桥。汽车站及火车站分别位于城区东部东大街南北两端，有列车班次到[[厦门]]、[[昆明]]、[[深圳]]等大城市。

===铁路===
{{rint|cn|rail}}[[漳龙坎铁路]]、{{rint|cn|rail}}[[梅坎铁路]]
[[永定火车站]]是全区唯一一座客运火车站。仙师火车站、象牙村火车站、坎市站、富岭站等小站也曾为客运站，列车提速后取消，现大多数为货运站。

===公路===
{{中国国道名|235}}、{{中国国道名|357}}、{{中国省道名|203|P=福建}}、{{中国省道名|309|P=福建}}，[[双永高速公路]]位于永定区东部的永定汽车站为中心车站，另大多数乡镇有汽车站，城际及乡村[[巴士]]线路发达，有巴士往返永定下辖各乡镇。另有大巴或中巴往返于各大城市及邻县。

===水路===
[[汀江]]航道，有航班从坝头至洪山乡，另有旅游航班。

==著名景点==
永定客家土楼是福建省“八大旅游品牌”之一 <ref>{{cite web| language =zh-cn| publisher =福建省人民政府办公厅| title =福建省人民政府门户网站——龙岩市| url =http://www.fujian.gov.cn/bmdd/sxgk/ly/| date =| accessdate =2012-12-08| archive-date =2015-06-13| archive-url =https://web.archive.org/web/20150613211335/http://www.fujian.gov.cn/bmdd/sxgk/ly/| dead-url =yes}}</ref>，主要土楼群有[[洪坑土楼群]]、[[南溪土楼群]]、[[高北土楼群]]、[[初溪土楼群]]等。2008年7月6日，“[[福建土楼]]”被列入《[[世界遗产名录]]》。

此外，永定区还有[[国家森林公园]][[王寿山]]、[[龙湖影视城]]等其他景点。

== 特产 ==
永定特产之一的[[永定万应茶]]被列入[[中国国家级非物质文化遗产列表]]。
