'''龙游县'''是位于[[中国]][[浙江省]]的一个[[县]]，由[[衢州市]]代管，地处浙江西部，位于[[金衢盆地]]内。西与衢州市[[衢江区]]、南与[[丽水市]][[遂昌县]]接壤、北与[[杭州市]][[建德市]]、东与[[金华市]][[婺城区]]接壤。<ref>{{cite web |author1=龙游县人民政府 |title=龙游县情概况 |url=http://www.longyou.gov.cn/art/2021/3/5/art_1247796_52187752.html |website=龙游县人民政府 |accessdate=2021-03-05 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007051432/http://www.longyou.gov.cn/art/2021/3/5/art_1247796_52187752.html |dead-url=no }}</ref> 縣人民政府駐[[龙洲街道|龙洲街道太平西路1号]]。区域总面积为1,143平方公里。

== 历史沿革 ==

根据考古资料，早在一万年前的[[新石器时代]]早期，龙游县境内就有人类活动。县境内的荷花山遗址中，发现了大量的早期稻作农业遗址，也是浙江迄今发现的最早的新石器时代遗址。遗址内发现的稻作文化遗迹，被部分学者认为是目前发现的人类最早栽种的[[稻谷]]。部分学者认为，龙游县为世界稻作文明的重要发祥地之一。<ref>{{cite web |author1=光明日报 |title=龙游荷花山遗址发掘获新发现 浙江人1万年前已吃上稻谷？ |url=http://www.guoxue.com/?p=15254 |accessdate=2013-08-15 |archive-date=2021-10-06 |archive-url=https://web.archive.org/web/20211006231344/http://www.guoxue.com/?p=15254 |dead-url=no }}</ref>

春秋时期，[[姑蔑|姑蔑国]]建都于此，秦王[[嬴政]]25年（公元前222年），置太末县，后改太末县为末治县。[[东汉]][[建武 (东汉)|建武]]元年（公元25年），恢复太末县名。东汉[[初平]]三年，析太末县设立新安县（治今衢州市区）。公元218年，东汉析新安县设立定阳县（今[[常山县]]），析太末县南部地设立遂昌县。唐武德四年（公元621年），析太末县为盈川县、白石县、武安县，武德八年废。[[唐太宗]][[贞观]]八年（公元634年），改名龙丘，[[五代]][[吴越国|吴越]]宝正六年（公元931年），吴越王[[钱镠]]以丘不祥，改称龙游。[[北宋]][[宣和]]三年（1121年），将龙游县改名为盈川县。[[南宋]]绍兴元年（1131年），复称龙游县。[[元朝]]时期，龙游县隶属[[江浙行省]]衢州路。[[朱元璋]]攻占衢州后，改衢州路为龙游府，依然设立龙游县。不久之后,改龙游府为衢州府，龙游县属之。[[清朝|清]]时，龙游县属浙江省衢州府。[[中华民国]]成立后，龙游县属金华道。1928年，龙游县直属于浙江省，1936年，改隶属为第五行政督察区，解放后改属第三专区。[[中华人民共和国]]成立后，隶属衢州专区。1955年3月，因衢州专区撤销，改属金华专区。1959年11月8日，[[中共浙江省委]]决定撤销龙游县建制，并入衢县。1983年9月，龙游县建制恢复。1985年5月，金华地区撤销，分设金华、衢州为省辖市，龙游县归属衢州市领辖。<ref>{{cite web |author1=龙游县人民政府 |title=历史沿革 |url=http://www.longyou.gov.cn/art/2021/1/10/art_1229277394_56330819.html |accessdate=2021-01-10 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007023934/http://www.longyou.gov.cn/art/2021/1/10/art_1229277394_56330819.html |dead-url=no }}</ref>

== 自然环境 ==

'''龙游县'''地处浙西金衢盆地，介于北纬28°44'~29°17'，东经109°02'~119°20'之间，县境地貌为南北高、中间底的马鞍形。北部属[[千里岗]]山脉余脉，南部属[[仙霞岭]]山脉余脉，中部属衢江冲积平原。县内多丘陵地貌，基岩以红砂岩、紫砂岩为主，地貌类型具有明显过渡性。全县最高点为[[庙下乡]]茅山坑，海拔1442米；最低点为[[湖镇镇 (龙游县)|湖镇镇]]下童村，海拔35米。

境内河流均属钱塘江水系，以雨源型山溪为主。河流总长402.1千米，境内主要河流有[[衢江]]、灵山江、模环溪、罗家溪、塔石溪等。

全县属于[[亚热带季风气候]]区，四季分明，气候温和，全年无霜期较长，夏季高温日数较长。年均气温17.4℃，年均降水量1618.2毫米。<ref>{{cite book |author1=方志出版社 |editor=龙游县地方志委员会 |title=龙游县志·卷二·自然环境 |date=2018.5 |location=北京 |pages=205-298}}</ref>

== 交通 ==
[[File:20210804 龙游站新站房.jpg|缩略图|龙游站站房]]
'''龙游县'''为浙江东、中部地区连接江西、安徽和福建三省的重要交通枢纽，{{中国高速公路名|G60}}、{{中国高速公路名|G4012}}在龙游交汇，{{中国国道名|320}}、315省道、528省道纵横交错，建有全省县级城市中第一条城市环线公路。

铁路方面，{{rint|cn|crh}}[[沪昆客运专线]]、[[沪昆铁路]]、[[衢宁铁路]]过境并设有[[龙游站 (浙江省)|龙游站]]、[[龙游南站]]，[[杭衢铁路]]已经开工，正谋划建设[[衢丽铁路]]。<ref>{{cite web |author1=中国新闻网 |title=浙江龙游火车站新建站房正式开通启用 |url=http://www.zj.chinanews.com/jzkzj/2021-06-29/detail-ihanruav0580503.shtml |access-date=2021-10-06 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007015428/http://www.zj.chinanews.com/jzkzj/2021-06-29/detail-ihanruav0580503.shtml |dead-url=no }}</ref>

空运方面，龙游县距[[衢州机场|衢州]]、[[义乌机场|义乌]]、[[杭州萧山国际机场|萧山]]等机场均在30分钟至1.5小时交通圈。

水运方面，已建成衢江500吨级内河航道和设有14个500吨级泊位的龙游港区，2020年完成吞吐量240.71万吨。<ref>{{cite web |author1=衢州日报 |title=龙游港区首条集装箱航线开通 |url=https://cs.zjol.com.cn/zjbd/qz16508/201906/t20190621_10386189.shtml |website=浙江在线 |access-date=2021-10-06 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007023857/https://cs.zjol.com.cn/zjbd/qz16508/201906/t20190621_10386189.shtml |dead-url=no }}</ref>

== 語言 ==

{{参见|龙游话}}
'''龙游县'''方言以[[吴语]][[金衢片]][[龙游话]]为主，分布县内各乡镇，以县城方言为代表；县域内另有外籍移民方言，如[[温州话]]、[[闽南话]]、淳安话及畲客话等。温州话主要分布詹家、七都、箬塘、庙下、溪口等乡，其中詹家、后厅、槐王、童家等村说温州话村民最多；闽南话主要为平阳闽语，分布溪口区各乡及上圩头乡魏家村，寺后乡柳村、寺后等地；[[新安江水库]]移民说淳安话，主要分布在上圩头乡街路，窑山新建村，罗家乡廖家，詹家乡新安村，灵山乡大杨家，溪口乡双港口，沐尘乡大车，坑头乡上塘，湖镇新建、联合等村；畲客话在畲族居民中通行，他们在家说畲客话，入乡则说龙游话。<ref>{{cite web |title=龙游方言介绍 |url=http://map.51pla.com/fangyanshow.aspx?uid=1154 |access-date=2021-10-06 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007023938/http://map.51pla.com/fangyanshow.aspx?uid=1154 |dead-url=no }}</ref>

== 经济 ==

龙游县在经济上被纳入[[长三角]]、[[浙中城市群]]和[[海西经济区]]组团，连续13年入选全国中小城市投资潜力百强县，连续三年跻身前二十位。2019年，入围全国科技创新百强县市、中国营商环境百佳示范县市。龙游经济开发区规划面积40.2平方公里，目前已开发27.81平方公里，入园企业700多家。2020年，全县地区生产总值同比增长4.4%；固定资产投资增长3.9%；一般公共预算收入增长3.7%；城镇和农村居民人均可支配收入分别增长5.8%和7.5%。<ref>{{cite web |author1=微龙游 |title=“数”说百年！来看龙游经济发展～ |url=https://new.qq.com/omn/20210628/20210628A0B95U00.html |website=腾讯网 |accessdate=2021-06-28 |archive-date=2021-10-06 |archive-url=https://web.archive.org/web/20211006154902/https://new.qq.com/omn/20210628/20210628A0B95U00.html |dead-url=no }}</ref>

全县支柱产业有高档家具制造、特种纸、绿色食品饮料、高端装备、新材料、智能制造，目前已有10亿元以上企业4家，8家企业成功挂牌新三板，7家企业启动主板上市。<ref>{{cite web |author1=浙江省经济厅 |title=龙游经济开发区简介 |url=http://zcom.zj.gov.cn/art/2021/5/17/art_1416319_58930557.html |access-date=2021-10-06 |archive-date=2021-10-06 |archive-url=https://web.archive.org/web/20211006154909/http://zcom.zj.gov.cn/art/2021/5/17/art_1416319_58930557.html |dead-url=no }}</ref>

农业上，龙游农业资源丰富，被授予“中国竹子之乡”“中国黄花梨之乡”称号，发糕、小辣椒、富硒莲子、“中黄三号”黄茶等农产品在海内外享有盛誉。

== 旅游 ==
[[File:Longyou Xiaonanhai Shishi 2016.12.11 16-10-51.jpg|缩略图|[[龙游石窟]]]]
'''龙游县'''境内山脉、丘陵、平原、河流兼具，自然资源与人文景观融为一体，自成特色，素有“东游西游不如龙游”的说法。[[龙游石窟]]是[[全国重点文物保护单位]]、衢州市首个国家4A级旅游景区，现正积极申报世界历史文化遗产；[[鸡鸣山民居苑]]则是全国两处古民居异地集中保护地之一；总规划面积3.5平方公里、总投资80多亿元的红木小镇入选省级优秀特色小镇并成功创建国家4A级旅游景区。

此外，还有位于县南的六春湖旅游度假区，以及浙西大竹海、石佛三门源、饭甑山火山颈等诸多风景名胜。<ref>{{cite web |author1=龙游县人民政府 |title=名城古迹 |url=http://www.longyou.gov.cn/col/col1229277486/index.html |access-date=2021-10-06 |archive-date=2021-10-07 |archive-url=https://web.archive.org/web/20211007051415/http://www.longyou.gov.cn/col/col1229277486/index.html |dead-url=no }}</ref>
