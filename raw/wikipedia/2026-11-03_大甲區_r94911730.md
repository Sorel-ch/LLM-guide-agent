== 歷史 ==
{{main|大甲歷史}}
1895年4月17日，清廷簽訂《[[馬關條約]]》，[[台灣日治時期|割臺灣及所屬島嶼予日本]]；6月28日，臺灣改設3縣1廳，大甲由[[臺中縣 (日治時期)|臺灣縣]]直轄。1896年3月改設1縣2民政支部1廳，隸屬臺灣民政支部苗栗出張所{{sfn|陳明終|1981|p=57}}。1897年3月復改3縣1廳，隸屬臺中縣苗栗支廳；5月改6縣3廳，屬[[新竹縣 (日治時期)|新竹縣]]大甲辦務署第二堡{{sfn|陳明終|1981|p=57}}{{r|鎮志大事記|p=1716}}。1898年改3縣3廳，屬臺中縣大甲辦務署[[苗栗三堡]]{{r|鎮志大事記|p=1716}}。1901年11月，全臺灣改設20廳，大甲隸屬[[苗栗廳]]苗栗三堡{{sfn|陳明終|1981|p=57}}{{r|鎮志大事記|p=1717}}。1909年10月改設12廳，隸屬[[臺中廳]]大甲支廳苗栗三堡，一部分屬大甲區，一部分屬十八-{庄}-區，一部分屬五里牌區{{sfn|陳明終|1981|pp=60－61}}{{r|鎮志大事記|p=1718}}。1920年改訂地方官制，臺灣改設5州2廳，大甲支廳與沙鹿支廳合併改稱[[大甲郡]]，大甲-{庄}-屬[[臺中州]]大甲郡{{r|鎮志大事記|p=1721}}。大甲-{庄}-轄大甲、番子寮、-{庄}-尾、橫圳、社尾、營盤口、山腳、外水尾、頂店、六塊厝、後厝子、日南、日南社、五里牌、九張犁、船頭埔、銅安厝、頂後厝子、西勢、雙寮、新-{庄}-子等21個大字{{sfn|陳明終|1981|pp=58－59}}。1922年4月，大甲-{庄}-改制為「[[大甲街]]」{{r|鎮志大事記|p=1722}}。

== 地理 ==
=== 位置與範圍 ===
大甲區由大甲以及大安溪北側的[[日南 (臺灣)|日南]]兩地組成，東西最大跨距約10公里；南北最大跨距8公里，總面積約58平方公里。位置在行政區劃上位於[[台中市]]西北端，北邊與[[苗栗縣]][[苑裡鎮]]以南房裡溪與新復溝為界；南邊與[[清水區 (台灣)|清水區]]相隔[[大甲溪]]，西側與[[大安區 (臺中市)|大安區]]及[[臺灣海峽]]相鄰，東面則與[[外埔區]]相接。在地形上位於[[苗栗丘陵]]南端；[[清水平原]]北面；[[后里台地]]的西側<ref name="大甲地理位置"/><ref name="臺中市大甲區行政區域圖">{{Cite web|url =http://taiwanarmap.moi.gov.tw/moi/GetImage.aspx?city=%25E8%2587%25BA%25E4%25B8%25AD%25E5%25B8%2582&town=%25E5%25A4%25A7%25E7%2594%25B2%25E5%258D%2580&cg=new|title =《臺中市大甲區行政區域圖》|author =內政部地政司|date =2014|publisher =內政部地政司|language =zh-tw|accessdate =2016-10-28|quote =|deadurl =yes|archiveurl =https://web.archive.org/web/20160304075858/http://taiwanarmap.moi.gov.tw/moi/GetImage.aspx?city=%25E8%2587%25BA%25E4%25B8%25AD%25E5%25B8%2582&town=%25E5%25A4%25A7%25E7%2594%25B2%25E5%258D%2580&cg=new|archivedate =2016-03-04}}</ref>。

=== 地形與水文 ===
大甲區地形主要以[[臺灣地理|大甲扇狀平原]]以及[[后里台地]]所構成。大甲扇狀平原為[[大甲溪]]與[[大安溪]]因堆積作用而形成之[[沖積扇平原]]。后里台地則是介於大甲溪與大安溪下游間一長方形的緩傾台地。台地東西跨距長約12公里長，靠近大甲的台地西側地形陡降，但西北與西南角突出升高形成丘陵地形，即為大安溪南岸標高236公尺的[[鐵砧山]]；及在大甲溪北岸標高179公尺的水尾山。大甲區水文除大甲溪與大安溪，區內尚有瓦瑤溪、[[房裡溪]]、溫寮溪等溪河以及頂店圳、虎眼圳、日南圳、九張犁圳等水圳，由東向西注入台灣海峽<ref name="大甲地形地貌地質"/>。

=== 地質與土壤 ===
大甲區地質主要含有兩種地層，大部分為地質年代[[全新世]]之[[沖積層]]，其土壤為沖積土，由礫石、沙、粉沙及黏土等成分組成；其次為后里台地西側，地質年代[[更新世]]之{{le|階地堆積層|Terrace (geology)}}，其土壤為紅棕壤，內含紅土、礫石、沙及粉沙等成分<ref>{{Cite book| author =陳明終| title =《大甲風貌》| location =臺中大甲| publisher =大甲風貌編輯委員會| date =1981-08| pages =| ISBN =| accessdate =2016-11-02| url =http://old.dajia.taichung.gov.tw/book01/book01.html| language =zh-tw| quote =| deadurl =yes| archiveurl =https://web.archive.org/web/20161104014842/http://old.dajia.taichung.gov.tw/book01/book01.html| archivedate =2016-11-04}}</ref><ref>{{Cite web|url =http://gis.moeacgs.gov.tw/gwh/gsb97-1/sys8/index.cfm|title =地質資料整合查詢|author =經濟部中央地質調查所|date =|publisher =經濟部中央地質調查所|language =zh-tw|accessdate =2016-11-02|quote =|deadurl =yes|archiveurl =https://web.archive.org/web/20161004101145/http://gis.moeacgs.gov.tw/gwh/gsb97-1/sys8/index.cfm|archivedate =2016-10-04}}</ref>。

=== 氣候 ===
大甲區之氣候為[[亞熱帶季風氣候]]，夏季濕熱多雨，冬季乾旱多風。全年平均氣溫約攝氏24度，年降雨量約1500毫米，雨季落在5~8月間的[[梅雨]]、[[颱風]]與夏季[[西南季風]]盛行期間<ref name="大甲氣候"/>。

=== 區政組織 ===
[[File:大甲區行政中心.jpg|thumb|200px|大甲區行政中心]]
[[大甲區公所]]是[[臺中市政府]]在大甲區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為臺中市政府。[[区长]]由[[臺中市市長|市長]]任命，其任期為無任期保障，並置一名主任秘書襄理區務。在區長及主任秘書之下，設有5課4室等9個內部單位<ref>{{Cite web |url=https://www.dajia.taichung.gov.tw/982944/982950/982962/1260494/post |title=機關介紹 - 組織架構 |publisher=臺中市大甲區公所 |date=2013-05-12 |access-date=2021-06-26 |language=zh-tw |archive-date=2021-01-16 |archive-url=https://web.archive.org/web/20210116182705/https://www.dajia.taichung.gov.tw/982944/982950/982962/1260494/post |dead-url=no }}</ref>。

=== 行政區 ===
現今大甲區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二聽，設大甲-{庄}-屬臺中州大甲郡{{r|鎮志政事篇|p=472}}。大甲-{庄}-轄船頭埔、頂後厝子、銅安厝、日南、日南社、九張犁、五里牌、西勢、雙寮、新-{庄}-子、社尾、頂店、橫圳、營盤口、山腳、-{庄}-尾、大甲、外水尾、番子寮、後厝子、六塊厝等21個大字{{sfn|施添福|2006|p=170}}。1922年，大甲-{庄}-改制為「大甲街」{{r|鎮志政事篇|p=472}}。1945年，改為「大甲鎮」，屬臺中縣大甲區。1950年，裁撤區署，大甲鎮改直隸於臺中縣{{r|鎮志政事篇|p=474}}。2010年12月25日，臺中縣市合併改制為直轄市，大甲鎮改制為市轄區「大甲區」，隸屬臺中市<ref name="合併改制"/>。

大甲區共轄29個里，其行政區主要可分為大安溪以北之『溪北區域』與大安溪以南之『溪南區域』。溪北區域為為台中市唯一在大安溪以北的行政區。溪南區域為大甲區政經中心，不僅為大甲區主要人口活動區域，亦是相鄰之大安區、外埔區等鄰近之鄉鎮之生活中心<ref name="大甲地理位置"/>。大甲區部分下轄行政區與道路名稱，早期之戶政人員以[[封神榜]]為藍本進行命名，如以[[周王朝]]發祥地[[西岐]]命名之西岐里、代表[[太白金星|太白星]]、[[文曲星]]、[[武曲星]]之太白里、文曲里、武曲里等<ref>{{cite news |language = zh-tw |author = 張軒哲 |coauthors =  |url = http://news.ltn.com.tw/news/local/paper/540721 |title = 〈中部〉大甲里名路名 戲說封神榜 |publisher = 自由電子報 |pages =  |date = 2011-11-21 |accessdate = 2016-10-29 |archive-date = 2016-10-30 |archive-url = https://web.archive.org/web/20161030001356/http://news.ltn.com.tw/news/local/paper/540721 |dead-url = no }}</ref><ref>{{cite news |language = zh-tw |author = 陳榮昌 |coauthors =  |url = http://history.n.yam.com/taiwanhot/place/20150318/20150318922974.html |title = 大甲多里及路有封神名　區公所規畫封神大甲爭觀光 |publisher = 台灣好新聞 |pages =  |date = 2015-03-18 |accessdate = 2016-10-29 |archive-date = 2016-10-30 |archive-url = https://web.archive.org/web/20161030074513/http://history.n.yam.com/taiwanhot/place/20150318/20150318922974.html |dead-url = no }}</ref>。

=== 史前文化與遺址<ref>{{Cite web |url = http://digimuse.nmns.edu.tw/da/collections/ha/a0/intro/ |title = 臺灣史前文化 臺灣中部考古學概述 |author = 國立自然科學博物館、數位典藏國家型科技計畫 |date =  |publisher = 國立自然科學博物館、數位典藏國家型科技計畫 |language = zh-tw |accessdate = 2016-10-02 |quote =  |archive-date = 2017-01-11 |archive-url = https://web.archive.org/web/20170111081628/http://digimuse.nmns.edu.tw/da/collections/ha/a0/intro/ |dead-url = no }}</ref><ref>{{Cite book| author =廖瑞銘| title =《大甲鎮志》第三篇 開墾篇| location =臺中大甲| publisher =臺中縣大甲鎮公所| date =2009-01| pages =| ISBN =| accessdate =2016-10-30| url =http://old.dajia.taichung.gov.tw/book14/the-history/0277-0460.pdf| language =zh-tw| quote =| deadurl =yes| archiveurl =https://web.archive.org/web/20160402160311/http://old.dajia.taichung.gov.tw/book14/the-history/0277-0460.pdf| archivedate =2016-04-02}}</ref> ===
*[[番仔園文化]]與番仔園遺址：番仔園文化為距今2000~400年前鐵器時代的史前文化，其相關遺址遍布[[大肚台地]]與[[苗栗丘陵]]南部，以大甲區之番仔園遺址作為命名遺址，番仔園遺址位於鐵砧山西側山麓紫竹寺與大甲高工附近。
*鐵砧山平頂遺址：距今4000~3000年前，屬於新石器時代[[牛罵頭文化]]的遺址，位於鐵砧山忠烈祠後約100公尺。
*水源地遺址：距今4000~3000年前，屬於新石器時代牛罵頭文化的遺址，位於大甲區中山里水尾溪北側斷崖上。
*麻路頭遺址：距今3500~2000年前，屬於新石器時代後期的[[營埔文化]]，位於大甲區東南方，水尾溪南岸，距溪水不到100公尺。

*大甲三寶：媽祖、[[奶油酥餅 (大甲)|奶油酥餅]]、[[藺草]]帽蓆。

*大甲三大民宅：社尾黃氏古厝、頂店梁宅瑞蓮堂及順德居王宅（不存）。
