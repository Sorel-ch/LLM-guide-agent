'''屏南县'''（{{lang-cdo|buc=Bìng-nàng-gâing|ipa=piŋ˥˥ naŋ˥˧ kaiŋ˨˦˨}}）是[[宁德市]]下辖的一个县，位于[[福建省]]东北部、宁德市与[[南平市]]的交界处，通行[[闽语]][[闽东片]][[侯官小片]]屏南话，縣政府駐[[古峰镇|古峰鎮]]。

== 历史 ==
屏南县原属[[古田县]]，雍正九年（1731年）古田知县赵琳“以古邑界连四府九县，地方辽阔，跨有六百里，鞭长莫及。且又中多层峦叠嶂，深林密箐，最易存奸，…… 乃议请分隶。”[[雍正]]十二年（1734年），闽浙总督郝玉麟具题，得到[[雍正帝]]俞允，乃析古田县境东北部移风里、新俗里和横溪里的13个都建县，县治双溪位于翠屏山之南<ref>{{cite book |title=《清世宗憲皇帝實錄卷之一百四十三》 |url=https://sillok.history.go.kr/mc/id/qsilok_006_1430_0010_0010_0130_0010 |accessdate=2024-07-15 |archive-date=2025-05-31 |archive-url=https://web.archive.org/web/20250531211827/https://sillok.history.go.kr/mc/id/qsilok_006_1430_0010_0010_0130_0010 |url-status=live}}</ref>。

屏南建县后隶属于福州府，歷史上曾是[[福州十邑]]之一。中华人民共和国成立后，屏南县曾先后隶属于南平专区、闽侯专区，1970年7月划入福安专区（后改称宁德地区），始为宁德的下辖县。

== 资源 ==
因出产夏香菇而有“中国夏香菇之乡”之称号。屏南县的水电蕴藏量达40万[[千瓦]]，是全国100个农村电气化试点县之一。

== 教育 ==
截至2021年，全县拥有普通中学11所，九年一贯制学校1所，小学19所，教学点17个，中等职业学校1所，幼儿园18所。

== 文化 ==
屏南县的四平戏、屏南双溪铁枝、屏南平讲戏及木拱桥传统营造技艺被列入[[国家级非物质文化遗产名录]]。

== 旅游 ==
[[File:Pingnan Confucian Temple 2014.08.03 07-35-19.jpg|300px|缩略图|[[屏南文庙]]]]
* [[白水洋]]·鸳鸯溪：[[宁德世界地质公园]]的重要组成部分，5A级旅游景区。
* [[万安桥 (屏南)|万安桥]]：俗称长桥、彩虹桥，位于长桥村东面的长桥溪上，始建于北宋，是中国现存最长的木拱廊桥。全国重点文物保护单位[[闽东北廊桥]]之一。
