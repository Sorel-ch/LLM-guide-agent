'''罗定市'''，古称'''龙乡'''、'''泷州'''、'''泷水'''，为[[中华人民共和国]][[广东省]]辖[[县级市]]，现由[[云浮市]]代管。罗定位于广东省西部，[[西江]]以南，毗邻[[粵港澳大灣區|粤港澳大湾区]]<ref>{{Cite web |title=东融湾区 西接RCEP丨云浮这些年：八方通衢势如虹 |url=https://finance.sina.com.cn/jjxw/2025-02-28/doc-inemzcmm7122271.shtml |website=finance.sina.com.cn |date=2025-02-28 |access-date=2026-01-01}}</ref>。全市总面积2327.5平方公里。市人民政府駐[[罗城街道 (罗定市)|羅城街道]]寶定路31號。

罗定拥有广阔的平原地貌和独特的盆地性气候，罗定盆地是广东最大盆地。罗定是海陆丝绸之路最早的对接通道之一<ref>{{Cite web |title=【广东印记】在海陆丝绸之路的节点，寻觅古建筑里的传奇_南方网 |url=https://culture.southcn.com/node_cef89b1023/cc3344ba95.shtml |website=culture.southcn.com |access-date=2026-05-14}}</ref>，史称“门庭巨防，抚绥重地” 。罗定有独特的地方文化<ref name=":0">{{Cite web |title=广东省首批历史文化名城（镇）  广东省人民政府门户网站 |url=https://www.gd.gov.cn/zwgk/gongbao/1991/2/content/post_3355925.html |website=www.gd.gov.cn |access-date=2026-08-14}}</ref>，在长期交融中形成了开放、兼容的多元文化特色，开拓、冒险、进取和创新的文化特质。明万历年间（1577），因平定罗旁地区的“瑶乱”，肇庆府德庆州[[泷水县]]升格为[[羅定直隸州|罗定州]]，成为岭南历史上第一个直隶州。1913年，罗定州改为罗定县，直属广东省都督府。1914年，罗定县隶属粤海道。1949年中华人民共和国成立，1951年3月起罗定县隶属西江专员公署，同年12月起隶属粤中行政公署。1961年4月，罗定县先后隶属肇庆专员公署和肇庆地区行政公署、肇庆市（地级）。1994年4月5日，设立地级云浮市，代管罗定市（县级）<ref>{{Cite web |title=云浮市建置沿革 |url=https://www.yunfu.gov.cn/zjyf/lsyg/content/post_1901211.html |website=云浮市人民政府门户网站 |date=2025-03-11 |access-date=2026-01-01}}</ref>。

罗定是广东省首批历史文化名城、广东财政省直管县、[[云浮市]]域副中心城市<ref>{{Cite web |title=立体交通织网 六大产业聚能 ——罗定市绘就副中心振兴新图景 |url=https://www.yunfu.gov.cn/zxzx/xsqxw/content/post_1970568.html |website=云浮市人民政府门户网站 |date=2025-12-15 |access-date=2026-01-01}}</ref>。

==历史沿革==

=== 古代 ===
春秋时期，罗定为百越地。<ref name=":1">（梁）沈约。宋书 (卷三十八 州郡志四)[M]. 北京：中华书局，1974；（唐）魏征，令狐德棻。隋书 (卷三十一 地理志下)[M]. 北京：中华书局，1973；（后晋）刘昫。旧唐书 (卷四十一 地理志四)[M]. 北京：中华书局，1975；（宋）欧阳修，宋祁。新唐书 (卷四十三上 地理志七上)[M]. 北京：中华书局，1975；（元）脱脱。宋史 (卷九十 地理志六)[M]. 北京：中华书局，1977；（唐）杜佑。通典 (卷一百八十四 州郡十四)[M]. 北京：中华书局，1988；（宋）乐史。太平寰宇记 (卷一百六十四 康州)[M]. 北京：中华书局，2007；（宋）李昉。太平御览 (卷七百八十五 四夷部六)[M]. 北京：中华书局，1960；（唐）李吉甫。元和郡县图志 (卷三十四 岭南道)[M]. 北京：中华书局，1983；黄伟宗，司徒尚纪。中国珠江文化史 [M]. 广州：广东教育出版社，2010；司徒尚纪。广东文化地理 [M]. 广州：广东人民出版社，2003；曾昭璇。岭南史地与民俗 [M]. 广州：广东人民出版社，1994；辞海编辑委员会。辞海 (历史地理分册)[M]. 上海：上海辞书出版社，2009；复旦大学历史地理研究中心。中国历史地理信息系统 (CHGIS) v6.0 [DB/OL]. 上海：复旦大学历史地理研究中心，2018。</ref>

秦始皇三十三年（前214年）平定岭南，置南海郡、桂林郡、象郡三郡，今罗定地属南海郡。据唐《通典》卷一百八十四载：秦始皇“后遣任嚣攻取陆梁之地，遂平南越，置郡，此为南海，今南海、始兴……晋康、临封、开阳、高凉、连城、新兴、铜陵、怀德等郡是。”<ref name=":1" /><ref>{{Cite web |title=文獻通考 : 卷三百二十三·輿地考九 - 中國哲學書電子化計劃 |url=https://ctext.org/wiki.pl?if=gb&chapter=210583 |website=ctext.org |language=zh-TW |last=Sturgeon |first=Donald |access-date=2026-05-14}}</ref>

汉元鼎六年（前111年）汉武帝平南越，置南海、苍梧等九郡，于苍梧郡置端溪县。元封五年（前106年），置交趾刺史部，苍梧等郡属其监察。罗定大部分地属端溪县。<ref name=":1" />

三国吴黄武五年（226年），罗定地属广州苍梧郡端溪县。端溪县包括今德庆、罗定、郁南、云城、云安、信宜等的部分地方。<ref name=":1" />

东晋永和七年（351年），析苍梧郡置晋康郡，初领十四县。元熙元年（419年）置龙乡、夫阮二县，龙乡县为泷水县的旧名。龙乡县处要津军事重地，南来豪族治理，用汉语命名。夫阮县用俚人治理，用古越语命名，汉语译为“荒地的村”，意为新开辟的地方。<ref name=":1" />

南朝宋初年，置平原县，后升平原县为平原郡，领龙乡县。永初至元嘉年间（420～453年），罗定地包括平原郡（领龙乡县）及晋康郡之夫阮县。南齐永明元年（483年），废平原郡置广熙郡，析龙乡县置永熙县、罗平县两县，郡治龙乡县。罗定地括龙乡、永熙、罗平、夫阮四县。<ref name=":1" />

南朝梁天监六年（507年），分广州置桂州，为后世两广分置之行政雏形。同年析广州置泷州（泷州之名源于今罗定江罗镜段有泷喉，滩高水急，巨石横截中流，十分险要）和建州，此时的泷州州治在今罗镜镇、太平镇境内。建州州治在今附城街道古城角。析广熙郡置平原、开阳、梁德、罗阳四郡。泷州辖平原郡（领龙乡县）、开阳郡（领开阳县）、梁德郡（领梁德县、永业县）；建州辖广熙郡（领安南县、永熙县）、罗阳郡（领罗阳县）。其中永业县治在今广西岑溪市筋竹镇，梁德郡、梁德县治在今信宜市池洞镇。南陈仍按梁设。<ref name=":1" />

隋开皇九年（589年），改龙乡县为平原县，与开阳县、怀德县、永业县同隶泷州。永熙县、安南县、罗阳县改隶建州。罗定地有平原、开阳、永熙、安南、罗阳五县。开皇十八年（598年），改平原为泷水县，改罗阳为正义县。罗定始有泷水县名。大业三年（607年），改泷州置永熙郡，废建州。并开阳县、正义县入泷水县，并安南县入永熙县，安遂县划归永熙郡。永熙郡辖六县：泷水县、永熙县、永业县、怀德县、良德县、安遂县。<ref name=":1" />

唐武德四年（621年），改永熙郡设泷州，此时泷州州治在今太平镇潭白村一带（武德四年至贞观二年<621—628年>，信宜南扶州<后更名窦州>因境内僚乱曾侨治泷州）。析泷水县置开阳县、正义县，以泷水、开阳、正义、怀德四县隶泷州；另置南建州，以永熙县、安遂县、永业县隶南建州。武德五年（622年）并正义县入怀德县，永熙县更名永宁县。贞观元年（627年），废泷州，以泷水、开阳、怀德三县改属南建州。是年，唐分天下为十道，泷水县属岭南道。贞观六年（632年），复置泷州，领泷水、开阳、怀德三县；贞观八年（634年），南建州改称药州。贞观十八年（644年），废药州，省安遂、永业二县，以永宁、安南二县改隶泷州。天宝元年（742年），泷州改称开阳郡，隶岭南道。乾元元年（758年）开阳郡复为泷州。<ref name=":1" />

宋开宝六年（973年）撤销泷州建制，开阳、建水、镇南三县并入泷水县，县署设于原开阳县境（今船步镇旧县址）。元大德八年（1304年），知县陈泽将设在开阳乡的泷水县治迁于建水乡羊禄埠（今罗城街道南区）。自宋开宝六年（973年）直至明万历五年（1577年），其间六百余年，罗定地域仅设泷水县，先后隶属宋代广南东路康州、元代德庆路、明代肇庆府德庆州等。<ref name=":1" />[[File:20251123 Luoding city wall.jpg|thumb|[[罗定州城墙]]，現為[[罗定市文物保护单位]]]]明万历四年（1576年），凌云翼征广东罗旁山区，平瑶乱。万历五年（1577年），升泷水县为罗定直隶州，直隶广东布政使司，罗定直隶州领东安县、西宁县。罗旁平定，因以罗定为州名，罗定州之东西也安宁，便以东安、西宁为县名。由是泷水之名始革，而罗定之名亦始于此。<ref name=":1" />

清朝沿置罗定直隶州，州治罗城，辖本州（罗定州）和东安县、西宁县。罗定州直隶广东省。另外，兵备道在不同时期有不同的设置。自明万历五年开州设罗定道驻州治，清康熙二年，罗定兵备道归并岭西守道。康熙六年裁撤岭西守道。康熙九年复设高雷廉道驻高州，罗定州守备隶之。康熙十六年复设罗定道驻州治。康熙二十一年裁并入岭西巡道分巡肇高廉罗道驻肇庆。雍正八年析为肇罗道。同治六年改分巡肇阳罗道驻肇庆府城。清末罗定州属[[廣肇羅道|广肇罗道]]。<ref name=":1" />

=== 中华民国时期 ===
民国元年（1912年），政府统一撤销州、府一级建制。罗定州改为罗定县，原罗定直隶州所辖之东安县（后更名云浮）、西宁县（后更名郁南）均改为省直辖县，同隶广东都督府。同年隶属肇罗经略处。民国三年（1914年）隶粤海道。民国十二年（1923年）改隶西江善后督办署。民国二十一年（1932年）转属广东西区绥靖委员公署高要行署。民国二十五年（1936年）隶广东省第三行政督察专员公署。民国三十八年（1949年）5月起，改隶广东省第十二行政督察专员公署。<ref name=":1" />

=== 中华人民共和国时期 ===
1949年10月29日，中共人民解放军占领罗定县[[罗城街道 (罗定市)|罗城镇]]。11月成立罗定县军事管制委员会，12月成立中共罗定县委员会，属于[[西江地方委员会]]。11月11日广东省[[西江行政督察专员公署]]成立，随后于1950年3月，改称[[西江区行政督察专员公署]]，1950年9月易名为[[西江区专员公署]]，罗定县皆属之。1952年12月，撤销西江专署，罗定县转属广东省[[粤中行署]]。1956年1月4日，撤销[[粤中行署]]，设立[[高要专区]]，罗定县随属。8月21日，郁南县加益区划入罗定县。

1958年11月4日，罗定县、郁南两县合并为[[罗南县]]。12月1日转属[[江门专属]]。 1959年1月4日，[[罗南县]]改称罗定县。1960年1月，[[云浮县]]东坝人民公社划入罗定县，次年转划入[[郁南县]]。1961年4月2日转属江门专属撤销，统合为[[肇庆专属]]。4月10日，析罗定县恢复原罗定、郁南两县建制，罗定县隶属广东省肇庆专区。1988年1月7日，撤销肇庆地区，设立[[肇庆市]]，代管罗定县。

1993年4月8日，经国务院批准，罗定县撤县设立罗定市（县级），由广东省直辖，肇庆市代管。1994年4月5日，国务院批准云浮市升格为地级市；同年4月28日，广东省人民政府批复委托云浮市代管罗定市。<ref>{{Cite web |title=罗定市志（1979－2003） {{!}} 广东省情网 |url=https://dfz.gd.gov.cn/dfz/f/book/viewer?keywords=%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97,%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&bookId=f2aae862c90045b19c535dd4a1d18fda&file=/upload/f2aae862c90045b19c535dd4a1d18fda/f2aae862c90045b19c535dd4a1d18fda/0.pdf&bookName=%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&snTopicCode=%E5%B8%82%E5%8E%BF%E5%BF%97%E4%B9%A6-%E4%BA%91%E6%B5%AE%E5%B8%82-%E7%BD%97%E5%AE%9A%E5%B8%82&pubDate=1632821762000 |website=dfz.gd.gov.cn |access-date=2026-05-14}}</ref><ref>[http://www.gov.cn/test/2007-03/23/content_559172.htm {{Wayback|url=http://www.gov.cn/test/2007-03/23/content_559172.htm |date=20200202033342 }}][//web.archive.org/web/20200202033342/http://www.gov.cn/test/2007-03/23/content_559172.htm 页面存档备份]<span>，存于</span>[[互联网档案馆|-{zh-cn:互联网档案馆;zh-tw:網際網路檔案館;zh-hk:互聯網檔案館;zh-sg:互联网档案馆;}-]]<span>）</span> 国务院1994年4月5日批复国函[1994]24号</ref><ref>{{Cite web |title=云浮市升格为地级市  广东省人民政府门户网站 |url=https://www.gd.gov.cn/zwgk/gongbao/1994/9/content/post_3357115.html |website=www.gd.gov.cn |access-date=2026-08-14}}</ref>

==语言==
罗定方言主要有白话、㑷古话、客家话和闽南话4种。

'''白话：'''属粤语的一个分支，以罗城为代表，分布于罗城、附城、榃滨、新乐、加益全境，罗镜、新榕、船步、䓣塘、苹塘、金鸡、双东、黎少、生江、连州、泗纶、都门、扶合的大部分乡村和太平、分界、华石、素龙的部分乡村。2003年讲白话的居民约占全市人口的61%。

'''㑷古话：'''属粤语方言<ref>{{Cite web |title=人口语言民族 云浮市人民政府门户网站 |url=https://www.yunfu.gov.cn/zjyf/rkmz/content/post_1860288.html |website=www.yunfu.gov.cn |access-date=2026-05-14}}</ref>，大约形成于南北朝时期。分布于围底全境，素龙、太平、罗平、华石的大部分和罗镜、分界、苹塘、双东的部分地区。2003年讲㑷古话的居民约占全市人口的26%。

'''客家话：'''即亻厓话，以泗纶为代表，分布于泗纶、都门、连州、分界、罗镜、太平、新榕、罗平、船步、䓣塘、苹塘等地。2003年讲客家话的居民约占全市人口的13%。

'''闽南话：'''疏疏落落分散于罗平、太平、船步和䓣塘的一些小村庄。2003年讲闽南话的居民约占全市人口的0.08%。<ref>{{Cite web|title=罗定市志（1979-2003） {{!}} 广东省情网|url=http://dfz.gd.gov.cn/dfz/f/book/viewer?keywords=,%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&bookId=f2aae862c90045b19c535dd4a1d18fda&file=/dfz/book/f2aae862c90045b19c535dd4a1d18fda/0.pdf&bookName=%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&snTopicCode=undefined&pubDate=1632821762000|access-date=2023-03-16|website=dfz.gd.gov.cn|archive-date=2023-03-16|archive-url=https://web.archive.org/web/20230316053215/http://dfz.gd.gov.cn/dfz/f/book/viewer?keywords=,%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&bookId=f2aae862c90045b19c535dd4a1d18fda&file=/dfz/book/f2aae862c90045b19c535dd4a1d18fda/0.pdf&bookName=%E7%BD%97%E5%AE%9A%E5%B8%82%E5%BF%97%EF%BC%881979-2003%EF%BC%89&snTopicCode=undefined&pubDate=1632821762000|dead-url=no}}</ref>

==文化==
罗定是广东省首批历史文化名城，是广府文化的重要区域，有独特的地方文化。历史文化底蕴深厚，名胜古迹众多，各处细节都体现出气势并存的建筑风貌及多元融合的文化底蕴。<ref name=":0" /><ref>{{Cite web |title=岭南园林展在罗定开展 展览时间持续至6月25日 云浮市人民政府门户网站 |url=https://www.yunfu.gov.cn/zxzx/xsqxw/content/post_1916617.html |website=www.yunfu.gov.cn |language=zh-CN |access-date=2026-08-14}}</ref>

罗定境内考古遗存丰富，是岭南远古文明的重要发祥地。在岭南考古发现出土随葬器物超过100件的青铜大墓只有3座，其中一座在肇庆，两座在罗定。在罗定的两座先秦青铜墓葬，一座是太平镇的南门垌墓、一座是罗平镇的背夫山战国墓。1983年至1984年文物普查中，考古工作者先后在苹塘镇下山洞遗址发现了距今数万年前的旧石器时代智人桡骨和猩猩等远古动物化石；在金鸡镇饭甑山岩遗址发现了石器、木炭和远古动物骨骼化石等。在罗平镇背夫山发现了战国墓葬，出土了人首柱形器、鼎、鉴等精美青铜器。在罗镜镇鹤咀山发现一处南朝墓葬，出土了带有西亚和中亚风格纹饰的瓷器和金手镯，印证了古代中外文化的交流。2012年，广东省文物考古研究所考古调查队在华石镇军步湾后山顶上，发现了20多件人工打制特征明显的石制品，这是罗定江流域可以确定的第一个旧石器时代遗址，以此为线索发现的郁南磨刀山遗址，亦是广东迄今发现的年代最早的古文化遗存之一。北京大学环境考古学专家夏正楷等学者提出，罗定江是广东文化母亲河的概念，孕育了岭南文化的“根”。<ref>{{Cite web |title=岭南文化源头在哪？专家“破译”广东史前考古地图-文史广东 |url=https://www.gdwsw.gov.cn/zhuanti/tjzqlntygc/ysyd/content/post_37045.html |website=www.gdwsw.gov.cn |access-date=2026-05-14}}</ref><ref>{{Cite web |title=【广东印记】这里，留下了60万年前古人类的足迹_南方网 |url=https://culture.southcn.com/node_cef89b1023/885523f85e.shtml |website=culture.southcn.com |access-date=2026-05-14}}</ref>

罗定古称泷州，是古代海陆丝绸之路最早的对接通道之一。历史上唐代宰相张柬之、诗人宋之问、南宋词人朱敦儒、明代礼部尚书彭华等，或因贬谪、或因避乱隐居于此。宋之问《入泷州江》、朱敦儒《相见欢·泷州几番清秋》，均记录了当时身赴泷州的情景。明万历五年（1577年）罗定直隶州设立后，各级文武官员如凌云翼、陈璘、郑人逵、马梦箕、邹德淇、宋起凤、王植等，都对地方发展作出了重要贡献。罗定自古传承兴学、尚武和爱国的优良传统，英才辈出。
