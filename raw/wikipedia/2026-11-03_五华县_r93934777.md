'''五华县'''，舊名'''長樂縣'''，位于[[中华人民共和国]][[广东省]]东北部，属于[[梅州市]]管辖。人口及面積皆為梅州市下辖县中第一。东边与梅州[[丰顺县]]相邻，南边与揭阳[[揭西县]]、汕尾[[陆河县]]相邻，西边与河源[[紫金县]]、[[东源县]]、[[龙川县]]相邻，北边与梅州[[兴宁市]]相连，县政府驻[[水寨鎮 (五華縣)|水寨镇]]华一东路1号。

由於地處山區，五华县的經濟發展落後鄰近的縣份。近年因[[梅州客家]]足球隊等而知名。

== 历史 ==
「長樂」一名來自前214年左右，南越國首任君主趙佗於[[龍川縣]]郊五華山（今五華縣[[華城鎮]]塔崗村）築[[長樂台]]為行宮<ref>{{Cite web |title=梅州五华县，实干笃行方能“华”丽转身 |url=https://news.southcn.com/node_54a44f01a2/5e16fc771c.shtml |website=[[南方日報|南方网]] |date=2024-03-19 |access-date=2025-10-05 |archive-date=2025-10-14 |archive-url=https://web.archive.org/web/20251014205841/https://news.southcn.com/node_54a44f01a2/5e16fc771c.shtml |url-status=live }}</ref>。[[北宋]][[熙宁]]四年（1071年）始置長樂縣，屬[[惠州 (北宋)|惠州]]，县治設於长乐镇（今[[華城鎮]]）。[[清]][[雍正]]年間改屬[[嘉應州]]，[[民國紀年|民國]]三年（1914年）因與[[福建省 (1912年－1949年)|福建省]][[長樂縣 (唐朝)|長樂縣]]、[[湖北省 (中華民國)|湖北省]]長樂縣重名，而[[改定各省重複縣名及存廢理由清單|改名]]五華縣<ref>{{Cite web |title=五华，何以“文质彬彬”？ |url=https://epaper.nfnews.com/nfdaily/html/202503/01/content_10128305.html |website=[[南方日報]] |date=2025-03-01}}</ref>。

五华县治以前主要設於華城鎮，直至1954年迁移到[[水寨镇 (五华县)|水寨鎮]]。五華的地勢可按[[琴江 (广东)|琴江河]]的上下游分為兩部分，县境南部（河之上游）称为“上山”地區，北部（河之下游）稱為“下山”地区。水寨鎮位處下山地帶的河口，貿易發達，而華城則略偏於北，因而遷移。此外，“上山”地區的中心[[安流鎮]]因位處公路交滙點，同樣貿易發達，亦一度成為新县治的選址<ref>{{Cite news |title=近代五华“上山”“下山” 两次县治迁移之争 |url=https://mzrb.meizhou.cn/html/2024-02/19/content_351312.htm |work=[[梅州日报]] |date=2024-02-19}}</ref>。

=== 癸未饥荒 ===
1943年（癸未年），廣東出現大饑荒，全省死亡人數達300萬人，佔當時省內人口十分之一，史稱「[[癸未饥荒]]」。五華縣先在1942年秋季受虫患所害，農作物歉收，43年春季，再因大旱致早稻失收。不少家庭被逼借高利贷、賤賣田地，甚至全家餓死。其後因難民流亡，[[霍乱]]流行，不少人病死。五华县當時人口有三十多萬人，1942年到1945年間減少八千多人<ref>{{Cite news |title=五华人的大饥荒记忆 |url=https://mzrb.meizhou.cn/html/2024-03/25/content_353526.htm |work=[[梅州日报]] |date=2024-03-25}}</ref>。

==人口==
五华县以[[汉族]][[客家人]]为主。

2025年末，五华县户籍人口147.38万人，其中城镇人口51.49万人、乡村人口95.89万人；男性78.32万人、女性69.06万人，性别比为113.41。同年末常住人口91.87万人，其中城镇人口38.16万人，常住人口城镇化率为41.54%。<ref name="2025stat">{{Cite web |title=2025年五华县国民经济和社会发展统计公报 |url=https://www.wuhua.gov.cn/xxgk/zfjg/xtjj/zfxxgkml/gzdt/content/mpost_2906299.html |website=五华县统计局 |date=2026-05-21 |access-date=2026-07-23}}</ref>

人口最多的四個鎮依序是水寨镇、河东镇、安流镇、华城镇，其中水寨镇及河东镇有超過10萬人居住<ref>{{Cite web |title=五华县各镇常住人口统计 |url=http://data.wuhua.gov.cn/mzdata/Dataclass/show/3068/sjj |website=五华县统计局 |date=2021-06-21 |access-date=2025-10-07 |archive-date=2025-10-16 |archive-url=https://web.archive.org/web/20251016000305/http://data.wuhua.gov.cn/mzdata/Dataclass/show/3068/sjj |url-status=live }}</ref>。

== 经济 ==
2025年，五华县地区生产总值为207.38亿元，同比增长4.5%。其中，第一产业增加值为44.42亿元，增长3.2%；第二产业增加值为46.90亿元，增长9.2%；第三产业增加值为116.06亿元，增长3.4%。三次产业结构比重为21.4:22.6:56.0，全县人均地区生产总值为22515元，增长4.9%。<ref name="2025stat"/>

2025年，全县粮食产量34.19万吨，其中稻谷32.64万吨；水果产量13.33万吨，肉类总产量6.54万吨。年末有规模以上工业企业59家，规模以上工业增加值同比增长16.7%，其中制造业增长7.6%，电力、热力、燃气及水的生产和供应业增长44.8%。<ref name="2025stat"/>

第三产业方面，近年正借助高铁通车及足球文化推动旅游业发展<ref>{{Cite news |title=五华：首破200亿，产业撑起县域经济“脊梁” |url=https://www.nfnews.com/content/K3BDm1V1oY.html |work=[[南方日报]] |date=2025-06-17 |access-date=2025-10-05 |archive-date=2025-06-17 |archive-url=https://web.archive.org/web/20250617095533/https://www.nfnews.com/content/K3BDm1V1oY.html |url-status=live }}</ref>，2024年的旅游业收入较上年增长10.3%。<ref name="2024stat">{{Cite web |title=2024年五华县国民经济和社会发展统计公报 |url=https://www.wuhua.gov.cn/xxgk/sjfb/tjgb/content/post_2771184.html |website=五华县统计局 |date=2025-05-12 |access-date=2026-07-23 |archive-date=2025-10-12 |archive-url=https://web.archive.org/web/20251012074719/https://www.wuhua.gov.cn/xxgk/sjfb/tjgb/content/post_2771184.html |url-status=live }}</ref>

== 教育 ==
2025年，五华县教育支出为16.42亿元。全县有技工学校1所、职业中学1所、普通中学57所（其中高中13所）、小学161所及幼儿园222所；技工学校、职业中学、普通中学、小学和幼儿园的在校学生分别为3,892人、1,924人、82,977人、90,490人和29,298人。适龄儿童入学率为100%，小学、初中及高中毕业生升学率分别为100%、99.3%和97.5%。<ref name="2025stat"/>

县内中学和职业学校包括[[五华县水寨中学]]、五华县高级中学、五华县田家炳中学、五华县五华中学、五华县安流中学及五华县职业技术学校等。<ref>{{Cite web |title=2024年五华县教育局部门预算 |url=https://www.wuhua.gov.cn/attachment/0/184/184060/2617468.pdf |website=五华县人民政府门户网站 |access-date=2026-07-23}}</ref>县城义务教育学校包括五华县第一小学、五华县第五小学、兴华中学和华新中学等。<ref>{{Cite web |title=2025年秋季五华县城区义务教育学校招生公告 |url=https://www.wuhua.gov.cn/xxgk/zdlyxxgkzl/jyxxgk/content/post_2778077.html |website=五华县人民政府门户网站 |date=2025-05-30 |access-date=2026-07-23}}</ref>

=== 足球文化 ===
五华县與現代中國足球的關係深厚。1873年，德国传教士毕安等人於五华县辦學，將足球引入學校的體育課程內，為中國首次引入現代足球，因此曾被[[国家体委]]誉为“足球之乡”。1930年代著名足球員[[李惠堂]]正是出身於五华县<ref>{{Cite news |title=梅州加大实施“体育+”战略 |url=https://epaper.nfnews.com/nfdaily/html/202509/12/content_10147614.html |author=唐林珍, 汪思婷 |work=[[南方日报]] |date=2025-09-12}}</ref>。

現在，五华县足球氣氛依然熱切。五华县拥有省的足球训练基地和[[中国足球协会超级联赛]]首个县级城市球队——[[梅州客家足球俱乐部]]。五华县有330支足球隊，6000名球員。全县共有標準足球場291個，人均每萬人擁有足球場3.1個，為全省第一<ref>{{Cite news |title=地方立法推動足運 梅州建設足球小鎮 |url=https://www.tkww.hk/epaper/view/newsDetail/1853158037305561088.html |work=[[大公報]] |date=2024-11-04}}</ref>。梅州客家2013至2019賽季的主場[[五華縣體育場]]、2019年至今的主場[[五華惠堂體育場]]，都位於五华县。
