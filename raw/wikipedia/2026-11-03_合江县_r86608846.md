'''合江县'''是[[中华人民共和国|中国]][[四川省]][[泸州市]]所辖的一个[[县]]。因[[长江]]与[[赤水河|赤水]]在此汇合得名，被誉为“长江出川第一港口县”，水运便利。面积2422平方公里，人口约90万。

合江历史悠久，2014年10月成功申报联合国“千年古县”。<ref>{{Cite web |title=合江“千年古县”在京评审全票通过 |url=https://mp.weixin.qq.com/s/wY9U4VlQjRfRZAHk_Qd1bw |website=合江新闻 |date=2014-10-24 |language=zh-cn |author=何开明 |last= |access-date=2024-11-26 |via=微信公众平台 |archive-date=2024-12-05 |archive-url=https://web.archive.org/web/20241205171024/https://mp.weixin.qq.com/s/wY9U4VlQjRfRZAHk_Qd1bw |dead-url=no }}</ref>

== 历史 ==

[[西汉]]元鼎二年（前115年）置[[符縣]]，隶[[犍为郡]]，治安乐水会，即今合江镇南关地段。[[东晋]]穆帝永和三年（347年）后，符县改名安乐县，隶益州东江阳郡。[[南朝宋]]（420-479年）时，撤销安乐县。[[南朝齐]]（480-502年）复置安乐县，置安乐戍。[[北周]]保定四年（564年）撤销安乐戍，改置合江县，隶属泸州江阳郡。
== 人口 ==
2020年末，根據全國第七次人口普查統計數字顯示：全县常住人口为68.87万人。<ref>{{Cite web|title=中國: 四川省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/sichuan/admin/|access-date=2023-12-30|website=www.citypopulation.de|archive-date=2023-12-30|archive-url=https://web.archive.org/web/20231230221857/https://www.citypopulation.de/zh/china/sichuan/admin/|dead-url=no}}</ref>

== 地理 ==
合江位于[[四川盆地]]南缘，川渝黔结合部，长江、赤水河交汇处。属[[大娄山]]支系，地势南高北低。

== 交通 ==
合江县距泸州市区38.7公里，距[[成都市]]260.1公里， 距[[重庆市|重庆]][[朝天门]]109.2公里、{{中国高速公路名|G5001}}（外环高速）69公里。合江县是四川省与重庆市毗邻的所有区县中唯一一个既拥有长江黄金水道，又融入重庆“一小时经济圈”的县。

境内建成{{中国高速公路名|G93}}、{{China Expwy Name|G4215}}两条高速公路，规划建设{{China Expwy Name|S27||P=四川}}与{{China Expwy Name|S84||P=四川}}。{{中国国道名|353}}、{{中国省道名|438|P=四川}}、{{中国省道名|439|P=四川}}于县城交汇，{{中国国道名|546}}穿西南县境而过。其中，{{中国高速公路名|G93}}在合江两跨长江，到重庆外环高速只需57公里路程，1小时即可到达重庆市主城区境内；{{China Expwy Name|G4215}}为四川省南北向大动脉，是四川前往贵州的重要通道，也为合江交通的发展注入更大的活力。

境内长江航道全年可通航1000吨级船舶，中水期可通航2000-3000吨级船舶。

== 经济 ==
2023年合江县实现地区生产总值(GDP)319.1亿元。

== 教育 ==
全县各级各类学校218所。学前教育学校120所，义务教育学校92所，普通高中学校5所，特殊教育学校1所，老年教育机构1家，中等职业学校3所，高等教育学校1所（四川三河职业学院），成人高校（社区大学）1所。各级各类学校专任教师0.6686万人，各级各类学校在校学生12.2744万人。
