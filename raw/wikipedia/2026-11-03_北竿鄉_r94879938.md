'''北竿鄉'''（{{lang-cdo|mb=Póyk-kang-hyong|buc=Báe̤k-găng-hiŏng}}）位於[[閩江]]口外[[東海]]中，隸屬於[[中華民國]][[福建省 (中華民國)|福建省]][[連江縣 (中華民國)|連江縣]]，為該縣第二大鄉。北竿鄉轄區包括人口聚居的主要島嶼北竿島，及[[高登島]]、[[亮島]]、[[大坵島]]等大小島嶼十餘座，均屬於[[馬祖列島]]的一部分。

== 歷史 ==
北竿鄉位於[[馬祖列島|馬祖]]列島中北部，座落於福建閩江口外，昔日史書上，與[[南竿島]]分別稱作下竿塘、上竿塘或北竿塘、南竿塘，合稱竿塘。過去也有官塘、吳潼等名稱<ref name=":0">{{Cite book|chapter=|url=https://www.matsu.gov.tw/chhtml/news/371040200A/2344|publisher=連江縣北竿鄉公所|date=2005年|location=福建省連江縣|isbn=986-00-3310-2|oclc=82956237|last=邱新福|last2=|title=北竿鄉志|first=|year=|pages=|access-date=2024-03-13|archive-date=2024-03-13|archive-url=https://web.archive.org/web/20240313053536/https://www.matsu.gov.tw/chhtml/news/371040200A/2344|dead-url=no}}</ref>。 

考古證據顯示，早在距今約八千年前，即有人類於[[亮島]]活動<ref>{{Cite web|title=亮島專題之一》首次發現！澳學者 ：馬祖亮島1號人是早期出非洲的澳美人種 {{!}} 生活|url=https://newtalk.tw/news/view/2017-09-14/97539|accessdate=2020-04-24|date=2017-09-14|work=新頭殼 Newtalk|language=zh-TW|archive-date=2020-06-01|archive-url=https://web.archive.org/web/20200601164445/https://newtalk.tw/news/view/2017-09-14/97539|dead-url=no}}</ref>。北竿本島則至少在六千年前即有人類活動。至宋元世代則確知已有人長期定居。北宋中期，福建長樂、連江等縣已有沿海居民涉海徙居南北竿塘謀生，到元末時聚落發展已初有規模<ref name=":0" />。

明朝初年，政府實行[[海禁]]政策，將南北竿塘居民全數遷徙至大陸，竿塘諸島的開發因此遭受嚴重挫折。直到明代中葉開放海禁以後，才又得以發展。迨至明末時，又已村落稠密。清代初期政府則實施更嚴厲的[[遷界令]]，復將人民悉徙內地，並焚毀島上所有房舍田園。至康熙後期開始，長樂、連江等縣沿海貧民又陸續大舉遷居島上<ref name=":0" />。

1869年隨著北竿塘漁業的興盛，而對鹽的配置產生許多糾紛。[[閩浙總督]]為了進行漁戶重新配鹽，於塘岐、橋仔設置總督配鹽勒石告示碑，遂通行告示禁止。<ref>{{Cite web

1935年馬祖列島始設保甲，設竿西聯保辦公處於塘岐鹽倉（今塘岐國小），後以轄地過廣，再劃分成竿塘、西洋兩保，在當時北竿是馬祖地區的政經中心，此一地位，一直到1949年[[中華民國國軍]]進駐，先是成立[[馬祖守備區指揮部]]於南竿，接著實施戰地政務，連江縣政府設於南竿，馬祖的政經中心逐漸轉移至南竿<ref name=":0" />。

馬祖地區於1992年解除戰地政務，次年開放觀光，但同時國軍也開始逐年自馬祖撤軍，至今北竿駐軍人數僅約千人，與昔日的「北高師」一萬餘名駐軍，不可同日而語，北竿長期依賴軍方消費的經濟型態，也大幅改變，造成民生經濟重大衝擊，引發另一波人口外流。

1994年1月，島上的[[馬祖北竿機場|北竿機場]]啟用，再度開啟北竿興盛的契機，甚至一度吸引人口回流，但好景不長，在2003年1月[[馬祖南竿機場|南竿機場]]落成後，北竿不再是馬祖的空中交通的主要門戶<ref name=":0" />。不過，由於南、北竿只有十分鐘航程，近年來，在地方政府大力投入觀光軟硬體建設下，現已漸轉型為南竿的「後花園」。

== 地理 ==
=== 地形 ===
北竿鄉包括北竿島、[[高登島|高登]]、大坵、小坵、[[亮島]]以及眾多無人島礁。位居福建省閩江口外東海中，遠眺中國大陸連江縣黃岐灣。北竿島處於馬祖列島中心位置，和南竿島隔海相望，近在咫尺，最近距離不到三千公尺<ref>{{Cite web |url=http://www.beigan.gov.tw/geo_land.htm |title=北竿鄉公所全球資訊網 |access-date=2017-04-17 |archive-url=https://web.archive.org/web/20170418081333/http://www.beigan.gov.tw/geo_land.htm |archive-date=2017-04-18 |dead-url=yes }}</ref>。北竿與南竿以西海域通稱竿塘洋<ref name=":0" />。

本鄉全境總面積9.3平方公里，係第二大鄉。北竿島的主要岩體是花崗岩與花崗閃長岩，島上有壁山標高291.7公尺，是本縣第一高山<ref>連江縣(馬祖)第二高山為南竿島雲台山</ref>，另有芹山標高234.7公尺，位居第三高山。

=== 語言 ===
北竿鄉通行[[馬祖話]]，是[[閩東語]]的一種在地方言。北竿通行的馬祖話與[[长乐区|長樂區]]、[[连江县|連江縣]]的[[長樂話 (閩東語)|長樂話]]、[[連江話]]比較接近，但有一定區別。[[橋仔]]、[[塘岐]]一帶存在一些[[莆田]]和[[泉州]]的移民村落，他們中老一輩移民操[[莆仙語]]或[[閩南語]]，並且同時能夠使用馬祖話；但年輕一輩大多數只會說馬祖話。<ref>{{Cite web |url=http://www.matsu.idv.tw/beigan/history/frame02.htm |title=《北竿鄉志·住民篇·第二章：語言》 |accessdate=2015-03-30 |archive-date=2015-09-20 |archive-url=https://web.archive.org/web/20150920185322/http://www.matsu.idv.tw/beigan/history/frame02.htm |dead-url=no }}</ref>

=== 鄉政組織 ===
[[連江縣北竿鄉公所|北竿鄉公所]]是北竿鄉最高層級的地方[[行政機關]]，在中華民國政府架構中為鄉自治的行政機關，同時負責執行縣政府及中央機關委辦事項，北竿鄉的自治監督機關為[[連江縣政府]]。鄉長由全體鄉民直接選舉產生，任期為四年，可連選連任一次。北竿鄉公所並置鄉政會議，為鄉政最高決策機構，在鄉長之下，設有3課2室等5個內部單位<ref>{{Cite web |url=http://www.beigan.gov.tw/Chhtml/content/2184 |title=公所組織-組織架構 |publisher=馬祖-連江縣北竿鄉公所 |access-date=2021-10-02 |language=zh-tw |archive-date=2021-12-19 |archive-url=https://web.archive.org/web/20211219182922/http://www.beigan.gov.tw/Chhtml/content/2184 |dead-url=no }}</ref>。

[[連江縣北竿鄉民代表會|北竿鄉民代表會]]是北竿鄉的最高[[民意機關]]，代表北竿鄉全體鄉民立法和監察鄉政。鄉民代表由公民直選選出，任期為四年，可連選連任。北竿鄉民代表會共有5位鄉民代表，選區劃分上為不分區，主席、副主席由5位鄉民代表互選產生<ref>{{Cite web |url=http://client.matsu.idv.tw/tour/beigan-gov/council_now.htm |title=鄉民代表會-現任鄉代 |author=北竿鄉民代表會 |publisher=北竿鄉公所全球資訊網 |access-date=2021-10-02 |language=zh-tw |archive-date=2021-10-02 |archive-url=https://web.archive.org/web/20211002180102/http://client.matsu.idv.tw/tour/beigan-gov/council_now.htm |dead-url=no }}</ref>。

北竿鄉為[[連江縣議會]]第二選區，在連江縣議會9席縣議員中，北竿鄉共選出2席縣議員<ref>{{Cite web |url=http://client.matsu.idv.tw/gov/council/ab_organization.html |title=議會簡介-議會組織 |publisher=連江縣議會 |access-date=2022-10-27 |language=zh-tw |archive-date=2021-06-13 |archive-url=https://web.archive.org/web/20210613115920/http://client.matsu.idv.tw/gov/council/ab_organization.html |dead-url=no }}</ref>。

*[[午沙村]]：為一軍港，行政區劃隸屬於[[塘岐村]]
*[[后沃村]]：比鄰[[塘后沙灘]]與[[馬祖北竿機場|北竿機場]]和塘岐村相望，背有大澳山設立[[戰爭和平紀念公園]]
*[[坂里村]]：北竿農業中心，馬祖三寶（高麗菜、大白菜、蘿蔔）多種植於此，內有坂里沙灘與北竿遊客中心
*[[白沙村 (連江縣)|白沙村]]：原為一漁港，現已擴建為商港，是島際與兩岸海運中心
*[[芹壁村]]：閩東建築保存重點村落，，素有亞洲地中海之稱，村落前方海面有一狀似烏龜之島嶼稱「烏龜島」
*[[上村 (連江縣)|上村]]：全北竿地勢最高與唯一不靠海之村落，行政上隸屬於[[芹壁村]]
*[[橋仔村]]：廟比人多所指就是此村
