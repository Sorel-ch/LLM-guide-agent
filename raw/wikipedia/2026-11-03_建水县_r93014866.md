'''建水县'''，是[[中华人民共和国]][[云南省]][[红河哈尼族彝族自治州]]下辖的一个[[县]]，位于[[红河]]之畔、[[滇东高原]]的南部边缘，全县总面积3,782平方公里，县城建成区19.6平方公里，属于南亚热带季风气候。[[中华人民共和国第七次全国人口普查|2020年人口普查]]中全县总人口55.48万人。其中少数民族人口23.02万人，占全县总人口的41.5%，以[[彝族]]、[[回族]]、[[哈尼族]]为主。县人民政府驻[[临安镇]]。

[[南诏|南诏国]]时期，在此建惠历城，元时设建水州，明代为[[臨安府 (雲南)|临安府]]治，清时裁为建水县。元至清末時期作為滇南地区的政治、军事、经济和文化中心長達五百餘年。建水县是[[国家历史文化名城]]，自古重教兴文，进士辈出，拥有中国南方最大的[[孔庙]]之一，享有“滇南邹鲁、文献名邦”之美誉。

== 历史 ==
{{Expand section|time=2023-02-18|small=111}}

=== 南诏、大理时期 ===
[[南诏]]国时期在此筑城，称惠历城，汉语译作建水。后[[大理国]]设建水郡。

建水地区因位于滇南交通要道，连接滇中与红河流域，自南诏时期起即为滇南重要城镇。大理国时期，建水郡成为其南部边疆的重要据点之一。<ref>{{cite book |title=中国历史地名大辞典 |publisher=中国社会科学出版社 |year=2005 |page=1638}}</ref>

=== 明清时期 ===
{{seealso|臨安府 (雲南)}}
明洪武十五年（1382年），临安路改临安府，府治迁至建水州，并设临安卫指挥使司（滇南军事指挥机关），拓地改建砖城，故有建水城又称“临安城”。<ref>{{Cite web |title=千年古镇 建水临安 |url=https://ynmz.yn.gov.cn/cms/dimingfengcai/11250.html |website=云南省民政厅 |date=2024-11-27 |access-date=2026-06-10}}</ref>

明代以后，建水长期为临安府治所在地，是滇南地区的政治、军事与文化中心。<ref>{{cite book |title=建水县志 |publisher=中华书局 |year=1994 |page=72-75}}</ref>由于文风兴盛、科举人才辈出，素有“文献名邦”“滇南邹鲁”之称。

清初沿明制，于此置临安府和临元镇总兵官，建水州属临安府。雍正八年（1730年）7月，临安府属迤东道。乾隆三十一年（1766年）10月，临安府属迤南道。乾隆三十五年（1770年）2月，改建水州为建水县，仍属临安府。<ref>{{Cite web |title=红河“三千四百年”历史文化名片——千年临安古城 |url=https://www.hh.gov.cn/info/9021/794782.htm |website=红河哈尼族彝族自治州人民政府 |date=2022-02-15 |url-status=live |access-date=2026-06-10}}</ref>光绪十三年（1887年）10月，临安府属临安开广道。

清代建水商业繁荣，城内兴建大量书院、祠庙及民居建筑，形成现存建水古城的基本格局。现存的[[朝阳楼]]、[[朱家花园]]等历史建筑均与这一时期的发展有关。<ref>{{cite book |title=云南通史（清代卷） |publisher=云南大学出版社 |year=2011 |page=356-360}}</ref>

=== 中华民国时期 ===
民国元年（1912年）10月，临安府所在地的建水县被裁撤，由临安府府长兼理建水县行政事务。民国二年（1913年），撤销临安府，复设县治于建水，改名为临安县；将建水县北区划出，设曲江行政委员，属县级行政机关，隶[[蒙自道]]。民国三年（1914年）1月，因与浙江临安县重名，仍恢复建水县旧名。民国七年（1918年），撤曲江行政委员，改由建水县曲江县佐管理，县佐由省政府委派。<ref name=":1">{{Cite journal |title=建水县志 |journal= |publisher=昆明:中华书局 |year=1994.5 |page=1-47 |via=建水县志编纂委员会|issue=ISBN 7-101-01324-4}}</ref>

民国十一年（1922年），将曲江县佐地划出，增设曲溪县，民国十八年（1929年）11月，县政府驻新街。民国十八年（1929年），废道后建水、曲溪县由省直辖。民国三十一年（1942年），建水、曲溪县属云南省第三行政督察区（驻建水县）。民国三十七年（1948年），建水、曲溪县属云南省第五行政督察区（驻建水县）。<ref name=":1" />

民国时期，建水仍为滇南重要城镇和区域交通枢纽。随着近代教育的发展，建水传统书院逐步改制为新式学校，对滇南近代教育产生一定影响。<ref>{{cite book |title=建水文史资料选辑 |publisher=中国人民政治协商会议建水县委员会 |year=1990 |page=45-52}}</ref>

== 地理 ==
建水位于云南省南部，[[滇东高原]]南缘<ref>{{Cite web |title=自然概貌_印象云南_云南省人民政府门户网站 |url=https://www.yn.gov.cn/yngk/gk/201904/t20190403_96255.html |website=www.yn.gov.cn |access-date=2026-06-10}}</ref>，[[北回归线]]横贯县境。

境内山区面积3381平方千米，占总面积的89%，而坝子面积仅有408平方千米。坝子中以建水坝子最大，面积约260平方千米，其次为曲江坝子和面甸坝子<ref name=":2" />。

县内最高峰为焕文山五老峰，海拔2515米。红河岸边的阿土村海拔仅230米，为境内海拔最低点。

境内河流大部分属于[[南盘江]]水系，南部地区为[[红河]]水系。<ref name="南疆邹鲁">{{Cite book |author=曹荆, 谭晓云 |title=南疆邹鲁——建水 |publisher=三秦出版社 |year=2003 |isbn=7-80628-737-X |pages= }}</ref>

==经济==
2022年，建水县[[国内生产总值|生产总值]]达262.32亿元，按可比价格计算，比上年增长3.0%。其中[[第一产业]]增加值51.68亿元，增长5.3%；[[第二产业]]增加值67.08亿元，增长3.5%；[[第三产业]]增加值143.56亿元，增长1.8%。三次产业结构为19.7∶25.6∶54.7。人均生产总值49,225元。城乡常住居民人均可支配收入分别为42,088元、19,974元。职工年平均工资119,521元。地方一般公共预算收入12.39亿元，人均2,326元。地方一般公共预算支出40.86亿元，人均7,667元。<ref name=":2">{{Cite book|title=云南统计年鉴 2023|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

== 人口 ==
[[File:Jianshui Xian - Qujiang Zhen - Guanyi Cun - P1360748.JPG|thumb|建水县曲江镇馆驿村]]
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，建水县总人口（常住人口）共有534,205人，城镇人口271,874人（占50.89%），乡村人口262,331人（占49.11%）。共有男性274,691人、女性259,514人，[[人類性別比|性别比]]为105.85。0—14岁人口共94,942人（占17.77%），15—59岁人口共349,681人（占65.46%），60岁及以上人口共89,582人（占16.77%），其中65岁及以上人口共66,046人（占12.36%）。大学专科学历及以上人口有39,740人，15岁以上的文盲有8,809人，占15岁以上人口的2.01%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>

===民族===
全县人口中，[[汉族]]人口最多，约占三分之二，其次为[[彝族]]、[[回族]]、[[哈尼族]]、[[傣族]]、[[苗族]]等。其中彝、哈尼、傣族为土著民族，汉、回族主要于元明时期迁入，而苗族则多数为中华人民共和国成立后迁入。<ref name="南疆邹鲁"/>

== 文化 ==
文化为多民族融合型态，主要风俗有“花灯”、“长街宴”、彝族山歌“四大腔”等，特产手工制作的紫陶器。

== 风景名胜 ==
{{see also|建水县各级文物保护单位列表}}
[[File:臨安府署 20191225113040 01.jpg|thumb|臨安路上的臨安府署]]
*1994年建水风景名胜区被列为[[国家重点风景名胜区]]。建水风景名胜区以建水古城为核心，此外还有燕子洞和红河大峡谷两处景区。燕子洞是一组大型[[溶洞]]，有水、旱两洞，巢居着数十万只雨燕。而红河大峡谷则以民族风情为旅游特色。

*[[全国重点文物保护单位]]：[[纳楼长官司署]]、[[建水文庙]]、[[指林寺大殿]]、[[朝阳楼]]、[[双龙桥]]、[[建水土主庙]]、[[学政考棚]]、[[建水玉皇阁|玉皇阁]]及[[建水崇文塔|崇文塔]]

*[[云南省文物保护单位]]：[[朱家花园]]、[[建水古窑]]、[[天缘桥]]、[[建水文笔塔|文笔塔]]、[[团山民居]]

* 位於建水古城核心區臨安路上的[[臨安府 (雲南)|臨安府署]]，經過四年的修繕重建已於2019年9月28日孔子文化節當天重新開放參觀。臨安府署為明清兩代「府」級官署，即俗稱（府級）衙門。始建於明洪武15年，至今已有630多年歷史可考。四年前，為完整展现建水古城历史价值與文化内涵，进一步丰富古城旅游业态，建水县决定恢复重建临安府署。如此，建水便具备了从衙、官（学政考棚）、学（文庙）、楼（朝阳楼）、墙（古城墙）、商（明清商业街）、住（古宅恢复）、家（朱家花园）等各历史文化元素都完备的古城风貌。<ref>{{Cite web|title=云南建水：再现明清滇南盛景的临安府署正式开放|url=https://wap.peopleola.com/travel/20190929/77e1d1127435d40b.html|accessdate=|author=|date=|format=|publisher=|language=|archive-url=https://web.archive.org/web/20200419001453/https://wap.peopleola.com/travel/20190929/77e1d1127435d40b.html|archive-date=2020-04-19|dead-url=yes}}</ref>
