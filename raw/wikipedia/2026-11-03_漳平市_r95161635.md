'''漳平市'''为[[福建省]][[龙岩市]]代管的县级市，位于福建省西南部，[[九龙江]]北溪上游，地处[[闽西]]的东大门，东毗[[永春县]]、[[安溪县]]，南连[[华安县]]、[[南靖县]]，西邻[[新罗区]]，北接[[永安市]]、[[大田县]]，是[[华南]]重要的交通枢纽，也是福建省重要的花卉和茶叶产地。市人民政府駐[[菁城街道]]。

==名称由来==
《[[读史方舆纪要]]》载：“县居漳上游，千山中地稍平衍，因曰漳平”<ref>{{cite web|date=2006-05-15|title=你知道漳平的行政变迁吗？|url=http://www.zp.gov.cn/TourInfo/ShowArticle.asp?ArticleID=44|accessdate=2008-05-29|publisher=漳平市人民政府|language=zh-hans}}{{dead link|date=2018年3月|bot=InternetArchiveBot|fix-attempted=yes}}</ref>。

== 历史 ==
[[明]][[成化]]六年（1470年）析龙岩县（今新罗区）置漳平县。

[[第二次国共内战]]期间，[[中国人民解放军]]闽粤赣边区纵队第八支队第四团一营联合漳平县武工队及民兵于1949年6月21日攻取漳平县城。<ref>{{cite news|title=70年前，解放的号角响彻泉州城|url=http://www.qzwb.com/gb/content/2019-09/06/content_7003501.htm|author=吴拏云|publisher=泉州网|date=2019-09-06|editor=黄冬虹|access-date=2019-09-06|archive-url=https://web.archive.org/web/20191106132740/http://www.qzwb.com/gb/content/2019-09/06/content_7003501.htm|archive-date=2019-11-06|dead-url=yes}}</ref>

1956年，[[宁洋县]]撤销，县城双洋等地划归漳平县。1990年8月，漳平撤县建市。

== 地理 ==
东连[[永春县]]、[[安溪县]]，东南与[[华安县]]交界，南与[[南靖县]]接壤，西与[[新罗区]]相连，北与[[永安市]]交界，东北与[[大田县]]毗邻。

漳平地势从南、北向河谷倾斜。苦笋林尖[[海拔]]1666米，为全市最高峰。主要河流[[九龙江]]北溪。年平均气温20.3℃，年降水量1496毫米，无霜期317天。

== 人口 ==
以[[汉族]][[闽南人]]为主，少数[[客家人]]。有[[满族]]、[[蒙古族]]、[[畲族]]、[[回族]]、[[苗族]]、[[壮族]]、[[布依族]]、[[土家族]]等少数民族。

根据[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]数据，截至2020年11月1日零时，漳平市户籍总户数8.75万户，总人口29.15万人。<ref>{{Cite web|title=中國: 福建省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/fujian/admin/|access-date=2023-08-14|website=www.citypopulation.de|archive-date=2021-02-26|archive-url=https://web.archive.org/web/20210226125808/https://www.citypopulation.de/zh/china/fujian/admin/|dead-url=no}}</ref>

== 物产 ==
* 矿产有金、银、铁、煤、钨、石灰石、铅锌、铜、稀土、石墨、大理石等20多种。
* 福建省潘洛铁矿由潘田、洛阳两矿区组成。洛阳矿区位于漳平市芦芝乡大深村；该矿建于1958年，现为本省最大的铁矿石生产基地，国家中型铁矿山。40多年来，该矿职工艰苦创业，将潘洛铁矿建成为拥有各种矿山机械设备，采矿、选矿、运输机械化的成龙配套的现代化中型铁矿山，设计年采铁矿能力90万吨，年选矿能力40万吨。
* 土特产主要有笋干、水仙茶、明姜、花卉、青仁乌豆、水蜜桃、芦芝柚、竹藤编。
