'''来宾市'''（{{langx|za|Laizbinh Si}}）是[[中华人民共和国]][[广西壮族自治区]]下辖的[[地级市]]，位于广西中部。市境西南接[[南宁市]]，西北邻[[河池市]]，北界[[柳州市]]，东北连[[桂林市]]、[[梧州市]]，东南毗[[贵港市]]。地处桂中盆地低山丘陵区，地势东西高，中间低，东部为[[大瑶山]]。[[红水河]]穿越市区，在市境中部与[[柳江]]汇合成[[黔江]]。[[湘桂铁路]]穿过境内，全市[[壮族]]人口比例超过七成，市人民政府驻[[兴宾区]]城北街道人民路1号。

== 历史 ==
[[唐朝|唐]][[乾封]]二年（667年）在境内置[[严州]]，辖循德、归化、怀义3县。[[天宝 (唐朝)|天宝]]二年（743年），怀义县更名为来宾县，据《[[元和郡县志]]》记载：来宾“在都泥江北，来宾水（今[[北之江]]）东，故以得名”。[[宋朝|宋]]、[[元朝|元]]两代属[[象州]]。[[明朝|明]]、[[清朝|清]]属[[柳州府]]。

[[中華民國|民国]]2年（1913年）废府制，县由省直辖。民国6年（1927年）设立[[柳江道]]，来宾县属之。民国38年（1949年）属[[廣西省 (中華民國)|广西省]]第十三行政督察区所辖。

1949年11月30日，[[解放军]]占领来宾县，由[[柳州专区]]所辖。1953年改属[[宜山专区]]。1954年，来宾县政府驻地由城厢迁至水落村（今来宾城区）。1958年，宜山专区更名柳州专区，来宾县属之，专署驻[[柳州市]]。1970年，柳州专区改为[[柳州地区]]。1981年6月，由来宾县析置[[合山市]]。2002年，撤销柳州地区，新设立地级来宾市，来宾县改为来宾市[[兴宾区]]，来宾市辖原柳州地区的[[忻城县]]、[[象州县]]、[[武宣县]]、[[金秀瑶族自治县]]，代管县级合山市。

== 人口 ==
截至2022年末，来宾市户籍总人口267.77万人。全市常住人口207.78万人，占总人口的比重为77.6%，其中城镇人口102.27万人，占常住人口比重（即常住人口城镇化率）为49.22%，比上年末提高0.11个百分点。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,074,611人<ref>{{cite web |author1=来宾市统计局、来宾市第七次全国人口普查领导小组办公室 |title=来宾市第七次全国人口普查主要数据公报 |url=http://www.laibin.gov.cn/hdjl/hygq/t9041362.shtml }}{{Dead link}}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,099,711人相比，十年共减少了25,100人，下降1.2%，年平均增长率为-0.12%。其中，男性人口为1,074,915人，占总人口的51.81%；女性人口为999,696人，占总人口的48.19%。总人口性别比（以女性为100）为107.52。0－14岁的人口为483,711人，占总人口的23.32%；15－59岁的人口为1,222,582人，占总人口的58.93%；60岁及以上的人口为368,318人，占总人口的17.75%，其中65岁及以上的人口为271,907人，占总人口的13.11%。居住在城镇的人口为1,006,712人，占总人口的48.53%；居住在乡村的人口为1,067,899人，占总人口的51.47%。

=== 民族 ===
全市常住人口中，[[壮族]]人口为1,493,971人，占72.01%；[[汉族]]人口为484,400人，占23.35%；其他[[少数民族]]人口为96,240人，占4.64%。与2010年第六次全国人口普查相比，汉族人口减少2,399人，下降0.49%，占总人口比例增加0.16个百分点；各少数民族人口减少22,701人，下降1.41%，占总人口比例下降0.16个百分点。其中，壮族人口减少34,605人，下降2.26%，占总人口比例下降0.79个百分点；瑶族人口增加5,119人，增长7.46%，占总人口比例增加0.29个百分点。

== 地理 ==
来宾市位于广西中部，故有"桂中"之称，东经108°24′-110°28′，北纬23°16′-24°29′之间，北回归线从境内穿过，市域总面积13411平方千米，市政府驻地兴宾区距离首府[[南宁市]]156公里；[[西江]]干流红水河穿越市区，[[红水河]]、柳江在武宣县境内交汇后称黔江，来宾市属于西江经济带城市之一，有5个县(市、区)通航，千吨级船舶可直航珠三角，内河通航里程341千米。

来宾市地处桂中低山丘陵区，地貌类型以山地丘陵为主，山地占38.4%，丘陵占26.2%，平原占22.5%，台地占8.8%，其余为水域等。人均耕地2.82亩。年平均气温21.2°C，年降雨量1959.6毫米，森林面积687813公顷，[[森林覆盖率]]达51.4%<ref>{{cite web |title=广西来宾 |url=http://www.laibin.gov.cn/zjlb/t71076.shtml |website=来宾市人民政府 |date=2021-09-06 |access-date=2022-08-20 |archive-date=2021-03-04 |archive-url=https://web.archive.org/web/20210304193427/http://www.laibin.gov.cn/zjlb/t71076.shtml |dead-url=no }}</ref>。
