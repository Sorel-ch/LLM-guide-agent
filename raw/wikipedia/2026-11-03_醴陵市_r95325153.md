'''醴陵市'''，[[湖南省]]辖[[县级市]]，由[[株洲市]]代管，地处湖南省东部，东与[[江西省]][[湘东区|萍乡市湘东区]]交界，东北连江西省萍乡市[[上栗县]]，北界[[浏阳市]]，西接[[渌口区]]，南邻[[攸县]]。醴陵市辖19个[[镇]]、5个[[街道办事处|街道]]、1个省级经济开发区，区域总面积为2156.46平方千米。2022年末，醴陵市人口总户数为28.1万户，户籍人口数为102.7万人。

== 词源 ==

已知「醴陵」之名最早的紀錄出自《[[史记]]》，“（[[吕后]]）四年，封[[呂嬃]]為臨光侯，[[呂他]]為俞侯，[[呂更始]]為贅其侯，[[呂忿]]為呂城侯，及諸侯丞相五人。”<ref>{{cite book |author1=[[司马迁]] |title=《史記/卷009》 |url=https://zh.wikisource.org/wiki/%E5%8F%B2%E8%A8%98/%E5%8D%B7009 |accessdate=2023-09-18 |archive-date=2023-04-01 |archive-url=https://web.archive.org/web/20230401084509/https://zh.wikisource.org/wiki/%E5%8F%B2%E8%A8%98/%E5%8D%B7009 |dead-url=no }}</ref>而《[[:s:史記集解 (司馬遷, 四庫全書本)/卷009|会注考证]]》中则提到吕后册封的“諸侯丞相五人”中，就有获封'''醴陵侯'''的刘越<ref name="l">{{cite book |author1=《醴陵市志》编纂委员会 |title=《醴陵市志》 |date=1995年2月 |publisher=湖南出版社 |location=湖南省长沙市 |isbn=7543809354 |url=http://www.hnfzg.cn:8889/xboot/elasticsearch/openHtml?id=215288978889248771 |access-date=2023-09-18 |archive-date=2023-11-06 |archive-url=https://web.archive.org/web/20231106165134/http://www.hnfzg.cn:8889/xboot/elasticsearch/openHtml?id=215288978889248771 |dead-url=yes }}</ref>{{rp|1110}}。[[清朝]][[同治]]年间的《醴陵县志》还认为醴陵之名在秦朝即已经存在。此名稱的來源有兩種說法，[[宋朝]]《[[元丰九域志]]》称当地的山陵上有井，井水甘甜似醴（甜酒）而得名醴陵，该说法也为后世的《舆地广记》、《一统志》、《湖广通志》乃至[[中华人民共和国]]时期的部分典籍所采纳<ref name="k">{{cite book |author1=《醴陵市志》编纂委员会 |title=《醴陵市志（1991-2002）》 |date=2005年9月 |publisher=湖南人民出版社 |location=湖南省长沙市 |isbn=7543841185}}</ref>{{rp|814}}；不过也有部分学者认为“醴陵”得名于当地原住民[[扬越]]人取[[渌水]]酿造甜酒，其居住的山丘因此得名“醴陵”<ref name=p>{{cite journal |author1=彭雪开 |title=醴陵地名源流考释 |journal=《湖南大学学报(社会科学版)》 |date=2012年 |volume=26 |issue=3 |pages=33-37 |url=http://www.cnki.com.cn/Article/CJFDTOTAL-HDXB201203010.htm |publisher=湖南大学 |location=湖南省长沙市 |access-date=2023-09-18 |archive-date=2019-05-11 |archive-url=https://web.archive.org/web/20190511222824/http://www.cnki.com.cn/Article/CJFDTOTAL-HDXB201203010.htm |dead-url=no }}</ref>{{rp|34-35}}，而“陵”所指的山丘则是[[杨岐山]]，当地在[[东汉]]初期隶属于醴陵县，后来才划归[[萍乡县]]<ref>{{cite journal |author1=丁水生 |title=酒文化和醴泉文化的结合——也说醴陵地名的由来 |journal=《湖南工业大学学报（社会科学版）》 |date=2009-06-03 |volume=14 |issue=2 |doi=10.3969/j.issn.1674-117X.2009.02.011 |publisher=湖南工业大学 |location=湖南省株洲市 |issn=1674-117X}}</ref>{{rp|45}}。

== 历史 ==

醴陵一带在夏朝时期属于[[荊州 (九州)|荆州]]<ref name="l" />{{rp|56}}，而在[[商朝]]时期，醴陵已经拥有手工藝製作與貿易产业<ref>{{cite journal|author=高至喜|title=《“商文化不过长江”辨——从考古发现看湖南的商代文化》|pages=107-112|journal=《求索》|date=1981年|issue=第02期|url=http://www.cnki.com.cn/Article/CJFDTOTAL-QSZZ198102015.htm|access-date=2023-09-18|archive-date=2019-05-10|archive-url=https://web.archive.org/web/20190510152143/http://www.cnki.com.cn/Article/CJFDTOTAL-QSZZ198102015.htm|dead-url=no}}</ref>{{rp|108}}<ref>{{Cite ZGBK |id=127070 |title=象尊 |author=李松 |date=2022-01-20}}</ref>。[[春秋时期|春秋]]及[[战国]]时期，当地隶属于[[楚国]][[黔中郡]]<ref name="l" />{{rp|56}}，[[秦灭六国]]后，当地属[[长沙郡]][[临湘县 (西汉)|临湘县]]，并已经建立了基層行政區單位<ref name="k" />{{rp|814}}<ref name=p />{{rp|34}}。[[西汉]]时期，[[吕后]]分封刘越为醴陵侯，并在今[[国瓷街道]]古城村建立醴陵侯城，醴陵仍属临湘县<ref>{{cite news |title=醴陵古城，你知道吗？ |url=https://zzrb.zznews.gov.cn/content/201808/03/c1440113.html |work=株洲日报 |date=2018-08-03 |location=湖南省株洲市 |page=B3 }}{{Dead link}}</ref>，后刘越因罪被废，醴陵侯城因此荒废<ref name="l" />{{rp|56}}。

[[东汉]]时期，朝廷析[[临湘县 (西汉)|临湘县]]及[[湘南县]]地置[[醴陵县]]<ref>{{cite book |author1=[[陈梦雷]] |title=《欽定古今圖書集成》 |date=1726年 |url=https://zh.wikisource.org/wiki/%E6%AC%BD%E5%AE%9A%E5%8F%A4%E4%BB%8A%E5%9C%96%E6%9B%B8%E9%9B%86%E6%88%90/%E6%96%B9%E8%BC%BF%E5%BD%99%E7%B7%A8/%E8%81%B7%E6%96%B9%E5%85%B8/%E7%AC%AC1201%E5%8D%B7 |accessdate=2023-09-18 |archive-date=2021-02-25 |archive-url=https://web.archive.org/web/20210225080450/https://zh.wikisource.org/wiki/%E6%AC%BD%E5%AE%9A%E5%8F%A4%E4%BB%8A%E5%9C%96%E6%9B%B8%E9%9B%86%E6%88%90/%E6%96%B9%E8%BC%BF%E5%BD%99%E7%B7%A8/%E8%81%B7%E6%96%B9%E5%85%B8/%E7%AC%AC1201%E5%8D%B7 |dead-url=no }}</ref>，县治在原醴陵侯城，后迁至今址<ref name=p />{{rp|36-37}}。[[隋朝]]大业三年（607年），醴陵县并入[[长沙县]]。[[唐]]武德四年（621年）分长沙县复置醴陵县<ref name="l" />{{rp|56}}。[[元代]]曾升为醴陵州，[[明朝]][[洪武]]二年（1369年）初，醴陵废州复县，隶[[长沙府]]<ref>{{cite book |author1=嵇璜、刘墉 撰 |coauthors=紀昀 校訂 |title=《钦定续通典 (四库全书本)》 |date=1783年 |url=https://zh.wikisource.org/wiki/%E6%AC%BD%E5%AE%9A%E7%BA%8C%E9%80%9A%E5%85%B8_(%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC)/%E5%8D%B7144 |accessdate=2023-09-18}}</ref>。中华人民共和国甫成立时，醴陵县由长沙区行政专员公署管辖，后归属[[湘潭专区]]<ref>{{cite book |author1=《湘潭市志》编纂委员会 |title=《湘潭市志（第七册）》 |date=1997年 |publisher=中国文史出版社 |location=北京市 |isbn=7503406895 |page=438-439}}</ref>。1959年，该县[[渌口镇]]、均坝乡、南阳桥乡、洲坪乡、漂沙井乡、鸿仙乡、姚家坝乡等乡镇并入株洲市郊区<ref>{{cite book |author1=《株洲市郊区志》编纂委员会 |title=《株洲市郊区志》 |date=1993年12月 |page=21 |url=http://www.hnfzg.cn:8889/chorography/catalogue/getLevelOne?bookId=183559 }}{{Dead link}}</ref>。1983年7月，醴陵从湘潭转划归株洲市管辖，1985年5月24日，[[中华人民共和国国务院]]批准撤销醴陵县，设立[[县级市|县级]]醴陵市，由[[地级市|地级]][[株洲市]]代管，并以原醴陵县的行政区域作为醴陵市的行政区域<ref>{{cite book |author1=株洲市地方志编纂委员会 |title=《株洲市志（第一册）》 |date=1995年8月 |publisher=湖南出版社 |location=湖南省长沙市 |isbn=7543810514 |page=91-92 |edition=1}}</ref>。

== 地理 ==
* 醴陵市位于湖南东部，[[罗霄山脉]]北段西沿，[[湘江]]支流渌水流域。地貌以[[山地]]、[[丘陵]]和[[岗地]]为主，[[平原]]占16%，水域占5%。境内江河交织，均属湘江水系人杰地灵。主要河流有渌水、昭陵河和涧江，[[水利资源]]蕴藏量为87462千瓦，地下水量16.3亿立方米。市内共有大中小型[[水库]]193座。 市境属中[[亚热带]]东南季风湿润气候。年均气温18℃左右，[[无霜期]]305-279天，年平均日照时数1588-1321小时，[[年平均降水量]]在1300至1600毫米之间。 
* 目前已发现的矿种有[[铀]]、[[金]]、[[银]]、[[铁]]、[[锰]]、[[铅]]、[[锌]]、[[煤]]、[[石灰石]]、[[瓷泥]]等23种，矿产地117处，其中大型矿床1处，中型矿床6处。
* 土壤成分以[[板页岩]]为主，占47.8%；次为红色[[粘土]]，占20.7%。植物资源丰富，具备粮食作物、经济作物和林木生长的良好自然条件。[[瓷土]]、[[陶土]]、[[耐火泥]]、[[石灰石]]、[[沙石]]等[[非金属矿产]]和铅、锌等金属矿产蕴藏丰富。

== 行政区划 ==
{{PAGENAMEBASE}}下辖4个[[街道办事处]]、19个[[行政建制镇|镇]]<ref>{{PRC admin/ref sgc|43/02/81}}</ref>：

醴陵于1949年7月实现和平解放，隶属湖南省长沙专区，1952年9月改属湘潭专区，1983年7月，划归株洲市管辖。醴陵辖区行政区划在不同历史时期均有一定的调整。新中国成立初期，醴陵辖区面积为2506.5平方公里，划为5个区。1950年建立乡村政权，划全县为11个区、1镇，154个乡和7个居民委员会。1958年至1982年，实行“政社合一”的人民公社制度。1959年1月，将西北乡349.3平方公里地域划归株洲市郊区管辖。1985年5月，醴陵撤县设市（县级）。为加快小城镇建设步伐，一批乡先后撤乡建镇，且多次开展乡、村合并。2015年，湖南省进行乡镇区划调整改革，此后全市下辖李畋镇、浦口镇、王仙镇、船湾镇、明月镇、茶山镇、左权镇、枫林镇、白兔潭镇、东富镇、板杉镇、沩山镇、嘉树镇、官庄镇、孙家湾镇、石亭镇、均楚镇、泗汾镇、沈潭镇等19个乡镇，来龙门街道、国瓷街道、阳三石街道、仙岳山街道等4个街道办事处，共有40个村和19个社区。<ref>{{cite web |title=醴陵市乡镇区划调整改革工作方案已获省民政厅批复 |url=http://www.liling.gov.cn/c1051/20161012/i234454.html |accessdate=2018-10-11 |archive-date=2020-11-16 |archive-url=https://web.archive.org/web/20201116114634/http://www.liling.gov.cn/c1051/20161012/i234454.html }}</ref>

== 经济 ==
*2022年，醴陵市实现地区生产总值875.7亿元，按可比价计算，增长5.4%。分产业看：第一产业实现增加值76.9亿元，增长3.1%；第二产业实现增加值473.3亿元，增长6.9%，其中：工业增加值增长5.5%；第三产业实现增加值325.5亿元，增长3.9%。三次产业结构由2021年的9.4:53.3:37.3调整为8.8:54:37.2。三次产业对经济增长的贡献率依次为5.6%、67.3%和27.1%，分别拉动经济增长0.3个、3.6个和1.5个百分点。人均地区生产总值达9.95万元。
*2022年，醴陵市完成地方税收收入22.3亿元，增长14.2%。地方税收收入占地方收入比重为72.1%。公共财政预算支出84.8亿元，增长3.0%，其中：教育、科学技术、卫生健康、农林水事务、社会保障和就业、住房保障支出分别为11.7亿、8.0亿、8.8亿、9.7亿、10.4亿、1.8亿，分别增长1.9%、88.3%、1.1%、4.5%、8.1%、16.4%；文化体育与传媒支出0.86亿，分别下降38.9%。
*2022年，醴陵市固定资产投资增长5.5%。分产业来看，第一产业下降42.2%，第二产业增长19.5%，第三产业下降29.9%。从投资方向来看，工业投资增长19.5%，房地产开发投资下降51.5%，高新技术产业投资增长109.4%。
*2022年，醴陵市城乡居民人均可支配收入4.45万元，其中城镇居民人均可支配收入5.1万元，同比增加2616元，增长5.4%；农民居民人均可支配收入3.6万元，同比增加2203元，增长6.5%。城乡居民人均可支配收入比为1.41，比2021年缩小0.02。

* 建国以来醴陵投资规模最大的旗滨玻璃项目总投资50亿元，将搬迁升级、新建5条国内最先进的浮法节能玻璃生产线，3年建成达产后，年销售收入可达50亿元，税收不低于3亿元。
* 醴陵是[[花炮]]创始人[[李畋]]的故乡，目前[[花炮]]制作产业极为兴旺，是全市的另一个经济支柱。
* 此外，还有[[建材]]、[[电瓷]]、陶瓷机械和[[服装]]工业等也发展较快。
* 农业主产[[水稻]]、[[番薯|甘薯]]等，特产[[辣椒]]、[[西瓜]]。

== 教育 ==

在宋朝时期，醴陵县城已经建立了数座书院，此为醴陵教育事业之始<ref name="l" />{{rp|695}}，明清时期，私塾与义学也开始在醴陵发展。[[光緒]]二十七年（1901年），[[清政府]]採取教育改革措施，下詔改全國書院為學堂；因此在1904年，渌江书院改制为渌江高等小学堂，翌年，醴陵在地的知识分子[[文俊铎]]、[[宁调元]]等人将小学堂增建为渌江中学堂，开始传播新式教育理念<ref name="a">{{cite book |author1=株洲市地方志编纂委员会 |title=《株洲市志（第十三册）》 |date=1996年11月 |publisher=湖南出版社 |location=湖南省长沙市 |isbn=7543813521}}</ref>{{rp|36}}。醴陵目前有一所湖南工业大学醴陵陶瓷学院，醴陵市陶瓷烟花职业技术学校是唯一一所公办职业学校<ref>{{Cite web |url=http://www.llzz.cn/show.asp?id=352 |title=存档副本 |access-date=2011-05-23 |archive-url=https://web.archive.org/web/20180501230617/http://www.llzz.cn/show.asp?id=352 |archive-date=2018-05-01 |dead-url=yes }}</ref>，[[醴陵一中]]已经成为湖南省屬重點中學，实力较强劲，其培養的學生中也不乏考入北京大學及清華大學等中国大陆重點高校者<ref>{{cite web |author1=肖捷、匡凤 |title=从全球逾6300件参赛作品中脱颖而出 醴陵一中图书馆获“缪斯设计奖”银奖 |url=http://www.zhuzhouwang.com/2023/0421/408917.shtml |website=株洲网 |publisher=[[株洲晚报]] |date=2023-04-21 }}{{Dead link}}</ref><ref name=rn>{{cite web |title=醴陵市第一中学：承继百年办学强势 铸就三湘教育品牌 |url=https://moment.rednet.cn/pc/content/646745/54/12217020.html |website=[[红网]] |date=2023-01-10}}</ref>，[[醴陵四中]]以艺术特长生闻名于株洲。
