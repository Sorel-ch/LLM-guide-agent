'''大理市'''（[[拼音白文|白文]]：{{lang|bfs|Dallit sil}}）是[[中华人民共和国]][[云南省]][[大理白族自治州]]的一个[[县级市]]，也是大理州的州府，位于[[中国]][[云南省]]西部，地处[[云贵高原]]，[[蒼山 (大理)|苍山]]之麓，[[洱海]]之滨，全市面积1739平方千米，2020年总人口77.11万人，市人民政府驻[[海东镇]]。

大理市是[[国家历史文化名城]]<ref>{{Cite web |date=1982-02-08 |title=国务院转批国家基本建设委员会等部门关于保护我国历史文化名城的请示的通知 |url=http://www.gov.cn/gongbao/shuju/1982/gwyb198204.pdf |publisher=中华人民共和国国务院 |archive-url=https://web.archive.org/web/20200601050128/http://www.gov.cn/gongbao/shuju/1982/gwyb198204.pdf |archive-date=2020-06-01 |dead-url=no |accessdate=2020-01-29}}</ref>、[[中国优秀旅游城市]]、[[国家园林城市]]<ref>{{Cite web |date=2016-01-15 |title=住房城乡建设部关于2015年国家生态园林城市、园林城市、县城和城镇的通报 |url=http://www.mohurd.gov.cn/wjfb/201601/t20160129_226498.html |publisher=中华人民共和国住房和城乡建设部城市建设司 |archive-url=https://web.archive.org/web/20210517041538/http://www.mohurd.gov.cn/wjfb/201601/t20160129_226498.html |archive-date=2021-05-17 |accessdate=2022-05-16 |dead-url=yes}}</ref>、[[国家全域旅游示范区]]<ref name=":10" />。古代先后为[[南诏国]]和[[大理国]]的都城，是云南省开发较早的地区之一，曾作为云南地区的政治、经济和文化中心长达五百余年。

== 历史 ==
=== 汉至清末 ===
[[File:Du Halde, map of Dali.jpg|thumb|left|18世纪初期由法国绘制的大理地图。]][[汉武帝]]时期，[[张骞]]出使[[西域]]，刺激汉武帝探索从西南方前往[[印度]]的“[[蜀身毒道]]”，经营西南边疆。[[汉武帝]][[元封]]二年（前109年）在大理地区遥置[[叶榆县]]，隶属[[益州郡]]。[[东汉]][[永平 (东汉)|永平]]十二年（69年）置[[永昌郡]]，叶榆县属永昌郡。[[蜀汉]][[建兴 (蜀汉)|建兴]]三年（225年），[[诸葛亮南征]]，分[[建宁郡]]、[[越巂郡]]、[[永昌郡]]三郡置[[雲南郡|云南郡]]，叶榆县属云南郡。[[西晋]][[永嘉 (西晋)|永嘉]]五年（311年），析云南郡置[[东河阳郡]]，叶榆县改属东河阳郡。[[隋朝]]时隶南宁州总管府。

[[唐朝]]初年，洱海周边有6个较大的部落，称为[[六诏]]。[[唐高宗]]时，蒙舍诏以外的五诏均被[[吐蕃]]征服。唐[[开元]]二十六年（738年），蒙舍诏首领[[皮罗阁]]在[[唐朝]]支持下兼并五诏，建立起[[南诏国]]，并将都城从蒙舍（今[[巍山]]）搬迁到了[[太和城遗址|太和城]]（位于今[[太和街道 (大理市)|太和街道]]太和村）<ref>{{Cite web |title=大理历史沿革 |url=http://www.yndl.gov.cn/gk/index.htm |archive-url=https://web.archive.org/web/20070610002636/http://www.yndl.gov.cn/gk/index.htm |archive-date=2007-06-10 |access-date=2007-06-14 |dead-url=yes}}</ref>，并以此为基地，继续征服周边地区，控制今天云南大部。

[[天宝 (唐朝)|天宝]]九年（750年）到天宝十三年754年，唐朝先后三次派[[鲜于仲通]]、[[李宓]]率大军攻打南诏国，南诏王[[阁逻凤]]与[[吐蕃]]结盟，三次大败唐军。

唐[[大曆|大历]]十四年（779年），皮逻阁之曾孙将都城迁至[[羊苴咩城]]，即今大理旧城。[[唐德宗]][[貞元 (唐朝)|贞元]]十年（794年），派遣节度使前往南诏，与南诏王异牟寻会盟于苍山，两国再度恢复和平。

唐[[天复]]二年（902年），南诏权臣[[郑买嗣]]夺权，建立“[[大长和国]]”。927年，[[杨干贞]]扶持[[赵善政]]建立“[[大天興|大天兴国]]”，随后又自立为王，建“[[大義寧|大义宁国]]”。后晋天福二年（937年），[[段思平]]也于羊苴咩城定都建国，国号大理。段氏自称是[[汉人]]后裔，立国后，大力推行汉文化，并与[[南宋]]遣使通商。

[[大理国]]历经了316年后，在[[元宪宗]]三年（1253年），为[[忽必烈]]亲征所灭。[[元朝|元]][[至元 (元世祖)|至元]]十一年（1274年），元朝为便于统治，在押赤城（又名[[中庆路]]，今[[昆明市]]）设置了[[云南行省]]，同时设立[[大理路]]及[[太和县 (元朝)|太和县]]，隶属于云南行省。从此云南的中心城市便由大理转移到了昆明。

[[明朝|明]][[洪武]]十五年（1382年），明军攻占大理，大理路改为[[大理府]]，仍治太和县，并筑新的府城，即今[[大理古城]]。[[清朝|清]][[顺治]]十六年（1659年），清军攻入云南。清代沿袭明制。清[[咸丰]]六年（1856年）爆发[[杜文秀起义]]，建立[[杜文秀]]政权，控制云南大部分地区。[[同治]]十一年（1872年），起义失败<ref>{{Cite journal |author=刘晨 |date=2012 |title=杜文秀起义始末 |journal=云南档案 |issue=12 |page=29-31|url=https://qikan.cqvip.com/Qikan/Article/Detail?id=44380027&from=Qikan_Search_Index}}</ref>。

=== 中华民国时期 ===
[[民國紀年|民国]]二年（1913年）4月，裁撤大理府；改太和县为大理县，改[[赵州 (云南)|赵州]]为赵县，隶属[[滇西道]]（次年更名[[腾越道]]）；次年1月因赵县重名，改为[[凤仪县]]<ref>{{Cite book|title=中国行政区划通史·中华民国卷|last=傅林祥; 郑宝恒|publisher=复旦大学出版社|year=2007|isbn=978-7-309-05604-4|location=上海}}</ref>{{Rp|302-310}}。民国18年（1929年）废道，县直属省<ref name=":8">{{Cite book|title=大理白族自治州志·卷一|last=大理白族自治州地方志编纂委员会编纂|publisher=云南人民出版社|year=1998|isbn=7-222-02255-4|location=昆明}}</ref>{{Rp|310}}。民国21年（1932年），全省设12个政务视察区，大理县、凤仪县属第八区；民国23年（1934年）增加为16个政务视察区，大理县、凤仪县改属第十二区；次年，视察区减为6个，又改属第四区；民国27年（1938年）改为15个视察区，大理县、凤仪县改属第十一区<ref name=":8" />{{Rp|310}}。同年，政务视察区演变为行政督察区{{NoteTag|政务视察区是临时视察区域，由省政府派出专员对各县官吏进行考核督促；行政督察区既作为省政府派出机构督察所属各县，又是一级行政区划。<ref name=省志一/>{{Rp|110-111}}}}；至1949年，全省共14个行政督察区，大理县、凤仪县属第十一区<ref name="省志一">{{Cite book|title=云南省志·卷一·地理志|last=云南省地方志编纂委员会|publisher=云南人民出版社|year=1998|isbn=7-222-02247-3|location=昆明}}</ref>{{Rp|113}}。<ref>{{Cite web |date=2021-03-03 |title=民国时期 |url=http://www.dali.gov.cn/dlrmzf/c101711/201905/7294b725e2824934804f7b7e2bda5be7.shtml |website=大理州人民政府门户网站 |access-date=2022-08-19 |archive-url=https://web.archive.org/web/20251007113629/https://www.dali.gov.cn/dlrmzf/c101711/201905/7294b725e2824934804f7b7e2bda5be7.shtml |archive-date=2025-10-07 |url-status=live}}</ref>

1925年3月16日，大理发生[[1925年大理地震|7.0级地震]]，墙倒屋塌，城内大火焚烧一夜，大理、凤仪两县共4,951人遇难，7,812人受伤，94,930间房屋倒塌<ref>{{Cite book|title=云南省志·卷三·地震志|last=云南省地方志编纂委员会编|publisher=云南人民出版社|year=1999|isbn=7-222-02829-3|location=昆明|pages=47}}</ref><ref>{{Cite web |date=2012-03-28 |title=1925年大理大地震 |url=http://www.dali.gov.cn/dlrmzf/c101713/201203/0e3738934dbd496d91aa3f8cc300fd21.shtml |website=大理州人民政府门户网站 |access-date=2022-08-19 |archive-date=2022-08-19 |archive-url=https://web.archive.org/web/20220819121109/http://www.dali.gov.cn/dlrmzf/c101713/201203/0e3738934dbd496d91aa3f8cc300fd21.shtml |dead-url=no }}</ref>。

== 地理 ==
[[File:Satellite photo of Dali City-Sentinel-2 L2A-2022-07-01.png|缩略图|大理市卫星照片]]
大理市地处[[云南省]]中部偏西，[[大理白族自治州]]中部。东与[[宾川县]]、[[祥云县]]毗邻，南与[[巍山县]]、[[弥渡县]]相接，西与[[漾濞县]]相望，北与[[洱源县]]交界。位于[[东经]]99°58′－100°27′，[[北纬]]25°25′－25°58′ 之间，东西最大跨距46.3千米，南北最大跨距59.3千米<ref name=":5" />{{Rp|1}}。大理市区位于市境南部，东路距省会[[昆明市]]331千米。大理市总面积1,739平方公里<ref>{{cite book|author=云南省统计局|title=云南统计年鉴·2022|year=2022|publisher=中国统计出版社|isbn=978-7-5230-0007-6|location=北京|url=http://stats.yn.gov.cn/tjsj/tjnj/202212/t20221208_1083373.html|archive-date=2023-10-06|archive-url=https://web.archive.org/web/20231006081434/http://stats.yn.gov.cn/tjsj/tjnj/202212/t20221208_1083373.html|access-date=2023-10-08|url-status=dead}}</ref>。

=== 地形地貌 ===
[[File:远看苍山洗马潭索道 - panoramio.jpg|缩略图|[[苍山 (大理)|苍山]]洗马潭索道]]
大理市地处滇东高原与滇西[[横断山脉]]的交汇地带<ref>{{Cite book|title=云南省志·卷一·地理志|last=云南省地方志编纂委员会编|publisher=云南人民出版社|year=1998|isbn=7-222-02247-3|location=昆明|pages=176}}</ref>，地势西高东低。山地面积1,278.8平方千米，占总面积的70.5%；坝区（[[盆地]]）面积286.2平方千米，占总面积的15.8%；洱海水域面积250平方千米，占总面积的13.7%<ref name=":0" />{{Rp|48}}。全市最高点是[[苍山 (大理)|苍山]]玉局峰，海拔4,097米；最低点的太邑乡坦底摩村，海拔1,340米<ref name=":3">{{Cite web |date=2022-05 |title=市情概要 |url=http://www.yndali.gov.cn/dlszf/c103380/tydp.shtml |url-status=live |website=大理市人民政府 |archive-url=https://web.archive.org/web/20220615133213/http://www.yndali.gov.cn/dlszf/c103380/tydp.shtml |archive-date=2022-06-15 |access-date=2022-06-13}}</ref>；下关市区海拔1,976米<ref>{{Cite book|title=大理州年鉴·2018|last=大理白族自治州地方志编纂委员会|publisher=云南民族出版社|year=2018|isbn=978-7-5367-8054-5|location=昆明|pages=390}}</ref>。

大理市境内山脉属[[云岭]]余脉，西有[[苍山 (大理)|苍山]]，东有玉案山，南有哀牢山。苍山由19座南北走向的山峰组成，海拔3,500米－4,122米<ref name=":0" />{{Rp|48}}。

=== 水系 ===
大理市主要属于[[澜沧江]]水系，境内大小河溪100余条，主要河溪26条，除西洱河外均发源于大理盆地四周山麓并注入洱海<ref name=":3" />。[[西洱河]]是洱海唯一天然出口，自洱海南端流出，在漾濞县境内注入[[漾濞江]]，全长23公里<ref name=":5" />{{Rp|97}}。

[[洱海]]是[[云南湖泊列表|云南省第二大湖泊]]，湖面面积252.19平方千米，蓄水量30亿立方米，南北长40.5千米，东西宽3－9千米<ref name=":3" /><ref name=":0" />{{Rp|48}}。全市有小（一）型水库3座，小（二）型水库27座，总库容1,764万立方米<ref name=":6">{{Cite book|title=云南县域经济|last=云南省县域经济发展协调小组办公室编|publisher=云南民族出版社|year=2008|isbn=978-7-5367-4315-1|location=昆明|pages=289}}</ref>。

大理市[[地下水]]年均径流量2.77亿立方米，地下水资源储存量26.25亿立方米<ref name=":6" />。

=== 气候 ===
大理市属于[[亚热带]][[高山气候|高原]][[季风]]气候，具有气候温和，光照充足，雨热同季，干湿季分明，立体气候明显，风能资源丰富的特点<ref>{{Cite book|title=大理市年鉴·2006|last=大理市地方志编纂委员会，大理市年鉴编辑部编|publisher=云南民族出版社|year=2006|isbn=7-5367-3451-4|location=昆明|pages=40}}</ref>。大理市的年均气温为15.1℃，极端最高温33.4℃（1952年7月23日），极端最低温3.7℃（1997年1月19日）。年平均[[无霜期]]239.6天。年平均日照时数2,228.1小时。年平均[[降雨量]]1,054.9毫米<ref name=":3" /><ref name=":7" />{{Rp|2334}}。大理全市属多风区，大风主要出现在秋冬季节，大理片区年平均风速2.3米/秒，年大风日数64.6天；下关片区年平均风速4.1米/秒，年大风日数78.5天<ref name=":5">{{Cite book|title=大理市志|last=大理市史志编纂委员会|publisher=中华书局|year=1998|isbn=7-101-01802-5|location=北京}}</ref>{{Rp|84-85}}；历史最大风速达35.7米/秒，有“风城”之称<ref>{{Cite web |date=2020-12-16 |title=大理市进入大风多发季节 |url=http://www.dali.gov.cn/dlrmzf/c101533/202012/44527a28af124d40986e6905ad20fb5b.shtml |website=大理日报 |access-date=2022-08-18 |archive-date=2022-08-18 |archive-url=https://web.archive.org/web/20220818060352/http://www.dali.gov.cn/dlrmzf/c101533/202012/44527a28af124d40986e6905ad20fb5b.shtml |dead-url=no }}</ref>。

2021年测得数据为全年均温16.2℃，总日照时数2,226.9小时，降雨量638.2毫米<ref name=":3" />。

=== 工业 ===

== 旅游 ==
旅游业是大理市国民经济的支柱产业之一，已形成集山水景观、文物古迹、民族风情和良好的气候条件为一体的旅游胜地。2021年全市接待游客1,389.52万人次，其中海外游客0.56万人次，旅游总收入184.37亿元，其中旅游外汇总收入275.63万美元<ref name=统计公报2021/>。截至2022年，大理市已建成旅游景点138处<ref name=":3" web |date=2022-05 |title=旅游 |url=http://www.yndali.gov.cn/dlszf/c103384/202104/09d913eea1644a28b9c2d75736f05527.shtml |website=大理市人民政府 |access-date=2022-07-13 |archive-date=2022-08-07 |archive-url=https://web.archive.org/web/20220807105225/http://www.yndali.gov.cn/dlszf/c103384/202104/09d913eea1644a28b9c2d75736f05527.shtml |dead-url=no }}</ref><ref>{{Cite web |date=2020-08-15 大理市的核心旅游区域为[[大理古城]]及其东西两侧的[[苍山 (大理)|苍山]][[洱海]]自然风光，均位于苍山洱海[[国家级自然保护区]]内<ref>{{Cite ZGBK |id=224166 |title=大理苍山洱海国家级自然保护区 |access-date=2022-07-13 |archive-date=2022-08-07 |archive-url=https://web.archive.org/web/20220807123313/https://www.zgbk.com/ecph/words?SiteID=1&ID=224166 |dead-url=no}}</ref>。大理古城始建于[[明朝|明]][[洪武]]年间，南北5条大街，东西8条街巷，呈棋盘式布局<ref>{{Cite ZGBK |id=345587 |title=大理古城 |access-date=2022-07-13 |archive-date=2022-08-07 |archive-url=https://web.archive.org/web/20220807105214/https://www.zgbk.com/ecph/words?SiteID=1&ID=345587 |dead-url=no}}</ref>，有大量民居建筑，于2019年10月入选首届“小镇美学榜样”名单<ref>{{Cite web |date=2020-10-16 |title=回顾首届“小镇美学榜样”，重温那些美 |url=https://www.jiemian.com/article/5121944.html |website=界面新闻 |access-date=2022-07-13 |archive-date=2022-07-16 |archive-url=https://web.archive.org/web/20220716163324/https://www.jiemian.com/article/5121944.html |dead-url=no }}</ref>；古城内有各级文物保护单位14项。

[[苍山 (大理)|苍山]]位于古城以西，属于[[云岭]]山系，山上植物种类丰富，有十九峰、十八溪、[[蝴蝶泉]]等景观，冬季雪景美丽。[[洱海]]位于古城以东，形如人耳，为[[云南湖泊列表|云南第二大淡水湖]]，[[中国淡水湖泊列表|中国第七大淡水湖]]，内有三岛四洲，風光迤邐。山、海、城、塔四者浑然一体、相映成辉，景致无限美妙。

另外，据传统的说法，大理有“风花雪月”四大景致，即“[[下关街道 (大理市)|下关]]风、[[上关镇 (大理市)|上关]]花、[[苍山 (大理)|苍山]]雪、[[洱海]]月”<ref>{{Cite book|title=新编大理风物志|last=薛琳主编|publisher=云南人民出版社|year=1999|isbn=7-222-02726-2|location=昆明|pages=13-14}}</ref>。

大理市有[[大理市各级文物保护单位列表|各级文物保护单位101项]]，其中[[全国重点文物保护单位|国家级]]9项，[[云南省文物保护单位|省级]]17项，[[大理州文物保护单位|州级]]28项，市级47项<ref>{{Cite web |date=2021-07-06 |title=大理市公布12项第五批市级文物保护单位 |url=http://www.dalidaily.com/content/2021-07/06/content_13345.html |work=大理日报 |archive-url=https://web.archive.org/web/20220516122348/http://www.dalidaily.com/content/2021-07/06/content_13345.html |archive-date=2022-05-16 |access-date=2022-05-16 |dead-url=no}}</ref>，数量位居大理白族自治州首位。其中全国重点文物保护单位有：[[崇圣寺三塔]]、[[太和城遗址]]（包括[[南诏德化碑]]）、[[喜洲白族古建筑群]]、[[元世祖平云南碑]]、[[佛图寺塔]]、[[银梭岛遗址]]、[[弘圣寺塔]]、[[云南提督府旧址]]（杜文秀元帅府）、[[大理天主教堂]]。
