'''{{Zy|济|jǐ|ㄐㄧˇ|zai<sup>2</sup>}}南市'''（简称“济”，通称“济南”），别称“'''泉城'''”，是[[中华人民共和国]][[山东省]][[中华人民共和国省会列表|省会]]，[[副省级市]]，位于华东地区黄河下游、山东省中西部。济南是山东省的[[政治]]、[[经济]]、[[文化]]、[[科技]]、[[教育]]、[[交通]]和[[金融]]中心，也是[[山东半岛城市群]]和济南都市圈的核心城市之一，在国家城镇体系中被定位为[[区域中心城市]]。<ref name="jnprofile">{{cite web |url=http://english.jinan.gov.cn/col/col29554/index.html |title=City Profile |website=Jinan Municipal People's Government |publisher=Jinan Municipal People's Government |language=英语 |access-date=2026-01-03}}</ref>截至2025年末，全市常住人口961.6万人。<ref name="jnstat2024">{{cite web |url=https://jntj.jinan.gov.cn/col/col18254/art/2026/art_7dc3135bb2209f961b3c65baa8ab3d2d.html |title=2025年济南市国民经济和社会发展统计公报 |website=济南市统计局 |publisher=济南市统计局 |date=2026-03-30 |access-date=2026-06-08|language=zh-cn}}</ref>

济南是全国重要的综合性交通和物流枢纽城市，集铁路、公路、航空和城际轨道交通于一体，同时集聚多家区域性金融机构和科技创新平台，在黄河流域和华北—华东地区承担着面向内陆和沿海的双向开放门户功能。<ref name="jnprofile"/><ref>{{cite web |url=https://jntzcjj.jinan.gov.cn/art/2025/3/27/art_88392_4781484.html |title=济南发布最新“成绩单”！|website=济南市投资促进局 |publisher=济南市人民政府 |date=2025-03-27 |access-date=2026-01-03}}</ref>城市北接首都经济圈，南联[[长三角城市群|长三角经济圈]]，东连[[山东半岛]]沿海港口，西通[[华中地区]]，位于环渤海经济区和京沪发展轴的交汇地带。<ref name="jnprofile"/>

济南建城历史可追溯至公元前21世纪左右，迄今已有4200余年，被视为中华文明和[[龙山文化]]的重要发祥地之一。因城内泉群密集、泉水出露点众多，自古有“[[七十二名泉]]”之称，代表性景观包括[[趵突泉]]、[[千佛山]]、[[大明湖]]等，由此获得“泉城”美誉，“四面荷花三面柳，一城山色半城湖”的对联即描绘其山水格局。<ref>{{cite web |url=https://vacation.eztravel.com.tw/sight/plc0000134780/jinan-%E6%BF%9F%E5%8D%97 |title=济南 |website=易游网旅游指南 |publisher=易游网 |language=中文（繁体） |access-date=2026-01-03}}</ref>1986年，济南被[[中华人民共和国国务院|国务院]]公布为[[国家历史文化名城]]，此后先后被授予国家创新型城市、中国软件名城、[[国家园林城市]]、首批中国优秀旅游城市和国家知识产权示范城市等称号。<ref>{{cite web |url=https://zh.wikipedia.org/zh-cn/%E6%B5%8E%E5%8D%97%E5%B8%82 |title=济南市 |website=维基百科 |publisher=维基媒体基金会 |language=中文 |access-date=2026-01-03}}</ref>

根据市级生产总值统一核算结果，2024年济南地区生产总值为13527.6亿元，比上年增长5.4%，在山东省各地级市中居第二位，经济总量稳居全国城市前二十，人均地区生产总值超过11万元。<ref name="jnstat2024"/><ref>{{cite web |url=https://www.jinan.gov.cn/col/col24702/index.html |title=经济建设 |website=济南市人民政府 |publisher=济南市人民政府 |date=2025-03-25 |access-date=2026-01-03}}</ref><ref>{{cite web |url=https://www.sohu.com/a/871767209_121861075 |title=枣庄倒数第一！山东各地2024年GDP总值排行出炉 |website=搜狐新闻 |publisher=水又木二 |date=2025-03-16 |access-date=2026-01-03}}</ref>2025年10月13日，中国标准化研究院在第56届世界标准日主题活动上发布首份《城市综合发展指数报告（2025年）》，在纳入评估的36座城市中，济南以80.3分的综合发展指数位列第5名。<ref>{{cite web |url=https://www.cnis.ac.cn/bydt/kydt/202510/t20251014_61779.html |title=中国标准化研究院首发报告《城市综合发展指数报告（2025年）》 |website=中国标准化研究院 |publisher=中国标准化研究院 |date=2025-10-14 |access-date=2026-01-03}}</ref><ref>{{cite web |url=https://m.dzplus.dzng.com/share/general/0/NEWS2820774LFZATDTWBTQQL |title=综合发展指数“全国第五”，“优等生”济南是这样炼成的 |website=齐鲁壹点 |publisher=齐鲁晚报 |date=2025-10-17 |access-date=2026-01-03}}</ref>

济南位于山东省中西部，北濒[[黄河]]、南依[[泰山]]，地形由南部山地、中部丘陵向北部冲积平原过渡。全市总面积10,244平方千米，下辖10个[[市辖区]]和2个[[县]]，分别与西南部的[[聊城市]]、北部的[[德州市]]和[[滨州市]]、东部的[[淄博市]]、南部的[[泰安市]]接壤。<ref>{{cite web |url=https://www.xzqh.org/show/china/2024/37/370100.html |title=济南市（2024年） |website=行政区划网 |publisher=行政区划网 |date=2024-03-01 |access-date=2026-01-03}}</ref><ref>{{cite web |url=https://www.jinan.gov.cn/col/col24701/index.html |title=民族人口 |website=济南市人民政府 |publisher=济南市人民政府 |date=2025-03-25 |access-date=2026-01-03}}</ref>中共济南市委、济南市人大常委会、济南市人民政府和济南市政协机关均驻[[历下区]]龙鼎大道1号。<ref>{{cite web |url=https://zh.wikipedia.org/zh-cn/%E6%B5%8E%E5%8D%97%E5%B8%82 |title=济南市 |website=维基百科 |publisher=维基媒体基金会 |language=中文 |access-date=2026-01-03}}</ref>

21世纪以来，济南先后承办2004年[[亚足联亚洲杯|亚洲杯足球赛]]部分比赛、2009年[[中华人民共和国第十一届运动会]]、第七届中国（国际）园林花卉博览会、2013年第十届中国艺术节等多项大型国际和国家级活动；2015年举行的第二十二届国际历史科学大会，是该会议创办百余年来首次在亚洲城市召开。<ref>{{cite web |url=https://zh.wikipedia.org/zh-cn/%E6%B5%8E%E5%8D%97%E5%B8%82 |title=济南市 |website=维基百科 |publisher=维基媒体基金会 |language=中文 |access-date=2026-01-03}}</ref>2016年12月7日，济南被国务院确定为第三批国家新型城镇化综合试点城市；<ref>{{cite web |url=https://www.jinan.gov.cn/art/2018/1/15/art_120574_4979473.html |title=关于印发济南市国家新型城镇化综合试点实施方案的通知 |website=济南市人民政府公报 |publisher=济南市人民政府 |date=2018-01-15 |access-date=2026-01-03}}</ref>2018年1月，《山东新旧动能转换综合试验区建设总体方案》获国务院批复，明确支持济南建设国家新旧动能转换先行区；<ref>{{cite web |url=https://www.ndrc.gov.cn/xxgk/zcfb/tz/201801/t20180124_962650.html |title=国家发展改革委关于印发《山东新旧动能转换综合试验区建设总体方案》的通知 |website=国家发展和改革委员会 |publisher=国家发展和改革委员会 |date=2018-01-24 |access-date=2026-01-03}}</ref>2021年4月，国务院办公厅同意《济南新旧动能转换起步区建设实施方案》，济南新旧动能转换起步区成为《[[黄河流域生态保护和高质量发展规划纲要]]》中唯一获批设立的实体性新区，是继[[雄安新区]]之后全国第二个起步区，成为济南对接黄河流域生态保护和高质量发展国家战略的重要平台。<ref>{{cite web |url=https://www.gov.cn/zhengce/content/2021-04/30/content_5604138.htm |title=国务院办公厅关于同意济南新旧动能转换起步区建设实施方案的函 |website=中国政府网 |publisher=中华人民共和国国务院办公厅 |date=2021-04-30 |access-date=2026-01-03}}</ref><ref>{{cite web |url=https://www.ndrc.gov.cn/xwdt/ztzl/cjgyjjpwzz/dfjyhzf/202304/t20230428_1355216.html |title=济南新旧动能转换起步区高质量“起步” |website=国家发展改革委 |publisher=新华每日电讯 |date=2023-04-28 |access-date=2026-01-03}}</ref>

「济南」之名，最早见于[[西汉]]，源于当时设立的[[济南郡]]。据《[[汉书·地理志]]》记载：“济南郡，故齐国也，高帝元年（前206）置。”<ref>{{cite book|author=（汉）班固|title=汉书·地理志第十二}}</ref> 顾名思义，济南之“济”指[[济水]]，而“南”则表方位，故“济南”意为“济水之南”。

{{主条目|济水}}

古济水是中国古代一条重要河流，与[[长江]]（江）、[[黄河]]（河）、[[淮河]]（淮）并称为“[[四渎]]”，是古代中国王朝的祭祀对象<ref>邹逸麟. (2005). 《中国历史地理》. 华东师范大学出版社.</ref>。古济水发源于现[[河南省]][[济源市]]王屋山，因其“伏流清波”的独特水文特性（即河水时而潜入地下，时而复出）而闻名。其流域大致相当于现在的[[黄河]]山东段。然而，济水的命运与黄河的变迁紧密相连。历史上，黄河曾多次改道。在西汉[[新莽]]天凤元年（14年），黄河在[[濮阳市|濮阳]]附近改道，开始流入济水的以北的那一段河道，但济水故道尚存。至[[北宋]]建炎二年（1128年），为阻挡金兵南下，东京守将杜充决开黄河大堤，黄河下游遂夺[[泗水]]、[[淮河]]河道入海，史称“黄河夺淮”，此后七百余年，黄河主要流向东南。直至[[清朝|清]]咸丰五年（1855年），黄河在河南兰考铜瓦厢决口，再次向北改道，夺大清河（古济水下游故道）入[[渤海]]<ref>关树谦. (1981). 一百二十多年来黄河下游河道变迁. 《地理学报》, 36(1), 16-29.</ref>。此次改道彻底占用了古济水的下游河床，使其成为今天黄河下游的干流河道。尽管济水作为独立河流已不复存在，但其历史印记深深刻在了沿岸地名中，如[[济源]]（意为济水之源头）、[[济南]]（济水之南）、[[济阳]]（济水之北）及[[济宁]]等。

最早记入史册的济南古称是{{zy|泺|luò|ㄌㄨㄛˋ|lok<sup>6</sup>}}邑，简称泺，早于“济南”之名。此简称源于古[[泺水]]，一条由[[趵突泉]]为首的城内诸泉汇流而成的河流。「濼」（“泺”的[[繁体字|繁体]]）是一个专用于此地的古[[地名]]用字。<ref>{{Cite web |title=山东省民政厅 地名文化 “济南”地名的由来 |url=http://mzt.shandong.gov.cn/art/2013/10/22/art_92441_7204887.html |website=mzt.shandong.gov.cn |access-date=2026-06-08}}</ref>

根据学者[[王恩田]]的研究，商代末期[[帝乙]]、[[帝辛]]（[[纣]]）征伐东夷时的[[甲骨文]]卜辞中，已出现“{{zy|[[wikt:濼|泺]]|luò|ㄌㄨㄛˋ|lok<sup>6</sup>}}”字。卜辞中记载的“王往于泺”等内容，被考证为商王途经济南一带的泉水（即今日的[[趵突泉]]）并进行祭祀或占卜的记录。这一发现将济南泉水有文字记载的历史追溯至距今三千五百多年的晚商时期<ref>{{cite journal|author=王恩田|title=甲骨文中的济南和趵突泉|journal=济南大学学报(社会科学版)|volume=11|issue=4|pages=28-32|year=2001|doi=10.3969/j.issn.1008-2519.2001.04.007}}</ref>。

到了[[春秋时期]]，济南一带被称为“泺邑”，地理位置位于[[齐国]]境内，邻近[[鲁国]]，是齐鲁两国交往的要冲，现今济南境内仍能看到[[齐长城]]的遗址。《春秋·桓公十八年》（公元前694年）记载：“春王正月，公（鲁桓公）会齐侯（齐襄公）于泺。公与夫人姜氏遂如齐。”<ref>{{cite book|author=（春秋）孔子 编，（清）阮元 校勘|title=春秋左传注疏·桓公十八年|publisher=中华书局}}</ref>。此处“泺”即指“泺邑”，是两国国君会盟的重要地点。“泺”字不仅承载了济南厚重的泉水文化，也是其作为信史起点的地名标识。

此外，"济"字与[[齐国]]（齊）之"齐"字，在古代地理、文化乃至[[上古汉语]]中均有紧密联系。从地理上看，[[济水]]是[[齐国]]疆域内的重要河流，长期作为齐国与西面[[鲁国]]、[[卫国]]等诸侯国的天然分界<ref>谭其骧. (1982). "中国历史地图集" (第一册). 地图出版社.</ref>。如"左传·庄公十年"载有"齐师... 遂... 济"，即指齐国军队渡过济水，显示了济水作为齐国军事与地理要冲的地位<ref>{{cite book|author=（春秋）左丘明 撰，（晋）杜预 注|title=春秋左氏传集解·庄公十年}}</ref>。

在[[上古汉语]]中，"齐"与"济"二字读音相近（上古拟音中"齐"为 /*[dz]i[l]/，"济"为 /*[ts]i[t]s/），学者很早就注意到两者间的联系<ref>王力. (1980). "汉语史稿". 中华书局. ISBN 978-7-101-00100-3.</ref>。有学者（如清代[[顾炎武]]）考证认为，在某些古代文献中，二字存在[[通假]]的可能。而[[清华简]]（贰）中收录的"景公入年"篇章被发现后，提供了新的佐证。文中"齐"与"济"的用法，引发了关于两者是否同源或存在古老地名混用的讨论<ref>李学勤. (2011). "清华大学藏战国竹简（贰）". 上海：中西书局. ISBN 978-7-5475-0177-3.</ref>。一种观点认为，[[东夷]]人先民对这条河流（济水）的称呼，可能同时也是其部族（齐）的称呼来源，后世逐渐分化为两个不同的汉字<ref>沈长云. (2012). 清华简"景公入年"与"齐"、"济"关系考. "管子学刊", (3), 108-112.</ref>。因此，"济"不仅是济南地名之源，其字音与字义也与齐鲁文化的核心——"齐"之概念，在历史长河中相互交织。

== 历史 ==
远在9000年前的新石器时代早期，已有先民在此繁衍生息。

济南是距今4000～4500年前以磨光黑陶为特征的[[龙山文化]]的发现地，于1928年在原[[历城区|历城县]][[龙山街道 (济南市)|龙山镇]]（今[[章丘区]]龙山街道）的[[城子崖遗址|城子崖]]的发掘中首次发现，并以发掘地命名为[[龙山文化]]。<ref name=":2">{{Cite web |title=济南市政府门户网站-济南概况 |url=http://jinan.cn/col/col129/index.html |website=jinan.cn |archive-url=https://web.archive.org/web/20160331052949/http://jinan.cn/col/col129/index.html |archive-date=2016-03-31 |access-date=2025-04-28 |dead-url=no }}</ref>

夏代，城子崖一带建有较大规模的城市。商周时代，济南为古谭国（东方方国，都城在今城子崖、平陵城一带）<ref name=":2" />

2025年12月11日，有关部门公布了在地铁六号线大明湖站（大明湖西南门东南侧）的考古发现：龙山文化城墙及壕沟被发掘，城墙内采集的碳14样品测年为距今4200年左右。这一成果将济南建城史提前了约1500年。<ref>{{Cite web |title=考古新发现将济南建城史提前约1500年-新华网 |url=http://www.xinhuanet.com/20251211/b28cf4ce2ec14d9ab12e28d06f262c42/c.html |website=www.xinhuanet.com |access-date=2025-12-12}}</ref>

跟济南相关的最早的传说，是舜耕历山，《史记》记载“舜耕历山，历山之人皆让畔；渔雷泽，雷泽上人皆让居，陶河滨，河滨器皆不苦窳”，相传[[舜]]曾“渔于雷泽，躬耕于[[千佛山|历山]]”。所以市内至今还散遺各個以[[舜]]命名的地名，如“[[舜井]]”、“[[舜耕路]]”、“[[舜耕山]]”等。因为叫历山的山有很多，所以现在比较有争议，其中一说是济南的千佛山。而北魏郦道元所著《水经注》中写道“城南对山，山上有舜祠。山下有大穴，谓之舜井，抑亦茅山禹井之比矣。《书》舜耕历山，亦云在此，所未详也。”

春秋时期著名的[[齐国|齐]][[晋国|晋]]“鞍”之战发生在市北的马鞍山一带。成書於春秋的《[[诗经]]·大东》，是现存最早的一篇有关济南的文献。[[汉代]]公元前164年设立济南国，公元前154年又废国改[[濟南郡|郡]]。西汉时期，有多位皇亲被分封在济南，刘辟光、刘就、刘圣等王公贵族先后被封为济南王，济南王刘辟光後参与了“七国之乱”。西汉末年，外戚王莽篡权，史称“王莽改制”。其在位期间，把济南改成乐安，直到十六年后，光武帝又将乐安改为济南国。

东汉期间依舊設济南王，後因為无嗣导致“国除”：“安帝延光四年（125年），济南王香薨，无嗣国除。顺帝永建元年（126年），以阜阳侯刘显为济南王。桓帝永兴元年（153年），济南王广薨，无嗣国除。灵帝熹平三年（174年），以河闲王刘利子刘康为济南王。”

[[汉灵帝]]时，[[曹操]]曾任济南相。[[西晋]]永嘉（307-312年）年间，济南郡治由[[东平陵]]移至[[历城]]。

[[隋高祖]][[开皇]]三年（583年），改[[濟南郡]]为[[齊州 (濟南市)|齐州]]。这段时期济南的佛教比较兴盛，留有[[千佛山]]、[[灵岩寺 (长清)|灵岩寺]]、千佛崖石窟造像、[[四门塔]]（中国现存最古老的石塔）等佛教遗迹。隋开皇初废郡，大业初复置齐郡，辖有历城、[[祝阿县|祝阿]]、[[临邑县|临邑]]、[[临济]]、[[邹平]]、[[章丘县|章丘]]、长山、[[高苑]]、[[亭山县|亭山]]、[[淄川]]10县。唐武德元年（618年）改齐郡为齐州，次年置总管府。[[贞观]]元年（627年）撤总管府，贞观七年又置总督府。天宝年间先后改称临淄郡、济南郡，[[乾元 (唐朝)|乾元]]元年（758年）复为齐州，辖历城、章丘、亭山、临邑、长清、禹城、临济7县。

到了[[北宋]]初属[[京东路]]，[[元丰 (北宋)|元丰]]元年（1078年）属京东西路。[[宋徽宗]][[政和 (年號)|政和]]六年（公元1116年），齐州升为[[济南府]]，领历城、禹城、章丘、长清、临邑5县。[[曾巩]]任职于济南时曾各种赋诗撰文，促进了济南文学的发展。两宋交际时期，济南府的文学更加繁荣，出现了[[李清照]]、[[辛弃疾]]等中国历史上的著名宋词作家，两人被称作“济南二安”（李清照号“易安”，辛弃疾字“幼安”）。中国广告史上最早的商业印刷广告，出现在北宋时期的济南府。[[上海博物馆]]藏的[[北宋]]济南刘家针铺广告铜版，是现存最早的工商业印刷广告。在这则高12.5厘米，宽13厘米的广告铜板上，中心位置绘有商标——白兔捣药图，广告的标题是商店名称“济南刘家功夫针铺”，告诉人们商店的地址是“认门前白兔儿为记”，商店经营项目、质量要求和经营方针是：“收买上等钢条，造功夫细针，不误宅院使用；可转为贩，别有加烧。请记白”。这是目前世界上发现的最早印刷广告文物，比西方的印刷广告早三百多年。

1128年，北宋的京东东路的济南府被完颜宗翰、完颜宗辅、完颜宗泽、完颜宗弼、拔离速的3万金军攻占，之后依称[[济南府]]，属京东东路，领历城、临邑、齐河、章丘、禹城、长清、济阳7县。元初改为济南路，属中书省，领历城、章丘、邹平、济阳4县及棣、滨2州，棣州治厌次（今惠民县），辖厌次、商河、阳信、无棣4县；滨州治渤海（今滨州市），辖渤海、利津、沾化3县。1214年，[[金朝]]的京东东路的济南府被[[成吉思皇帝]]与[[拖雷]]的大军攻占，1216年底—1217年初金军驱逐了之前攻占京东东路的[[济南府]]的大军驻军，1220年济南府再次被[[木华黎]]攻占。

[[元朝]]属于[[中书省|腹里]]的[[济南路]]，济南的文化依旧兴盛，产生过[[杜仁杰]]、[[张养浩]]等著名文学家和散曲文人。[[元惠宗|元顺帝]][[至正]]十二年（1352年），年初朝廷征召附近民夫修理决口的黄河河道，由于监工管理极为粗暴，肆意鞭打这些民夫，因此[[颍川郡|颍川路]]人刘福通和韩林儿（韩山童之子）就利用这些民夫的不满情绪发动了[[紅巾軍|红巾军之乱]]；参与[[紅巾之亂|红巾军之乱]]的军队对当时的大城市都要攻占和杀掠一番（对达官贵人，富商大贾和平民百姓等都是如此）；[[紅巾軍|红巾军之乱]]的队伍纯粹是一群不受指挥与控制的强盗土匪，他们于1358年从海宁州渡海攻占[[胶西路]]、[[益都路]]和[[济南路]]等地；1362年[[扩廓帖木儿|王保保]]镇压了之前攻占[[济南路]]、[[胶西路]]、[[益都路]]的[[红巾军]]驻军。

明[[洪武]]元年（1368年），明军攻占济南路，曾置山东行中书省。洪武九年（1376年）省治由青州移治济南，济南开启了作为山东省会的历史。时济南府治历城县，辖有历城、章丘、邹平、淄川、长山、新城、齐河、齐东、济阳、禹城、临邑、长清、肥城、青城、陵县15县及泰安、德州、武定、滨州4州，州领11县。泰安州辖新泰、莱芜2县；德州辖德平、平原2县；武定州辖阳信、海丰、乐陵、商河4县；滨州辖利津、沾化、蒲台3县。到了[[嘉靖]]、[[万历]]和[[天启]]年间（1521—1627年）济南府成为当时中原第一大都会，1635年，1636年，1638年，1639年，1642年满清五次引兵攻占[[北直隶]]和[[山东承宣布政使司]]，杀掠无数，尤其是1642年攻陷济南府时，肆意戮掠后撤退，济南府城内外积尸十三万具。满清顺治朝时，山东多次爆发反抗满清统治而后被镇压的起义，这给当时的山东尤其是济南府造成不小的损毁。据说当时白天赤地千里，榛榛莽莽，夜晚手游鬼哭，人迹罕至（超过百万人遇害）。[[清朝|清]][[康熙]]年间，济南的商业开始缓慢恢复发展。后为山东布政使司的治所。

1904年，济南开设了[[商埠]]，工商业有了进一步的发展。1911年[[津浦铁路]]开通并路过济南。1912年[[清政府]]被推翻，[[中华民国]]成立后，济南改作济南市。民国时期济南的工商业更加繁荣，[[瑞蚨祥]]、[[大观园]]商业城和济南[[嘉禾卷烟厂]]开张，商埠的面积不断扩大。1928年，进行[[北伐战争|北伐]]的[[国民革命军]]占领济南。而[[日本]]却借口以“北伐军杀害济南日本侨民”为由，于5月3日出兵济南报复，将[[国民政府]]外交部特派山东交涉员[[蔡公时]]及署内职员17人虐杀，随后对城中百姓进行大规模杀掠，超过6000济南市民被杀害，史称“[[五三惨案]]”。直至1929年3月，南京国民政府与日本政府签订《中日济案协定》之后，日军才退出济南。1929年7月，[[南京国民政府]]析[[历城]]县城、城外商埠及其四郊置济南市，全市面积为175平方公里，设城内一、二、三区，城外一、二、三区，商埠一、二、三、四区，共10个区。1937年7月7日，[[抗日战争]]爆发。同年12月，[[馬良 (民國)|马良]]出城迎接欲侵略济南的日军进城，济南陷落。占领济南后，日军将济南划为11个区，称城内东区、城内西区、城外东区、城外西区、商埠东区、商埠西区、商埠中区、东乡区、南乡区、西乡区、北乡区。1945年8月15日，日本战败，[[国民政府]]于同年收复济南，此时济南设11个区，总面积177.62平方公里。1948年[[第二次国共内战]]时期，战乱导致全国物价飞涨、纸币贬值，济南经济全面崩溃，商埠逐渐消失。同年9月24日，[[中国人民解放军]][[济南战役|占领济南]]，成立[[中国人民解放军华东军区济南特别市军事管制委员会]]、'''济南特别市'''和济南特别市人民政府，1949年5月改为山东省的省辖市。

[[中华人民共和国]]成立后，济南进行工商业[[社会主义]]改造，各商铺以及工厂改由公私合营办理，同时，出现了[[中国重汽]]等著名企业。1958年，将[[泰安专区]]的[[泰安市]]和[[章丘区|章丘]]、[[长清区|长清]]、[[莱芜县|莱芜]]、[[新泰市|新泰]]、[[历城区|历城]]、[[宁阳县|宁阳]]划归济南市。1959年9月，[[平阴县]]、[[肥城县]]划归济南市，同时设立[[新汶市]]，撤销长清县。1960年，平阴县划归[[菏泽专区]]，1961年，泰安专区恢复，将济南市除历城县外的8个县（市）划归泰安专区，济南市辖区范围恢复1958年前的建制。[[文化大革命]]时期，济南再次陷入混乱局面。学校和单位以开批斗大会为由停止工作，全市各部门瘫痪，[[红卫兵]]上街抄家、武斗。

[[改革开放]]后，济南进入复苏阶段。相继出现[[浪潮集团|浪潮]]、[[鲁能集团|鲁能]]等著名企业，居民的生活水平有所提高，商业、旅游业、体育业也有所发展。

1978年，长清、章丘2县重新划入，调整后，济南市共辖历下、市中、天桥、槐荫、郊区5个区和历城、长清、章丘3个县。1987年，撤销济南市郊区和历城县，设立济南市历城区。1989年，将[[德州地区]]的[[济阳]]、[[商河]]两县划归济南市。1992年，撤销章丘县，设立章丘市（县级市）。1994年2月，济南市被确定为[[副省级城市]]。2001年，撤销长清县，设立长清区。

2004年济南成为[[2004年亚洲杯足球赛|亚洲杯足球赛]]的主赛场之一，2004年还在大明湖举办了O-125世界摩托艇锦标赛。2007年7月济南遭受[[2007年济南特大暴雨|特大暴雨袭击]]。由于短时间雨量过大以及城市排水系统能力不足，造成25人死亡、4人失踪、170多人受伤，和重大财产损失<ref>{{Cite web|title=CCTV.com-济南特大暴雨降水量创纪录 死亡人数已升至25人|url=http://news.cctv.com/china/20070719/111830.shtml|accessdate=2020-07-06|work=news.cctv.com|archive-date=2020-12-05|archive-url=https://web.archive.org/web/20201205092722/http://news.cctv.com/china/20070719/111830.shtml|dead-url=no}}</ref><ref>{{Cite web|title=南方周末：7-18济南暴雨黑色3小时(组图)_新闻中心_新浪网|url=http://news.sina.com.cn/c/2007-07-26/100013531488.shtml?from=wap|accessdate=2020-07-06|work=news.sina.com.cn|archive-date=2021-04-09|archive-url=https://web.archive.org/web/20210409154450/http://news.sina.com.cn/c/2007-07-26/100013531488.shtml?from=wap|dead-url=no}}</ref>。2009年济南承办了[[中华人民共和国第十一届全运会]]，2013年，济南又举办了第十届[[中国艺术节]]，借助举办大型赛事的机遇，济南大力发展了东部新城与西部新城。2012年春节，市政府由济南市经二路193号<ref>{{cite web |author=大汉网络 |url=http://www.jinan.gov.cn/20050808/column/2518.htm |title=首页→关于我们 |publisher=Web.archive.org |date= |accessdate=2017-06-10 |deadurl=yes |archiveurl=https://web.archive.org/web/20070318105506/http://www.jinan.gov.cn/20050808/column/2518.htm |archivedate=2007-03-18 }}</ref>搬迁到全运会时期建设的[[龙奥大厦]]，位于龙鼎大道1号。<ref>{{Cite web |url=http://www.ycwb.com/ePaper/ycwb/html/2012-12/12/content_34119.htm?div=-1 |title=济南豪华政府大楼造价40亿？ |access-date=2015-09-09 |archive-date=2012-12-28 |archive-url=https://web.archive.org/web/20121228073155/http://www.ycwb.com/ePaper/ycwb/html/2012-12/12/content_34119.htm?div=-1 |dead-url=no }}</ref>2016年，撤销章丘市，设立济南市[[章丘区]]。2018年，撤销济阳县，设立济南市[[济阳区]]。

== 地理 ==

=== 气候 ===
济南地处中纬度地带，由于受太阳辐射、大气环流和地理环境的影响，属于暖温带大陆性季风气候区。其特点是季风明显，四季分明，春季干旱少雨，夏季温热多雨，秋季凉爽干燥，冬季寒冷少雪。年平均气温13.6℃，无霜期235天，气温最高42.5℃（1955年7月24日），最低气温零下19.7℃（1953年1月17日）。最高月均温27.2℃（7月），最低月均温-3.2℃（1月）。年平均降水量614.0毫米。<ref>{{Cite web|title=濟南氣候怎麼樣? - 雅瑪知識|url=https://www.yamab2b.com/why/8056779.html|website=www.yamab2b.com|archive-url=https://web.archive.org/web/20230806213219/https://www.yamab2b.com/why/8056779.html|archive-date=2023-08-06|access-date=2023-08-06|dead-url=no}}</ref>

济南属于[[温带季风气候|暖温带半湿润大陆性季风气候]]。其特点是季风明显，四季分明，春季干旱少雨，夏季高温多雨，秋季较为清爽，冬季风大寒冷。1月平均气温-0.2℃，7月平均气温27.6℃；极端最高气温42.5℃（1955年7月24日，市区），极端最低气温-26.8℃（1985年12月8日，章丘），市区极端最低气温-19.7℃（1953年1月17日）；年平均气温14.9℃，年平均降水量702.5毫米，且山区较平原降水量大达710毫米，由于地表倾斜，不易存水。济南夏季降水多于一般北方城市，加之三面环山的地形令水汽和热空气回流聚集，导致了济南的夏季高温湿热。1951-2013年日最高温≥40℃天数19天<ref>{{cite web|title=济南气象资料|url=http://cdc.cma.gov.cn/home.do|date=|language=|accessdate=2013年5月|publisher=中国气象科学数据共享服务网|deadurl=yes|archiveurl=https://web.archive.org/web/20150302053152/http://cdc.cma.gov.cn/home.do|archivedate=2015-03-02}}</ref>。{{济南市气候数据}}

=== 地形地貌 ===
[[File:Jinan 117.02265E 36.67601N.jpg|thumb|left|濟南及其周邊的衛星圖]]
济南市位于北纬36度40分，东经117度00分，南依[[泰山]]，北跨[[黄河]]，地处鲁中南低山丘陵与鲁西北冲积平原的交接带上，地势南高北低。地形可分为三带：北部临黄带，中部山前平原带，南部丘陵山区带。境内主要山峰有[[长城岭]]、[[跑马岭]]、[[梯子山]]、[[黑牛寨]]等等。陆地面积8154平方公里，山地丘陵3000多平方公里，平原5000平方公里。

=== 地表径流 ===

济南境内河流主要有[[黄河]]、[[小清河]]、[[徒骇河]]、[[大汶河]]四大河流。除这四大流量较大的河流外，还有南部山区季节性比较强的锦阳川和锦绣川两大河流，[[淄河]]发源于[[莱芜区]]。湖泊有[[大明湖]]（历下区）、[[芽庄湖]]、[[雪野湖]]等。

=== 泉水特色 ===
济南别称泉城，泉群众多、水量丰沛，被称为的天然岩溶泉水博物馆。济南城内百泉争涌，分布着久负盛名的[[趵突泉泉群及园林建筑|趵突泉泉群]]、[[黑虎泉泉群及园林建筑|黑虎泉泉群]]、五龙潭泉群、[[珍珠泉 (济南)|珍珠泉泉群]]、白泉泉群、[[百脉泉|百脉泉泉群]]、[[玉河泉|玉河泉泉群]]、涌泉泉群、袈裟泉泉群以及平阴的洪范池泉群十大泉群。以上十大泉群均属“济南泉群”。济南城内百泉争涌，向有名泉七十二之说，流传甚广 。

济南之所以泉水众多，是因为它的独特地形地质构造。济南处在山东省的心脏地带，鲁中南低山丘陵与鲁西北冲积平原，正好把它夹在中间，为一平缓的单斜构造，高差达500多米，市区的地势自然也就随之南高北低，这种南高北低的地势，利于地表水和地下水向城区汇集。

济南地下是可溶性灰岩，在漫长地质变迁年代，经过多次构造运动和长期溶蚀，形成了大量溶沟、溶孔、溶洞和地下暗河，成了能够储存和输送地下水的地下管网。济南南部山脉大量的地下水，沿着石灰岩地层潜流，纵横交错，一路向北，遇到了北郊组织紧密的岩浆岩的阻挡，如同一面天然设置的石墙，将水脉阻断拦蓄。最终，拦蓄在这里的大量地下水，凭着强大压力，沿地下连接地表的许多裂缝和通道，一股脑的涌出地面，于是就出现了天然涌泉。也正是这样的地质构造，使得济南虽然处在河北平原和鲁北平原地震带上，但地下的震动，却可以被地下水最大限度的有效缓冲。

=== 水利设施 ===
济南属于中国东部大型城市，为保证城区供水与保证各大泉群喷涌，济南市采取关闭大部分地下水井，改用地表水源的方法。因此在城市南面，西面和北面都建有大型水库，保证全年的市区自来水供应。

* 南部在锦阳川、锦绣川、锦云川流域主要水利设置有[[黄巢水库]]，[[锦绣川水库]]和[[卧虎山水库]]，他们都位于济南市[[历城区]]境内。
* 西部主要是利用黄河水作为水源的[[玉清湖水库]]，位于济南市[[槐荫区]]与[[长清区]]交界处。
* 城市北部有利用黄河水作为水源的[[鹊山水库]]，位于济南市[[天桥区]]境内。

除以上大型水利设施外，还有很多小型的塘坝和土坝建在南部山区的主要河流上。这些小型水利设施有效的降低水流速度，减小水土流失，加强地下水补给，同时也保障了南部山区农业有足够的灌溉用水。

这些水利设施除了为济南市提供必要的水源外，另外还有风景区的功能，水库广阔的水域面积和湿地气候吸引了很多野生动物在库区栖息。因此这几个水库也是济南市民经常光顾的休闲场所。另外水库中还发展有养殖业，淡水鱼类是主要的品种。

== 政治 ==
=== 党政机构 ===
中国共产党济南市委员会是[[中国共产党]]在济南市的领导机关，由中国共产党济南市代表大会选举产生，向其负责并报告工作。中共济南市委接受中共山东省委的领导。

济南市人民代表大会是济南市的国家权力机关，由各区和驻济解放军代表大会选举产生的[[人大代表|市人大代表]]组成。 济南市人民代表大会常务委员会是市人大的常设机关，在闭会期间履行市人民代表大会的部分职能。

济南市人民政府是济南市地方国家[[人民代表大会制度|权力机关]]的执行机关和济南市[[行政机构|国家行政机关]]，市人民政府组成人员由济南市人民代表大会选举产生；市政府对人大负责，受人大监督。济南市政府同时接受山东省人民政府的领导。

中国人民政治协商会议济南市委员会是[[中国人民政治协商会议]]在济南的地方组织，是爱国统一战线和[[多党合作]]、[[政治协商]]的重要地方机构。

中国共产党济南市纪律检查委员会与济南市监察委员会[[合署办公]]，是履行纪检、监察两项职责的机关。[[山东省济南市中级人民法院|济南市中级人民法院]]是济南市的审判机关，组成人员由济南市人民代表大会选举产生；对人大负责，受人大监督。济南市人民检察院是济南市的监察机关，组成人员由济南市人民代表大会选举产生；对人大负责，受人大监督；同时接受山东省人民检察院的领导。

==== 中央、山东省驻济机构 ====
济南作为军事战略要地，是[[中国人民解放军北部战区陆军]]机关、[[中国人民解放军山东省军区|山东省军区]]驻地。大军区时期曾是[[中国人民解放军济南军区|济南军区]]所在地，负责山东、河南等2个省级行政区内陆、海、空军部队作战指挥和所属部队的军事、政治、后勤工作。

济南作为重要金融中心，是[[中国人民银行]]山东省分行、[[国家金融监督管理总局|金融监管总局]]山东监管局、[[中国证券监督管理委员会|中国证监会]]山东监管局、[[国家外汇管理局]]山东省分局所在地。济南是山东的经济中心，直属于[[中华人民共和国海关总署|海关总署]]的济南海关也驻于此。除此之外，[[中华人民共和国财政部|财政部]]山东监管局、[[中华人民共和国审计署|审计署]]驻济南特派员办事处、[[国家税务总局|税务总局]]山东省税务局、[[国家统计局]]山东调查总队也坐落在济南。

由于济南是山东省省会，[[中国共产党山东省委员会]]、[[山东省人民代表大会]][[山东省人民代表大会常务委员会|常务委员会]]、[[山东省人民政府]]、[[中国人民政治协商会议山东省委员会]]以及[[中国共产党山东省纪律检查委员会]]、[[山东省监察委员会]]、[[山东省高级人民法院]]、[[山东省人民检察院]]和各民主党派山东省委员会机关也都位于此。

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为9,202,432人<ref>{{cite web |author1=济南市统计局、济南市第七次全国人口普查领导小组办公室 |title=济南市第七次全国人口普查公报 |url=http://jntj.jinan.gov.cn/art/2021/6/16/art_18254_4742896.html |access-date=2023-07-24 |archive-date=2023-07-24 |archive-url=https://web.archive.org/web/20230724133151/http://jntj.jinan.gov.cn/art/2021/6/16/art_18254_4742896.html |dead-url=no }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的8,112,513人相比，十年共增加了1,089,919人，增长13.44%，年平均增长率为1.27%。其中，男性人口为4,612,797人，占总人口的50.13%；女性人口为4,589,635人，占总人口的49.87%。总人口性别比（以女性为100）为100.5。0－14岁的人口为1,512,643人，占总人口的16.44%；15－59岁的人口为5,852,677人，占总人口的63.6%；60岁及以上的人口为1,837,112人，占总人口的19.96%，其中65岁及以上的人口为1,294,977人，占总人口的14.07%。居住在城镇的人口为6,760,007人，占总人口的73.46%；居住在乡村的人口为2,442,425人，占总人口的26.54%。

2025年末常住人口961.6万人，比上年增加10.1万人，增长1.1%，其中，城镇常住人口743.5万人，占总人口比重（常住人口城镇化率）77.3%，比上年提高1.1个百分点。户籍人口828.8万人，增长2.0‰。全年申报出生人口5.8万人，申报出生率为7.0‰；申报死亡人口6.0万人，申报死亡率为7.2‰，人口自然增长率-0.2‰。<ref>{{Cite web |title=2025年济南市国民经济和社会发展统计公报 |url=https://jntj.jinan.gov.cn/col/col18254/art/2026/art_7dc3135bb2209f961b3c65baa8ab3d2d.html |website=jntj.jinan.gov.cn |access-date=2026-06-08}}</ref>

=== 民族 ===
全市常住人口中，[[汉族]]人口为9,055,707人，占98.41%；各[[中国少数民族|少数民族]]人口为146,725人，占1.59%。与2010年第六次全国人口普查相比，汉族人口增加1,074,362人，增长13.46%，占总人口比例增加0.02个百分点；各少数民族人口增加15,557人，增长11.86%，占总人口比例下降0.02个百分点。

在中国的56个民族中，济南市有42个民族居住。其中[[汉族]]人口占98.31%，[[回族]]占1.62%，其他少数民族人口较少。

== 经济 ==
[[File:Map of Jinan, 1950s.jpg|thumb|清末民初的濟南地圖，此時的經濟活動主要集中在老城西部的商埠區（此圖中濟南被標註為Chi-Nan）]]
古城西关在明清时期就有不少店铺。自[[清朝]]后期，济南产生了[[资本主义]]的萌芽。1904年，山东巡抚会同当时的直隶总督[[袁世凯]]奏请[[清廷]]在济南开设商埠，“准各国洋商并华商与划定节内租地贸易”。开埠以来济南市的工商业有较快发展，并逐步成为一个主要的商业城市。20世纪初由[[德国]]修建的[[胶济铁路]]和[[津浦铁路]]交汇与此，更促进了济南的繁荣。当时著名的商业区有“一巷，二路，三街，四场”（即剪子巷、经二路、估衣市街、筐市街、普利街、万紫巷商场、大观园商场、新市场、国货商场），著名的店铺摊贩有十大货栈、八大花行和十大酱园，多聚集于经一路、经二路与纬七路一带。[[瑞蚨祥]]也发祥于济南<ref>《济南市志》第一卷, page 347, page 360, page 366，中华书局，2010-10-28查阅</ref>。

1948年[[国共内战]]时期，由于战乱，济南的商埠、市场逐渐凋零，大批商户倒闭，经济也随之萎缩。最近几年，济南致力于大规模整体商埠区<ref>{{Cite web|url=http://jinan.iqilu.com/news/2015/0614/2441745.shtml|title=济南老商埠区享“高规格待遇” 拟不再拓宽道路红线_济南要闻_济南_齐鲁网|accessdate=2018-03-01|work=jinan.iqilu.com|archive-url=https://web.archive.org/web/20180301164534/http://jinan.iqilu.com/news/2015/0614/2441745.shtml|archive-date=2018-03-01|dead-url=no}}</ref>，在规划开发上有所限制。

=== 经济总量 ===
* 國家統計局年鑒數據顯示，該市2007年經濟總量是2563億元，第一、第二、第三產業分別佔5.9%、45.2%、48.9%。
* 2008年，济南市完成GDP3017亿元，在省会城市中第6位，在省会城市中次于[[广州]]（8215）、[[杭州]]（4781）、[[武汉]]（3960）、[[成都]]（3901）、[[南京]]（3775）。
* 2009年，济南市完成GDP3350亿元，较2008年增长11.3，位于全国第21位，省会城市第7位，在省会、[[直辖市]]中次于[[上海]]（14900.9）、[[北京]]（11865.9）、广州（9112.7）、[[天津]]（7500.8）、[[重庆]]（6528.7，[[重庆主城区]]5697.4）、杭州（5088）、武汉（4560）、成都（4502.6）、[[沈阳]]（4359）、南京（4230.2）、[[长沙]]（3745），高于[[郑州]]（3300）。
* 2011年济南全市生产总值4406.29亿元，比上年增长10.6%。按常住人口计算人均生产总值64331元，增长8.9%，折合9960美元。
* 2016年，济南全市地区生产总值6536.1亿元，比上年增长7.8%。按常住人口计算，人均地区生产总值90999元，增长6.5%；按年均汇率折算，为13700美元<ref name=":0" />。
* 2022年，济南市地区生产总值为12027.5亿元，按不变价格计算，增长3.1%，其中，第一产业增加值为420.5亿元，增长3.1%；第二产业增加值为4180.2亿元，增长3.2%；第三产业增加值为7426.7亿元，增长3.0%。三次产业构成比为3.5:34.8:61.7。<ref>{{cite web |author1=吴培利 |title=2022年济南市国民经济和社会发展统计公报 |url=http://jntj.jinan.gov.cn/art/2023/4/12/art_18254_4748571.html |website=济南市统计局 |accessdate=2023-06-02 |archiveurl=https://archive.today/20230602094628/http://jntj.jinan.gov.cn/art/2023/4/12/art_18254_4748571.html |archivedate=2023-06-02 |language=zh-cn |date=2023-04-12}}</ref>

== 交通 ==

济南市作为山东省省会，位于山东省的中心位置，济南也是连接中国华东、华北和中西部地区交通枢纽之一。

在铁路方面，中国铁路济南局集团有限公司（China Railway Jinan Group Co Ltd.），是中国国家铁路集团有限公司管理的18个铁路局集团有限公司之一。曾用名“济南铁路局”，简称“济局”，下属的济南西站，是中国高铁客流最大的干线：京沪高铁，五大始发站之一。

在公路方面，济南市作为山东省省会，连接着全省主要干道，济南公路建设位于全国前列，南北、东西方向以及绕城方向公路发达，是全省公路网络中心和高速公路中心枢纽。 
山东省的交通建设位于全国前列，全省遍布密集的高速公路网。国家公路，省级公路和县级以及县级以下公路互相连接，四通八达。公路路况良好。

在航空方面，济南遥墙国际机场（Jinan Yaoqiang International Airport，IATA：TNA，ICAO：ZSJN）位于济南市东北方向的历城区遥墙镇，距市中心直线距离23千米、公路距离30千米，是中国重要的入境门户和干线机场之一。
2022年6月，济南遥墙国际机场二期改扩建工程可行性研究报告获得国家发改委正式批复。
济南遥墙国际机场二期改扩建工程，预计2026年底竣工。
扩建后，济南遥墙国际机场为山东省首个：3跑道4F机场，同时成为山东省最大机场。

在航运方面，济南港地处省会城市群经济圈的中心，黄河经济带、环渤海经济区及山东半岛城市群的重叠区，济南港主要是运货。 

在公共交通方面，济南市已通过济南轨道交通地铁，串联起：济南遥墙国际机场（Jinan Yaoqiang International Airport，IATA：TNA，ICAO：ZSJN）、济南西站、济南东站、济南站等空铁枢纽。

[[济南地铁|济南轨道交通]]（Jinan Metro），是服务于中国济南市的城市轨道交通系统，其第一条线路济南轨道交通1号线于2019年4月1日正式商业运营。截至2025年12月，济南轨道交通运营线路共有3条地铁、1条云巴环线，总长约127km；在建线路共有6条，分别为：[[济南轨道交通4号线]]、[[济南轨道交通6号线|6号线]]、[[济南地铁7号线|7号线]]、[[济南轨道交通8号线|8号线]]、[[济南轨道交通9号线|9号线]]、[[济南轨道交通济阳线|济阳线]]，总长约188千米。

=== 铁路 ===
{{Main|济南铁路枢纽}}
成立于1949年4月济南战役之后，固定资产为6257568万元，现任总经理刘再民（推荐人选），副总经理赵红森。集团公司营业里程5114.6公里，其中高速铁路1205.7公里，配属动车组127列161标准组、机车741台、客车1596辆。

济南局集团公司，东临沿海，西依中原，北与北京铁路局接轨，南与上海铁路局毗邻，管内京沪高铁、石济客专、京沪线、京九线、蓝烟线、胶新线等线纵贯南北，济郑高铁、青荣城际、胶济客专、胶济、邯济、瓦日、菏兖日、德龙烟等线横跨东西，覆盖山东省全境，辐射140个县、市。营业里程5114.6km，其中高速铁路1205.7km（京沪高铁405.7km、胶济客专393.0km、青荣城际337.2km、石济客专69.8km，均含联络线），电气化率和复线率分别为94.9%和67.7%，配属动车组127列161标准组、机车741台、客车1596辆。
济南的铁路建设始于二十世纪初，1904年建成[[胶济铁路]]，1911年建成[[津浦铁路]]，济南遂成为中国重要的铁路枢纽。途经济南的高速铁路有[[京沪高速铁路]]、[[济青高速铁路]]、[[胶济客运专线]]、[[石济客运专线]]、[[济莱高速铁路]]、[[郑济高铁]]、[[济滨城际铁路]]（在建）、[[济枣高速铁路]]（在建）、[[莱临高速铁路]]（规划）、[[济济高速铁路]]（规划），干线铁路有[[京沪铁路]]、[[胶济铁路]]、[[邯济铁路]]、[[辛泰铁路]]、[[磁莱铁路]]，支线铁路有[[济南铁路]]，[[济南铁路局]]也位于济南市。始建于1904年的[[济南站]]是全国大型综合客运货运站之一，属[[特等站 (中国大陆)|特等站]]，乘坐从济南火车站始发和途经的快速列车可以到达全国各省会和主要城市。2011年落成的[[济南西站]]是全国大型现代化客运站之一，属[[特等站 (中国大陆)|特等站]]，是[[京沪高速铁路]]的五大始发站，乘坐从济南西站始发和途径的高速列车和动车组可以到达[[京沪高铁]]沿线各城市。2018年落成的[[济南东站]]是山东省规模最大的火车站，是[[济青高速铁路]]、[[石济客运专线]]、[[济莱高速铁路]]、[[济滨城际铁路]]（在建）的起始站。[[大明湖站]]是胶济线上的二等客货运车站。2022年12月30日启用的[[历城站]]是[[济莱高速铁路]]上的高铁站。在济中心城区外，还建有[[长清站]]、[[章丘北站]]、[[章丘南站]]、[[章丘站]]、[[雪野站]]、[[莱芜北站]]、[[钢城站]]，在建[[遥墙机场站]]、[[济阳站]]、[[商河南站]]、[[南山站（高铁）|南山站]]。

=== 航空 ===
{{Main|济南遥墙国际机场}}

在航空方面，济南遥墙国际机场（Jinan Yaoqiang International Airport，IATA：TNA，ICAO：ZSJN）位于济南市东北方向的历城区遥墙镇，距市中心直线距离23千米、公路距离30千米，是中国重要的入境门户和干线机场之一。济南遥墙国际机场于1992年7月26日建成通航，2000年10月完成飞行区扩建工程；2005年3月完成航站区扩建工程；2015年南指廊建成投入使用；2021年北指廊建成投入使用。

2022年6月，济南遥墙国际机场二期改扩建工程可行性研究报告获得国家发改委正式批复。
2022年8月27日上午，济南遥墙国际机场二期改扩建工程建设推进会，在济南遥墙国际机场举行。2024年6月30日，济南遥墙国际机场综合交通枢纽工程：济滨高铁2号隧道首板拱顶浇筑完成。9月4日消息，济南机场二期改扩建综合交通中心主体结构封顶。2025年11月11日，济南遥墙国际机场二期改扩建工程西飞行场道项目西二跑道顺利贯通。济南遥墙国际机场二期改扩建工程，预计2026年底竣工。

济南遥墙机场二期改扩建工程是山东省新旧动能转换和建设交通强省的重大工程，总投资500.84亿元，其中机场工程投资419.27亿元。扩建后，济南遥墙国际机场为山东省首个：3跑道4F机场，同时成为山东省最大机场。飞行区及航站区土建工程按目标年2035年、年旅客吞吐量5500万人次进行建设。飞行区按4F等级进行建设，新建两条3600米长的跑道、60万平方米的航站楼，新建167个各类机位的站坪。

济南市区公共交通的历史始于1938年[[中華民國臨時政府 (1937年—1940年)|中华民国临时政府]]设立的“华北交通株式会社济南自动车营业所”<ref>{{Cite web |title=记忆 {{!}} 老公交：在济南时光中穿行 |url=https://www.sohu.com/a/www.sohu.com/a/160845692_488237 |website=www.sohu.com |language=zh-CN |access-date=2026-06-08}}</ref>。现在济南1路公交的中间一段仍沿当年1路车的路线运行。济南市公共交通十分发达，为全国公共交通建设先进示范城市。为保证公交优先，市区主干道大多建设有公交专用道。快速公交系统的信号优先措施也在逐步实施中。

==== 公交车 ====
{{main|济南公交}}
[[公共汽车]]和[[无轨电车]]为居民出行的主要交通工具，市区内共有近7500多辆公交车辆，公共交通线路560多条，由济南公共交通集团有限公司承运<ref>{{Cite web |title=济南公交总公司 |url=https://www.jnbus.com.cn/gjztqyjj.jhtml |website=www.jnbus.com.cn |access-date=2026-06-08}}</ref>，基本遍布于城市每个角落，市区线路均为无人售票车，单一票价，普通车票价1元，空调车、K开头空调车及BRT线路2元（IC卡八折，两小时内换乘六折，学生卡四折）。

* [[济南快速公交|快速公交（BRT）]]：目前有13条主要线路，票价两元，实行车站内免费换乘。由于采用了硬隔离中央专用道、信号优先等措施，车速较普通公交有很大提高，目前已成为市区重要的公共交通形式之一。但“BRT”公交的专用车道挤占了马路空间反而使得交通状况恶化，而且在一些拥堵路段仍然要受到信号灯等各种因素的困扰，因此招致部分公众批评。2019年起部分普通公交线路也开始部分停靠BRT车站，线路号改为B开头。

* 常规线路：遍及市区各地。自2018年起，济南公交已基本实现空调车全覆盖<ref>{{Cite news|url=http://fangchan.qlwb.com.cn/news/2018/cjgh_0706/54323.html|title=年底济南公交车全部更新为空调车 还将推虚拟公交卡|author=|date=|work=齐鲁晚报|publisher=|accessdate=|language=|format=|archive-date=2019-06-22|archive-url=https://web.archive.org/web/20190622115233/http://fangchan.qlwb.com.cn/news/2018/cjgh_0706/54323.html|dead-url=no}}</ref>，票价2元。少部分非空调车票价1元。原有K开头空调车2元（IC卡八折，两小时内换乘六折，学生卡四折）。
** [[济南无轨电车|无轨电车线路]]：线路号为101至104，均为济南市重要的公共交通线路，客流量大，运营时间长。票价与普通公交汽车相同。

* 社区线路：往返与各个社区之内，线路号为5开头的三位数，票价1元。

* 近郊线路：市郊线路包括去往南部山区村镇的，线路号多为8开头的三位数，票价一元。以及去往东郊的线路号多为3开头的三位数。

* 通勤线路：仅在早高峰与晚高峰期间运行，线路号为T开头（包括K201、K205、K209），票价2元。

* 旅游线路：往返在市区与旅游景点之间，线路号为游7开头的三位数，票价20元（游709）或40元（游701、游707、游709）。以及行驶在市区内著名景观之间，线路号为777的三条支线，票价12元(非节假日当日车票可乘坐2次)，可享受名泉泡茗茶一杯(一票一次)，泉城特色邮政车票一张。旅行社团队6折优惠，20人以上团队6折优惠，10人以上团队7折优惠。

* 机场线路：共4条线路，分别在玉泉森信大酒店、[[济南站]]、[[济南西站]]和[[济南长途汽车总站]]与[[济南遥墙国际机场]]之间往返，票价20元。

* 远郊线路：远郊线路由山东交通运输集团运营，包括去往长清的线路3条，分别为济长1路、2路和3路，票价4元；去往章丘的线路4条；去往济阳的线路3条；去往莱芜的线路3条，分别为济南济莱城际快客总站线、东站线和西站线，票价20元；去往平阴的线路2条；去往齐河的线路5条；去往泰安的线路1条，多级票价，全程15元。其中去往章丘、济阳、泰安的线路号多为K9开头的三位数，大部分实行多级票价。

== 文化 ==
=== 语言 ===
{{Main|济南话}}

[[济南话]]属[[冀鲁官话]][[石济片]][[聊泰小片]]，使用于市中、历下、槐荫、天桥、历城、长清六区，与[[普通话]]相差不大，会普通话的很容易听懂济南话。而由于改革开放后，特别是20世纪90年代来济南工作定居的外地人的增多，[[90后]]出生的“新济南人”在家庭和学校里通常使用[[普通话]]，因而导致了济南话使用者的逐渐减少，传统济南词汇逐渐流失。

济南话的语调相对简单。一般在双音节词中首字为普通话的一声，济南话则为三声，普通话的三声济南话为一声（即一三对换），如末字为一声多数情况下保持一声，末字普通话为二声济南话则为四声，四声调基本相似。句法方面济南方言在比较句、反复问句和补语结构等方面有自己的特点，但其基本语序和句子的主要组织方式上与普通话差异不大。因此大多数人可以听懂济南话，但有很多[[方言]]性词组及[[俚语]]需要额外解释。

此外，莱芜区与钢城区的[[莱芜话]]、[[平阴县]]的平阴话与济南话同属聊泰小片，而章丘区的章丘话属冀鲁官话[[章利片]]，济阳区的济阳话属冀鲁官话[[沧惠片]][[阳寿小片]]，[[商河县]]的商河话属冀鲁官话沧惠片[[黄乐小片]]。

==== 佛教 ====

济南的佛教自隋唐时期开始发展，此后一段时间内十分兴盛。济南高僧义净，曾继[[玄奘|唐僧]]之后赴[[印度]]取经，译佛经百余部。

济南市内有诸多佛教胜迹。历城的[[四门塔]]为中国现今最古老的石塔。建于隋朝的[[千佛山]][[兴国禅寺]]为[[汉族地区佛教全国重点寺院]]之一。[[灵岩寺 (长清)|灵岩寺]]、青铜山、玉函山、龙洞等地亦有其他佛教遗迹。

==== 道教 ====

元代在大明湖畔建立了一所道观，名为[[北极阁 (济南)|北极阁]]，供奉[[玄武帝]]。

==== 伊斯兰教 ====

位于济南市中区礼拜寺街的[[济南清真南大寺|礼拜寺]]，为中国[[伊斯兰教]]早期著名的[[清真寺]]之一，[[文化大革命]]中遭到严重破坏，改革开放后由济南社会各界斥资重修。后殿的两个巨星圆窗雕刻有《[[古兰经]]》经文，为罕见的中国伊斯兰古典艺术珍品。

==== 天主教 ====

1870年，顾立爵神父在济南东郊的洪家楼购地兴建教堂。1902年，[[方济各会]]的[[荷兰]][[传教士]]{{link-en|申永福|Ephrem Giesen}}利用[[八国联军]]侵华后中国政府的[[庚子赔款]]，在洪家楼动工兴建新的教堂，即今日的[[洪家楼教堂]]，是中国[[华北地区]]最大的教堂。该教堂1966年[[文化大革命]]中被关闭，济南全市亦严禁任何宗教活动。改革开放后的1985年[[圣诞节]]，洪家楼教堂重新开放，济南市的天主教基督徒在此举行了盛大[[弥撒]]。

=== 文学 ===
济南历史上涌现了很多文人墨客，最著名的是“济南二安”：[[李清照]]（号易安）和[[辛弃疾]]（字幼安），李清照是中国历史上最著名的女词人，词作具有独特的艺术风格，创造了“易安体”，同时也被称为“婉约派”之宗。[[辛弃疾]]被认为是“豪放派”的代表人物，被誉为“词中之龙”。元代的[[张养浩]]，散曲造诣极高，[[元曲]]在他的时期达到顶峰。

==== 千佛山庙会 ====
济南自元代开始，就在每年的农历九月九日（[[重阳节]]）在[[千佛山]]上举行庙会。旧时赶庙会者大多会购买一定数量的柿子，遂有“柿子节”之称。庙会鼎盛时段，千佛山上的各种摊位可以达到1000以上。全国各地的药商会趁此时机在山上进行药材交易，此被单独成为“药市会”。庙会期间亦有各种杂技、马戏、歌舞表演等。

近年来，千佛山庙会依然兴盛，举办时间为农历春节期间、[[上巳节|农历三月初三]]<ref>{{Cite web|url=http://www.sanqin.com/2017/0330/289089_4.shtml|title=济南千佛山“三月三”庙会迎游客_三秦网|accessdate=2018-03-01|work=www.sanqin.com|language=zh-CN|archive-url=https://web.archive.org/web/20180301164534/http://www.sanqin.com/2017/0330/289089_4.shtml|archive-date=2018-03-01|dead-url=yes}}</ref>、重阳节。以春节庙会为例，众多市民前来上香祈福，并有各色民俗活动，敲大鼓等活动亦允许市民参与。商贩亦借此机会在上山步道两侧摆摊设点贩卖商品，以特色小吃及工艺品为主，亦有书摊及其他特色摊位。

==== 趵突泉灯会 ====
自1980年起，济南每逢[[元宵節 (華人)|元宵节]]和[[中秋節 (華人)|中秋节]]，会在[[趵突泉]]公园举行灯会，从未中断。灯会以老济南特色为主，亦吸引了不少外地及外国游客。近年来之灯会，强调环保、创新、参与，不仅逐渐使用LED灯替换原有卤素灯，还制作如扫码抽奖、头像合成等供市民参与的灯组<ref>{{Cite web|url=http://www.qlmoney.com/content/20180212-312023.html|title=趵突泉迎春花灯会初一亮灯 2018年济南看花灯攻略详解-齐鲁财富网|accessdate=2018-03-01|work=www.qlmoney.com|archive-url=https://web.archive.org/web/20180301164424/http://www.qlmoney.com/content/20180212-312023.html|archive-date=2018-03-01|dead-url=no}}</ref><ref>{{Cite web|url=https://www.dzwww.com/tupian/wyzp/201802/t20180212_17041177.htm|title=靓！2018趵突泉花灯提前看！大年初一晚亮灯迎客_大众网|accessdate=2018-03-01|last=孙翔|work=www.dzwww.com|language=zh-CN|archive-url=https://web.archive.org/web/20180301225054/https://www.dzwww.com/tupian/wyzp/201802/t20180212_17041177.htm|archive-date=2018-03-01|dead-url=no}}</ref>。

==== 放河灯 ====
据济南当地的传说，农历七月三十日是佛教中地藏王菩萨成道的日子。他曾发誓要普度有罪孽的众生，使他们脱离苦海。为“超度亡魂”，每逢农历七月三十日晚，济南市民以及寺庙的僧侣会制作众多的[[河灯]]及纸船，放入护城河及大明湖水中。北极庙的道士亦同在此日悼念亡魂，他们在大明湖畔放置大量“[[法船]]”并在岸边做法，后将“法船”一一烧毁，场面壮观。这个习俗在[[文化大革命]]后彻底消失。

==== 曲水流觞 ====
从[[魏國 (春秋)|魏]][[晋朝|晋]]开始，济南市民及文人墨客在农历的三月初三[[上巳節]]会举行一种名叫“[[曲水流觞]]”的诗酒宴会。人们围坐在溪水周围，把置有酒杯的托盘放在上游的水面，任其沿水流漂流。托盘若停下，则谁离停下的酒杯近，谁就得饮酒作诗，若作诗未果则要被罚酒。[[北魏]][[郦道元]]在《[[水经注]]》一书中写道：“历祠下泉源竞发，北流经历城东又北，引水为流杯池，州僚宾宴公私多萃其上”。后经考证，“流杯池”即为今日的[[王府池子]]，市民举行诗酒宴会的溪水便是其分流，被称作“曲水河”，所在的街巷因此而叫做[[曲水亭街]]。此习俗止于清末民初。

== 社会 ==
=== 教育 ===
{{main|济南市学校列表}}
济南作为[[山东省]][[中华人民共和国省会列表|省会]]，[[山东大学]]、[[山东师范大学]]、[[济南大学]]、[[山东财经大学]]、[[齐鲁工业大学]]等高等院校在此建驻。20世纪60-70年代[[文革]]时期，[[毛泽东]]号召高校转移到偏远地区，部分驻济南高校搬迁到[[泰安市|泰安]]等地级市，文革以后，大部分院校回迁，2003年[[长清大学科技园]]开工程建设，部分高校入驻。除此之外，[[山东省实验中学]]等很多初等教育机构也有着十分悠久的历史。

=== 体育 ===
[[File:JinanOlympic.JPG|thumb|[[济南奥体中心]]]]
{{main|山东省体育赛事列表|山东职业体育俱乐部列表|模板:济南市体育场馆}}

== 旅游 ==
{{main|济南市旅游景点列表}}
济南的旅游突出“泉城”特色。市区为恢复旧城“四面荷花三面柳，一城山色半城湖”的风貌，做了不少努力。改革开放初期济南的泉水曾遭到严重破坏，后来为了恢复市区内各个泉群的持续喷涌，济南市制定了“保泉”计划。通过限制地下水开采，加强补给区水利建设等措施，现今济南各大泉群均已保证了全年喷涌。此外，济南作为明清两代省会及历史文化名城，名胜古迹众多。市区内即有英雄山（[[济南革命烈士陵园]]）、郎茂山等山丘，如今多数已辟为郊野公园。近年来亦在郊区开发众多主题公园及郊野公园，吸引市民游览。

== 外国驻济南领事机构 ==
{{see also|山东外事}}
[[File:British Consulate, Jinan.jpg|thumb|[[英国驻济南领事馆旧址]]]]

[[英国]]、[[德国]]、[[日本]]、[[瑞士]]和[[美国]]曾于20世纪初在济南设置领事机构；[[意大利]]、[[奥地利]]也曾经在济南设立领事代办处，但均于1949年以前结束领事服务<ref>{{cite web|url=http://www.infobase.gov.cn/bin/mse.exe?seachword=&K=a&A=13&rec=70&run=13|title=《山东省省情资料库-市中区志-第三卷 外国领馆与外侨-第一类 领（事）馆》|accessdate=2012-05-16|work=|publisher=山东省情网|deadurl=yes|archiveurl=https://web.archive.org/web/20131221041116/http://www.infobase.gov.cn/bin/mse.exe?seachword=|archivedate=2013-12-21}}</ref> <ref>{{cite web|url=http://61.133.102.60/common/news.asp?n_id=88|title=《济南历史优秀建筑－原德国驻济领事馆》|accessdate=2010-01-18|work=|publisher=中共济南市委党校图书馆}}{{dead link|date=2018年2月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref> <ref>{{cite web|url=http://www.infobase.gov.cn/bin/mse.exe?seachword=&K=a&A=13&rec=69&run=13|title=第二辑 外国驻青岛领事机构|publisher=《山东省志》}}{{dead link|date=2018年1月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>。

2020年6月16日，中国-柬埔寨政府间协调委员会第五次会议召开，据此会议的决议，[[柬埔寨]]将在济南设立柬埔寨王国驻济南总领事馆，为中华人民共和国成立以来外国在济南设立的首个总领事馆，<ref>{{Cite news | url=http://www.jinan.gov.cn/art/2020/6/22/art_3731_4495517.html | title=济南将迎“首个”总领事馆 | publisher=济南市人民政府 | date=2020-06-22 | accessdate=2020-09-22 | archive-date=2020-09-26 | archive-url=https://web.archive.org/web/20200926004712/http://www.jinan.gov.cn/art/2020/6/22/art_3731_4495517.html | dead-url=no }}</ref><ref name="CambodiaMissions">{{cite web |url=https://www.mfaic.gov.kh/EmbassyCambodiaMissionAbroad |title=Cambodia Mission Abroad |publisher=Ministry of Foreign Affairs & International Cooperation of Cambodia |accessdate=2021-08-05 |archive-date=2021-08-13 |archive-url=https://web.archive.org/web/20210813171620/https://mfaic.gov.kh/EmbassyCambodiaMissionAbroad |dead-url=no }}</ref>其地址位于济南市高新区经十路7000号汉峪金融商务中心五区三号楼（云鼎大厦）48楼<ref>{{Cite web |title=外国驻华领事机构信息_中华人民共和国外交部 |url=https://www.mfa.gov.cn/web/lbfw_673061/lsgmd_673079/202201/t20220117_10591470.shtml |website=www.mfa.gov.cn |access-date=2026-06-08}}</ref>。
