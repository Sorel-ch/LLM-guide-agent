'''兴国县'''是[[中国]][[江西省]][[赣州市]]所辖的一个[[县]]， 位於江西省中南部、東與寧都縣接壤，東南與于都縣相鄰，南與贛縣區相連，西與吉安市萬安縣交界，西北與吉安市泰和縣為鄰，北靠吉安市永豐縣、吉安縣、 也是[[客家人]]的聚居地之一，縣人民政府駐[[潋江镇]]客家路8號。

== 历史沿革 ==
[[三国]]·[[吴]][[嘉禾 (孙吴)|嘉禾]]五年（公元236年）曾在今兴国县地置'''平阳县'''。

[[北宋]][[太平兴国]]七年（公元982年）析[[赣县]]、[[庐陵县|庐陵]]、[[泰和县|泰和]]三县地置兴国县<ref name="gps">[http://chgis.hmdc.harvard.edu/v3_src_note.php?ntid=40842 China Historical GIS]，2001-2010 - Harvard University and Fudan University</ref>，以年号“[[太平兴国]]”为县名<ref name="旅游资源概况">{{Cite web |url=http://www.xingguo.gov.cn/xggk/lyzn/200810/t20081024_13579.htm |title=旅游资源概况 |accessdate=2010-10-09 |archive-date=2011-01-31 |archive-url=https://web.archive.org/web/20110131202619/http://www.xingguo.gov.cn/xggk/lyzn/200810/t20081024_13579.htm |dead-url=no }}</ref>，属[[虔州]]<ref name="gps" />。是为兴国县之始，以后未改。[[太平天国]]时曾避讳“天国”而改名为“兴郭县”。

== 地理 ==
===区位===
兴国县位于江西省中南部、赣州市北部，东倚[[宁都县]]，东南邻[[于都县]]，南连[[赣县]]，西邻[[万安县]]，西北界[[泰和县]]，北毗[[吉安市]][[青原区]]和[[永丰县]]。位于[[雩山]]山区，连接[[吉泰盆地]]<ref name="江西省地图册">{{cite book |title=江西省地图册 |author= |year=2008 |publisher=星球地图出版社 |isbn=978-7-80212-369-4 }}</ref>。距赣州市82公里，距[[南昌]]346公里。

===地形地貌===
面积3214.46平方公里，东西长84公里，南北宽71.5公里，地貌以[[低山]]、[[丘陵]]为主<ref name="自然资源">{{Cite web |url=http://www.xingguo.gov.cn/xggk/zrzy/200810/t20081023_6576.htm |title=自然资源 |accessdate=2010-10-10 |archive-date=2011-06-09 |archive-url=https://web.archive.org/web/20110609044535/http://www.xingguo.gov.cn/xggk/zrzy/200810/t20081023_6576.htm |dead-url=no }}</ref>，山地占79.6%，耕地占9.9%，水域占7.8%，道路庄园等占12.6%，形成“七山一水一份田，一份道路和庄园”的自然风景。

最高峰[[大乌山]]，海拔1205米，位于北部与[[青原区]]交界处。其次有[[十八排]]，海拔1176米，位于西北与[[泰和县]]交界处。<ref name="江西省地图册"/>

最低处是[[龙口乡]]睦埠村，海拔127.9米。<ref name="自然资源"/>

===水系===
[[File:Changgang Reservoir before the dam.jpg|thumb|长冈水库大坝前的水面（丹霞湖）]]
主要河流为[[平江 (贡水支流)|平江]]及其上游支流[[潋水]]、[[濊水]]<ref name="hanspub">{{cite web |url=https://pdf.hanspub.org/JWRR20220600000_98118029.pdf |title=基于水力学模型和综合风险度的洪水风险区划 |author=李亚琳，李德龙，许小华，梁秀 |language=zh |publisher=水资源研究 |date=2022-12-31 |accessdate=2023-06-06 |archive-date=2023-06-06 |archive-url=https://web.archive.org/web/20230606191924/https://pdf.hanspub.org/JWRR20220600000_98118029.pdf |dead-url=no }}</ref><ref name="sohu">{{cite web |url=https://www.sohu.com/a/25221012_217984 |title=兴国旅游“潋江国家湿地公园” |language=zh |publisher=搜狐 |date=2015-08-01 |accessdate=2023-06-06 |archive-date=2023-06-06 |archive-url=https://web.archive.org/web/20230606191925/https://www.sohu.com/a/25221012_217984 |dead-url=no }}</ref>，此外还有[[泷江]]、[[良口河]]、[[梅江 (赣江支流)|梅江]]、[[云亭河]]，共五大水系。流域面积10平方公里以上的河流有53条，主要干流788.6公里，河网密度为每平方公里0.23公里。<ref name="自然资源"/>

建有大型水库[[长冈水库]]和中型水库[[长龙水库]]。<ref name="江西省地图册"/>

=== 气候 ===
兴国属[[亚热带季风气候]]，年平均气温为18.8℃，年平均降雨量为1515.6毫米，年平均无霜期284天。<ref name="自然资源"/>

== 人口 ==
[[File:Bell Tower Xingguo County.jpg|thumb|upright|left|钟楼]]
兴国是[[客家人]]的主要聚居地之一，客家先民主要来自今[[陕西]]、[[甘肃]]、[[河南]]、[[河北]]、[[山西]]、[[山东]]6省，尤以河南、甘肃两省为多。<ref>{{Cite web |url=http://www.xingguo.gov.cn/xggk/lsyg/200810/t20081023_6575.htm |title=历史沿革 |accessdate=2010-10-10 |archive-date=2011-06-09 |archive-url=https://web.archive.org/web/20110609044510/http://www.xingguo.gov.cn/xggk/lsyg/200810/t20081023_6575.htm |dead-url=no }}</ref>

2003年人口为73.2万。

2021年末，興國縣户籍人口總户數23.27萬户；總人口85.87萬人，其中鄉村人口63.46萬人，城鎮人口22.41萬人；出生人口8408人，死亡人口3961人。

== 经济 ==
大力发展红门工业园区。发展特色水果，轻工业发展较快。

=== 自然景观 ===
[[File:Lianjiang National Wetland Park 2025-10-16 (23239).jpg|thumb|潋江国家湿地公园]]
兴国是[[丹霞地貌]]的分布区，主要分布于距县城不远的北侧和东侧，两个区域连成一片，呈[[哑铃]]状。[[宝石仙境风景区]]位于城北13公里处，总面积约30平方公里；[[灵山 (兴国)|灵山]][[冰心洞]]风景区位于城东10公里处，总面积约30平方公里，丹霞湖（[[长冈水库]]）位于其东侧。<ref name="旅游资源概况"/>

除了丹霞地貌，兴国还有[[喀斯特地貌]]，位于[[梅窖镇]]的[[太平岩溶洞]]是一个迷宫式中型[[石灰岩]][[溶洞]]，总面积在1万平方米以上，洞内结构复杂，已探明的有三层以上。<ref name="旅游资源概况"/>

[[均福山森林公园]]位于城北的[[崇贤乡]]和[[枫边乡]]境内，[[文天祥]]曾在此抗击元兵，1931年9月15日，毛泽东、朱德在此歼灭[[中華民國國軍|国军]]第52师。高80米的[[龙下瀑布]]、海拔1205米的[[大乌山]]均位于园内。<ref name="旅游资源概况"/>

[[潋江国家湿地公园]]位于城南，规划总面积为53655亩，其中湿地面积为35437亩，以湿地公园内的潋水、濊水、长冈水库为骨架，集河流、沼泽、蓄水区、水塘等于一体的自然与人工复合湿地系统。<ref name="湿地">{{cite web | url = http://jx.people.com.cn/n2/2017/0214/c362505-29713749.html | title = 航拍：兴国潋江国家湿地公园 | publisher = 人民网 | date = 2017-02-14 | accessdate = 2017-08-20 | archive-date = 2020-05-04 | archive-url = https://web.archive.org/web/20200504030231/http://jx.people.com.cn/n2/2017/0214/c362505-29713749.html | dead-url = no }}</ref>

== 文化 ==
[[File:Former residence of Chen Qihan 20230509 161944.jpg|thumb|[[陈奇涵故居]]]]
[[File:Former residence of Xiao Hua, 2025-09-27.jpg|thumb|[[萧华故居]]]]
===红色文化===
兴国號稱是中華人民共和國的将军县，1955年—1964年间授衔的兴国籍将军有54位，著名的有[[萧华 (上将)|萧华]]、[[陈奇涵]]等。此外[[毛泽东]]、[[陈毅]]、[[朱德]]等人都曾在兴国工作、战斗。<ref name="旅游资源概况"/>

===客家文化===
兴国是[[客家]]人的聚居地，是很有代表性的客家县。<ref name="旅游资源概况"/>

===堪舆文化===
兴国是[[风水]]学中最盛行的流派——赣派风水的发源地，[[梅窖镇]][[三僚村]]被誉为“中国风水地理文化第一村”。<ref name="旅游资源概况"/> 历史上著名的风水师有[[杨筠松]]、[[曾文辿]]、[[廖瑀]]等。
