'''平湖市'''是由[[中华人民共和国]][[浙江省]][[嘉兴市]]代管的一个[[县级市]]，位于浙江省北部、杭嘉湖平原东端，南临杭州湾，东北与上海市金山区交界，西与嘉兴市南湖区接壤，西南与海盐县为邻，西北与嘉善县相接。区域总面积为554.14平方公里。

== 历史 ==
[[File:Du Halde - Description de la Chine - Villes de Kiu tcheou fou - Pinghou hien.jpg|thumb|left|200px|[[衢州府]]和[[平湖县]]的地图，出自1736年[[杜赫德]]所著《中国概况》]]
[[File:City of Pinghu in 1780.jpg|thumb|left|200px|清乾隆四十五年（1780年）《平湖县志》县治城内全图。]]

[[明朝|明]][[宣德]]五年（1430年）自[[海盐县]]析置“'''平湖县'''”，属[[嘉兴府]]。1991年，撤销平湖县，设立县级平湖市至今。

== 地理 ==
平湖市地处[[杭嘉湖平原]]，东北部与[[上海市]]相接，南濒[[杭州湾]]，境内地势低平、河网密布。

平湖属江南古陆外缘杭州湾凹陷，为一冲积平原。境内地势平坦，平均海拔2.8米。除东南沿海有呈带状分布的20座低丘和11座岛礁（共4.89平方公里）外，其余均为大片平原。全市陆域面积557平方公里，海域面积1,086平方公里，海岸线长27公里；耕地面积47万亩。

== 气候 ==
平湖属北亚热带季风气候，年平均气温16℃左右，年平均日照时数在2,000小时左右，年平均降水量1,170毫米左右，全年无霜期225天左右。

== 人口 ==
2021年，平湖市常住人口68.35万人，比上年增长1.8%。人口城镇化率67.6%，比上年提升0.6个百分点。户籍总户数173248户，户籍总人口51.30万人，增长1.0%。

2024年，平湖市常住人口69.7万人，比上年增长约0.7%。人口城镇化率71.2%，比上年提升2.09个百分点。户籍总人口51.7885万人，增长约0.28%。

== 经济 ==
平湖市经济较为发达，为全国最具实力的[[县级行政区|县市]]之一。2023年，全平湖市[[国内生产总值|国内生产总值]]（GDP）总量为1,008.66亿元<ref name="gdp2023" />。在中小城市发展战略研究院发布的《2023年度全国综合实力百强县市》中，平湖市位列第57位<ref>{{cite web|title=2023年度全国综合实力百强县市|url=http://www.csmcity.cn/luntan/bbs2023/2023_01.php|publisher=中小城市发展战略研究院|language=zh|accessdate=2024-04-28|archive-date=2023-12-01|archive-url=https://web.archive.org/web/20231201005632/http://www.csmcity.cn/luntan/bbs2023/2023_01.php|dead-url=no}}</ref>。

由于临近[[上海]]，平湖吸引了500余家外资跨国企业投资落户，主要集中在日本光机电和德国精密制造产业。传统优势工业涵盖[[服装]]、[[箱包]]、[[机电]]和[[造纸]]等领域，其中服装制造业产值极高，出口额居全国前列。

在农业方面，平湖盛产粮油和[[水产品]]，素有“金平湖”之称。主要作物与农产品包括[[水稻]]、[[小麦]]、[[油菜]]、[[对虾]]和[[禽蛋]]等，并以特产[[糟蛋]]和[[西瓜]]闻名。

市境西南部的[[乍浦镇]]拥有[[杭州湾]]畔重要的深水港[[嘉兴港]]。此外，乍浦镇东部建有装机容量达512万千瓦的[[嘉兴发电厂]]<ref>{{cite web|title=全国“装机容量最大”四大火力发电厂！|url=https://power.in-en.com/html/power-2376850.shtml|publisher=国际电力网|language=zh|accessdate=2020-10-07|archive-date=2021-02-27|archive-url=https://web.archive.org/web/20210227212000/https://power.in-en.com/html/power-2376850.shtml|dead-url=no}}</ref>，为中国巨型火力发电厂之一。

== 教育 ==
平湖市（含乍浦地区）共有中小学及乌幼等全日制学校83所，教职工6,665人。其中：幼儿园40所、小学18所、初中11所、九年一贯制学校5所、普通高中4所、完全中学1所、特殊教育学校1所、中职学校3所，在校生共74,945人<ref>{{cite web|title=宜居平湖 教育|url=http://www.pinghu.gov.cn/art/2020/11/28/art_1229438650_59017708.html|publisher=平湖市人民政府|language=zh|access-date=2020-11-28|archive-date=2021-06-14|archive-url=https://web.archive.org/web/20210614090230/http://www.pinghu.gov.cn/art/2020/11/28/art_1229438650_59017708.html|dead-url=yes}}</ref>。
