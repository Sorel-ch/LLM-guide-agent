'''朝阳区'''是[[北京市]]的一个[[市辖区]]，属于[[城六区]]之一，位于北京市区东部，东与[[通州区]]接壤，西与[[海淀区|海淀]]、[[西城区|西城]]、[[东城区|东城]]等区毗邻，南连[[丰台区|丰台]]、[[大兴区|大兴]]两区，北接[[顺义区|顺义]]、[[昌平区|昌平]]两区。朝阳区是[[城六区]]中面积最大的一个，南北长28公里，东西宽17公里，土地总面积470.8平方公里，其中建成区面积177.2平方公里。2021年实现地区生产总值7617.8亿元，同比增长7.5%，人均GDP约3.6万美元<ref>{{cite web |title=朝阳区2021年国民经济和社会发展统计公报 |url=http://www.bjchy.gov.cn/affair/tjgb/4028805a801c0ab301801c9c96760085.html |website=北京市朝阳区统计局 |date=2022-04-12 |access-date=2023-09-01 |archive-date=2023-09-01 |archive-url=https://web.archive.org/web/20230901135711/http://www.bjchy.gov.cn/affair/tjgb/4028805a801c0ab301801c9c96760085.html |dead-url=no }}</ref>。區人民政府駐[[朝外街道]]日壇北街33號。

== 历史 ==
[[File:朝阳区“十四五”时期水系连通建设工程图.jpg|thumb|朝阳区“十四五”时期水系连通建设工程图]]
[[File:朝阳区“十四五”时期绿色空间结构规划图.jpg|thumb|朝阳区“十四五”时期绿色空间结构规划图]]
朝阳区历史久远。从[[秦朝|秦]]至[[隋朝|隋]][[唐朝|唐]]，该地区属[[广阳郡]]，后属[[幽州]]所辖的[[蓟县]]，[[辽朝|遼]]时归燕京道[[析津府]]，[[金朝|金]]时属[[中都路]][[大兴府]]，[[元代]]将中都路大兴府改为中都路[[大兴县 (金朝)|大兴县]]，[[明朝|明]][[清朝|清]]时属京师[[顺天府]]，仍归大兴县管辖。1925年设[[區 (中華民國)|区]]，称北京市东郊区，1928年改为[[北平市]]东郊区，1958年经[[中华人民共和国国务院|国务院]]批准改为'''朝阳区'''至今<ref>{{cite news |title=朝阳区行政区域的演变过程 |url=https://k.sina.com.cn/article_2080600803_7c0372e3001011uir.html |work=北京日报 |date=2020-06-30 |accessdate=2023-09-01 |archive-date=2023-09-02 |archive-url=https://web.archive.org/web/20230902040111/https://k.sina.com.cn/article_2080600803_7c0372e3001011uir.html |dead-url=no }}</ref>。

== 人口 ==
截至2022年末，朝陽區常住人口344.2萬人，比上年末減少0.7萬人<ref name=pop>{{Cite web|title=2022年末朝阳区常住人口344.2万人|url=http://www.bjchy.gov.cn/affair/tjxx/compile/4028805a874a890001874b0c8f0000b0.html|access-date=2023-08-13|website=北京市朝阳区统计局|archivedate=2023-08-13|archiveurl=https://web.archive.org/web/20230813031355/http://www.bjchy.gov.cn/affair/tjxx/compile/4028805a874a890001874b0c8f0000b0.html|dead-url=no}}</ref>。其中，常住外來人口124.3萬人，佔常住人口的比重為36.1%。常住人口出生率為5.48‰，死亡率為5.17‰，自然增長率為0.31‰。截至2022年末，朝陽區户籍人口218.9萬人，比上年末增加2.7萬人，比上年增長1.3%。

== 科教文体 ==
[[File:朝阳区“十四五”时期空间结构示意图.jpg|thumb|朝阳区“十四五”时期空间结构示意图]]
朝阳区是北京市[[教育]]、[[科技]]、[[文化]]的密集区。现有中央、市属科研院所159家，民营科技企业1037家，促进了辖区经济发展和科技进步。有大学28所，占北京市高校总数的22.8％；成人学校有260多所，另有特殊学校7所。区内有[[人民日报]]社、[[北京广播电台]]等新闻出版单位17个，[[中国中央电视台|中央电视台]]、[[北京电视台]]也已迁入朝阳区。此外，区内还有专业文化团体和艺术院校15个，广播电视用地2处，图书馆1座，博物馆3座，影剧院16座，文化站或社区文化中心47个，社会文化娱乐场所603家。[[亚运会]]、[[奥运会]]主场馆都在朝阳区。除奥运公园的14个场馆外，朝阳区还有2个改扩建场馆，占北京市奥运场馆近一半，朝阳是名副其实的北京市[[体育运动|体育]]中心。

== 旅游资源 ==
朝阳区旅游资源丰富，旅游定点餐馆、旅游定点商店、A级旅游区（点）、旅游定点演出单位、旅游摄像公司和旅游社及分支机构达200余家。<ref>[http://bj.bendibao.com/zqjs/52_0.htm 北京市朝阳区概况] {{webarchive|url=https://web.archive.org/web/20090403200651/http://bj.bendibao.com/zqjs/52_0.htm |date=2009-04-03 }}</ref>因为旅游资源丰富，朝阳区吸引了大批游客，据统计，近年来朝阳区的旅游收入每年都在120亿元人民币以上，在北京各区县中排名首位。

== 涉外设施 ==
[[File:China National Convention Center Phase II (20211124105149).jpg|thumb|[[国家会议中心 (中国大陆)|国家会议中心]]二期]]
朝阳区是北京市、乃至中国的主要外事活动区。160个外国驻华[[使馆]]、[[联合国]]办事机构、国际足迹办事处都设在朝阳区。各国驻京新闻机构的90%以上，海外企业代表机构的60%以上也在朝阳区。朝阳区内云集了北京60％以上的外国商社，3000多家外国公司以及167家国际新闻机构。世界500强入驻北京的158家企业中，有2/3落户朝阳。外国驻华使馆中除[[俄罗斯]]、[[卢森堡]]外，都在朝阳区境内。已经形成了[[建国门外]]、[[三里屯]]、[[亮马河]]三个使馆区，东坝新区还将兴建第四个使馆区。

区内共有涉外高档宾馆60余家，数量为全市之冠。全市32家五星级饭店中，有12家在朝阳。另外，[[国家会议中心 (中国大陆)|国家会议中心]]、[[北京国际会议中心|国际会议中心]]、[[中国国际贸易中心|国际贸易中心]]、[[中国国际展览中心|国际展览中心]]（老馆）、[[中国国际青年交流中心|中日青年交流中心]]、[[燕莎购物中心]]、[[国际大厦 (北京)|国际大厦]]、[[北京国际俱乐部|国际俱乐部]]、[[友谊商店#北京/天津|国际商店]]、[[华乡别墅]]、[[华侨村]]等涉外设施都在朝阳<ref>{{cite web |title=概况信息-区情特色 |url=http://www.bjchy.gov.cn/chaoyang/cygk/gkxx/ |website=北京市朝阳区人民政府 |accessdate=2023-08-20 |archive-date=2023-11-13 |archive-url=https://web.archive.org/web/20231113102122/http://www.bjchy.gov.cn/chaoyang/cygk/gkxx/ |dead-url=no }}</ref>。 

朝阳区有涉外星级宾馆112家，占北京市总量的五分之一，另外，朝阳区旅游定点餐馆、旅游定点商店、A及旅游区（点）、旅游定点演出单位、旅游摄像公司和旅游设计分支机构达200余家。
