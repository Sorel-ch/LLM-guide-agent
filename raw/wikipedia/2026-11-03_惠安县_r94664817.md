'''惠安县'''（{{lang-nan|poj=Hūi-oaⁿ-koāiⁿ}}），别稱'''螺城'''、'''螺陽'''，是[[中华人民共和国]][[福建省]][[泉州市]]下辖的一个[[县]]，與[[晉江]]、[[南安]]，合稱[[泉州三邑]]。惠安县位于福建省东南沿海，东北部介于[[泉州湾]]和[[湄洲湾]]之间，东临[[台湾海峡]]，辖境东北连[[泉州湾]]，西接[[洛江区]]，北邻[[泉港区]]，南隔[[泉州湾]]与[[晋江市]]相望，縣政府駐[[螺城镇]]中山北街50号。

惠安的综合竞争力位居福建省第三位。惠安县位居2018年度福建省县域经济实力“十强”县（市）第六位，[[中国百强县|2018年位居全国百强县（市）第三十五位]]。2009年，惠安县[[国内生产总值|GDP总量]]344.52亿元（[[人民币汇率|折合50.43亿美元]]），人均GDP为36,573元（合5,354美元）<ref>概况相关人口与经济数据指标来源于[http://www.stats-fj.gov.cn/tongjinianjian/dz10/index-cn.htm  《福建统计年鉴2010》] {{webarchive|url=https://web.archive.org/web/20101216085029/http://www.stats-fj.gov.cn/tongjinianjian/dz10/index-cn.htm |date=2010-12-16 }}</ref>。2018年，惠安县GDP总量1,094.53亿元，人均GDP为16,328美元。

全县辖15个镇、1个民族乡（百崎回族乡），县政府驻螺城镇。惠安县以[[惠安女]]独特民俗及[[石雕]]而闻名。县境内[[北宋]][[洛阳桥]]、[[明代]][[崇武城]]均为[[国家重点文物保护单位]]。

==地名由来==
北宋太平兴国六年（981年）析晋江置县，取“以惠安民”意定县名为“惠安”，领三乡、三十四[[都甲制|都]]，治所在螺山之阳，故县城名“螺城”，属泉州。唐为晋江县地，北宋太平兴国六年（981年）析置惠安县。<ref>{{cite book |author=史为乐 |title=中国地名语源词典 |year=1995 |publisher=上海辞书出版社 |isbn=9787532602445 |page=254}}</ref>

== 地理 ==
惠安县的[[地理坐标]]为118°38'~119°05'（东经），24°49'~25°15'（北纬）。全县总面积为972k㎡<ref> {{cite web |url=http://huian.gov.cn/comeon2.asp?types=6 |title=历史文化 |accessdate=2008-05-05 |publisher=惠安县人民政府办公室 |language=zh-hans |deadurl=yes |archiveurl=https://web.archive.org/web/20080517031314/http://www.huian.gov.cn/comeon2.asp?types=6 |archivedate=2008-05-17 }}</ref>，属[[副热带季风气候|亚热带海洋性季风气候]]。

惠安县最高[[山峰]]为大雾山，主峰海拔789米。

根據[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]數據，截至2020年11月1日零時，惠安縣常住人口為781397人。<ref>{{Cite web|title=中國: 福建省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/fujian/admin/|access-date=2023-08-14|website=www.citypopulation.de|archive-date=2021-02-26|archive-url=https://web.archive.org/web/20210226125808/https://www.citypopulation.de/zh/china/fujian/admin/|dead-url=no}}</ref>

== 历史沿革 ==
[[File:惠安县山川城池图.png|thumb|《嘉庆惠安县志》中的惠安县山川城池图]]
[[新石器时期]]，惠安境内就已经有古人类活动。[[北宋]][[太平兴国]]六年（公元981年），惠安置县，县名意为“以惠安民”<ref>{{cite web |url=http://www.fjqhdmw.com/Html/2007312/2007312164324.shtml |title=福建地名多吉祥 |accessdate=2008-05-05 |date=2007-03-12 |work=福建史志（2003） |publisher=福建地名网 |language=zh-hans }}{{Dead link}}</ref>。[[熙宁]]三年，[[王安石变法]]，创[[保甲法]]，全县分为三十四[[都甲制|都]]。[[咸淳]]七年，惠安隶属泉州路。[[元贞]]元年，全县改为四乡，东为文质乡，南为行满乡、北为忠恕乡、西为信义乡，仍为十八里、三十四都。[[嘉靖]]四十三年，全县并为三十都，每都十甲。康熙二年，废除甲班，全县34都改为68铺。

1853年—1855年，[[林杯]]、[[邱二娘]]在惠安县北部（今属[[泉港区]]）起义反清，一度攻打惠安县城。

1930年9月，中共泉州特委、惠安县委发动“[[惠安暴动旧址|惠安暴动]]”。

1949年8月23日，中共闽中系统惠安人民游击队、闽南系统惠安武工队在获悉国民党惠安县政府撤离后，进驻惠安并接管县城。8月28日，[[中国人民解放军]]第八十七师师部进驻惠安。<ref>{{cite news|title=70年前，解放的号角响彻泉州城|url=http://www.qzwb.com/gb/content/2019-09/06/content_7003501.htm|author=吴拏云|publisher=泉州网|date=2019-09-06|editor=黄冬虹|access-date=2019-09-06|archive-url=https://web.archive.org/web/20191106132740/http://www.qzwb.com/gb/content/2019-09/06/content_7003501.htm|archive-date=2019-11-06|dead-url=yes}}</ref>

== 文化 ==
===語言===
惠安县境内通行多种腔调的[[闽南语]]，惠安县城腔与泉州市的府城腔大致相同，仅在发音上稍有不同。[[惠北地区]]（包括现今已经不属于惠安县的[[泉港区]]）的腔调稍有不同，有些次方言接近漳州腔，有些则接近[[莆仙语]][[仙游话]]。

===非物質文化遺產===

== 教育 ==
=== 古代历史 ===
宋太宗[[端拱]]二年（989年），[[崔拱]]中进士并成为惠安置县后第一个[[进士]]。宋徽宗[[政和 (北宋)|政和]]五年（1115年），[[吴温恭]]成为惠安县首位特奏名进士。

=== 当代教育 ===
2005年，全县共有幼儿园（点）237所、小学230所、初中阶段学校55所（含民办3所）、普通高中12所（其中，[[惠安第一中学]]、[[惠安荷山中学]]和[[泉州惠南中学]]为[[福建省达标高级中学|福建省一级达标高级中学]]）、中职学校5所（含民办2所）<ref>其中，惠安职校和开成职校为省级重点</ref>、民办高等学校1所、各级各类民办教育机构20个<ref> {{cite web |url=http://www.huian.gov.cn/comeon2.asp?types=5 |title=教育概况 |accessdate=2008-05-05 |publisher=惠安县人民政府办公室 |language=zh-hans |deadurl=yes |archiveurl=https://web.archive.org/web/20080517031306/http://www.huian.gov.cn/comeon2.asp?types=5 |archivedate=2008-05-17 }}</ref>。

2006年，全县共有公办小学217所<ref>{{cite web |url=http://www.hajxschool.com/ReadNews.asp?NewsID=1401 |title=惠安县教育发展面临的问题及对策 |accessdate=2008-05-05 |author=庄志经 |date=2007-04-24 |publisher=惠安县教育局 |language=zh-hans |archive-url=https://web.archive.org/web/20070628231401/http://www.hajxschool.com/ReadNews.asp?NewsID=1401 |archive-date=2007-06-28 |dead-url=yes }}</ref>。而截止2007年，惠安县约有办园点数278个，其中有一所市优质幼儿园；15所县优质幼儿园<ref>{{cite web |url=http://www.huian.gov.cn/report_show.asp?id=17 |title=惠安县幼儿教育概况 |accessdate=2008-05-05 |date=2007-10-12 |publisher=惠安县人民政府 |language=zh-hans |archive-date=2019-05-19 |archive-url=https://web.archive.org/web/20190519185540/http://www.huian.gov.cn/report_show.asp?id=17 |dead-url=yes }}</ref>。此外，惠安特殊教育学校为惠安县唯一一所综合性、全寄宿特殊学校<ref>{{cite web |url=http://hatj.edu.qz.fj.cn/about.htm |title=发展中的惠安县特殊教育学校 |accessdate=2008-05-05 |publisher=惠安县特殊教育学校 |language=zh-hans |archive-date=2005-09-06 |archive-url=https://web.archive.org/web/20050906162459/http://hatj.edu.qz.fj.cn/about.htm |dead-url=yes }}</ref>。

惠安县现有专科高等院校2所：[[泉州华光职业学院]]、[[泉州医学高等专科学校]]惠安校区。

惠安县为[[百强县|全国县域经济基本竞争力百强县（市）]]之一。

惠安的支柱产业有石化、[[石雕]][[石材]]业、[[建筑]][[房地产]]业、[[食品]][[饮料]]业、鞋服箱包及[[海洋]][[水产]]业。石化产业主要以中化炼化一体化项目为代表。惠安[[校服]]产业产值占全国市场份额的三分之一<ref>{{Cite web |title=惠安校服何以三分天下有其一？ |url=https://mp.weixin.qq.com/s?__biz=MjM5Nzc0NDIxNA==&mid=2656630673&idx=2&sn=7624f83629e8abfa57aa3dec5b169efd&chksm=bc9613efc46d6bf5d002ac421c0fa1bc7220e6eac748debb30e9d37834a776fdabcf31240468#rd |website=微信公众平台 |access-date=2025-06-15}}</ref>。

惠安是中国著名的石雕石材生产基地，石雕石材业是惠安的传统产业。著名石匠有淨峰鎮的[[張火廣]]、[[張木成]]父子檔、[[蔣馨]]等蔣姓石匠家族。同时，惠安是福建省首个建筑之乡及全国20个渔业大县之一。

=== 著名企业 ===
惠泉啤酒（[[燕京啤酒]]關连企業）和[[福建达利集团]]为惠安县的大型企业。惠泉啤酒为市龙头企业，达利食品集团为省龙头企业。

=== 旅遊及古蹟 ===
[[File:Temple of People's Liberation Army.JPG|thumb|left|位于崇武古城附近的[[解放军庙]]]]
[[File:青山王張將軍像 20240211.jpg|thumb|[[惠安青山宮]]祖廟致贈予[[艋舺青山宮]]的[[靈安尊王]]雕像]]
惠安县是福建省重要的旅游县市之一。

惠安县有着包括[[崇武古城]]（崇武镇）、[[洛陽橋]]（洛阳镇，中國現存最早的跨海梁式大石橋）在内的古建筑及[[青山王]]墓、[[王潮墓]]（螺阳镇）、[[施琅墓]]（黄塘镇）等古墓葬。青山灣和科山（螺城镇）也是惠安重要的旅游景点。此外，惠安也有一些名人住处，如[[陳伯達]]故居、[[李叔同]]晚年居住过的[[淨峰寺]]等景点。在这些景点中，崇武城墙、洛阳桥及施琅墓均为[[全国重点文物保护单位]]。

惠安县的古遗址主要有大岞山新石器时代遗址（崇武镇大岞村）、音楼山新石器时代遗址（百崎乡下埭村音楼山）、窑内窑址（黄塘镇松溪窑内村）、后窑窑址（螺阳镇霞光后窑村）、莲城遗址（净峰镇东莲乡）、东山城遗址（小岞乡东山村）、大坪山道场遗址（张坂镇崧山村）等。

惠安县的古墓葬包括[[青山王]]墓（即青山宫，山霞镇青山村）、黄忠墓（张坂镇后边村）、百崎回族郭氏古墓群（百崎乡下埭村、里春村、后海村）、王潮墓（螺阳镇盘龙村）、[[吴仁禄]]墓（螺阳镇盘龙村）、[[黄宗旦]]墓（涂寨镇前林村）、[[刘望海]]墓（洛阳镇屿头村）、施琅墓（黄塘镇虎窟村）、[[施世纶]]墓（黄塘镇许田村）等。

惠安县的古建筑主要有净峰寺（净峰镇山透村）、青山宫（山霞镇青山村）、孔庙（螺城镇中山北路）、昭惠庙（洛阳镇万安街洛阳桥北）、科山寺（螺城镇科山上）、葛山宫（涂寨镇庄内村）、凤阳宫（也称霞阳宫，张坂镇下洋村）、云峰庵（崇武镇靖江村）、一片瓦寺（紫山镇南安村）岩山寺（黄塘镇后郭村）及西峰后宫（张坂镇浮山村）[[劉望海]]故居、惠安螺阳镇东风村沈厝古厝群等。

== 志书 ==
嘉靖八年，知县[[莫尚简]]聘张岳纂《惠安县志》，这是惠安置县后的第一部县志。嘉靖二十一年，崇武千户[[朱彤]]编纂的《莅官总要》是崇武的首部地方志书。
