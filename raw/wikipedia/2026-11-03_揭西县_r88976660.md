'''揭西县'''为[[中国]][[广东省]]下辖县，现由[[揭阳市]]代管。县人民政府驻[[河婆街道|河婆街道霖都大道66號]]。

揭西县位于中国广东省东部、揭阳市西部，地处[[潮汕地區|潮汕]]平原西北部，榕江南河中上游。东连揭阳产业转移工业园，南邻[[普宁市|普宁]]市，西南接汕尾市陆河县，西北与梅州市五华县相邻，北与梅州市丰顺县接壤。全县总面积约1347平方公里，属亚热带季风气候，北回归线横贯县境。揭西县于1965年7月19日成立，因位于揭阳之西而得名。

== 历史沿革 ==
1965年7月19日，析[[揭阳县]]、[[陆丰县]]部分乡镇村置揭西县，成立揭西县人民政府，隶属汕头专员公署。

1975年2月，划[[普宁县]]贡山、湖西、四乡3个生产大队归揭西县棉湖镇管辖。

1983年10月，揭西县由广东省人民政府直辖，[[汕头市]]代管。

1991年12月，揭西县转由广东省人民政府直辖，[[揭阳市]]代管<ref>{{Cite web|title=历史沿革|url=http://www.jiexi.gov.cn/zjjx/lsyg/content/post_688426.html|access-date=2023-01-31|archive-date=2023-01-30|archive-url=https://web.archive.org/web/20230130210436/http://www.jiexi.gov.cn/zjjx/lsyg/content/post_688426.html|dead-url=no}}</ref>。

== 人口 ==
根據[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]數據，截至2020年11月1日零時，揭西縣常住人口為67.48萬人<ref>{{Cite web|title=2021年[揭阳]揭西县常住户籍人口和第七次人口普查结果-红黑人口库|url=https://www.hongheiku.com/xianjirank/gdxsqpm/10307.html|access-date=2023-04-02|website=www.hongheiku.com|archive-date=2021-12-08|archive-url=https://web.archive.org/web/20211208094354/https://www.hongheiku.com/xianjirank/gdxsqpm/10307.html|dead-url=no}}</ref>。

== 经济 ==
揭西县坚持“工业富县、农业强县、文旅活县”战略，积极推进高质量发展。县内加快重点民生项目建设，不断提升教育医疗服务水平，着力推进农业现代化，全面推进乡村振兴。<ref>{{Cite news|url=http://www.jieyang.gov.cn/xwdt/qxbmdt/content/post_811962.html|title=揭西县开展新媒体采风活动|work=揭阳日报|accessdate=2024-12-23|archivedate=2023-11-14|archive-url=https://web.archive.org/web/20231114044041/http://www.jieyang.gov.cn/xwdt/qxbmdt/content/post_811962.html|dead-url=no}}</ref>

== 美食 ==
揭西县是一个潮客交融的地方，形成了客家菜和潮州菜两大菜系。民间风味小吃品种丰富，特色风味小吃主要有细粄、客家擂茶、南山包粄等。

==方言==
揭西县主要说两种方言，分别[[揭西话|客家语]]和[[潮州话]]。客家语分布在河婆街道、良田乡、五云镇、上砂镇、坪上镇、龙潭镇、南山镇、灰寨镇、五经富镇和京溪园镇。而潮州话則分布在大溪镇、钱坑镇、 金和镇、 凤江镇、 棉湖镇、塔头镇和东园镇。
