'''鼓浪屿'''（{{lang-nan|poj=Kó͘-lōng-sū}}；[[邮政式拼音]]：{{lang|nan-latn|Kulanghsü/Kulangsu}}）是位于[[中华人民共和国]][[福建省]][[厦门市]][[思明区]]西南方的一个小岛，行政区划为[[鼓浪屿街道]]，面积不到2平方公里（0.77平方哩），人口约2万。有“海上花园”之美称。除环岛[[电动车]]外不允许机动车辆上岛。<ref>{{cite web|title=鼓浪屿概况-厦门市鼓浪屿|url=http://gly.xm.gov.cn/glyfq/jqgk/glygl/|accessdate=2023-04-08|language=zh-cn|archive-date=2023-04-08|archive-url=https://web.archive.org/web/20230408031538/http://gly.xm.gov.cn/glyfq/jqgk/glygl/|dead-url=no}}</ref>2005年《[[中国国家地理]]》杂志将鼓浪屿评为“中国最美的[[城区]]”第一名。<ref>{{cite web|title=第1名  厦门鼓浪屿 中国国家地理网|url=http://www.dili360.com/cng/article/p5350c3d7c810954.htm|accessdate=2023-04-08|language=zh-cn|archive-date=2023-04-08|archive-url=https://web.archive.org/web/20230408074118/http://www.dili360.com/cng/article/p5350c3d7c810954.htm|dead-url=no}}</ref>2017年7月在[[波兰]][[克拉科夫]]举行的[[第41届世界遗产大会]]上被正式列入《世界遗产名录》<ref>{{cite news|title=鼓浪屿申遗成功，助力中国世遗总数第一，今后将控制游客数|author=朱洁树|url=https://www.thepaper.cn/newsDetail_forward_1726081|work=澎湃新闻|date=2017-07-08|accessdate=2023-04-08|language=zh-cn|archive-date=2023-04-08|archive-url=https://web.archive.org/web/20230408074118/https://www.thepaper.cn/newsDetail_forward_1726081|dead-url=no}}</ref>。

== 历史 ==
[[File:Tcitp d823 kulangsu settlement and amoy in the background.jpg|thumb|left|200px|1908年的鼓浪嶼]]
鼓浪屿开拓于[[宋朝|宋]]末[[元朝|元]]初，原名“'''圆沙洲'''”、“'''圆洲仔'''”、五龍嶼。[[明朝]]改称“鼓浪屿”。[[郑成功]]曾以此为军事据点屯兵操练，对抗[[清朝|清]]兵。目前日光岩上尚存有当时建造的水操台、石寨门故址。

[[鸦片战争]]时期，[[英国|英]]军曾佔领鼓浪屿，直到1845年撤军。1843年后，[[厦门]]根据《[[中英南京条约]]》开辟为[[通商口岸]]。[[中日甲午战争]]以后，[[日本]]佔领[[台湾]]，为避免日本进一步觊觎厦门，[[清朝]]政府决定请列强“兼护厦门”<ref>张震世：《公共租界时期的鼓浪屿》，《厦门文史资料》第3辑，第20页</ref>。1902年1月10日（[[光绪]]二十七年十二月初一日），[[大英帝国|英国]]、[[美国]]、[[德意志帝国|德国]]、[[法兰西第三共和国|法国]]、[[西班牙]]、[[丹麦]]、[[荷兰]]、[[瑞典-挪威聯合|瑞典-挪威]]、[[大日本帝國|日本]]等9国驻厦门领事与清朝[[福建省]]兴泉永道台[[延年]]在鼓浪屿日本领事馆签订《[[厦门鼓浪屿公共地界章程]]》<ref>中国第一历史档案馆外务部档案，综合类，第4462号</ref>，鼓浪屿成为[[鼓浪屿公共租界|公共租界]]<ref>{{Cite web |url=http://www.shixing.org.cn/book/u/4/archives/2008/68.htm |title=厦门古代史 |access-date=2009-02-18 |archive-date=2021-08-20 |archive-url=https://web.archive.org/web/20210820004838/http://www.shixing.org.cn/book/u/4/archives/2008/68.htm |dead-url=yes }}</ref>，次年1月，鼓浪屿公共租界工部局成立。在此前后，陆续有英、美、法、德、日等13个国家先后在岛上设立[[领事馆]]。

这段时期，有很多[[传教士]]来到鼓浪屿传教。<ref>{{cite web |url=http://www.amoymagic.com/discovergulangyu5eduzh.htm |title=鼓浪屿——中国现代教育的摇篮 |publisher=Amoymagic.com |date= |accessdate=2017-07-09 |archive-date=2021-05-01 |archive-url=https://web.archive.org/web/20210501150944/http://www.amoymagic.com/discovergulangyu5eduzh.htm |dead-url=no }}</ref>例如：1898年，英国牧师[[韦玉振]]与夫人[[韦爱莉]]到鼓浪屿传教时创办的“怀德幼稚园”，是中国第一所[[幼儿园]]（现已更名为日光幼儿园）。

1949年10月，[[中国人民解放军]][[厦门战役 (1949年)|進駐鼓浪屿]]。

2003年4月经[[中华人民共和国国务院|国务院]]批准，厦门市的[[鼓浪屿区]]、思明区和[[开元区]]合并成立新的思明区。<ref>{{Cite web|title=国务院关于同意福建省调整厦门市部分行政区划的批复_2003年第19号国务院公报_中国政府网|url=http://www.gov.cn/gongbao/content/2003/content_62181.htm|access-date=2023-03-13|website=www.gov.cn|archive-date=2021-02-27|archive-url=https://web.archive.org/web/20210227184856/http://www.gov.cn/gongbao/content/2003/content_62181.htm|dead-url=no}}</ref>在这之前鼓浪屿区是全国面积最小、人口最少的副厅级行政区<ref>{{Cite web|title=见证：厦门行政区划调整 11年后回头看 1+1+1确实大于3（2）|url=http://www.taihainet.com/news/xmnews/szjj/2014-03-06/1217051_2.html|access-date=2023-03-13|archive-date=2023-03-13|archive-url=https://web.archive.org/web/20230313034524/http://www.taihainet.com/news/xmnews/szjj/2014-03-06/1217051_2.html|dead-url=no}}</ref>。

2017年7月8日 「鼓浪嶼國際歷史社區」通過了世界遺產大會的終審，成功列入世界文化遺產名錄，成為中國大陆第52項世界遺產專案<ref>{{cite web|url=http://www.un.org/chinese/News/story.asp?NewsID=28353|title=中国鼓浪屿国际历史社区被教科文组织列为世界遗产|publisher=联合国新闻|date=|accessdate=2017-07-09|archive-date=2020-03-15|archive-url=https://web.archive.org/web/20200315172703/https://news.un.org/zh/|dead-url=no}}</ref>。

== 地理 ==
面积1.77平方-{zh-hans:千米; zh-hant:公里;}-，与厦门市区相隔不到1,000-{zh-hans:米; zh-hant:公尺;}-<ref>《[[中国国家地理]]》，2005年10月，p201，[[舒婷]]。</ref>。最高海拔92.7-{zh-hans:米; zh-hant:公尺;}-（日光岩顶）。

== 风景名胜 ==
* [[日光岩]]，俗称“晃岩”，为鼓浪屿制高点。岩顶可观鼓浪屿全岛。
* 毓园（林巧稚大夫纪念园）：纪念出生于鼓浪屿的[[林巧稚]]医生。
* 皓月园：园名取自[[郑成功]]诗句“思君寝不寐，皓月透素帷”。园中[[郑成功]]石像为1985年建成，高15.7-{zh-hans:米; zh-hant:公尺;}-（据说[[郑成功]]本人身高1.57-{zh-hans:米; zh-hant:公尺;}-）。
* 菽庄花园：建于1913年，主人[[林爾嘉]]，字叔藏，又作菽庄。[[甲午战争]]后，[[台湾]]被割给[[日本]]，其父[[板橋林家]][[林維源]]全家迁来鼓浪屿居住，修建菽庄花园。面积2万多平方-{zh-hans:米; zh-hant:公尺;}-（包括水域）。1951年林爾嘉在台湾病逝后，其夫人将菽庄花园捐献给厦门市政府<ref>{{cite web |url=http://gb.cri.cn/1321/2004/06/11/661@192196.htm |title=闽江茶座，2004年6月11日 |publisher=Gb.cri.cn |date= |accessdate=2017-07-09 |archive-date=2016-03-04 |archive-url=https://web.archive.org/web/20160304135936/http://gb.cri.cn/1321/2004/06/11/661@192196.htm |dead-url=no }}</ref>。
* 厦门海底世界：1998年1月对外开放，展出鱼类350多种，一万多尾，并陈列有世界最大的[[抹香鲸]][[标本]]。<ref>{{Cite web |url=http://www.xmuww.com/ |title=厦门海底世界网站 |accessdate=2007-07-12 |archive-date=2007-06-29 |archive-url=https://web.archive.org/web/20070629235013/http://www.xmuww.com/ |dead-url=no }}</ref>

鼓浪屿岛内以步行为主要出行方式，岛上部分区域设有观光电瓶车服务，供游客乘坐。过去，岛内货物运输曾使用人力拉车。

== 其他 ==
=== 钢琴之岛 ===
[[File:Gulangyuconcert.jpg|thumb|一位女钢琴家在鼓浪屿上演出]]
鼓浪屿的人均[[钢琴]]拥有率为全国最高，因1990年成立的[[厦门大学]]附属鼓浪屿音乐学校与2006年成立的[[中央音乐学院]]附属鼓浪屿钢琴学校坐落岛上而被美名“钢琴之岛”，也因[[殷承宗]]等众多国际知名的音乐家诞生于岛上。2002年鼓浪屿被中国音乐家协会命名为“音乐之岛”，岛上有两个著名的博物馆——钢琴博物馆、风琴博物馆（八卦楼）。另外，除了鼓浪屿音乐学校与鼓浪屿钢琴学校，岛上还有一所演艺职业学院。

=== 鼓浪屿登岛轮渡及收费 ===
[[File:Gulangyu Island Ferry Round Trip Ticket.jpg|thumb|left|100px|鼓浪屿轮渡船票]]
[[File:Sanqiutian Ferry Terminal (20170120173750).jpg|thumb|鼓浪屿东侧的三丘田码头]]
2003年之前厦门至鼓浪屿的船票为往返程3元，2003年初，[[厦门]]政府拟征收80元“上岛费”以增加旅游业收入，激起厦门民众普遍抗议，因为鼓浪屿并非纯粹旅游区，其仍然是城市整体功能区的一部分<ref>{{Cite web |url=http://news.xinhuanet.com/travel/2004-12/11/content_2321131.htm |title=初定80元鼓浪屿"上岛费"引争议 |accessdate=2007-07-10 |archive-date=2005-01-23 |archive-url=https://web.archive.org/web/20050123204300/http://news.xinhuanet.com/travel/2004-12/11/content_2321131.htm |dead-url=no }}</ref>。后仅船票升至往返8元，其余照旧<ref>{{cite web |author=林漉 |url=http://news.fznews.com.cn/fujian/2006-3-31/20063314YJ+YL4_VU10741.shtml |title=3元→8元厦鼓轮渡票价明起调高 |publisher=News.fznews.com.cn |date=2006-03-31 |accessdate=2017-07-09 |archive-date=2020-08-17 |archive-url=https://web.archive.org/web/20200817104546/http://news.fznews.com.cn/fujian/2006-3-31/20063314YJ+YL4_VU10741.shtml |dead-url=no }}</ref>。

2014年10月20日，厦鼓轮渡航线调整，游客白天进入鼓浪屿的码头调整为湖里区的邮轮中心厦鼓码头及海沧区的嵩屿码头，思明区轮渡码头只保留居民专线、旅游客运夜航航班和异常天气及特殊情况应急疏运<ref>{{cite web |url=http://news.xmnn.cn/a/xmxw/201410/t20141005_4123065.htm |title=厦鼓轮渡航线20日起调整 游客将从东渡、嵩屿乘船上岛 |publisher=News.xmnn.cn |date= |accessdate=2019-06-30 |archive-date=2021-05-01 |archive-url=https://web.archive.org/web/20210501152421/http://news.xmnn.cn/a/xmxw/201410/t20141005_4123065.htm |dead-url=no }}</ref>。厦门市民乘船往返票价为8元，非厦门市民乘船票价为30元（嵩屿码头）、35元（邮轮中心厦鼓码头普通游船）、50元（邮轮中心厦鼓码头豪华游船）<ref>{{Cite web |url=http://www.xmferry.com/mtjjt/ylzhxmt/hxjpj/25329.htm |title=厦门轮渡有限公司-邮轮中心厦鼓码头 |access-date=2017-07-15 |archive-url=https://web.archive.org/web/20170823000846/http://www.xmferry.com/mtjjt/ylzhxmt/hxjpj/25329.htm |archive-date=2017-08-23 |dead-url=yes }}</ref>。

=== 日光岩索道 ===
日光岩索道1993年由原鼓浪屿区政府投资建设，连接日光岩与英雄山两大景点，索道全长202米，曾是世界上最短的索道。1995年3月正式对外营运，运营16年共5.5万小时，运载游客上千万人次。因鼓浪屿申报[[世界文化遗产]]的需要，根据《鼓浪屿历史文化遗产保护规划》及申遗专家的建议，鼓浪屿管委会将索道列入申遗整治项目，2012年6月8日索道開始拆除。<ref>{{cite web |url=http://www.glysyw.com/html/sydt/2016/0311/2016.html |title=鼓浪屿申遗重点环境整治项目日光岩索道拆除工程启动 |publisher=Glysyw.com |date=2012-06-12 |accessdate=2019-06-30 |archive-date=2021-05-01 |archive-url=https://web.archive.org/web/20210501151028/http://www.glysyw.com/html/sydt/2016/0311/2016.html |dead-url=no }}</ref>

=== [[故宫鼓浪屿外国文物馆]] ===
故宫鼓浪屿外国文物馆，位于鼓浪屿鼓新路70-80号，是[[故宫博物院]]的分馆，主要展出故宫博物院收藏的外国[[文物]]。2017年5月13日正式开馆。
