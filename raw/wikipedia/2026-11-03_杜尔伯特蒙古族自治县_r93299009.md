'''杜尔伯特蒙古族自治县'''（{{mong|m=ᠳᠥᠷᠪᠡᠳ <br>ᠮᠣᠩᠭᠣᠯ <br>ᠦᠨᠳᠦᠰᠦᠲᠡᠨ ᠦ <br>ᠥᠪᠡᠷᠲᠡᠭᠡᠨ <br>ᠵᠠᠰᠠᠬᠤ <br>ᠰᠢᠶᠠᠨ}}），简称'''杜蒙县'''，[[黑龙江省]][[大庆市]]下辖[[自治县]]。西邻[[泰来县]]，西南与[[吉林省]][[镇赉县]]隔江相望，南与[[肇源县]]毗邻，东靠大庆市区，北与齐齐哈尔市、[[林甸县]]接壤。面積6040平方公里，縣政府駐[[杜尔伯特镇|杜爾伯特鎮]]。

杜爾伯特縣是黑龍江唯一一個自治縣。每年的九月一日被定为自治县成立纪念日<ref>{{Cite web |url=http://www.daqing.gov.cn/zfgw/xqgw/4903.shtml |title=黑龙江省杜尔伯特蒙古族自治县自治条例 |access-date=2012-03-03 |archive-date=2016-03-11 |archive-url=https://web.archive.org/web/20160311201336/http://www.daqing.gov.cn/zfgw/xqgw/4903.shtml |dead-url=no }}</ref>。该县财政由黑龙江省直管，曾为[[国家级贫困县]]，但已于2012年3月被划出贫困县行列。

==历史==
杜尔伯特县历史悠久，历史上长期为[[塞外]]游牧民族的牧场，民族文化源远流长。[[金代]]属[[蒲与路]]，元代属[[辽阳行省]][[开元路 (元朝)|开元路]]。明初属[[兀良哈三衛]]之一的[[福余卫]]，後為[[韃靼 (蒙古)|東部蒙古]]各部遊牧地。[[15世纪]]，[[成吉思汗]]之弟[[哈布图哈萨尔]]第十六世孙爱纳噶率部游牧于[[嫩江]]两岸，以其分牧次序“四”而自称“[[杜爾伯特部 (博爾濟吉特氏)|杜尔伯特]]”。而据《蒙古秘史》载，成吉思汗的十二世祖[[朵奔蔑尔干]]之兄都蛙锁豁儿有4个儿子，此后被称为[[朵鲁班|朵儿边]]部，二者虽然蒙古语名称相同但实为异部。

[[File:喇嘛头饰，杜尔伯特.jpg|thumb|腰新乡后新村征集的清代[[喇嘛]]头饰]]
明末，爱纳噶的儿子阿都齐跟随[[奥巴]]归附后金。清崇德元年（1636年），阿都齐之子色稜因功封辅国公；顺治五年（1648年），编[[杜爾伯特部 (博爾濟吉特氏)|杜尔伯特部]]为一[[扎萨克]]旗，属[[哲里木盟]]。旗地在嫩江之东，大致相当于今杜尔伯特蒙古族自治县，以及安达市、林甸县一部分。光绪三十二年正月（1906年2月），将杜尔伯特旗靠近[[中东铁路]]的[[安达站 (黑龙江省)|安达站]]一带划归安达厅。同年10月，于多耐站（今东吐莫东南）设置沿江荒务行局，开始出放时、和、年、丰四段荒地。光绪三十三年（1907年），撤销沿江荒务行局，在多耐站设武兴设治公所。同时在嫩江西岸设哈拉霍硕屯垦局，管理北洋陆军退伍兵屯垦事宜。宣统元年（1909年），撤销武兴设治公所，并于哈拉霍硕屯垦局，管理杜尔伯特、扎赉特两旗荒务，称杜扎屯垦局。

[[中華民國大陸時期|民国初年]]，旗内的汉人放垦地改属泰来设治局（[[泰来县]]前身），归[[黑龍江省 (中華民國)|黑龙江省]]。1927年4月，由安达、林甸、泰来三县析置泰康设治局，<ref>{{Cite web |title=泰康设治局 |url=https://m2.guoxuedashi.net/diming/43198efmr/ |website=国学大师 |access-date=2025-07-30}}</ref>又新放民、康、物、阜四段，实行[[旗县并存]]。此时杜尔伯特旗驻巴彦查干，泰康设治局驻莫古台，而今杜尔伯特县城（泰康镇）原名小蒿子。

九一八事变后，1933年10月1日，[[满洲国]]将泰康设治局改为[[泰康县]]。1934年12月，划归[[龍江省]]管辖。1940年5月，撤销泰康县，并入杜尔伯特旗，旗公署迁至泰康街（今杜尔伯特镇）。<ref>{{Cite web |title=泰康县 |url=https://www.guoxuedashi.net/diming/43199nink/ |website=国学大师 |access-date=2025-07-30}}</ref>

[[File:Republic of China edcp location map (disputed territories) Nunkiang.svg|thumb|第二次国共内战期间，杜爾伯特縣屬嫩江省]]
1945年[[日本投降]]后，杜尔伯特旗属[[中共]][[解放区]]。1946年4月，旗、县分设，泰康县政府驻泰康镇（今[[杜尔伯特镇]]）；杜尔伯特旗政府驻巴彦查干王府；县、旗均隶于嫩南行政区。同年5月，改由[[嫩江省 (解放区)|嫩江省]]管辖。1946年8月2日，撤销泰康县，并入杜尔伯特旗，旗政府驻泰康镇。1947年2月至9月，隶属黑嫩联合省第四专区，黑嫩联合省分开后，仍隶属嫩江省。

1949年5月，撤销嫩江省，划归黑龙江省管辖。1954年8月，改属新设之[[嫩江专区]]。1956年10月10日，經[[中华人民共和国国务院|国务院]]批准，撤销杜尔伯特旗，设置杜尔伯特蒙古族自治县，自治县人民委员会仍驻泰康镇。1960年5月至1961年10月，嫩江专区曾一度撤销时，改由[[齐齐哈尔市]]领导。1984年12月15日，經国务院批准，划归齐齐哈尔市。1992年8月21日，划归[[大庆市]]，黑龙江省政府于9月26日下发通知，从12月1日起正式变更隶属关系。<ref>{{Cite web |title=大庆市杜蒙县历史沿革 |url=http://wap.tcmap.com.cn/heilongjiang/duerbotemengguzuzizhixian_history.html |website=博雅地名网 |access-date=2025-07-30}}</ref>

== 人口 ==
杜尔伯特蒙古族自治县作為黑龙江省唯一的少数民族自治县。总人口25.05万人，有[[蒙古族|蒙古]]、[[汉族|汉]]、[[满族|满]]、[[达斡尔族|达斡尔]]等17个民族，蒙古族人口4.28万人，满族、[[回族]]等其他少数民族人口约4700人，其余为汉族人口。蒙古族人口占了总人口的18.2%。

2020年末，根據全國第七次人口普查統計數據顯示：常住人口199293人<ref>{{Cite web|title=中國: 黑龙江省 (地级行政、县级行政区) - 人口统计，图表和地图|url=https://www.citypopulation.de/zh/china/heilongjiang/admin/|access-date=2023-08-22|website=www.citypopulation.de|archive-date=2023-08-22|archive-url=https://web.archive.org/web/20230822034844/https://www.citypopulation.de/zh/china/heilongjiang/admin/|dead-url=no}}</ref>。

2021年，杜爾伯特蒙古族自治縣總人口25.2萬，有蒙、漢、滿、回等21個民族，其中蒙古族人口占總人口的18.2%。
