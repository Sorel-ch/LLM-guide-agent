'''凤庆县'''是[[中国]][[云南省]][[临沧市]]辖[[县]]，亦称蒲门<ref>{{cite web |title=历史沿革 |url=http://www.ynfq.gov.cn/fqxrmzfmh/5406855026658246656/20061129/87481.html |website=凤庆县人民政府门户网站 |date=2004-04-07 |language=zh-hans |archive-url=https://web.archive.org/web/20070906111530/http://www.ynfq.gov.cn/fqxrmzfmh/5406855026658246656/20061129/87481.html |archive-date=2007-09-06 |accessdate=2008-04-23 |dead-url=yes}}</ref>。全县面积3324平方千米，2020年总人口38.54万人。

== 历史沿革 ==
[[唐朝]]，凤庆属[[姚州 (云南)|姚州]]。[[宋朝]]时，属永昌。[[元朝]][[泰定 (元朝)|泰定]]四年（1327年），凤庆内附并设[[顺宁府 (泰定)|顺宁土府]]。[[天顺 (元朝)|天顺]]元年（1328年），设顺宁府宝通州、[[庆甸县]]。[[万历]]二十六年（1598年），改为[[流官]]制，称顺宁府。[[清朝]][[乾隆]]三十五年（1770年），置[[顺宁县]]。[[中華民國|民国]]2年（1913年）废府留县，先隶[[迤南道]]，后属[[迤西道]]。民国18年，裁撤道署，直属云南省府。民国31年属[[蒙化第五行政区]]。民国三十八年（1949年）属蒙化第十一行政区。

1950年2月22日，顺宁县人民政府成立。1953年3月属[[大理专区]]。1954年6月30日，[[中华人民共和国内务部|内务部]]批准将顺宁县更名为凤庆县<ref name="政区沿革">{{Cite book |title=云南省政区沿革（1949-1985）|author=云南省民政厅|publisher=内部发行|year=1988}}</ref>{{Rp|42}}<!-- 1954年8月26日 -->。1956年改属[[临沧地区]]，1959年与[[云县]]合并后又分开，分设凤庆建制。

== 地理 ==
凤庆境内[[山脉]]，属[[怒山]]、[[云岭]]两大[[山系]]。澜沧江以南属怒山山系，澜沧江以北属云岭山系。

==经济==
2022年，凤庆县[[国内生产总值|生产总值]]达178.07亿元，按可比价格计算，比上年增长4.3%。其中[[第一产业]]增加值68.61亿元，增长5.2%；[[第二产业]]增加值46.73亿元，增长8.6%；[[第三产业]]增加值62.73亿元，增长0.5%。三次产业结构为38.5∶26.2∶35.3。人均生产总值46,665元。城乡常住居民人均可支配收入分别为35,458元、15,471元。职工年平均工资99,714元。地方一般公共预算收入6.30亿元，人均1,650元。地方一般公共预算支出30.32亿元，人均7,945元。<ref>{{Cite book|title=《云南统计年鉴2023》|author=云南省统计局|publisher=中国统计出版社|year=2023|location=北京|isbn=978-7-5230-0253-7|url=http://stats.yn.gov.cn/Pages_22_3785.aspx|access-date=2023-12-14|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214040732/http://stats.yn.gov.cn/Pages_22_3785.aspx|dead-url=no}}</ref>

==人口==
2020年[[中华人民共和国第七次全国人口普查|第七次人口普查]]结果，凤庆县总人口（常住人口）共有385,420人，城镇人口106,946人（占27.75%），乡村人口278,474人（占72.25%）。共有男性197,695人、女性187,725人，[[人類性別比|性别比]]为105.31。0—14岁人口共73,673人（占19.11%），15—59岁人口共243,784人（占63.25%），60岁及以上人口共67,963人（占17.63%），其中65岁及以上人口共47,295人（占12.27%）。大学专科学历及以上人口有22,962人，15岁以上的文盲有14,214人，占15岁以上人口的4.56%。<ref>{{Cite book|title=中国人口普查分县资料 2020|author=国务院第七次全国人口普查领导小组办公室|location=北京|publisher=中国统计出版社|year=2022|isbn=978-7-5037-9772-9}}</ref>

== 农业 ==
凤庆县农业以[[茶叶]]、[[核桃]]为主<ref>{{Cite journal |author=张兴旺 |title=核桃成为凤庆县农林业第二骨干产业 |journal=中国果业信息 |year=2007 |issue=12 |pages=33 |issn=1673-1514 |id={{CNKI|GJYR200712023|CJFQ}}}}</ref>。

凤庆县具有丰富的茶文化传统，是盛产茶叶的地方，有驰名中外的“滇红茶乡”之称<ref>{{cite web |url=http://www.fq.lcagri.gov.cn/contect.asp?id=277&subject=%C5%A9%D2%B5%B8%C5%BF%F6&name=%B7%EF%C7%EC%B5%C4%C5%A9%D2%B5%B8%C5%BF%F6 |title=凤庆农业概况 |accessdate=2008-05-05 |language=zh-hans }}{{Dead link|date=2019年10月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>。通过普查统计，全县古茶树资源面积56000多亩<ref>{{Cite journal |author=许文舟 |author2=周武 |title=云南凤庆古茶树记 |journal=福建茶叶 |year=2006 |issue=3 |pages=46 |issn=1005-2291 |id={{CNKI|FJCA200603029|CJFQ}}}}</ref>。凤庆县境内的香竹箐，有一株茶树高10.6m，围粗5.82m。据推断，这株茶树已经有超过3000年历史，并被尊称为世界茶王之母<ref>{{Cite journal |author=陈开心 |title=茶树起源在临沧 |journal=蚕桑茶叶通讯 |year=2006 |issue=3 |pages=30–31 |issn=1007-1253 |id={{CNKI|CSCT200603018|CJFQ}}}}</ref>。此外，凤庆县还有着独特的传统茶俗：[[百抖茶]]。百抖茶亦称土法功夫茶<ref>{{Cite journal |author=许文舟 |title=云南凤庆百抖茶 |url=https://kns.cnki.net/KCMS/detail/detail.aspx?dbcode=CJFQ&dbname=CJFD2007&filename=GDZC200703012 |journal=广东茶业 |year=2007 |issue=3 |pages=37 |issn=1672-7398 |id={{CNKI|GDZC200703012|CJFQ}} |access-date=2024-11-29 |archive-date=2025-12-20 |archive-url=https://web.archive.org/web/20251220095431/https://kns.cnki.net/KCMS/detail/detail.aspx?dbcode=CJFQ&dbname=CJFD2007&filename=GDZC200703012 |url-status=live }}</ref>，因其制作颇费功夫而得名。

凤庆一直以来都有种植核桃的传统。2004年12月，国家林业局授予凤庆县“中国核桃之乡”称号。

== 旅游 ==
* [[凤庆文庙]]：位于凤庆县城西文庙街，始建于明万历三十四年（1606年），清康熙八年（1669年）迁建。
* [[保石洞寺]]：位于凤庆县城东南30千米洛党乡箐头村。建于清乾隆六十年（1795年），1926年重修。
* [[青龙桥 (凤庆县)|青龙桥]]：位于凤庆县城东北约60千米的澜沧江上。始建于清乾隆二十六年（1761年），嘉庆十九年（1814年）、道光二十四年（1844年）两次复修。青龙桥是澜沧江上现顾惟一的古桥。
* [[玉龙池]]和[[黑龙潭]]：位于小湾镇与凤山镇交界的山顶上，海拔分别在2400—2860米以上，现属澜沧江省级自然保护区。
* [[庆甸遗址]]：位于麦地村明王室（寺）后的老君山峰献山顶，为元朝天顺元年（1328年）所置勐氏衙门。
* [[勐氏石城]]：为勐氏部落城堡遗址，位于新华乡牛尘山中部。
