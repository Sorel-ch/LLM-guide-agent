'''保山市'''，古称'''永昌'''，是[[中华人民共和国]][[云南省]]下辖的[[地级市]]，位于云南省西部。市境北接[[怒江州]]，东北临[[大理州]]，东南界[[临沧市]]，西邻[[德宏州]]，西北与南面一小段边界与[[缅甸]]接壤。地处[[横断山脉]]南缘，[[高黎贡山]]和[[怒山]]峡谷纵贯全境，[[澜沧江]]、[[怒江]]、[[龙川江 (金沙江支流)|龙川江]]自北往南流经。全市面积19,062平方千米，2020年总人口243.12万，市人民政府驻[[隆阳区]]。

== 历史沿革 ==
[[File:云南保山昌宁大甸山墓地-卷尖人面纹铜弯刀-战国-保山市博物馆.jpg|thumb|left|昌宁[[大甸山遗址]]出土的哀牢文物，卷尖人面纹铜弯刀]]
[[先秦]]时今市境属[[哀牢国]]，今市区一带为哀牢国统治中心。[[西汉]][[元封 (西汉)|元封]]二年（前109年），[[汉武帝]]派兵攻打哀牢，并置'''[[不韦县]]'''，属[[益州郡]]，县治在今市区隆阳坝东金鸡村。相传汉武帝徙[[南越国]]丞相[[吕嘉 (南越国)|吕嘉]]之子孙宗族于此，以彰显其先人之恶，故名；另一说为因迁徙[[秦朝]][[吕不韦]]子弟宗族于此而得名。[[东汉]][[永平 (东汉)|永平]]十二年（69年），哀牢王[[柳貌]]内属，遂析益州郡西七县设置'''[[永昌郡]]'''，治所初在[[嶲唐县]]（今[[云龙县]][[旧州镇 (云龙县)|旧州镇]]），[[建初 (东汉)|建初]]二年（77年）迁治不韦县。[[东晋]]时郡县漸废。

[[唐代]]今境属[[南诏]]，南诏国于[[澜沧江]]以西置[[永昌节度]]，治永昌城（今[[隆阳区]]）。[[大理国]]初期仍置永昌节度，并于越赕设[[软化府]]（治今[[腾冲市]]）。大理国后期改永昌节度置[[永昌府]]，改软化府为[[腾冲府]]，直至大理国被[[蒙古]]所灭。

[[元宪宗]]七年（1257年）改永昌府、腾冲府置[[千户制|千户]]。[[至元 (忽必烈)|至元]]十一年（1274年）改置[[永昌州 (云南)|永昌州]]、[[腾越州]]，属[[云南等处行中书省]][[大理路]]，又置[[腾越县]]；于故大理国广夷州地置[[石甸长官司]]（今[[施甸县]]）。至元十四年（1277年）又改腾越州置腾冲府，后以[[顺江州]]和腾越、[[越甸县|越甸]]、[[古勇县|古勇]]三县省入腾冲府。至元十五年（1278年）升永昌州为'''[[永昌府]]'''。至元二十五年（1288年）罢腾冲府、腾越县。至元二十二年（1285年），大理段氏[[金齿]]并入大理路，设[[大理金齿宣慰司]]，迁治所至永昌府。

[[File:永昌府城城墙残垣 - 2023-07-25 05.jpg|thumb|left|[[永昌府]]城城墙残垣]]
[[明]][[洪武]]十七年（1384年）改石甸长官司为[[施甸长官司]]，属永昌府。洪武二十三年（1390年）改永昌府置[[金齿军民指挥使司]]。[[永乐]]元年（1403年）于故腾冲府置[[腾冲千户所]]，又置[[湾甸州]]（治今[[昌宁县]]西湾甸）。[[宣德]]五年（1430年）置[[广邑州]]（治今[[昌宁县]]西广益）。[[正统 (年号)|正统]]元年（1436年）裁广邑州入[[顺宁府 (云南)|顺宁府]]，改为[[右甸守御千户所]]，迁治至今昌宁县[[右甸镇]]。[[正统 (年号)|正统]]十年（1445年）升腾冲千户所为[[腾冲军民指挥使司]]。[[嘉靖]]元年（1522年）复置永昌府，次年置'''[[保山县]]'''（今[[隆阳区]]）为附郭县，因城西[[太保山]]而得名。嘉靖三年（1524年）改腾冲军民指挥使司为[[腾越州]]。

[[清朝|清]][[顺治]]十六年（1659年）湾甸州改属永昌府。[[乾隆]]三十五年（1770年）于猛弄置[[龙陵厅]]，属永昌府。[[嘉庆]]二十四年（1819年）改腾越州置[[腾越直隶厅]]，[[道光]]二年（1822年）改[[腾越厅]]，属永昌府。[[光绪]]二十八年（1902年）[[迤西道]]移驻腾越厅。

[[中華民國|民国]]二年（1913年）废府、州、厅改县，废湾甸州入保山县，并改保山县为[[永昌县]]，改腾越厅为[[腾冲县]]，改龙陵厅为[[龙陵县]]，各县属[[滇西道]]。1914年滇西道更名[[腾越道]]，复改永昌县为保山县。1929年废腾越道，设云南第一殖边督办公署。1935年由保山县、[[顺宁县]]析置[[昌宁县]]，从原所属永昌府、顺宁府各取一字得名。1939年置腾龙边区行政监督公署。民国三十一年（1942年）置云南省第六行政督察区，专署驻腾冲县，1946年改称第十二行政督察区。

[[中华人民共和国]]建国后，1950年置[[保山专区]]，专员公署驻[[保山县]]。1953年析置[[德宏傣族景颇族自治区]]（后改称自治州）。1956年撤销保山专区并入[[德宏州]]。1962年析保山县南部置[[施甸县]]。1963年复置保山专区，辖保山、施甸、腾冲、龙陵、昌宁5县。1970年保山专区改称[[保山地区]]。1983年撤销保山县，改设县级保山市。2000年12月，撤销保山地区、县级保山市，改设地级[[保山市]]；原县级保山市改置[[隆阳区]]<ref>{{Cite web |url=http://www.gov.cn/gongbao/content/2001/content_61254.htm |title=国务院关于同意云南省撤销保山地区设立地级保山市的批复 |accessdate=2017-05-11 |archive-date=2020-08-20 |archive-url=https://web.archive.org/web/20200820190636/http://www.gov.cn/gongbao/content/2001/content_61254.htm |dead-url=no }}</ref><ref>{{cite wikisource|title=国务院关于同意云南省撤销保山地区设立地级保山市的批复（国函〔2000〕137号）|publication-date=2000-12-30|wslanguage=zh|wslink=国务院关于同意云南省撤销保山地区设立地级保山市的批复}}</ref>。2015年8月，撤销腾冲县，设立[[腾冲市]]，由保山市代管<ref>[http://www.mca.gov.cn/article/yw/qhdm/qhgl/201508/20150800868043.shtml 民政部关于同意云南省撤销腾冲县设立县级腾冲市的批复]{{dead link|date=2017年11月 |bot=InternetArchiveBot |fix-attempted=yes }}</ref>。

== 地理 ==
保山跨东经98°05′～100°02′，北纬24°07′～25°52′之间，距省会昆明486公里，外与缅甸山水相依，内与大理、临沧、德宏、怒江4州市相连。

== 人口 ==
2022年末常住总人口239.7万人，比上年末减少2.1万人。全年出生率7.31‰；死亡率7.48‰；自然增长率-0.17‰。年末乡村人口151.65万人，城镇人口88.05万人，城镇常住人口占总人口比重（常住人口城镇化率）为36.73%。<ref>{{Cite web|title=保山市2022年国民经济和社会发展统计公报 - 中国统计信息网|url=http://www.tjcn.org/tjgb/25yn/37600.html|access-date=2023-10-01|website=www.tjcn.org|archive-date=2025-12-05|archive-url=https://web.archive.org/web/20251205110440/http://www.tjcn.org/tjgb/25yn/37600.html|url-status=live}}</ref>

根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为2,431,211人<ref>{{cite web |author1=保山市统计局、保山市第七次全国人口普查领导小组办公室 |title=保山市第七次全国人口普查主要数据公报 |url=http://www.baoshan.gov.cn/info/4213/4116364.htm |access-date=2023-07-23 |archive-date=2024-12-25 |archive-url=https://web.archive.org/web/20241225124222/https://www.baoshan.gov.cn/info/4213/4116364.htm |url-status=live }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的2,506,491人相比，十年共减少了75,280人，下降3%，年平均增长率为-0.3%。其中，男性人口为1,247,911人，占总人口的51.33%；女性人口为1,183,300人，占总人口的48.67%。总人口性别比（以女性为100）为105.46。0－14岁的人口为448,839人，占总人口的18.46%；15－59岁的人口为1,548,973人，占总人口的63.71%；60岁及以上的人口为433,399人，占总人口的17.83%，其中65岁及以上的人口为306,172人，占总人口的12.59%。居住在城镇的人口为853,166人，占总人口的35.09%；居住在乡村的人口为1,578,045人，占总人口的64.91%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为2,166,204人，占89.10%；各[[中国少数民族|少数民族]]人口为265,007人，占10.90%。与2010年第六次全国人口普查相比，汉族人口减少81,936人，下降3.64%，占总人口比例下降0.59个百分点；各少数民族人口增加6,656人，增长2.58%，占总人口比例增加0.59个百分点。
