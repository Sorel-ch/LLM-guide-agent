'''后里區'''位於[[臺灣]][[臺中市]]北端，介於[[大甲溪]]與[[大安溪]]之間，東西兩側由埤頭山與月眉山環繞{{r|鄉志封域志|p=45}}，境內地勢平坦，為[[后里台地]]的主要部分{{r|鄉志封域志|p=47}}。后里區的最早前身為1920年設立的「內埔-{庄}-」，1945年將內埔-{庄}-改制臺中縣豐原區內埔鄉，1950年裁撤區署，改直隸臺中縣，1955年因鄉名與[[屏東縣]][[內埔鄉]]同名，遂改以轄內最大聚落「后里」為鄉名{{r|鄉志沿革志|p=115}}，2010年縣市合併，改設為臺中市市轄區「后里區」<ref name="歷史沿革"/>。

早期境內大部分的土地原為台糖所有，並主要種植甘蔗{{r|鄉志經濟志|p=312}}，直至1990年代末期停止種植甘蔗後，后里農場與七星農場的糖廠農地作為[[中部科學園區]]三期計畫的用地，使其工業逐漸轉為科技產業發展{{sfn|施添福|2006|p=277}}<ref name="縣志續修經濟志"/>{{Rp|395}}。而在其他工業產業上，后里區是臺灣樂器製造業的重要地區之一，其有[[薩得爾企業]]等公司與{{tsl|en|Chang Lien-cheng Saxophone Museum|張連昌薩克斯風博物館}}等地標，是臺灣製造[[薩克斯風]]的產業聚集地<ref>{{Cite news |url=https://news.ltn.com.tw/news/life/breakingnews/3692625 |title=「后里阮ㄟ愛」旅遊親善大使及攝影徵件開跑 總獎金高達40萬元 |author=歐素美 |publisher=自由時報 |date=2021-10-04 |access-date=2024-10-01 |language=zh-tw |archivedate=2021-10-20 |archive-url=https://web.archive.org/web/20211020050333/https://news.ltn.com.tw/news/life/breakingnews/3692625 |dead-url=no }}</ref>。農業方面，其以花卉、[[高接梨]]、釀酒葡萄、[[马铃薯|馬鈴薯]]、[[芋]]、[[稻米]]為主，由於盛產多種花卉，有「花卉之鄉」之美譽<ref>{{Cite web |url=https://www.houli.taichung.gov.tw/980809/980811/980825/980835/1006976/post |title=機關介紹-認識后里-產業發展 |publisher=臺中市后里區公所 |date=2019-05-08 |access-date=2024-10-01 |language=zh-tw |archive-date=2022-06-30 |archive-url=https://web.archive.org/web/20220630014542/https://www.houli.taichung.gov.tw/980809/980811/980825/980835/1006976/post |dead-url=no }}</ref>。境內的著名景點有[[麗寶樂園]]、[[月眉糖廠]]、[[后里馬場]]等。

==地名沿革==
后里一帶原屬[[臺灣府]][[諸羅縣]]，1731年改隸臺灣府[[淡水廳]][[苗栗三堡|大甲堡]]，1875年改隸[[臺北府]][[新竹縣 (清朝)|新竹縣]][[苗栗三堡|竹南四堡]]。1887年台灣建省，劃歸[[臺灣府]][[苗栗縣 (清朝)|苗栗縣]][[苗栗三堡]]。

[[台灣日治時期|日本統治台灣]]後，改臺灣府為[[臺中縣 (日治時期)|臺灣縣]]、苗栗縣為苗栗出張所；隔年兩者改為臺中縣、苗栗支廳。1897年廢支廳設[[辨務署]]，改隸[[新竹縣 (日治時期)|新竹縣]]大甲辨務署，隔年廢縣併回[[臺中縣 (日治時期)|臺中縣]]。1901年廢縣、辨務署，改制為廳、[[區 (臺灣日治時期前中期)|區制]]，改隸為[[苗栗廳]]大甲支廳內埔區，為內埔地區獨立設置行政區之始，1909年廢廳併回[[臺中廳]]。1920年廢廳區，改制為州郡-{庄}-制，改隸為[[臺中州]][[豐原郡 (台灣)|豐原郡]]'''[[內埔庄 (台中州)|內埔-{庄}-]]'''。1935年的[[1935年新竹台中地震|新竹台中地震]]造成內埔-{庄}-962人死亡、1,694戶住家毀損。<ref>{{cite book|title=昭和十年　臺灣震災誌|publisher= 臺灣總督府|date=1936-03-25}}</ref>

[[臺灣戰後時期|二戰後]]，州、郡、-{庄}-改制為縣、[[縣轄區 (中華民國)|縣轄區]]、鄉，成為[[臺灣省]]臺中縣豐原區'''內埔鄉'''。因與[[屏東縣]][[內埔鄉]]同名，復於1955年改以鄉內另一大聚落'''后里'''，且該地亦有[[后里車站]]，而改名為'''后里鄉'''。2002年2月7日，樂業村併入眉山村（今眉山-{里}-）、義里村（今義-{里}--{里}-）西側分割出義德村（今義德-{里}-）。2010年12月25日配合臺中縣市合併，后里鄉改為「后里區」<ref name="歷史沿革">{{cite web |url=https://www.houli.taichung.gov.tw/980809/980811/980825/980829/1001297/post |title=機關介紹-認識后里-歷史沿革 |publisher=臺中市后里區公所 |date=2019-04-10 |access-date=2023-01-23 |language=zh-tw |archive-date=2023-01-23 |archive-url=https://web.archive.org/web/20230123222348/https://www.houli.taichung.gov.tw/980809/980811/980825/980829/1001297/post |dead-url=no }}</ref>。

==地理==
===地形===
* 后里區位於台中市北翼，北隔[[大安溪]]，和[[臺灣省]][[苗栗縣]]相接；南隔[[大甲溪]]，與[[豐原區]]、[[神岡區]]相臨；西連[[月眉山 (臺中市)|月眉山]]與[[外埔區]]為界；東以[[埤頭山]]與[[東勢區]]為鄰。
* 后里區五分之四的面積屬於台地地形，另外五分之一為丘陵地形；[[后里台地]]位於大安溪、大甲溪兩溪之間，[[大甲扇狀平原]]以東，[[東勢丘陵]]以西，地形走勢從東北側的海拔300公尺，逐漸向西南緩降成為120公尺。

===氣候===
后里區屬於[[亞熱帶季風氣候]]，冬季乾旱而夏季高溫多雨。12月至3月，平均溫皆在攝氏14至18度之間，4月至11月，平均溫高於攝氏20度。根據1961年至1975年的氣候資料顯示，后里區的年均溫為攝氏22.2度，月均溫最高為7月的攝氏27.8度，最低為1月的攝氏14.7度{{r|鄉志封域志|pp=52－53}}。年雨量約為1,383.3毫米，月平均雨量最多為6月的362.3毫米，最低為11月的15.6毫米，雨量自東邊地勢高聳處向西方的臺地地區遞減{{r|鄉志封域志|pp=53、56}}。

===區政組織===
[[File:內埔庄役場.jpg|thumb|200px|后里區公所]]
[[后里區公所]]是[[臺中市政府]]在后里區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為臺中市政府。[[区长]]由[[臺中市市長|市長]]任命，其任期為無任期保障。在區長、主任秘書與秘書之下，設有5課4室等9個內部單位<ref>{{Cite web |url=https://www.houli.taichung.gov.tw/980809/980811/980813/1001230/post |title=機關介紹 - 組織架構 |publisher=臺中市后里區公所 |date=2017-04-05 |access-date=2021-09-15 |language=zh-tw |archive-date=2022-03-28 |archive-url=https://web.archive.org/web/20220328063653/https://www.houli.taichung.gov.tw/980809/980811/980813/1001230/post |dead-url=no }}</ref>。

===行政區===
現今后里區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設內埔-{庄}-屬臺中州豐原郡{{r|鄉志政事志|p=126}}。內埔-{庄}-轄后里、墩子腳、公館、中社、新店、七塊厝、圳寮、牛稠坑、中和、舊社、四塊厝、月眉等12個大字{{sfn|施添福|2006|p=273}}。1945年，改為「內埔鄉」，屬臺中縣豐原區{{r|鄉志政事志|p=131}}。1950年，裁撤區署，內埔鄉改直隸於臺中縣{{sfn|施添福|2006|p=273}}。1955年10月10日，內埔鄉改名「后里鄉」{{r|鄉志政事志|p=131}}。2010年12月25日，臺中縣市合併改制為直轄市，后里鄉改制為市轄區「后里區」，隸屬臺中市<ref name="歷史沿革"/>。

==經濟發展==

;農畜業

;小黃公車
[[臺中市小黃公車]]是由臺中市政府交通局推動的公車系統之一，於2017年4月1日啟用，路線皆採固定時間發車且免費搭乘，乘車需於前一天預約，預約人數較多時則安排多輛計程車以提供載客服務，當中僅無臺中市市區公車行駛、停靠之路段可隨招隨停，以擴大公共運輸服務範圍至年長者、行動不便、偏遠地區、攜帶大型行李的民眾<ref>{{cite news |url=https://news.ltn.com.tw/news/life/breakingnews/2011162 |title=台中「小黃公車」下月上路！事先預約免費搭 |author=張菁雅 |date=2017-03-21 |access-date=2024-12-18 |publisher=自由時報 |language=zh-tw |archivedate=2024-02-06 |archive-url=https://web.archive.org/web/20240206074122/https://news.ltn.com.tw/news/life/breakingnews/2011162 |dead-url=no }}</ref>。行經后里區的小黃公車路線有黃18路（慈濟后里聯絡處至后里車站）<ref>{{cite web |url=https://www.traffic.taichung.gov.tw/df_ufiles/df_pics/df_file/%E9%BB%8318-1130701.png |title=黃18路后里四塊厝線 路線及各班次時間 |format=JPG |publisher=臺中市政府交通局 |access-date=2024-12-18 |language=zh-tw |archive-date=2026-08-30 |archive-url=https://web.archive.org/web/20260830092936/https://www.traffic.taichung.gov.tw/df_ufiles/df_pics/df_file/%E9%BB%8318-1130701.png |url-status=live }}</ref>、黃19路（后里口-{庄}-至外埔）<ref>{{cite web |url=https://www.traffic.taichung.gov.tw/df_ufiles/df_pics/df_image/102/%E9%BB%8319%E6%96%B01110922.jpg |title=黃19路口庄水美線 路線及各班次時間 |format=JPG |publisher=臺中市政府交通局 |access-date=2024-12-18 |language=zh-tw |archive-date=2026-08-30 |archive-url=https://web.archive.org/web/20260830092852/https://www.traffic.taichung.gov.tw/df_ufiles/df_pics/df_image/102/%E9%BB%8319%E6%96%B01110922.jpg |url-status=live }}</ref>等2條，提供眉山、聯合、舊社、墩南、墩西、墩北、墩東、厚里、后里、義德、義里、太平等12個里{{NoteTag|黃18路在后里區行經眉山里、聯合里、舊社里、墩南里、墩西里、墩北里、墩東里、厚里里、后里里、義德里、義里里等11個里。黃19路在后里區行經太平里。}}的居民搭乘<ref>{{cite web |url=https://www.traffic.taichung.gov.tw/content/index.asp?Parser=1,7,505,52 |title=首頁 > 便民服務 > 線上查詢 > 臺中市小黃公車 |publisher=臺中市政府交通局 |access-date=2024-12-18 |language=zh-tw |archive-date=2024-07-03 |archive-url=https://web.archive.org/web/20240703094202/https://www.traffic.taichung.gov.tw/content/index.asp?Parser=1,7,505,52 |dead-url=no }}</ref>。

* [[后里馬場]]：創建於1937年，是[[台灣總督府]]的產馬牧場，戰後1952年5月設立[[聯勤]]種馬牧場，替軍隊提供軍需馬匹。後來部隊機械化，馬匹的需求不再這麼重要，1997年移交鄉公所經營。由於曾經設置過很多電影的佈景，所以早期台灣的電影、電視劇取景都曾在后里馬場內拍攝，後來這些設施都陸續撤除。近年，在縣政府發展觀光的政策下，后里馬場會不定時的舉辦藝文活動，例如前一陣子的兩馬音樂季，吸引了大批民眾的參與，也使得本來平平無奇的馬場，變成后里重要的觀光勝地<ref>{{Cite web |url=http://taiwan.net.tw/pda/m1.aspx?sNo=0001112&id=9407 |title=交通部觀光局 后里馬場 |accessdate=2012-02-04 |archive-date=2012-01-19 |archive-url=https://web.archive.org/web/20120119044306/http://taiwan.net.tw/pda/m1.aspx?sNo=0001112&id=9407 |dead-url=yes }}</ref>。
