'''连州市'''（[[粵拼]]：Lin<sup>4</sup>zau<sup>1</sup>）是[[中國大陸]][[广东省]]下辖的[[县级市]]，由[[清远市]]代管。位于广东省的西北部，[[北江]]支流[[连江 (河流)|连江]]的上游。北面与靠[[湖南省]]交界，全市总[[面积]]2668[[平方公里]]。市人民政府驻[[连州镇 (连州市)|连州镇]]。

== 历史沿革 ==
连州是广东省历史文化名城。[[西汉]]初（前183年）立县，[[隋朝]][[开皇]]十年（590年）建州，称[[连州 (连县)|连州]]。[[明]][[洪武]]二年(1369)三月，[[桂阳州 (元朝)|桂阳州]]省入连州，[[清朝]]時為[[連州直隸州]]，1912年改为[[连县]]，[[抗日战争]]期间，连县曾作为广东省政府临时办公地点，1994年4月经[[中华人民共和国国务院|国务院]]批准撤县设市并改名为连州。

连州于2000多年前便有历史记载，许多历史上的著名人物，如[[唐代]]文学家[[韩愈]]，诗人[[刘禹锡]]，[[北宋]]哲学家[[周敦颐]]，[[南宋]]宰相[[张浚]]、学者[[张式]]，[[明代]]诗人[[屈大均]]，[[清代]]学者[[翁方纲]]等文人都在这里留下了诗文、墨迹和碑记。连州又是古代兵家必争之地，[[汉代]]伏波将军[[路博德]]、[[唐朝]][[黄巢]]以及[[南宋]]将领[[岳飞]]都在连州驻守过。当年[[邓小平]]、[[张云逸]]曾率领红七军转战连州，留下一段佳话。如今，连州还是第三批全国城市环境综合整治优秀城市，全国体育先进市、优秀旅游城市、广东省旅游中心城市。

== 地理 ==
=== 位置境域 ===
连州市位于广东省西北部、清远市西北部，地处北江支流[[连江_(河流)|连江（小北江）]]上游。地理坐标为北纬24°37′至25°12′、东经112°07′至112°47′。全市总面积2663.33平方千米，约占广东省总面积的1.26%；市境东西相距约68千米，南北相距约65千米，行政区域边界线全长约610千米。市境东南与[[阳山县]]毗邻，西南与[[连南瑶族自治县]]相连，西北与[[湖南省]][[蓝山县]]、[[江华瑶族自治县]]接壤，北与[[湖南省]][[临武县]]交界，东北与[[湖南省]][[宜章县]]为邻。<ref name="连州概况">{{Cite web |url=https://www.lianzhou.gov.cn/ <!--TODO：替换为"连州概况/地理位置"具体页--> |title=连州概况 |publisher=连州市人民政府 |access-date=2026-09-08 |website=连州市人民政府门户网站}}</ref>

=== 地形地貌 ===
连州地处[[南岭山脉]]南麓，地势西、北、东三面高而中部低，以山地、丘陵为主，山地约占全市总面积的72.2%，丘陵约占15.9%。主要山脉有两列：簸箕山脉绵延于丰阳、瑶安一带，主峰天堂岭海拔1712米，为全市最高峰，位于[[瑶安瑶族乡]]与湖南省蓝山县交界处；大东山山脉横跨潭岭、朝天、西江一带，主峰岩坑山海拔1604米，为全市第二高峰；其余山岭海拔多在1000米以下。星子、大路边、龙坪、保安等镇的大部分地区为小盆地，西岸、东陂两镇河流两岸为河谷盆地。<ref name="地形地貌">{{Cite web |url=https://www.lianzhou.gov.cn/ <!--TODO：替换为"地形地貌"页--> |title=地形地貌 |publisher=连州市人民政府办公室 |access-date=2026-09-08 |website=连州市人民政府门户网站}}</ref>

=== 气候 ===
连州属亚热带季风气候区，四季均受季风影响：冬季盛行偏北风，气候干冷；夏季盛行偏南风，暖湿多雨。

== 人口 ==
截至2025年末，连州市户籍人口51.78万人，常住人口37.38万人，其中城镇常住人口18.43万人，常住人口城镇化率49.32%。全年出生人口1697人，出生率4.92‰；死亡人口3348人，死亡率9.71‰；人口自然增长率为-4.79‰。<ref name="公报2025">{{Cite web |url=http://www.lianzhou.gov.cn/qylztjj/gkmlpt/content/2/2153/post_2153411.html |title=2025年连州市国民经济和社会发展统计公报 |publisher=连州市统计局 |date=2026-06-04 |access-date=2026-09-08 |website=连州市人民政府门户网站}}</ref>

== 连州国际摄影年展 ==
经文化部批准，连州国际摄影年展于2005年起每年举办一届，影展致力于打造国际性和学术性的摄影节。

连州因影展的成功举办于2006年获得中国摄影家协会授予“中国摄影之城”称号。
