'''临沂市'''，简称'''沂'''，古称'''琅琊'''、'''沂州'''，是[[中華人民共和國]][[山東省]]轄[[地級市]]，Ⅱ型大城市，位于山东省东南部，因临[[沂河]]而得名。市境西接[[枣庄市]]、[[济宁市]]，北临[[泰安市]]、[[淄博市]]、[[潍坊市]]，东界[[日照市]]，东南达[[江苏省]][[连云港市]]，南毗江苏省[[徐州市]]。地处[[山东丘陵]][[沂蒙山区]]与沂沭河冲积平原过渡带，地势北高南低。[[沂山]]、[[蒙山 (山东)|蒙山]]、[[尼山]]三大山脉分布于北部，中部为丘陵，南部为平原。[[沂河]]、[[沭河]]、[[泗水 (山东河流)|泗水]]皆发源于沂蒙山流入[[东海]]。山东省面积最大、人口最多的地级市<ref>{{Cite web|title=山东省第七次全国人口普查公报（第二号）|url=http://tjj.shandong.gov.cn/art/2021/5/21/art_6293_10287511.html|archive-url=https://web.archive.org/web/20210815154404/http://tjj.shandong.gov.cn/art/2021/5/21/art_6293_10287511.html|archive-date=2021-08-15|access-date=2023-04-22|website=山东省统计局 普查公报 |dead-url=no}}</ref>，市政府驻[[兰山区|兰山区北京路17号]]。臨沂是第三批[[全國文明城市]]、[[中国优秀旅游城市]]、[[國家园林城市]]、[[國家衛生城市]]、[[國家环境保护模范城市]]和[[國家森林城市]]。

== 歷史 ==
[[商朝]]出现[[郯國|郯]]、[[莒国|莒]]、[[费]]等方国。[[周朝|周]]灭商后，[[鲁国]]和[[齐国]]是[[周王朝]]控制东方的重要支柱，临沂地域除分属齐、鲁等国外，见于《[[春秋 (书)|春秋]]》的还有啟陽、中丘、祝丘、費、防、台、東陽、武城、丘輿、顓、陽、向、次室、根牟、於丘、杞、蒙、鄆、堂阜、蓋、艾、紀障、密、鄢陵等20个。[[战国时期]]，域内诸封国先后为齐、楚所兼并，至战国末期，南部属楚，北部属齐。

[[秦朝]][[统一六國]]後，地方实行[[郡县制]]，全国分为三十六郡，临沂地域分属[[琅琊郡]]和[[郯郡]]。[[西汉]]时，郡国并行。临沂地域分属[[徐州]]之[[琅琊国]]、[[东海郡]]、[[城阳国]]和[[兖州]]之[[泰山郡]]。[[东汉]]承西汉制度，分属徐州之[[利城郡]]、东海郡、琅琊郡、琅琊国和兖州之泰山郡、[[东莞郡]]、[[东安郡]]和城阳国。[[三国时期]]，属[[魏国]]。至魏末，分属东海国、琅琊国、东莞郡、泰山郡。[[西晋]]时期，分属徐州之琅琊国、东海郡、兰陵郡、东莞郡、兖州之泰山郡。晋室南渡后，地域先后属于[[后赵]]、[[东晋]]、[[前燕]]、[[后燕]]、[[南燕 (十六國)|南燕]]、[[前秦]]和[[北魏]]。

[[晋元帝]]在[[江乘县]]侨置[[南东海郡]]、[[南琅琊郡]]、[[南东平郡]]、[[南兰陵郡]]。南琅琊郡寄治在江乘县的金城。金城为三国[[东吴]]修筑。《[[三国志]]·吴书·孙和传》中记载：[[宝鼎]]二年(267年)十二月，“皓于金城外露宿。”到[[晋成帝]][[咸康 (东晋)|咸康]]元年(335年)，[[桓温]]任南琅琊郡内史，出镇江乘县金城，请求割丹阳郡江乘县境以立郡。不久，南琅琊郡正式在江乘县划土立定，江乘县改隶南琅琊郡。咸康七年(341年)，割江乘县西境设立临沂县。[[南朝]][[南齐|齐]][[永明]]六年(488年)，[[齊武帝]]以为江乘县白下垒（位于今[[南京市]]中央门外北崮山）依带江山，将南琅琊郡治从金城迁至白下垒，名白下城。[[陳 (南朝)|陈]][[太建]]十年(578年)废除南琅琊郡，置[[建兴郡]]。

[[隋朝]]分属[[沂州]]（琅琊郡）、[[泗州]]（[[下邳郡]]）、[[密州 (山东)|密州]]（[[高密郡]]）、[[海州]]（东海郡）、徐州（彭城郡）。[[唐朝]]分属沂州（琅琊郡）、密州（高密郡）、徐州（彭城郡）。[[宋朝]]分属沂州（琅琊郡）、密州（高密郡）、[[淮郡军]]等。宋室南渡后，分属于[[金朝]][[山东东路]]的沂州、[[莒州]]、[[邳州]]、[[泰安州]]。[[元朝]]，属[[中书省]][[山东东西道宣慰司]][[益都路]]。[[明朝]]，分属[[山东布政使司]][[兖州府]]和[[青州府]]。[[清]]初因之，[[雍正]]十二年（1734年）升沂州为[[沂州府]]，置附郭[[兰山县]]，降[[莒州]]为散州。属沂州府。有兰山、[[郯城]]、[[费县]]、[[沂水]]、[[蒙阴]]、[[日照縣|日照]]、莒州6县1州。1668年日照发生大[[地震]]。

[[中华民国]]成立后，废府撤州，实行省、道、县三级制。1913年撤销沂州府，改莒州为[[莒县]]。1914年分山东省为4道，改兰山县为[[临沂县]]，临沂地域分属济宁道和胶东道。1918年撤销。1925年10月22日，新建琅琊道，辖区即沂州府旧治全境，治所驻临沂县。1928年，琅琊道撤销，各县直隶于省。1936年，置山东省第三区行政督察专员公署。抗日战争时期，此地發生[[臨沂保衛戰]]，[[張自忠]]與[[龐炳勳]]率部於此地與日軍血戰40多日，日軍第5師團在1938年2月中旬至4月中旬戰死1,444名、戰傷5,268名<ref>JACAR(アジア歴史資料センター)Ref.C11112087000、第２軍作戦経過の概要　昭和１２年８月下旬～１３年７月中旬(防衛省防衛研究所)</ref>，其中絕大多數死傷於臨沂保衛戰。中国共产党这里创建抗日根据地。1940年8月，在沂南县青驼寺成立山东省战时工作推行委员会。1943年9月改为山东省战时行政委员会。1945年8月在莒南县大店镇成立[[山东省政府 (中共)|山东省政府]]。

1948年7月，鲁中、鲁南、滨海三个行政区合并为[[鲁中南行政区]]，设鲁中南行政公署（驻临沂城），下辖7个专区，49个县。至1949年10月1日，临沂地域分属沂蒙专区、尼山专区、台枣专区、滨海专区。中华人民共和国成立后，对行政区划进行调整。1950年5月，鲁中南行政区撤销。以[[沂蒙专区]]为基础，成立[[沂水专区]]，辖9县。以[[滨海专区]]为基础，成立[[临沂专区]]，辖9县。1953年1月将原属临沂专区的赣榆、东海、邳县、新海连市划入江苏省。1953年7月，沂水专区撤销，除日照县划入胶州专区外，所辖其余各县皆划归临沂专区，同时，原划入[[滕县专区]]的[[平邑县]]亦复归临沂专区。1956年3月，[[日照县]]划归临沂专区。至1961年4月，[[临沂专区]]辖临沂市、[[郯城]]、[[兰陵县|苍山]]、[[临沭]]、[[莒南]]、[[沂南]]、[[沂水]]、沂源、蒙阴、平邑、费县、日照、莒县1市12县。1985年3月22日，撤销日照县和石臼办事处改为县级日照市。1989年6月12日，[[日照市]]升格为地级市。1989年12月2日，沂源县划入淄博市。1992年1月，莒县划入日照市。至此，临沂地区辖临沂市、郯城、苍山、莒南、沂水、蒙阴、平邑、费县、沂南、临沭1市9县。1994年12月，撤销[[临沂地区]]和县级临沂市，设立地级临沂市。原临沂市分为兰山、河东、罗庄3个县级区。地级临沂市辖兰山、罗庄、河东3区和郯城、苍山、莒南、沂水、沂南、平邑、费县、蒙阴、[[临沭]]9县<ref>{{cite web |title=历史沿革 |url=http://www.linyi.gov.cn/sq/lygk/lsyg1.htm |website=临沂市人民政府 |accessdate=2024-10-11 |archive-date=2026-06-07 |archive-url=https://web.archive.org/web/20260607075634/https://www.linyi.gov.cn/sq/lygk/lsyg1.htm |url-status=live }}</ref>。 2014年1月21日，[[苍山县]]复名[[兰陵县]]。

== 地理 ==
临沂市位于[[山东]]的东南部，地处长三角经济圈与环渤海经济圈结合点，位于鲁南临港产业带、海洋产业联动发展示范基地、东陇海国家级重点开发区域。东连[[日照市|日照]]，地近[[黄海]]，西接[[枣庄]]、[[济宁]]、[[泰安]]，北靠[[淄博]]、[[潍坊]]，南临[[江苏]]的[[徐州]]、[[连云港]]，大致位于京沪连线的中心位置，境内有京沪高速公路穿过。临沂市以临近横贯临沂南北的山东省第二大河亦即山东省第一大内河——[[沂河]]，而得名。地跨北纬34°22′～36°13′，东经117°24′～119°11′之间，总面积17191.2平方千米，<ref>{{Cite web|title=地理位置|website=临沂市人民政府|url=http://www.linyi.gov.cn/sq/lygk/dlwz1.htm|url-status=dead|accessdate=2023-04-22|archive-date=2026-06-07|archive-url=https://web.archive.org/web/20260607074021/https://www.linyi.gov.cn/sq/lygk/dlwz1.htm}}</ref>南北最大长距228千米，东西最大宽度161千米。是[[山东省]]面积最大、人口最多的地市。<ref>{{Cite web|title=区位优势--中国临沂网|url=http://www.lytoday.com/kfly/tzys/2013-12/17/content_1161.htm|access-date=2023-04-22|archive-date=2019-05-10|archive-url=https://web.archive.org/web/20190510070945/http://www.lytoday.com/kfly/tzys/2013-12/17/content_1161.htm|dead-url=no}}</ref>

气候方面，临沂市属于典型的[[温带季风气候]]，夏季受东南季风影响，高温多雨；冬季寒冷干燥。

=== 行政区划 ===
临沂市现辖3个[[市辖区 (中华人民共和国)|市辖区]]、9个[[县 (中华人民共和国)|县]]。
* 市辖区：[[兰山区]]、[[罗庄区]]、[[河东区 (临沂市)|河东区]]
* 县：[[沂南县]]、[[郯城县]]、[[沂水县]]、[[兰陵县]]、[[费县]]、[[平邑县]]、[[莒南县]]、[[蒙阴县]]、[[临沭县]]

除正式行政区划外，临沂还设立以下经济功能区：[[国家级经济技术开发区|国家级]][[临沂经济技术开发区]]、[[国家级高新技术产业开发区|国家级]][[临沂高新技术产业开发区]]、[[临沂临港经济开发区]]、北城新区。

== 人口分布 ==
=== 人口 ===
根据2020年[[第七次全国人口普查]]，全市[[常住人口]]为1101.84万人，占全省人口比重10.85%，位列全省首位。人口性别比为104.66%，65岁及以上老年人口比重为14.12%。同[[第六次全国人口普查]]相比，十年共增加97.9万人、增长9.75%，年平均增长率为0.93%、分别高于全国全省0.4、0.35个百分点。全市常住人口中共有家庭户390万户、家庭户人口为1066.6万人。市辖区常住人口为365.2万人，占全市常住人口的比重达33.14%，比2010年提高5.8个百分点。9县常住人口为736.6万人，占全市常住人口的比重为66.86%。男性人口为563.4万人，占51.14%；女性人口为538.4万人，占48.86%。人口性别比为104.66、低于全国0.41个百分点，与2010年相比提高1.28个百分点。0-14岁人口为258.5万人、占23.46%；15-59岁人口为627万人、占56.91%；60岁及以上人口为216.3万人、占19.63%，其中65岁及以上人口为155.5万人、占14.12%。与2010年相比，0-14岁人口比重上升5.33个百分点、占比分别高出全国全省平均水平5.51个和4.68个百分点，15-59岁人口比重下降10.61个百分点<ref>{{cite web |title=临沂市第七次全国人口普查公报（第四号） |url=http://tjj.linyi.gov.cn/info/1065/10737.htm |website=临沂市统计局 |date=2021-06-11 }}{{Dead link}}</ref>。

=== 民族 ===
临沂市有53个民族，以汉族为主，有1060.88万人，占常住人口的99.45%；52个少数民族，人口为5.83万人，占常住人口的0.55%，回族最多，为4.68万人，占常住人口的0.44%，其他少数民族1.15万人，占常住人口的0.11%。<ref>{{Cite web|title=临沂市人口民族简介|url=http://tjj.linyi.gov.cn/info/1064/7456.htm|date=2020-03-13|website=临沂市统计局|access-date=2023-04-22|archive-date=2025-02-18|archive-url=https://web.archive.org/web/20250218083144/http://tjj.linyi.gov.cn/info/1064/7456.htm|url-status=dead}}</ref>

=== 公共交通 ===
临沂市公共交通起步较晚，最早可追溯于民国时期从大城市传入的“黄包车”，但巅峰时期，即使加上外地车夫，黄包车的数量也仅百余辆，且服务对象多为富商官绅。临沂自解放后至1970年，临沂市的公共交通仍然一片空白。<ref>{{Cite book |title=临沂地区志 |author=李兴河 |publisher=中华书局 |year=2001年 |isbn=7101031625 |page=城乡建设·建筑业-城市建设-临沂城建设}}</ref>直到1970年5月，临沂县城建局建立“临沂县革命委员会基本建设局公共汽车班”，临沂公交也在这时开通了第一批线路，从此填补了临沂历史上无公交的空白。<ref name=":0">{{Cite web |title=临沂公交集团 基本简介 |url=http://www.linyibus.net/gjzt/qyjj/index.html |website=临沂公交集团 |language=zh}}</ref>

==== 公交车 ====
{{Main|临沂公交}}
临沂公交多使用公共汽车。截至2026年，市区内共运营公交车2434台，自有公交场站16处。共开通常规公交线路126条，特色线路87条，线路总长3632.4公里，线网总长1572.5公里，由临沂公交集团承运。<ref name=":0" />临沂公交（不包括城际公交）车票价格为空调车2元、普通车1元。优惠政策包括普通IC卡85折、中小学生5折、60周岁以上老年人/伤残军人/残疾人免费。<ref>{{Cite web |title=临沂市物价局临价费发〔2015〕94号 |url=http://www.linyibus.net/a/4022/373/1948183490164453377.html |website=临沂公交集团 |date=2015-08-20 |language=cn}}</ref><ref>{{Cite web |title=临沂市物价局临价费发〔2017〕134号文件 |url=http://www.linyibus.net/a/4024/495/1948183490248339457.html |website=临沂公交集团 |date=2017-12-20 |language=cn}}</ref>2022年1月1日，临沂公交实行市区分时段免费乘公交政策，从首班车到9点为早高峰免费乘车时段；17点到19点为晚高峰免费乘车时段；若当天出现空气重污染警报则全天免费乘车至该警报结束<ref>{{Cite web |title=临沂公交多举措助力免费乘公交期间市民出行 |url=http://www.linyibus.net/a/4028/506/1948183303815720963.html |website=临沂公交集团 |date=2021-12-31 |language=cn}}</ref>。

临沂公交线路字头普遍带K字头，K原指全线空调车线路，截至2022年因全部普及空调车所以K字头无实际意义。BRT字头代表快速公交，G代表高铁专线，Y字头与游字头都指旅游公交<ref>{{Cite web |title=临沂市公交线路一览表 |url=http://www.linyibus.net/a/4032/331/1948183443465072641.html |website=临沂公交集团 |date=2026-07-22 |language=cn}}</ref>

* 常规线路：常规公交线路共126条，自2022年起因空调车全覆盖而统一票价2元。
* [[巴士快速交通系統|快速公交（BRT）]]：临沂快速公交有1条主线（[[临沂公交BRT1号线|BRT-1]]）和16条普通线。普通线只是途径BRT公交专用道的常规公交线路。BRT线路收费与常规线路一致。
* 城际公交：城际公交主要补充临沂市区与周边县市的交通空白。目前有往返临沭、费县、莒南、沂南、兰陵、郯城的城际公交线路，收费按距离为10元到15元不等。
* 旅游公交：旅游线路多为景区提供便利。临沂公交K256路是第一条旅游线路，后更名为Y001路。除Y001路以外，还有游1路、游2路共三条旅游公交线路。
* 定制公交：定制公交多为D字头。
* 助学线路：临沂公交目前共开通5条助学线路。<ref>{{Cite web |title=临沂第二批65台“沂蒙红”新能源公交车上线运营 |url=https://baijiahao.baidu.com/s?id=1726924133235787947&wfr=spider&for=pc |website=大众日报 |date=2022-03-10 |language=cn}}</ref>

==== 轨道交通 ====
{{Main|临沂地铁}}
临沂轨道交通目前‌仍处于规划研究阶段‌，暂无明确的开通时间表，尚未开始正式建设。早在2016年，临沂市便启动了轨道交通线网的规划编制。2017年，临沂临沂城市建设投资集团有限公司投资成立临沂轨道交通有限公司。2019年《临沂市城市轨道交通线网规划》通过省级审查，并确定3条主线并规划远期2条辅助线；2022年启动1、2号线沿线地块规划研究，明确线路走向及配套布局。<ref>{{Cite web |title=临沂市城市轨道交通线网规划（含罗庄区） |url=http://www.luozhuang.gov.cn/info/5433/64162.htm |website=罗庄区人民政府 |date=2022-10-30 |language=cn}}</ref>2023年，临沂市启动了《临沂市轨道交通线网规划修编》工作，并于2024年6月征求社会公众意见。<ref>{{Cite web |title=市长信箱 |url=https://www.linyi.gov.cn/hd/content-list.jsp?wbtreeid=1086&leadermailid=F49B22755025C527473700CD63DFB95A |website=临沂市人民政府 |date=2024-11-15 |language=cn}}</ref>

因国家“十四五”期间暂停受理地级市首轮大中运量轨道交通申报，因此临沂市轨道交通建设规划工作遥遥无期，因此在2023年启动的修编工作中对线网进行修编并预留云巴通道作为补充。<ref>{{Cite web |title=网友建议建云轨、云巴！临沂官方答复！ |url=https://sdxw.iqilu.com/w/article/YS0yMS0xNjMyMTk2NA.html |website=临沂新闻 |date=2025-03-17 |language=cn}}</ref>

== 经济 ==
随着京沪高速、胶新铁路、荷兖日铁路等的建设与电气化和临沂机场复航吞吐量突破56万人次，和临沂批发市场的扩大，其经济发展势头强劲，现正全力打造省会和半岛外的黄金三角经济第三极。气候湿润温和，适宜于农、林、牧、副、渔综合发展，盛产农副土特产品。以[[建材]]为主的非金属矿藏储量大且质量好，已被省定为建材基地，水资源充足，水质优良，发达的公路、铁路交通运输网。拥有建材、[[轻纺]]、[[食品]]、[[化学工业|化工]]、[[机械]]、[[电子]]、[[电力]]、[[煤炭]]等十几个工业门类。[[手工业]]生产历史较长，风格独特。通讯设施完备，覆盖全市。
