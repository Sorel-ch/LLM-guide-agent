'''长春龙嘉国际机场'''（{{airport codes|CGQ|ZYCC}}，简称'''长春机场'''或'''龙嘉机场'''）位于[[吉林省]][[长春市]][[九台区]]，是[[吉林省]]的航空枢纽，也是[[中国东北地区]]的四大国际机场之一。

== 概况 ==
长春龙嘉国际机场位于[[长春市]][[九台区]][[龙嘉街道]]（原[[二道区]][[龙嘉镇]]），距长春市中心约32公里，[[吉林市]]35公里，两市共用该机场。长春龙嘉机场于1998年立项，2003年5月29日全面开工，2005年8月27日零时投入运营，取代了[[长春大房身机场]]的[[民航]]功能。长春龙嘉国际机场于2011年5月完成一期全部工程，现有一条长宽为3200米×45米的跑道以及一条等长的平行滑道，[[机场飞行区等级]]为4E，[[停机坪]]面积近22万平方米，[[航站楼]]面积7.3万平方米。<ref>[http://www.ccdrc.gov.cn/ccNEWS.asp?id=270 长春市发展与改革委员会网站 长春龙嘉国际机场本月27日零时将正式启用] {{webarchive|url=https://web.archive.org/web/20120323005820/http://www.ccdrc.gov.cn/ccNEWS.asp?id=270 |date=2012-03-23 }}</ref>，现为[[哈尔滨太平国际机场]]和[[沈阳桃仙国际机场]]的备降机场。

长春龙嘉国际机场是东北唯一一座[[高速铁路]]和机场无缝衔接的大型国际机场，通过[[长珲城际铁路]][[龙嘉站]]连接机场航站楼，是中国主要建设的干线机场和东北亚门户枢纽，项目为中国国家民航总局，吉林省和长春市政府共同投资建设的重点工程，是吉林省十五期间百项重点工程之一。 1998年5月工程立项，于2005年建成。现为首都机场集团下属机场，可同时为省内各大城市提供航空服务。<ref>{{Cite web |url=http://www.ccairport.cn/News/introduction.aspx |title=存档副本 |access-date=2014-12-17 |archive-url=https://web.archive.org/web/20150720154654/http://www.ccairport.cn/News/introduction.aspx |archive-date=2015-07-20 |dead-url=yes }}</ref>

== 历史 ==
{{further|长春大房身机场}}
长春原有的民用机场为[[长春大房身机场]]，始建于1941年。由于城市建设和机场运营的矛盾日益突出，而且军民两用也造成了诸多不便，1998年5月[[中華人民共和國國務院|国务院]]、[[中華人民共和國中央軍事委員會|中央军委]]批准新建长春民用机场工程立项，并于2003年5月29日全面开工。

2005年8月27日，长春龙嘉国际机场正式投入使用；与此同时，大房身机场结束其民用历史。 长春龙嘉国际机场是国家民航总局和吉林省共同投资建设的重点工程，是吉林省十五期间百项重点工程之一。现为首都机场集团下属4E机场。

2009年6月24日，长春龙嘉国际机场开始实施一期扩建。扩建后[[机坪|候机坪]]达到22万平方米，停机位32个；[[候机楼]]7.3万平方米，设备齐全。启动综合交通枢纽项目，实现民航、铁路、公路、轨道、常规交通、出租车等多种方式的无缝对接。跑道材质为[[水泥]]，长3200米、宽45米，可起降大中型客机<ref name="ccairport">{{cite web |title=机场简介 |url=http://www.ccairport.com.cn/List/introduce |publisher=长春龙嘉国际机场 |accessdate=2022-03-31 |archive-date=2019-07-09 |archive-url=https://web.archive.org/web/20190709065525/http://www.ccairport.com.cn/List/introduce }}</ref>。

二期扩建工程于2015年10月开工建设。主要建设内容包括航站楼及高架桥工程、飞行区工程、配套工程。航站楼工程新建12.8万平方米的航站楼、5万平方米地面[[停车场]]和4万平方米地下停车楼；飞行区工程新建长1068.5米的第二平行[[滑行道]]、两条快速滑行道、一条垂直联络道及28个停机位的站坪；配套工程新建供电、供水、供暖、污水厂及辅助生活用房等。2017年竣工并通过施工单位工程验收。2018年10月19日，通过民航东北地区管理局组织的行业验收<ref name="ccairport" />。

==== T1航站楼 ====
[[File:Changchun Longjia International Airport T1 20220815.jpg|thumb|right|长春龙嘉机场T1航站楼]]
T1航站楼于2002年6月开工建设，2005年8月投入使用，建筑面积达6.23万平方米。一期续建工程投入使用后，T1航站楼总建筑面积达7.3万平方米。<ref>{{Cite web |title=长春龙嘉国际机场T1航站楼即将改造建设 |url=http://swj.changchun.gov.cn/sy/tzgg/202507/t20250718_3415812.html |website=长春市商务局 |date=2025-07-18 |access-date=2026-06-22}}</ref>2018年10月28日T2航站楼启用后，T1航站楼的国内航班陆续转场至T2航站楼，T1则仅提供国际及港澳台航班保障。<ref>{{Cite web |title=11月14日零时起 南航将转场长春龙嘉国际机场T2航站楼 |url=https://jl.cri.cn/20191106/7a737f29-c075-41dc-8b08-3cabab40be60.html |website=央广国际在线 |date=2019-11-06 |author=陈施 |access-date=2026-06-22}}</ref>候机厅设有母婴室、饮水处、充电桩及电扶梯等基础服务设施<ref name="ccairport" />。

==== T2航站楼 ====
[[File:Changchun Longjia International Airport T2 20220815.jpg|thumb|right|长春龙嘉机场T2航站楼]]
T2航站楼位于T1航站楼的东侧，有连廊与T1航站楼相连，于2018年10月28日正式启用。

T2航站楼平面呈“人”字型，东西长约650m，南北长约400m，总占地面积约5.56万平方米，总建筑面积12.8万平方米，单层面积约5万平方米。T2航站楼东[[指廊]]设有9层机坪[[塔台]]，共设置23个近机位登机口（对应42个固定[[登机桥]]、27个活动登机桥)。主楼共5个出入口，4个[[值机]]岛，56个值机柜台、14条[[安检]]通道，直梯20部、[[扶梯]]10部、自动步道梯6部，自助值机设备8台、自助行李托运设备4台，包括信息集成、离港、安检信息、广播、航显等20个系统。<ref>{{Cite web |url=http://news.carnoc.com/list/466/466691.html |title=图集{{!}}长春龙嘉机场T2航站楼10月28日启用 |access-date=2018-11-04 |archive-date=2020-04-24 |archive-url=https://web.archive.org/web/20200424024058/http://news.carnoc.com/list/466/466691.html |dead-url=no }}</ref>

T2航站楼共分4层，其中地上3层，地下1层：
* 地下一层：地下换乘通道，通往龙嘉高铁站和地下停车楼
* 一层：到达大厅，主要用作行李提取，迎接国内到达航班旅客
* 二层：旅客到达通道及中转流程办理区域
* 三层：国内航班出发大厅，主要用作旅客值机、国内安检

由于T2航站楼的空间面积比较大，为节约旅客乘机时间，2楼走廊的位置，设有6条长约50米的自动步道，乘客可通过自动步道快速到达行李提取处。T2航站楼商业、餐饮店面主要覆盖于航站楼的出发大厅、到达大厅和国内隔离区三大区域，其中商业经营涵盖书刊音像、服装服饰、儿童玩具、电子产品等多元化品类业态，餐饮方面包括中餐、西餐，可满足旅客就餐多样化需求<ref name="ccairport" />。

== 配套交通 ==
=== 城际铁路 ===
{{main|龙嘉站}}
2011年1月11日，[[长珲城际铁路]][[龙嘉站]]开通运营，龙嘉机场因此成为中国东北地区首座实现[[空铁联运]]的机场。该站位于T1航站楼南侧，为地下站，与T1及T2航站楼均设有地下连廊连通。龙嘉站每日停靠数十对往返[[长春站]]（或[[长春西站]]）至[[吉林站]]的动车组列车，亦开设有部分往返四平、延吉、白城等城市方向的车次。<ref>{{Cite web |title=长春龙嘉国际机场空铁联运正当时 |url=https://whhlyt.jl.gov.cn/stdt/201904/t20190422_5810849.html |website=吉林省文化和旅游厅 |date=2019-04-22 |access-date=2026-06-22}}</ref>

===机场巴士===
龙嘉机场开设有往返長春市和吉林市市區的巴士线路<ref>{{Cite web |title=巴士线路 |url=https://www.jlairports.com/changchun/contents/15/327.html |website=吉林省民航集团有限公司 |date=2025-12-02 |access-date=2026-06-22}}</ref><ref>{{Cite web |title=最新！长春机场大巴运营时间 |url=http://wglj.changchun.gov.cn/sy_44789/gzfw/202501/t20250117_3375793.html |website=长春市文化广播电视和旅游局 |date=2025-01-17 |access-date=2026-06-22}}</ref>。
* 1号线：往返全安广场（[[南关站|南关]]），途中停靠[[东方广场站|东方广场]]、乐群街、临河街，全程票价25元。机场方向发车时间05:00至19:00，每小时一班；市区方向与3号线并线运营（终点至长春站北口）。
* 2号线：往返[[卫星广场站|卫星广场]]（高速客运站），途中停靠[[世纪广场站|世纪广场]]（首地首城）、[[会展中心站 (长春市)|会展中心]]、临河街（[[职业学院站|职业学院]]），全程票价25元。机场方向发车时间08:40至16:40，每小时一班；市区方向发车时间10:00至18:00，每小时一班。
* 3号线：往返[[长春站北站|长春站北口]]（凯旋公路客运站），途中停靠东方广场、乐群街、临河街、南关、[[人民广场站 (长春市)|人民广场]]、百货大楼（重庆路）、西广场（北京大街），全程票价25元。机场方向发车时间13:30至16:30，每小时一班；市区方向首次航班落地60分钟内至末次航班落地60分钟内发车，发车间隔不超过60分钟（与1号线并线运营）。
* 999路：往返吉林市（欧亚综合体），途中停靠越山东路、桃源广场、世纪广场，全程票价18元。机场方向发车时间04:00至19:00，每30分钟至60分钟一班；市区方向发车时间09:30至次日01:00，每30分钟至60分钟一班。

== 未来规划 ==
机场三期设计规模为客运吞吐量3,800万人次、货邮吞吐量27万吨，总投资300亿元，建设第二条跑道、平行滑行道、快速出口滑行道及垂直联络滑行道，建设T3A航站楼及相应站坪机位、站坪滑行道等<ref>{{Cite web |title=吉林省国民经济和社会发展第十四个五年规划和2035年远景目标纲要 |url=https://xxgk.jl.gov.cn/szf/gkml/202103/W020211203538197228678.pdf |date=2021-03 |author=吉林省人民政府 |access-date=2025-11-07 |archive-date=2025-02-09 |archive-url=https://web.archive.org/web/20250209061133/https://xxgk.jl.gov.cn/szf/gkml/202103/W020211203538197228678.pdf |dead-url=no }}</ref>。长春龙嘉国际机场枢纽一期北区已先行建设施工，并于2018年6月与机场T2航站楼同步投入使用。未来将适时进行枢纽一期南区建设，按照规划，一期南区将与[[长春轨道交通9号线|轨道交通9号线]]、[[九台隧道]]同步建设，包括龙嘉高铁站东扩站房、[[龙嘉机场站|地铁站]]、[[长途客运站]]、综合换乘大厅。还将建设枢纽二期工程和T3航站楼，枢纽二期位于[[长珲城际铁路]]与未来的T3航站楼之间，将来枢纽二期与T3航站楼同步建设<ref name="ccairport" />。
