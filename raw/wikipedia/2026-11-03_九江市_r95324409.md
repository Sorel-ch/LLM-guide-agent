'''九江市'''，简称'''浔'''，古称'''江州'''、'''浔阳'''、'''柴桑'''，是[[中华人民共和国]][[江西省]]下辖的[[地级市]]，位于江西省北部，有“江西北大门”之称。市境东南接[[上饶市]]，南抵[[南昌市]]、[[宜春市]]，西南界[[湖南省]][[岳阳市]]，西北邻[[湖北省]][[咸宁市]]、[[黄石市]]，北隔长江与湖北省[[黄冈市]]、[[安徽省]][[安庆市]]相望，东北达安徽省[[池州市]]。地处赣鄂皖湘四省交界，[[长江]]南岸，扼[[鄱阳湖]]口，[[幕阜山]]绵延西北，[[九岭山]]横亘西南，[[庐山]]耸立中部，东部为[[鄱阳湖平原]]，[[赣江]]在东部注入[[鄱阳湖]]，[[修水]]自西往东横贯中部，中游建有[[柘林水库]]，市政府駐八里湖大道166号。

九江市是江西省区域中心城市之一、昌九一体化双核城市、环鄱阳湖城市群副中心城市、长江中游城市群成员城市、长江经济带支点城市、赣鄂皖湘区域性现代化中心城市。

== 历史 ==
据《晋太康地记》记载，九江的得名源于“[[刘歆]]以为湖汉九水（即赣水、鄱水、余水、修水、淦水、盱水、蜀水、南水、彭水）入[[彭蠡泽]]也”。

秦设[[九江郡]]，治所在[[寿春]]（今[[安徽]][[寿县]]），范围包括了今天的九江市，不过并未置县。这是九江之名第一次出现，但是该九江郡范围很快大大缩小，到三国时被改名为[[淮南郡]]。

汉高祖六年（前201年）在此置[[柴桑县]]，汉文帝设[[寻阳]]县（县治在江北，古长江大概为今[[太白湖]]、[[龙感湖]]一线），是此地置县之始。

三国时属孙吴，柴桑隶[[武昌郡]]，寻阳隶[[庐江郡]]。

[[西晋]][[永兴 (西晋)|永兴]]元年（304年），析庐江之寻阳、武昌之柴桑二县立[[寻阳郡]]，初治寻阳县，咸康中移治柴桑县，隶[[江州]]。[[永嘉]]三年（309年），寻阳县治南迁，江北划归蕲春。江北的寻阳老城改称为“浔水城”。[[东晋]][[咸和 (东晋)|咸和]]中[[温峤]]移江州治寻阳，从此“江南之寻阳著，江北之寻阳益晦，后遂废汉寻阳县入柴桑县，自是以后皆以寻阳郡城为寻阳城矣。”<ref>《[[读史方舆纪要]]》</ref>

[[南朝梁]]析柴桑县置[[汝南]]县，析[[豫章郡]]别置[[豫宁郡]]，属[[高州]]，寻阳郡改属[[西江州]]。[[陈 (南朝)|陈]][[天嘉]]四年废高州，旋省西江州，寻阳、豫宁2郡仍属江州。

[[隋]][[开皇]]九年（589年）废郡置江州，废柴桑、汝南，复立寻阳县。十九年（599年），改浔阳县为彭蠡县。[[大业]]二年（606年），改彭蠡县为彭城县，寻废彭城县为湓城县。三年又改江州为[[九江郡]]。

[[唐]][[武德]]四年（621年）复称江州，[[貞觀 (唐朝)|贞观]]初属[[江南道]]，[[开元]]二十一年属[[江南西道]]，[[天宝 (唐朝)|天宝]]元年（742年）江州改称浔阳郡，[[乾元 (唐朝)|乾元]]元年（758年）复为江州。析湓城置浔阳、[[楚城县]]，后俱入浔阳县。[[南唐]]改浔阳县为[[德化县 (南唐)|德化县]]，废江州。

[[宋朝|宋]]复置江州。[[太平兴国]]七年（982年）析江州[[星子县|星子]]、[[都昌县|都昌]]和[[洪州 (江西省)|洪州]][[建昌县|建昌]]3县置[[南康軍|南康军]]，[[天禧 (北宋)|天禧]]四年江州、南康军同属[[江南东路]]，[[绍兴]]元年江州隶[[江南西路]]，南康军隶江南东路。[[元朝|元]]为[[江州路]]和南康路，属[[江西行中书省]]。元末[[陈友谅]]称帝，以江州为都。

[[明]]改江州路和南康路为[[九江府]]和[[南康府]]，从此九江之名基本固定。[[清]]沿明制。

1853年9月，[[太平天國西征|太平天国西征军]]攻占九江，由检点[[林啟榮|林启容]]率部驻守，严密布防，与对岸小池口、东50里之湖口鼎足而立，互为犄角。1858年4月，[[湘军]][[李续宾]]部攻破九江，将城中近2万军民全部屠杀。李续宾的上司湖广总督官文在给[[咸丰帝]]的奏折中说：“城外勇冲杀而入，该逆（城内军民）无路可奔，号叫之声惨不可闻，自卯至午，歼除净尽……尸骸堆积，流水腥红。”<ref>《清政府镇压太平天国档案史料》</ref>

1861年，九江根据《[[天津条约]]》和《[[北京条约]]》开辟为[[商埠|通商口岸]]，并在城西长江和[[甘棠湖]]之间的狭长地段设立了[[九江英租界]]，面积150亩（1927年中国收回）。开埠不久，作为[[怡和洋行|怡和]]、[[太古洋行|太古]]轮船在江西唯一的停靠港，九江迅速取代[[樟树镇]]、[[吴城镇]]成为江西全省贸易的枢纽。发展为中国最著名的“[[四大米市]]”、“[[四大茶市]]”之一。19世纪末，[[庐山]]山顶的[[牯岭]]发展为著名的避暑地，每年夏天吸引众多中外人士上山避暑，[[中華民國|民国]]时期甚至号称中国的“夏都”。

1912年废府，各县直隶于省。1914年设浔阳道，德化县因与[[福建省 (1912年—1949年)|福建]][[德化县]]同名，改为[[九江县]]。1917年设[[九江市 (县级)|九江市]]，后又并入九江县。为解决鄂赣皖三省长江堤防问题，1936年1月31日，《[[中央日報]]》刊登[[行政院]]决议，鄂赣皖三省以长江天然主道为界，将九江县团牌洲、封廓乡划入[[湖北省 (中華民國)|湖北省]][[黄梅县]]，桑落半乡、老洲头屯等地划入[[安徽省 (中華民國)|安徽省]][[宿松县]]。此次划界，江西省失去长江主道以北所有土地，鄂赣皖三省省界确立<ref>{{Cite web |url=https://www.jjcbw.com/v2/news/article/315961.html |title=荐读九江 &#124; 历史上两场超级洪灾引发的三省划界 |accessdate=2026-01-06 |author=月明晖 |editor=编辑：王嘉琪，责编：钟千惠，审核：杨春霞 |date=2024-07-14 |work= |quote= |publisher=掌中九江，来源：长江周刊，《九江日报》总992期2024年7月14日 |language=Zh-hans |archive-date=2025-05-25 |archive-url=https://web.archive.org/web/20250525232703/https://www.jjcbw.com/v2/news/article/315961.html |url-status=live }}</ref>。

1938年7月26日，日军占领九江，实行殖民统治。<ref>{{Cite web|title=九江沦陷经过及日军暴行-江西党史网|url=http://www.jxdys.cn/article/20150518/1318.html|access-date=2021-08-29|work=www.jxdys.cn|archive-date=2021-12-16|archive-url=https://web.archive.org/web/20211216093023/http://www.jxdys.cn/article/20150518/1318.html}}</ref>1945年9月5日九江[[日本投降|光复]]。

1949年5月7日，九江解放，7月19日设九江专员公署，同年析[[九江县]]城区设县级[[九江市 (县级)|九江市]]。

1980年3月28日，九江市从九江地区划出，升为省辖市，同年5月20日市设庐山区、浔阳区、郊区三区。1983年7月27日[[地市合并]]。

1989年12月，瑞昌县撤县设市，设立县级[[瑞昌市]]。

2010年9月，设立县级[[共青城市]],原德安县茶山街道办事处、甘露镇、金湖乡，永修县江益镇和燕坊镇坪塘村、燕坊村，星子县苏家垱乡、泽泉乡划归共青城市管辖<ref>{{Cite web |url=http://www.jiujiang.gov.cn/zjjj/xqjj/201506/t20150622_1300571.htm |title=九江市政府门户网站-活力四射共青城市 |access-date=2018-07-10 |archive-url=https://web.archive.org/web/20180710194920/http://www.jiujiang.gov.cn/zjjj/xqjj/201506/t20150622_1300571.htm |archive-date=2018-07-10 |dead-url=yes }}</ref>。

2015年5月，市政府由浔阳区长虹大道66号搬迁到八里湖大道166号<ref>{{Cite web |url=http://epaper.jjxw.cn/xywb/html/2015-04/09/content_394139.htm |title=市民服务中心20日开始搬迁 |accessdate=2015-08-06 |archive-date=2017-04-11 |archive-url=https://web.archive.org/web/20170411135342/http://epaper.jjxw.cn/xywb/html/2015-04/09/content_394139.htm |dead-url=no }}</ref>。

2016年5月，庐山区更名为[[濂溪区]]，撤星子县设立县级[[庐山市]]<ref name="#1">{{Cite web |url=http://www.jiujiang.gov.cn/zjjj/jjgk/lsyg/201506/t20150613_1216637.htm |title=九江市政府门户网站-历史沿革 |access-date=2018-07-10 |archive-url=https://web.archive.org/web/20180710195515/http://www.jiujiang.gov.cn/zjjj/jjgk/lsyg/201506/t20150613_1216637.htm |archive-date=2018-07-10 |dead-url=yes }}</ref>。

2017年8月，撤销九江县，设立[[柴桑区]]<ref name="#1"/>。

2022年3月28日，九江市列为国家历史文化名城<ref name=":0">{{Cite web|title=国务院关于同意将江西省九江市列为国家历史文化名城的批复（国函〔2022〕25号）|url=http://www.gov.cn/zhengce/content/2022-04/02/content_5683190.htm|access-date=2022-04-02|work=中国政府网|archive-date=2022-04-03|archive-url=https://web.archive.org/web/20220403043108/http://www.gov.cn/zhengce/content/2022-04/02/content_5683190.htm}}</ref>。

== 地理位置 ==
九江为江西北部门户。

北隔[[长江]]、[[幕阜山]]与[[安徽]]、[[湖北]]相邻。西为[[罗霄山]]之余脉，与[[湖南]]接壤。

西部和东部多山，在永修、武宁境内建有[[柘林水库]]，为江西最大水库。中部为[[鄱阳湖平原]]和[[鄱阳湖]]区，在九江市区和鄱阳湖之间为庐山。

== 社会 ==
=== 人口 ===
根据2020年[[中华人民共和国第七次全国人口普查|第七次全国人口普查]]，全市[[常住人口]]为4,600,276人<ref>{{cite web |author1=九江市统计局、九江市第七次全国人口普查领导小组办公室 |title=九江市第七次全国人口普查公报 |url=http://tjj.jiujiang.gov.cn/zwgk/zdly/tjgb/202106/P020210611315177788811.pdf |access-date=2022-07-11 |archive-date=2021-11-03 |archive-url=https://web.archive.org/web/20211103131902/http://tjj.jiujiang.gov.cn/zwgk/zdly/tjgb/202106/P020210611315177788811.pdf |dead-url=yes }}</ref>。同[[中华人民共和国第六次全国人口普查|第六次全国人口普查]]的4,728,778人相比，十年共减少了128,502人，下降2.72%，年平均增长率为-0.28%。其中，男性人口为2,355,145人，占总人口的51.2%；女性人口为2,245,131人，占总人口的48.8%。总人口性别比（以女性为100）为104.9。0－14岁的人口为964,298人，占总人口的20.96%；15－59岁的人口为2,823,062人，占总人口的61.37%；60岁及以上的人口为812,916人，占总人口的17.67%，其中65岁及以上的人口为580,674人，占总人口的12.62%。居住在城镇的人口为2,814,240人，占总人口的61.18%；居住在乡村的人口为1,786,036人，占总人口的38.82%。

=== 民族 ===
全市常住人口中，[[汉族]]人口为4,581,491人，占99.59%；各[[中国少数民族|少数民族]]人口为18,785人，占0.41%。与2010年第六次全国人口普查相比，汉族人口减少136,681人，下降2.9%，占总人口比例下降0.18个百分点；各少数民族人口增加8,179人，增长77.12%，占总人口比例增加0.18个百分点。

=== 语言 ===
九江市区以及瑞昌大部所讲方言属于官话中的[[江淮官话]][[黄孝片]]，是一种北方方言，其余的县市属于[[赣方言]]。

== 旅游 ==
[[File:九江琵琶亭白居易石像.JPG|thumb|right|250px|九江琵琶亭白居易石像]]
[[File:九江市锁江楼古塔.JPG|thumb|right|250px|九江市锁江楼古塔]]
[[File:Lushan White Lotus Grotto Academy.JPG|thumb|right|250px|白鹿洞书院]]
[[File:东林寺.JPG|thumb|right|250px|东林寺]]

* 九江市拥有丰富的旅游资源，集名山（[[庐山]]）、名川（[[长江]]）、名湖（[[鄱阳湖]]）于一身；2022年3月28日列为[[国家历史文化名城]]<ref name=":0" />。
* 市内有风姿绰约的[[甘棠湖]]，有传说中[[三国]][[周瑜]]操练水军的点将台——[[烟水亭]]，有[[白居易]]创作千古之作《[[琵琶行]]》的[[琵琶亭]]，有[[宋江]]题反诗的[[浔阳楼]]。
* 有“匡庐奇秀甲天下山”之称的庐山是世界文化、自然遗产，山下有[[李白]]名句“飞流直下三千尺，疑是银河落九天”所吟咏的秀峰风景区，有被称为“海内第一书院”的[[白鹿洞书院]]，[[朱熹]]曾在此讲学。还有[[佛教]][[淨土宗 (中國)|净土宗]]开源之地的[[东林寺]]等。
* [[鄱阳湖]]有三分之二在九江境内。湖口有[[石钟山]]、大孤山、小孤山胜景，并曾是[[朱元璋]]大败[[陈友谅]]、[[太平天国]]军大败[[曾国藩]][[湘军]]的古战场。
* [[彭泽县]]有号称“可藏百万兵”的[[龙宫洞]]，曲折奇险；[[庐山市]]温泉密布；[[共青城市|共青城]]还有[[胡耀邦]]陵园。
* 庐山西海风景名胜区，原为云居山-柘林湖风景区，国家级风景名胜区、国家森林公园、省级地质公园、全国三大样板丛林之一，地跨永修、武宁两县，总面积680平方公里，是集游览观光、休闲度假于一体的山岳湖泊型省级重点风景名胜区。
