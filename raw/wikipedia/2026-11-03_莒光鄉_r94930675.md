'''莒光鄉'''（{{lang-cdo|mb=Kȳ-kuong-hyong}}），原稱'''東沙鄉'''、'''白犬鄉'''（{{lang-cdo|mb=Pàh-īng-hyong}}），为[[中華民國]][[福建省 (中華民國)|福建省]][[連江縣 (中華民國)|連江縣]]所管辖的一[[鄉 (中華民國)|鄉]]。位於[[馬祖列島]]南部，由七個大小不同的島嶼和岩礁組合而成'''，'''最大島為'''[[東莒島]]'''、'''[[西莒島|西莒島]]'''次之'''，'''其餘為'''犀牛嶼、大嶼'''、'''林坳'''、'''蛇山'''、及'''永留嶼'''。

莒光鄉下設青帆、田沃、西坵、大坪、福正等五個行政村落。莒光鄉公所設於[[西莒島]]的青帆村74之2號。

== 歷史 ==
=== 名稱 ===
莒光舊名'''白犬'''、'''白肯'''，「肯」為福州話「犬」之擬音），因其二島山形如二狗，東島稱'''東犬島'''，西島稱'''西犬島'''，合稱「'''白犬列島'''」。

1971年10月更名為莒光鄉，寓意「[[毋忘在莒]]」，東犬島、西犬島因此更名為東莒島、西莒島。而對其宣稱拥有主权的[[中华人民共和国]]则维持東犬、西犬之名不变，在中華人民共和國官方發行的地圖等文件資料中，白犬列島劃歸福建省[[福州市]][[長樂區]][[梅花鎮 (福州市)|梅花鎮]]<ref>{{cite web |title=2023 福州市水资源公报 |url=https://slj.fuzhou.gov.cn/gzcy/zyxz/202409/P020240909572472396987.pdf |website=福州市人民政府 |accessdate=2025-09-16 |location=中国福建 |pages=6-7 |language=zh-cn |date=2024}}</ref><ref>{{cite book |editor=高宇彤 |title=长乐市志 |date=2001 |publisher=福建人民出版社 |location=中国福建 |isbn=9787211039784 |page=29 |url=https://data.fjdsfzw.org.cn/2017-02-07/content_4.html |accessdate=2025-09-16 |language=zh-cn |chapter=岛屿与滩涂 |archive-date=2021-10-22 |archive-url=https://web.archive.org/web/20211022121018/http://data.fjdsfzw.org.cn/2017-02-07/content_4.html |dead-url=no }}</ref><ref>{{cite web |url=https://bzdt.fjmap.net/widget/townmap/result/result.html?resultid=15 |title=梅花鎮地圖 |author=福建省製圖院 |language=zh-cn |id=榕圖審〔2021〕22號  |accessdate=  }}</ref>。

當地住民常以「東島」、「西島」稱東莒、西莒。

=== 沿革 ===
1935年，長樂縣籌設'''東沙聯保辦事處'''，適逢海上與地方不靖，派往之聯保辦事處主任，不願來海島，以致擱置。

1936年，梅花鎮公所派督編員，在本區成立東沙聯保辦事處，負責編組保甲，惜抗日軍興，又有偽軍勾結日本盤據各島，海島幾成無政府狀態。東沙聯保辦事處，設於青蕃澳，開始編查保甲，轄有東莒二保、西莒二保。

1945年，抗戰勝利，福建海上保安隊進駐東、西莒，負責恢復地方秩序，維持治安，正式設立東沙聯保辦事處，區劃由梅花鎮建制。<ref>{{cite web |url=https://www.chukuang.gov.tw/chhtml/Detail/2579?mcid=52324 |title=《莒光鄉志》|website=莒光鄉公所 |publisher= |accessdate= |archiveurl=https://web.archive.org/web/20250717220557/https://www.chukuang.gov.tw/chhtml/Detail/2579?mcid=52324 |archivedate=2025-07-17 |quote= }}</ref>

1946年，置'''東沙鄉'''。轄'''青蕃保'''、'''熾坪保'''、'''滬嶼保'''，共三保二十五甲，含青蕃澳、坤丘村、熾坪澳、滬裡村、澳井村五[[自然村]]，鄉公所位於青蕃澳。{{r|六里志|p1=30|長樂市志|p2=12}}

1949年12月，改东沙乡公所为白肯乡公所。1950年10月，設[[馬祖行政公署]]，白肯鄉改為白肯區，並隸屬馬祖行政公署。1953年8月，馬祖行政公署改為閩東北行政公署，並管轄縣府遭佔的連江、長樂兩縣。而將長樂縣政府移設於白肯區内。同年9月，中央政府将“白肯区”划分为“白肯镇”、“东肯乡”和“[[東引鄉|东湧乡]]”；1954年東湧鄉改隸[[羅源縣]]<ref>{{cite web |author1=林金炎 |title=馬祖列島隸屬與建置 |url=https://www.matsu.idv.tw/print.php?f=183&t=135502&p=1 |website=馬祖資訊網 |accessdate=2025-09-16 |language=zh-tw |date=2015-04-30 |archive-date=2025-08-10 |archive-url=https://web.archive.org/web/20250810190007/https://www.matsu.idv.tw/print.php?f=183&t=135502&p=1 |dead-url=no }}</ref>。

1955年7月，閩東北行政公署改為第一行政督察區。隔年7月，第一行政督察區及長樂縣裁撤，兩鄉鎮改隸連江縣，並改名「西犬鄉」、「東犬鄉」。

1960年，中華民國政府将“西犬乡”和“东犬乡”合并为“'''白犬鄉'''”。

1971年11月，中華民國政府将“白犬鄉”更名“莒光鄉”，以示“毋忘在莒”，東犬島、西犬島因此更名為東莒島、西莒島<ref>{{cite news |title=白犬鄉更名莒光鄉 東犬西犬亦更名為東莒西莒 |url=https://tcmb.culture.tw/zh-tw/detail?indexCode=Culture_Event&id=234906 |accessdate=2025-09-16 |work=[[馬祖日報]] |publisher=馬祖日報社 |via=[[國立臺灣歷史博物館]]|date=1971-11-07 |location=中華民國福建省連江縣 |page=第二版 |language=zh-tw}}</ref>。

== 地理 ==
=== 位置 ===
莒光鄉由東莒島及西莒島兩個主島及數個無人小島组成，為[[連江縣 (中華民國)|連江縣]]（[[馬祖]]）最南端的鄉。位於福建閩江口之外，西距閩江口梅花約二十五公里，南距平潭島約38公里，北距馬祖本島約26公里，東距台灣基隆約180公里。其中東莒島總面積约2.5平方公里，西莒岛面积约2.2平方公里<ref>{{cite book |title=中華民國年鑑 |date=1987 |publisher=中華民國年鑑社 |location=臺灣 |pages=119-122 |url=https://books.google.com.sg/books?id=o_MXAQAAIAAJ |accessdate=2025-09-16 |language=zh-tw}}</ref>{{rp|120}}。

=== 鄉政組織 ===
[[連江縣莒光鄉公所|莒光鄉公所]]是莒光鄉最高層級的地方[[行政機關]]，在中華民國政府架構中為鄉自治的行政機關，同時負責執行縣政府及中央機關委辦事項，莒光鄉的自治監督機關為[[連江縣政府]]。鄉長由全體鄉民直接選舉產生，任期為四年，可連選連任一次。莒光鄉公所並置鄉政會議，為鄉政最高決策機構，在鄉長之下，設有4課2室等6個內部單位<ref>{{Cite web |url=https://www.chukuang.gov.tw/Chhtml/content/2367 |title=公所組織-組織架構 |publisher=馬祖-連江縣莒光鄉公所 |access-date=2021-10-02 |language=zh-tw |archive-date=2022-06-20 |archive-url=https://web.archive.org/web/20220620173547/https://www.chukuang.gov.tw/Chhtml/content/2367 }}</ref>。

[[連江縣莒光鄉民代表會|莒光鄉民代表會]]是莒光鄉的最高[[民意機關]]，代表莒光鄉全體鄉民立法和監察鄉政。鄉民代表由公民直選選出，任期為四年，可連選連任。莒光鄉民代表會共有5位鄉民代表，選區劃分上為不分區，主席、副主席由5位鄉民代表互選產生<ref>{{Cite web |url=http://client.matsu.idv.tw/tour/chukuang/council.php |title=鄉民代表會-鄉代會簡介 |publisher=連江縣莒光鄉公所 |access-date=2021-10-02 |language=zh-tw |archive-date=2022-03-04 |archive-url=https://web.archive.org/web/20220304130857/http://client.matsu.idv.tw/tour/chukuang/council.php }}</ref>。

莒光鄉為[[連江縣議會]]第三選區，在連江縣議會9席縣議員中，莒光鄉共選出1席縣議員<ref>{{Cite web |url=http://client.matsu.idv.tw/gov/council/ab_organization.html |title=議會簡介-議會組織 |publisher=連江縣議會 |access-date=2022-10-27 |language=zh-tw |archive-date=2021-06-13 |archive-url=https://web.archive.org/web/20210613115920/http://client.matsu.idv.tw/gov/council/ab_organization.html |dead-url=no }}</ref>。

== 交通 ==
莒光鄉的西莒、東莒二島各有一條公車路線，其中，西莒線連結了莒光鄉公所及青帆碼頭，而東莒線则連結大坪村及猛澳碼頭<ref>{{Cite web|title= 公車處莒光幸福巴士1天7班即起收費|url= https://www.chukuang.gov.tw/chhtml/Detail/2569?mcid=81584|language=zh-tw|work=馬祖日報|date=2023-02-14|accessdate=2024-11-19|archive-date=2024-11-22|archive-url=https://archive.today/20241122055947/https://www.chukuang.gov.tw/chhtml/Detail/2569?mcid=81584|dead-url=no}}</ref>。

莒光鄉聯外交通不便，主要仰赖水路，由南竿、莒光對開的交通船連結莒光及外界。而西莒、東莒则有對開交通船<ref>{{cite web |title=馬祖(南竿)-馬祖(莒光) |url=https://www.motcmpb.gov.tw/PassengerShip/Schedule?SiteId=1&NodeId=610&ShipLaneNo=C015 |website=交通部航港局 |accessdate=2025-09-16 |location=臺灣 |language=zh-tw |date=2025 |archive-date=2025-07-16 |archive-url=https://web.archive.org/web/20250716023936/https://www.motcmpb.gov.tw/PassengerShip/Schedule?SiteId=1&NodeId=610&ShipLaneNo=C015 |dead-url=no }}</ref>。

== 經濟 ==
莒光鄉位置偏遠，却是馬祖較早夜間擁有[[燈泡]]照明的鄉鎮，1950年代[[美國]][[西方公司]]進駐莒光鄉後，在西莒島設有駐紮地，就有小型[[柴油發電機]]供應夜間所需用電，但當時僅供美國人需要，其餘民間仍以[[煤油]]燈、[[蠟燭]]等為主<ref name="莒光鄉公所">{{Cite web|language=zh-TW|url=https://www.chukuang.gov.tw/chhtml/Detail/2578?mcid=52335|title=莒光鄉志 第三節　電力|author=|publisher=莒光鄉公所|date=|accessdate=2022-07-19|archive-date=2022-07-04|archive-url=https://web.archive.org/web/20220704072449/https://www.chukuang.gov.tw/chhtml/Detail/2578?mcid=52335|dead-url=no}}</ref>，直到1979年後，馬祖電力公司才先後在莒光鄉建立[[西莒發電廠]]、[[東莒發電廠]]<ref name="源雜誌">{{cite web|url=http://www.tri.org.tw/per/75/P04.PDF|title=馬祖的發電廠|author=朱瑞墉|publisher=源雜誌|date=2009-05|accessdate=2016-03-14|archive-date=2016-01-28|archive-url=https://web.archive.org/web/20160128020617/http://www.tri.org.tw/per/75/P04.PDF|dead-url=no}}</ref>{{rp|9}}。
