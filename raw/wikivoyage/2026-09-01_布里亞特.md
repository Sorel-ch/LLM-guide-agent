'''[http://www.buryatia.ru/buryatia/index_e.html 布里亞特]{{Dead link|date=October 2023 |bot=InternetArchiveBot |fix-attempted=yes }}''' （[[俄語會話手冊|俄語]]： Бур́ятия ''boor-YAH-tee-yuh''）位於[[東西伯利亞]]，是俄罗斯的一个自治共和国，南鄰[[蒙古]]，西鄰[[圖瓦]]，北部與西北部與[[伊爾庫茨克州]]接壤，東鄰[[外貝加爾邊疆區]]。

境内最著名的景点是世界最深、蓄水量最大的淡水湖，有“西伯利亚明珠”之称的贝加尔湖。首府乌兰乌德市是东西伯利亚第三大城市，城市风貌富于民族特征，是远近闻名的文化旅游城市。

== 城市 ==

*[[烏蘭烏德]] — 布里亞特的首府
*[[阿爾尚]] — 位於通卡國家公園的一座溫泉度假小鎮，以及樹林附近的佛教寺廟
*[[古西諾奧澤爾斯克]] — 位於古西諾耶湖附近的大型煤山鎮
*[[恰克圖]] — 中蒙邊境附近的一座小鎮；建於18世紀，為當時[[俄羅斯]]和[[中國|清朝]]之間的貿易中心
*[[奧爾利克‎]] — [[圖瓦]]邊境且為探索附近河流最便利的基地，美麗奧卡地區的主要城鎮且擁有火山和溫泉；對於騎馬、山地自行車、泛舟和登山偉大的目標旅客，可以前往這裡觀光
*[[北貝加爾斯克]] — 大型[[貝阿鐵路]]的貝加爾湖北岸城鎮
*[[塔爾巴哈台]] — 以“非正統”俄羅斯東正教老信徒的聚居地，這個村莊為[[烏蘭烏德]]以北約50公里處

== 了解 ==

該共和國成立於1923年，曾是與兩個地區接合而來的，目前已在[[俄羅斯|俄羅斯聯邦]]內的共和國的地位。俄羅斯人於該共和國有一百萬人口屬佔多數的族群，雖然原生藏傳佛教和薩滿教的布里亞特人（蒙古族血統的種族）仍然是一個最大的少數民族（約30％的人口）；當然，布里亞特人構成俄羅斯[[西伯利亞]]之後的最大的族群。

除了有文化的景點和首府外，布里亞特是一個自然愛好者的天堂。幾乎80％的領土被山脈覆蓋著，以及布里亞特下的管轄範圍有一半以上為貝加爾湖的沿岸線。在首府烏蘭烏德以外，主要的旅遊景點包括溫泉，貝加爾湖和蒙古風格的佛教寺院。

由於一些長期存在的因素，如缺乏足夠的自然資源、政治效率低等，許多布里亞特的基礎設施仍停留在修復的迫切需要。然而，在布里亞特有最大的列寧頭像和美麗的風景，還有很多正整修的寺院值得一看。

== 語言 ==

布里亞特語為布里亞特少數民族廣泛使用的語言。然而，每個人都會講[[俄語會話手冊|俄語]]。

== 抵達 ==

西伯利亞鐵路有停靠布里亞特的四個車站，由西向東：坦霍伊、巴布什金、[[烏蘭烏德]]，以及塞格列沃。

烏蘭烏德機場由來自[[莫斯科]]、[[克拉斯諾亞爾斯克]]、[[伊爾庫茨克]]和[[雅庫茨克]]國內航班。該機場已中止從[[烏蘭巴托]]前往各地的旅客服務。

== 環遊 ==

依照俄羅斯的標準，布里亞特大部分基礎設施仍然大致以低度開發的；以及環遊旅行對一般旅行者來說，可以說是相當困難的。鐵路大多班次少，而且道路是非常混亂也非常曲折，尤其是在[[烏蘭烏德]]。

環遊旅行飛機也因飛機的老舊和當地機場路面磨損，而請旅客務必小心。

商務巴士路線將帶你從烏蘭烏德到區域內的大多數位置。不過，為了到達奧卡地區和[[奧爾利克‎]]，你需要僱用或租一輛吉普車並使其沿著長長的土路。

在烏蘭烏德 - 納烏什基鐵路分叉跨[[西伯利亞鐵路]]將採取遊客前往[[古西諾奧澤爾斯克]]。

== 安全 ==
比起如[[莫斯科]]、[[聖彼得堡]]和[[北高加索]]的地區來說，布里亞特一般是一個非常安全的地方。然而，犯罪確實存在有的，但都屬於小規模。應避免可疑人物與酒鬼接觸；就像在大多數[[俄羅斯]]的城市一樣，他們可是會向你拳腳攻擊的。

此外，也建議採取搭乘合法的計程車 - 一些非法計程車可能將會試圖剝削你，並會拉高不合理的車費。非法計程車常見於西伯利亞鐵路的車站周邊。

== 衛生 ==

如果您決定露營在森林中，一定要帶驅蚊劑，因為蜱蟲和蚊子在該地區十分普遍。

儘管經濟狀況正在改善，醫療保健系統以西方的標準來說，仍然屬於落後的。
