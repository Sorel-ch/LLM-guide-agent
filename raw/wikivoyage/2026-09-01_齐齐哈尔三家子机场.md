'''[https://www.hljairport.com.cn/cn/branch/2/index.html 齐齐哈尔三家子机场]'''（{{IATA|NDG}}，{{ICAO|ZYQQ}}）位于[[黑龙江省]][[齐齐哈尔市]]。机场跑道长2600米，宽45米，附有有Ⅰ类仪表着陆系统，停机坪面积32000平方米，可同时停放5架中型客机。候机楼建筑面积7400平方米，分国际、国内两厅，日高峰小时可容纳100人，年可容纳旅客7万人次、货物40吨。2019年齐齐哈尔机场共实现旅客吞吐量44万人次。

==地面交通==
===机场巴士===
发车地点：候机楼门前。

发车时间：每班航班降落后30分钟。

票价：20元/人。

经停站：机场—火车站南站—三百客运站—客运东站—火车站。

==={{公交}}===
 111路城市公交,往来机场和齐齐哈尔站之间,全程共12.8公里，票价1元。由齐齐哈尔华能客运公司经营。

 '''营业时间'''
 发往市区方向:06:00-17:30，发往机场方向:06:00-18:30。

 '''行驶路线'''
 1.火车站 → 2.徐工集团 → 3.南浦立交桥 → 4.齐铁一小 → 5.南山体育场 → 6.革命公墓 →7.大乘寺 → 8.高等师范专科学校 → 9.液化气站 → 10.瑞祥小区 → 11.民祥小区 → 12.龙沙区政府 → 13.龙沙法院 → 14.市中医院南院 → 15.一中北门 → 16.第一中学 → 17.农垦局 → 18.公安指挥中心 → 19.中汇国际五金城 → 20.三合家园 → 21.奥悦水世界 → 22.中恒药业 → 23.龙华汽车有限公司 → 24.花力屯蔬菜基地 → 25.齐市民航机场
