'''江宁区'''是[[中国]][[江苏省]][[南京市]]的一个市辖区，位于南京市东南部。它不仅是南京重要的现代制造业基地和交通枢纽，更是一个历史底蕴深厚、山水风光秀丽的地区。从古老的湖熟文化到辉煌的南朝石刻，从牛首山的佛国圣境到汤山的温泉度假，江宁完美地融合了古老与现代。

== 了解 ==

江宁的历史可以追溯到数千年前，是“湖熟文化”的发源地之一。其名称始于西晋，寓意“江外无事，宁静于此”。历史上，它是南京（金陵）的重要组成部分，留下了丰富的文化遗产。

* '''语言'''：官方语言为普通话。当地方言为南京官话。
* '''最佳旅行季节'''：春秋两季（3月-5月，9月-11月）气候宜人，是游览的最佳时节。

== 抵达 ==

=== {{航空}} ===

* '''南京禄口国际机场'''就坐落于江宁区境内，是中国重要的航空枢纽。
** **地铁**： 可乘坐南京地铁S1号线（机场线）直接进入南京市区的南京南站或新街口等地。
** **出租车/网约车**： 机场到达层外有出租车和网约车上客点，可便捷前往江宁各区及南京市区。

=== {{铁路}} ===

* '''南京南站'''（亚洲最大的高铁站之一）部分位于江宁区，是京沪高铁、沪汉蓉高铁等多条高速铁路的枢纽，此外，区内还有江宁站、江宁西站。
** 从南京南站可乘坐地铁1号线、3号线、S1号线、S3号线等线路前往江宁及南京各处。

=== {{公路}} ===

* 江宁公路网络发达，通过绕越高速、长深高速、沪蓉高速等可轻松自驾抵达。

== 交通 ==

* '''地铁'''：南京地铁1号线、3号线、5号线、S1号线、S6号线等多条线路覆盖江宁，是穿梭于江宁与南京主城之间最便捷的交通方式。
* '''公交'''：江宁区内公交线路（东山公交）密集，连接各街道和景点。
* '''出租车/网约车'''：随处可见，方便快捷。

== 活动 ==

* '''温泉养生'''：在汤山选择一家心仪的温泉度假村，泡汤放松，驱散疲惫。
* '''礼佛禅修'''：在牛首山佛顶宫参与一场禅修活动，感受内心的宁静。
* '''乡村休闲'''：在石塘人家等美丽乡村骑行、徒步，体验田园之乐。
* '''购物娱乐'''：前往江宁开发区的各大商场，如景枫KINGMO、21世纪太阳城，享受现代都市生活。

== 购物 ==

* '''江宁开发区商圈'''：聚集了景枫KINGMO、21世纪太阳城、金鹰等大型购物中心，品牌齐全，餐饮娱乐丰富。
* '''特色农产品'''：可以购买江宁的土特产，如横溪西瓜、江宁草莓等。

== 安全 ==
{{Infobox emergency call|police = 110 |ambulance = 120 |fireman = 119 }}
江宁区是南京市治安非常好的区域。但仍需注意：
* 在人流密集的公共场所保管好个人财物，防止被盗。
* 遵守交通规则，注意交通安全。
