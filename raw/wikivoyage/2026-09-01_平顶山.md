== 了解 ==
{{mapframe|33.733333|113.3|zoom=auto}}
{{mapshape|wikidata=Q404116}}

[[File:Spring Temple Buddha 1.jpg|thumb| Spring Temple Buddha]]
'''平顶山市'''是[[:w:中华人民共和国|中华人民共和国]][[:w:河南省|河南省]]下辖的[[:w:地级市|地级市]]，位于河南省中南部。平顶山市西靠[[:w:伏牛山|伏牛山]]，东接[[:w:黄淮平原|黄淮平原]]，因环绕市区北面的[[:w:山峰|山峰]]皆平坦如削，故得名。[[:w:西周|西周]]时期，今平顶山市境内的[[:w:应国|应国]]以[[:w:鹰|鹰]]为[[:w:图腾|图腾]]，因此平顶山别称'''鹰城'''。

近代，平顶山市做为[[:w:中国|中国]]重要的[[:w:煤炭|煤炭]]产地，在[[:w:中华人民共和国|中华人民共和国]]建立以后，成为了一座因煤而立、因煤而兴的新兴的能源型工业城市，是中国重要的能源原材料工业基地。

平顶山市境内的旅游资源以[[:w:尧山 (鲁山县)|尧山]]、[[:w:温泉|温泉]]、[[:w:湖泊|湖泊]]和[[:w:寺庙|寺庙]]为主，2007年初，平顶山市成为[[:w:中国优秀旅游城市|中国优秀旅游城市]]中的一员。

市人民政府駐[[:w:新华区 (平顶山市)|新华区]]祥云路。

== 区划 ==
平顶山市下辖4区、2市、4县：
* 区：新华区、石龙区、卫东区、湛河区
* 市：[[汝州|汝州市]]、[[舞钢|舞钢市]]
* 县：[[叶县]]、[[郏县]]、[[宝丰|宝丰县]]、[[鲁山|鲁山县]]

石龙区被宝丰县和鲁山县所夹，与其他市辖区并不接壤。

* 机场大巴：乘坐城际大巴平顶山线至矿工路长途汽车站，票价80元/60元。

== {{交通}} ==
=== {{公交}} ===

平顶山市公交由平顶山市公共交通有限公司（简称公交公司）运营，该司是国有独资有限公司。根据市政府的资料，平顶山市中心城区公交站点500米覆盖率为100%，公共交通出行分担率23.39%。公交票价1元起步。联系电话：+86 375 2233800

平顶山市公交收班时间较早，请您提前查询好收班时间。若末班已过，请您考虑其他交通方式出行。此外，近年来平顶山公交严重亏损，甚至无法正常为员工发放工资。多有反映发车间隔长的问题，建议您出行前先查询实时公交位置。

您可以下载车来了、掌上公交等软件，或者使用相应的微信小程序查询公交车。

=== {{出租车}} ===
平顶山市出租车公告的收费规则：
<blockquote>
一、出租汽车起步价5元（2千米），超出部分每千米运价1.5元。

二、超过8千米部分加收空驶费0.5元/千米；夜间自23时至次日凌晨7时（含7时）和冰雪，大雾天气运价加收0.5元/千米；春节（农历正月初一至初五）期间加收0.5元/每千米。上述收费项目不重复计价。
</blockquote>

尽管如此，屡有反映出租车不按计费规则收费、宰客、绕远路等现象。请您酌情采用其他交通方式出行。

=== {{非机动车}} ===
平顶山市没有共享单车运营。共享单车的投放曾经引起出租车罢工，后来全部撤出了。该市亦没有共享电动车。

== 观光 ==

== 活动 ==

平顶山市在节日期间会组织各种活动。譬如2024年元宵节在市体育村举办了民俗主题活动，现场安排了定向赛、射箭、投壶、猜灯谜等活动。

一年一度的'''宝丰马街书会'''，绵延700余年不衰，被誉为“中国十大民俗”之一，由此宝丰被中国曲协命名为“曲艺之乡”，平顶山被命名为“中国曲艺城”。每年的正月十三到十五是马街书会的会期，期间，来自河南省内外的说书艺人负鼓携琴，汇集于此，规模壮观。

== {{购物}} ==
九头崖的杂货店遍布全镇，都为红色和黄色的标志很容易被识别。

还有几家'''丹尼斯超市''':一家在曙光街尽头开元路，一家在中兴路尽头公路。

'''网络市场'''位于建设路，开始于中兴路以西。 那个拐角处的建筑是建设路东侧一个半街区的主市场的一个小店。 

美发沙龙几乎被一致称为小上海，服装精品店称为小香港，四川餐馆称为小四川。

平顶山万达广场位于卫东区建设路899号，您可以考虑前去购物，或者在夜晚前去打发时间。

根据英文维基导游的观点，美食不是去平顶山的理由。这里最受欢迎的菜是一碗回绵面，既清淡又丰满。然而，当地人靠它生存下来，所以你不妨试一试。不然的话，找个饺子店，或者一家川菜馆，好像有很多。 有餐厅和许多食品推车与麻辣烫（您选择了一系列的材料：肉类、豆腐、蔬菜、蘑菇等，至少在餐厅，收费按重量）。拉面（手工面条）在这里也很受欢迎。 也许最有趣的用餐体验。这些地方出售用棍子烤的山羊的所有部分，上面有各种额外的凉菜，如四季豆和小蕃茄。坐在这些地方之一将保证能和朋友在这享受至少一个小时的时间。内蒙古小肥羊和重庆青马火锅连锁店都在光明北路。二者都是很好的标准火锅店，只是比正宗火锅店贵。如果您想节省预算，有柔嘉墨馅面包卷，很有心灵食粮，很舒服，也很美味。馅料从猪肉、芽到豆腐、洋葱和青椒不等。任何人都可以买到，通常人民币2元左右。你可以沿着街道在小摊上找到小贩。麦当劳和肯德基在市中心随处可见，也是一个很好的吃饭选择。
