'''溧水区'''是[[中国]][[江苏省]][[南京市]]的一个市辖区，位于南京市南部。这里被誉为“南京南部中心”，融合了秀美的自然山水、悠久的历史文化和充满活力的现代田园都市风貌。溧水是百里秦淮的源头，以生态优良、草莓闻名，是都市人远离喧嚣、回归自然的理想之地。

== 了解 ==

溧水建县于隋朝，已有1400多年历史。其名源于“溧水”（今胥河），意为“清澈的水流”。这里拥有优美的田园风光和丰富的物产，是长三角地区知名的“梅乡”、“草莓之乡”。

* '''语言'''：官方语言为普通话。当地方言为属于江淮官话的溧水话。
* '''最佳旅行季节'''：**春季**（3月-5月）梅花、桃花、油菜花相继盛开，特别是3月的梅花山和傅家边草莓节；**秋季**（9月-11月）天高气爽，适合户外活动和品尝当季水果。

== 交通 ==

* '''地铁'''：S7号线覆盖了溧水城区及周边主要区域，是出行的骨干。
* '''公交'''：区内公交线路网络完善，可到达各镇街和主要景点。
* '''出租车/网约车'''：方便易用。
* '''自驾'''：探索溧水乡村和山水景点最灵活的方式。

== 活动 ==

* '''草莓采摘'''： 春季到傅家边等草莓园亲手采摘草莓，是溧水最受欢迎的亲子活动。
* '''环湖骑行'''： 在石臼湖岸或无想山内规划良好的绿道上骑行，感受湖光山色。
* '''徒步登山'''： 无想山有多条成熟的徒步路线，是户外爱好者的天堂。
* '''梅园赏花'''： 初春时节，前往傅家边梅园欣赏千亩梅花盛放的壮观景象。

== 购物 ==

* '''特色农产品'''： 傅家边草莓、蓝莓、青梅制品、有机大米是绝佳的伴手礼。
* '''黑莓系列产品'''： 溧水是中国黑莓之乡，可购买黑莓果汁、果干、果酒等深加工产品。

== 安全 ==
{{Infobox emergency call|police = 110 |ambulance = 120 |fireman = 119 }}
溧水是治安非常好的地区。在自然景区内活动时，请遵守安全规定，特别是在水边和山路行走时注意防滑。
