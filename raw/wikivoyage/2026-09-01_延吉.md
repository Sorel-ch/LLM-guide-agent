'''[http://www.yanji.gov.cn/ 延吉市]'''（[[朝鲜语]]：{{lang|ko|연길시／延吉市}}）位于[[吉林省]][[延边朝鲜族自治州]]，延边朝鲜族自治州首府。与其他中国城市不同，这座小城相对干净宁静。这里有很多咖啡馆提供美味的咖啡，而且城里到处都是茶馆。

== 了解 ==
{{mapframe|43.1235|129.3880|zoom=9}}
{{mapshape|wikidata=Q713362}}
1869年一系列饥荒之后，朝鲜族人首次迁徙至延吉地区。该地区被称为延边朝鲜族自治州，是朝鲜境外最大的朝鲜族聚居地。虽然也有少量来自朝鲜和韩国的侨民，但大多数居住于此的朝鲜族人持有中国国籍而非韩国国籍。由于延边大片地区曾禁止游客进入，旅游设施几乎不存在，但这种情况正在改变。

==交流==
不出所料，由于延吉的朝鲜族人口众多，朝鲜语咸镜方言在当地非常普及。不过，延吉的大多数朝鲜族居民都能说流利的普通话和[[韩语会话手册|朝鲜语]]，所以讲普通话的游客应该不会遇到太多沟通障碍。所有官方标识也都同时使用汉字和谚文。

== {{交通}} ==
按中国标准来看，延吉算是一座小城市，但面积也不小，尤其是在盛夏或严冬，步行游览会比较拥挤。截至2025年，延吉还没有共享单车系统，这意味着游客出行只能选择出租车或公交车。
==={{出租车}}===
出租车起步价为5元人民币。除了用中文写好地址外，您也可以用朝鲜语写出来，因为延吉的大多数人（甚至汉族人）都能说一口流利的朝鲜语。出租车很多，等候时间通常不会太长。

您也可以使用滴滴等网约车软件。在机场，滴滴司机会在停车场接您，停车场就在出租车候车点对面的马路边。这样仍然很方便，您无需走太远就能到达出租车候车点。但是，在延吉西站，滴滴司机似乎需要在主干道上接客，因此从火车站乘坐滴滴出行（截至2025年）会稍微有些不便。不过，乘坐网约车前往火车站仍然非常方便。

==={{公交车}}===
在中国，公交车几乎是出行最便捷、最经济实惠的方式——前提是您能看懂中文。延吉的公交车时刻表、信息以及车内广播都使用朝鲜语。大多数线路的票价为1元人民币，部分线路为2元人民币（例如前往帽儿山）。请注意，根据线路不同，公交车最早可能在18:00就停运。

您可以通过支付宝购买延吉电子公交卡。只需在“交通”类别下搜索“延边”，然后选择“延吉”即可。上车或进入BRT小站时，请扫描二维码。

==观光==
延吉并非热门观光目的地；除了几栋相对较新的俄式建筑外，并没有什么特别引人注目的建筑，城市周边也没有令人叹为观止的景色。相反，这里并非旅游胜地，而是一处可以漫步、沉浸、迷失其中的世外桃源：韩国和中国文化的交融之地，既不张扬，又热闹非凡。

== {{购物}} ==
延吉以松茸闻名。火车站前有很多商店。

著名的延吉西市场是一座多层建筑，几乎什么都能买到。一楼摆满了泡菜、鱼干和其他各种农产品。其他楼层则出售价格实惠的纪念品、服装和其他商品。顶楼设有美食广场。

延吉百货商店提供高档购物体验。地下一层有一家大型且货源充足的超市。楼上则有餐厅和美食广场。

想要体验当地风情，不妨从延吉百货商店出发，沿着步行街向东漫步，感受一下当地的氛围。
== {{用餐}} ==
冷面，韩式中餐的特色美食，地道的韩式风味别处难寻。甜、凉、微辣，口感独特。价格在10-15元人民币左右。寻找“冷面”的招牌即可。人民路和光明街附近都有冷面店。

此外，延吉市还以其他韩式特色美食闻名，例如韩式烧烤和参鸡汤（一种用草药和人参熬制的鸡汤，配以米饭）。延吉市内也有很多“狗肉”餐厅。

延吉水市是该地区最大的早市之一。水市位于延吉江畔，主要出售各种韩国特色食品，例如年糕、泡菜、血肠和米酒。水市每天早上5点至8点半营业。在这里，您可以体验到最地道的韩国风味，并感受延吉市独特的文化魅力。

==举止==
尽管拥有中国国籍，延吉的朝鲜族人与半岛南北朝鲜族人拥有共同的文化。在与延吉朝鲜族人交往时，也应遵循[[韩国#举止|韩国相关条目]]中关于举止的部分。

== 夜生活 ==

== {{住宿}} ==
和许多其他中国城市一样，外国人只能入住符合“标准”的住宿，即使有很多廉价旅馆。这意味着旺季期间每人至少要支付100元人民币以上的费用（淡季大约是80元人民币）。如果写着“旅馆”，外国人很可能不能入住。如果写着“酒店”或“宾馆”，你或许可以入住，但价格会比那些小旅馆贵（普通旅馆的房间价格在20到50元人民币之间）。不过，外国人还是可以选择价格低于100元人民币的住宿。
